# 성경 강의 — 강의하는 책

`study-guide/`(정리본)를 재료로, 강사가 학생들 앞에서 설명하듯 풀어 쓴 읽는 책이다 (사용자 결정 2026-10-09).

## 원칙
- **원본은 정리본**: 내용의 근거와 사실·해석의 구분(〔정리자 해석〕 등), 교정 기록은 `study-guide/`에 있다. 오류를 고칠 때는 정리본을 먼저 고치고 강의책에 옮긴다.
- **재료**: 정리본에 있는 내용만 쓴다. 새 사실은 넣지 않는다. 문장을 잇는 설명(“사람의 눈에는 우연이지만 …”)만 강의의 말로 더한다.
- **성경 인용**: 따옴표 안의 인용은 개역개정 본문 그대로.
- **문체**: 합니다체, 강의하듯.
- **구성**: 책을 몇 개의 ‘강’으로 나눈다 — 1강 책을 펴기 전에(성경 속 자리, BRI, 뼈대) → 장별 강의 → 마지막 강 “이 책이 말하는 것”(주제와 연결, 알아 둘 차이).
- **요약 표**: 강마다 끝에 ‘N강 정리’ 표를 둔다 (사용자 결정).
- **해석 표시와 출처 태그는 쓰지 않는다** (사용자 결정). 견해가 갈리는 곳은 “한 강의는 … 다른 자료는 …”처럼 문장으로 밝힌다.
