## BRI [레A]

- **저자**: “여호와께서 모세에게 말씀하셨다”는 기록 — 모세 개인에게 33번(1:1; 4:1; 5:14; 6:1, 8, 19, 24; 7:22, 28; 8:1…), 모세와 아론에게 5번(10:3[표기 그대로]; 11:1; 13:1; 14:33; 15:1), 시내산에서 모세에게 명령 2번(7:38; 27:34).
- **기록 시기**: 장소는 시내산(7:38; 25:1; 26:46; 27:34).
  - 연표: 출애굽(유월절 후) BC 1446.1.15 → 시내산 도착 1446.3월(출 19:1) → 언약 체결(출 19–24), 두 번(출 34장) → **성막 완성 1445.1.1**(출 40:17) → **그가 부르심 1445.1.1(레 1:1)** → 12지파 지휘관 헌물 1445.1.1(민 7장) → 유월절 1445.1.14(민 9장) → 인구조사 1445.2.1(민 1:1) → **시내산에서 광야로 행진 1445.2.20**(민 10:11).
  - 좁게: **BC 1445.1.1 ~ 1445.2.20 — 시내산에서의 약 1달 20일(50여 일)을 기록한 책.**
  - 넓게: 성막 완공 후 ~ 모세의 죽음(신 34:5–8, BC 1406) 사이.
- **독자**: 원청중 = 출애굽 1세대 / **원독자 = 출애굽 2세대**.

## 1–7장 제사

- **두 관점**: 백성의 관점(1:1–6:7, “이스라엘 자손에게” 1:2; 4:2) ↔ 제사장의 관점(6:8–7:38, “아론과 그의 자손에게”). 순서 차이: 백성 관점은 번제–소제–**화목제**–속죄제–속건제, 제사장 관점은 번제–소제–속죄제–속건제–**화목제**(마지막).
- **제사 방식** [레A]: 화제(불로 태움) / **요제**(흔들어 드림 → 제사장 소득, 가슴·곡식단) / **거제**(높이 들어 드림 → 제사장 소득, 든 뒷다리·넓적다리) / 전제(포도주·독주를 부음).

## 8–10장 제사장

- **8장 위임식** [레A] 교차: A 위임식 준비 — 여호와의 명령(1–5) / B 거룩하게 함 — 관유(기구·아론)(6–13) / **C 세 가지 제사(14–29)** / B′ 거룩하게 함 — 관유와 피(옷)(30) / A′ 7일간 진행 — 명령대로 다 준행(31–36).
  - 순서 [레B]: 씻김 → 의복 → 기름부음 → 속죄제·번제·위임식 숫양 → 피를 바름 → 사방에 뿌림 → 요제 → 태움. (명령은 출 29장 → `02_출애굽기.md`)
- **9장 아론의 첫 제사**: 자신을 위해(속죄제·번제) → 백성을 위해(속죄제·번제·소제·화목제 — **속건제만 빼고 전부**) → **여호와의 영광이 나타남**(23–24). [레B] 아론의 첫 제사가 **수송아지** — **출 32장 금송아지와 대조**.
- **10장 나답과 아비후**: “여호와께서 명하지 않은 **다른 불**”(10:1) — 대조. 제사장 지침: 회막에 들어갈 때 포도주·독주 금지(9), **거룩한 것과 속된 것, 부정한 것과 정한 것을 분별**(10), 규례를 가르치라(11) = 제사장의 주요 임무 2가지(분별·가르침). 16–20 속죄제 분깃에 관한 모세와 아론의 논쟁.

## 11–16장 정결과 부정

- **11장 음식법**: 짐승(새김질 + 굽이 갈라짐), 물고기(지느러미 + 비늘), 새(맹금류 제외), 곤충(뛰는 다리 — 메뚜기류). [레B] 질문: “부정한 짐승과 정결한 짐승을 구분하는 기준은?” / 살아 있는 부정한 동물은 부정을 옮기지 않음, 제사 없이 죽은 동물은 부정(광야에서만 — 레 17:1–7, 신 12:15–25), 부정은 일시적. **신약: 막 7:19, 행 10:15.**
- **12장 출산**: 아들 7 + 33 = 40일 / 딸 14 + 66 = 80일. 번제(어린양)와 속죄제(비둘기), 빈민은 비둘기 두 마리(→ 눅 2:24).
- **13–14장 피부병**: 나병 = **차라아트**(6883) — 오늘날 나병보다 넓은 **악성 피부질환 전반**. [레B] 3구분: 13:1–59 사람·옷 / 14:1–32 처리 / 14:33–57 **집의 곰팡이** (각각 “규례니라/그러하니라/이러하니라”로 끝남). 복귀 의례 4단계(집에서 새 두 마리·백향목·홍색 실·우슬초 → 7일 후 씻음 → 8일째 성소에서 속건제·속죄제·번제·소제, 피와 기름을 환자에게).
- **15장 유출**: 남자·여자 × 단기·장기. 목적(31절).
- **16장 대속죄일** (7월 10일): 대제사장이 1년에 하루 휘장 안에 **세 번** 들어감 — ① 향로의 향연으로 속죄소를 가림(12–13) ② 자신을 위한 수송아지 피(14) ③ 백성을 위한 염소 피(15). 염소 두 마리: 속죄제 염소 / **아사셀 염소**(광야로, 21–22). 이어 숫양 번제(23–28). 백성의 의무(29–34).

- **17장 단일 성소와 피**: 광야 기간 식용 도살도 회막에서만(3–7), 회막 밖 제사 금지(8–9), **피를 먹지 말라**(10–14), 사냥한 고기(13–16).
- **18–20장 교차** [레A]:

  - B 가증한 풍속(성적 타락)을 따르지 말라 18:6–30
  - C **너희는 거룩하라, 나 여호와 하나님이 거룩함이니라** 19:1–2

  - **E 내 모든 규례와 법도를 지켜 행하라 19:37** (중심)
  - D′ 규례가 아닌 우상을 섬기는 자 20:1–6
  - C′ 스스로 깨끗하여 거룩하라, 나는 너희를 거룩하게 하는 여호와 20:7–8
  - B′ 가증한 풍속을 따르는 자는 반드시 죽일지니 20:9–21
  - A′ 내 규례와 법도를 지키라 20:22–27

- **23장 7대 절기** (+ 안식일 23:1–3): 유월절·무교절(4–8) / 초실절(9–14) / 칠칠절(15–22) / 나팔절(23–25) / 대속죄일(26–32) / 초막절(33–43).

- **25장 안식년과 희년**: 희년 = 일곱 번의 안식년 다음 해(50년째). 땅의 안식, **기업 무르기**(땅·가옥·가난한 채무자), 종 무르기.
- **26장 축복과 저주** — [레A]의 관찰 라벨:
  - **<전환>** 전제(우상 금지, 안식일, 성소 경외 1–2) → A 축복(4–13: 비, 평화, **하나님의 임재** 11–13) → B 불순종(14–15: 청종하지 않고, 멸시하고, 싫어하고, 언약을 배반) → C 저주(16–39).
  - **<진전>** “일곱 배나 더” 4단계: A1 18–20 / A2 21–22 / A3 23–26 (“내게 대항할진대… 나도 너희에게 대항하여”) / A4 27–39 (진노로 대항). [레B]는 저주를 5단계로(14–17 / 18–20 / 21–22 / 23–26 / 27–39).
  - **<교환>** 40–45: A 죄를 자복하고 형벌을 기쁘게 받으면(40–41) / B **야곱·이삭·아브라함과 맺은 언약을 기억**하고 땅을 기억(42) / A 땅이 황폐하여 안식을 누림(43) / B 원수의 땅에서도 버리지 않고 언약을 폐하지 않음, 조상과의 언약을 기억(44–45). (야곱→이삭→아브라함의 **역순** 나열은 본문 특징)

## 레위 지파 직분의 변화 [레위] (도표 — 페이지를 이미지로 렌더링해 직접 확인)

- 제목: **“제사장 직분의 변화”**
- 레위 → 게르손 / **고핫(그핫)** / 므라리. (레위 → 고핫 → 아므람 → 아론으로 이어지는 굵은 화살표가 중심 줄기)
- 고핫 → 아므람 · **이스할** · 헤브론 · 웃시엘 (웃시엘의 아들 엘리사반 = 고핫 사람의 지휘관, 민 3:30).
- 아므람 → 모세 · 미리암 · **아론**.
- 아론 → 나답 · 아비후(**레 10:1–7 죽음**) · **엘르아살** · **이다말**.
  - 엘르아살 → **비느하스**(“민 25:11 영원한 제사장의 언약 – 삼상 2:30”) → **사독** (대상 6:4–8)
  - 이다말 → **엘리** → **아히멜렉** (대상 24:3)
  - 이스할 → **사무엘** (대상 6:34–38) — 사무엘은 아론 계열이 아닌 **이스할(고라) 계열 레위인**.
- 레위인의 직무 기간 **30–50세**(민 4:3, 23, 30, 35, 47).
- 직무: 아론의 아들들 = 제사장 직분 / 게르손 = 휘장들(민 3:25–26) / 므라리 = 널판·기둥·받침(민 3:36–37) / 고핫 = 성소 기물(민 3:31–32).
- 관리: 엘르아살(민 4:16), 이다말(민 4:28, 33).
- **민 25:11 비느하스 = 영원한 제사장의 언약 ↔ 삼상 2:30 엘리 가문에 대한 선언** → 제사장 직분이 이다말 계열(엘리 → 아히멜렉)에서 엘르아살 계열(비느하스 → 사독)로 옮겨 가는 흐름을 보여 주는 도표. 두 줄기가 나란히 오른쪽 화살표로 끝남(사독 / 아히멜렉). (“옮겨 간다”는 해석은 도표 제목과 인용 구절에 근거한 추정)
- → 사무엘상·열왕기(사독의 등장, 아비아달 파면 왕상 2:27)에서 다시 확인할 것.
