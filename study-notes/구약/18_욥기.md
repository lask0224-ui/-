# 욥기

> 출처: [욥] `구약 자료/15.욥기.pdf` — **더바이블미니스트리 남영남**, 65쪽 (원본 추출, 모든 쪽 텍스트).

## 표제 · 주제

- 표제 구절: **“보라 주를 경외함이 지혜요 악을 떠남이 명철이니라”(욥 28:28)**
- 중심 주제: **여호와를 경외하는 것이 지혜의 근본이다.**
- 쓰인 이유: ① **모든 고통은 죄로 말미암았다는 당시의 사상을 논박**하기 위해 ② **응보적 정의만이 인간을 통치하는 유일한 원리가 아님**을 말하기 위해.

- **저자 후보**: 욥 또는 엘리후 / **모세**(유대 전통) / 포로기 이후 편집자.
- **욥은 어느 시대 사람인가? — 족장 시대 근거 9가지**: ① 제사 드리는 장소(1:5 — 가장이 제사) ② 부를 **가축 수**로 평가(1:3; 42:12 — 아브라함 창 12:16; 13:2, 야곱 창 30:43; 32:5) ③ 스바인·갈대아인 묘사(1:15, 17) ④ “금 조각” = 히 **케쉬타**(42:11; 창 33:19; 수 24:32에만) ⑤ **딸들도 상속인**(42:15; 민 27:8 슬로브핫 딸들) ⑥ 재난 후 140년을 더 삶(42:16) ⑦ 하나님의 이름 **전능자(샤다이)** ⑧ 유사한 문학이 족장 시대 이집트·메소포타미아에 존재 ⑨ 인명·지명이 족장 시대와 연관.
- **연대 후보**: 족장 시대(BC 1800년대) / 모세 시대(1446–1406) / 솔로몬 시대(970–931) / 예레미야 시대 / 포로 후기.
- **독자**: **솔로몬 통치 시기의 이스라엘 백성** (강의안의 입장 — 사건 시대(족장)와 기록·독자 시대(솔로몬)를 구분한 것으로 읽힘).
- **문학 양식**: 지혜서 / 산문(1–2장, 42:7–17) / 시.

## 1–2장

- **우스 땅**(1:1) 위치 후보: 에돔(애 4:21; 창 36:28, 남동쪽) / 남쪽(렘 25:20) / 아람(창 10:23; 22:21, 북쪽) / 70인역: 욥을 **에돔 왕**으로, 에돔과 아라비아 경계 / 이스라엘 북동쪽 **하우란**.
- 욥의 소개: 인물(1) / 자녀(2) / 소유(3) / **행위(4–5 — 자녀를 위한 번제)**.
- **1:6–2:10 교환 구조**: A 하늘(1:6–12) / B 땅 — 자녀와 재산을 잃음(1:13–22) / A 하늘(2:1–6) / B 땅 — 건강을 잃음(2:7–10).
- **1–2장 3열 병행**:

| | 1:1–5 | 1:6–22 | 2:1–10 |
|---|---|---|---|
| A 소개 | 1:1 욥의 소개 | 1:6–12 천상회의, 욥의 소개(8) | 2:1–6 천상회의, 욥의 소개(3) |
| B 소유 | 1:2–4 자녀와 소유 | 1:13–19 자녀와 소유를 잃음 | 2:7–8 건강을 잃음 |
| C 욥의 행위 | 1:5 | 1:20–22 | 2:9–10 |

  - (관찰) 1장의 욥 소개(1:1, 8)가 하늘에서 하나님의 입으로 반복됨(1:8; 2:3) — 욥의 온전함은 하나님이 증언하심.
- 세 친구(2:11–13): **엘리바스(데만), 빌닷(수아), 소발(나아마)**.

## 3–27장

- **3장 욥의 탄식**: 태어나지 않았어야(1–10) / 나올 때 죽었더라면(11) / 젖을 먹지 않았더라면(12–16) / 죽음은 쉼의 자리(17–19) / **왜 생명을 주셔서 쓰디쓴 인생을 살게 하시는가**(20–26).
- **대화 3싸이클**:
  - 1차(4–14장): 엘리바스 4–5 / 욥 6–7 / 빌닷 8 / 욥 9–10 / 소발 11 / 욥 12–14
  - 2차(15–21장): 엘리바스 15 / 욥 16–17 / 빌닷 18 / 욥 19 / 소발 20 / 욥 21
  - 3차(22–27장): 엘리바스 22 / 욥 23–24 / 빌닷 25 / 욥 26–27 — **소발의 세 번째 말이 없음**(강의안 구조에 소발 없음 — 관찰)
- **친구들의 논리 (응보론)**:
  - 엘리바스 1: 경외하고 온전했다면 고난이 오래가지 않는다(4:6), 악인은 반드시 망한다(4:7–11), 비천한 인간(4:12–21), 하나님께 용서를 구하라(5:8–16), **전능자의 징계를 업신여기지 말라**(5:17–27 ↔ 잠 3:11–12).
  - 빌닷 1: 하나님의 심판은 정의롭다(8:3), **네 자녀들이 죽은 것은 죄 때문**(8:4), 깨끗하고 정직하면 회복(5–7), 물 없는 왕골과 갈대(11–15), 악인은 뿌리째 뽑힘(16–19).
  - 소발 1: 말 많은 자가 의로우냐(11:2), 하나님이 네 죄를 **잊게 해 주셨기에** 깨닫지 못함(6), 하나님의 오묘함(7), 모든 것을 지켜보심(11), 회개하면 회복(13–19).
  - 엘리바스 2: 네 입이 너를 정죄한다(15:6), 건방 떨지 말라(12–16), **전통과 조상의 지혜**(18–19) — 악인은 평생 고통·두려움·궁핍, 이유는 교만(20–26).
  - 빌닷 2: 세상은 **권선징악**의 원리로 돌아간다 — 결코 바뀌지 않는다(18장).
  - 소발 2: 끝까지 잘되는 악인은 없다(20장).
  - 엘리바스 3: 인간의 의는 하나님께 유익이 없다(22:2–3), **욥의 죄의 구체적 예**(6–9)를 지어냄, 겸손히 용서를 구하라(21–30).
  - 빌닷 3: 하나님은 비교할 수 없다, 모든 인간은 죄인이다(25장).
- **욥의 대답의 흐름**:
  - 나의 고통은 하나님에게서 왔다(6:4), 말씀을 거역하지 않았다(6:10), 친구들은 귀도 기울이지 않음(6:14–23), **무엇을 잘못했는지 알려 달라**(6:24).
  - 9–10장: 누구도 하나님 앞에서 의롭다 할 수 없다(9:2–3), 창조주요 주권자(5–14), 그러나 **내 상황에 관심이 없으신 것 같다**(16–20), 의인과 악인을 구분하지 않고 멸하신다(22–24) / 10장 기도: 죄인 취급하지 마시고 이유를 알려 주소서, **손수 빚으신 나를 왜 멸하려 하십니까**(8), 평안히 죽게 해 주십시오(20–22).
  - 12–14장: “너희가 죽으면 지혜도 죽겠구나”(12:2), 강도가 평안히 산다(12:6), 자연 만물은 주권을 안다(7–12), **그러나 기준을 알 수 없다**(13–25), **하나님을 만나 말씀드리고 싶다**(13:3), 하나님을 변호한다며 거짓말하지 말라(13:7–8), **“그가 나를 죽이실지라도 나는 그를 의뢰하리니”**(13:15), 나는 하나님 앞에 설 수 있다(16), 두 가지 간구(주의 손을 거두소서, 두렵게 하지 마소서)·세 가지 질문(내 죄가 얼마나 되나이까, 왜 얼굴을 가리시나이까, 왜 쫓으시나이까)(13:20–27), 인생의 허무와 스올에 숨겨 달라는 기도(14장).
  - 16–17장: “**재난을 주는 위로자들**”(16:2), 고난은 하나님께로부터(7–16), 그러나 죄 없음(17), **내 증인은 하늘에 계신 하나님**(19).
  - **19장**: 하나님이 나를 억울하게(1–6), 적으로 여기심(11), 모두가 등을 돌림, “친구야 불쌍히 여겨다오”(13–22) → **“내가 알기에는 나의 대속자가 살아 계시니”**(23–27, 강의안: “그러나 나는 확신한다. 하나님은 나의 구원자이시다”) → 너희를 벌하실 것(28–29 → 42장 성취).
  - 21장: **악인들이 장수·번성하고 심판이 임하지 않는다** — 친구들의 권선징악을 정면 반박.
  - 23–24장: 하나님은 내 형편을 모르신다, 만날 수 없다(23:8–10), 결백(11–12), 그 계획이 이루어지고 있기에 두렵다(13–17), 심판의 때를 정하지 않으셨다, 세상에는 심판주가 없다(24장).
  - 26–27장: 너희는 어리석다, 창조와 통치(26:5–14), **죽기까지 결백을 주장**(27:1–6).
- (강의 흐름에서 읽히는 핵심 — 해석) 친구들: “고난 = 죄의 결과” / 욥: “나는 죄 때문에 고난받는 것이 아니다. 그러나 하나님이 왜 이러시는지는 모른다.” — 둘 다 **응보의 틀** 안에서 말함.

## 28장 지혜 (중심)

- 지혜는 광산에서 캘 수 없다(1–11) / 사람에게서 발견되지 않는다(13) / 깊은 바다에도 없다(14) / 돈으로 살 수 없다(15–19) / 생물과 새의 눈에도 감추어짐(21) / 멸망과 사망도 본 적이 없다(22) / **지혜는 하나님과 함께 있다(23–28)** ⇒ **“주를 경외함이 지혜요 악을 떠남이 명철이니라”(28)**.

## 29–31장 욥의 마지막 발언

- **29장 과거 회고** (교환): A 하나님이 주셨던 축복(1–10) / B **축복의 통로**로서의 삶(11–17) / A 무병장수의 기대(18–20) / B 위로와 희망을 주는 지혜자의 자리(21–25).
- **30장 현재의 탄식**: 사람들의 조롱(1–15) / 하나님의 학대(16–19) / 기도(20–23) / 탄식(24–31).
- **31장 결백 서약 9가지**: 음욕으로 처녀를 보지 않음(1) / 속이지 않음(5) / 간음하지 않음(9–12) / 지위로 착취하지 않음(13–15) / 가난한 자를 거절하지 않음(16–23) / 재물과 우상을 섬기지 않음(24–28) / 원수의 고통을 기뻐하지 않음(29–32) / 죄를 숨기지 않음(33–34) / 남의 땅·소작농을 착취하지 않음(38–40).

## 32–37장 엘리후

- 이름 뜻: **“그는 나의 하나님이시다.”** 욥에게 화냄(자기를 의롭게 여김, 2) / 세 친구에게 화냄(대답하지 못하고 욥을 정죄, 3).
- 말하는 이유: **나이가 아니라 하나님이 지혜를 주신다**(32:6–10) / 친구들이 설득하지 못했다(11–17) / 침묵하면 폭발할 것 같다(18–22).
- 33장: 하나님은 사람보다 크시다(12), 하나님이 사람과 다른 점(13–22).
- 34장: 욥의 주장 요약(5–6) → 비난(하나님 비방을 물 마시듯, 악인과 한패, 섬겨 봐야 소용없다고 함 7–9) → 반박(하나님은 결코 불의를 행하지 않으심, **행위대로 갚으심**, 절대 주권 10–33) → 욥은 죄인이다(34–37).
- 35–37장: 사람의 악·의가 하나님께 영향을 주지 못함(35:1–8) / 심판은 공평(36:5–15) / 심판받을 때 회개하라(17–21) / **인간의 지식으로 하나님을 알 수 없다** — 천둥 같은 음성, 날씨를 다스리심, 오묘한 일(36:22–37:22) / **전능자를 우리가 찾을 수 없다, 정의와 공의를 타협하지 않으심 ⇒ 그래서 경외해야 한다**(37:23–24).

## 38–42:6 하나님의 말씀

- 교환 구조: A 하나님의 첫 질문(38:1–40:2) / B 욥의 첫 대답(40:3–5) / A 두 번째 질문(40:6–41:34) / B 두 번째 대답(42:1–6).
- 첫 질문 — **“너는 ~아느냐?” (창조주)**: 땅, 바다의 한계, 하루의 시작, 지하 세계, 빛과 어둠, 눈·우박·바람, 짐승의 새끼 치는 때 / **“너 ~할 수 있느냐?” (주권자)**: 별 떼를 묶고 풀기, 구름에 명령, 짐승을 다스리기.
- 욥의 첫 대답 = **침묵**: “손으로 내 입을 가릴 뿐이로소이다… 다시는 대답하지 않겠나이다”(40:4–5).
- 두 번째 질문: **“네가 네 의를 세우려고 나를 악하다 하겠느냐”(40:8)** — 네가 악인을 심판하고 스스로 구원할 수 있으면 해 보라(11–14) / **베헤못**(40:15–24, “내가 너를 지은 것같이 그것도 지었느니라”) / **리워야단**(41장, “누가 내게 감히 대항하겠느냐” 10, 하나님만이 속속들이 아심).
- 욥의 두 번째 대답: **주권을 인정**(42:2–5) / **회개**(6).

## 42:7–17 회복과 결말

- 세 친구에게 노하심: “너희가 나를 가리켜 말한 것이 **내 종 욥의 말같이 옳지 못함**이니라”(7) → 수소 일곱·숫양 일곱을 욥에게 가져가 번제 → **욥의 기도를 받으심**(8–9).
- 축복: 곤경을 돌이키심(10) / 소유의 갑절과 관계 회복(10–12) / 자녀(13–15; 딸들에게도 기업).
- 결말: 140년, 4대를 봄, “늙어 나이가 차서 죽었더라”(16–17).
