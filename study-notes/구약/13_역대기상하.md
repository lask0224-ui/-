# 역대기상·하

> 출처: [대] `구약 자료/11.역대기 상& 12.역대기 하.pdf` — **THE BIBLE MINISTRY 김상민 간사**, 62쪽 (원본 추출, 텍스트 완전). 역대상 1–40쪽, 역대하 41–62쪽.
> TBS 과정 번호상 역대기(11–12)가 열왕기(13–14)보다 **먼저** 배치됨.

## 표제 · 이름

- **“그 날의 일들”** (히브리어 제목 디브레 하야밈의 뜻)
- 70인역 이름 **Paralipomenon** = “삭제된 것들, 빠진 것들, 남은 것들”.

## 역대기의 문제와 “역사” 이해

- 문제: **50% 이상이 이미 기록된 사건**(사무엘·열왕기). 추가된 이야기와 삭제된 이야기가 주는 혼돈 → “사무엘·열왕기 역사의 편집·변경·왜곡이다, 신뢰할 수 없는 역사”라는 비판.
- 강의의 답: **다름 vs 틀림**. “역사”는 **목적을 갖는 용어**.
  - 시간 속에 실제로 일어난 일 = **사건** / 사건에 대한 기억 = **역사** → 기억은 주관적 → **역사 인식의 차이**.
  - 성경이 역사적 사실을 그대로 전하는가? → **원독자와 저자, 각각의 입장이 만나는 곳**. 열왕기의 저자·독자 ≠ 역대기의 저자·독자. = **목적을 지닌 역사 진술**.
  - (사도행전 예습 강의의 “사건은 하나, 해석은 여럿 — 넘어진 강사 예화”와 같은 원리 → `../신약/05_사도행전.md`)
- 이스라엘의 역사 = **언약이 성취되어 가는 과정**: 하나님은 약속을 이루기 위해 무엇을 하셨는가? 백성은 약속을 받고 어떻게 반응했는가?
  - 마 1:17 세 구간: 아브라함~다윗 / 다윗~바벨론(왕하 17:13) / 바벨론~예수 그리스도(대하 15:2).

## 두 관점: 선지자 vs 제사장

| 사무엘서·열왕기 | 역대기 |
|---|---|
| **선지자적 관점** | **제사장 관점** |
| 정치적인 역사 | 종교적인 역사 |
| 전쟁 중심 | **성전 중심** |
| 북이스라엘·남유다의 역사 | **남유다의 역사에 주목** |
| **인간의 실패(불순종)** | **하나님의 성공(신실하심)** |

## 위치: 역사서인가, 성문서인가

- 기독교 전통: 여호수아–사사기/룻기–사무엘–열왕기(사사·왕정 시대) → 역대기·에스라·느헤미야·에스더(포로·귀환 시대).
- 유대교 전통: **성경의 맨 마지막**에 위치.
- **타낙** (눅 24:44 “모세의 율법, 선지자의 글, 시편”):
  - 토라(광의/협의)
  - 느비임: 전기 선지서(여호수아·사사기·사무엘·열왕기) / 후기 선지서(이사야·예레미야·에스겔·12소선지서)
  - 케투빔: 시가서(시편·잠언·욥기) / **5축**(아가·룻·애가·전도서·에스더) / 적용(다니엘·에스라·느헤미야·역대기)

## BRI

- **저자: 에스라**(유대 전통)
  - 특징: 족보에 대한 특별한 언급(에스라·느헤미야 족보와 연관) / 제사장에 대한 관심 / 성전 강조 / 제사장과 율법의 관계(대하 17:1–9).
  - **역사 기록을 접할 수 있었던 사람**: 이스라엘 왕조실록(대상 9:1; 대하 20:34), 유다와 이스라엘 열왕기(대하 16:11; 25:26; 28:26; 32:32), 열왕기 주석(대하 24:27), 이스라엘과 유다 열왕기(대하 27:7; 36:8), 이스라엘 왕들의 행장(대하 33:18), 애가(대하 35:25).
  - **선지자들의 기록**: 사무엘·나단·갓의 글(대상 29:29), 나단(대하 9:29), 실로 사람 아히야의 예언, 선견자 잇도의 묵시(9:29), 잇도의 족보(12:15), 잇도의 주석(13:22), 하나니의 아들 예후의 글(20:34), 이사야의 글(26:22), 이사야의 묵시(32:32), 호새의 사기(33:19).
  - 마카비2서 2:13 — 느헤미야가 도서관을 세우고 왕·선지자에 관한 책, 다윗의 책 등을 모음.
  - **대하 36:22–23 = 스 1:1–3 (고레스 칙령)** — 두 본문을 나란히 비교 → 같은 저자의 연결.
  - 에스라(스 7:1–10): 아론의 **16대손** 제사장 가문, 모세의 율법에 익숙한 학자, 왕에게 구하는 것을 다 받음, 바벨론→예루살렘 귀환, **율법을 연구·준행·가르치기로 결심**(10). 느 12:1 느헤미야와 동시대.
- **기록 연대: BC 450–250 사이, BC 444년경** — 고레스 원년(539, 대하 36:22) / 귀환자 명단(대상 3:17–24; 9:1–34), **스룹바벨 이후 6대**가 기록됨 → 느헤미야 시기(450경) / 대상 29:7 **“다릭”** = 다리오 1세 즉위 기념 주화(515 이후) / 쿰란 사본에 역대기 일부(250).
- **수신자**: 바벨론에서 돌아와 예루살렘 주변에 정착한 유대인(대상 9장). **70년**의 의미: 렘 25:11–13; 29:10, 단 9:2.
  - 70년 계산 두 가지: BC 609 요시야의 죽음 → 539(538) 1차 귀환 / BC 586 3차 포로 → **516 성전 완공**. (포로: 605 1차, 597 2차, 586 3차)
- **기록 장소**: 예루살렘과 그 주변.
- **역사적 배경 — 귀환 후 100년**:
  - 귀환: 539 스룹바벨(1차) / **458 에스라(2차)** / **444 느헤미야(3차)**.
  - 페르시아 연표: 539 바벨론 멸망·고레스 칙령 → 530 고레스 사망, 캄비세스 → 525–522 애굽 정벌 후 귀로에 죽음 → 522–520 반란, **다리오 1세** 승리 → 490 마라톤 패배 → 486 다리오 사망, **아하수에로(크세르크세스)** → 483–480 테르모필레·살라미스·플라타이아 패전 → **474–473 부림절의 위기** → 465 **아닥사스다** → 460 애굽 반역(458 에스라 귀환) → 449 메가비수스 반란(444 느헤미야 귀환).
  - 성전 재건: 539 칙령 → 536 시작(스 3:8) → 536–522 대적의 방해로 중단 → 522–520 다리오 즉위, 재개 → **516 완성** (귀환 후 22년 / 기초 후 20년 / 중단 16년 / 재개 후 4년). 질문: 538–520년 원독자가 겪은 일은?
  - 에스라의 상황(458): 함께 돌아갈 레위인·제사장이 없음(스 8:15~), **이방 여인과의 통혼, 변질된 예배**(9–10장).
  - 느헤미야의 상황(444): 허물어진 성벽, 대적의 방해, 에스라와 함께 언약 확인(느 8장), 총독들의 압제(5:14), 통혼(13:23), 십일조를 안 함(13:10), 안식일을 안 지킴(13:15).
  - 에스더와 말라기: 하만으로 전멸할 뻔함 / 말 1:2 하나님의 사랑을 의심, 1:6–8 제사를 멸시하는 제사장, 2:4–9 가르침을 버림, 2:13–16 이혼(언약 저버림), 3:5 점·간음·거짓·불평등·경외 없음, 3:14–15 섬김에 대한 회의.
  - **원독자의 상태**: 헌신의 결과에 대한 **회의감**, 경외함 없음, 하나님의 사랑을 의심, **낙심·실망, 약속에 대한 기대가 없음**. → “이런 원독자들에게 다윗과 왕들의 이야기가 주는 의미는?”
- **중심 사상**: 이스라엘의 과거 역사에 임했던 **언약에 신실하신 하나님** / 성전과 언약에 신실한 태도를 유지한 결과 = **이스라엘의 영광** / **예배를 통해 회복될 하나님의 영광**.
- **쓰여진 이유**: 옛 이스라엘의 언약에 대한 소망 회복(성전, 왕) / **족보 — 정체성과 하나님의 계획이 끊이지 않았음** / 회복될 다윗 왕가의 통치를 기다림 = **메시야** / 회복될 성전에 임할 하나님의 영광에 대한 소망.

## 역대상

- **1–9장 족보**: 1:1–2:2 아담 → 이스라엘(1:1–27 아담·셋·에노스~아브라함 = 창 4–12장; 창 4:26, 12:8 “여호와의 이름을 부름”과 연결) / 2:3–9:1 이스라엘 / 9:2–34 예루살렘에 돌아와 정착한 사람들.
  - 지파별 분량(절 수): 유다 99·시므온 20(남부) / 르우벤 10·갓 7·므낫세 반 9(요단 동편) / **레위 81**(레위 성읍·도피성) / 잇사갈 5·베냐민 7·납달리 1·므낫세 반 6·에브라임 10·아셀 11(북부) / 베냐민 40(중부). → **유다와 레위가 압도적**.
  - **4:9–10 야베스의 기도** — 유다 계보(4:1–8) 한가운데 삽입, “이스라엘 하나님께 아뢰어”.
  - 6장 레위인: 1–10 솔로몬 성전까지 / 11–15 솔로몬~바벨론 / 16–28 레위~사무엘의 아들 / 31 “언약궤가 평안을 얻은 후” 32 “솔로몬이 성전을 세울 때까지” 찬양 직무 / 33–48 사무엘의 아들(헤만)~므라리.
  - 9:2 처음 거주한 자 = **제사장, 레위 사람, 느디님 사람**.
- **9:35–10:14 사울**: 사울의 족보 → 죽음. “사울과 세 아들과 **그 온 집안이 함께 죽으니라**”(10:6), 10:13–14 사울이 죽은 이유.
- **11:1–29:30 다윗의 통치**:
  - 11–12장 다윗의 용사들(헤브론·시글락·광야의 갓·베냐민·므낫세 용사) — 반복어 **“마음”**(12:17, 33, 38).
  - **13:1–16:6 다윗의 장막 — 언약궤가 평안을 얻다**: 13장 계획과 실패 / 14:8–17 블레셋 전쟁, “**하나님께 물어 이르되**” 2번 / 15:3–16:6 준비하여 옮김 / 15:29 미갈이 “업신여김”.
  - 16장 **다윗의 예배와 기도**: 화목제 / 레위인의 찬양 “**항상**”(4–6, 37–38) / 7–36 기도 = “언약의 역사”(**아브라함 언약**) / 39–40 기브온에서 번제.
  - 17장 다윗의 마음과 하나님의 마음(1–15) → 기도(16–27) = **다윗 언약**.
  - 18–20장 전쟁(“그 후에” 18:1, 19:1 / “해가 바뀌어” 20:1).
  - 21–29장 업적: 인구조사와 **오르난의 타작마당**(21:1–22:1) → 성전 건축 준비(22장) → 솔로몬에게 부탁 → **레위인 정비(23–26장)** → 정치 제도(27장) → 성전 건축과 솔로몬 즉위(28:1–29:9) → 다윗의 기도(29:10–19) → 평가.
  - (관찰) 역대기는 밧세바 사건·압살롬 반역을 싣지 않고, 다윗의 성전 준비와 레위인 조직에 분량을 줌 — 제사장 관점의 선택(해석; 강의안의 “추가·삭제된 이야기” 논의와 연결).

## 역대하

- **1–9장 솔로몬**: 왕권(1장) / 성전 건축(2:1–5:1) / 성전 봉헌(5:2–7:22) / 나머지 업적(8–9장).
  - 5:2–14 궤의 이동과 **하나님의 영광이 성전에 임함** / 6장 솔로몬의 기도 / 7:1–11 **하늘에서 불**, 영광 / 7:12–22 응답.
  - **6장 솔로몬의 기도 — “와서 기도하면”**: 제단 앞(12–13) / 다윗 언약을 기억(14–17) / 성전에 임하시기를(18–21) / “만일” — 이웃에게 범죄(22–23), 주께 범죄해 패전(24–25), 비가 오지 않음(26–27), 기근(28–31), **이방인**(32–33), 전쟁(34–35), **포로에서 돌아오게**(36–39) / 성전에 임하시기를(40–42).
  - 7:12–22: 7:12 응답 / **7:13–14** (“내 이름으로 일컫는 내 백성이 스스로 낮추고 기도하여…”) / 7:17 “네가 만일” / 7:19 “그러나 너희가 만일”.
- **분열 왕국 — 유다 왕들** (각 왕의 평가 틀: 하나님을 “찾음/구함”):
  - **르호보암**(10–12장): 북왕국의 반란 → 스마야의 경고에 순종 → 11:13–17 “**마음을 굳게 하여** 하나님을 찾은 자”(레위인이 남으로) → 12:5 시삭 → 스마야를 통해 돌이키심 → **12:14 “여호와를 구하는 마음을 굳게 하지 아니함이러라”**.
  - **아비야**(13장): 역대기 “아비야”(**여호와는 나의 아버지**) vs 열왕기 “아비얌”(왕상 14:31; 15:1, 7, 8 — **얌 = 바다의 신**). 분량: 열왕기 8절 / 역대기 22절. 전쟁의 시작 → 아비야의 연설(4–12) → 결말.
  - **아사**(14–16장) — “**용두사미?**”: 전반기(개혁, 구스와 전쟁 — **기도로 승리**, 오뎃의 예언과 종교개혁) / 후반기(이스라엘과 전쟁 — **아람을 의지**, 하나니의 책망) / 마지막 — 병들어 **하나님을 구하지 않고 의원들에게 구함**.
  - **여호사밧**(17–20장) — “**다윗과 같았다**”: 다윗과 같다는 평가를 받은 왕 = 여호사밧(17:3)·히스기야(29:2)·요시야(34:2). 분량: 열왕기 51절 / 역대기 102절. 열왕기의 특별한 언급: 아들 여호람을 **이세벨의 딸 아달랴**와 결혼시킴. 17:6–9 **백성에게 율법을 가르침** / 18:1–19:3 길르앗 라못(아합과 교제), 선지자 예후의 평가 / 19:4–11 재판 제도 / 20장 모압·암몬 — 하나님을 의지하여 승리 / 20:31–21:1 평가(아하시야와 교제).
  - **여호람 가족**(21–22장): 여호람 — 아우들을 모두 죽임(21:4), **엘리야의 편지**(12–15), 병들어 죽고 조상의 묘실에 못 들어감 / 아하시야 / **아달랴 — 유다 왕국의 씨를 진멸하려 함**(22:10).
  - **요아스**(23–24장): 제사장 **여호야다의 개혁** / 여호야다와 함께 통치한 시절(성전 보수) ↔ 홀로 통치한 시절(**스가랴를 죽임**, 신하들에게 죽임당함, 묘실에 못 들어감).
  - **아마샤**(25장) — “온전한 마음으로 행하지 않음”: 에돔 전쟁(이스라엘 용병 → 선지자의 말로 돌려보내고 승리) → 불순종 → 북이스라엘 요아스와 전쟁 → 반역으로 죽임.
  - **웃시야**(26장): “하나님의 묵시를 밝히 아는 **스가랴가 사는 동안**”(5) 형통 → **마음의 교만(16) → 나병**, 열조의 무덤에 못 들어감.
  - **요담**(27장) / **아하스**(28장) — “**곤고할 때에 더욱 범죄**”(28:22).
  - 계보 요약: 여호사밧 → 여호람 → 아하시야 → (아달랴) → 요아스 → 아마샤 → 웃시야 → 요담 → 아하스 → **히스기야** → 므낫세 → 아몬 → **요시야** → 여호아하스 → 여호야김 → 여호야긴 → 시드기야.
  - **히스기야**(29–32장): 즉위와 평가 → **성전 정화와 예배 회복** → **유월절**(30장) → 예물(31장) → 32:1 “이 모든 충성된 일을 마친 후에” 앗수르 침공 → 준비 → 랍사게의 망언 → 기도와 구원 → 결과.
  - **므낫세**(33장): 범죄(1–9) → **므낫세의 기도**(10–13) → 개혁(14–20) — 열왕기에 없는 회개 기사. 아몬(21–25).
  - **요시야**(34–35장): 8세 즉위(640) → 16세(632) “아직 어렸을 때” 하나님을 찾음 → 26세(622) 18년 성전 수리·율법책 → 훌다의 예언(34:23–28) → 35:20 “이 모든 일 후에”(므깃도).
  - **마지막 왕들**(36:2–21): 여호아하스 → 여호야김 → 여호야긴 → 시드기야 → **36:22–23 고레스 칙령으로 끝남**(= 에스라 1장으로 연결).
