# 전도서

> 출처: [전] `구약 자료/35.전도서.pdf` — 38쪽, The Bible Ministry (원본 추출, 텍스트 완전; 각 쪽 이미지는 배경 장식). 표제 **“오직 너는 하나님을 경외할지니라!”**(5:7).

## BRI (Basic Required Information)

### 저자는 누구인가?
- 1:1 “**다윗의 아들 예루살렘 왕** 전도자의 말씀이라” / 1:12 “나 전도자는 예루살렘에서 이스라엘 왕이 되어” / 2:9 “나보다 먼저 예루살렘에 있던 모든 자들보다 더 창성하니” / 왕상 4:7; 4:22–23; 4:29–34.
- 유대인 랍비들과 전통은 **솔로몬 왕** / 잠언(1:1)과 아가(1:1)에는 솔로몬 이름이 언급(전도서는 “전도자”로만).
- **전도자 = 코헬렛(Qoheleth)** — **설교자, 수집자** / **전도서에만 7번**(1:1, 2, 12; 7:27; 12:8, 9, 10).
- 전도자는: 예루살렘 왕(1:1, 12) / 마음을 다하며 지혜를 써서 하늘 아래 모든 일을 연구한 자(1:13) / 해 아래 모든 일을 본 자(1:14) / 지혜와 지식을 많이 만나 본 자(1:16) / **스스로를 시험 삼아 낙을 누린 자**(2:1) / 12:9–10 **지혜자, 지식을 가르치는 자, 깊이 생각하는 자, 연구하는 자, 잠언을 많이 지은 자, 아름다운 말들을 구한 자, 진리의 말씀을 정직하게 기록한 자** / 솔로몬(왕상 4:29–34): 잠언 3000, 노래 1005, 온 세상에 명성.
- **솔로몬 저자설 반박**: 1:16 “나보다 먼저 예루살렘에…” (솔로몬 이전 예루살렘 왕은 다윗뿐) / 3:16; 4:1; 10:16 등 솔로몬 당시 상황과 거리가 멂 / **포로기 이후 사용된 히브리 단어들**.
- **솔로몬 저자설 (강의 결론)**: 단어들을 포로기 이후로 특정할 수 없음(당시 무역이 활발 — 외래어 유입 가능) / **1–2장은 솔로몬 시대 상황과 맞음** / 12:9–10 전도자 = 솔로몬 → **저자는 솔로몬**.

### 독자 및 기록시기
- 독자: **솔로몬의 통치 말기** / 기록: **BC 940–930**.

### 쓰여진 이유
- 모든 것이 **헛됨(hebel)**을 가르치기 위해 / **청년의 때에 창조주를 기억하게** / 전도자가 깨달은 것을 말하기 위해 / **하나님을 경외하는 것이 본분**임을 / **심판하시는 하나님**을 기억하도록.

## 구조 (세 가지 제시)
1. **프롤로그–에필로그 수미상관**: 1:1–3 시작하는 말 — 2절 “헛되고 헛되며 헛되고 헛되니 모든 것이 헛되도다” ↔ 12:8–14 끝내는 말 — 8절 “헛되고 헛되도다 모든 것이 헛되도다”.
2. **3구분**: 1:1–3:15 **인생 = 하나님의 선물** / 3:16–9:10 **헛된 평생의 날, 즐겁게 살지어다** / 9:11–12:14 **모든 사람의 본분 = 하나님을 경외함**.
3. **2구분**: 1:1–6:12 **모든 수고가 헛되다** (1:3 “해 아래에서 수고 … 무엇이 유익” ↔ 6:11 “헛된 많은 일들 … 무슨 유익”) / 7:1–12:14 **모든 사람의 본분 = 하나님을 경외함** (7:29 “내가 깨달은 것” ~ 12:14 “하나님은 … 선악 간에 심판하시리라”).

## 핵심 단어
- **헛되다 — 헤벨(hebel)**: 단어적 정의 **“증기”, “숨”, “헛됨”** / 번역가마다 다양 — 의미 없음, 덧없이 지나가 버리는, 부질없는 생각, 무상함, 헛수고, 불합리, 이해할 수 없는, 일치하지 않는, 비어 있는 / **인물 이름으로도 사용(아벨)** / **전도서에서 38번 반복**.
- **해 아래에서** — 헤벨이 일어나는 장소 / 피조 세계 / **인간의 한계** / **30번 반복**.
- (해 아래 = 하나님 없이 보는 관점, 해 위 = 하나님의 관점으로 보는 해석이 가능 — 강의 명시 없음, 해석)

## 본문

### 1:1–11
- “헛되고” ×5(2) / “해 아래에서 … 모든 수고가 사람에게 무엇이 유익한가”(3) / **순환 원리(4–11)** — 해, 바람, 강물 / **“해 아래에는 새 것이 없나니”**(9).

### 1:12–2:11
- **지혜를 알고자 함(12–18)**: 하늘 아래 모든 일을 연구 / “하나님이 인생들에게 주사 수고하게 하신 것”(13 = **창 3:16–19**) / 구부러진 것도 곧게 할 수 없고(15 = 7:13) / **“지혜가 많으면 번뇌도 많으니”**(18 = 7:23).
- **너는 낙을 누리라(2:1–11)**: 웃음 = 미친 것 / 희락 = 무슨 소용 / 왕의 수고(4–10) — 사업, 집, 포도원, 동산, 종, 은금, 노래하는 자 / 결론 — **모든 것이 헛되어 바람을 잡는 것** / 반복: 헛되어(1:14), 헛되도다(2:1), 헛되어(2:11).

### 2:12–26
- 지혜와 망령됨과 어리석음(12–17): **지혜 ↔ 우매(13–14a, 빛과 어둠처럼 다름) / 지혜 = 우매(14b–16, 같은 죽음)** → “내가 사는 것을 미워하였노니”.
- 해 아래 모든 수고를 미워함(18–23): **미워하였노니 = 사네(증오하다)** — 히브리어 성경 **17절과 18절 첫 단어가 “사네”** / 실망하였도다 = **야아쉬(절망하다)**.
- **24–26 하나님을 기뻐하는 자** — 먹고 마시며 수고 중에 낙을 누리는 것이 **하나님의 손에서 나오는 것**.

### 3:1–22
- **범사에 기한이 있고 천하 만사가 다 때가 있나니(1–8)** — “~있고, ~있으며” **14번**(대구 14쌍).
- 무슨 이익이 있으랴(9 = 1:3).
- **하나님이 하신 일(10–11)**: 인생들에게 노고를 주사 애쓰게 하심(= 1:13) / **모든 것을 지으시되 때를 따라 아름답게 하셨고** / **영원을 사모하는 마음을 주심** / 하나님이 하시는 일의 시종을 사람이 측량할 수 없게.
- **하나님의 선물(12–13)**: 기뻐하며 선을 행하는 것 / **먹고 마시는 것과 수고함(노동)으로 낙을 누리는 것**.
- 결론(14–15): **하나님을 경외하라(14)** / 새것이 없다(15 = 1:9–10).
- **하나님의 심판(16–22)**: 재판하는 곳의 불의 / **하나님의 심판 = 하나님의 때** / “인생들의 일에 대하여 하나님이 그들을 시험하시리니” — **시험하다 = 깨끗하게 하다, 선별하다** / 짐승과 다름이 없는 줄을 깨닫게 / 자기 일에 즐거워하라.

### 4장 — “더 나은 것”
- 해 아래 학대(1–3) — 악한 일을 보지 못한 자가 더 복됨 / 수고와 재주로 이웃에게 시기(4–6) — **“한 손에만 가득하고 평온함이 더 나으니라”**.
- 해 아래 헛됨(7–16): 홀로 있는 자의 만족하지 못하는 수고(8) / **두 사람이 한 사람보다 나음(9–12)** / 왕의 권력 — 후에 오는 자들은 그를 기뻐하지 않음 → **“권력무상”**.

### 5장
- **하나님을 경외할지니라(1–7)**: 하나님의 집에 들어갈 때 발을 삼갈 것 / 하나님 앞에서 함부로 입을 열지 말 것 / **서원하였거든 갚기를 더디게 하지 말 것** → 7절 **“오직 너는 하나님을 경외할지니라”(표제)**.
- 정의와 공의를 짓밟는 것을 볼지라도 이상히 여기지 말라(8–9; 3:16; 4:1) / **은을 사랑하는 자는 은으로 만족하지 못함(10–12)** / 해 아래 큰 폐단 — **재물을 해가 되도록 소유**(13–17; 눅 12:16–21 어리석은 부자).
- **아름다움(18–20)**: 하나님께서 주신 바 일평생에 먹고 마시며 수고 중에 낙을 보는 것이 선하고 아름다움 / 재물과 부요를 주사 **제 몫을 받아 수고함으로 즐거워하게 하신 것은 하나님의 선물** / 하나님이 그 기뻐하는 것으로 응답하심.

### 6장
- 해 아래 불행한 일: 재물·부요·존귀를 받았으나 **누리도록 허락하지 않음**(= 5:13) / 행복으로 만족하지 못하고 안장되지 못하면(율법을 어긴 자, 간음하다 붙잡힌 자 등 — 강의 설명) / 결론(11–12) — 많은 일들, 사람에게 무슨 유익이 있으랴.

### 7장
- **더 나은 것(1–10)**: 좋은 이름 > 좋은 기름 / **죽는 날 > 출생하는 날** / **초상집 > 잔칫집** / 슬픔 > 웃음(얼굴의 근심이 마음에 유익) / 지혜로운 자의 책망 > 우매한 자의 노래 / 일의 끝 > 일의 시작 / 참는 마음 > 교만한 마음 / “옛날이 오늘보다 나은 것이 어찜이냐” 하지 말라.
- **지혜(11–14)**: 유산같이 아름답고 / 돈의 그늘과 같으나 지혜가 지혜 있는 자를 살림 / **형통한 날에는 기뻐하고 곤고한 날에는 되돌아보아라 — 하나님이 병행하게 하사 장래 일을 헤아려 알지 못하게 하셨느니라**.
- 멸망하는 의인, 장수하는 악인(15–18): **지나치게 의인이 되지 말며 지나치게 지혜자도 되지 말라** — 하나님을 경외하는 자는 이 모든 일에서 벗어남 / 온전한 의인은 없다(19–22).
- **전도자의 깨달음(23–29)**: **“하나님은 사람을 정직하게 지으셨으나 사람이 많은 꾀들을 낸 것이니라”(29)**.

### 8:1–10:4 《카이아즘》
- A 때와 판단과 분변의 지혜(8:1–8)
- B 악인이 성읍 안에서 잊어버린 바 됨(8:9–10)
- C 악한 일에 관한 심판이 지연됨(8:11–13)
- D 불합리한 세상 & 희락을 찬양(8:14–15)
- **E 모든 사람은 하나님의 손 안에 있다(8:16–9:1)**
- D′ 모든 사람의 결국이 일반이라 & **즐겁게 살지어다**(9:2–10)
- C′ 시기와 기회는 모두에게 임함(9:11–12)
- B′ 가난한 지혜자를 기억하는 사람이 없음(9:13–16)
- A′ 지혜자의 말과 우매한 자의 말(9:17–10:4)

### 10:5–20
- 주권자에게서 나오는 허물(5–7) / **오직 지혜는 성공하기에 유익하니라(8–11)** / 우매자의 말 = 심히 미친 것(12–15) / 어리석은 왕과 현명한 왕(16–20).

### 11:1–8
- **“네 떡을 물 위에 던져라”(1–2)** — 일곱에게나 여덟에게 나눠 줄지어다 / 사람이 여러 해를 살면 항상 즐거워할지로다.

### 11:9–12:8
- **청년이여 네 어린 때를 즐거워하며(11:9–10)** — 마음이 원하는 길, 눈이 보는 대로 행하라 / **그러나 하나님이 이 모든 일로 너를 심판하실 줄 알라**.
- **청년의 때에 창조주를 기억하라(12:1–8)** — 영은 그것을 주신 하나님께로 돌아가기 전에(7) / 결론(8) “헛되고 헛되도다 모든 것이 헛되도다”.

### 12:9–14 에필로그
- 전도자의 권위(9–10).
- **전도서의 결론(13–14)**: **“일의 결국을 다 들었으니 하나님을 경외하고 그의 명령들을 지킬지어다 이것이 모든 사람의 본분이니라 / 하나님은 모든 행위와 모든 은밀한 일을 선악 간에 심판하시리라.”**

- (관찰) 전도서의 흐름 = **헤벨(헛됨) 진단 → 하나님의 선물(먹고 마시고 수고 중 낙을 누림) → 하나님을 경외함(본분) → 심판** / “헛되다”의 부정과 “즐거워하라”의 긍정이 교차하며, 둘을 잇는 것이 “하나님의 손/선물” (해석).
