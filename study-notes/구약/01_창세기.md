## 1–2장 창조

- **1:1 “태초에”(베레쉬트)** = “근원에”, “시작에”. 창세기는 **과학적 설명(어떻게 창조되었나)이 아니다.** 요 17:5 “창세 전에”.
- **창조하다(바라, bara)**: 주어가 하나님일 때만 쓰임 → **만든 이가 강조**됨. 하나님이 만드신 것 = “하늘과 땅”.
- **1:2 운행하다(라하프, rachaph)**: 선회하다, 배회하다, **품다**.
- **1:3 “하나님이 이르시되… 그대로 되니라”** = 운행하심의 결과. 말씀하시는 하나님 ↔ 말씀이신 예수님(요 1:1–3). 혼돈·공허·흑암의 자리에 **말씀이 자리함**.
- **6일 구조** (틀과 채움):

| 틀 (혼돈 해결) | 채움 (공허 해결) |
|---|---|
| 1일 빛/어둠 | 4일 해·달·별 (낮과 밤, 계절) |
| 2일 물·궁창·물 | 5일 새, 물고기 |
| 3일 땅/바다, 풀·채소·나무 | 6일 가축·기는 것·짐승, **사람** |

  - 어둠과 물은 특별히 **비강조**, **3일째와 6일째가 강조**됨.
- **1:26–31 인간 창조 = 창조의 절정**
  - 형상(image, “새기다”) / 모양(likeness, “~과 비슷하다”).
  - 인간의 4가지 의미: ① 존귀한 인간(하나님의 형상 = **왕 같은 존재**) ② 평등한 인간(남자와 여자) ③ 통치하는 인간(위탁받은 통치) ④ 하나님과 교제하는 인간.
  - ★역본 비교: 새한글성경 1:27 “하나님이 사람을 자기 모습으로 창조하셨다…”
- **1:28 복(바라크, barak)**: 무릎을 꿇다, 축복하다, 복을 주다, 찬양하다. 명령 5가지: 생육·번성·충만·정복·다스림. ★1:29–31과 9:3–4 비교(식물 → 육식 허용).
- **“좋았더라”(토브, TOV)** = 운행하심의 결과. 요약: **운행하심 → 말씀하심 → 좋았더라**.
- **2:1–3 안식일** = 하나님과 사람이 함께하는 자리. 구조: 1:1–31 이름을 지어 주시는 하나님 / 2:1–3 안식일 / 2:4–25 이름을 지어 주는 아담.
- **2:15 경작하며 지키게 하심**:
  - **아바드**: + 땅·물건 = 다스리다 / + 신적 단어 = **예배하다** / + 사람 = 섬기다.
  - **샤마르**: 지키다, 보존하다, 준수하다 → 창조를 지속시키다. 일·노동의 시작.
- **2:16–17 명령 vs 3:3 하와의 기억**: “먹지 말라, 먹는 날에는 반드시 죽으리라” → “먹지도 말고 **만지지도** 말라, 죽을까 하노라” (말씀의 변형).

## 3–4장 타락과 가인

- 3:7 무화과 잎 치마 → 3:8 **하나님이 찾아오심** → 아담의 변명(3:12)·하와의 변명(3:13) → 심판(3:14–20) → **3:21 가죽옷을 지어 입히심**(원복음·은혜).
- 추방 이유: 3:22. 3:23 “그의 근원이 된 땅을 갈게” = 경작 명령은 지속됨(인간의 본질). 땅에서 버려지는 사건이 4장으로 이어짐.
- **4장 가인과 아벨**: 아벨 양치는 자 / 가인 농사하는 자. 가인의 제물을 거절하신 이유? ★참고 구절: 레 5:11, 히 9:22, 삼상 15:22, 사 1:11–17(자료 표기 “사 11:11~17”, 오기로 보임).
  - 4:7 “죄가 문에 엎드려 있느니라… **너는 죄를 다스리라**.”
  - 4:9 “내가 **지키는 자**니이까” ↔ 2:15 지키라.
- **3장과 4장의 대응**:

| 3장 | 4장 |
|---|---|
| 명령: 선악과를 먹지 말라 | 명령: 죄를 다스리라 |
| 하와·아담의 불순종 | 가인의 불순종 |
| 아담을 찾으심 | 아벨을 찾으심 |
| 심판: 땅을 갈게 | 심판: 땅이 소산을 내지 않음 |

- **단어 연결로 본 실패**: 1:26 “다스리게 하자” ↔ 4:7 “죄를 다스리라”(→ 죄가 원하는 것을 들어줌 = 살인) / 2:15 “지키라” ↔ 4:9 “내가 지키는 자니이까” = **부르심의 자리를 잃어버림**.
- 흐름: 창조–운행–이르시되–좋았더라… **그러나**.

## 4–5장 두 계보

- ★가인 계보: 가인 → 에녹 → 이랏 → 므후야엘 → 므드사엘 → 라멕(아다·씰라; 자료 표기 “야다, 실라”) → 야발·유발·두발가인·나아마.
- 셋 계보: 아담 → 셋 → 에노스(**여호와의 이름을 부름** 4:26) → 게난 → 마할랄렐 → 야렛 → 에녹(**하나님과 동행**) → 므두셀라 → 라멕 → 노아(6:8 여호와께 은혜를 입음) → 셈·함·야벳.
- 대비: 양쪽 모두 에녹·라멕이 있다(가인 계보의 에녹·라멕 ↔ 셋 계보의 에녹·라멕).
- 5장 반복 문형: “낳고, 지내며, 낳았으며, 살고, 죽었더라”. 5:3 아담이 **자기의 형상과 같은** 아들 셋을 낳음 (1:26 하나님의 형상과 대비).
- 4:25 셋 = 아벨을 대신해 주신 **다른 씨**.

## 6장 하나님의 아들들과 노아

- **6:1–4 하나님의 아들들 = 셋의 자손**(여호와의 이름을 부른 자들), **사람의 딸들 = 가인의 자손**. 대조가 아니라 “전환!”. 연결: 신 7:1–4 가나안 통혼 금지, 민 13:33 네피림의 후손 아낙 자손.
- **토브(좋았더라) → 나함(한탄하다, 후회하다)**: 1장의 “보시기에 좋았더라” ↔ 6:5 “보시고” 6:12 “보신즉” 한탄. 세상을 보는 관점 = 말씀, 말씀대로 이뤄진 상태. **성경이 제공하는 선과 악**.
- 구조:
  - (대조) 6:1–7 모든 사람 악함 ↔ 6:9–22 한 사람 의로움
  - (전환) 6:1–7 → **6:8 은혜** → 6:9–22
- 노아: 의인, 당대에 완전한 자, 하나님과 동행.
- 3장·4장·6장 모두에서 **은혜**가 반복: 가죽옷 → 셋(다른 씨)과 여호와의 이름을 부름 → 노아가 은혜를 입음, 홍수 중 “기억하심”(8:1).

## 9장 새로운 시작과 노아 언약

- 9:1–7: 짐승들이 두려워함(9:2), **육식 허용 — 단, 피째 먹지 말 것**. 생명 존중(9:4–5), 하나님의 형상 존중(9:6).
- 9:8–17 새 언약: 다시 홍수로 멸하지 않음(9:11), **무지개**(9:13) = “내 무지개”, 언약의 증거. **기억하리니**(9:15, 16) ↔ 8:1, 출 2:24.

## 10–11장 바벨탑

- ★배열: 10:21–30 셈의 족보 → 10:31–32 백성이 나뉨 → 11:1–9 바벨탑 → 11:10–26 셈의 족보 → 11:27–32 데라의 족보.
- 동방 이주, 시날 평지(메소포타미아), 벽돌로 돌을, 역청으로 진흙을 대신 = 문명의 발전. 슬로건: “성읍과 탑을 건설하자, 탑 꼭대기를 하늘에 닿게 하여 **이름을 내고 흩어짐을 면하자**.” 지구라트, 달의 여신 숭배.
- 구조: 11:1 언어가 하나 / 11:2–4 **사람들의 계획** — 흩어짐을 면하자 / 11:5 하나님이 내려오심 / 11:6–8 **하나님의 계획** — 흩으심 / 11:9 언어를 혼잡하게.
- **구속사적 관점**: 창 11장 언어가 나뉨 → 창 12장 아브라함 언약(땅의 모든 민족이 “복”) → 이스라엘의 시작과 실패의 역사 → **행 2장 오순절**(천하 각국 사람이 자기 방언으로 들음 = 새 이스라엘의 시작) → **계 7:9–17**(각 나라·족속·백성·방언).
  - → 사도행전 자료의 “창 11장 ↔ 행 2장 대조표”와 연결 (`../신약/05_사도행전.md`).

## 12장 아브라함의 소명 ★

- 12:1 “가라” — 본토·친척·아비의 집을 떠나 보여 줄 땅으로.
- 12:2–8 약속: 큰 민족 / 이름을 창대하게 / 복이 되어 **땅의 모든 민족이 너로 말미암아 복을 얻을 것** / 12:7 가나안 땅이 후손의 기업.
- 아브라함 언약 3요소: **민족(12:1–3) · 땅(15:13–21) · 나라(18:18)**.
- 구약 = 이스라엘의 역사 = **언약사**. 이스라엘을 통한 계획 = **구속사**. 신약 = 구속사의 정점.

## 12–25장 아브라함

### 언약의 시점과 점진적 확대
- **언제 언약이 주어졌는가?** (각 언약 앞의 상황)
  - 12:1–3 아버지 데라가 죽은 후
  - 13:14–17 롯과 작별한 후
  - 15:5 후사를 포기하려 했을 때
  - 17:10 이스마엘이 태어난 후
  - 22:16–18 모리아산에서 독자 이삭을 드린 후
- **언약의 점진적 확대**: 가나안 땅(13:14, 15:7) → 자손의 수 증대(13:16, 15:5, 22:17) → 땅의 범위(15:18–21) → 민족과 왕들(17:6, 16) → 네 후손의 하나님(17:7–8) → 천하 만민이 복(12:3, 22:18).
- **원독자 관점의 질문**: 이 약속들은 언제, 누구를 통해 성취되는가? — 출애굽 백성은 **민족**을 이루신 성취를 보았고, 시내산에서 “조상의 하나님”이 아닌 **그들의 하나님**을 인정하고 하나님의 백성이 되었다. **이제 남은 것은? → 땅.**

### 아브라함의 이동 (원독자에게 주는 의미)
- 12:1–3 언약 → 12:4–5 롯과 함께 떠남 → 12:6–8 **세겜–벧엘**: 단을 쌓고 **“여호와의 이름을 부름”**(↔ 4:26) → 12:9 남방(네게브) → 12:10–20 애굽에서의 위기 → 13:1–2 네게브로 → 13:3–4 벧엘, “전에 여호와의 이름을 불렀던 곳” → 13:5–13 롯과 갈라섬(소돔·고모라) → 13:14–18 언약, **헤브론**에 제단.
- 질문: **세겜, 벧엘, 헤브론… 원독자(가나안에 들어갈 세대)에게 주는 의미는?**
- **12:10–20 애굽에서의 위기**: 가뭄 → 애굽 → 수모 → 애굽에 재앙 → 바로가 내보냄(양·소·노비·낙타를 얻음). 강의 질문 “**원독자?**” — 출애굽 사건과 겹쳐 읽힘(애굽 내려감–재앙–재물을 얻고 나옴). (해석: 강의안은 질문만 던짐)

### 14장 롯의 구출
- 북방 4왕(시날·엘라살·엘람·고임; 대장 엘람 왕 그돌라오멜) vs 염해 5왕(소돔·고모라·아드마·스보임·소알).
- 아브라함과 가신 **318명**(자료 표기 “380명”은 오기로 보임 — 창 14:14 318명), 단까지 추격해 롯 구출.
- 14:20–23 승리: 가나안 왕들의 환영, **십일조**, 소돔 왕의 제안(14:21)을 **거절**(14:22) = 하나님의 승리를 인정 → **이름이 창대하게 됨**(12:2 성취).

### 15장 언약 예식
- 15:1–3 상속자 = 엘리에셀? → 15:4–7 네 몸에서 날 자 → 15:8–11 예식 준비(쪼갠 짐승) → 15:12 해 질 때 흑암과 두려움 → **15:13–16** → 15:17a 연기 나는 화로와 횃불 → **15:17b 하나님이 홀로 쪼갠 짐승 사이를 지나심**(약속 언약) → 15:18–21 땅.
- **15:13–16 = 원독자들이 겪은 시간(400년 종살이)에 대한 확증과 의미.** 15:16 “아모리 족속의 죄악이 아직 가득 차지 아니함이니라.”
- 16:1 → 상속자 = 이스마엘?

### 16–17장 이스마엘과 할례
- 16장: 아브라함 85세, 사래의 제안(하갈을 첩으로) — 당시 문화로는 정상(**누지 문서**). 그러나 하나님의 뜻 안에서는? **관습을 따를 것인가?**
- 16:13 하갈의 고백 “나를 살피시는 살아 계신 이” = **브엘라해로이**. 이스마엘 = “하나님이 들으셨다”. 16:12 “들나귀 같이”.
- 17장: 이스마엘 출생 후 **13년이 지남**(16:16–17:1). 17:18 “이스마엘이나 하나님 앞에서 살기를 원하나이다”.
- **17:1 “너는 내 앞에서 행하여 완전하라”** = 13년의 시간을 설명하는 명령: 하갈을 통해 약속을 이루려 한 아브라함에게 하나님은 **완전하라**고 요구하심. “행하다” = **할라크**(창 3:8 하나님이 동산에 “거니시는”과 같은 단어).
- 17:4–6 아브람 → **아브라함**(민족의 아버지, 왕들) / 17:7–14 **할례** — 아브라함과의 언약을 **자손과의 언약**으로 연결, 할례를 받지 않으면 “내 언약을 배반”(17:14) / 17:15–16 사래 → **사라**(민족의 어머니).
- 두 웃음: 17:17–18 **아브라함의 웃음** / 18:11–15 **사라의 웃음**. 이삭 탄생 예고: 17:19–22 하나님 / 18:1–10 천사.

### 18–19장 소돔
- 18:17 하나님이 계획을 아브라함에게 나누심. **18:18 ↔ 출 19:6**(제사장 나라). **하나님이 아브라함을 택하신 이유 = 18:19 “여호와의 도를 지켜 의와 공도를 행하게 하려고”.**
- 18:20–33 중보: **50 → 45 → 40 → 30 → 20 → 10 (진전)** — 소돔의 죄가 강조됨(의인 10명이 없음) + **끝까지 기다리시는 하나님의 인내**. 의인 롯(벧후 2:6–8). 원독자?
- 19:1–11 죄악이 증명됨. 19:8 딸을 대신 내보내려는 롯 = “의롭다는 사람의 수준”. 겔 16:49–50 소돔의 죄악.
- 19:12 “네게 속한 자가 있느냐” ↔ 수 6:25 라합의 경우.
- 19:30–38 롯의 두 딸: 모압(모압 자손의 조상), 벤암미(암몬 자손의 조상).

### 20–25장
- 20장 그랄 왕 아비멜렉 앞에서 **아브라함의 실수 반복** → 하나님 “그는 **선지자**라” → 아브라함의 기도로 태가 열림 → 결과: 제물을 얻음.
- 21:1–8 이삭 출생(아브라함 100세) / 21:9–21 이스마엘이 쫓겨남 / 21:22–34 아비멜렉·비골과 **평등언약** — 아비멜렉이 아브라함을 인정, **브엘세바 = 맹세의 우물**.
- **22장**: 아브라함을 시험하시려고. **모리아산 = 예루살렘**. 22:5 “**우리가** 너희에게 돌아오리라”, 22:8 “번제할 어린양은 하나님이 자기를 위하여 준비하시리라” — **아브라함이 경험한 하나님**. 22:16–19 “네 독자라도 아끼지 아니하였은즉”.
- 23장 사라의 죽음(127세), **막벨라 굴** 매입(헷 족속, 기럇아르바, 은 400세겔), 23:19 마므레 = 헤브론. [창A] 막벨라 굴 ↔ 여호수아 14장(헤브론 = 갈렙의 기업) 연결.
- 24장 이삭의 신부 조건: **가나안 여자는 안 된다, 고향 족속에서, 아들을 고향으로 돌아가게 하지 말라**(24:3–6). 원독자에게 주는 의미? ↔ 26:34–35 에서의 헷 여인 결혼(리브가의 근심), 27:46, 28:6–9.
- 25:1–11 “열조에게로 돌아감”, 이삭과 이스마엘이 함께 막벨라에 장사.

## 25–36장 이삭과 야곱

- 25:19–26 출생, **25:23 “큰 자가 어린 자를 섬기리라”** / 25:27–34 장자의 명분을 판 에서 → 장자의 명분이 에서에서 야곱으로. 리브가의 입장 vs 이삭의 입장.
- **26장 이삭의 언약** — ★[창B] 구조 (“이삭 파워^^”):
  - 그랄에서 나타나심: 2–5 **조건적 축복**(그랄을 떠나지 말라) → 6 이삭이 지킴 → 7–11 리브가 보호 → 12–16 번성(농작물·짐승)
  - 브엘세바에서 나타나심: 23–24 **무조건적 축복** → 25 예배(이름을 부름) → 26–31 아비멜렉과 조약(보호) → 32–33 번성(우물: 에섹·싯나·르호봇 → 브엘세바)
  - [창A]의 구조: 26:1–2 흉년, “애굽으로 내려가지 말라” / 3–5 아브라함 언약 계승 “이 땅에 거류하면” / 6–11 리브가를 누이라 속임 / 12–22 축복 / 23–25 언약·제단·이름을 부름 / 26–33 아비멜렉이 계약 요청 / 34–35 “에서” 때문에 이삭과 리브가의 근심.
  - (관찰) 아브라함의 이야기(애굽행 위기, 아내를 누이라 함, 아비멜렉과 언약, 브엘세바 우물)가 이삭에게서 반복됨.
- **27장 속임수와 축복**: 이삭의 마음 / 리브가의 마음 — “**하나님의 말씀(25:23)을 기억하고 있는 리브가**” / 이삭의 상태는? 27:28–29 속임을 통한 축복 → 28:3–4 도망갈 때의 축복(아내를…).
- **야곱의 언약 — 벧엘 이야기**: 28장 벧엘의 하나님(28:20–22 서원) → 29–31장 라반의 딸들(31:7–13; [창A] 31:11–13) → 32–33장 에서를 만날 준비, **하나님과의 씨름**, 에서를 만남 → 세겜에 머묾 → 34장 디나의 치욕 → **35장 “벧엘로 올라가자”** — 야곱의 언약. (구조: 28장 벧엘 ↔ 35장 벧엘로 감싸는 틀)
