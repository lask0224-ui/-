## 중심 내용 · 기록 목적

- 중심 내용: **이스라엘 백성의 불순종에도, 약속하신 가나안 땅으로 인도하시기 위해 백성을 훈련시키시고 이끄시는 하나님의 신실하심.**
- 기록 목적 4가지:
  1. 1·2세대를 가나안으로 인도하기 위해 어떻게 **준비**시키셨는지 알려 주려고
  2. **1세대의 실패를 통해 2세대에게 교훈**하려고
  3. 1세대의 실패에도 **2세대를 일으켜** 가나안으로 인도하실 것을 알려 주려고
  4. 가나안 땅에서 **하나님과 함께하는 삶**을 알려 주려고

## 1:1–10:10 1세대를 위한 준비 (시내산)

- **1장 1차 인구 계수**: 출애굽 둘째 해 둘째 달 첫째 날, 20세 이상 싸움에 나갈 만한 남자. 교차: A 명령(1–4) / B 지파별 우두머리 12명(5–17) / A′ 시행(18–19). 반복 어구: 지파 이름 / 종족과 가문 / 20세 이상 / 싸움에 나갈 만한 / 명수대로 / 계수.
  - 지파별: 르우벤 46,500 · 시므온 59,300 · 갓 45,650 · **유다 74,600(최다)** · 잇사갈 54,400 · 스불론 57,400 · 에브라임 40,500 · 므낫세 32,200 · 베냐민 35,400 · 단 62,700 · 아셀 41,500 · 납달리 53,400 → **603,550**.
  - **레위인 강조**(1:47–54): 계수에 들지 않음, 성막 사방에 진 → “이스라엘 회중에게 진노가 임하지 않게”.
- **2–4장 진 편성** (회막을 중심으로, 반복 어구: 진영의 군기·군대로 계수된 자·행진):
  - 동 **유다**(유다·잇사갈·스불론) 186,400 — 제1대로 행진
  - 남 **르우벤**(르우벤·시므온·갓) 151,450 — 제2대
  - (회막과 레위인 진영이 중앙에서 행진, 2:17)
  - 서 **에브라임**(에브라임·므낫세·베냐민) 108,100 — 제3대
  - 북 **단**(단·아셀·납달리) 157,600 — 후대
  - 성막 바로 둘레: 동쪽 모세·아론과 그 자손 / 서 게르손 / 남 고핫 / 북 므라리.
- **3장 레위인**: 제사장(엘르아살·이다말; 나답·아비후는 다른 불로 죽음) 아래서 시종. **레위인을 택한 이유 = 이스라엘의 장자를 대신**(3:11–13, 애굽의 장자를 치던 날 구별). 1개월 이상 레위인: 게르손 7,500(서쪽) / 고핫 8,600(남쪽) / 므라리 6,200(북쪽). 레위인 지휘관의 어른 = 엘르아살(3:32). 이스라엘 장자 22,273 — 레위인보다 **273명 초과 → 1인당 5세겔, 1,365세겔 속전**을 아론에게.
- **4장 회막 봉사자 계수** (30–50세): 고핫(지성물을 **멤** — 아론이 덮은 후, 성소를 보지 말라, 죽으리라; 감독 엘르아살) 2,750 / 게르손(휘장·덮개; 감독 이다말) 2,630 / 므라리(널판·기둥·받침; 감독 이다말) 3,200.
- **5장 부정에서 정결로**: 부정한 자는 진 밖으로(“내가 그 진영 가운데 거함”) / 배상할 죄 → 속건제, 1/5을 더해 / **의심의 법**(쓴 물).
- **6장 정결의 유지 — 나실인**: 포도 소산 금지 / 머리 자르지 않음 / 시체를 가까이하지 않음(부모라도 — **제사장 규례 레 21:11 적용**). 부정해지면 기간 무효. 서원 종료 시 헌물은 **대제사장 위임식(레 8장)과 나란히 비교**(강의안이 두 칸으로 대조).
  - **6:22–27 대제사장의 축복** — 강의안은 **원문 어순 그대로 한글로 번역**해 보여 줌:
    - 24 네게 복을 주시기를 / 여호와는 / 그리고 너를 지키시기를
    - 25 비추시기를 / 여호와는 / 그의 얼굴을 / 너에게 / 그리고 네게 은혜 베푸시기를
    - 26 드시기를 / 여호와는 / 그의 얼굴을 / 너에게 / 그리고 주시기를 / 네게 / 평강을
    - 27 “내 이름으로 축복할지니 **내가** 그들에게 복을 주리라.”
- **7–8장 헌신**:
  - 7:1–9 수레 6·소 12 → 게르손(수레 2·소 4), 므라리(수레 4·소 8), **고핫은 주지 않음(어깨로 메는 직임)**.
  - 7:10–88 12지파 지휘관이 **12일 동안 똑같은 헌물**(진영 순서: 동→남→서→북). 총계 은 2,400세겔, 금 120세겔 등.
  - **7:89 하나님의 임재**: 속죄소 위 두 그룹 사이에서 모세에게 말씀하시는 목소리 = 출 25:22의 성취.
  - 8:1–4 등잔불 = 성막의 완성, 하나님의 임재(출 27:21; 40:25).
  - 8:5–22 레위인을 **요제**로 봉헌(교차: 명령 / 이유 — 장자 대신, 속죄, 재앙이 없게 / 시행).
- **9장**: 9:1–14 **두 번의 유월절** — 시체로 부정해 지키지 못한 자들의 질문 → **둘째 달 14일에 다시 지키게 하심**(“놓친 유월절, 다시 얻은 유월절”). 9:15–23 구름이 떠오르면 행진, 머물면 진 — “**여호와의 명령을 따라**” ×7.
- **10:1–10 은나팔**: 둘 불면 온 회중, 하나면 천부장, 크게 불면 행진(동→남). 약속의 땅에서: 전쟁 때 크게 → “여호와가 너희를 기억하고”, 절기·초하루에 불면 “하나님이 기억하시리라”.

## 10:11–15:41 1세대의 실패 (이동)

- **10:11 둘째 해 둘째 달 20일** 구름이 떠오름 → 바란 광야. 행진 순서: 유다 진영 → 게르손·므라리(성막) → 르우벤 진영 → 고핫(성물) → 에브라임 진영 → 단 진영. 언약궤는 **삼 일 길을 앞서 가며 쉴 곳을 찾음**(10:33).
- 10:29–32 호밥 요청 “우리의 눈이 되리이다” / 10:35–36 **모세의 기도**(궤가 떠날 때 “여호와여 일어나사…”, 쉴 때 “돌아오소서”).
- **11–12장 세 가지 불평** (강의안 제목):
  1. **11:1–3 다베라 — ‘하나님의 인도하심’에 대한 불평**: 시내산을 떠난 지 3일 후, 악한 말로 원망 → 여호와의 불.
  2. **11:4–35 기브롯핫다아와 — ‘하나님의 공급하심’에 대한 불평**: 섞여 사는 다른 인종의 탐욕 → “애굽에서는 값없이 생선·오이·참외·부추·파·마늘” → 모세도 “혼자 감당할 수 없다” → 70장로에게 영 / 메추라기 한 달 / “여호와의 손이 짧으냐”. 결과: 욕심낸 자들이 죽음.
  3. **12:1–16 하세롯 — ‘하나님의 권위’에 대한 불평**: 미리암과 아론, 구스 여자 문제 → “여호와께서 모세와만 말씀하셨느냐” → 하나님이 ‘갑자기’ 부르심: “그는 내 온 집에 충성, **대면하여 명백히**, 여호와의 형상을 봄”. 모세의 성품 “**온유함이 지면의 모든 사람보다 더하더라**”(12:3). 미리암 나병 → 모세의 간구로 회복.
- **13–14장 정탐 실패**:
  - 13장 (명령–실행–결과): 모세가 **호세아(구원) → 여호수아(여호와는 구원이시다)**로 이름을 부름 = 정탐 결과에 대한 하나님의 기대. 보고: 젖과 꿀이 흐르나 **아낙 자손**, “우리는 **메뚜기** 같다” / 갈렙 “능히 이기리라”.
  - **14장 교차**:
    - A 1–5 약속의 땅을 포기(불순종) — “애굽으로 돌아가자”
    - B 6–10 여호수아·갈렙이 죽을 뻔함
    - C 11–12 하나님의 진노
    - **D 13–19 모세의 기도** — “노하기를 더디 하시고 인자가 많아…”
    - **D′ 20–25 기도를 들으심** — “내가 네 말대로 사하노라”, **열 번이나 시험**, “내 종 갈렙은 그 마음이 그들과 달라”
    - C′ 26–35 진노의 결과 — “너희 말이 내 귀에 들린 대로”, 20세 이상 광야에서, **40년**
    - B′ 36–38 여호수아·갈렙만 생존
    - A′ 39–46 약속의 땅을 억지로 취하려 함(불순종) — 호르마에서 패함
  - (관찰) 포기도 불순종, 억지로 취함도 불순종 — A와 A′가 짝.
- **15장 제사 규례** — 실패 직후 “**내가 주어 살게 할 땅에 들어가서**”(15:2)로 시작 = 약속은 유효함. 부지중 범죄(속죄제) vs **고의 범죄(끊어짐)**, 본토인과 타국인에게 **같은 법**. 예: 안식일에 나무한 자(32–36). 대책: **옷단 귀의 술과 청색 끈**(37–40) — 보고 계명을 기억. 41절 “나는 너희의 하나님이 되려고 너희를 애굽 땅에서 인도해 내었느니라”.

## 16:1–19:22 1세대의 계속되는 실패

- **16장 고라·다단·아비람·온의 반역** 교차:
  - A 1–3 반역의 시작(레위 고핫 자손 고라 + 르우벤 다단·아비람·온 + 지휘관 250명: “회중이 다 거룩한데 너희가 분수에 지나도다”)
  - B 4–14 반역의 이유: 고라 = **제사장 직분을 구함** / 다단·아비람 = “젖과 꿀이 흐르는 땅(**애굽**)에서 끌어내어… 젖과 꿀이 흐르는 땅(가나안)으로 인도하지 못한다” — **애굽을 ‘젖과 꿀이 흐르는 땅’이라 부름**
  - C 15–19 향로를 가지고 오라
  - **D 20–24 하나님의 진노와 모세의 기도**(“모든 육체의 생명의 하나님이여, 한 사람이 범죄하였거든 온 회중에게…”)
  - C′ 25–30 악인의 장막에서 떠나라
  - B′ 31–35 땅이 삼킴, 불이 250명을 사름
  - A′ 36–40 향로로 제단을 싸는 철판 = 표
- 16:41–50 이튿날 온 회중이 “너희가 여호와의 백성을 죽였도다” → 염병 14,700명 → **아론이 향로를 들고 죽은 자와 산 자 사이에 섬** → 그침. (제목: “계속되는 1세대의 실패 vs 하나님의 은혜”)
- **17장 아론의 싹 난 지팡이**: 12지파 지팡이, 레위 지팡이에 아론의 이름 → 움·순·꽃·**살구 열매** → 증거궤 앞에 간직 = 반역자에게 표징, “원망을 그치고 죽지 않게”. 백성의 반응: “가까이 나아가는 자마다 죽사오니…” → 18장으로 연결.
- **18장 제사장·레위인의 직무와 몫** — “성막에 가까이 나아가는 것을 돕는 사람들”:
  - A 1–7 역할과 관계(교차: 제사장–레위인–**중요성: 여호와의 진노가 다시는 미치지 않게**–레위인–제사장)
  - B 8–18 제사장의 몫 / **C 19–20 소금 언약, “내가 네 분깃이요 네 기업이니라”** / B′ 21–24 레위인의 몫 = 십일조, 기업 없음 / A′ 25–32 **십일조의 십일조**를 제사장에게
- **19장 붉은 암송아지의 재** — 부정을 씻는 물: 흠 없고 멍에 메지 않은 붉은 암송아지, 진 밖에서 잡아 엘르아살이 피를 7번 뿌리고 백향목·우슬초·홍색 실과 함께 태움 → 재를 진 밖 정한 곳에 = “속죄제”. 시체 접촉 시 **셋째 날과 일곱째 날**에 뿌림, 정결하게 하지 않으면 성막을 더럽혀 끊어짐.

## 20:1–21:35 1세대의 퇴장과 2세대의 등장

- 20:1 **미리암의 죽음**(가데스, 첫째 달) — 1세대의 퇴장. cf. 20:22–29 아론의 죽음, 20:12 모세가 가나안에 들어가지 못함.
- **20:2–13 므리바 물 — “2세대의 등장”**: 2세대도 원망(“파종할 곳도 마실 물도 없다”) → 하나님: “반석에게 **명령하여**” → 모세: “반역한 너희여, **우리가** 이 반석에서 물을 내랴” + **지팡이로 두 번 침** → “너희가 나를 믿지 아니하고 **내 거룩함을 나타내지 아니한** 고로” → 모세와 아론은 들어가지 못함.
- 20:14–21 **에돔 왕의 거절을 통한 순종의 훈련**: 형제 관계 호소, 큰길로만 지나가겠다 → 거절 → 이스라엘이 **돌이킴**.
- 20:22–29 호르산에서 **아론의 옷을 벗겨 엘르아살에게** → 대제사장 교체, 30일 애곡.
- **21장 2세대를 위한 훈련**:
  - 21:1–3 **호르마 — 전쟁의 훈련**(아랏 왕, 서원 후 승리; 14:45 호르마에서 패했던 곳)
  - 21:4–9 **불뱀과 놋뱀 — 회개의 훈련**(에돔 우회로 마음이 상해 원망 → 불뱀 → “우리가 범죄하였나이다” → 놋뱀을 쳐다보면 삶)
  - 21:10–20 **이동의 훈련**: 호르산 → 오봇 → 이예아바림 → **세렛 골짜기(1세대 죽음의 성취, 신 2:13–15)** → 아르논 → 브엘(우물 노래) → 맛다나 → 나할리엘 → 바못 → 비스가산. “여호와의 전쟁기” 인용.
  - 21:21–35 **전쟁의 훈련**: 아모리 왕 시혼(야하스; 아르논~얍복 점령, 헤스본 거주, 모압을 점령했던 시혼에 대한 노래) / 바산 왕 옥(에드레이, “두려워 말라”).

## 22:1–36:13 2세대를 위한 준비 (모압 평지)

- **22–24장 발락과 발람**:
  - 22:1–40 (발단–전개–위기–절정–결말): 발락이 두려워 발람을 부름 → “가지도 말고 저주하지도 말라, 그들은 복을 받은 자들” → 더 높은 고관 → “가라, 그러나 내가 이르는 말만” → **나귀와 발람의 대화, 여호와의 사자** = 최고의 지식을 자부하는 주술사의 굴욕 → “하나님이 내 입에 주시는 말씀 그것을 말할 뿐”.
  - 22:41–24:25 **네 번의 예언**:

- **25장 싯딤(바알브올) — “2세대들의 실패”**: 모압 여자와 음행, 그들의 신에게 절함 → 염병 **24,000명** → 비느하스가 시므리와 미디안 여인 고스비를 창으로 → **비느하스에게 평화의 언약, 영원한 제사장 직분의 언약**(“하나님을 위하여 질투함”) → 미디안을 치라. (→ `03_레위기.md` “제사장 직분의 변화” 도표의 민 25:11)

- **27–36장 교차 — “약속의 땅에 들어가고 살기 위해 무엇을 준비해야 하는가?”**
  - A 27:1–11 슬로브핫 딸들의 질문 — “아들이 없다고 아버지의 이름이 삭제되리이까” → **옳다**. 상속 순서: 아들 → 딸 → 형제 → 가까운 친족. (cf. **고엘 제도** 룻 4:3–6)
  - B 후계자 여호수아(27:12–23: “목자 없는 양같이 되지 않게”, **엘르아살 앞에 서서 우림으로** 물음) / 제사와 절기(28–29장) / 서원(30장) / 미디안 전쟁·정결·전리품(31장) / 요단 동편(32장) / 노정(33장) / 경계(34장) / 레위 성읍·도피성(35장)
  - A′ 36:1–13 므낫세 지파의 질문 — 딸들이 다른 지파로 시집가면 기업이 옮겨 감 → **요셉 지파의 말도 옳다**, 조상 지파 안에서만 결혼 → 숙부의 아들들과 결혼.
  - 요점: “가나안 땅을 기업으로 상속받는 것은 **하나님 언약의 성취**이며, 하나님의 언약을 기억하고 지키는 것.”
- **28–29장 제사와 절기** — 매일(상번제 숫양 2), 안식일(+숫양 2), 초하루(수송아지 2·숫양 1·어린 숫양 7 + 속죄제 숫염소), 유월절·무교절, 칠칠절(새 소제), 나팔절(7월 1일), 대속죄일(7월 10일, “심령을 괴롭게”), **초막절**(7월 15일부터: 수송아지 13 → 12 → 11 … → 7일째 7, 8일째 1).
- **30장 서원**: 어린 딸은 아버지가, 아내는 남편이 듣는 날 무효화 가능(“여호와께서 사하시리라”), 과부·이혼녀는 지켜야 함.
- **31장 미디안 전쟁**: 비느하스가 성소 기구와 나팔을 들고 출전, 다섯 왕과 **발람**을 죽임. 모세의 노함 — “발람의 꾀를 따라 범죄케 한 여인들”. 7일간 진 밖 정결(19장 규례). 전리품: 반분(군인·회중), 군인 몫의 1/500 → 제사장, 회중 몫의 1/50 → 레위인(양 675,000 / 소 72,000 / 나귀 61,000 / 사람 32,000). 지휘관들이 “한 사람도 축나지 않았다”며 금 16,750세겔을 속전으로.
- **32장 요단 동편**: 르우벤·갓 “요단을 건너지 않게 하소서” → 모세: **가데스바네아 사건과 같은 일**, 백성을 낙심케 함 → 두 지파의 제안(무장하고 선봉에, 기업을 얻기까지 돌아오지 않음) → 조건부 허락 “**너희 입이 말한 대로 행하라**” → 갓·르우벤·므낫세 반 지파에게 시혼과 옥의 나라.
- **33장 노정** 교차: A 3–4 애굽에서 나타내신 영광(“그들의 신들에게도 벌을”) / B 5–37 라암셋 → 호르산(40년) / **C 38–40 아론의 죽음(40년째 5월 1일) — 1세대 활약의 끝, 2세대 활약의 시작** / B′ 41–49 호르산 → 모압 평지(6개월) / A′ 50–56 **가나안에서 나타내야 할 영광** — 원주민을 몰아내고 우상을 깨뜨리라, 남겨 두면 “눈에 가시, 옆구리에 찌르는 것”.
- **34장 경계**(남·서·북·동)와 요단 서편 9지파 반 / 동편 2지파 반, 분배할 지휘관(엘르아살·여호수아 + 각 지파 1명, 르우벤·갓 제외).
- **35장 레위인 성읍 48개**(도피성 6 + 42), 많이 받은 지파에서 많이. **도피성**: 요단 이쪽 3, 가나안 3, 부지중 살인자가 **대제사장이 죽기까지** 머묾. 고의 살인은 속전 불가, 증인 2명 이상. “**피는 땅을 더럽힘… 나 여호와는 이스라엘 자손 중에 있음이니라**”(35:33–34).
