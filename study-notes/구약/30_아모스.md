# 아모스 (+ 선지서 개론)

> 출처: [암] `구약 자료/16.아모스.pdf` — 15쪽, 표제 **“Seek the Lord, that you may live”**(암 5:6). 원본 추출(모든 쪽 텍스트). **개요(목차) 형식의 슬라이드로, 각 항목의 설명은 강의 중 구두로 한 것으로 보임 — 슬라이드에 있는 항목만 기록함.**
> TBS 과정 순서상 아모스(16)가 소선지서 중 첫 책 → 이 파일의 “선지서 개론”이 선지서 전체의 도입.

## 선지서 개론 (선지서 공통)

1. **선지서(예언서)에 대한 일반적 오해** — 점검할 질문 4가지:
   - 선지자의 주된 관심은? (미래 예고인가, 현재의 언약 관계인가 — 질문만 제시)
   - 미래(축복과 저주)는 정해진 것인가?
   - 선지자들의 평가 기준은?
   - 선지자의 역할은?
2. **예언 형식**:
   - **오라클(Oracle)**: ① **송사 오라클**(Lawsuit Oracle) ② **화 오라클**(Alas Oracle) ③ **구원(약속) 오라클**(Promise Oracle)
   - **예언적 완료**(Prophetic Perfect): 미래 일을 이미 이루어진 것처럼 완료형으로 말함 (호 8:8 예 — `28_호세아.md`)
   - **텔레스코핑**(Telescoping): 가까운 성취와 먼 성취를 한 시야에 겹쳐 말함 (호 1:4 예)
3. **예언의 성취를 해석하는 방법**: ① 말씀 자체가 해석하는 경우 ② 한 번의 성취 ③ 가장 가까운 성취를 선택 ④ **영적인 성취** ⑤ **순환적 예언**
4. **선지자를 구분하는 기준**: ① 선지자의 역할(예언)에 대한 성경적 이해 ② 메시지 & 성취 ③ 삶 ④ 하나님의 부르심

## BRI

- **저자**: **드고아의 목자 아모스**(1:1) — 이름 뜻 / (이사야의 아버지 아모스와 다른 인물 — 슬라이드 항목 “이사야의 아들”은 구분하라는 뜻으로 보임) / 목자 / **남유다 사람으로 북이스라엘 벧엘에서 선포**(7:13–15) / **선지자 가문 출신이 아님**(7:14), 전문 선지자 교육을 받지 않음 / 환상을 기록(7:8; 8:2).
- **기록 연대**: 여로보암 2세(793–753) / 웃시야(790–739) / **지진 전 2년**(1:1; 슥 14:5 — 표기 14:6) / 사역 연대와 기록 연대의 구분.
- **수신자**: 여로보암 2세 당시 북이스라엘 — **하나님과의 관계에 아무 문제가 없다고 생각함**(4:4–5; 5:4–6, 21–23) / **여호와의 날에 대한 잘못된 이해**(5:18–20) / 자신들의 미래는 흔들리지 않을 것이라 생각(6:1). 남유다도 포함(6:1 “시온에서 교만한 자”). **원청중과 원독자의 구분**.
- **역사적 배경**: **제2의 황금기**(정치 — 국내·국외, 경제, 종교) / “스스로의 생각”(자기 확신).

## 구조 (세 가지 방식)

1. 심판과 구원: 심판(1:1–9:10) / 구원(9:11–15)
2. **말씀하신 것(1–6장) / 보여 주신 것(7–9장)**
3. 내용: 열국 심판(1:1–2:4[2:3]) / 유다와 이스라엘 심판(2:5[2:4]–6:14) / 5가지 환상(7:1–9:10) / 열방의 회복(9:11–15)

## 1–6장 하나님께서 말씀하신 것

- 1:1 말씀이 임한 방법과 시기 / 1:2 **“부르짖으며” = 히 샤아그**(사자의 포효; 1:2; 3:4, 8).
- **주변 6나라 심판**(1:3–2:3): 다메섹 → 블레셋 → 두로 → 에돔 → 암몬 → 모압 → 이어서 **유다와 북이스라엘**(2:4–16).
  - 2장 구조: 이스라엘이 하나님께 행한 것 / 하나님께서 이스라엘에게 행하신 것 / 이스라엘이 하나님께 행한 것.
- 이스라엘의 죄: 사람과 사람 사이 / 하나님과 사람 사이 / **근본적인 죄 = “그래도 너희가 내게로 돌아오지 아니하였느니라”**(4:6, 8, 9, 10, 11 — 5번 반복).
- **9개의 수사 의문문**(3:3–8).
- 하나님의 심판(4:6, 7, 9; 5:19) / **하나님의 권면·요구**(5:4, 6, 14, 15, 24 — “나를 찾으라 그리하면 살리라”, “정의를 물같이, 공의를 마르지 않는 강같이”).
- **5:1–17 애가 — 카이아즘**: A 애가(1–3) / B 회개의 촉구(4–6) / C 죄의 증거(7) / **D 여호와는 누구이신가?(8–9)** / C′ 죄의 증거(10–13) / B′ 회개의 촉구(14–15) / A′ 애가(16–17).

## 7–9장 하나님께서 보여 주신 것

- 각 환상을 **내용 / 특이 사항 / 성취**의 틀로 분석:
  1. 메뚜기(7:1–3)
  2. 불(7:4–6)
  3. **다림줄**(7:7–9)
  - **아마샤 vs 아모스**(7:10–17): 아마샤 = 북이스라엘 벧엘의 제사장, 그의 목적.
  4. **여름 과일 한 광주리**(8:1–14)
  5. 범죄한 나라를 멸하심(9:1–10)
- **9:11–15 이스라엘의 회복** (“다윗의 무너진 장막을 일으키고” — 행 15장 예루살렘 공의회에서 야고보가 인용 → `../신약/05_사도행전.md`)
