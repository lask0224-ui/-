## BRI

- **저자: 브에리의 아들 호세아**(1:1) — 브에리 = “나의 우물”, 호세아 = “구원”(사 12:2).
  - **북왕국 출신**: 북왕을 “**우리 왕**”(7:5), 북이스라엘 지리(2:22 이스르엘; 4:15 길갈·벧아웬; 5:1, 8 미스바·다볼·기브아·라마; 6:7–8 아담·길르앗·세겜).
  - 북이스라엘의 자연·생태 묘사: 야생동물과 가축, 사냥, 농사, 과일과 꽃, 날씨, 바람과 비.
  - **벧엘(벧아웬)과 사마리아**에 대한 특별한 언급(4:15; 5:8; 10:5 “벧아웬의 송아지”; 7:1; 8:5 사마리아의 죄; 10:5–7; 13:16).
  - 종교 타락의 현장 목격(2:5; 3:1; 4:11–14; 9:1).
  - 저자의 특별한 사역: 1:1–3:5(개인의 경험) / 4:1–14:9(메시지).
- **원청중 vs 원독자** (강의의 핵심 구분):
  - **원청중 — 호세아의 활동 시기**: 1:1의 단서 — 유다 왕 웃시야–요담–아하스–**히스기야**(731–686) + 이스라엘 왕 **여로보암**(793–753). “67년?” — 웃시야 외의 유다 왕들은 여로보암 2세와 겹치지 않음 → **본문이 제공하지 않는 시간(역사적 관점)**: 여로보암 이후 스가랴·살룸·므나헴·브가히야·베가·호세아(722) **약 31년의 혼란기가 언급되지 않음**, 722 멸망도 언급되지 않음 → **BC 753–723 활동**.
  - **원독자 — 호세아의 저작 시기**: 유다 왕 히스기야까지 언급, 732 아람–이스라엘 연합의 위협, 722 멸망, 히스기야의 개혁을 경험, **1:7 유다 구원 예언은 701 산헤립 침공(왕하 18:13–19:37) 이전** → **BC 722–701 사이 기록**.
  - 원청중: 여로보암 2세 이후 이스라엘 백성 — 여로보암 시대의 회복과 이후의 몰락, 앗수르의 위협.
  - 원독자: **히스기야 시대의 유다 백성** — 이스라엘의 멸망 목격, 히스기야 개혁 경험, 다가오는 위협. 본문의 유다 언급: 1:1, 7, 11; 3:5; 4:15; 5:10, 12; 6:11; 8:14; 10:11; 11:12; 12:2.
- **역사적 배경 — 월드파워의 변화**: 앗수르 왕 살만에셀 4세 → 앗술단 → 앗술니라리 → **디글랏빌레셋 3세** → 살만에셀 5세 → 사르곤 2세 → 산헤립. BC 742 므나헴 공격(왕하 15:19–20), 732 아람 멸망(15:29), 701(왕하 18–19).
- **문학 양식**: 산문 1:1–2:1; 2:16–20; 3:1–5 / 나머지는 시.
- **중심 내용**: **이스라엘의 불성실 — 음란 / 하나님의 성실 — 심판, 회복.**

## 1:2–2:1 호세아와 고멜의 결혼

- 1:1 호세아와 그의 시대. 1:2 호세아가 “**처음**” 들은 말씀 — **테힐라**(시작, 시초, 처음). “음란한 여자를 맞이하여 음란한 자식들을 낳으라” ↔ **레 21:13–15**(제사장의 결혼 규례와 대조).
- 1:3 디블라임의 딸 **고멜** — 견해 4가지: ① 종교적 매춘을 행하는 창녀 ② 결혼 후에 음란해짐 ③ 음란한 상태로 호세아를 속이고 결혼 ④ 가나안 종교의식에 참여.
- **1:4 이스르엘** — “**텔레스코핑**” 심판–심판–심판: “조금 후에 이스르엘의 피를 예후의 집에 갚으며”(→ **753 스가랴의 죽음**) / “이스라엘 족속의 나라를 폐할 것”(→ **722 멸망**) / “그날에 이스르엘 골짜기에서 이스라엘의 활을 꺾으리라”. 이스르엘 골짜기: 왕상 21장 아합과 나봇의 포도원(예언) → 왕하 9–10장 요람·아하시야·이세벨의 죽음(성취) → 왕하 10:30 “**4대를 지내리라**”(예후 왕조 4대 = 스가랴까지).
- 1:6 **로루하마**(긍휼히 여김을 받지 못하는 자) — “용서하지 않을 것”, 배경: 여로보암 2세 시대의 축복. / 1:7 “그러나 **유다 족속을 긍휼히 여겨**” — 구원(“어떤 구원?”).
- 1:9 **로암미**(내 백성이 아니라) ↔ 출 6:6–7, 레 26:12(“너희 하나님이 되고 너희는 내 백성이 되리라” — 언약 문구의 역전).
- 1:10–2:1 **이스라엘의 회복** — 약속 오라클, **영적 성취**: “이스라엘 자손의 수가…” → 성취 **롬 9:25–26, 벧전 2:10**.
- 요약: 1:2 호세아와 고멜 = 남편과 아내 / 1:3–9 이스르엘·로루하마·(유다)·로암미 / 1:10–11 그러나 이스르엘의 날이 클 것 / 2:1–2 암미·루하마 vs 음란한 어머니.

## 2:2–13 음란한 어머니에 대한 송사 오라클

- 송사 오라클의 틀: **호출 → 증거 → 평결**.
  - 호출(2:2) 너희 어머니 / 증거: “그는 내 아내가 아니요 나는 그의 남편이 아니라”, 얼굴의 음란, 유방 사이의 음행.
  - 음란 = **자눈**: 명사 구약 12회 중 호세아 6회, 동사 “음행하다” 호세아 14회·에스겔 22회.
  - 평결(2:3–4): 벌거벗겨 난 날같이, 광야·마른 땅같이, 자녀를 긍휼히 여기지 않음 → **성취 BC 725–722 앗수르의 사마리아 포위**(왕하 17:3–5).
- 2:5–8 어머니의 행음: 백성이 아는 것 — “나를 사랑하는 자(바알)를 따르리니 떡·물·양털·삼·기름·술을 준다” / 하나님의 말씀 — 2:6 길을 막고 담을 쌓아 “그제야 본남편에게 돌아가겠다”, 2:8 곡식·포도주·기름은 **내가 준 것**, 바알을 위해 쓴 은과 금 → **“그가 알지 못한다.”**
- 2:8–13 하나님의 심판: 도로 찾음 / 빼앗음 / 수치를 드러냄 / 절기·안식일·명절을 폐함 / 황폐케 함 → “**나를 잊어버리고** 바알들을 섬긴 시일대로 벌을 주리라.”

## 2:14–23 하나님의 회복 (회복의 약속 오라클, 텔레스코핑)

- 2:14–15 “내가 그를 **타일러**(속여서, 꾀어서) **거친 들로** 데리고 가서 **말로 위로**” → 거기서 포도원을 주고 **아골 골짜기로 소망의 문**을 삼음(수 7장 아간의 골짜기) → 거기서 응대하기를 “어렸을 때, 애굽 땅에서 올라오던 날과 같이.”
- “그날에” 3번: 2:16–17 바알의 이름을 기억하지 않음 / 2:18–19(20) **“네가 여호와를 알리라”** / 2:21–23 긍휼히 여김을 받을 것, 내 백성이 될 것.
- 2장 흐름 요약: 1:10–2:1 회복(한 우두머리) → 2:2–3 음행을 제하라 → 2:4–6 자녀를 긍휼히 여기지 않음 → 2:7–8 본남편을 생각하나 “알지 못한다” → 2:9–12 심판 → 2:13 나를 잊고 → 2:14–15 심판의 의미 → 2:16–20 장가들어 “여호와를 알리라” → 2:21–23 긍휼 → 3:1–3 음녀를 사랑하라 → **3:4–5 “다윗을 찾고 하나님을 경외”**.

## 3:1–5 타인의 사랑을 받아 음녀가 된 그 여자

- 3:1 “**여호와가 그들을 사랑하나니** — 타인의 사랑을 받아 음녀가 된 그 여자를 사랑하라.” 3:2 은 15개와 보리 한 호멜 반 / 3:3 “많은 날 동안”(↔ 2:13) / 3:4–5 왕도 제사도 없이 지내다가 **다윗을 찾고 하나님을 경외**.

## 4–14장 순환 예언

- **4:1 지식이 없어 망하는 백성** (송사 오라클): 호출 — 이스라엘 백성, **이 땅의 주민**, 제사장(4:4) / 증거 — “**진실도 없고 인애도 없고 하나님을 아는 지식도 없고**”, 저주·속임·살인·도둑질·간음·포악·피 / 4:4 백성이 제사장과 다투는 자처럼 됨 / 평결 — 제사장은 낮에, 선지자는 밤에 넘어지고, 네 어머니를 멸하리라(성취 753–722).
  - 4:1–10 지식이 없는 원인(“내 백성이 지식이 없으므로 망하는도다” 4:6) / 4:11–14 깨닫지 못하는 백성 — 우상숭배 / 4:15–19 지식 없음의 결과, **유다 언급**.
- **5:1 교만한 지도자들**: 호출 — 제사장들아(들으라)·이스라엘 족속들아(깨달으라)·왕족들아(귀를 기울이라) / 증거 — 미스바의 올무, 다볼의 그물 / 5:2 패역자가 살육죄에(**아마도 므나헴**, 왕하 15:16–20) / 5:3 음행·더러워짐 / **5:4 “그들의 행위가 하나님께 돌아가지 못하게 하나니 이는 음란한 마음이 있어 여호와를 알지 못하는 까닭이라”** / 평결 5:5 이스라엘과 에브라임이 넘어지고 **유다도** 넘어지리라(텔레스코핑; 므나헴? 베가?).
  - 5:6–7 양 떼와 소 떼를 끌고 여호와를 찾아도 만나지 못함, 이미 떠나심 / 정조를 지키지 않고 사생아(“새 달이”) — 민 10:10 절기의 나팔 BUT 호 5:8–9 **전쟁의 나팔** / 왕상 12:25–33 여로보암의 죄.
  - 5:10–12 유다의 지도자들 — **지계표를 옮기는 자** / 에브라임에게는 좀·썩이는 균, 유다에게는 젊은 사자.
  - 5:13 에브라임·유다가 병을 깨닫고 **앗수르의 야렙 왕**에게 → 왕하 15:19 므나헴, 16:7–9 아하스, 18:13 히스기야와 앗수르 — 상처를 낫게 하지 못함.
- **5:15–6:11 여호와께 돌아가자**:
  - 5:15 “그들이 죄를 뉘우치고 **내 얼굴을 구하기까지** 내 곳으로 돌아가리라, 고난 받을 때에 나를 간절히 구하리라.”
  - **6:1–3 “오라 우리가 여호와께로 돌아가자”(↔ 2:7)** — 이 기도의 성격은??? 백성의 고백인가, **선지자의 중보(호소)**인가? (강의는 “선지자의 호소”로 정리)
  - 6:4 “너희의 인애가 **아침 구름**이나 쉬 없어지는 **이슬** 같도다” / 6:5–6 선지자들로 그들을 치고 입의 말로 죽였나니 — **“나는 인애를 원하고 제사를 원하지 아니하며 번제보다 하나님을 아는 것을 원하노라.”**
- **7:1–16 반역의 모습**: “내가 이스라엘을 치료하려 할 때 에브라임의 죄와 사마리아의 악이 드러나도다” / 비유: 간음하는 자, **달궈진 화덕, 뒤집지 않은 전병, 어리석은 비둘기, 속이는 활**.
- **8:1–14 위선이 드러남**: 8:1 독수리 — 언약의 심판 선언(신 28:49) / 8:2 “나의 하나님이여 우리가 주를 아나이다” = **위선** / 8:3–6 이스라엘이 버린 선 — 하나님에게서 나지 않은 왕·지도자·우상, 결국 파괴(성취: 사마리아 송아지 파괴, 왕하 23:15–20 **남유다 요시야**) / **8:8 예언적 완료** “이미 삼켜졌은즉 — 여러 나라 가운데” / 8:14 이스라엘은… 유다는….
- **9:1–9 위선에 대한 심판 선언**(송사): 호출 9:1 “이방 사람처럼 기뻐 뛰놀지 말라” / 증거 9:1 / 평결 9:3–6 // 호출 9:7 “선지자가 어리석었고 신에 감동하는 자가 미쳤나니” / 증거 9:7–8 / 평결 9:9.
- **9:10–11:11 불성실한 이스라엘과의 동행을 기억**: 9:10 광야의 포도·무화과 첫 열매 같던 이스라엘 → **바알브올**의 범죄 / 9:11–12 임신 없음, “내가 그들을 떠날 때에 화” / 9:13–17 두로 같던 에브라임 / **10:1–3 열매 맺는 무성한 포도나무 — 열매 맺을수록 우상숭배** / 10:4 밭이랑의 독초 / 10:5–10 사마리아 송아지의 운명 / 10:11 길들인 암소 / **11:1–11 “내 사랑하는 아들”**(“이스라엘이 어렸을 때에 내가 사랑하여 내 아들을 애굽에서 불러냈거늘”).
- **11:12–12:14 속이는 이스라엘, 신실하지 못한 유다**: 11:12 하나님을 속이는 에브라임, 하나님에 대해 정함이 없는 유다 / 12:1 **앗수르와 계약하며 기름을 애굽으로** / 12:2–6 유다와의 논쟁 / 12:7–14 이스라엘과의 논쟁.
- **12:7–13:16 이스라엘의 심판**: 12:7–8 스스로 속임 / 12:9 “애굽 땅에서부터 나는 네 하나님” — 다시 장막에 거주하게 / 12:10–13 선지자를 통해 비유, **한 선지자로 보호받았거늘** / 12:14 격노하게 함 // 13:1–3 우상숭배 / 13:4 “애굽 땅에서부터 나는 네 하나님 — **나 외에는 구원자가 없다**” / 13:5–6 “광야 마른 땅에서 너를 알았거늘… 배가 불렀고 교만하여 **나를 잊었음**” / 13:7–16.
- **14:1–3 진실된 돌아옴** — **6장의 “돌아오라”와 대조해서 공부해 보기**: 심판의 원인 / **말씀을 가지고** 돌아옴 / **수송아지가 아닌 입술의 열매**를.
- **14:4–9 이스라엘의 회복** — 6장에 나타난 하나님의 반응(6:4 “내가 네게 어떻게 하랴”)과 대비.
- 마지막 그림 캡션: “**이르시되 너희 중에 죄 없는 자가 먼저…**(요 8:7)” — 고멜 이야기를 간음한 여인 이야기와 연결(해석적 적용).

## 주석 작성 시 활용 포인트 (해석)

- **이름 신학**: 이스르엘–로루하마–로암미 → 루하마–암미(2:1, 23) → 롬 9:25–26, 벧전 2:10.
- **“안다(야다)” 주제**: 2:8 알지 못함 → 2:20 여호와를 알리라 → 4:1, 6 지식이 없음 → 5:4 여호와를 알지 못함 → 6:3, 6 여호와를 알자, 하나님을 아는 것을 원함 → 8:2 위선적 “아나이다” → 13:4–5 “너를 알았거늘… 나를 잊었음”.
- **6장 vs 14장** “돌아가자/돌아오라” 대조.
