## 표제 · 중심 주제

- 표제: **“왕이 없으므로 자신의 옳은 소견대로 행하는 이스라엘”**
- 중심 주제: **자기 소견대로 살아가는 백성들에게 진정한 왕이 필요하다.**
- 쓰인 이유:
  1. 반복적인 죄악에도 **하나님의 긍휼과 사랑이 매우 크심**을 알리려고
  2. 자기 소견대로가 아니라 **이스라엘의 진정한 왕이신 하나님**을 의지하며 살라고
  3. 이스라엘에게 필요한 왕(하나님 마음에 합한)은 **하나님이 세운 사람(다윗)**임을 말하려고

## BRI

- **저자: 사무엘** (추정 근거):
  - 여호수아서 기록이 반복 인용(삿 1:10–15 ← 수 15:13–19; 삿 1:21 ← 수 15:63; 삿 1:27–29 ← 수 17:11–13)
  - 고난의 원인이 **우상 숭배**임을 관찰할 수 있는 사람(2:1–6; 6:7–10; 10:10–16)
  - “그때에 왕이 없었다” 반복(17:6; 18:1; 19:1; 21:25[자료 표기 21:31])
  - 가나안 족속이 **게셀**에 거함(1:29) — 게셀은 후에 바로가 솔로몬의 아내(자기 딸)에게 준 땅(왕상 9:15–16)
  - 여부스 족속이 아직 예루살렘에(1:21) — 후에 다윗이 추방
  - 성막이 **실로**에(18:31)
  - **유다 지파를 부각**(1–2장), **베냐민을 격하**(19–21장), 에브라임 이야기가 상세
  - → 왕정 시대에 살되 다윗 즉위 이전의 제사장 또는 사사 = **사무엘**
  - 사무엘: 이름 = “하나님에 대하여 들음”(8050), 에브라임 지파 소속 제사장 엘가나의 아들, 한나의 기도로 잉태(삼상 1장), 엘리 앞에서 자람(1:24; 2:11), 말씀을 가르침(4:1), 신앙 회복(7:5–11), **마지막 사사이자 선지자**(7:15–17), 사울과 다윗에게 기름부음(10:1; 16:13), 왕의 제도 선포(12장), 다윗 행적 일부 기록(대상 29:29)
  - 외증: 탈무드는 **룻기와 사사기를 사무엘이 기록**했다고 봄.
- **기록 시기**: 왕이 없었다는 반복 → 저작 시에는 왕이 있음. 사무엘은 다윗 즉위를 못 보고 죽음(삼상 25:1) → **사울 통치 중, 사무엘 사망 전: BC 1050–1010**. (사울 1050–1010, 다윗 1010–970)
- **수신자**: 사울이 불순종하기 시작했을 때부터 사무엘이 죽기 전, 다윗이 왕이 되기 전의 이스라엘 백성(사울과 다윗 포함).

## 17–21장 왕이 없으므로

- 틀(수미상관): A **17:6** “그때에는 이스라엘에 왕이 없으므로 사람마다 자기 소견에 옳은 대로 행하였더라” … A′ **21:25** 같은 문장.
  - 1) 미가의 집에 신상과 개인 제사장(17장) 2) 단 지파가 땅 분배 때 새긴 신상과 제사장(18장) 3) 베냐민 기브아인의 만행 → 윤리적 타락(19장) 4) 지파 간 내전: 베냐민 ⇔ 이스라엘(20장) 5) 베냐민의 아내 찾기 → 또 다른 살육(21장)
  - (관찰) 범위가 **한 가정(17장) → 한 지파(18장) → 온 이스라엘(19–21장)**으로 확대 — 강의안 소제목 “한 가정에서”, “한 지파가”, “온 이스라엘이(모든 지파)”.
- **17장 카이아즘 — “한 가정에서”**: A 미가가 어머니의 은을 훔쳤다 돌려줌, 어머니가 “여호와께 복 받기를” 빔(1–2) / B 어머니가 은으로 신상을 새기고 부어 만듦, 신당·에봇·드라빔, 아들을 제사장으로(3–5) / **C 17:6 왕이 없으므로…** / B′ 레위인을 **돈으로** 개인 제사장으로 고용 / A′ “여호와께서 내게 **복 주실 줄** 아노라”(13).
- **18장 병행 — “한 지파가”**: 1a “그때에 왕이 없었고” / A 단의 용사 5명이 정탐 중 미가의 집에 들름(1b–2 ↔ 13–14) / B 미가의 제사장을 만남(3–6 ↔ 15–26) / C 라이스 땅을 얻음(7–12 ↔ 27–28).
- **19장** 1절 “왕이 없을 그때에” → 온 이스라엘(모든 지파)이 자기 소견대로(19–21장).
- **21장**:
  - 샌드위치: A 미스바에서 맹세 — 베냐민에게 아내를 주지 않으리라(1) / **B “여호와여 어찌하여 이런 일이 생겨 한 지파가 없어지게 하시나이까”(2–4)** / A′ 미스바에서 맹세 — 올라오지 않은 자는 죽이리라(5). → **어리석은 맹세의 결과로 또 다른 살육, 자기 죄를 여호와께 탓함.**
  - 병행(6–14 / 15–24): 뉘우침 → 아내를 얻게 할까? → 주지 않기로 맹세함 → **해결책**: 야베스길르앗 주민을 죽이고 처녀 400명 / 실로의 명절에 춤추는 여자 200명을 붙듦.

## 사사기와 사무엘의 병행 구조 (삿 13:1–삼상 7:15) [병행]

- 사사기의 패턴(범죄 → 대적에게 넘겨짐·압제 → 회개 → 구원 → 평화)은 **삿 13장에서 시작해 사사기가 아니라 삼상 7장에서 완성**된다.
  - **삿 13:1 블레셋 40년 압제**는 **삼상 7:13–15 블레셋 압제가 끝남, 평화 선언**에서 마쳐진다.
  - 삼손은 20년 사사였으나 **평화가 언급되지 않음**.
- 사사기 후반부는 **의도적으로 연대를 흐트러뜨려** 두 사건을 배치하고, 병행 구조로 **실로 성소의 부정적 요소**를 조명한다. 사무엘상 1–7장의 세 번째 사건이 이어져 결국 **실로의 성막이 무너지고 “여호와의 영광이 없다”(이가봇)**로 끝난다 = **제사장 나라(출 19:6)로서의 정체성이 무너진 사건**(시 78:56–66).
- **레위인의 실패 1·2·3** (같은 5요소: 도입 / 이동 / 범죄 / 전쟁 / 성소):

| | 레위인의 실패 1 (삿 17–18) | 레위인의 실패 2 (삿 19–21) | 레위인의 실패 3 (삼상 1:1–7:1) |
|---|---|---|---|
| 도입 | **에브라임**에 사는 미가와 모친 | **에브라임**에 사는 레위인과 첩 | **에브라임**에 사는 엘가나·한나·브닌나 |
| 이동 | **베들레헴**에서 온 레위인 | **베들레헴**에서 기브아로 | 에브라임에서 **실로**로 |
| 범죄 | 레위인이 미가의 제사장이 됨 | 첩이 능욕당해 죽음 | 엘리의 아들들이 제사를 멸시 |
| 전쟁 | 단 지파가 제사장·신상·에봇·드라빔을 빼앗음 | 이스라엘 ⇔ 베냐민, 멸절 위기 | 블레셋과 전쟁, **궤를 빼앗김** |
| 성소 | **실로에 하나님의 집이 있는 동안** 단에 미가의 신상(18:31) | **실로에서** 여자들을 납치(21:19–23) | 엘리의 죽음, **이가봇** — 궤가 기럇여아림으로 |

- **실로 성막이 무너진 증거**: 수 18:1 실로에 회막 / 삼상 6:18–21 돌아온 궤를 둘 곳이 없음 / 삼상 7:1 기럇여아림 아비나답의 집, 엘르아살이 궤를 지킴 / 삼하 6:2 바알레유다(대상 13:6–7) / 시 132:5.
- 도표 2 (사사기 ⇔ 사무엘의 3단 병행):

| | 사사기 | 사무엘상 |
|---|---|---|
| 출생 | 삼손: 임신 못함 → 여호와의 사자가 찾아옴 → 나실인. 부모: “말씀이 이루어질 때 존귀히 여기리다”(삿 13:17) | 사무엘: 여호와께서 임신하지 못하게 → 하나님께 나가 기도 → 나실인. 부모: **엘리의 말을 신뢰, 먹고 얼굴에 근심이 없음**(삼상 1:17–18) |
| 사역 | 블레셋 상대 20년 — **구원하지 못함** | 말씀이 온 이스라엘에(4:1), 궤가 돌아온 20년 후 미스바 대각성, **에벤에셀 승리 — 블레셋에게서 구원을 이룸** |
| 제사장의 타락 | 미가의 신당, 레위 자손이 미가의 제사장, 단 지파가 탈취 — “왕이 없으므로”(17:6) | 실로의 장막, 엘리 아들들의 패역, 궤를 빼앗김, 영광이 없음 — “**여호와의 말씀이 희귀**”(3:1) |
| 베냐민 지파 이야기 | 베냐민과 전쟁 → 미스바에 모임 → **길르앗 야베스** 불참 응징, 처녀 400 → 실로의 여인들 → 집으로 — “왕이 없으므로”(21:25) | 왕을 청함(8:5–6, 19–20 “우리를 다스리고 우리의 싸움을 싸우게”) → **베냐민 청년 사울** 기름부음 → **미스바에 모임**(제비) → 집으로 → **길르앗 야베스**의 위기와 구원 → 사울이 왕으로 인정 |

- **사무엘의 관점** [병행]:
  - 사무엘은 왕정을 세웠지만 **왕정을 지지한 사람은 아니다**.
  - 사무엘에 따르면 사사 시대는 왕이 없는 시대가 아니었다 — **왕은 하나님이셨다**(삼상 12:12).
  - 사무엘이 원하는 왕의 모습은 백성이 원하는 모습과 다르다(미스바에서 사울에게 보인 반응).
  - **소견대로 행한 것은 왕이 없어서가 아니다. 이스라엘에서 레위인의 역할이 무엇인지 상고해 보라.**
  - 삼상 12장 사무엘의 고별사 = 사사기의 요약 결론: 자신의 사역 확증(1–5) / 사사 시대 담론(6–11) / 왕을 구하는 것의 의미, 악을 행함, 자신은 기도할 것(12–25).
- ⚠ **긴장 기록**: [삿A][삿B]의 사사기 강의는 “자기 소견대로 사는 백성에게 **진정한 왕(다윗)이 필요하다**”를 중심 주제로 삼는 반면, [병행] 자료는 “**왕이 없어서가 아니다 — 왕은 하나님이셨고, 문제는 레위인(제사장)의 실패**”라고 본다. 두 관점 모두 기록. 주석에서는 “표면의 반복구(왕이 없으므로) + 그 이면의 레위인·성소의 붕괴”를 함께 보여 주는 방식이 두 자료를 모두 살림(해석). → `../자료간_차이.md`
