### 2. 기록 연대
1. 각각의 예언은 각각의 시대에 기록 — 요시야, 여호아하스, 여호야김, 여호야긴, 시드기야, 멸망 후.
2. **여호야김 시대에 기록** — 36:20–26(태우고), 27–28(다시 기록) → **대부분의 말씀(예언)은 여호야김 시대에 선포된 말씀**.
3. 예루살렘 멸망 직후에 기록 — 39–43장.
4. 애굽으로 끌려간 후에 기록 — 44장.
5. **여호야긴(여고냐)의 복권이 기록됨** — c. BC 561년경의 사건. ([렘본] p45는 “c. BC 560년경” — 차이 기록)

### 6. 예레미야 선지자에 대해
- ① 이름: **“야훼가 내던지다” 혹은 “야훼가 세우시다/높이시다”** ② 고향: **아나돗**(1:1) ③ 부르심 받은 당시의 나이 ④ **사역 기간: 요시야 13년(627) ~ 예루살렘 멸망(586)** ⑤ 결혼(16:1–4 — 결혼하지 말라는 명령) ⑥ 사역 기간 중의 일: **5명의 유다 왕과 1명의 총독**(그다랴) / 앗수르 멸망(612) / **유다의 멸망(605, 597, 586, 582)** / 애굽으로의 이주.

### 7. 역사적 배경
- **정치적 상황**: ① 5명의 왕이 교체됨 — **요시야가 죽을 당시(609) 왕자들의 나이: 여호아하스 23세(요시야가 하나님을 구하기 시작한 해에 태어남), 엘리야김 25세, 시드기야 9세**.
  - 요시야의 일생: 640 8세 즉위(왕하 22:1; 대하 34:1) / 632 16세 하나님을 구하기 시작(대하 34:3a) / 628 20세 우상 제거 시작(34:3b) / **627 21세 예레미야 사역 시작**(렘 1:2) / 622 26세 우상 제거·성전 정결/보수·율법책 발견·유월절(대하 34:8, 14) / 612 36세 앗수르 멸망 / 609 39세 죽음.
  - ② 앗수르의 멸망(612) ③ 남유다의 멸망.
- **사회적 상황(유다의 죄)**: 지도자들(왕·선지자·제사장)의 부패 / 가난한 자·고아·과부 압제 / **노예를 풀어주지 않음(언약 파기)** / 무죄한 자의 피(불공평한 재판).
- **종교적 상황**: 우상 숭배 / 자녀를 불 가운데 지나가게 함 / 성전을 더럽힘 / 안식일을 지키지 않음(언약 불성실) / 선지자들의 예언 무시 / 거짓 선지자들 / 언약을 깨뜨림 / 하나님보다 이방 나라들을 의지 / 위선·중상모략 / 경고에도 돌이키지 않음.

### 8. 예레미야서의 특징
1. **신명기를 기반으로 한 유다 멸망의 이해**: ① 하나님과 맺은 **언약의 파기가 결국 유다의 멸망**을 가져옴 ② 렘 11, 26장 ③ **성전의 멸망은 하나님의 실패가 아니라, 오히려 하나님께서 언약에 신실하신 분이심을 증명함**.
2. **새 언약과 마음** — 가장 근본적인 문제(마음).
3. 예루살렘 멸망에 대한 이해: 왜 하나님께서 예루살렘을 심판하셔야만 했는가? / 그 심판은 무슨 의미가 있으며 왜 중요한가?

1. **16:1–18**: **3가지 명령** — 아내를 맞이하지 말고 자녀를 두지 말라(2) / 초상집에 들어가지 말고 애곡하지 말라(5) / 잔칫집에 들어가 먹거나 마시지 말라(8) → 예레미야의 삶 자체가 메시지 / **원독자(바벨론 포로)들의 생각 — 조상들의 죄로 인해 자신들이 고통당한다고 생각** / 포로 귀환 약속(16:14–15).
2. **16:19–17:18**: 예레미야의 기도와 응답(16:19–20) / 유다의 죄가 **금강석 끝 철필로 마음과 제단 뿔에 새겨짐**(17:1) / **축복과 저주 《대조》(17:5–11)** — 사람을 믿는 자 vs 여호와를 의지하는 자 / 예레미야의 간구(17:12–18) — 하나님을 ‘보좌’, ‘성소’라 칭함; 하나님 = 이스라엘의 소망, **생수의 근원**, 회복의 근원, 피난처.
3. **17:19–27 안식일**: 십계명(언약의 핵심) / 짐을 지고 예루살렘 문으로 들어오지 말라(21–22, 24, 27) / 하나님의 말씀(언약)에 무관심한 예루살렘.

### 18–20장
1. **토기장이(18:1–19:15)**: 토기장이의 집(18:1–12) — 진흙으로 그릇을 만드는 토기장이(4), **하나님의 주권적 통치 강조, 그러나 기꺼이 뜻을 돌이키기 원하심(18:7–10)** / 죄(13–15) / 심판(16–17) — 하나님의 얼굴(임재)을 숨기심(암 8:11–12) / 예레미야를 죽이려는 음모(18:18–23) — “제사장에게서 율법, 지혜로운 자에게서 책략, 선지자에게서 말씀이 끊어지지 않을 것”이라며 **예레미야의 말에 주의하지 않기로 결정** / **옹기를 사서 힌놈의 골짜기에서 깨뜨림**(19:1–15).
2. **예레미야와 바스훌(20:1–18)**: 바스훌 — 임멜의 아들(20:1; 대상 24:14), 제사장, **성전의 총감독(대제사장 다음, 성전 문제 책임)** / 바벨론 포로 예언 — **“북방민족” → “바벨론”으로 명시(20:4)** / 예레미야의 탄식 — **“여호와를 선포하지 아니하면 마음이 불붙는 것 같아 견딜 수 없음”(20:9)**.

### 21–24장 〈카이아즘〉
- A 21:1–10 바벨론 포로 — 하나님의 뜻(**생명의 길/사망의 길**) / B 21:11–22:30 **왕**에 대한 심판 / **C 23:1–8 다윗에게서 날 의로운 왕(메시야)** / B′ 23:9–32 **선지자**에 대한 심판 / A′ 23:33–24:10 바벨론 포로 — 하나님의 뜻(**좋은 무화과/나쁜 무화과**).
- 다윗에게서 날 한 의로운 가지(23:1–8): 양 떼를 흩어지게 하는 목자(1–2) / 회복의 약속(3) / **의로운 가지(23:5–8; 33:14–18; 사 11:1, 10)**.

### 25장 초기 사역의 요약
- 배경(25:1–3 — 여호야김 4년 = 느부갓네살 원년) / 내용 / **바벨론 70년 포로 생활 예언** / **모든 나라를 향한 진노의 잔(25:15–26)** / 진노의 잔의 시작(25:29 — 내 이름으로 일컬음을 받는 성에서부터).

### 26장
- 성전에서의 설교(26:1–7) / 사람들의 반응(26:8–24): 제사장·선지자·백성들이 죽이려 함 / 고관들이 성전 새 대문 입구에 옴 / 예레미야의 말 / **히스기야와 미가 선지자(26:18–19 — 미 3:12 인용)** / **우리야(26:20–23 — 여호야김이 애굽까지 쫓아가 죽임)** / 예레미야의 구원(26:24 — 사반의 아들 아히감).

### 27–29장
1. **바벨론의 멍에(27:1–22)**: 배경 — 여호야김 vs 시드기야(27:3, 12, 20; 28:1 — 27:1 “여호야김” 표기 문제를 짚은 것으로 보임) / **《교환–대조》**: A 하나냐의 예언(28:2–4, 거짓) / B 예레미야(28:5–9, 참) / A 하나냐(28:10–11, 거짓 — 멍에를 꺾음) / B 예레미야(28:12–16, 참 — 쇠 멍에) / **C 예레미야 예언의 성취(28:17 — 하나냐가 그 해 일곱째 달에 죽음)**.
2. **예레미야의 편지(29장)**: 배경(29:1–3) — 여고니야 왕이 예루살렘을 떠난 후(원문 “BC 567년 이후” — 597의 오기로 보임, `자료간_차이.md`) / 내용(29:4–23): **바벨론에서 집을 짓고 살라(5)** / **사로잡혀 간 그 성읍의 평안을 구하라(7)** / **70년이 차면 돌아올 것(10, 14; 25:11)** / **하나님의 생각 — 재앙이 아닌 평안, 미래와 희망(11)** / 부르짖고 온 마음으로 구하고 찾으라(12–13) / 스마야의 편지(24–29) / 예레미야의 예언 / 거짓 선지자(거짓 평안).

### 30–33장 회복 — 새 언약
1. **회복에 대한 약속(30장)**: 포로 귀환(3, 10, 18) / 멍에를 꺾고 다시는 이방인을 섬기지 않음(8) / 여호와를 섬김(9) / 폐허 위에 성읍 건축(18) / 감사와 즐거움의 소리(19) / 영도자가 그들 중에서 나옴(21) / **“너희는 내 백성이 되겠고 나는 너희의 하나님이 되리라”(22)**.
2. **새 언약(31:1–40)**: 회복의 약속(1–14) / **회복의 근거** — 하나님의 영원한 사랑(3, 20), 인자함(3), 인도하심(3, 9), 깊이 생각하심(20), 긍휼(20) / **라헬의 애곡과 위로(15–22)** (마 2:18 인용 — 보충) / **죄의 유전(29–30)** — “아버지가 신 포도를 먹었으므로…”를 다시 말하지 않음 (원독자의 질문에 대한 답 — 해석) / **새 언약 — 새 언약궤(31–34)**.
   - **옛 언약 vs 새 언약 (옛 언약궤 vs 새 언약궤)**:

| 옛 언약 (출 19–24장; 신 6:1) | 새 언약 (렘 31:31–34) |
|---|---|
| 언약의 내용이 **돌판**에 새겨짐 | 언약의 내용이 **마음**에 새겨짐 |
| 언약 문서(돌판)를 **나무 궤** 속에 둠 | 언약 문서(마음)를 **사람** 속에 둠 |
| 돌판을 품은 나무 궤 → **옛 언약궤** | 마음을 품은 사람 → **새 언약궤** |
| 언약궤가 놓이는 곳: 지성소 — **고정된** 언약궤/지성소 | 지성소 — **움직이는** 언약궤/지성소 |
| 하나님이 언약궤에 임하심 (**God with us**) | 하나님이 언약궤에 임하심 (**God in us**) |
| 구름기둥이 이스라엘 앞에서 인도 | **성령님이 우리 안에서** 인도 |

3. **아나돗 밭을 사는 예레미야(32장)**: 배경 — **시드기야 10년(BC 587)**, 바벨론 군대가 예루살렘을 에워쌈(2), 예레미야는 시위대 뜰에 갇힘(2–5) / **하나멜의 밭(6–15)** — 숙부 살룸의 아들, “사람들이 이 땅에서 집과 밭과 포도원을 다시 사게 될 것”(15) / 기도와 응답(16–35) / **영원한 언약(36–44)** — 복을 주기 위해 떠나지 않음, **하나님을 경외하는 마음을 그들 마음에 둠**(40).
4. **회복에 대한 약속(33장)**: 배경 — 여전히 시위대 뜰(1) / “일을 행하시는 여호와, 그것을 만들며 성취하시는 여호와”(2) / **“크고 은밀한 일을 보이실 것”(3)** / 성을 치료하여 낫게 하심(6) / 다윗에게서 한 의로운 가지(33:15; 23:5; 사 11:1 — 원문 “사11:11”, 오기로 보임).

### 34–38장
1. **하나님의 말씀을 무시하는 유다(34장)**: 배경 / 예레미야의 예언(2–5) / **시드기야의 언약 수립과 파기(8–11) — 노예 해방 후 다시 잡아들임** / 언약 파기에 대한 말씀(12–22).
2. **선조의 말을 존중하는 레갑 사람들(35장)**: 레갑 사람들 — **겐 족속**(대상 2:55; 창 15:19; 삿 1:16 — 원문 “창15:9”) / **요나답(여호나답, 왕하 10:15, 23)의 명령**(렘 35:6–7: 포도주를 마시지 말고 집을 짓지 말고…) / 하나님의 축복(35:19).
3. **첫 번째와 두 번째 두루마리(36장)**: 배경 / 기록(2–4) — 기록 목적(하나님의 기대, 3: 각기 악한 길에서 떠나면 용서) / **《교환–대조》**: A 말씀 낭독(5–8) / B **백성**의 반응 — 금식 선포(9–10) / A 낭독(11–15) / B **고관들**의 반응 — 두려워함(16–19) / A 낭독(20–23) / B **왕**의 반응 — **말씀을 불태움**(23–25) / 다시 기록(27–32).
4. **예레미야가 갇힘(37–38장)**: 시드기야 즉위(37:1–5) / 예언 — 갈대아인이 다시 와서 성을 빼앗아 불사를 것(37:8) / 예레미야를 가둠(37:11–38:28) / 감옥 뜰로 이동.
- **34–38장 〈카이아즘〉**: A 34:1–7 바벨론 포로 — 하나님의 뜻 / B 34:8–22 하나님의 말씀을 무시하는 유다 / **C 35:1–19 조상 요나답의 말을 존중하는 레갑 족속** / B′ 36:1–32 하나님의 말씀을 무시하는 유다 / A′ 37:1–38:28 바벨론 포로 — 하나님의 뜻. (레갑 족속이 사람의 말에 순종한 것과 유다가 하나님의 말씀에 불순종한 것의 대조가 중심 — 해석)
