## 다윗과 솔로몬 [왕B]

- **통일 왕국 BC 1050–931**: 사울 1051–1011 / 다윗 1011–971 / 솔로몬 971–931. (사무엘 강의 1050–1010·1010–970과 1년 차 → `../자료간_차이.md`)
- **다윗의 통치**: 30세 즉위, 40년(헤브론 7년 6개월, 예루살렘 33년). 이스보셋은 **마하나임**에서 북쪽 지파의 왕, 다윗은 헤브론에서 유다의 왕 → 모든 지파의 왕 → 수도를 예루살렘으로. 말년: 수넴 여자 아비삭(왕상 1:3–4).
- **영토 확장**: 블레셋 항복(삼하 5:17–25; 8:1), 모압(8:2), 소바(8:3), 다메섹 아람(8:5), 하맛의 조공(8:9), 암몬·에돔·아말렉(8:12–13), 두로와 화친(5:11).
- **솔로몬의 왕위 계승** — 솔로몬 vs 아도니야:

| | 솔로몬 | 아도니야 |
|---|---|---|
| 출신 | 밧세바의 넷째 아들(대상 3:5), 출생 시 **여디디야**(삼하 12:24–25) | 헤브론에서 낳은 넷째(암논·길르압·압살롬·아도니야), 학깃의 아들 |
| 왕으로 부르심 | **하나님으로부터** | **스스로** |
| 추종자 | 사독(대제사장), 브나야(군사령관), **나단(선지자)** | 아비아달(대제사장), 요압(군사령관) — **함께한 선지자가 없음** |
| 즉위 장소 | **기혼**(왕상 1:33) | 에느로겔 근방 소헬렛 바위(1:9) |
| 찬양 | 있음 | 있음 |
| 기름부음 | 있음(성막에서 취한 기름, 1:39) | **없음** |
| 뿔나팔 | 있음 | **없음** |

- **다윗의 유언**(왕상 2:2–4)을 읽는 질문 5가지: 다윗의 왕권에 대한 태도 / 왕권을 유지하는 비결 / 왕의 역할 / **다윗과 모세의 유언 비교** / 요압·바르실래·시므이.
- **솔로몬의 통치**:
  - 반대 세력 제거: 아도니야·요압·시므이(모두 **브나야**가), 아비아달(파면 2:27 — 엘리 가문 예언의 성취 → `03_레위기.md`).
  - 지혜를 구함: **기브온 산당**(대하 1:3), 산당 제사, 1,000번제(왕상 3:4).
  - 행정: 대제사장 사독과 아비아달, 제사장 아사리아(사독의 아들), 서기관, 사관, 군사령관 브나야, 지방 관장의 두령, 궁내대신 아히살, 노동 감독관 아도니람 / **12지방 장관** / 4대 수입원: 세금·부역·외국 공물·무역.
  - **다윗과 솔로몬 비교**: 자란 환경(가난·넓은 자연·목동 / 부유·갇힌 궁전·왕자) / 군대(공격적 / 방어적) / 왕궁(소박, 주로 밖 / 사치, 주로 궁) / 경비(전쟁으로 / 세금·무역으로).
- **성전 건축**:
  - 시작: **솔로몬 4년 2월 2일**(대하 3:2), **모리아산 여부스 사람 오르난의 타작마당**(대하 3:1).
  - 다윗은 피를 많이 흘려 짓지 못하고 준비만(대상 22:8–10; 22, 29장), 하나님이 다윗에게 **식양**을 주심(대상 28:11–12, 19).
  - 두로 왕 히람과 교역(약 3년), 장인 히람(납달리 지파 과부의 아들, 아버지는 두로인).
  - 인력: 역군 30,000 / 짐꾼 70,000 / 돌 뜨는 자 80,000 / 감독 3,300. **성전에서는 돌 다듬는 소리가 나지 않음**(6:7).
  - 규모 60×20×30 규빗(27.36×9.12×13.68m). 성소·지성소·현관, 모세의 장막과 흡사하나 낭실과 교창, 30개 골방, 현관의 두 놋기둥 **보아스와 야긴**(7:15, 21).
  - 금 600달란트(약 20,400kg). 6:11–13 하나님이 **성공 비결**을 말씀하심.
  - 완공: **솔로몬 11년 불월(8월)**(6:38). 궁전은 13년, 100×50×30 규빗.
