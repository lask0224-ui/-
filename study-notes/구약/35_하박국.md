## BRI

1. **누가 썼는가?** — **하박국**(하박쿠크, H2265): **「포옹」 — 손을 모으다, 껴안다, 끌어안다**. 1:1 “선지자 하박국이 묵시로 받은 경고라” / 3:1 “**시기오놋**에 맞춘 선지자 하박국의 기도라” → 선지자 하박국.
2. **언제 쓰여졌는가?** (범위를 단계적으로 좁힘)
   - 성전에 계신 여호와(2:20), 율법에 의한 죄악 판단(1:4) → **성전 멸망 이전, BC 586 이전**.
   - 갈대아 사람들이 일어났던 시기(1:6) → **신바벨론이 일어난 BC 626 이후**.
   - 갈대아인들을 강한 군대인 것처럼 묘사(1:5–11) → **느부갓네살(BC 605–562) 통치 이전**.
   - 포로들을 잡아가는 것을 말함(1:9, 표준새번역 “포로를 모래알처럼 많이 사로잡아 갈 것이다”) → 바벨론 포로 전, **1차 포로 BC 605 이전**.
   - 1:4 “악인이 의인을 에워쌌으므로 정의가 굽게 행하여짐” → BC 626 이후 남유다의 선한 왕은 요시야, **BC 609 요시야 죽음** 이후 4명의 왕은 요시야의 길을 가지 않고 악을 행함 → 요시야 시대는 아님.
   - 결론: 요시야 다음 여호아하스(살룸, 609, 3개월), **여호야김(엘리아김, 609–597)** 시대 → **BC 609–605**.
3. **누구에게?** — **여호야김(BC 609–597) 통치 시대에 살고 있는 남유다 백성**.
4. **World Power: 바벨론**
   - **나보폴라살(BC 626–605)**: 626 바벨론 차지 / 614 메대 **키악사레스**와 동맹 / 612 니느웨 정복 / 609 **1차 갈그미스 전투** 승(vs 애굽·앗수르 연합).
   - **느부갓네살(BC 605–562)**: 605 **2차 갈그미스 전투** 승 / **4번에 걸친 바벨론 포로** — 605 1차(다니엘) / 597 2차(여호야긴, 에스겔) / 586 3차(예루살렘 성·성전 파괴, 멸망) / 582 4차(렘 52장).
5. **유다의 종교적 상황**:
   - **요시야(BC 640–609, 31년)** (왕하 22:1–23:35; 대하 34:1–35:27): 640 8세 즉위, 어렸을 때 다윗의 하나님을 찾음(대하 34:3) / 628(20세, 12년) 예루살렘 정결 / 622(26세, 18년) 성전 수리, 율법책 발견, 언약 체결, 대대적 종교개혁, 유월절 / 609(39세) **므깃도에서 죽음**(애굽에 의해).
   - 요시야의 갑작스런 죽음으로 남유다는 위기.
   - **요시야 이후 왕 계보(대상 3장)**: 요하난 / ① **여호아하스(살룸)** 3개월, BC 609 애굽으로 잡혀감 / ② **여호야김(엘리아김)** 11년(609–597) — 605 2차 갈그미스, 1차 포로(다니엘) / ③ **여호야긴(여고냐)** 3개월 — 597 2차 포로(여호야긴 & 에스겔) / ④ **시드기야(맛다니야)** 11년(597–586) — 586 3차 포로(성과 성전 멸망) / 582 4차 포로(남은 자들).
   - 여호아하스: “그의 조상들의 모든 행위대로 여호와 보시기에 악을”(왕하 23:32).
   - **여호야김**(왕하 23:34–24:5; 대하 36:4–8 — 원문 표기 “왕하24:34~24:5 / 대하36:36:4~8”): “그의 조상들이 행한 모든 일을 따라서 … 악을”(왕하 23:37). **악행**: 일꾼의 품삯을 주지 않고 무죄한 피를 흘림·압박·포악(렘 22:13–19) / 선지자를 보내 회개 기회를 주셨으나 듣지 않음(렘 25:1–14) / 회개를 촉구한 선지자를 죽임(렘 26장) / **두루마리를 면도칼로 베어 화로 불에 던져 태움**(렘 36장).
6. **중심 내용/주제**: **의인은 믿음으로 산다** / **하나님의 주권 — 여호와의 영광을 인정하는 것이 세상에 가득할 것이다**(2:14).
7. **쓰인 이유**: 하나님이 모든 역사와 상황을 주관하시고 다스리시는 분임을 알게 / 악인은 하나님이 반드시 심판하심을 알게 / **환난 중에 믿음으로 살도록 격려**.

## 구조 (세 가지)

1. **구조 1**: 유다 악인에 대한 선지자의 질문 & 하나님의 대답(1:1–11: A 질문 1:1–4, B 대답 1:5–11) / 갈대아인에 대한 선지자의 질문 & 하나님의 대답(1:12–2:20: A 질문 1:12–17, B 대답 2:1–20) / 선지자의 믿음의 찬양 — 하박국의 기도(3:1–19).
2. **구조 2 〈병행구조〉**: A 질문(1:1–4) “유다 악인들의 행위, 어찌하여 잠잠하십니까?” → B 대답(1:5–11) “너희의 생전에 놀랄 일 — 사나운 갈대아인을 일으킬 거야” → C 반응(1:12) “주께서 심판하기 위해, 경계하기 위해 그들을 세웠습니다” // A 질문(1:13–17) “어찌하여 거짓된 자들(갈대아인)을 통해 유다를 심판하십니까?” → B 대답(2:1–20) “이 묵시는 정한 때가 있다. 갈대아인도 심판 받을 거야. 믿음으로 인내하고 기다려라” → C 반응(3:1–19) “진노 중에라도 긍휼을, 환난 날을 내가 기다립니다”.
3. **구조 3 〈카이아즘〉**: A 첫 번째 불평 — 주께서 구원하지 아니하시나이다(1:2–4) / B 하나님의 첫 대답 — 바벨론의 강력한 군대가 올 것(1:5–11) / C 두 번째 불평 — 거짓된 바벨론으로 유다를 심판합니까?(1:12–17) / **D 정한 때가 반드시 이른다 — 의인은 믿음으로 말미암아 산다(2:1–5)** / C′ 하나님의 대답 — 바벨론 역시 심판을 받을 것(2:6–20) / B′ 하나님의 임재 — 전사이신 하나님이 오실 것(3:1–15) / A′ 하박국의 찬양 — 구원의 하나님을 인하여 기뻐하리로다(3:16–19).
   - (구조 2는 1:12를 첫 반응으로, 구조 3은 1:12–17을 두 번째 불평으로 묶음 — 1:12의 경계 설정이 구조마다 다름. 자료 내 차이로 기록)

## 1:1–12 첫 번째 질문·대답·반응

- **A 1:2 〈교환〉** (A 선지자의 외침 / B 하나님의 무반응): A 여호와여 내가 부르짖어도 / B 주께서 듣지 아니하시니 어느 때까지리이까 / A 내가 강포로 말미암아 외쳐도 / B 주께서 구원하지 아니하시나이다.
  - **강포 — 하마스(H2555)**: 폭력, 난폭, 부당행위, 불법, 악. **외쳐도 — 자아크(H2199)**: 부르짖다, 외치다, 부르다.
- **1:4 〈인과〉 율법이 시행되지 못하는 이유**: 결과 — “이러므로 율법이 해이하고 정의가 전혀 시행되지 못하오니” / 원인 — “이는 악인이 의인을 에워쌌으므로 정의가 굽게 행하여짐이니이다”.
  - **굽게 — 아칼(H6127)**: 비틀다, 구부리다. **구약에서 합 1:4에 1회만 나옴**.
- **B 1:5–11 〈목록〉 갈대아 사람들의 특징**: 사납고 성급함(6) / 자기 소유가 아닌 거처를 점령(6) / 두렵고 무서움(7) / 당당함과 위엄이 자기들에게서 나옴(7).
  - **〈목록〉 바벨론 군대의 특징**: 군마는 표범보다 빠르고 저녁 이리보다 사나움(8) / 마병은 먹이를 움키려는 독수리처럼(8) / 강포를 행하려 앞을 향해 나아감(9) / 사로잡아 모으기를 모래같이(9) / 왕들을 멸시, 방백을 조소(10) / 견고한 성들을 비웃고 흉벽을 쌓아 점령(10) / **자기들의 힘을 자기들의 신으로 삼는 자들**(11) / 바람같이 급히 몰아 지나치게 행하여 범죄(11).
- **C 1:12 〈동의 대구〉**: A 여호와여 주께서 **심판**하기 위하여 / 그들을 **두셨나이다** // B 반석이시여 주께서 **경계**하기 위하여 / 그들을 **세우셨나이다**.
  - **두다 — 숨(H7760)**: 두다, 정하다, 임명하다, 확립하다 — **“특별한 목적을 위해 따로 구별해 두다”**. **경계 — 야카흐(H3198)**: 꾸짖다, 징계하다.

## 1:13–3:19 두 번째 질문·대답·반응

- **A 1:13–17 〈수사적 의문문〉 하나님을 향한 질문 3가지**: ① 악인이 자기보다 의로운 사람을 삼키는데 잠잠하십니까?(13) ② 어찌하여 사람을 바다 고기 같게, 벌레 같게 하십니까?(14) ③ 그들이 여러 나라를 낚시하듯 무자비하게 멸망시키는 것이 옳은 것입니까?(15–17).
- **B 2:1–20**:
  - **〈목록〉 하나님의 응답 — 묵시는 반드시 온다(2:2–3)**: ① 묵시를 판에 명백히 새기되 **달려가면서도 읽을 수 있도록** ② 묵시는 **정한 때**가 있다, 종말이 속히 이른다, 결코 거짓되지 아니한다 ③ 비록 더딜지라도 기다리라, 지체되지 않고 반드시 응하리라.
  - **〈대조〉 2:4**: “보라 **그의 마음은 교만하며** 그 속에서 정직하지 못하나 / **의인은 그의 믿음으로 말미암아 살리라**.” (신약 인용: 롬 1:17; 갈 3:11; 히 10:38 — 보충)
  - **5개의 화 오라클(2:6–20)** — 각 “고통의 이유 → 멸망의 예언” 구조:
    1. 2:6–8 자기 소유 아닌 것을 모으는 자여 (이유 6 / 예언 7–8)
    2. 2:9–11 자기 집을 위하여 부당한 이익을 취하는 자여 (9–10 / 11)
    3. 2:12–14 피로써 성읍을 건설하며 불의로 성을 건축하는 자여 (12 / 13–14)
    4. 2:15–17 술 취하게 하고 폭력을 일삼는 자여 (15 / 16–17)
    5. 2:18–19 우상의 나라여 (18–19 / 20 — “여호와는 그의 성전에 계시니 온 땅은 그 앞에서 잠잠할지니라”)
- **C 3:1–19 선지자 하박국의 기도 〈카이아즘〉**: A **시기오놋**에 맞춘 하박국의 기도(3:1) / B 선지자의 반응 — 듣고 놀람, **진노 중에 긍휼** 바람(3:2) / C 하나님의 임재 — 말을 타고 오심, 전사의 모습(3:3–11) / **D 주께서 주의 백성 구원하려 오심 — 악인의 머리를 치심(3:12–13)** / C′ 하나님의 임재 — 말을 타고 오심, 전사의 모습(3:14–15) / B′ 선지자의 반응 — 듣고 놀람, 환난 날을 기다림, 찬양함(3:16–19a) / A′ **수금**에 맞춘 하박국의 노래(3:19b).
  - (3:17–18 “비록 무화과나무가 무성하지 못하며 … 나는 여호와로 말미암아 즐거워하며” — 슬라이드에는 B′ 요약만 있음)
