- ★**공간적 배경 — 나일강** [출B]: 범람의 규칙성 → 풍요 보장 → 안정 속의 낙관적 사고 → 창조도 질서 있고 규칙적이라 생각 → 죽음 이후에도 삶이 계속되는 **순환론적 세계관**.
- ★**시간적 배경** [출B]: 출애굽 BC 1446 = 애굽 18왕조(BC 1570–1320). 야곱 130세(창 47:9)에 애굽 거주 시작 BC 1876. 왕상 6:1 출애굽 후 480년 = BC 966. 거주 430년(출 12:40–41).
- ★**구약의 절대 연도** [출B]: 니느웨에서 **앗수르 연대기(Eponym List)** 토판 발굴 → 수백 년 연대가 연결됨 → 토판 속 **일식 기록**으로 서기력 환산 가능 → 성경과의 가장 확실한 접점: **산헤립의 예루살렘 포위 BC 701** = 히스기야 14년(왕하 18:13–16). 앗수르 기록: “유대인 히스기야를 그의 왕도 예루살렘에 새장처럼 가두었다.”
  - → 사도행전 예습 강의의 “절대 연도·상대 연도” 설명과 같은 원리(`../신약/05_사도행전.md`).
- ★**18왕조와 모세** [출B] (창세기 도표보다 자세함):
  - 아모시스 1570–1546 (창시자) → 아멘호텝 1세 1546–1526 → **투트모세 1세 1526–1512**: 모세 출생, **남아 살해 사건의 주범**, 하셉수트의 아버지.
  - 투트모세 2세 1512–1504: 투트모세 1세와 후궁의 아들, 하셉수트(모세의 양모)의 남편, 아들 없음 → 후궁을 통해 투트모세 3세, 병약하여 일찍 사망.
  - **하셉수트 1503–1482**: 투트모세 3세의 섭정(약 20년), 상·하 이집트 통일, 두 왕관을 합친 관, 남장·가짜 수염. 모세 1486 도망, 하셉수트 1482 사망.
  - 투트모세 3세 1504–1450: 하셉수트와 사이가 나빠 그녀의 기록을 모두 삭제, **하셉수트의 양아들 모세를 경계 → 모세가 돌아오지 못함**.
  - **아멘호텝 2세 1450–1425**: 출애굽 당시의 바로, 10재앙과 장자의 죽음을 경험.
  - 투트모세 4세 1425–1417: 아멘호텝 2세의 **장자가 아님**(장자 재앙의 영향) — **‘꿈의 비석’(스핑크스)**.
- ★**원독자** [출B]:
  - 출애굽 1세대: 아브라함 언약의 후손 / 노예의 삶을 경험 / 애굽 종교의 영향 / 시내산 언약 당사자.
  - 출애굽 2세대: 출애굽 당시 20세 미만 + 광야 출생. 20세 이상의 죽음을 목격, 윗세대 잘못으로 40년 방황, 가나안 정복 전쟁을 앞둠.

## 1–18장 출애굽

### 1장
- 70명(창 46:8–27, 야곱과 아들들) → 보행 장정 60만 가량(12:37) = **여호와의 군대**.
- [출A] 교차: A 1:8–11 학대(국고성) / B 1:12 번성 / A 1:13–19 학대(노동·남아 살해) / B 1:20 번성.
- ★[출B] 1:1–5 열두 아들 명단(레아: 르우벤·시므온·레위·유다·잇사갈·스불론 / 라헬: 베냐민·요셉 / 빌하: 단·납달리 / 실바: 갓·아셀). 1:6–7 과거(요셉 세대 다 죽음) ↔ 현재(생육·번성·온 땅에 가득).
- ★[출B] 1:8–22 **바로 vs 산파(십브라·부아) 대조**: 바로는 이스라엘을 두려워함 ↔ 산파는 하나님을 두려워함 / 학대할수록 번성 ↔ 산파의 집안 흥왕.

### 2장 모세
- 2:2 **잘생긴(토브)** ↔ 창 1장 “좋았더라” / 2:3 **갈대 상자(테바, 8392)** ↔ 창 6장 **방주**(같은 단어) / 2:10 모세 = 물에서 건져 냄.
- 2:11 장성한 후(40세, 행 7:23), 애굽 사람을 죽임, 미디안 도주. 2:22 게르솜 = “내가 타국에서 나그네가 되었다”.
- ★[출B] 모세의 신분 변화: **애굽 왕자 → 살인자·도망자 → 나그네** (추방, 내몰림).
- 모세의 생애 3×40 (행 7장): 40세 미디안 도주 / 80세 떨기나무(행 7:30, 출 7:7) / 120세 죽음(신 34:7).
- [출A] 하나님의 계획 (교차): A 번성과 학대(1:7–22) / B 하나님의 준비 — 모세 출생·도주(2:1–22) / A 탄식과 부르짖음(2:23) / B **언약을 기억하시는 하나님**(2:24–25). ★[출B] 2:23–25 **들으시고, 돌보시고, 기억하심**.

### 3–4장 부르심
- 때: 장인의 양 떼를 칠 때, 80세. 장소: 하나님의 산 호렙, “신을 벗으라, 거룩한 땅”.
- 하나님의 계획: 조상에게 약속한 땅(3:8, 17) / 인도해 냄(10, 12) / 애굽 물품을 취함(21–22).
- 하나님의 이름: 아브라함·이삭·야곱의 하나님 / **스스로 있는 자**(3:14) / 여호와 = 영원한 이름, 대대로 기억할 칭호(3:15).
- ★[출B] 3:6–22 교차: A 6–10 (신명·고통을 들으심·약속·사명) / **B 11–14 “모세는 누구인가?” “하나님은 누구신가?”** / A′ 15–22 (반복·확장). 3:12 “이 산에서 하나님을 섬기리니 이것이 내가 너를 보낸 증거”.
- **모세의 거절 vs 하나님의 설득** (3:11–4:17):

| 모세 | 하나님 |
|---|---|
| 내가 누구이기에(3:11) | 내가 반드시 너와 함께 있으리라(3:12) |
| 이름이 무엇이냐 하면(3:13) | 스스로 있는 자(3:14) |
| 나를 믿지 않을 것(4:1) | 표징: 지팡이→뱀, 손 나병, (나일 물→피)(4:2–9) |
| 말을 잘하지 못함(4:10) | 누가 입을 지었느냐, 네 입과 함께(4:11–12) |
| 보낼 만한 자를 보내소서(4:13) | 노하심, 아론이 네 입을 대신(4:14–17) |

- **4:24–26 피남편** [출A] 교차: A 여호와께서 모세를 죽이려 하심 / B 십보라가 돌칼로 아들의 포피를 벰 / A′ 놓아주심 / B′ 피남편 = 할례 때문. ★[출B]는 4:18–31 전체를 교차로: A 애굽 귀환 결정 / B 목숨이 위태로움(네 목숨을 노리던 자가 죽음) / **C 애굽에 내릴 재앙 — “이스라엘은 내 아들 내 장자”, “네 장자를 죽이리라”(4:22–23)** / B′ 목숨이 위태로움(피남편) / A′ 애굽 도착, 백성이 믿고 경배.

### 5–7장
- 5장: “내 백성을 보내라” → 바로 “여호와가 누구냐”(5:2) → 짚 없이 벽돌 → 백성이 모세를 원망 → 모세 “어찌하여 나를 보내셨나이까”.
- [출A] **두 번의 부르심 대조**: 3장(미디안, 애굽으로 돌아가라 → 백성의 고난 가중) / 6장(애굽, 바로 앞에 들어가라 → 애굽에 재앙).
- [출A] **6:2–8 교차**: A 나는 여호와라(2) / B 조상에게 땅을 언약(3–5) / **C 출애굽의 목적 — 내 백성 삼고 너희 하나님 되리라(6–7)** / B′ 약속한 땅으로 인도(8) / A′ 나는 여호와라(8b).
- 6:10–7:7 병행 [출A]: 바로에게 말하라 → 나는 입이 둔한 자 → (6:14–27 레위 족보: 모세와 아론) → 7:1–6 모세와 아론(대언자) → 7:7 모세 80세, 아론 83세. ★[출B]는 D = 6:14–25 족보를 중심으로 한 교차 구조로 봄.
- [출A] **7:1–7 1인칭 “내가/내” 반복 7회** — 주도권이 하나님께 있음.

### 7–12장 열 재앙
- ★[출B] **재앙의 목적** 3가지: 이스라엘 속량(6:6) / 애굽이 여호와를 알게(7:4–5) / **애굽의 모든 신을 심판**(12:12).
- ★[출B] **“완악하게 하다” 3단어 표**: 하자크(강하게 하다) · 카샤(단단하게 하다) · 카바드(무겁게 하다). 주어가 **바로**인 경우(7:13, 14, 22; 8:15, 19, 32; 9:7, 34, 35; 13:15)와 **여호와**인 경우(4:21; 7:3; 9:12; 10:1, 20, 27; 11:10; 14:4, 8, 17)가 섞여 있음 → 초반은 주로 바로가 스스로, 6번째 재앙(9:12)부터 여호와가 주어로 두드러짐. (해석: 표를 보면 그렇게 읽힘)
- ★[출B] **3×3 사이클**: 각 사이클 1·2번째 재앙은 **사전 경고 있음**, 3번째(이, 종기, 흑암)는 **경고 없음**. 1·4·7번째는 “아침에 바로에게 서라”.

### 12–15장 유월절과 홍해
- [출A] **12–14장 병행**: 유월절·무교절(12:1–28) ↔ 유월절·무교절·장자 봉헌(12:43–13:16) / 하나님의 보호(12:29–36) ↔ 구름·불기둥(13:17–22) / 애굽에서 나옴(12:37–42) ↔ 홍해를 건넘(14장).
- **유월절(페사흐, 6453)** ← 파사흐(6452, 넘어가다). 12:13, 23, 27 “넘어가리니”. 할례받은 자만(이방인 포함) 참여(12:48). 무교절: 군대를 인도해 낸 날, 영원한 규례, 타국인에게도 동일.
- ★[출B] **11:1–12:36 “전쟁에서 승리하신 하나님을 기념하라”** 교차: A 승리 예고·은금 패물 / B 전쟁 방식 예고(밤중, 처음 난 것) / C 기념하라(달력의 시작, 유월절, 무교절) / C′ 첫 유월절 시행, 자녀가 물으면 / B′ 예고대로 실현 / A′ 떠나라, 은금 패물.
- ★[출B] **12:37–13:22**: A 약속의 성취(라암셋→숙곳, 430년, 창 15:13–14 “큰 재물을 이끌고 나오리라”) / B 기념할 규례(유월절·무교절·**처음 난 것** — 손의 기호, 미간의 표) / A′ 약속의 성취(요셉의 유골, 창 50:24–25).
- 13:17–18 블레셋 길이 아닌 홍해 광야 길. 13:19 요셉의 유골. 12:38 수많은 잡족. 12:41 **여호와의 군대**.
- 14장: 14:4 “바로로 말미암아 영광을 얻어 애굽 사람들이 나를 여호와인 줄 알게”. ★[출B] 교차: A 두려워 부르짖음, “가만히 서서 여호와의 구원을 보라, 여호와께서 싸우시리라” / B 바다를 가르리라 예고 / B′ 실행(큰 동풍, 애굽 “여호와가 그들을 위하여 싸운다”) / A′ 두려움에서 구원 → **백성이 여호와를 경외하며 여호와와 그 종 모세를 믿었더라**(14:31).
- 15:1–21 모세의 노래: ★[출B] 과거에 행하신 일(1–10, 애굽 군대) / **“신 중에 주와 같은 자 누구”(11)** / 미래에 행하실 일(12–18, 가나안 족속, 주의 기업의 산, 성소).

### 15:22–18장 시내산으로 가는 길
- [출A] 돌보시는 하나님 교차: A 마라의 쓴 물(15:22–27) / B 만나와 메추라기(16장) / A′ 반석의 물(17:1–7). 마라: A 쓴 물을 달게 / B 계명을 지키라, **치료하는 여호와** / A′ 엘림(샘 12, 종려 70).
- ★[출B] **시험의 방향 전환**: 마라 = **마시는 것**으로 하나님이 백성을 시험(계명 순종) / 신 광야 = **먹는 것**으로 하나님이 백성을 시험(율법 준행) / 르비딤(맛사·므리바) = 마시는 것으로 **백성이 하나님을 시험** — “여호와께서 우리 중에 계신가 안 계신가”(17:7).
- ★[출B] 16:13–30 **만나 원칙–순종 교차**: 원칙(한 사람 한 오멜) → 순종 / 원칙(아침까지 남기지 말라) → **불순종, 벌레** / 원칙(여섯째 날 갑절, 간수) → 순종 / 원칙(일곱째 날 없음) → **불순종, 얻지 못함** / 원칙(일곱째 날 나오지 말라) → 순종, 안식.
- 16:31–36 만나 한 오멜을 항아리에 담아 증거판 앞에 간수 — 40년 동안 가나안 접경까지.
- 17:8–16 아말렉: 모세의 손, 아론과 훌, 여호수아. “**책에 기록하여** 여호수아의 귀에 외워 들리라”(17:14 — 모세 저작 증거), **여호와 닛시**. ★[출B] 하나님을 시험한 이스라엘에게 주신 답변.
- 18장 이드로: 방문(게르솜·엘리에셀, “이제 내가 알았도다 여호와는 모든 신보다 크시므로”) / 조언(천부장·백부장·오십부장·십부장, “하나님께서도 허락하시면” 18:23).

  - “여호와께서 모세에게 **명령하신 대로**” ×18 반복 [출A].
  - ★39:32–43: 이스라엘 자손이 “명령하신 대로” 다 마침(32, 42) → **모세가 보니 명령하신 대로 되었으므로 축복**(43).
  - ★40:1–16 세우라는 명령 ↔ 40:17–33 실행(**둘째 해 첫째 달 초하루**). 세우는 순서: 증거궤 → 휘장 → 상 → 등잔대 → 금향단 → 성막 문 휘장 → 번제단 → 물두멍 → 뜰 포장 → 관유 → 아론과 아들들 위임.
  - **40:34–38** 구름이 회막을 덮고 **여호와의 영광이 성막에 충만**, 모세도 들어갈 수 없음. 구름이 떠오르면 행진, 아니면 머묾 — 낮엔 구름, 밤엔 불.
  - (해석) 1장 “이름들은 이러하니”(쉐모트)로 시작해 40장 영광의 임재로 끝남 = 29:45 표제 구절의 성취. 창 2:1–3 “창조의 완성·안식” ↔ 출 39:43 “모세가 보니… 축복하였더라”의 연결 가능성은 강의안에 명시되지 않음(주석 작성 시 검토 후보).
