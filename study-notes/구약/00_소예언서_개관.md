## 예언서 이해
- **예언이란 무엇인가?** — 예언(預言: **맡길 예**, 말씀을 맡은 자) vs 선지(先知)/예언(豫言: 미리 예, 미래를 미리 앎). (한자 구분으로 “미래 예고”보다 “말씀을 맡아 전함”을 강조 — 해석; `30_아모스.md` 선지서 개론의 “일반적 오해”와 연결)
- **하나님은 왜 예언자를 보내셔서 말씀을 선포하시는가?**
  1. **기억** — 렘 2:2–3 등
  2. **예방** — 렘 5:31 등
  3. **책망**(범죄 직시와 회개 촉구) — 사 1:15; 렘 4:1 등
  4. **소망**(위로와 회복) — 사 40:1–2 등

## 소예언서 전체 개관
- “십이 소예언서” 명칭은 **불가타(Vulgata)의 *Prophetae Duodecim***에서 유래.
- “대예언서”(이사야, 예레미야, 에스겔)와 구분되는 이유 — **분량** (다니엘은? 12장).
- 포함: 호세아(14장), 요엘(3), 아모스(9), 오바댜(1), 요나(4), 미가(7), 나훔(3), 하박국(3), 스바냐(3), 학개(2), 스가랴(14), 말라기(4). 이름은 예언자 이름에서 유래.

### 시기적·지리적 배경
- 시기적 배경 및 저술 시기(모든 주장을 고려하면) **주전 9세기 ~ 주전 3세기**.
- 시기 구분: **주전 8세기 — 호세아, 아모스, 요나, 미가 / 주전 7세기 — 나훔, 하박국, 스바냐 / 주전 6–5세기 — 학개, 스가랴, 말라기 / 요엘과 오바댜 — 주전 9–4세기 사이로 추정**.
- 지리적 배경: 대부분 유대 땅, 요나는 니느웨도 배경 / 예언의 대상: 메소포타미아~애굽 사이의 나라들. (고대 근동 지도 수록)
- **연표 “십이 소예언서의 시대”** (이미지 확인):
  - 북이스라엘 예언자: 엘리야/엘리사 → **아모스, 호세아, 요나(?)** (여로보암 2세 787–747 전후).
  - 남유다 예언자: **미가, 이사야**(히스기야 725–697 전후) / **나훔(?), 스바냐**(요시야 639–609 전후) / **예레미야, 하박국(?)** / **에스겔** / **학개, 스가랴, 말라기**(538 고레스 칙령·성전 재건 이후) / **요엘(9–5세기 사이로 추정), 오바댜(9–6세기 사이로 추정)** — 넓은 막대로 표시.
  - 연표상 왕 연대(이 자료의 표기): 남유다 요시야 639–609, 여호야김 608–598, 여호야긴 598–597, 시드기야 597–587, **남유다 멸망 587**, 여호야긴 사면 560, 고레스 칙령 538 / 북이스라엘 여로보암 2세 787–747, 북이스라엘 멸망 722.
  - 주변국 상호 영향력(패권국가): 앗수르(중→강, 8세기) → **앗수르→바벨론** → 바벨론 → **바벨론→바사** → 바사. 앗수르: 불(745–727), 사르곤(721–705), 에살핫돈(680–669), 아슈르바니팔(669–627), **니느웨 멸망 612, 앗수르 멸망(갈그미스) 609** / 애굽: 느고(609–594), 호브라(588–569) / 바벨론: 느부갓네살(604–562), 에윌므로닥(561–560), **바벨론 멸망 538** / 바사: 고레스(539–530).

## 책별 요약 (개관 자료 기준)

### 호세아
- 이름: **“그가 도우신다”, “그가 건지신다”** / 별칭 **사랑의 예언자** / 출신 **북이스라엘** / 선포 대상 북이스라엘(**이후 유다에서 편집**) / 활동 **주전 약 750–722** / 주요 개념: 결혼, 음행, 인애, 하나님을 아는 지식.
- **구조(심판/구원 교차)**: 1:1 표제 / **1:2–3:5** — 1:2–9 호세아의 혼인과 세 아이의 출생(심판) / 1:10–2:1 구원 예언(구원) / 2:2–13 신실하지 못한 이스라엘(심판) / 2:14–23 신실하신 하나님의 사랑, 3:1–5 호세아의 음부 사랑(구원) / **4:1–11:11** — 4:1–3 불신실함과 받을 벌 / 4:4–11 제사장들 심판 / 4:12–19 이스라엘의 음행 / 5:1–7 지도자들 심판 / 5:8–15 심판 예고 / **6:1–6 백성의 경박한 참회와 야훼의 답변** / 6:7–7:2 악행 / 7:3–7 그릇된 왕정 / 7:8–16 그릇된 동맹 정책 / 8:1–14 여러 가지 죄(언약 파기, 왕정, 우상 숭배) / 9:1–6 절기의 기쁨을 못 누릴 / 9:7–9 조롱받고 박해받는 예언자 / 9:10–17 버림받을 / 10:1–15 왕정 멸망 예고 → **11:1–11 하나님의 크신 사랑(구원)** / **11:12–14:8** — 11:12–12:14 조상 야곱처럼 거짓된 에브라임 / 13:1–16 에브라임 심판 예고 → **14:1–8 회개의 권고와 구원의 약속** / 14:9 맺음말.
- 내용: 1–3장 고멜과의 결혼 = 영적 간음, **자녀 이름: 이스르엘(지명), 로루하마(동사), 로암미(명사)** / 4–13장 심판 — **“인애를 원하고 제사를 원하지 아니하며”(6:6)**, 앗수르에 의한 멸망 / 14장 회복 — 새로 심긴 포도나무.
- 핵심: **배신한 백성조차 포기하지 않으시는 사랑의 하나님** / 회개 없는 신앙은 심판, 회개하는 자에겐 회복.
- 주요 구절: 1:2; 1:4; **2:16 “내 남편이라 일컫고 다시는 내 바알이라 일컫지 아니하리라”**; **4:6 “내 백성이 지식이 없으므로 망하는도다”**; 4:15; **6:1–3 “힘써 여호와를 알자”**; **6:6 인애(헤세드) / 하나님을 아는 것(다아트 엘로힘)**; **11:8 “에브라임이여 내가 어찌 너를 놓겠느냐” — 아드마·스보임은 소돔·고모라 같은 심판을 받은 성(신 29:23)**; 14:3.

### 요엘
- 이름: **“여호와(야훼)가 하나님이시다”** / 선포 대상 **남유다(또는 귀환 후 유다)** / 활동 **주전 9–5세기로 추정 — 유력: 주전 5세기, 유다의 멸망을 옛 사건으로 암시** / 주요 개념: 여호와의 날(재앙과 심판의 날, 구원의 날), 메뚜기 재앙.
  - ⚠ **[욜](구약 자료, 2024)은 전기설 BC 812–796(요아스 시대)을 결론으로 제시** → 자료 간 충돌. 사용자 원칙(최신 우선)에 따라 **기본값은 ★[소개관]의 “후기(5세기) 유력”**이되, 주석에서는 두 견해를 병기 권장. `29_요엘.md`, `자료간_차이.md`.
- **구조**: 1:1 표제 / **1:2–2:17 재난 상황** — [현재] 1:2–4 이미 닥친 메뚜기 재난, 1:5–14 애곡과 금식 권고, 1:15–18 탄식(15: **여호와의 날**), 1:19–20 기도 / [장래] 2:1–11 **여호와의 날** 재난 묘사, 2:12–14 회개 권고, 2:15–16 금식·애곡 권고, 2:17 기도 권고 / **2:18–3:17 구원의 말씀** — 2:18 백성을 향한 사랑의 심정, 2:19–27 구원을 약속하는 응답(27 “내가 … 너희가 알 것이라”), 2:28–32 영을 부어주신다는 약속, **여호와의 날(31) 전의 징조와 구원**, 3:1–17 **여호와의 날(14)의 이방 심판과 이스라엘 구원**(17 “너희가 나는 … 여호와인 줄 알리라”) / 3:18–21 맺음말.
- 핵심: 메뚜기 재앙은 범죄로 인한 심판이자 회개의 기회 / 여호와의 날은 두려움과 구원의 날 / 영의 부으심을 통한 회복.
- 주요 구절: 1:4; 1:15; 2:1; **2:28**; 3:1; 3:20.

- 내용: 금등잔대와 두 감람나무 = 스룹바벨과 여호수아, **성령의 능력** / 금식 문제 — **순종 없는 제의는 무가치** / 9–14장 메시아 예언 — 나귀 탄 겸손한 왕, **배반당하는 목자(은 30세겔)**, 열방 심판과 예루살렘 구원, 모든 나라가 예배.

- 주요 구절: **1:3 “내게로 돌아오라 … 내가 너희에게로 돌아가리라”**; 8:3; 8:9; 8:13; **9:9**; **12:10**.

### 말라기
- 이름: **나의 사자(messenger)** / 선포 대상 예루살렘 / 활동 **주전 5세기경(?)** / 개념: 제사, 제사장, 나의 사자, 여호와의 날, 엘리야 / 인물: **말라기(고유명사인지 일반명사인지 알 수 없음)**.
- **구조 — 여섯 가지 논쟁 (1:2–4:3)** — 각 논쟁: (진술·물음·요구) → (되물음) → (대답) → (주제/동기):

| 논쟁 | 진술 | 되물음 | 대답 | 주제 |
|---|---|---|---|---|
| 1 (1:2–5) | “내가 너희를 사랑하였노라”(2전) | “어떻게 우리를 사랑하셨나이까?”(2후) | 야곱 택하심(2), 에돔 심판(3–4) | 여호와의 사랑에 대한 **이스라엘의 의심** |
| 2 (1:6–2:9) | “제사장들아 … 나를 공경함이 어디 있느냐?”(1:6전) | “어떻게 주의 이름을 멸시하였나이까?”(6후) | 흠 있는 제물(7전, 8–14), 뻔뻔스런 말(7, 12), 심판(2:1–9) | **무성의한 제사, 무성의한 직무(율법 가르침)** |
| 3 (2:10–16) | “우리 열조의 언약을 욕되게 하느냐?”(10), “헌물을 받지 아니하시거늘”(13) | “어찌 됨이니이까?”(14전) | 이방 혼인 심판(11–12), 불성실한 혼인 생활(14–16) | **이방 혼인, 불성실한 혼인 생활** |
| 4 (2:17–3:5) | “너희(낙심한 의인들)가 말로 여호와를 괴로우시게 하였다”(2:17전) | “어떻게 여호와를 괴로우시게 하였나?” | 잘못된 말: “모든 행악자는 여호와의 눈에 선히 보이며…”, “공의의 하나님은 어디 계시냐?”(2:17후) / 심판의 날 예고(3:1–5) | 행악자들에 대한 **하나님의 조치가 없어 보임** |
| 5 (3:6–12) | “내게로 돌아오라”(6–7전) / “사람이 어떻게 하나님의 것을 도적질하겠느냐?”(8전) | “어떻게 하여야 돌아가리이까?”(7후) / “어떻게 주의 것을 도적질하였나이까?”(8전) | “십일조와 헌물이라”(8후), 조건부 약속(10) | **실천적 회개, 십일조와 헌물** |
| 6 (3:13–4:3) | “너희(낙심한 의인들)가 완악한 말로 나를 대적하였다”(3:13전) | “무슨 말로 주를 대적하였나이까?”(13후) | 잘못된 말: “하나님 섬기는 것이 헛되고 교만한 자가 복되다…”(14–15), 심판의 날 예고(3:17–4:3) | **악인의 번영과 의인의 불행** / “나의 정한 날”(3:17; 4:3) |

- **4:4–6 맺음말**: 모세의 율법을 기억하라(4) / “여호와의 크고 두려운 날”이 이르기 전에 **엘리야를 보내리라(왕상 19; 마 17:10–13)** / 아비와 자식 사이에 서로 마음을 돌이키게.
- ([말]은 4단 구조 + 10개 항변 목록 / [소개관]은 **6개 논쟁** — 같은 현상을 달리 묶음. 6논쟁 표가 더 정밀하므로 주석 틀로 적합 — 판단)
- 주요 구절: 1:6; 2:17; **3:10**; **4:2**; 4:5–6.
