## 시편의 특징·자리 ★[시25]
1. **시로 된 노래책** — 시편(詩篇): 시로 된 책, 시의 묶음(죽간, 편) / **테힐림(תהילים): 찬양, 찬양집**.
2. **인간 감정의 총체적 표현** — 논리적 연관성 / **정서적 연관성(솔직한 감정)**.
3. **예배에 사용됨** — 성전 예배와 묵상.
4. 역사와 믿음이 담겨 있음.
5. **하나님에 대한 바른 정보를 제공**.
- **주신 말씀 vs 드려진 말씀** — “드려진 말씀이 주신 말씀이 되는 까닭? → **확증된 진리, 말씀을 살아내는 과정에 대한 기록**.”
- 자리: 기독교 구약 순서(모세오경–역사서–시가서–선지서) vs 유대교 **타나크**(토라–네비임–케투빔; 눅 24:44 “모세의 율법과 선지자의 글과 시편”). 성문서 = 지혜서(시편·잠언·욥기) / 오축(아가·룻기·애가·전도서·에스더) / 인물(다니엘·에스라·느헤미야) / 역사 정리(역대기). (`27_다니엘.md`와 같은 틀)

## 1. 히브리 시의 특징 [시][시25]
- **1753년 이전에는 히브리 시를 알지 못함** → 성경이 산문으로만 여겨짐. 1753년 발견 — **운율이 아닌 대구(평행)법**. RSV가 처음으로 시를 시답게 번역 [시].
- [시] 66권 중 **레위기·룻기·에스더·학개·말라기 5권을 제외한 61권에 시가 포함**. ★[시25] “신구약 성경의 2/3 이상”.
- ★[시25] **은유(metaphor)** = meta(초월) + pherein(운반하다) → **“사실을 뛰어넘어 느낌으로”** — 시 23: 하나님이라는 “사실”을 목자라는 “느낌”으로. / 형식: 답관체(아크로스틱).

### 6개의 대구법 (Parallelism)
1. **동의적 대구법**: 첫 절의 내용이 둘째 절에서 다른 말로 — 시 6:1; 8:4; 15:1; 19:1; ★27:1.
2. **대조적(반의) 대구법**: 반대로 표현 — 잠 10:1; 13:1; 15:1; 사 1:3 [시] / ★시 1:6; 37:9 [시25] (★“잠 5:11 유순한 대답…”은 잠 15:1의 오기로 보임).
3. **종합적 대구법**: 둘째 절이 첫 절을 발전·완성(보충·확장·결과·이유) — **“뜻의 발전”** — 시 1:2; 34:2; 37:4; 37:34.
4. **상징적 대구법**: 한 절이 직유/은유 — 첫 행에 이미지, 둘째 행에서 실제 의미 — 시 42:1; 103:12; 103:13; 125:2.
5. **점층적(상승) 대구법**: 반복·확장하며 절정 — [시] 빌 2:6–11; 엡 1:20–21 / ★[시25] **시 29:1–2; 24:7–10**.
6. **교차 대구법(Chiastic)**: **사 6:10** — A 마음을 둔하게 / B 귀가 막히고 / C 눈이 감기게 // C′ 눈으로 보고 / B′ 귀로 듣고 / A′ 마음으로 깨닫고. (`23_이사야.md` 소명과 연결)

### 시적 표현
- **후렴**: 시 107:6, 13, 19(“여호와께 부르짖으매 … 건지시고”) / **시 136 — 26절에 26번 “그 인자하심이 영원함이로다”** / ★시 67:3, 5.
- **수미쌍관(Inclusio)**: 시 8 “여호와 우리 주여 주의 이름이 온 땅에 어찌 그리 아름다운지요” / 시 103, 104 “내 영혼아 여호와를 송축하라” / 시 118 “여호와께 감사하라 …”.

## 2. 저자 — 누구의 시인가?
- ★[시25] **표제어**: 150편 중 **116편이 표제**를 가짐 — 저자 / 배경 상황 / 음악적 성격. **116개 중 73개가 “다윗의 시”(미즈모르 레다비드)**. 표제 인물: 모세, 솔로몬, 아삽, 고라 자손, 헤만, 에단 → **“다윗의 시편” = “다윗의 삶, 그의 길”**.
  - 다윗의 이정표: **대상 6:31–32** 다윗이 성전 찬송 직분을 맡김(에단–헤만–아삽) / **암 9:11 “다윗의 무너진 장막”**.

### 주제/양식(문학 장르)에 따른 7분류
- 큰 두 부분: **찬양/감사 vs 탄식/탄원** → 세부 7: **찬양시, 감사시, 탄원시(신뢰시), 제왕시, 시온시, 예배 의식시, 지혜시**.
- ★[시25] 시를 이해하는 접근 — **내용 = 시를 느끼는 것(시의 생김새) / 형식 = 시를 생각하는 것(시의 쓰임새)**, 균형이 필요. 형식(유형)은 **시어를 담는 그릇**.

1. **찬양시 (테힐라)**: 하나님의 창조·구원·주권·은혜를 찬양 — 8, 19(:1–6), 29, 33, 47, 65, 66, 78, 93, 95–100, 103–106, 111, 113–114, 117, 134–136, 145–150.
   - 짜임새: ① **찬양하라는 요청(부름)** — 대상·방법·태도 (대다수는 명령형 복수 — 회중적; 할렐루야로 시작: 111–113, 117, 135, 146–150; 부름 없이 바로 내용: 8, 19, 65, 67, 114, 145; 구체적 대상: 33, 100, 103, 104, 146–148) ② **찬양해야 할 이유** — 하나님의 주권, 하신 일, 성품(돌보시는 은혜 113; 능력·통치 8, 19, 104, 148) ③ **결론** — 부름의 반복(103, 104, 113, 135, 146–150), 소원(19, 33), 확신(8, 100, 111).
   - 찬양의 방법 [시]: 음성(입, 큰 소리, 노래, 잠잠히, 방언) / 손(손뼉, 손을 들고, 악기) / 몸(서서, 무릎 꿇고, 엎드려, 춤추며).
   - ★쓰임새: 성소·예배·절기 / 찬양시 양식의 다른 시 — **시온 시편** 46, 48, 76, 84, 87, 122 / **제왕 즉위 시편** 24, 29, 47, 93, 95–99 — “원독자들에게 주는 의미는?”
2. **감사시 (토다)**: 찬양시가 회중적인 데 반해 **개인적 성격** (공동체 감사: 67, 75, 107, 124). 내용: 구원/구출, 용서, 치유, 적으로부터의 보호.
   - ★짜임새: 감사의 선언 → 과거의 고난 서술 → 구원의 간구와 응답 → 구원에 대한 찬양 → 감사의 확증.
3. **탄원시/신뢰시 (테필라)**: 공동체 탄원(12, 44, 60, 74, 80, 83, 85, 90, 94) — 나라의 위기 / 개인 탄원(3–7, 9–10, 13, 17, 22, 25–26, 28, 31, 35, 38, 40, 42–43, 51, 54–59, 61, 64, 69–71, 77, 86, 88, 102, 109, 120, 130, 140–143).
   - 형식: **부름(“하나님이여~”, 현재형) → 불평/호소/고소(“어찌하여?”, “언제까지입니까?” — 죄책감·질병·믿음·원수) → 도움 요청 → 신뢰의 확신(과거 하나님의 행하심 회상) → 찬양(의 다짐/위탁)**.

- **교차 구조**: A 73 아삽 — 개인의 신앙 위기 “**악인이 형통함을 보고 시기하였나이다**”(73:3) / B 74–79 성소 파괴, 공동체 절망 “주의 성소가 불타나이다”(74:3/7) / **C 80–83 회복 간구 “주의 얼굴을 비추사 우리가 구원을 얻으리이다”(80:3)** / B′ 84–87 시온을 사모, 회복 찬양 “주의 장막이 어찌 그리 사랑스러운지요”(84:1–2) / A′ 89 에단 — **왕권의 붕괴 속 신앙의 질문 “주의 기름 부으신 자를 … 버리셨나이까”(89:38)**.
- [시1-3] 세부: 74:12–23 “기억하소서” / 75–76 하나님을 향한 고백 / **77–78 “기억하겠습니다” — 실로 성막의 실패** / 79 성전의 파괴 / **80 “빛을 비추소서” 4번 반복** / 81 출애굽 세대의 심판 / 82 우상(신들)의 심판 / 83 “침묵하지 마소서” / 84 주의 집에 사는 자의 복, **“마음에 시온의 대로가 있는 사람”**(84:5), 하나님의 성전 문지기(고라 자손) / 85 “시간에 주의해서 읽자 — 진노가 풀리심?” / 86 다윗의 기도 / 87 성전의 회복? / **88 병의 노래 — 솔직한 심정** / 89 에단.

### 제4권 (90–106편) — 여호와께서 다스리신다 ★[시25]
- **왕국·땅·성전이 없던 시대에 하나님과 동행했던 사람들의 이야기**: 90편 “사람 모세의 기도” ↔ 106편 모세 이야기 / 등장인물: 아브라함(105:6, 9, 42), 이삭(105:9), 야곱(94:7; 105:6, 10), 요셉(105:17), 아론(99:6; 105:26; 106:16), 비느하스(106:30), 사무엘(99:6).
- **교차 구조**: A 90 모세 — 인간의 유한성과 하나님의 은총 / B 91–95 피난처가 되신 하나님, 예배받으실 왕 / **C 96–100 하나님의 통치의 선포 — 그가 임하실 것** / B′ 101–105 언약 백성의 기도 / A′ 106 모세 이야기 — 백성의 불순종과 하나님의 자비.
- 91 하나님이 피난처 / 92 찬양·감사·예배 / 93–100 하나님을 인생의 왕으로 모시고 걸어감 / **90:2; 103:17 주님의 사랑이 영원에서 영원까지** / **“주님이 다스리신다!!!”(93:1; 96:10; 97:1; 99:1)**.
- **104–106 창조 ~ 포로귀환까지의 역사**: 104 (창조)–홍수–노아 / 105 아브라함–이삭–야곱–요셉–출애굽 / 106 광야–브올의 바알–비느하스–므리바–약속의 땅–포로–귀환.
