# 잠언

> 출처: [잠] `구약 자료/34.잠언.pdf` — 10쪽 인쇄(슬라이드 39장), 더바이블미니스트리 **남영남** (원본 추출, 텍스트 완전). 표제 **“여호와를 경외하는 것이 지혜의 근본이요 거룩하신 자를 아는 것이 명철이니라”(9:10)**.

## 1. 히브리 성경에서 잠언의 위치
- **토라** — 넓은 의미: 구약 전체(미쉬나, 탈무드, 미드라쉬) / 좁은 의미: 모세오경 → **“원리”**
- **선지서** — 전기(여호수아, 사사기, 사무엘, 열왕기) / 후기(대선지서 3, 소선지서 12) → **“교육”**
- **성문서** — 지혜서(시편, 욥기, 잠언) / 오축(아가, 룻기, 애가, 전도서, 에스더) / 인물(다니엘, 에스라, 느헤미야) / 역사정리(역대기) → **“적용”**
- (토라=원리, 선지서=교육, 성문서=적용 이라는 기능 구분이 이 강의의 특징)

## 2. 지혜 문학
- **고대 근동의 지혜 문학**: 왕상 4:29–31 솔로몬의 지혜가 동쪽 모든 사람과 이집트의 지혜보다 뛰어남(에단, 헤만, 갈골, 다르다보다 나음).
  - 메소포타미아: 수메르 잠언(여자의 일상, 가족, 선한 사람, 거짓말쟁이, 소송, 왕궁 등) / 아카드어 잠언(왕자에게 주는 조언, 지혜의 권고, 슈루파크 교훈).
  - 이집트: **아멘엠오페의 교훈**(아들에게 주는 교훈) — **잠 22:17–23:11과 비슷**.

## BRI
1. **저자**: ① 솔로몬(1:1; 10:1; 25:1) ② 지혜 있는 자(22:17; 24:23) ③ **아굴**(30:1) ④ **르무엘 왕**(31:1) ⑤ **히스기야 신하들의 편집**(25:1).
2. **기록 연대**: ① 솔로몬 통치 중(BC 970–931) ② 히스기야 통치 중(BC 728–686, 25:1) ③ 포로기 이후 (최종 편집).
3. **독자**: 솔로몬 통치 시기 / 히스기야 신하들의 편집 시기.
4. **중심 내용**: **지혜와 훈계를 사랑하며 하나님을 경외하는 것이 지혜의 근본이요 목적이다.**
5. **쓰여진 이유**: ① 하나님을 경외함이 지혜의 근본임을 알게 하여 경외하는 삶을 살도록 ② **일상에서** 어떻게 지혜의 삶을 살아야 하는지 구체적으로 교훈.
6. **구조**:
   - 1:1–7 서론
   - 1:8–9장 솔로몬의 잠언 1
   - 10:1–22:16 솔로몬의 잠언 2
   - 22:17–24:22 지혜 있는 자의 말씀 1
   - 24:23–34 지혜로운 자들의 말씀 2
   - 25–29장 솔로몬의 잠언 3 (히스기야의 신하들이 편집)
   - 30장 아굴의 잠언
   - 31장 르무엘 왕의 잠언
7. **잠언의 양식**:
   1. 훈계/가르침 (1–9장; 22:17–24:34)
   2. 잠언/격언 (10–31장의 짧은 격언) — 10:19; 16:13; 10:1
   3. **답관체** (31:10–31)
   4. **숫자 격언** (6:16–19; 30:15–31) — 30:21 “세상을 진동시키며 … 서넛이 있나니”
   5. 축복 (3:13; 8:34; 28:14)

## 본문

### 1장 서론
1. “다윗의 아들 이스라엘 왕 솔로몬”(1).
2. **잠언 = 마샬** — “비슷하다, 닮다, 비교하다” → 쓰임: 예언(민 23:7 발람) / 속담(신 28:37) / 이야깃거리(시 44:14) / 풍자(욥 27:1; 29:1) / 비유(시 49:4).
3. **잠언의 목적(1:2–6)**: 지혜와 훈계를 알게, 명철의 말씀을 깨닫게(2) / 지혜롭게·공의롭게·정의롭게·정직하게 행할 일에 훈계를 받게(3) / 어리석은 자를 슬기롭게, 젊은 자에게 지식과 근신함을(4) / 지혜 있는 자는 학식이 더하고 명철한 자는 지략을 얻음(5).
4. **어리석은 자·젊은 자(4)**: 어리석은 — **페티**: 단순한, 순진한, **마음이 열린**(잠언에서 순진한 사람) / 젊은 자 — **나아르**: 아이, 소년, 젊은이, 종 — **유아와 혼기 사이의 청소년**.
5. **여호와를 경외하는 것(1:7)** — 반복 구절: 1:7 지식의 근본 / **9:10 지혜의 근본** / 8:13 악을 미워하는 것 / 15:33 지혜의 훈계, 겸손은 존귀의 길잡이 / 19:23 생명에 이르게 함.
   - **경외함의 결과**: 완전한 지혜, 행실이 온전한 자의 방패(2:7) / 공의·정의·정직(2:9; 14:2) / 장수(10:27) / 자녀들의 피난처(14:26) / 사망의 그물에서 벗어남(14:27) / 악에서 떠남(16:6) / 생명·족함·재앙을 당하지 않음(19:23) / **재물과 영광과 생명(22:4)** / 장래와 소망(23:17) / 칭찬(31:30).
   - (1:7 “경외” — 책 서론 / 31:30 “여호와를 경외하는 여자” — 책 결론 → 수미상관 — 해석)

### 잠언에서 말하는 지혜
- ① 하나님을 경외하는 것에서 시작(1:7; 9:10) ② 지혜를 구하고 찾다 보면 여호와 경외하기를 깨닫고 하나님을 알게 됨(2:1–5) ③ **지혜를 주시는 분은 여호와**(2:6–7) ④ **지혜 = “하나님의 뜻을 알고 그 뜻대로 올바르게 행하는 것”**(1:3; 2:7–9, 20–21; 3:7; 8:13; 11:1, 4; 16:6) ⑤ “지혜로운 사람” = 하나님의 뜻을 알고 그대로 올바로 행하는 사람 = **“정직한 사람”** ⑥ **“지혜자” = “의인”**과 같은 말 ⑦ **“지식” = 하나님(의 규범)을 아는 것 = “지혜”와 동의어**(1:7; 9:10; 2:2–5).
- **지혜에 이르는 길**: ① **경험** — 아들을 가르치는 아버지(1–9장) ② **관찰** — 개미(6:6–11), 지혜 없는 자의 행위(7:6–27), 사람들의 상황을 예리하게 읽음(22:10, 26–27; 26:15) ③ **전통에 근거한 교훈** — 아버지가 가르쳐 준 것(4:3–4), 아버지의 관찰(7장), 서른 가지 격언은 아버지에서 아들로 이어진 전통(22:17–21) ④ **실수로부터 배움**(12:1; 10:17; 8:13; 3:34; 11:2; 15:33; 16:18) ⑤ **여호와를 경외하는 것(계시)**(1:7; 2:6–8; 9:10) — **여호와의 주권을 인정하는 것**(3:6–7; 16:1–3, 9, 33; 19:21; 20:12, 24; 21:30–31; 29:26).

### 지혜의 의인화
- **1:20–33**: 지혜가 외치는 장소(20–21) / 부름 받는 대상(22) / 외치는 이유(23–25) / 부름을 외면한 대가(26–28).
- **8:1–31**: 외치는 장소(1–3) / 대상(4–5) / 이유(6–9) / 지혜의 가치(10–21) / 지혜가 있는 곳(12) / **지혜의 시작(22–31 — 창조 이전부터)** / 지혜를 만나는 방법(18, 20, 33).

### 30장 아굴의 잠언
1. “야게의 아들 아굴의 잠언” — 잠언 = **맛사**: 경고, 짐, 선포, 신탁 / 또는 **지명: 북 아라비아의 한 민족·부족 명칭**.
2. 자신의 부족함을 고백(2–5).
3. **두 가지 간구(7–9)** (헛된 것과 거짓말을 멀리, 가난하게도 부하게도 마옵시고 필요한 양식으로 — 본문 보충).
4. 종에 대해(10).
5. **네 무리(11–14)**: 아비를 저주하고 어미를 축복하지 않음 / 스스로 깨끗하다 하나 더러움을 씻지 않음 / 눈이 높음 / 앞니는 장검, 어금니는 군도 — 가난한 자를 삼킴.
6. **족한 줄 모르는 네 가지(15–16)**: 스올 / 아이 배지 못하는 태 / 물로 채울 수 없는 땅 / 족하다 하지 않는 불.
7. **기이히 여기고도 깨닫지 못하는 네 가지(18–20)**: 공중의 독수리 자취 / 반석 위 뱀의 자취 / 바다의 배의 자취 / 남자가 여자와 함께한 자취 + ⑤ 음녀의 자취.
8. **세상을 진동시키는 네 가지(21–23)**: 종이 임금 됨 / 미련한 자가 배부름 / 미움받는 여자가 시집감 / 여종이 주모를 이음.
9. **작고도 가장 지혜로운 네 가지(24–28)**: 개미(여름에 준비) / 사반(바위 사이에 집) / 메뚜기(임금 없이 떼를 지어) / 도마뱀(손에 잡힐 만하나 왕궁에 있음).
10. **위풍 있게 다니는 네 가지(29–31)**: 사자 / 사냥개 / 숫염소 / 당할 수 없는 왕.

### 31장 르무엘의 잠언
1. 르무엘 왕 — **그의 어머니가 그를 훈계한 잠언**(1).
2. 반복(2 — “내 아들아” 3번 — 보충).
3. 어머니의 교훈(3–4): 힘을 여자들에게 쓰지 말며 왕들을 멸망시키는 일을 하지 말라 / 포도주와 독주는 주권자에게 마땅하지 않음.
4. **왕의 직무(5–9)** (말 못하는 자와 고독한 자의 송사를 위해 입을 열라 — 보충).
5. **현숙한 아내(10–31) = 왕비의 덕목** — **현숙한 = 하일: 힘, 능력, 부, 재산, 군대, 덕행** / 29 덕행 있는 모든 여자보다 뛰어남 / **30 여호와를 경외하는 여자** / 31 성문에서 칭찬.
