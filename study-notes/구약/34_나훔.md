# 나훔

> 출처: [욘나] `구약 자료/20.요나& 21.나훔.pdf` p50–84 (이미지 렌더링으로 읽음). 표제 **“God's Word to Nineveh / God's Word to Judah”**. 앗수르 개관과 요나서와의 비교는 `32_요나.md`.

## BRI

- **저자**: 본문에서 직접 언급 — “**엘고스 사람 나훔**의 묵시의 글이라”(1:1).
  - 나훔: ① 이름 뜻 **위로자** ② 엘고스 사람 ③ 하나님에 대해 잘 알고 있는 사람 ④ **앗수르의 역사와 통치체제에 대해서 잘 알고 있음** ⑤ 앗수르의 멸망과 유다 민족의 구원을 선포.
- **기록연대**: ① 왕의 이름이 언급되지 않음 ② **니느웨가 멸망하기 전**(멸망 예언 1:1; 2:8, 10; 3:7) ③ **이집트의 노아몬(테베)이 멸망한 사건 언급**(3:8–10) — BC 663 앗술바니팔에 의해 멸망, **BC 654 노아몬 재건축** ④ 앗술바니팔의 통치시기 ⑤ **앗수르가 여전히 강성하여 유다를 억압할 때** 예언이 선포됨(1:12–13; 3:1).
  - 도식: **넓은 연대** = BC 663 노아몬 함락 ~ BC 633 앗술바니팔 사망 / **기록연대 = BC 663 노아몬 함락 ~ BC 654 노아몬 재건** / “** 남유다 **므낫세 왕의 통치시기**”.
  - (해석) 노아몬 재건 이전으로 좁히는 근거는 3:8의 “네가 어찌 노아몬보다 낫겠느냐” — 노아몬이 아직 폐허인 상태여야 비교가 효과적이라는 논리로 보임. 슬라이드에는 근거 문장이 없음.
- **원독자**: ① 니느웨와 그 왕을 향해 진술(1:11, 14; 2:1, 13; 3:5–17, 18, 19) ② **니느웨의 멸망 예언을 유다에게 말하고 있음**(1:12, 13, 15) → **므낫세 왕 통치시기의 유다**.
- **역사적 배경**:
  - 흐름: 아하스 도움요청 → 다메섹 멸망 / (강제이주) 북이스라엘 멸망 / 히스기야 조공거부 → 예루살렘 침공(산헤립).
  - **므낫세 왕의 통치(BC 697–642)**: 히스기야의 통치와 다름 / **친 앗수르 정책: 앗수르에 조공** / 앗수르의 간섭과 지배를 받음.
  - **World Power — 앗수르**: ① 잔인하고 포악함 ② 강력한 힘을 지닌 초대형 제국.
  - 역사적 사건: 697 므낫세 즉위 / 663 앗술바니팔의 노아몬 정복 / 654 노아몬 재건 / 612 니느웨 멸망 / 609 하란 멸망 / 605 갈그미스 전투.
  - **종교·문화적 상황**: 율법 무시, 악을 행함, **히스기야가 제거한 산당을 세움** / 바알 제단을 온 땅과 성전에까지 둠 / 여러 이방신 인정 / 점치고 사술과 요술, 신접한 자와 박수를 신임 / 백성들을 꾀어 악을 행하게 함(우상숭배)(왕하 21:1–9; 대하 33:1–20) / **죄 없는 사람들을 심히 많이 죽임**(왕하 21:16).
- **중심주제**: **하나님은 공의로 열방을 다스리시며 죄를 반드시 심판하신다.**
- **쓰여진 이유**: ① 하나님은 열방을 다스리시는 분 ② 공의의 심판을 하시는 분 ③ **하나님의 백성을 위로하기 원하시는 분**(이름 “위로자”와 연결) ④ 타락한 유다를 돌이키게 하기 위함.

## 1장 심판의 선포

- 1:1 “니느웨에 대한 **경고** 곧 엘고스 사람 나훔의 **묵시**의 **글**이라.”
  - 묵시 — **하존**: “보다, 바라보다”에서 유래, 환상·이상.
  - 글 — **세페르**: 문서, 기록, 책.
- **《샌드위치》 1:2–8**: A 하나님의 성품(1:2–3a) / **B 자연만물을 다스리시는 능력의 하나님(1:3b–6)** / A′ 하나님의 성품(1:7–8).
- **1:3b–6 자연만물을 다스리시는 하나님**: 여호와의 길은 회오리바람과 광풍에 있고 / 구름은 그의 발의 티끌 / 바다와 강을 말리심 / **바산과 갈멜이 쇠하며 레바논의 꽃이 시드는도다** / 산들이 진동하며 작은 산들이 녹고 / 땅 곧 세계와 모든 것들이 솟아오름 / 누가 능히 그의 분노 앞에 서며 누가 능히 그의 진노를 감당하랴 / 그의 진노가 불처럼 쏟아지니 바위들이 깨지는도다.
  - 지명: **갈멜** — 결실 풍요, 아름답기로 유명 / **바산** — 요단 동편 비옥한 땅 / **레바논** — 약속의 땅, 비옥한 땅 → 가장 풍요로운 곳들조차 시든다는 뜻 (해석).
- **1:2 《카이아즘》 하나님의 성품**: “여호와는 질투하시며(A) **보복**하시는(B) 하나님이시니라 / 여호와는 **보복**하시며(B) 진노하시되(A) / 자기를 거스르는 자에게 여호와는 **보복**하시며 / 자기를 대적하는 자에게 진노를 품으시며” — “보복” 3회.
- **하나님의 성품(1:2b–3a)**: 질투, 보복 / **노하기를 더디하심** / 권능이 크심 / 벌받을 자를 결코 내버려두지 않으심. (욘 4:2의 성품 목록과 대비 — `32_요나.md`)
- **《대조》 하나님의 성품 — 자기에게 피하는 자들 vs 자기 대적들**: 여호와는 선하시며 환난 날에 산성이시라, 자기에게 피하는 자들을 아시느니라(1:7) ↔ 거스르는 자에게 보복(1:2) / 대적하는 자에게 진노(1:3) / 벌 받을 자를 내버려두지 않으심(1:3) / 범람하는 물로 진멸하시고 흑암으로 쫓아내심(1:8).
- **《교환》 1:9–15**: A(1:9–11) / B(1:12–13) / A(1:14) / B(1:15) — A = 니느웨를 향한 말씀, B = 유다를 향한 말씀 (슬라이드는 절 범위만 표시; A/B의 내용 지정은 원독자 슬라이드의 절 배정[니느웨 1:11, 14 / 유다 1:12, 13, 15]에 근거한 추정).
- **여호와께 악을 꾀하는 한 사람(1:11)** → **열왕기하 18–19장** (슬라이드는 본문 참조만 제시; 산헤립을 가리키는 것으로 보임 — 해석).
- **“다시는” ×3**: 너를 괴롭히지 아니할 것이라(1:12) / 네 이름이 전파되지 않을 것이라(1:14) / 네 가운데로 통행하지 아니하리로다(1:15).

## 2장 심판의 방법

- **파괴하는 자(2:1)** — 흩뜨리는 자.
- **심판의 이유(2:2)**: **야곱의 영광을 회복(예언적 완료)** / 약탈, 포도나무 가지를 없이 함. (예언적 완료 → `30_아모스.md` 선지서 개론)
- (신바벨로니아 제국 지도, 니느웨 멸망 그림, 니느웨 성곽 평면도·사자 사냥 부조 수록)
- **니느웨 최후의 날(2:3–13) — 과거형/현재형 교차**:

| | 절 | 내용 | 시제 |
|---|---|---|---|
| A | 8a | 부강한 니느웨의 현재 | 과거형 |
| B | 8b | 비참한 니느웨의 심판의 날 | 현재형 |
| A | 9 | 부강한 니느웨의 현재 | 과거형 |
| B | 10 | 비참한 니느웨의 심판의 날 | 현재형 |
| A | 11–12 | 부강한 니느웨의 현재 | 과거형 |
| B | 13 | 비참한 니느웨의 심판의 날 | 현재형 |

- **예언의 시제 해설 도식**: <예언의 시제 — 하나님의 말씀> 과거: 부강한 니느웨 / 현재: 비참한 심판 ↔ <실제 시간 — 유다의 상황> 현재 / 미래. 즉 **실제로는 현재인 니느웨의 부강을 과거형으로, 미래의 심판을 현재형으로** 말함.
  - 비유 도식: <역사를 아는 우리> 과거 “일제 강점기” → 현재 “광복” ↔ <당시의 사람들> 현재 / 미래 — 당시 사람에게 미래인 해방을 이미 온 현재처럼 말하는 것.

## 3장 심판의 이유

- **《화 오라클》 3:1–7 “피의 성이여!”**:
  - 고통(심판)의 이유: 거짓·포악이 가득함(1) / 탈취가 떠나지 아니함(1) / 전쟁으로 많은 사람을 죽임(2–3) / 마술에 능숙한 미모의 음녀가 많은 음행을 함(4) / 음행으로 여러 나라를 미혹(4) / 마술로 여러 족속을 미혹(4).
  - 심판의 결과: 치마를 걷어 올리고 벌거벗은 것을 나라에, 부끄러운 곳을 뭇 민족에 보임(5) / 능욕하여 구경거리가 되게 함(6) / 보는 자가 다 도망(7).
  - **성취: BC 612 바벨론·메대 연합군에 의해 멸망**.
- **노아몬(3:8–10)**: 강들 사이에 있고 바다를 끼고 있는 천혜의 요새 / 강력한 동맹국(구스, 애굽, 붓, 루빔) / 가장 강하고 안전하다고 여겼던 곳.
- **《비교》 노아몬 멸망(3:10) vs 니느웨 멸망(3:11–13)**: 포로가 되어 사로잡혀 감, 아이들이 길모퉁이에서 메어침을 당함, 제비뽑혀 나뉘고 사슬에 결박됨(10) ↔ 피난처 없음(11), 산성은 쉽게 무너짐(12), 용사들이 여인처럼 약함(13), 성문이 쉽게 뚫리고 불에 탐(13).
- **조롱(3:14–15)**: “침공에 대비해 물도 준비하고 성벽을 튼튼하게 하기 위해 벽돌도 준비해봐! 메뚜기나 느치처럼 너희들이 많은 사람들을 동원해서 막아봐!” (강의의 의역)
- **질문(3:19)**: 나훔 “그들이 항상 네게 행패를 당하였음이 아니더냐?” ↔ 요나 “내가 어찌 아끼지 아니하겠느냐?”
