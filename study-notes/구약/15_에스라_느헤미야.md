## 표제

- 에스라: **“하나님의 선한 손의 도움으로 다시 세워지는 성전 & 백성”**
- 느헤미야: **“거룩한 성 예루살렘 & 거룩한 백성”**

## 배경

- BC 931 분열 → 722 북이스라엘 멸망 → 남유다 멸망(느부갓네살): **605 1차(다니엘, 엘리아김=여호야김 때) / 597 2차(여호야긴, 에스겔) / 586 3차(성·성전 파괴) / 582 4차(렘 52장)**.
- 바벨론 왕: **나보폴라살(626–605)** — 626 바벨론 탈취, 614 메대 키악사레스와 동맹, 612 니느웨 정복, 609 1차 갈그미스 전투 / **느부갓네살(605–562)** — 605 2차 갈그미스 전투 승리(vs 애굽).
- 요시야 이후 왕들(대상 3장): 요시야(609 므깃도에서 사망) → ① 여호아하스(살룸, 3개월, 애굽으로) → ② 여호야김(엘리야김, 609–597) → ③ 여호야긴(여고냐, 3개월, 597 2차 포로) → ④ 시드기야(맛다니야, 597–586).
- **포로기 유대인의 생활**(바벨론):
  - 직업: 포로 대다수가 기술자(왕하 24:14–16), 자기 사업 가능.
  - 사회적 지위: **다니엘(총독), 모르드개(총리), 에스더(왕비), 에스라(학사), 느헤미야(술 관원)**. 귀환자들의 헌금 규모가 상당(스 2:68–69). 유대인과 바벨론 가정의 법적 지위가 동등하다는 문서 발견. 요세푸스: “바벨론 포로들은 웬만큼 살았다.”
  - 자유: 이동·집 소유(겔 8:1), 예루살렘과 편지(렘 29:25–32), **성전이 없어 회당 문화 형성**, 희생 제사는 불가.
  - 공동체: 장로 중심(겔 8:1), 가족 공동체 → 귀환자 명단이 족보별로 기록, 언어는 **아람어**.
  - 예루살렘에 남은 자: 상류층·필요 인력은 포로로, 나머지는 비천한 자들로 폐허에(렘 24:5–10; 왕하 24:14; 25:12).
  - **특징: 바벨론에서 안정을 누린 사람들이 폐허 예루살렘으로 삶의 터전을 옮기기는 쉽지 않았다.**
- **“하나님의 주권 아래 있는 페르시아 왕들의 역사”**: 539 바벨론 멸망 → 538 고레스 칙령, 1차 귀환(스 1:1–3), 초막절(3:4) → 536 성전 기초(3:8–13), 방해로 중단(4장) → 530 고레스 사망, 캄비세스 2세(지원 끊김) → 525 애굽 점령 → 522 캄비세스 자살, 스멜디스(가우마타) → 522 **다리오** 즉위, 반란 → **520 학개·스가랴의 격려로 재개**(5:1–2) → **516 완공**, 봉헌식·유월절·무교절(6:13–22) → 486 아하수에로 → **478 에스더 왕비**(에 2:12–16) → 464 아닥사스다 1세 → 460 애굽 반란(그리스 지원) → **458 2차 귀환 에스라**(아닥사스다 7년, 스 7:6–9; 유다까지 반란이 번지는 것을 막으려는 정책, 7:14, 25) → 454 메가비주스가 애굽 반란 진압 → 449 메가비주스의 반란 → **444 3차 귀환 느헤미야**(아닥사스다 20년, 느 2장) → **432 느헤미야가 바벨론에 다녀옴**(느 13:6).

## BRI

- **저자: 에스라** — ① 7:27–9:15의 **1인칭** ② 2차 귀환(7–8장)의 자세한 정황 ③ **대하 36:22–23 = 스 1:1–2** ④ 느 11장·대상 9장 예루살렘 거주자 명단.
- **한 권인가, 두 권인가?** — 한 권으로 봄. 근거(외증): 요세푸스·탈무드 / 히브리어 성경 / 70인역 최고 사본 / **마소라 주기(注記)가 에스라 끝에는 없고 느헤미야 끝에만 있음** / 15세기까지 모든 히브리 사본. 분리: 오리겐(185–253)이 에스라 1·2서로 → 제롬의 불가타 → **1448년** 히브리 사본에 영향.
- **에스라–느헤미야 병행 구조**:

| | 에스라 | 느헤미야 |
|---|---|---|
| 역사 | 1장 고레스 칙령에 의한 귀환 | 1장 동족의 비극을 듣고 기도 |
| 포로 귀환 | 2장 1차 귀환(스룹바벨, 예수아) | 2장 3차 귀환(느헤미야) |
| 외부 재건 | 3–6장 대적의 방해 가운데 **성전** 건축 | 3–6장 대적의 방해 가운데 **성벽** 건축 |
| 포로 귀환 | 7–8장 2차 귀환(에스라) | 7장 1차 귀환 명단 |
| 백성 개혁 | 9–10장 에스라의 개혁(**미해결**) | 8–13장 느헤미야의 개혁(**미해결**) |

  - 또 다른 틀: A 스룹바벨의 귀환(스 1–2) / B 사역(3–6) / A 에스라의 귀환(7–8) / B 사역(9–10) / A 느헤미야의 귀환(느 1–2) / B 사역(3–7) / B′ 마지막 개혁과 명단(8–13).
- **반복구: “하나님의 선한 손의 도움”** — 스 7:6(“하나님 여호와의 도우심”), 7:9, 7:28, 8:18, 8:22, 8:31 / 느 2:8, 2:18. 뜻: 하나님의 은혜로운 간섭과 인도. **‘손’ = 능력, ‘도우신 일’ = 생활 속에 결과로 나타난 하나님의 역사.**
- **비슷한 사건을 연대와 상관없이 모아 기록**: 스 4장(520 다리오 때 성전 방해 + 465–458 아닥사스다 때 성벽 방해) / 느 5장(444 성벽 건축 중 생활고 + 432까지 12년간 총독의 녹을 받지 않음).
- **기록 연대**: 느 13:6(아닥사스다 32년) → **BC 432 이후**.
- **수신자**: 3차 귀환자와, 1·2차 귀환해 정착한 세대.
- **귀환자들의 생활**: 1차 귀환자 — 공사 중단, 가난·낙심·무기력(학 1:2), 성전보다 자기 집(학 1:1–4), 흉작(학 1:9–11; 2:15–17), **성전은 봉헌했으나 솔로몬 성전 같은 영광은 없음**(스 6:14–22) / **예배가 무너짐** — 안식일에 장사(느 13:15–22), 십일조를 안 내 레위인이 직무를 떠남(13:10) / **삶이 무너짐** — 저당·노예화(느 5:1–5), **이방인과의 통혼**(스 9–10; 느 13:23–27).
- **에스라 중심 내용**: **언약의 신실함으로 회복되는 성전과 백성들.** 쓰인 이유: ① 역사를 주관하시는 하나님의 **선하신 손**에 독자들이 있음을 깨닫게 ② 귀환자를 하나님 중심의 거룩한 사람으로 가르치고 온전케(율법, 성전 중심, 하나님 백성의 정체성 회복).
- **느헤미야 중심 내용**: 하나님의 선하신 손의 도움으로 성벽을 중건하고, 에스라–느헤미야를 통해 백성을 회복(종교개혁, 부흥운동). 쓰인 이유: 일반 역사를 주관하며 독자를 인도하시는 분이 이스라엘의 하나님임을 / **정체성을 분별하지 못하는 독자에게 언약 백성임을** / 이방 풍습이 아닌 거룩한 백성으로 / 성전 중심·율법을 지키는 삶으로.

## 에스라

- 구조: **스룹바벨 사역 — 거룩한 성전 재건**(1–6장) / **에스라 사역 — 거룩한 백성 재건**(7–10장).
  - 연대: 538 귀환(1–2장) / 536 시작·중단 → 520 재개 → **516년 12월 3일 완공**(3–6장) / 458년 1월 1일–5월 1일 2차 귀환(7–8장) / 458년 10월 1일–457년 1월 1일 통혼 명단 작성(9–10장).
- **1장 “고레스의 마음을 감동시키시매”**: 히브리 직역 — 1:1 “여호와께서 파라스 왕 코레쉬의 **영을 일깨우셔서**”, 1:5 “하나님께서 그 모두의 영을 일깨우셔서”. 감동시키다 = **우르(5782)**: 깨다, 분발하다, 일으키다, 각성하다.
  - 병행: A 하나님이 감동시킴(1 고레스 / 5 유다·베냐민 족장, 제사장, 레위인 / 7 고레스) — B 성전을 건축하라(2–3 / 5) — C 예물(4 기쁘게 / 6 기쁘게 / 7–11 고레스가 성전 기물을 내어 줌).
- **세스바살은 누구?** — 스룹바벨과 동일 인물로 보는 시도: 스룹바벨은 부친(스알디엘) 언급(스 3:2, 8; 5:2; 학 1:1, 12, 14; 2:2, 23), 세스바살은 없음 / **스룹바벨 = 히브리 이름 “바벨론에서 심겨진 씨”, 세스바살 = 바벨론 이름(샤마쉬-아바-우르츠, “샤마쉬여 부친을 보호하소서”)** / 요세푸스도 동일 인물로 봄. (대상 3장 계보: 여호야긴 → 스알디엘·말기람·브다야·세낫살… → 스룹바벨)
- **2장 1차 귀환자**: 가족 계보대로 / 거주 현황대로 / 제사장·성전 봉사자. 온 회중 42,360명(총 49,897명, 약 5만).
- **레위인(제사장)의 역할 9가지**: ① 거룩과 속됨, 부정과 정결을 분별(레 10:10; 11; 13–14장) ② **규례를 가르침**(레 10:11; 스 8:7–8; 대하 17:7–9) ③ 제사(레 10:17; 16:15–16) ④ 재판(신 17:8–13; 19:17; 21:5; 대상 23:4) ⑤ 여호와의 이름으로 축복(신 21:5; 민 6:26–27) ⑥ 성전 일(대상 23:4; 민 18:3–5) ⑦ 관원·서기관 ⑧ 문지기 ⑨ 찬양.
  - (→ 사사기–사무엘 병행 자료의 “레위인의 역할을 상고하라”와 연결 `07_사사기.md`)
- **느디님 사람들**: 레위인의 종(스 8:20) / 미디안 자손(민 31장) / **기브온 자손(수 9:23)** / 쫓아내지 못한 민족들 / 솔로몬이 노예로 삼은 이방인(왕상 9:20–21) / 늘 제사장·레위인·노래하는 자·문지기와 함께 기록됨.
- **3장**: 일곱째 달 절기(1일 나팔절, 10일 대속죄일, 15–21일 초막절, 22일 성회). **스룹바벨 = 스알디엘의 아들(왕의 계보, 대상 3장) / 예수아 = 여호사닥의 아들 여호수아(대제사장 계보, 대상 6장; 학 1–2장; 슥 6:11)** — 왕과 제사장의 짝.
- **3–6장 병행** (초막절로 시작 3:1–7 / 유월절로 끝 6:19–22):

| | 중단 | 완공 |
|---|---|---|

| B 대적의 질문 | 4:1b–2 | 5:3 |

| D 대적의 반응 | 백성을 낙담케 함(4:4–6) | 능히 막지 못함(5:5b) |

- **4장 연대 문제**: 원독자 기준 BC 432. 4:5 고레스~다리오(539–522) / 4:6 **아하수에로 즉위(486)** / 4:7–23 **아닥사스다 — 성벽 반대(465–444, 느헤미야 이전)** / 4:24 다리오(520).
- 레위 찬양대 계보(대상 6:33–47): 그핫–이스할–고라 계열 **헤만**(중앙) / 게르손–시므이 계열 **아삽**(헤만의 오른쪽) / 므라리–무시–말리 계열 **에단**(왼쪽) — “다윗의 규례대로?”
- **스룹바벨 성전의 의미 — 옛 언약 vs 새 언약**: 언약의 문서(십계명 / “나의 법” 렘 31:33; 히 8:10) · 기록(돌판 / 마음과 생각) · 보관(언약궤 / **그들의 속 — 사람이 언약궤**).
- **7장 에스라**: 아론의 16대손(1–5; 대상 6장과 비교) / 모세의 율법에 익숙한 학자(6) / 하나님의 도우심으로 왕에게 구하는 것을 다 받음(6, 27) / **율법을 연구하고, 준행하며, 가르치기로 결심**(10) / 하나님의 율법에 완전한 자(12).
  - **학자(서기관)**: 페르시아의 고위 관리, 법에 유능한 자, 여러 언어를 읽고 문서화하는 훈련된 자 + 모세의 율법에 익숙한 자. 포로기 이후 서기관의 업무: 포로민을 가르치고 신앙 지도 → **율법 교사·해석자**로 전문화, 성경 필사·문서 수집.
  - 7장 교차: A 선한 손의 도움으로 특혜를 받고 올라옴(6–9) / B 율법을 가르치기로 결심(10) / C1·C2 아닥사스다의 조서 — 에스라와 창고지기들에게 특혜(11–20; 21–24) / B′ 율법을 모르는 자들을 가르치라(25–26) / A′ 선한 손의 도움(27–28).
- **8장 하나님의 선한 손의 도우심** (3중 반복: 문제 → 에스라의 계책 → 하나님의 도우심): 레위인이 없음(15 → 16–17 → 18–20 찾음) / 길의 안전(21 → 22 **금식하며 기도**, 왕에게 군대를 청하기 부끄러워함 → 23 응낙하심) / 성전 그릇 운반(24–27 → 28–30 → 31–36 대적과 매복자의 손에서 건지심).
- **9–10장 백성 재건 — 이방 여인과의 통혼**:
  - “가증한 일”(9:1) = **토에바(8441)**: 혐오·증오·가증스러운 것.
  - **모든 이방 여인과의 결혼 금지?** 원래 금지 대상은 **가나안 족속**(출 34:11–16; 신 7:1–4; 수 23:12–13) — 이유: 아들을 유혹해 다른 신을 섬기게 함. 에스라는 **암몬·모압·애굽**을 추가. 좋은 예: 요셉·모세·라합·룻 / 나쁜 예: 솔로몬·아합·여호람(아달랴).
  - 9장 철저한 회개: 속옷과 겉옷을 찢고 머리털과 수염을 뜯음.
  - **9장 에스라의 기도 — 교환 구조**: A 이스라엘의 죄(6–7) / B 하나님의 은혜(8–9) / A(10–12) / B(13) / A(14) / B(15) → **하나님의 선하심 강조**.
  - 10장 병행: 모임(1 / 9월 20일 9) → 범죄 고백 → 내쫓겠음 → 백성의 고백 → 순종 / 반대(15) → 3개월 조사 → 명단(18–44). 결론: **미해결**로 끝남.

## 느헤미야

- 구조 (A 성벽 재건·거룩한 예루살렘 / B 백성 재건·거룩한 공동체의 교차):
  - 1–2 느헤미야 귀환(445년 9월) / 3 성벽 재건자 명단 / 4–6 대·내외 문제, **52일 만에 완공(444년 5월 4일–6월 25일)** / 7 1차 귀환 명단 / 8–10 언약 체결(7월 1일 나팔절, 15–21 초막절, 22 성회) / 11 예루살렘 거주자 명단 / 12–13 제사장·레위인 명단, 성벽과 백성의 정결(432년).
- **1장**: 아닥사스다 20년 **기슬르월**(445년 9월 = 현대 11–12월), **수산 궁**(페르시아 왕의 겨울 관저). 2–3절 “허물어진 성벽”은 언제? — 586년? 아니면 **스 4:7–23의 성곽 공사 중단**?
  - **1:8–10 언약에 근거한 기도**: “범죄하면 흩으리라”(레 26:27, 33; 신 28:15, 64; 4:25–27) / “돌아오면 모으리라”(레 26:39–42; 신 4:29–31; 30:2–3). (→ 레 26장 `03_레위기.md`)
  - **술 관원**(1:11): 왕의 술을 책임지는, 각별한 신임을 받는 관리.
- **2장 아닥사스다가 마음을 바꾼 이유?** — 스 4:7–23에서는 성벽 반대(465–458) → 20년 사이 변심. 배경: 460 애굽 반란 → 455 진압(강 서편 총독 메가비주스) → **449 메가비주스가 시리아에서 반란** → 444 느헤미야 파견(서쪽 변경의 안정을 위한 정책으로 읽힘 — 해석).
  - 2:8b–3장 병행: A 선한 손(2:8a–9 / 2:18) — B 대적의 근심(2:10) / 조롱(2:19) — C 느헤미야의 행동(2:11–16 / 2:20) — D 건축 독려(2:17) / 건축(3장).
- **3장 성벽 “성별”**: 3:1 대제사장 엘리아십이 양문을 건축하여 **성별(카다쉬 6942: 거룩하다, 성별하다, 봉헌하다)**.
- **4장 대적의 방해** (3회 반복: 방해 → 느헤미야의 행동 → 결과·전략): 산발랏·도비야(1–3 / 4–5 / 6) / (7–8 / 9a / 9b) / 내부 영향(10–12 / 13–14 / 15–23).
- **5장 내부의 어려움**: 양식 없음 / 흉년으로 저당 / 왕의 세금을 위해 빚 / **동족을 종으로 팖** / 귀족과 민장의 고리대(7).
  - **이자 규례**: 동족에게 이자 금지(출 22:25; 레 25:35–37; 신 23:19; 15:1–11), 이방인에게는 허용(신 23:19–20). 땅(레 25:23–28)·가옥(29–34)·가난한 동족 종(39–43)·종(44–55) 규례.
  - “옷자락을 털며”(13) = 모든 부정을 털어 버리는 상징 → “빈털터리가 되다, 망하게 되다”.
  - **총독의 녹(레헴 3899 = 음식, 빵)**: 느헤미야는 444–432년 12년간 받지 않음. <전환> 이전 총독들 ↔ **“나는 하나님을 경외하므로 이같이 행하지 아니하고”**(15) ↔ 느헤미야.
- **6장** (<진전> <샌드위치> <병행>): A1 외부 — 산발랏·게셈(1–9: 방해 → 대처 → 두렵게 하려 함 → 기도) / A2 내부 협력 — 도비야·산발랏이 **선지자 스마야·노아댜**를 매수(10–14: 같은 4단계) / B **엘룰월 25일 완공**(15–16) — 모든 대적이 두려워 낙담, **하나님께서 이루신 것을 앎** / A3 **내부 완전 결탁** — 귀족들과 도비야 가문의 혼인 동맹(17–19). 3:30 성벽을 쌓은 **므술람**의 딸이 도비야의 아들 여호하난과 결혼(6:18).
- **7장**: 문지기·노래하는 자·레위 사람을 세운 이유?(3:1 참고) / 하나님이 느헤미야의 마음을 감동케 하셔서 **1차 귀환자 계보** 등록.

- **9장 회개와 역사 회고** (굵은 베, 티끌):
