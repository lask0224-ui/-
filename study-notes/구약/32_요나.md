## 앗수르 개관 (두 책 공통 배경)

- **기원**: 니느웨 (창 10:8–12 — 구스가 니므롯을 낳음, “그가 그 땅에서 앗수르로 나아가 니느웨와 르호보딜과 갈라와 … 레센을 건설하였으니 이는 큰 성읍이라”).
- **역사 대조표**:

| 이스라엘의 역사 | 앗수르의 역사 |
|---|---|
| — | 고대 앗수르 |
| 족장시대 | 제1 중간기 (400년간) |

- 연표: BC 931 왕국분열 / 911 신앗수르 시작 / 722 북이스라엘 멸망 / 609 신앗수르 끝 / 586 남유다 멸망.
- **종교**: 다신교. 주신 **아슈르**와 **이쉬타르**(사랑과 전쟁의 신) — 전쟁 시 신의 이름을 선포하고 나감. 하위신: 태양신(샤마쉬), 달신(신), 나루르타(전쟁과 사냥), 아다드(폭풍의 신) 등.
- **신앗수르(BC 911–609)**: 고대 근동의 유례없는 초강대국 / 탁월한 군사력, 철기 기술 / **지배정책 — 조공상납: 자발적 항복 / 속국, 강제이주: 반역시도·배반** / 동서남북의 거의 모든 국가 정복.
- 앗수르 왕 연표(요나 시대 부분): 앗술나시르팔 2세(883–859) → 살만에셀 3세(859–824; **BC 853 카르카르 전투**, 예후가 조공을 바침 — 검은 오벨리스크 부조) → 샴시아다드 5세(824–810) → **아다드니나리 3세(810–783)** → **살만에셀 4세(783–773)** → **앗술단 3세(773–755)** → 앗술니라리 5세(755–745) → 디글랏빌레셀 3세(745–727). 810–745 구간을 **“침체기”**로 표시.
  - 아다드니나리 3세: ① 어린 나이에 등극 — 초기 4년 어머니 **샴무라마트**가 섭정 ② 종교개혁, **유일신으로 나부**를 숭배하게 함 ③ **BC 804 다메섹의 하사엘 제압** → 이스라엘이 아람의 압제에서 벗어남(왕하 13:3–5, 7) ④ 말년 우라르투와 전쟁, 서부원정 중단 ⑤ 종교개혁과 후세가 없어 이후 내부분쟁·국력약화 → “국력이 나름 강했던 시기”.
  - 살만에셀 4세: ① 북쪽 국경 **우라르투**의 공격 ② 다메섹에 대한 압력 유지 → **여로보암 2세가 국경을 넓힐 수 있었음** ③ 선왕이 후계자를 세우지 않아 내부 분열.
  - **앗술단 3세**: ① 내부분쟁 심화 ② **BC 765 심각한 역병** ③ **BC 763년 6월 15일 완전일식** ④ **BC 759 2차 역병** → 내부분쟁·역병·일식 등으로 **온 나라가 공포와 두려움에 사로잡혔을 가능성** (→ 니느웨가 요나의 선포에 즉각 반응한 배경으로 제시 — 강의의 연결 의도는 추정).

## BRI

- **저자** — 내증: 하나님의 말씀이 요나에게 임했다고 기록(1:1; 3:1) / 3인칭 화법이지만 요나의 말은 1인칭으로 자세히 / 물고기 뱃속 기도 내용이 본인이 직접 한 것처럼 자세히 / **요나의 감정을 솔직하고 실감나게 표현**(4:1, 2, 6, 9…). 다른 성경의 내증: 여로보암 2세 때 활동한 선지자(왕하 14:25–27) / **예수님께서 요나를 요나서의 저자로 인정**(마 12:39–41; 16:4; 눅 11:29–32).
- **요나**: 뜻 **비둘기** / 아밋대의 아들(1:1; 왕하 14:25) / **가드헤벨 출신 — 스불론 땅, 나사렛 동북쪽 성읍**(수 19:13) / 여로보암 2세 때 활동, 왕에게 이스라엘 영토 회복과 확장을 예언(왕하 14:25).
  - 성품: 예언의 성취로 북이스라엘에서 **인기가 많은 선지자였을 것으로 추정** / 하나님께 소명을 받은 사람 / **이방나라의 회개와 구원에 대해 탐탁지 않게 여김** / 고집스럽고 감정적이고 솔직함.
- **기록연대**: **앗술단 3세 때 선포된 것으로 본다면 BC 773–755년 사이**.
- **원청중 / 원독자 구분**: 원청중 = **니느웨 사람들**(1:2; 3:2; 4:2) / 원독자 = **요나의 주 활동지역이었던 북이스라엘 사람들**(왕하 14:25).
- **역사적 배경**:
  - 북이스라엘 여로보암 2세: 군사·정치·경제·문화의 황금기(왕하 14:23–29) / 북방 영토확장(**앗수르와 아람의 약화로 가능**) / 다윗·솔로몬 때와 흡사한 광대한 땅 지배 / 물질적 번영 뒤 타락, 부패와 빈부격차 심화(암 2:6–7; 8:4). (여로보암 2세 때의 영토 지도 3장 수록)
  - 남유다 웃시야: 부강·평안 / 농경 발전, 군대무기 제조(대하 26:10–15) / 에돔·블레셋·아라비아·마온과의 전쟁에서 승리(왕하 14:22; 대하 26:1–8).
  - **종교적 상황 — 부패와 타락**: 하나님의 긍휼로 번영했지만 자신들의 힘으로 여기며 교만, 타락한 문화 / 형식적 예배, 우상숭배, 하나님과 바알을 구분하지 못함 / **선민사상**.
  - **World Power**: 강대국 앗수르와 아람이 약화되었던 시기로 **없음**.
- **중심주제**: **하나님은 누구나 차별 없이 사랑하시고 회개하는 모든 사람에게 그분의 구원과 사랑을 베푸신다.**
- **쓰여진 이유**: ① 하나님은 열방을 사랑하시는 분임을 알려주기 위함 ② **이스라엘이 선민사상을 버리고 제사장 나라로서의 사명을 감당하도록** ③ 회개하면 구원을 얻음을 알려주기 위함.

2. **A 요나의 불순종(1장)** / **B 하나님의 구원 — 2장 요나의 회개와 구원 · 3장 니느웨의 회개와 구원** / **A′ 요나의 불순종(4장)**

## 1장 — 핵심 단어와 구조

- **일어나(쿰)** (1:2).
- **큰(가돌)**: 큰 성읍 니느웨(1:2; 3:2, 3; 4:11) / 큰 바람(1:4), 큰 폭풍(1:4, 12), 큰 물고기(1:17) / 선원들의 감정(1:10, 16) / 요나의 감정(4:1, 6).
- **외치라(카라)**: 하나님(1:2; 3:2), 요나(2:2; 3:4), 이방인(1:6, 14; 3:5, 8).
- **내 앞에(1:2) — 파님(פָּנִים): 얼굴**. “**여호와의 얼굴을 피하여**” ×3(1:3, 10). (지도: 욥바 → 다시스(서쪽 끝) vs 니느웨(동쪽))
- **내려가다(야라드)**: 욥바(1:3) → 배(1:3) → 배 밑층(1:5) → **산의 뿌리(2:6)** — 하강의 연속.
- **《대조》 선원들(이방인) vs 요나(이스라엘)**:

| 선원들 | 요나 |
|---|---|
| 두려워하여 자신의 신을 부름(1:5) | 배 밑에서 잠듦(1:5) |
| 하나님께 구하라고 권면(1:6) | 반응하지 않음(1:6) |
| 여호와의 일을 두려워함(1:10) | 여호와의 얼굴을 피함(1:10) |
| 요나를 살리기 위해 노력(1:13) | 자신을 바다에 던지라 함(1:12) |
| 여호와께 부르짖고 구함(1:14) | 바다에 던져짐(1:15) |

- **《카이아즘》 1:4–15**: A 하나님이 큰 바람을 바다에 던지심(4) / B 선원들이 폭풍을 두려워하여 **그들의 신**에게 부르짖음(5) / C 선원들의 배를 구하기 위한 노력(5) / D 요나의 대응: 깊이 잠듦(5) / E 선원들의 대응(6–7) / F 요나를 향한 질문(8) / **G 요나의 고백: “나는 여호와를 경외하는 자”(9)** / F′ 요나를 향한 질문(10) / E′ 선원들의 대응(11) / D′ 요나의 대응: 자신을 바다에 던지라 함(12) / C′ 선원들의 배를 구하기 위한 노력(13) / B′ 선원들이 **하나님**을 두려워하여 하나님께 부르짖음(14) / A′ 요나가 바다에 던져짐(15).

## 2장 요나의 기도

- 틀: **하나님께서 물고기를 예비, 요나를 삼키게 하심(1:17)** … **하나님께서 물고기가 요나를 토하게 하심(2:10)**.
- 기도(2:2–9): 고난으로 여호와를 불러 아룀(2) / 스올의 뱃속에서 부르짖음(2) / 주의 목전에서 쫓겨났을지라도 다시 성전을 바라볼 것(4) / 산의 뿌리까지 내려감(6) / 여호와를 기억함(7) / 감사하는 목소리로 주께 제사드리며 서원을 갚을 것(9) / **“구원은 여호와께 속하였나이다”**(9).
- **《대조》 2:8–9**: 거짓되고 헛된 것을 숭상하는 모든 자 — 자기에게 베푸신 은혜를 버렸음(8) ↔ 요나 — 감사하는 목소리로 제사, 서원을 갚겠다고 고백(9).
- **《비교》 요나 2:9 ↔ 선원들 1:16**: “나는 감사하는 목소리로 주께 **제사를 드리며** 나의 **서원을** 주께 갚겠나이다” ↔ “그 사람들이 여호와를 크게 두려워하여 여호와께 **제물을 드리고 서원을** 하였더라” — 이방 선원들이 먼저 한 일을 요나가 뒤따라 함 (관찰·해석).

## 3장 니느웨의 회개

- **《반복》 1장 ↔ 3장**: 여호와의 말씀이 임하니라(1:1 / 3:1) · 일어나(1:2 / 3:2) · 니느웨로 가서(1:2 / 3:2) · 외치라/선포하라(1:2 / 3:2) · 일어나서 갔더니 / 가니라(1:3 / 3:3).
- **니느웨의 반응(3:5–9)**: 하나님을 믿음 / 금식을 선포 / 높고 낮은 자를 막론하고 굵은 베옷 / 왕이 굵은 베옷을 입고 재 위에 앉음 / 조서를 내려 모든 백성에게 회개 촉구.
- **조서 내용(3:7–9)**: 사람이든 짐승이든 모두 금식 / 굵은 베옷 / 하나님께 부르짖으며 죄에서 떠날 것 / **회개하면 하나님께서 뜻을 돌이키시고 멸망시키지 않으실 수도 있음을 기대**.
- **《교환》 3:8–10**: A 니느웨 — 부르짖고 악한 길과 강포에서 떠날 것이라(8) / B 하나님 — 뜻을 돌이키시고 진노를 그치사 멸망하지 않게 하시리라(9) / A 니느웨 — 악한 길에서 돌이켜 떠남(10) / B 하나님 — 돌이켜 떠난 것을 보시고 뜻을 돌이켜 재앙을 내리지 않으심(10).

## 4장 요나와 하나님

- **《교환》 4:1–10(11)**: A 요나 화를 냄, 하나님의 성품 고백, 죽여달라 함(1–3) / B 하나님 — 성내는 것이 옳은지 질문(4) / A 대답 없음, 니느웨의 멸망을 지켜보려 함(5) / B 박넝쿨 예비(6) / A 요나가 기뻐함(6) / B 벌레 예비 — 박넝쿨 시듦, 뜨거운 동풍 예비(7–8) / A 혼미하여 죽기를 구함(8) / B 성내는 것이 옳은지 질문(9) / A “성내어 죽기까지 해도 옳습니다”(9) / B **큰 성읍 니느웨를 어찌 아끼지 않겠느냐** 질문(10–11).
- **하나님의 성품(4:2)**: 은혜로우심 / 자비로우심 / 노하기를 더디하심 / 인애가 크심 / 뜻을 돌이켜 재앙을 내리지 아니하시는 하나님 (출 34:6 계열 — 욜 2:13과 같은 고백; 연결은 해석).
- **“내가” ×8 (4:2–3)**: 요나의 기도 속 1인칭 반복(내가·내·내게서·내게) — 자기중심성 강조.
- **예비하사(마나)**: 큰 물고기(1:17) / 박넝쿨(4:6) / 벌레(4:7) / 뜨거운 동풍(4:8).
- **《대조》 요나 vs 하나님**: 니느웨의 회개에 성냄(1), 니느웨의 구원을 보고 죽기를 원함(3), 자기를 위하여 초막을 지음(5), 자신에게 그늘을 주는 박넝쿨을 아낌(9), 자신의 불편으로 성을 냄(9) ↔ 요나를 위해 박넝쿨 예비(6), 요나의 괴로움을 면케 하려 하심(6), 요나를 가르치기 위해 벌레와 동풍 예비(7–8), 큰 성읍 니느웨를 아끼심(10–11).
- 4:11 “하물며 이 큰 성읍 니느웨에는 좌우를 분변하지 못하는 자가 십이만여 명이요 가축도 많이 있나니 내가 어찌 아끼지 아니하겠느냐.” **아끼다(후스)** — 불쌍히 여기다, 측은히 여기다, 동정하다.

## 요나 이후 앗수르 (니느웨의 회개 이후)
