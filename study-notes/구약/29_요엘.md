## BRI

- **저자**: 브두엘의 아들 **요엘**(1:1; 행 2:16–21 “선지자 요엘을 통하여 말씀하신 것”). 이름 뜻 **“여호와는 하나님이시다”**.
  - 특징: **예루살렘 중심**으로 활동, 지역에 익숙(2:1, 15, 23, 32; 3:1, 6, 9, 16–20) / **제사 제도와 성전 구조에 익숙**(1:9, 13; 2:13–17) / 1인칭 사용(1:13, 19).
- **기록 연대 — 두 학설**:
  - 전기: 요아스 통치(BC 835–796). 근거: **왕 언급 없이 제사장만 언급**(1:9, 13; 2:13–17), 성전 언급(1:9, 13, 16), 시온·예루살렘 지명, **여호사밧(브라가) 골짜기**(3:2, 12; 대하 20:26), **앗수르·바벨론·페르시아 언급 없음**, 열거된 유다의 적국(3:4, 19 — 두로·시돈·블레셋·애굽·에돔), **우상숭배 죄 언급 없음**.
  - 후기: 포로기 이후(BC 515–500). 근거: 왕 이름 없음, 우상숭배 없음, 앗수르·바벨론 없음, 3:1–5 시제가 포로기를 과거로 암시.
  - ⚠ **★[소개관](2025-09, 최신)은 “주전 9–5세기, 유력: 주전 5세기(유다의 멸망을 옛 사건으로 암시)”** — 이 강의(2024)의 결론과 충돌. 사용자 원칙(최신 우선)상 기본값은 후기설, 주석에는 두 견해 병기 권장 → `00_소예언서_개관.md`, `../자료간_차이.md`.
  - **강의 결론(전기설)**: 성전 존재(586 이전) + 여호사밧 브라가 골짜기 사건 이후(853 이후) + **제사장 여호야다의 죽음 이후(812 이후)** + 요아스 통치(835–796) ⇒ **BC 812–796**.
- **원청중·원독자**: 남유다(시온·유다·예루살렘 반복) / **여호야다의 종교개혁을 경험했던 사람들**(왕하 12:2) / **개혁을 경험하고도 하나님을 배반한 유다 사람들**(대하 24:17–19) → 요아스 시대 여호야다 사후 다시 죄악에 물든 예루살렘 백성.
- **역사적 배경** (여호사밧 → 여호람 → 아하시야 → 아달랴 → 요아스):
  - 여호사밧(870–848): 아합과 동맹, 아들 여호람을 아합의 딸 아달랴와 결혼시킴.
  - 여호람(848–841): 바알 섬김, 산당 제사(대하 21:11).
  - 아하시야(841): 북 요람과 함께 아람 하사엘과 전쟁(대하 22:5), 예후에게 죽음.
  - 아달랴(841–835): 손자들을 죽이고 즉위(대하 22:10–12), 여호야다와 여호사브앗이 요아스를 숨김, 여호야다의 종교개혁(대하 23).
  - 요아스(835–796): 7세 즉위(대하 24:1), 성전 보수(왕하 12:6), **812 여호야다의 죽음** → 타락(아세라 목상, 대하 24:15–19), **여호야다의 아들 스가랴를 죽임**(20–22), 아람 침공(23–25), 죽음(26).
  - 종교적 상황: 여호야다 생전 — 항상 번제(대하 24:14), 정직(24:2) / 사후 — 아세라, 선지자의 경고를 듣지 않음, 스가랴 살해.
  - 본서에 나타난 상황: **소제와 전제가 성전에서 끊어짐**(1:9), 제사장들이 슬퍼함, **기쁨과 즐거움이 성전에서 끊어짐**(1:16).

## 1장 유다에 임한 심판

- **1:2–4 메뚜기 재앙** — “늙은 자들아, 땅의 모든 주민들아”(2). 네 단어(4):
  - 팥중이 **가잠** — “자르다”, 갉아먹는 성숙하지 못한 메뚜기
  - 메뚜기 **아르베** — “많은 떼”
  - 느치 **옐레크** — “핥아먹다”, 뛰는/어린 메뚜기
  - 황충 **하실** — “끝장을 낸다”
  - 구약 속 메뚜기 재앙: 출 10:4–5(여덟째 재앙) / 신 28:38, 42(언약의 저주) / 솔로몬의 기도(왕상 8:37; 대하 6:28; 7:13).
- **1:5–14 애곡하라** — 반복: 깨어 울지어다(5)·울지어다(5)·애곡함같이(8)·슬퍼하도다(9)·곡할지어다(11)·슬피 울지어다(13)·울지어다(13). 1:5–7 취하는 자들아 / 1:8–12 소제와 전제가 끊어짐, 땅의 황폐 / **1:13–14 제사장들에게 — 애곡과 금식, 금식일을 정하고 성회를 소집하여 성전에 모여 부르짖으라**.
- **1:15–18 여호와의 날의 정의와 시기**: “슬프다 그날이여 여호와의 날이 가까웠나니 멸망같이 전능자에게로부터 이르리로다”(15) / 16 기쁨과 즐거움이 끊어짐 / 19–20 선지자의 부르짖음.

## 2:1–11 여호와의 날의 경고

- 2:1 “시온에서 나팔을 불며 나의 거룩한 산에서 경고의 소리를 질러”. 여호와의 날의 모습: 떨음(1), 어둡고 캄캄함(2, 10), 불꽃(3; 1:19), 황폐(3).
- **《카이아즘》 2:1–11**: A 임박, 경고의 소리 — 떨게 함(1) / B 어둡고 캄캄한 날(2) / **C 공격과 파괴의 모습(3–9)** / B′ 해·달·별이 빛을 잃음(10) / A′ 여호와께서 군대 앞에서 소리 지르심 — 두려움(11).
- 2:10 ↔ **마 24:29** “해가 어두워지며 달이 빛을 내지 아니하며 별들이 하늘에서 떨어지며”.

## 2:12–17 회개 촉구 — “옷을 찢지 말고 마음을 찢고”

- “**내게로 돌아오라** — 금식하고 울며 애통하고 마음을 다하여”(12) / “**옷을 찢지 말고 마음을 찢고** 너희 하나님 여호와께로 돌아올지어다”(13) / 여호와의 성품(13 ↔ **출 34:6**) / 거룩한 금식일, 모임을 거룩하게(15–16) / 제사장들의 기도(17).

## 2:18–32 여호와의 날의 회복

- **《약속 오라클》 2:18–20** (약속 오라클의 3요소를 표시):
  - 미래를 나타내는 단어: “그때에”(18)
  - 급진적인 변화: 여호와의 **사랑과 긍휼**(18)
  - 축복: 곡식·새 포도주·기름 — 흡족(19), 욕을 당하지 않게, **북쪽 군대**를 쫓아냄(20), 큰일을 행하심(20)
- **《카이아즘》 2:19–27 “기뻐하며 즐거워하라”**: A 다시는 욕을 당하지 않게 — 곡식·포도주·기름 회복(19) / B 큰일 — 북쪽 군대(20) / **C 두려워 말고 기뻐하며 즐거워하라 — 온 땅의 회복(21–24)** / B′ 큰일 — **메뚜기 군대**를 갚아 주심(25) / A′ 다시는 수치를 당하지 않음 — **여호와의 이름 회복**(26–27).
- **《반복》 “너희 하나님 여호와”**(2:23, 26, 27) → 2:27 “내가 이스라엘 가운데에 있어 너희 하나님 여호와가 되고 다른 이가 없는 줄을 너희가 알 것이라.”
- **《약속 오라클》 2:28–29 “내 영을 만민에게”**: 미래 — “그 후에, 그때에” / 급진적 변화 — **내 영을 만민에게, 남종과 여종에게** / 축복 — 자녀는 장래 일을 말하고, 늙은이는 꿈을, 젊은이는 이상을 / **성취 — AD 30 오순절 성령 강림(행 2장)** → `../신약/05_사도행전.md`
- 2:30–32 심판의 날: 피·불·연기 기둥, 해가 어두워지고 달이 핏빛 / **“누구든지 여호와의 이름을 부르는 자는 구원을 얻으리니”(32; 행 2:21)**.

## 3장 열방 심판과 회복

- **《사건》 3:1–3** (육하원칙): 언제 — 사로잡힌 자를 돌아오게 할 그때 / 누가 — 내가 / 누구를 — 만국 / 어디서 — **여호사밧 골짜기** / 어떻게 — 내 백성 내 기업 이스라엘을 위하여 심문 / 왜 — 흩어 버리고 땅을 나누고 제비 뽑아 끌어가고 소년을 기생과, 소녀를 술과 바꿈.
- **《송사 오라클》 3:4–8**: 호출 — 두로·시돈·블레셋 / 증거 — 은금과 보물을 신전으로, 유다 자손을 **헬라 족속**에게 팔아 멀리 / 평결 — 너희 자녀를 유다 자손의 손에, 다시 스바 사람에게 팔리라.
- 3:9–16 모든 민족은 전쟁을 준비하라: “**보습을 쳐서 칼을, 낫을 쳐서 창을**”(10 — 사 2:4; 미 4:3의 역전) / 주의 용사들로 내려오게(11) / 낫을 쓰라, 포도주 틀(13 ↔ 사 63:3; 애 1:15; 계 19:15) / 여호와께서 시온에서 부르짖으심(16 ↔ 암 1:2).
- **《카이아즘》 3:17–21**: A 시온에 사는 너희 하나님 여호와(17) / B 예루살렘이 거룩하리니 / C 이방 사람이 통행하지 못함 / **D 산들이 단 포도주, 작은 산들이 젖, 유다 시내에 물, 성전에서 샘이 흘러 싯딤 골짜기에(18) — 회복과 축복** / C′ 애굽·에돔 황무 — 이방 / B′ 유다와 예루살렘이 영원히 / A′ 여호와께서 시온에 거하심.
- **《대조》 1장 심판 ↔ 3:18 회복**: 단 포도주가 끊어짐(1:5) ↔ 산들이 단 포도주 / 꼴이 없어 소 떼가 소란(1:18) ↔ 작은 산들이 젖 / 말랐던 시내(1:12[20]) ↔ 물이 흐름 / 기쁨이 사라진 성전(1:16) ↔ **성전에서 생수의 근원**(겔 47장 연결 가능 — 해석).
