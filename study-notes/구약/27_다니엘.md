## BRI

### 저자는 누구인가?
- 내증: **1인칭 단수 “나 다니엘”**(7:15, 28; 8:1, 15, 27; 9:2; 10:2, 7; 12:5) / **마 24:15 “선지자 다니엘이 말한 바 멸망의 가증한 것”**(단 11:31 인용).
- **저자 비평 1**: 11장이 너무 자세함 — 시리아/메소포타미아의 **셀류키드 왕조**(안디옥 수도, **북방 왕**) vs 팔레스타인/이집트의 **톨레미 왕조**(알렉산드리아 수도, **남방 왕**) → 사후 기록이라는 주장.
  - 반론: 다니엘의 1인칭 사용, 예수님의 인용, **역사적 기록이 아닌 하나님의 계시의 구체성**을 강조.
- **저자 비평 2**: **메대 사람 다리오**(6:1; 5:30–31 벨사살이 죽고 다리오가 62세에 왕이 됨) — 다리오는 페르시아의 바벨론 정복 당시 인물이 아니며, 역사의 다리오는 BC 520년경 페르시아 3대 왕 **다리우스 히스타스페스** / 렘 51:11은 바벨론이 **메대 사람**에게 멸망한다고 하는데 다리오와 고레스는 **바사 사람**.
  - **반론 1**: 5:31의 다리오 = 고레스 왕의 심복 **구바루**(Gubaru).
  - **반론 2**: **고레스와 다리오는 동일 인물** — 바사를 통치할 때는 고레스, 메대를 통치할 때는 다리오라는 이름 사용 / 렘 51:11 “메대 사람” = 메대를 통치하는 다리오의 이름 사용 → **예레미야 예언의 성취**를 강조 / 다니엘도 벨드사살과 두 개의 이름을 사용.
- **결론: 다니엘서의 저자는 다니엘**(마 24:15, 1인칭 대명사와 문맥의 연관성).

### 기록시기는?
- 10:1 “바사 왕 고레스 제삼년” = **BC 536**.
- 독자들에게 과거·현재·미래: **과거** = 예루살렘 멸망과 포로, 바벨론 멸망 / **현재** = 페르시아 제국에 거하는 유대인(이방에 사는) / **미래** = 헬라 제국과 로마 제국 열왕들, 그리고 하나님 나라.

### 누구에게?
- **페르시아 제국에 거주하는 유대인들** — 10:1(BC 536) 성전 재건을 시작한 유대인들?
- 그 외 **아람어를 사용하는 이방인들** — 3, 4장 느부갓네살의 조서는 제국 전역에, 6장 다리오의 조서도 전역에 → 다리오가 고레스의 장군이면 바벨론 지역에, 다리오가 고레스라면 페르시아 제국 전역에.

### 다니엘은 누구인가?
- **605년 느부갓네살의 공격으로 포로로 잡혀간 유다 자손(15–20세)**.
- 1:3 왕족 혹은 귀족 / 1:4 흠이 없고 용모가 아름다우며 지혜·지식·학문에 통달 / 바벨론 왕에게 택함 — **혹자는 내시라 하나 다니엘과 세 친구의 직책을 보면 내시는 아니었던 것 같음**.
- **겔 14:14 노아·욥과 함께 의인** / 1:21 고레스까지 관직 / 9:2 **예루살렘으로 돌아가지 못함(또는 않음)**.
- **활동**: 2장 느부갓네살의 꿈 해석 → 2:48 바벨론 온 도를 다스림, 모든 박사의 어른(BC 603/602) / 4장 꿈 해석 / 5장 벨사살 잔치의 글자 해석 → **바벨론의 셋째 치리자**(나보니두스, 벨사살, 다니엘) / 6장 다리오 왕 때 **총리 셋 중 하나** / **유다의 여호야긴 복권과 포로귀환 등에 상당한 영향력을 행사한 것으로 추측**.
- **개명**:

| 히브리 | 뜻 | 바벨론 | 뜻 |
|---|---|---|---|
| 다니엘 | 하나님께서 심판하신다 | 벨드사살 | 벨이여 그의 생명을 보존하소서 |
| 하나냐 | 하나님은 의로우시다 | 사드락 | 아쿠의 명령 |
| 미사엘 | 하나님과 같으신 분이 누구인가? | 메삭 | 아쿠신 같은 분이 어디 있으랴? |
| 아사랴 | 하나님께서 도우신다 | 아벳느고 | 느고의 종 |

### 다니엘서의 특징
- **죄의 언급이 없다** — 하나님으로부터 선포되는 예루살렘의 죄나 우상숭배가 언급되지 않음 (다른 선지서와의 차이).
- **꿈(환상)과 해석**으로 구성 — 해석자: 다니엘(1–6장), 천사(7–12장).
- **묵시문학**: 항상 **핍박(고난)의 시기**에 기록 / 다가올 심판과 구원을 다룸 / 연대기로 되어 있지 않음 / 꿈과 상징 / **상징적 숫자(7, 70)** / **큰 그림에 초점**.

### 역사관 (강의가 제시한 4가지)
- 직선 역사관(미개 → 발전) / 나선형 주기 역사관 / 비관주의(“잉크 묻은 술 취한 파리가 흰 종이에 찍어 놓은 자취”) / **하나님의 구속의 역사관 — 창조주 하나님께서 타락한 세계를 회복시키시고 마지막 날에 공의로 심판하심**.
- 제국 지도 슬라이드: 앗수르(BC 883–609) → 바벨론(626–539) → 메대의 정복 → 페르시아(559–336) → 헬라(336–323) → 분열된 헬라 → 로마.

## 구조

1. **언어**: 히브리어(1:1–2:3) / **아람어(2:4–7:28)** / 히브리어(8:1–12:13). 각 부분 끝: 1:21 “고레스 원년까지 있으니라” / 6:28 “형통하였더라” / 12:13 “마지막을 기다리라”.
   - **2–7장 카이아즘 (아람어 부분)**: A 2장 꿈 — 큰 신상(미래) / B 3장 세 친구의 고난과 승리 / C 4장 느부갓네살(하나님의 주권을 **인정**) / C′ 5장 벨사살(주권을 **인정하지 않음**) / B′ 6장 다니엘의 고난과 승리 / A′ 7장 꿈 — 네 짐승(미래).
   - 7장은 언어로는 앞(아람어)에, 내용(이상)으로는 뒤에 속함 → **7장이 두 부분을 잇는 경첩** (슬라이드 p47 도식: 1–6 역사 이야기 / 7–12 이상, 2:4–7장 아람어 / 8–12장 히브리어 — 해석).
2. **역사적 이야기와 이상**:
   - **1–6장 포로기의 역사 이야기**(바벨론 → 페르시아): 다니엘을 **3인칭**으로 / 다니엘이 꿈을 해석 ⇒ 하나님의 사람들은 핍박 중에도 승리 / **세상 사람들 vs 하나님의 사람들**.
   - **7–12장 세상 나라와 하나님 나라의 이상**(바벨론 → 하나님 나라): **1인칭** / **천사가 해석** ⇒ 열왕의 때에 하나님 나라는 영원하고 승리 / **세상 나라 vs 하나님 나라**.
   - **《비교》 1–6장 ↔ 7–12장**:
     - 성전이 더럽혀짐: 1:2 성전 기구를 신의 보고에 둠, 5:2 성전 기명으로 술을 마심 ↔ 8:11; 11:31 매일 드리는 제사를 제하고 성소를 헐음, 9:26 성소를 훼파, 9:27 미운 물건이 날개를 의지하여 설 것.
     - 핍박: 3장 세 친구(풀무불), 6장 다니엘(사자굴) ↔ 7:20, 25 성도들(작은 뿔, 적그리스도?), 8:13, 24 백성(작은 뿔, 에피파네스?).
     - 구원: 3장 “신들의 아들”, 6장 천사 ↔ 7:18, 22, 27 성도들이 나라를 얻음, 12:1 책에 기록된 자.
     - 심판: 3장 불꽃이 군사들을 사름, 6장 고소한 자들이 죽음 ↔ 7:26(원문 7:28) 작은 뿔 끝까지 멸망, 8:25 작은 뿔 깨어짐, 짐승들이 죽임을 당함.

## 본문

### 1장
- 1:1 “여호야김이 위에 있은 지 삼 년에” — 렘 46:2; 왕하 24:1–2, **BC 605**.
- 1:2 **“주께서”** 하나님의 전 그릇 얼마를 (넘기심 — 하나님의 주권).
- 1:4 “소년” — 10세에서 30대 초반까지 쓰이는 단어, 약 20세로 추정 / 환관 = 관리·내시 — 왕의 관리를 칭하는 단어, **다니엘은 내시가 아니었을 것**, 후에 총리가 됨.
- 1:8 **뜻을 정함** → (하나님의 은혜와 긍휼) → 모든 환상과 꿈을 깨달음(17) → 꿈 해석(2:31–45) → 왕이 엎드림(2:46) → 찬양(2:47).

### 3장 금 신상 vs 세 친구
- 금 신상: 1규빗 45cm → **높이 27m, 넓이 2.7m** / 두라 평지 / **세운 이유 — 2:38 “왕은 금 머리”**, 고대 왕들은 지역에 대한 주권 표시로 자기 형상을 세움 (금 머리에서 온몸 금 신상으로 — 2장 계시에 대한 반항으로 보는 해석 가능 — 해석).
- **《교환》 3장**: A 낙성의식(1–7) / B 거절하는 세 친구(8–12) / A 느부의 협박(13–15) “내 손에서 건져낼 신이 누구이겠느냐?” / B 거절(16–18) “**우리가 섬기는 하나님이 계시다면** … 그렇게 하지 아니하실지라도” / A 느부의 핍박(19–23) / B 승리(24–27) “**신들의 아들**”(25) / A 느부의 찬양(28–29) / B 높임 받는 세 친구(30).
- 3:28 찬양 내용 — 하나님이 구원하시는 자, 하나님을 의뢰하고, 몸을 바쳐, 왕의 명령을 거역하고, 하나님 밖에 다른 신을 섬기지 않는 종 / **조서(29)**: 대상 각 백성·나라·언어 / 명령 세 친구의 하나님께 경솔히 말하지 말 것 / 형벌 몸을 쪼개고 집을 거름터로.

### 4장 하나님의 주권을 고백하는 느부갓네살
- **카이아즘**: A 찬양(1–3) / B 꿈(4–18) / **C 다니엘의 해석(19–27)** / B′ 꿈이 성취됨(28–33) / A′ 찬양(34–37). (4장 전체가 느부갓네살의 1인칭 조서 — 보충)

### 5장 하나님보다 높아지려는 벨사살
- 벨사살 = **“벨이 왕을 지키시기를”**.
- **바벨론의 멸망 원인**: 5:22 **하나님을 알고도 마음을 낮추지 아니함** / 5:23 자신을 하늘의 주재보다 높이며 하나님께 영광을 돌리지 않음.
- **“메네 메네 데겔 우바르신”**: 메네 — 계수하다, 세다(무게 단위) / 데겔 — 무게를 달다(은화 측량 단위) / 우바르신(=베레스) — 둘로 나누다.

### 6장 다리오 왕과 다니엘
- 1–9 금령 / 10–15 금령을 어기는 다니엘 / 16–23 사자굴 / 24 고발한 자들 / 25–27 **다리오의 조서** — 대상 모든 백성·나라·언어 / “다니엘의 하나님 앞에서 떨며 두려워할지니 그는 살아계시는 하나님이시요 영원히 변하지 않으실 이시며 **그의 나라는 멸망하지 아니할 것**이요 …”.

| 금 신상에 절하지 않음 | 하루 세 번 무릎 꿇고 기도 |

| 천사가 도움 | 천사가 도움 |

### 7장 네 짐승
- **벨사살 원년(BC 553)** — 고레스의 세력이 커지던 시기.
- **《교환》**: A 네 짐승의 모습(4–8) / B 하늘 — **옛적부터 항상 계신 이**(9–10) / A 작은 뿔과 짐승들의 권세(11–12) / B 하늘 — **인자 같은 이, 영원한 권세**(13–14).
- **2장 ↔ 7장 대칭**: 머리 ↔ 사자 = 바벨론 / 가슴과 팔 ↔ 곰 = 메대-바사 / 배와 넓적다리 ↔ 표범 = 그리스 / 종아리 ↔ 무섭고 놀라운 짐승 = 로마 / 발 ↔ 열 뿔 = 열왕 / 뜨인 돌 ↔ 옛적부터 계신 이 = 하나님 나라. (그림 도표: 금 바벨론 605–539 / 은 메대페르시아 539–331 / 동 그리스 331–168 / 철 로마 168 BC–AD 476 / 철과 진흙 열국시대 AD 476–세상 끝 / 돌나라)
  - ※ 연대 표기 차이: 표 슬라이드(p31)는 헬라 330–30, 로마 30 BC– / 그림 도표(p46)는 그리스 331–168, 로마 168 BC–AD 476 → 기준이 다름(헬라 제국 존속 vs 로마의 헬라 세계 장악 시점). `자료간_차이.md`.

### 8장 두 번째 환상

- **7장과 8장의 작은 뿔 비교**:

### 9장 다니엘의 기도와 70이레
- 기도(1–19): 2절 **예레미야에게 알려 주신 연수 — 예루살렘의 황폐함이 70년 만에 그침**(렘 25:11; 29:10) / 16–19 “주를 위하여” — 17 주의 얼굴 빛을 황폐한 성소에 / **18 “우리의 공의를 의지하여 하는 것이 아니요 주의 큰 긍휼을 의지하여”** / 19 **“주 자신을 위하여 하시옵소서”** — 주의 성과 백성이 주의 이름으로 일컬음 받음.
  - 연결: **겔 36:22–23** “내가 이렇게 행함은 너희를 위함이 아니요 … 더럽힌 나의 거룩한 이름을 내가 거룩하게 할지라” (`26_에스겔.md`).
- **70이레의 목적 6가지(24)**: ① 허물이 그치며 ② 죄가 끝나며 ③ 죄악이 용서되며 ④ 영원한 의가 드러나며 ⑤ 환상과 예언이 응하며 ⑥ 지극히 거룩한 이가 기름 부음을 받으리라.
- **해석 기준(쟁점)**: 시작 — “예루살렘을 중건하라는 영이 날 때부터” / “기름 부음 받은 자 곧 왕” — 누구인가? / 때의 구분 — 셋? 넷? **중간에 공백기가 있느냐?** / 기간 — 상징적? 문자적? / **490년을 희년(49년) 10번으로 보는 해석**.
- **70이레 해석 4가지 (송병현 『다니엘 주석』 인용)**:

| 이슈 | 마카비 시대 | 로마 시대 | 종말 시대 — 상징적 | 종말 시대 — 사이/간격적 |
|---|---|---|---|---|
| 시작: 선포(25), 일곱 이레 | BC 605/586 포로 시작(예레미야) | 페르시아의 세 선포 중 하나(BC 538, 458, 445) | 고레스 선포 BC 538 | 크세르크세스 선포 중 하나(BC 458, 445) |
| 왕 메시아의 정체(25) | 고레스/제사장 여호수아 | 예수 | 예수 | 예수 |
| 62이레 | BC 538–170 고레스–안티오쿠스 시대 | 선포에서 예수님의 생애에 이르기 위하여 7주를 더한 것 | **교회 시대** | 예수님의 세례식, 혹은 예루살렘 입성 |
| 메시아의 정체(26) | **오니아스 3세**(BC 170 살해된 대제사장) | 예수 | 대환난 때의 예수 | 십자가의 예수 |
| 언약을 세우는 자의 정체(27) | 안티오쿠스와 유대인 매국노들 | 적그리스도 | 적그리스도 | 적그리스도 |
| 70이레(마지막 이레) | 안티오쿠스의 박해 | 로마 장군 **티투스의 예루살렘 함락(AD 70)** | 환난 | 환난 |

  - 슬라이드(p55) 이미지로 열 배정 확인함. “종말 시대”가 상징적 / 사이·간격적(69이레와 70이레 사이에 공백) 두 견해로 나뉨. 원 주석 자체는 직접 확인하지 못함.

### 10장 다니엘의 기도와 영적 전쟁

### 11장 큰 전쟁
- 2절 넷째 왕은? / 3절 능력 있는 왕은?(알렉산더) / **6절 남방 왕 = 톨레미 필라델푸스 — 히브리 성경을 헬라어로 번역(70인역)** / **10–19절 안티오쿠스 3세** — 북방 왕의 통치를 받는 유대, 유대인들에게 호의적.
- **21–35절 안티오쿠스 4세 에피파네스(8장 작은 뿔)**: 아람 사람 셈족(원문 표기) / 이스라엘에 적대적 / **헬라문화 보급** / **BC 171 예루살렘 공격, 4만 명 이상 살해** / **돼지를 성전 제단에 바침, 제사장들이 먹음 — 멸망의 가증한 것**.
- **36–45절 “이 왕은 누구인가?” — 에피파네스 4세가 아닌 이유**: 36 신보다 크다고 한 적이 없음 / 37 조상의 신들을 버린 적 없음 / 38 조상들이 알지 못하던 신을 공경한 적 없음. 특징: 자기 마음대로(36), 스스로 크다 함(37), 강한 신을 공경(38), 이방신을 힘입어 산성 점령(39), 여러 나라를 물 넘치듯(40), 영화로운 땅에 들어감(41), 장막 궁전을 바다와 거룩한 산 사이에(45) → **7장의 작은 뿔 = 적그리스도가 아닐까?** / **37절 “여자들이 흠모하는 것” = 교회?** (강의의 제안, 물음표 형식)
- (→ 11:21–35는 가까운 성취[에피파네스], 11:36–45는 먼 성취[적그리스도] — 이사야 강의·아모스 개론의 **텔레스코핑**과 같은 원리, `30_아모스.md` — 해석)

### 7–12장의 “때” 정리
