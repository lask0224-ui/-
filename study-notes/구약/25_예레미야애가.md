## BRI

### 1. 저자
**(1) 내적 증거**
1. **예루살렘 멸망에 대한 애통** (1:1, 2, 16; 2:1, 11, 18; 3:38–49; 4:1).
2. **예루살렘 멸망의 목격자**:
   - 포로로 잡혀감(1:3, 18; 2:9; 4:16)
   - 지도자(왕/제사장/선지자)들의 몰락(1:4, 6, 9, 19; 2:2, 6, 9, 10–12, 20; 3:48; 4:6, 7–8, 16, 20; 5:12)
   - 성소에 이방인이 들어옴(1:10) / 성전(제단)이 훼파됨(2:6, 7) / 제사·절기·안식일이 끊어짐(1:4; 2:6) / 성이 불타 무너짐(2:2–3, 5, 7–9; 4:1)
   - **부모가 자식을 먹음**(2:20; 4:10) / 갓난아이가 젖을 먹지 못함(4:4) / 기근(4:4, 9; 5:10) / 얼굴이 검게 됨(4:8; 5:10) / 여인들이 성적 수치를 당함(5:11) / 사람들의 애통(2:10)
3. **저자를 대하는 사람들의 태도**: 조롱(3:14, 63) / **구덩이에 던짐**(3:53) / 모해·비방(3:60–62) / 때림(3:62).
4. **선지자의 특성**: **신명기에 근거한 예루살렘 멸망의 이해** / 에돔에 대한 예언(4:21–22) / 시온에 대한 예언(4:22) / 회개의 촉구(3:40–54).
5. **제사장의 특성**: **하나님을 기업으로 삼음**(3:24) / **자신을 예루살렘과 동일시하며 하나님께 간구**(1:12–22) — 하나님과 예루살렘 사이에 서서 간구.
6. **예레미야서와 동일한 표현**: 눈물·슬픔·애곡(렘 7:29; 애 1:16; 2:2, 11) / 사람들로부터 고난(렘 37:15–16; 38:6 ↔ 애 3:53 — 구덩이) / “나의 마음이 병들었나이다”(렘 8:18; 애 3:53 — 표기 그대로) / “주께서 의로우시도다”(렘 12:1; 애 1:18) / “처녀 딸 유다/예루살렘/백성”(렘 14:17; 애 1:15) / “여호와의 진노(fierce anger)”(렘 4:8; 애 1:12) / **“마음속의 불”(렘 20:9; 애 1:13)** / 안과 밖에 임하는 심판(렘 14:18; 애 1:20) / 뿔이 잘림(렘 48:25; 애 2:3) / 노를 쏟으심(렘 6:11; 애 2:4) / **독한 물**(렘 8:14; 애 3:5).

**(2) 외적 증거**: 알렉산드리아 역본(헬라어, 칠십인역) / 불가타(라틴어) / 탈굼(아람어) — 1:1 앞 서문: **“때가 되니 이스라엘이 포로로 잡혀간 후 예루살렘은 황폐되었으므로 예레미야는 앉아서 예루살렘에 대해 이 애가로 울며 말했다.”**

→ 결론(함의): 저자 = 예레미야.

## 8. 구조

1. **답관체/이합체(Acrostic)**: 각 장의 절수 — **1장 22 / 2장 22 / 3장 66 / 4장 22 / 5장 22절** (히브리어 알파벳 22자; 3장은 한 글자당 3절 — 보충) / 답관체 시의 특징 / 다른 예: **시 119, 나훔 일부**. (5장은 22절이지만 답관체가 아님 — 보충)
2. **퀴나(Qinah)** — 애가 운율 (제목만).
3. **구성의 법칙**:
   - **샌드위치**: 1–2장 예루살렘 멸망에 대한 애가 / **3장 회개와 소망** / 4–5장 예루살렘 멸망에 대한 애가.
   - **카이아즘**: 1장 예루살렘 멸망에 대한 묘사와 애가 / 2장 하나님의 심판 — 영광에서 수치로 / **3장 절망 속에서 찾은 소망: 하나님** / 4장 하나님의 심판 — 영광에서 수치로 / 5장 예루살렘 멸망에 대한 묘사와 죄 고백.

## 본문

### 1장
- **의인화** — 예루살렘을 사람처럼 묘사.
- 단어: **“멸망”(1:7) — 히브리어로 ‘안식(일)’을 의미**(레 26:34–35; 대하 36:21 — 땅이 안식을 누림) / **“조소거리”(1:8) — ‘부정(unclean)’** / **“더러운 것”(1:9) — ‘부정(uncleanness)’** / “불결한 자”(1:17).
- **화자의 변화**: 1:1–11 (3인칭) → 1:12–22 (1인칭).
- **“처녀 딸 유다”(1:15)** — 딸 예루살렘/시온/유다(2:1, 2, 4, 10, 11, 13; 왕하 19:21; 렘 14:17).
- **“집 밖과 안”(1:20)** — 철저한 멸망(렘 14:18).

### 2장
- **“여호와의 발판”(2:1) = 언약궤**(대상 28:2; 시 99:5).
- 병행 구절(Parallelism): 2:5, 6.
- **“초막을 동산처럼 헐어버림”(2:6)** — ‘초막’ = 모세의 장막 → 성전 / ‘동산’ = **에덴 동산**.
- “선지자들은 여호와의 묵시를 받지 못함”(2:9).
- “I am in torment within”(2:11).
- **“거짓 선지자의 거짓 묵시”(2:14)** — 렘 5:12–13; 6:13–15; 8:10–12; 14:13–15; 23:9–40; 27:9–28:17.
- **Inclusio — “진노의 날”(2:1–22)** (2:1과 2:22가 같은 표현으로 감쌈).
- 화자의 변화: 2:1–10 (3인칭) → 2:11–22 (1인칭).

### 3장 (중심)
- **“여호와의 분노의 매”(3:1) = 바벨론**.
- **“고통”(3:5) — 히브리어로 ‘독(Poison)’**(렘 8:14; 9:15; 23:15).
- **“허리”(3:13) — 심장 혹은 신장**.
- **심판 속에서 찾은 예루살렘의 소망, 하나님(3:21–24)** — 예루살렘 회복의 근거 / 예루살렘의 유업. (3:22–23 “여호와의 인자와 긍휼이 무궁하시므로 우리가 진멸되지 아니함이니이다 이것들이 아침마다 새로우니 주의 성실하심이 크시도소이다”, 3:24 “여호와는 나의 기업이시니 그러므로 내가 그를 바라리라” — 표제 구절)
- **“심판과 긍휼”(3:32)**.
- **자신의 죄로 인한 심판(3:39)** (→ 조상 탓이 아님: 렘 31:29–30과 연결 — 해석).
- 화자의 변화: 3:1–24 (1인칭) → 3:25–39 (3인칭) → 3:40–66 (1인칭).

### 4장
- 예루살렘에 임한 하나님의 심판/진노(4:1–16) — **대조**(위 “전에는/이제는” 표).
- 화자의 변화: 4:1–16 (3인칭) → 4:17–22 (1인칭).

### 5장
- 예루살렘 멸망에 대한 묘사 / 간구.
- **화자의 변화가 없음** — 5:1–22 전부 1인칭 (공동체의 기도).

- (관찰) 1–4장은 3인칭 묘사에서 1인칭 탄식으로 넘어가는 패턴이 반복되고, 5장은 처음부터 끝까지 1인칭 기도 → 관찰자에서 기도자로 이동하는 흐름 (해석).
