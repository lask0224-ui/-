# 오바댜

> 출처: [합옵] `구약 자료/23.하박국& 24오바댜.pdf` p38–57 — “2023 TBS구약3 오바댜 **HS.P**” (원본 추출, 텍스트 완전). 표제 **“에서는 야곱에게 행한 포학으로 영원히 멸절되리라”**(10절).
> 하박국과 같은 제작자·양식 → `35_하박국.md`.

## BRI

1. **누가 썼는가?** — 1:1 “오바댜의 묵시라”. **오바댜(오바드야, H5662): “여호와의 종”**.
   - ① 에돔(에서)의 멸망에 대해 예언(1b, 18, 21) ② **시온 산에 대한 언급**(17, 21) → **남유다 출신**으로 볼 수 있음 ③ 여호와의 말씀을 듣고 선포(1b, 8, 18) → **남유다 출신 선지자 오바댜**.
2. **언제 쓰여졌는가?**
   - 예루살렘이 공격당하는 것을 표현(11–14) → **BC 586 이후**.
   - 유다의 회복에 대한 언급(20절, 공동번역): 20a “할라와 하볼로 잡혀갔던 이스라엘 백성” → BC 722 이후(왕하 17:6) / 20b “예루살렘에서 사렙다로 잡혀갔던 사람들은 네겝 성읍들을 차지하리라” → **BC 586 이후, 회복 예언, BC 538 1차 포로귀환 전**.
   - 에돔의 멸망을 예언한 동시대 다른 선지자들: **예레미야**(렘 49:13, 16–18), **에스겔**(겔 25:12–14; 36:15 — 표기 그대로) — 에돔의 영원한 멸망 / **애 4:21–22** — 예루살렘 멸망을 슬퍼하는 애가에서도 에돔 멸망 예언 / **시 137:7** — 예루살렘 멸망 당시 에돔이 유다를 조롱한 것을 하나님께 호소 → **본문 10–14절과 유사**.
   - **오바댜서와 예레미야서의 대칭**: 옵 1–4 / 렘 49:14–16 · 옵 5–6 / 렘 49:9–10 · 옵 8 / 렘 49:7 · 옵 16 / 렘 49:12 → **예루살렘 멸망 이후(BC 586 이후)에 기록**.
   - (참고: 오바댜 연대는 학계에서 이른 연대설[여호람 시대 등]도 있으나 이 강의는 586 이후설만 제시 — 보충)
3. **누구에게?** — **BC 586 예루살렘 성전 멸망을 겪고 바벨론 포로로 잡혀간 유다 백성들**.
4. **역사적 배경**:
   - 요시야 이후 왕 계보 도식 (하박국과 동일 슬라이드 — `35_하박국.md`).
   - **에돔의 주요 역사**:
     - BC 586 바벨론의 종주국이 되어(원문 표현) 예루살렘 멸망 시 예루살렘을 공격
     - BC 553 바벨론에 의해 (부분적으로) 멸망
     - 5세기 — **말라기에서 에돔이 이미 파멸된 것으로 말함**(말 1:2–4), 에돔은 아랍 나바테아족(아라비아)의 통치를 받음
     - BC 312 나바테아족이 에돔의 수도 **페트라(셀라)** 장악 → 에돔은 팔레스타인 남쪽(네겝)으로 쫓겨나 **이두매인**으로 불림
     - BC 164 유다 독립을 이끈 **마카비**가 이두매인을 장악
     - BC 120 **요한 힐카누스**(하스모니안 왕조)가 이두매를 정복, **유대교를 강요**
     - BC 64 종교독립 100년, 정치독립 80년 만에 유다는 다시 로마의 지배 → **이두매 출신 안티파터**가 로마로부터 유대의 행정관에 임명
     - BC 4–3 **이두매 출신 헤롯 대왕**이 예수 그리스도 탄생 시 베들레헴 유아 대학살(마 2:16)
     - **AD 70** 로마 디도 장군의 예루살렘 멸망 때 에돔인들은 유대인들과 함께 로마에 대항해 싸웠으나 멸망하여 **역사에서 사라짐** (→ 18절 “에서 족속에 남은 자가 없으리니”의 성취로 제시된 흐름 — 해석)
   - **유다의 종교적 상황**: 여호아하스(609, 3개월; 왕하 23:32) / 여호야김(609–597; 왕하 23:37) / 여호야긴(597, 3개월; 왕하 24:9) / 시드기야(597–586; 왕하 24:19) — 네 왕 모두 “여호와 보시기에 악을 행함”.
5. **중심 내용/주제**: **교만하여 형제나라 하나님의 백성을 대적한 에돔은 영원히 멸절될 것이다.**
6. **쓰인 이유**: 에돔에 대한 심판 선포와 유다에게 회복을 선언함으로 **이스라엘을 향한 하나님의 사랑이 끝나지 않았음**을 알게 / 바벨론 포로 생활을 잘 살아갈 수 있도록 / 악을 행하는 자를 심판하시는 공의의 하나님 / 역사를 주관하시는 하나님 / 포로생활 후 회복될 유다에 대한 소망.

- C 에돔의 멸망 모습 — **완전히 멸함**(5–9)

- C′ 에돔의 멸망 모습 — **본래 없었던 것같이 함**(15–16)

- A′ **구원받은 자들이** — 에서의 산을 심판함(21)
