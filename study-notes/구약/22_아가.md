# 아가

> 출처: [아] `구약 자료/36.아가서.pdf` — 47쪽 (원본 추출 + 이미지 쪽 확인). 표제 **“사랑은 죽음같이 강하고…”(8:6) / “열쇠를 잃어버린 자물쇠와 같은 책…”**.
> p25는 문자주의 해석을 풍자한 삽화(“The Song of Solomon illustrated — for our literalist friends”: 4장·7장의 비유를 문자 그대로 그린 여인) → **비유를 문자적으로 읽으면 안 된다는 점**을 보여주는 슬라이드.

## 아가서의 첫인상 — 접근의 난해성
- 문제: **어떻게 읽을 것인가? 어떻게 해석할 것인가?** / 성경에 아가서가 들어온 이유? / 성경의 일부로서 가지는 의미에 대한 의문.
- 성경 속 위치: **모세오경 = 법 / 선지서 = 예언 / 지혜문학(아가서) = 적용** — 타나크: 토라(원리) / 네비임(교육) / 케투빔(적용) (`20_잠언.md`와 같은 틀; 눅 24:44).

## 아가서를 이해한 방법들 (해석사) — “성경의 어떤 책보다 해석의 반경이 넓은 책”
1. **유대교 전통 — 오축(메길롯), 5개의 절기에 읽힌 책**:
   - **유월절 — 아가서 “구속사적 해석”**(1:9 “바로의 병거의 준마”, 2:9) / 맥추절 — 룻기 “언약에 대한 헌신” / 성전파괴(아브월 9일) — 애가 / 초막절 — 전도서(주후 8세기) / 부림절 — 에스더(주후 2세기).
   - **주의점: 주후 15세기 이후 드러난 ‘유대교’의 전통, 그들의 해석**.
2. **유대교 전통 — 알레고리**: 이스라엘에 대한 하나님의 사랑.
   - **1세기 랍비 아키바**: “아가서를 향연장에서 선율적인 음성으로 노래하거나 가요 형태로 취급하는 이는 누구든지 오는 세대에 참여치 못할 것이다.”(R. E. Murphy, *Song of Songs*, Hermeneia 13p) → 인간의 성보다 하나님과 인간의 관계성에 초점 — **알레고리 해석의 시작**. **랍비 아키바 이전에는 이런 해석이 발견되지 않는다**.
3. **초기 기독교 전통 — 알레고리**: 교회 또는 영혼에 대한 그리스도의 사랑.
   - AD 200 로마의 **히폴리투스**: 4:5 여인의 두 가슴 = 신약·구약.
   - **오리겐**(신플라톤주의/영지주의 사고 수용): 문자적 의미와 영적 의미를 구분, **후자를 위해 전자를 제거·무시할 수 있다**고 봄 → 신랑·신부 = 그리스도와 교회.
   - 제롬, 어거스틴, 버나드에 영향. (출처 표기: 두란노 『목회와 신학』 아가서)
4. **종교개혁 시기**: 알레고리??
   - **루터**: 알레고리의 문제점을 인식했으나 견지 — 1:2 입술의 입맞춤 = 하나님의 말씀 / 1:5 검은 피부 = 교회의 죄성.
   - **칼빈**(문법적·역사적 해석 강조): 5:3 “내가 발을 씻었으니 어찌 다시 더럽히랴마는” = 회개.
   - **웨스트민스터 총회**: (아가서를 문자적으로 보는 이들을 향해) “난잡한 아폴로나 큐피트에 의해 만들어진 육적인 소책자”라는 표현.
   - **J. 웨슬리**: 알레고리 해석의 중요성 강조.
5. **로마 가톨릭**: 알레고리에서 벗어나지 못함 / **아가서의 여인 = 성모 마리아** / 최근 알레고리에서 돌아서는 분위기.
6. **19세기 새로운 발견과 의견**: 플라톤 이원론의 영향에 대한 반성 / **아가서의 성적 메타포를 하나님과 교회에 적용 가능한가? — 신약 저자들이 아가서를 인용한 예가 있는가?** / **알레고리의 약점 = ‘주관적 해석’** / 고대 근동 고고학 — 이집트·메소포타미아·우가릿의 사랑 노래와 아가서의 닮음 → 새로운 접근.
7. **장르 이해 — 시, 드라마 형식(19세기 이후)**: 대화·독백·합창 요소 / 등장인물 2명? — ① 솔로몬과 수넴 출신 신부 ② 무명의 남자 목자와 수넴 여인 목자 / 등장인물 3명? — 솔로몬, 수넴 여인 목자, 목자 청년의 **삼각관계**.
8. **현대 — 시, 사랑의 노래**: 드라마로 보기 어려움(장면 전환 안내 없음, 내레이터 없음) / 노래·시 — 랍비 아키바가 연인의 노래로 쓰이는 것을 비난했다면 **아키바 이전에는 연인의 노래로 불렸다는 뜻??!!** / **“아가” = 노래 중의 노래 — 하나의 책이 아닌 사랑 노래 모음집? 최고의 노래!**
- **읽는 법 — 일관성**: 처음부터 끝까지 하나의 줄거리가 있는가? 전통적 해석 OK / 20세기 이후 해석자는 의문 제기 → 강의의 입장: **줄거리를 갖는다, 일관된 등장인물이 있다 — “사랑의 완성”, 솔로몬과 술람미 여인**.

### 저자
- 저자의 특징 — **다윗과 솔로몬 시대에 대한 정확한 지식, 눈으로 본 사람**:
  - 다윗과 솔로몬의 통치를 앎(4:4; 1:1) / **게달의 장막, 솔로몬의 휘장**(1:5) / **바로의 병거의 준마**(1:9 → 왕상 10:28–29) / 솔로몬의 가마 묘사(3:7–11) / 솔로몬의 포도원 **바알하몬**(8:11).
  - 지리: 엔게디 포도원의 헤나(1:14) / 베데르 산의 노루(2:17) / 길르앗 산기슭(4:1) / 레바논·아마나·스닐·헤르몬 꼭대기(4:8) / 헤스본 바드랍빔 문 곁의 연못, 다메섹을 향한 레바논 망대(7:4) → **남유다·북이스라엘의 경계가 드러나지 않음(통일왕국)** / 6:13 **술람미 = 잇사갈 지파 지경의 수넴** / 6:4 **예루살렘과 함께 언급되는 디르사**.
  - 계절의 변화: 2:11–13 겨울이 끝난 봄 / 4:1–15 여름의 목가 / 7:11 포도 열매를 거둠.
  - 레바논 동식물에 대한 다양한 지식(왕상 4:30–33) / 언급되는 향신료들.
- **솔로몬 6번 언급**(1:1; 3:7, 9, 11; 8:11, 12) / 1:1 “솔로몬의 아가라” — 솔로몬에게 속한, 쓰인, 위한, 헌정된.
- **결론: 솔로몬** / 잠 5:15–19와 아가서의 공통점.

### 쓰여진 시기

### 원독자
- **솔로몬 통치 시대의 이스라엘 백성들** (왕상 4:24–34 — 솔로몬 지혜의 범위와 영향력: 잠언 3,000, 노래 1,005).
- **잠언·전도서·아가서 = 지혜문학, 실천 — 율법(신명기) 아래서**.
  - **신명기의 관심 — 가나안의 성 문화**(신 27:16–26; 레 18:1–30) ↔ **아가서의 관심 — 하나님 백성의 성 문화**.

### 문학적 방법
- **히브리 시** — 은유, 직유, 상징.
- **와스프(wasf) 구조**: 인간 몸의 각 부분을 시적 이미지로 묘사 — **위에서 아래로, 혹은 아래에서 위로** / 애굽·메소포타미아 문학에서 발견 / **4:1–7**에 나타남.
- **노래: 여자, 남자, 코러스**.

### 중심 내용 / 쓰인 이유
- 중심: **서로를 향한 신실한 사랑 / 인간 남녀의 성에 대한 올바른 이해와 회복 / 하나님과 인간과의 사랑**.
- 이유: **언약의 틀 안에서 보호받는 신실한 사랑과 충성 그리고 헌신**.

## 본문

### 1:1 “솔로몬의 아가라” — 솔로몬과 사랑 노래?
- 사람들이 기억하는 솔로몬: 밧세바의 둘째 아들, **여디디야** / 왕상 1–2 아도니야, 나단 선지자 / 왕이 된 이후 **하나님의 마음에 든 기도 — 지혜** / 왕의 마음 / **사랑과 정체성**.

### 1:2–2:17 사랑하는 자들이 서로를 그리워함
- **화자 배분**: 1:2–4a 여자 / 1:4b 코러스(사랑에 동의) / 1:5–7 여자 / 1:8 코러스(남자가 있는 곳 힌트) / 1:9–10 남자 / 1:11 코러스 / 1:12–14 여자 / 1:15 남자 / 1:16–2:1 여자 / 2:2 남자 / 2:3–10a 여자 / 2:10b–15 남자 / 2:16–17 여자.
- **1:2–4a 여자의 고백**: 남자의 명성, 사랑받기 합당한 자 — “**기름(shemen)**이 향기로워 아름답고 **이름(shem)**이 쏟은 향기름 같으므로 처녀들이 너를 사랑하는구나” → **언어유희**(원인 → 결과) / “너는 나를 인도하라”.
  - 1:4a 번역 비교: 메시지 “나를 데려가 주세요! 우리 함께 도망쳐요!” / 새번역 “나를 데려가 주세요 … 임의 침실로” / 공동번역 “임을 따라 달음질치고 싶어라”.
- **1:5–6 “외모에 대한 약점”**: **“검으나 아름다우니 — 게달의 장막 같을지라도 솔로몬의 휘장과도 같구나”**(대하 3:14) / “나의 포도원을 내가 지키지 못하였구나” / 1:7 사랑하는 자가 어디 있는지 모름.

- **잠든 사랑이 깨어날 그날 “기다림” — 후렴 3회**: 2:7; 3:5; 8:4 “예루살렘의 딸들아 … 사랑하는 자가 원하기 전에는 흔들지 말고 깨우지 말지니라” ↔ **창 2:20–25 잠든 아담, 취하신 갈빗대, “이는 내 뼈 중의 뼈요 살 중의 살이라”** (하나님이 정하신 때의 사랑 — 해석).
- **사랑의 장애물에 대한 태도**: 2:8–9 산에서 달리고 작은 산을 빨리 넘어옴 — 장애물을 넘는 사랑 / **2:15 포도원을 허는 여우 — 관계를 방해하는 요소** / 1:6의 포도원 = 여자의 외모 → 2:15 **“우리”의 포도원** / 2:10, 13 “일어나서 함께 가자” ×2 / 2:14 **얼굴–소리–소리–얼굴**(교차).

### 3:1–6:3 여자 목자의 꿈

### 6:4–8:4 사랑하는 자들이 다시 그리워함
- 6:4–12 여인에 대한 묘사 / **6:13a 코러스 — 여인의 정체: 술람미 여인** / 6:13b–7:9a 여인 묘사(와스프, 발에서 위로 — 보충) / 7:9b–8:4 여인의 독백 **“확신”** — 흔들지 말며 깨우지 말지니라.

### 8:5–14 사랑하는 자들이 결합함
- **“누구인가?” 3회**: 3:6 (거친 들에서 올라오는 자) / 6:10 “아침 빛같이 뚜렷하고 달같이 아름답고 해같이 맑고 깃발을 세운 군대같이 당당한 여자가 누구인가?” / **8:5 “그의 사랑하는 자를 의지하고 거친 들에서 올라오는 여자가 누구인가?”**
- 8:5 장소: **사과나무 아래 — 해산의 장소** ↔ 2:3 사과나무 — 사랑의 장소.
- **8:6 “너는 나를 도장같이 마음에 품고 도장같이 팔에 두라 / 사랑은 죽음같이 강하고 — 매우 끈질기고 반드시 목적을 이룬다 / 질투는 스올같이 잔인하며 불길같이 일어나니 그 기세가 여호와의 불과 같으니라.”** (표제 구절)
- **8:7 “많은 물도 이 사랑을 끄지 못하겠고 홍수라도 삼키지 못하나니”**(사 43:2) / 온 가산을 다 주고 사랑과 바꾸려 할지라도 멸시를 받으리라.
- 8:8–10 청혼의 날 / 8:11–12 **솔로몬의 포도원 / 내게 속한 내 포도원** (1:6 “내 포도원을 지키지 못하였구나”의 회복 — 관찰) / 8:13 동산에 거주하는 자 / 8:14 “너는 빨리 달리라”.
