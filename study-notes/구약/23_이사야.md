# 이사야

> 출처: [사] `구약 자료/25.이사야.pdf` — 34쪽, THE BIBLE MINISTRY 양식, 머리글 “GOD is my salvation” (원본 추출 + 지도·연표·표 쪽 6장 이미지 확인). 표제 **“여호와는 구원이시라! 여호와를 영원히 신뢰하라!”**
> **범위: 강의안은 1–39장까지만 다룸**(마지막 쪽이 36–39장). 40–66장은 구조 슬라이드와 대응표에서만 언급됨 — 40–66장 상세는 이 자료에 없음.

## BRI

### 저자는?
- 사 1:1 “아모스의 아들 이사야가 … 본 계시라” / 사 30:8 “책에 써서 후세에 영원히 있게 하라”.
- **이사야 기록설에 대한 의문 — 1892년 독일 신학자 둠(Duhm)**: 39장과 40장의 연결성이 없다 → 세 명의 저자에 의해 기록·편집되었다고 주장.
  - 제1 이사야(1–39장): **마지막에 기록** — 이사야가 기록했지만 BC 2세기에 편집됨.
  - 제2 이사야(40–55장): **가장 첫 번째 기록** — 바벨론 유수 때 무명의 선지자.
  - 제3 이사야(56–66장): **두 번째 기록** — 예루살렘 귀향민 중 무명의 선지자.
- **둠의 주장에 대한 반론**:
  1. **1947년 발굴된 사해 사본**에 이사야서가 **한 권으로 완성**되어 기록(주전 2세기 필사).
  2. **신약 저자들이 이사야가 기록했음을 증거** — 요 12:38–41 (요 12:38 = 사 53:1, 요 12:40 = 사 6:10 → 두 부분 모두 “이사야가 말하였으되”로 인용).
  3. **“이스라엘의 거룩하신 이”, “거룩하신 이” 반복 — 1–39장 15번, 40–66장 17번** (양쪽에 고르게 분포 → 단일 저자). ※ 6장 슬라이드에는 “이스라엘의 거룩하신 이” ×26으로 되어 있음 — 표현 범위(“거룩하신 이” 포함 여부)에 따른 차이로 보임, `자료간_차이.md`에 기록.
- **결론: 이사야서 저자는 이사야!** — 대하 26:21–22 웃시야의 행적을 기록 / 대하 32:32 히스기야의 행적을 기록 (이사야가 기록자로 활동한 증거).

### 기록시기?
- 1:1 웃시야·요담·아하스·히스기야의 시대.
- 가장 이른 시기: **6:1 웃시야 왕이 죽던 해(BC 739)** / 가장 늦은 시기: **37:37–38 산헤립의 죽음(BC 681)** → **남유다 므낫세 왕의 통치 초기**.
- 연표 그림의 사역기간 막대: **이사야 739–681**, **미가 733–701**. (미가 강의[미]는 요담 750(739)부터로 제시 — 기준 차이)

### 누구에게?
- **므낫세의 통치(왕하 21:1–16) 시기의 백성들**: 하나님의 이름을 거역하고 가증스런 예배(1:2–15) / 동방 풍속이 가득(2:6) / 정의와 공의가 무너짐(4:7 — 표기 그대로; 5:7로 보임) / **몰렉을 섬김**(57:9) / 하나님의 말씀(선지자)을 듣지 않음(28:9–10) / **북이스라엘의 멸망(BC 722)을 보았던 사람들**.

### 주요연대 및 배경 — World Power 앗수르
- **카르카르(Qarqar) 전쟁 BC 853** — 북이스라엘과 주변국 연합 vs 앗수르.
- 살만에셀, 제국 서부 정복(BC 841), **예후가 조공을 바침**.
- **앗수르의 침체기(BC 803–745)**, 다메섹을 공격 → **북이스라엘과 남유다의 전성기**.
- 디글랏빌레셀 3세(BC 745–727).
- **북이스라엘과 아람의 연합이 유다를 공격(BC 735)** (사 7–8장).
- 사르곤 2세에 의해 북이스라엘 멸망(BC 722).
- **아스돗이 앗수르에 반란(BC 714)** (사 18–20장).
- 산헤립 즉위(BC 705) / **산헤립의 유다 침공(BC 701)**.
- 지도: 7세기 앗수르 패권(나 3:8–10; 대하 33:10–13 — 므낫세가 사슬에 묶여 끌려감, 에살핫돈의 바벨론 재건 표기).
- **히스기야의 수로**: 기혼샘 → **히스기야 터널(533m)** → 실로암 못. (평면도: 티로포에온 골짜기, 기드론 골짜기, 성벽, 굴착시 만난 곳, 에느로겔)
- **니느웨 왕궁 벽에 새겨진 산헤립의 침공**(산헤립 연대기 인용): 히스기야의 **강한 성읍 46개** 정복, 남녀노소 **200,150명**을 몰아냄, **“예루살렘, 그의 왕궁을 마치 새장의 새처럼 가두었다”**, 빼앗은 마을들을 아스돗 왕 미틴티·에그론 왕 파디·가사 왕 실리벨에게 줌, 조공 증액, 니느웨로 **금 30달란트, 은 800달란트**, 보석·상아 침상과 의자 등과 딸들·첩들·음악가들을 보냄. (왕하 18:14 “은 삼백 달란트와 금 삼십 달란트”와 금 액수 일치 — 비교는 보충. 연대기가 예루살렘 함락을 말하지 않는 점은 왕하 19:35–36과 연결됨 — 해석)
- **이사야서와 앗수르 — 세 시점**(연표 그림에 표시): ① **사 7–8장**(아하스, 735년경 시리아–에브라임 위기) ② **사 18–20장**(아스돗 반란 714) ③ **사 28–33장**(히스기야, 701 산헤립 침공 직전).

### 중심사상
- **사 12:2** “보라 하나님은 나의 구원이시라 내가 신뢰하고 두려움이 없으리니 주 여호와는 나의 힘이시며 나의 노래시며 나의 구원이심이라.”

### 이사야는 누구인가?
- **이사야(예샤야후) = “여호와는 구원이시다”**.
- **사역기간 58년** (739–681) / **귀족 계급의 선지자(왕족?)** / 7:3 아들 스알야숩과 함께 왕(아하스)을 만남 / 38:1 히스기야를 만남 / 복잡한 국내외 정세를 알고 있었던 사람.
- **가족**: 아내 = **네비아(여선지자)**(8:3) / 첫째 아들 **스알야숩 = “남은 자가 돌아오리라”** / 둘째 아들 **마헬살랄하스바스 = “약탈에 날래고 포획에 신속하다”** / **이사야와 아들들이 징조와 예표가 됨**(8:18).
- **부르심(6장)**: “만군의 여호와이신 왕을 뵈었음이로다” / 소명 — **백성의 마음을 둔하게 하며, 귀가 막히고, 눈이 감기게 하라** / 언제까지? — 성읍들이 황폐하여 … 여호와께서 멀리 옮기셔서 … 황폐한 곳이 많을 때까지.

## 구조

- **내용**: 1–39장 열국을 향한 하나님의 **심판(앗수르)** / 40–66장 열국을 향한 하나님의 **회복(바벨론)**.
- **시간**: **1:1–35:10 과거 / 36:1–39:8 현재 / 40:1–66:24 미래**.

## 1–5장 이스라엘의 죄

- **1:2–9 “하늘이여 들으라, 땅이여 귀를 기울이라”** (송사 형식):
  - **양육하였거늘 — 가달** = 창 12:2 “**창대하게**”와 같은 단어 (아브라함 언약의 성취로 키운 백성 — 해석).
  - **만홀히 여겨 — 나아츠**: 거부하다, 경멸하다, 업신여기다.
  - 소돔과 고모라 같으리로다(9).
- **1:10–17 타락한 예배** (백성의 행위 / 하나님의 반응):
  - 무수한 제물 / 나는 기뻐하지 않는다
  - 내 앞에 보이러 오니 / 내 마당만 밟을 뿐
  - 분향 / 내가 가증히 여기는 바
  - 성회와 아울러 악을 행하는 것 / 내가 견디지 못하겠다
  - 월삭과 절기 / 내게 무거운 짐, 지기에 곤비하였다
  - 너희가 손을 펼 때 / 내 눈을 가리고
  - 많이 기도할지라도 / 듣지 아니하리니
  - → **온전한 예배(16–17)**: 씻으며 스스로 깨끗하게 하여 … 선행을 배우며 정의를 구하며 학대받는 자를 도와주며 고아를 위하여 신원하며 과부를 위하여 변호하라.
- **2:6–10 야곱 족속을 버리신 이유**: 동방 풍속이 가득 / 점을 치고 / 이방인과 언약.
- **3:8 예루살렘이 멸망하고 유다가 엎드러진 이유**: 언어와 행위가 여호와를 거역.
- **5장 포도원 노래(심판)** — ↔ 27장 포도원 노래(회복).
- **화 오라클 5:8, 11, 18, 20, 21, 22** (6회).
- 하나님의 진노(심판): 5:24–25, 26–30.

## 6장 만군의 여호와이신 왕

- 1절 **웃시야 왕이 죽던 해(BC 739)** = 이스라엘의 왕(의 죽음) ↔ 1절 **주께서 높이 들린 보좌에 앉으셨는데** = 만군의 왕 → 지상 왕의 죽음과 하늘 왕의 보좌 대조 (해석).
- 2–4절 천사들의 예배, **“거룩하다” ×3**.
- 5절 **만군의 여호와이신 왕** — 재판관 / 전쟁을 수행하는 자.
- **“이스라엘의 거룩하신 이” ×26**.
- **《대응》 5–6장 ↔ 39–40장** (책 전반부와 후반부를 잇는 구조):

| 5–6장 | | 39–40장 | |
|---|---|---|---|
| 바벨론을 통한 심판 | 5:24–30 | 바벨론을 통한 심판 | 39:5–7 |
| 만군의 여호와이신 왕 | 6:1–5 | 창조주이신 하나님 | 40:1–43:28 |
| 이사야를 부르심 | 6:6–13 | 부르심 받은 자들 | 40:3, 6, 9 |

  - ※ 5:24–30을 “바벨론을 통한 심판”으로 표기(원문 그대로). 5:26 “먼 나라들”은 문맥상 앗수르로 보는 견해가 일반적이며, 같은 강의의 7장 표는 7장을 “앗수르를 통한 심판”으로 구분함 — `자료간_차이.md`에 기록.

## 7–12장

- **《대응》 7장 ↔ 36–37장**:

| 7장 | 항목 | 36–37장 |
|---|---|---|
| 아하스 | 왕 | 히스기야 |
| 북이스라엘, 아람 | 전쟁 | 앗수르 |
| **윗못 수도 끝 세탁자의 밭** | 장소 | **윗못 수도 끝 세탁자의 밭** |
| 신뢰하지 않음 | 하나님을 신뢰함 | 신뢰함 |
| 임마누엘 | 징조 | 올해, 둘째 해, 셋째 해 |
| 앗수르 | 동맹국 | 애굽 & 바벨론 |
| 앗수르를 통한 심판 | 심판 | 바벨론을 통한 심판 |

  (같은 장소에서 두 왕이 정반대로 반응 — 7:3; 36:2)
- **이름들**: 스알야숩 = 남은 자가 돌아오리라(7:3) / **임마누엘 = 하나님이 함께 하신다**(7:14) / 마헬살랄하스바스 = 약탈에 날래다, 포획에 신속하다(8:1) / 이사야 = 여호와는 구원이시다.
- **메시야 — 위기 속에 주어진 약속** (각 약속 앞에 위기가 놓임):
  - 7:14 “그 이름을 임마누엘이라 하리라” ← 7:1–2 위기, 7:11–12 (아하스가) 징조를 구하지 않음.
  - 8:8 “임마누엘이여” ← 8:1–7 앗수르 침략 위기.
  - **9:1–7 “한 아기가 우리에게 났고” (만군의 여호와의 열심)** ← 8:19–22 환난과 흑암과 고통의 흑암뿐.
  - **11:1–10 “이새의 줄기에서 한 싹이 나며”** ← 10:28–34 앗수르 침략.
- **앗수르 심판(10:5–19)**: 앗수르에게 임하는 화 / **앗수르 = 하나님의 진노의 막대기**(5) / 앗수르의 교만(12–14).
- (12장 = 중심사상 12:2)

## 34–35장 신원의 날
- 34장 **에돔의 심판** / 35장 광야·사막의 회복.
- **35장 ↔ 40장 이후 연결**: 맹인의 눈이 밝을 것(35:5) = 42:7 눈 먼 자들이 보게 될 것 / 사막에서 시내가 흐를 것(35:6–7) = 43:19 사막에 강을 / **대로, 거룩한 길(35:8)** = 40:3 하나님의 대로를 평탄케 하라 / 깨끗하지 못한 자는 지나가지 못하겠고.

## 36–39장 여호와를 신뢰하라 (역사 삽입부 — “현재”)
- 36장 앗수르의 위협 / 37장 히스기야의 기도 & 승리 / 38장 히스기야의 병이 나음(15년 연장) / **39장 바벨론을 의지하는 히스기야** → 39:5–7 바벨론 포로 예고 → 40장 이후(미래)로 연결.
