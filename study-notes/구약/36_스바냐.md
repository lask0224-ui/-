# 스바냐

> 출처: [습] `구약 자료/19.스바냐.pdf` — 30쪽 (원본 추출, 텍스트 완전). 요엘과 같은 양식.

## 표제

- **여호와의 날 — 그 가운데 계시는 / 네 가운데 계시는 여호와**

## BRI

- **저자**: “아몬의 아들 유다 왕 요시야의 시대에 스바냐에게 임한 여호와의 말씀”(1:1). 이름 뜻 **“여호와께서 숨기시다”**(→ 2:3 “숨김을 얻으리라”와 연결).
  - 특징: **왕족 혈통**(1:1 “히스기야의 현손”) / 예루살렘의 지리·정치·종교·사회·경제 실태를 잘 앎(1:4–13; 3:1–5) / 지도층과 주변국에 관심, 신분이 높음(1:8; 3:3–4; 2:4–15; 3:6, 8) / **율법을 앎**(1:7; 3:2, 7 — 여호와의 날, 교훈) / 제사·예배에 관심(1:7; 2:3, 11; 3:9–10, 18).
- **기록 연대**:
  - 본문의 시대적 특징: 북이스라엘 언급이 거의 없음(멸망 이후) / 예루살렘 구역 형성 이후(1:10 “제2구역” — 히스기야 시대 방어벽 개혁) / 예루살렘 멸망 예언(멸망 전) / **블레셋 5대 성읍 중 가드가 빠짐**(2:4–5 — 웃시야의 가드 점령 이후, 대하 26:6) / **앗수르 멸망 예언**(2:13 — 612 이전).
  - 유다의 상태: 우상숭배·혼합주의(1:4–6, 8), 경제적 부패와 물질주의(1:9, 11, 18), 불신과 배교(1:6; 3:2–4), 사회 전반의 패역 → 부패가 심한 시기.
  - **스바냐가 지적한 죄 ↔ 요시야 개혁 비교**: 바알·그마림·일월성신·말감 숭배, 혼합주의, 배반 / 지도층의 부정부패 / 백성의 물질숭배·교만·거짓 — 이 죄들이 **1차 개혁(BC 628, 대하 34:3–7: 산당·바알·아세라·태양신·우상 제사장 제거, 예루살렘과 성전 정결)**과 **2차 개혁(BC 622, 왕하 23; 대하 34:8–35: 남창의 집, 몰렉, 신접한 자, 언약 선포, 유월절)**에서 제거된 대상과 대응.
  - 결론: **요시야 통치 중 2차 개혁 이전, BC 640–622**. (스바냐의 선포가 개혁의 배경이 되었다고 보는 입장 — 해석)
- **원독자**: 요시야 시대 남유다 — **므낫세·아몬의 악행을 경험하고 함께 악을 행한 백성**(왕하 21:1–8; 대하 33:1–20) / 정치적 격변을 겪음 / 레위·제사장의 타락(3:4; 애 4:13) / 유다를 향한 심판 예언을 들은 백성(왕하 21:10–16).
- **연표**: 640 요시야 8세 즉위 / 632 재위 8년 하나님을 찾음(대하 34:3a) / 628 재위 12년 1차 개혁 / **627 예레미야 사역 시작**(렘 1:2) / 622 재위 18년 율법책 발견, 2차 개혁 / 612 앗수르 멸망(나보폴라살) / 609 요시야의 죽음(1차 갈그미스) / 605 1차 포로(2차 갈그미스) / 597 2차 포로 / 586 성전 멸망 / 582 (렘 52:30).

## 구조

- **유다와 열방 심판(1:1–3:8)**: 유다와 예루살렘에 임할 심판(1:1–2:3) / 열방에 임할 심판 — 주변 국가(2:4–15) / 패역한 성읍 예루살렘(3:1–8)
- **온 열방의 회복(3:9–20)**: 회복과 구원의 기쁨

## 1:1–2:3 유다와 예루살렘에 임할 심판

- 1:1 스바냐의 족보: **히스기야의 현손**, 아마랴의 증손, 그다랴의 손자, 구시의 아들.
- **1:2–3 온 세상 심판 — 창조의 역순**: 창조(창 1:20–28) 물고기 → 새 → 짐승 → 사람 / 심판(습 1:3) **사람 → 짐승 → 새 → 물고기** + 거치게 하는 것, 악인들.
- **1:4–13 심판의 대상들**:
  - Ⅰ 종교(4–6): 바알 숭배, **그마림**이란 이름과 그 제사장들, 별 숭배, **여호와께 맹세하면서 말감을 가리켜 맹세**(혼합주의), 여호와를 배반한 자, 여호와를 찾지도 구하지도 않은 자.
  - 1:7 “여호와께서 **희생(제바흐)**을 준비하고” — 유다 자신이 제물.
  - Ⅱ 지도층(8–9): 방백들·왕자들·**이방인의 옷을 입은 자**, 문턱을 뛰어넘어 포악과 거짓을 채운 자.
  - Ⅲ 백성(10–13): **찌꺼기같이 가라앉은 사람들**(12 — “여호와께서는 복도 내리지 아니하시며 화도 내리지 아니하시리라” 하는 자들).
- **1:14–18 여호와의 날**: 분노의 날, 환난과 고통의 날, 황폐와 패망의 날, 캄캄하고 어두운 날, 구름과 흑암의 날(15) / 나팔과 경고의 날(16) / **여호와의 질투(킨아)의 불**(18).
- **《반복》**: 진멸(1:2, 3×2) 3회 / 멸절(1:3, 4, 6, 18×2) 5회 / 벌하리라(1:8, 9, 12; 3:8, 19) 5회.
- **《대조》 2:1–3 회개 촉구**: “수치를 모르는 백성아 — 모일지어다 모일지어다 — 진노의 날 **전**에” ↔ “여호와의 규례를 지키는 세상의 모든 **겸손한 자들아** — 여호와를 찾으며 공의와 겸손을 구하라 — 분노의 날에 **숨김**을 얻으리라.” (이름 “스바냐 = 여호와께서 숨기시다”와 연결)

## 2:4–15 열방에 임할 심판

- 블레셋(가사·아스글론·아스돗·에그론, 4–7) / 모압과 암몬(8–11) / 구스(12) / 앗수르(13–15).
- **《샌드위치》**: A 블레셋·암몬·모압 심판(4–10) / **B 열방이 여호와를 두려워하며 경배(11)** / A′ 구스·앗수르 심판(12–15).

## 3:1–8 패역한 성읍 예루살렘 — 화 오라클

- “패역하고 더러운 곳, 포악한 그 성읍이 **화** 있을진저”(1).
- 이유: 명령을 듣지 않고 교훈을 받지 않고 **여호와를 의뢰하지 않고 하나님에게 가까이 나아가지 않음**(2) / 방백·재판장·선지자·제사장의 죄(3–4) / 수치를 모름(5) / 경고를 무시하고 부지런히 행위를 더럽힘(7).
- 멸망 예언(6, 8) → 성취: BC 586.
- **《반복》《대조》 “그 가운데”(3:3, 5)**: 그 가운데 방백들은 **부르짖는 사자**, 재판장은 **저녁 이리**, 선지자는 경솔하고 간사, 제사장은 성소를 더럽히고 율법을 범함 — 불의한 자는 수치를 모름 ↔ **그 가운데 계시는 여호와**는 의로우시고 불의를 행하지 않으시며 **아침마다 빠짐없이 공의를 비추심**.

## 3:9–20 온 열방의 회복

- **《약속 오라클》 3:9–10**: 미래 — “그때에” / 급진적 변화 — **여러 백성의 입술을 깨끗하게**, 다 여호와의 이름을 부르며 한 가지로 섬김(창 11장 바벨 언어 혼잡의 역전 — 해석) / 축복 — 흩은 자의 딸이 예물을 가지고 옴 / 성취 — **교회 시대**.
- **3:17 여호와의 구원과 기쁨의 노래**: “너의 하나님 여호와가 **너의 가운데** 계시니 그는 구원을 베푸실 전능자이시라. 그가 너로 말미암아 **기쁨을 이기지 못하시며** 너를 **잠잠히 사랑하시며** 너로 말미암아 **즐거이 부르며 기뻐하시리라**.”
- **《반복》 “네 가운데” ×4**: 교만한 자를 네 가운데서 제거(11) / 곤고하고 가난한 백성을 네 가운데 남겨 둠 — **남은 자**(12) / 이스라엘 왕 여호와가 네 가운데(15) / 너희 하나님 여호와가 네 가운데(17).
- **《카이아즘》 3:9–20**: A 흩은 자들을 모아 나를 섬기게(9–10) / B 예루살렘·성산 — 남은 자의 회복(11–13) / C 회복의 노래 — **예루살렘의 기쁨**, 여호와가 네 가운데(14–15) / **D “두려워 말라, 네 손을 늘어뜨리지 말라”(16)** / C′ 회복의 기쁨 — **하나님의 기쁨**, 여호와가 네 가운데(17) / B′ 예루살렘·절기 — 남은 자(18) / A′ 쫓겨난 자들을 모아 칭찬과 명성을 얻게(19–20).
- (관찰) 3:1–8의 “그 가운데”(불의한 지도자들 ↔ 의로우신 여호와)가 3:11–17의 “네 가운데”(남은 자와 기뻐하시는 여호와)로 전환 — 표제가 이 대조를 담고 있음.
