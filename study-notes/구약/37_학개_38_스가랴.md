## 공통 배경

### 931–538년 이스라엘의 역사

### 포로기 유대인의 생활 (바벨론에서)
1. **직업**: 기술자들은 자기 사업을 가질 수 있었음 — 포로의 대다수가 기술자(왕하 24:14–16).
2. **사회적 지위**: 고위층 — 다니엘(총독), 모르드개(총독), 에스더(왕비), 에스라(학사), 느헤미야(술 관원) / **귀환자들의 헌금이 상당한 액수**(스 2:68–69) / 유대인 가정과 바벨론 가정의 **법적 지위가 동등**함을 말하는 문서 발견 / 요세푸스: “바벨론의 포로들은 웬만큼은 살았다”.
3. **자유**: 이동의 자유 / 자기 집(겔 8:1) / 예루살렘과 편지 가능(렘 29:25–32) / **성전이 없어 회당 문화 형성** / 희생제사는 드릴 수 없음.
4. **공동체**: 장로 중심(겔 8:1) / 가족 공동체 — 귀환자 명단이 족보별로 기록 / 언어 — **아람어** 사용.
5. **예루살렘에 남은 자들**: 포로는 대부분 상류층과 필요한 사람들(왕하 24:14–16) / 나머지는 본토에서 괴로움(렘 24:5–10) / 파괴된 성전과 도시에 비천한 사람들만 남음(왕하 24:14; 25:12).
6. **포로기의 특징**: 바벨론의 유대인은 어느 정도 사회적 안정 / **이미 바벨론에서 삶의 기반을 닦은 자들이 폐허인 예루살렘으로 삶의 터전을 옮기는 것은 쉬운 일이 아니었음** (→ 귀환자가 적고 성전 재건이 지연된 배경 — 해석).

## 학개

### BRI
- **저자**: 학 1:1, 3, 12; 2:1, 10, 20 / 스 5:1; 6:14.
  - **학개(학가이, H2292) — “축제” 또는 “축제에서 태어난”** / 스가랴와 동시대, **스가랴보다 2개월 먼저** 예언 시작(학 1:1 BC 520년 6월 1일; 슥 1:1 520년 8월) / **나이가 많았을 것으로 추정**(2:3 — 옛 성전의 영광을 본 자).
- **누구에게**: 스룹바벨과 여호수아(1:1; 2:2, 23) / 백성(1:4; 2:2) → **1차 귀환 후 성전 재건이 중단(538–520)된 시기의 유대인들**.
  - **스룹바벨** = 스알디엘의 아들 — **대상 3장 왕의 계보**(요시야 → 여호야긴 → 스알디엘/브다야 → 스룹바벨) / **여호사닥의 아들 여호수아** — 대상 6장 **아론의 계보, 대제사장의 후손**(학 1:12, 14; 2:2; 슥 6:11) → 왕의 계보 + 제사장 계보.
- **언제**: 첫째 메시지 1:1 **다리오 2년 6월 1일(BC 520)** / 둘째 2:1 7월 21일 / 셋째 2:10 9월 24일 / 넷째 2:20 9월 24일.
- **정치적 상황**: 539 바벨론 멸망 → 538 고레스 칙령(스 1:1–4), 1차 귀환의 목적(스 1:5 — 성전 건축) / 538 제단을 먼저 만듦(스 3:1–3), 7월 15–21일 초막절(3:4) / 536년 2월 성전 기초(3:8–13) / **사마리아 사람들의 방해(스 4:1–24) → 16년 동안 중단(536–520, 스 4:24)**.
- **중심 내용: 성전 재건의 촉구**.
- **쓰여진 이유**: 성전 재건을 다시 시작하도록 / **하나님이 함께하심과 그 성전이 이전보다 더 영화롭게 될 것**을 말하여 침체된 백성을 위로·격려.

## 스가랴

### BRI
- **저자**: 슥 1:1, 7; 7:1, 8 / 다리오 2년(520)에 예언한 선지자는 학개와 스가랴(스 5:1; 6:14).
  - **스가랴(제카르야, H2148) — “여호와께서 기억하신다”** / **잇도의 손자, 베레갸의 아들**(1:1).
- **언제**: ① 첫째 메시지(1:1–6) **BC 520년 8월** ② 둘째 — **8가지 환상(1:7–6:8/15) 520년 11월 24일** ③ 셋째(7–8장) **518년 9월 4일** ④ 넷째(9–14장) **연대 없음** / 성전 완공 516(스 6:15).
  - **학개와 스가랴 메시지 순서**: 학개 2번째(2:1–9, 7월 21일) → **스가랴 1번째(1:1–6, 8월)** → 학개 3번째(2:10–19, 9월 24일) → 학개 4번째(2:20–23, 9월 24일) → 스가랴 8환상(11월 24일).
  - 11월 24일 = **성전 재건 시작한 지 5개월**(학 1:15, 6월 24일) = **성전 지대를 놓은 후 2개월**(학 2:18–19, 9월 24일).
- **누구에게**: 바벨론 포로에서 돌아와 **성전을 재건하고 있는 사람들과 그 자손들**.
- **중심 내용**: **진정한 성전은 예수 그리스도에 의해 지어진다** / 하나님의 능력으로 되어질 성전 재건(예루살렘의 회복)과 **메시야 예언**.
- **쓰여진 이유**: 성전 재건을 위한 격려 / 재건이 **하나님의 능력**으로 이루어질 것(4:6 “힘으로 되지 아니하며 능력으로 되지 아니하고 오직 나의 영으로” — 보충) / **메시야가 이루실 영화로운 미래의 통치**.

- **6:9–15 금 면류관을 쓰는 여호수아** (대제사장에게 면류관 — “순” 곧 메시아의 예표: 왕과 제사장의 결합 — 본문 보충·해석).

### 7–8장 이스라엘을 회복하겠다 《카이아즘》
- A 금식(7:1–7) / B 이스라엘이 **하지 않은** 일 4가지(7:8–10: 진실한 재판, 인애와 긍휼, 과부·고아·나그네·궁핍한 자를 압제하지 말 것, 악을 도모하지 말 것 — 보충) / C 이스라엘의 **심판 이유**(7:11–14) / **D 예루살렘의 회복 모습(8:1–8)** / C′ 이스라엘의 **회복 이유**(8:9–15) / B′ 이스라엘이 **행할** 일 4가지(8:16–17) / A′ 금식(8:18–23 — 금식이 기쁨과 즐거움의 절기로).
- **이스라엘의 금식 (4·5·7·10월)**:
  - **4월** — 586 느부갓네살이 예루살렘을 점령(렘 39:2; 왕하 25:2–3)
  - **5월** — 586 예루살렘 성전 파괴(왕하 25:8–17; 렘 52:12)
  - **7월** — 586 유다 총독 그달리야 암살(왕하 25:22–25; 렘 41:1–10)
  - **10월** — 588 예루살렘 포위 시작(렘 39:1; 왕하 25:1; 렘 52:4)
- **8:20–23 많은 백성과 강대한 나라들이 와서 여호와를 찾음** (점층): A 여러 백성과 많은 성읍의 주민이 올 것(20) → a1 이 성읍 주민이 저 성읍에 가서 만군의 여호와를 찾음(21) → a2 많은 백성과 강대한 나라들이 예루살렘으로(22) → a3 **이방 백성 10명이 유다 사람 1명의 옷자락을 잡고** 하나님을 찾음(23).

### 12–14장 예루살렘을 정결케 하시는 메시야
- 《카이아즘》: A 예루살렘을 친 열방 심판 — 예루살렘의 희생을 동반(12:1–9) / B **목자의 죽음으로 인한 애통**(12:10–14 — “그들이 그 찌른 바 그를 바라보고” → 요 19:37 — 보충) / **C 예루살렘을 정결케 하시는 메시야(13:1–6 — 죄와 더러움을 씻는 샘)** / B′ **목자의 박해로 인한 양 떼의 흩어짐**(13:7–9 — “목자를 치면 양이 흩어지려니와” → 마 26:31 — 보충) / A′ 열방 심판 — 예루살렘을 친 열방이 **초막절**을 지킴(14:1–21).
