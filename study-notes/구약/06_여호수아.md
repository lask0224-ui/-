## 역사서란 무엇인가 [수A] (역사서 공통 도입)

1. 역사서는 **이야기**다.
2. 역사서는 **목적을 가진** 이야기들이다.
3. 역사서는 **민족의 정체성**을 확립하게 한다.
4. **하나님이 이야기의 주인공**이며, 그분이 영광을 받으신다.
- 역사서를 읽는 원리: ① 하나님께서 **말씀과 행위**를 통해 역사를 주관하신다 ② 하나님의 말씀이 **언약 안에서 어떻게 성취**되는지 서술된다 ③ **역사 그 자체가 하나님의 백성을 향한 하나님의 선포**다.
- 타낙(히브리 성경) 구조도: 율법(토라: 창–신) / 선지서(느비임: **전기 선지서** = 여호수아·사사기·사무엘·열왕기, **후기 선지서** = 이사야·예레미야·에스겔·열둘) / 성문서(케투빔: 시편·잠언·욥·아가·룻·애가·전도서·에스더·다니엘·에스라-느헤미야·역대기). → 여호수아는 **전기 선지서**의 첫 책.
- 역사적 방법(Historical Method)의 질문 틀 [수A]: 사건의 연대 / 하나님이 쓰신 사람들 / 그때의 적과 하나님이 그들을 어떻게 쓰셨는가 / 그 땅의 역사와 문화.

  - **여호수아 한 인물의 반복(154회)**
  - 모세의 후계자 개념 강조(1:1, 17; 4:10, 14; 8:30–32…)
  - 외증
  - 여호수아가 기록하지 않은 부분: 여호수아의 죽음(24:29–30) — [수B] 유대 전통상 **엘르아살**이 기록.
- **여호수아라는 사람** [수B]: 호세아(구원) → 여호수아(여호와께서 구원하신다) / 에브라임 지파 족장 엘리사마의 손자, 눈의 아들(대상 7:27[표기 7:17], 민 1:10) / 모세의 수종자(출 24:13; 32:17; 33:11; 민 11:28) / 아말렉 전투 지휘관(출 17장) / 시내산에 모세와 함께 / 12정탐꾼(민 13:8) / 갈렙과 함께 보고(민 14:6, 30) / **모세 곁에서 하나님을 섬기는 법을 직접 보고 배움**.
- **기록 시기**: 모세가 죽은 후(1:1)·요단 도하 이후(4:19) / 갈렙 85세 이후(14:10) / 여호수아가 죽기 전(24:29) [수A] → **정복과 분배가 끝난 후** [수B].
- **수신자**: 가나안을 정복하고 땅을 분배받은 자들. 근거 [수B]: 가나안 도시의 **옛 명칭**(예루살렘 = 여부스, 헤브론 = 기럇아르바)이 언급됨, **시돈은 아직 정복되지 않음**(13:4–6).
- **연대** [수A]: 모세의 죽음 BC 1406 / 요단 도하 1405 / 정복 전쟁 1405–1400.
  - [수B] 갈렙의 나이로 계산: 출애굽 1446(39세) → 정탐 1445(40세, 14:7) → 광야 40년 → 정복 완료 1400(85세, 14:10) ⇒ **정복에 5–6년**.
- **하나님이 쓰신 사람들**: 여호수아, 엘르아살, 지파의 족장들, 비느하스, 갈렙.
- **적**: 여리고 / 아이성 / 가나안 7족속 / 아모리 5왕 / 북부 하솔 연합군.
- **가나안의 역사와 문화** [수A]: 후기 청동기(BC 1500–1200), 애굽 18·19왕조가 힉소스 이후 다시 일어남, 애굽·미탄니·헷의 대립으로 팔레스타인 지배가 느슨. 문화: 수메르·아카드 영향, 신들 = **생산(풍요)과 밀접**, 남신과 여신이 가족 관계, **엘·아세라·바알·아스다롯**, 신전 창기.
- **중심 내용**: **신실하신 하나님이 친히 싸워 주심으로, 언약대로 이스라엘 백성이 가나안 땅을 정복하고 정착하게 하셨다.**
- **기록 목적**: ① 하나님의 약속이 가나안 정착으로 이루어졌음을 알게 ② 언약 백성으로서의 정체성 확인 ③ 하나님을 경외함으로 언약에 순종하는 삶.
- **강조되는 하나님의 성품**: 신실하심(언약 성취) / **공의로우심(가나안 족속 심판, 아간의 심판)** / 전능하심(자연을 다스리심).

## 본문 [수B 중심]

### 1장
- 모세 → 여호수아: 리더의 권위·역할·책임 위임. 1:2 두 명령(일어나 건너라).
- “**모든 백성과 더불어**”(2절), “이스라엘 자손에게 **주는** 그 땅”.
- 질문: 가나안 땅은 **주어진 땅인가, 주어질 땅인가?** 지금 필요한 것은?
- **1:5–9 교차**: A 너와 함께 있을 것(5) / B 강하고 담대하라(6) / **C 율법을 지켜 행하라(7–8)** / B′ 강하고 담대하라(9) / A′ 너와 함께 있을 것(9). → 질문: “마음을 강하고 담대하게 하는 방법은?” (구조상 답 = 중심의 율법)
- 약속의 땅 범위(4절): 광야·레바논에서 유브라데까지, 헷 족속의 온 땅, 대해까지.
- 양식을 준비하라(11), 동편 2½지파는 앞서 건너가 도우라(12–14; 민 32장).
- 가나안에 들어가게 하시는 목적: **안식**(1:13, 15; 히 3:18; 4:8–11).

### 3–4장 요단 도하
- 싯딤에서 요단에 이른 후 **사흘**(3:1). 요단: 갈릴리(−212m) → 사해(−391m), 179m 낙차. **니산월(3–4월) 헐몬산 눈이 녹아 범람**(3:15).
- 언약궤와 백성 사이 **2,000규빗**(3:4).
- **카이아즘**: A 제사장들이 요단에 멈춰 섬(3:8) / B 물이 멈춰 섬(3:13) / **C 제사장들의 생명을 건 순종(3:14–15)** / B′ 물이 멈춤(3:16) / A′ 제사장들이 멈춰 섬(3:17).
- 12돌: 길갈에 / 요단에. 결과: 4:14 여호수아를 크게 하심, 5:1 가나안 왕들의 마음이 녹음.

### 5장 길갈
- **할례**(의미 / 군사적 전략상으로는 위험) → **길갈 = 애굽의 수치를 굴러가게 함** → **유월절**(14일 저녁, 여리고 평지) → **만나가 그침**(12) → **여호와의 군대 장관**(14–15, 신을 벗으라 — 출 3:5와 연결).

### 6장 여리고
- 무교절과 연결. 여리고 = 종려나무의 성읍(신 34:3), 면적 약 32,000–36,000㎡ 추정. “굳게 닫혔고”(1) — 성문을 여는 당시 방법 vs **하나님의 방법**.
- **양각 나팔 = 히 요벨**(희년과 같은 단어; 레 25:13–15 등).
- “**네 손에 넘겨 주었으니**” 반복(1:2, 3, 11, 13, 14; 2:24; 6:2, 16; 8:1, 18; 11:8; 21:44).
- 온전히 바치라 = 헤렘(6:17–18; 레 27:28–29). 6:26 재건 저주 → 왕상 16:34 성취.
- 라합의 구원: **붉은 줄**, 모형론.
- **헤렘(진멸) 논쟁** [수A] — 강의가 제시한 6가지 입장:
  1. 하나님이 명령했으므로 옳은 행동이다.
  2. 불가피한 비극, 우상 숭배 문제의 유일한 현실적 해결책.
  3. 실제 사건이 아니라 **영적 의미의 진멸**.
  4. 고대 근동의 다른 나라도 시행했으므로 정상.
  5. 가나안 거민의 악함이 심각해도 헤렘의 명분은 되지 못한다.
  6. **헤렘이 불편하다면, 어쩌면 믿음이 우리에게 더 이상 생명과 죽음의 문제가 아니라는 뜻인지도 모른다.**
  - (강의안은 입장을 나열만 하고 결론을 명시하지 않음. 6번이 마지막 도전으로 배치됨)

### 7–8장 아이
- 아이 = 벧엘 동쪽 벧아웬 근처 작은 성, 약 12,000명(8:25), 동쪽은 절벽.
- **아간**: 유다 지파 세라의 증손·삽디의 손자·갈미의 아들, 시날산 외투·은 200세겔·금 50세겔. 6:18 “이스라엘 진영으로 바치는 것이 되게 하여” 성취. 제비로 뽑힘 — **아간이 말한 것 vs 말하지 않은 것**.
- 아이 정복: 8:1 하나님의 말씀 / 여리고와 다른 점(탈취 허용). **성공과 실패를 가른 것은?**
- **에발산 제단**(8:30; 출 20:25; 신 27:2–8, 12–13): 세겜 한쪽 939m, 숲이 없어 **저주** 상징. “**기록된 대로**”(8:31, 33, 34).

### 9장 기브온
- 해발 772m, 가나안 4대 도시 중 하나, 그비라·브에롯·기럇여아림과 **도시 연방**, 히위 족속(함의 후손, 창 10:17–20).
- 조약 → 나무 패고 물 긷는 자(21, 27) → 후일: 삼하 21장, 느 3:7; 7:25.
- 신 20:10–13(먼 성읍과 화친) vs 신 20:17–18(가나안은 진멸) — 긴장.

### 10–12장 정복
- 10장: 기브온 구원이 **남부 점령의 계기**. 예루살렘 왕 **아도니세덱** 중심 아모리 5왕(예루살렘·헤브론·야르뭇·라기스·에글론). 길갈 → 기브온 31km 밤새 올라감. **태양이 멈춘 기적**(12). “**여호와께서 이스라엘을 위하여 싸우심**”(10:14; 23:3). 남부 점령(29–43) 후 길갈로.
- 11장: **하솔 왕 야빈**이 북부 연합군 총사령관, 남부보다 큰 규모. 11:6. 할락산(최남단)~헤르몬산(최북단)(17).
- 12장 요약: 요단 동편(모세 — 시혼·옥) / 요단 서편(여호수아 — **31왕 = 남부 16 + 북부 15**).

### 13–21장 분배
- 13장: **아직 정복되지 않은 땅이 많은데도 분배하라**(6–7). 요단 동편 분배. 레위의 기업 = 여호와(13:33; 18:7).
- 14장 요단 서편 9½지파. 순서: **갈렙 → 유다 → 요셉(에브라임·므낫세)**. 갈렙: 유다 지파, **그니스 사람** 여분네의 아들(창 15:19 — 원래 이방 족속 계통), 85세, 헤브론(창 49:29–31 막벨라와 연결).
- 15장 유다: 갈렙이 아낙의 세 아들(세새·아히만·달매) 축출. 네게브 29 / 평지 42 / 산지 38 / 광야 6성읍. **그러나 여부스 족속을 쫓아내지 못함**(63).
- 16장 에브라임: 두 번째로 분배(자료 표기 “여호수아가 속한 유다 지파”는 오기 — 여호수아는 **에브라임** 지파), 장자의 축복(창 48:12–20), **게셀의 가나안 족속을 쫓아내지 않음**(10).
- 17장 므낫세 반: 동·서 양쪽, **가나안 주민을 쫓아내지 못함 — 가나안 족속이 결심하고 거주**(12). 요셉 자손의 불만(14).
- **18:1 길갈 → 실로: 이스라엘의 중심이 바뀜.** 나머지 7지파(베냐민·시므온·스불론·잇사갈·아셀·납달리·단).
- 19:49–50 **여호수아가 제일 마지막에** 기업을 받음.
- 20장 도피성. 21장 레위 성읍 48(그핫 13+10, 게르손 13, 므라리 12). **21:44 안식을 주심.**
- (관찰) 13–19장에 “쫓아내지 못함/않음”이 반복 → 사사기 1장으로 이어지는 복선(해석).

### 22–24장 섬기라
- 22장 동편 지파 귀환, **요단 가 제단** 갈등 → 비느하스.
- 23장 여호수아의 유언(지도자들에게): 과거(행하신 은혜 3–4) / 현재(남은 정복을 마치라 5) / 미래(하나님만 섬기라 6–14) / 경고(15–16). 110세(24:29).
- **24장 다시 세겜** — 아브라함에게 처음 땅을 약속한 곳(창 12:6–7). **세겜 언약** = 종주권 조약 형식 [수A]: 전문(24:2) / 역사적 서언(24:1–13) / 규정(24:14–15, 16–25) / 문서 보관(24:26) / 증인(24:22, 27) / 저주와 축복(24:19–20).
- 여호수아의 죽음(24:29–31; 삿 2:7, 10 — **“그 후에 일어난 다른 세대”**로 사사기가 이어짐), 딤낫세라, **요셉의 뼈**(24:32 — 창 50:25, 출 13:19의 완결), 엘르아살의 죽음.
