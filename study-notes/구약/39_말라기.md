# 말라기

> 출처: [말] `구약 자료/39.말라기.pdf` — 19쪽, The Bible Ministry (원본 추출, 텍스트 완전; 각 쪽 이미지는 배경). 표제 **“언약의 사자가 임하시리라”**(3:1).

## BRI

### 저자는 누구인가?
- 1:1 “여호와께서 **말라기**를 통하여 이스라엘에게 말씀하신 경고라”.
- **말라키 = “나의 사자”** / 말라키야 = “여호와의 사자” (비교: 이사야 = 여호와는 구원이시다, 엘리야 = 여호와는 하나님이시다 — 이름에 여호와가 들어간 형태) → **저자는 말라기**.
- **저자의 특징**: 레위 언약 및 제사장의 역할에 대한 이해 / 제사장들을 향한 메시지(1:6; 2:1) / 부정한 제물에 대한 이해 / **레위 언약(2:4–5)** / **제사장들의 불평을 잘 알고 있음** (제사장 계열이거나 성전 사정에 밝은 인물로 보는 흐름 — 해석).

### 기록시기는?
- 내적 증거:
  1. **에돔의 멸망(1:3–4)** — c. BC 552 바벨론 **나보니두스**에 의해 멸망 (시 137:7). ([렘본] 552 / [합옵] 553 — `24_예레미야.md`, `31_오바댜.md`)
  2. **총독(1:8)** — 페르시아 제국 시대 지방 관장의 직임 (스 5:14–15 총독 세스바살; 느 8:9 총독 느헤미야).
  3. **성전과 제사(1:6–2:9)** — 성전이 있음(516 이후), 제사가 드려짐.
  4. **이방 신의 딸과 결혼(2:11)** — 스 9:1–10; 느 13:23–27, 28.
  5. **십일조(3:7–12)** — 느 13:4–5 암몬 사람 도비야, 엘리아십이 도비야와 연락 / 느 13:10–11 성전을 떠나는 레위 사람들.
- ⇒ **말라기와 에스라/느헤미야 시대의 상황이 비슷** → **BC 458 에스라 귀환 직전 또는 BC 432 느헤미야 개혁 직전**.

### 역사적 배경
- **성전(스룹바벨 성전) 완공 이후 하나님의 영광은 임하지 않았다** — 그러나 회복 약속이 있었음: 학 2:9 “이 성전의 나중 영광이 이전 영광보다 크리라” / 슥 1–8장 성전을 재건하라(8개의 환상 = 회복 약속) / 렘 23:5–8; 29:10–14.
- (→ 약속이 지연된 듯한 실망 속의 백성 — 아래 “이스라엘의 항변”의 배경 — 해석)

### 쓰여진 이유
- **언약에 신실한 만군의 여호와께로 돌아오도록** / **주를 경외함으로 언약의 사자를 기다리도록** / 하나님을 향한 **제사를 회복** / **경건한 자손**으로 살아가도록.

## 본문의 특징
1. **“만군의 여호와” 24번** — 만군의 = **차바(전쟁, 군대)** → **“전능자 여호와”**. 선지서별 빈도: 이사야 62, 예레미야 77, 학개 14, 스가랴 53, **말라기 24** — **말라기 총 55절 중 24회(약 43%)**.
2. **언약의 사자** — 구약의 언약들: **아브라함 언약 / 시내산 언약 & 모압 언약 / 다윗 언약** (+ 2:4–5 레위 언약).

## 구조
- 1:1–14 **야곱 족속에게 멸시당하는** 만군의 여호와
- 2:1–16 **야곱 족속을 심판하시는** 만군의 여호와
- 2:17–3:15 **성전에 임하시는 언약의 사자**
- 3:16–4:6 **율례와 법도를 기억하라**

## 본문

### 1:2–2:16 《카이아즘》
- A **야곱 족속에게 인정받지 못하는** 만군의 여호와(1:2–5)
- B **제사장들에게 더럽혀진** 만군의 여호와(1:6–14)
- B′ **제사장들을 심판하시는** 만군의 여호와(2:1–9)
- A′ **야곱의 장막을 심판하시는** 만군의 여호와(2:10–16)

### 1장
- **1:2–5 “주께서 어떻게 우리를 사랑하셨나이까?”** — 백성들에게 인정받지 못하심 (야곱을 사랑하고 에서를 미워함 — 에돔의 멸망이 증거).
- **1:6–14 “우리가 어떻게 주의 이름을 멸시하였나이까?”** — 제사장들에게 멸시받으심 (눈먼 것, 저는 것, 병든 것을 드림; “그것을 너희 총독에게 드려 보라”).
- **이방 민족에게서 높임받으시는 여호와** — 1:5, 11, 14 (“해 뜨는 곳에서부터 해 지는 곳까지의 이방 민족 중에서 내 이름이 크게 될 것이라” — 1:11).

### 2:1–16
- **2:1–9 제사장을 심판하심**: “듣지 아니하고, 마음에 두지 아니하고, 내 이름을 영화롭게 하지 아니하면” → **복 ⇒ 저주** / **레위와 세운 나의 언약 = 생명과 평강의 언약**(민 25:11–13 비느하스) / **하나님을 경외 ↔ 사람에게 치우치게 함** / 모든 백성 앞에서 멸시와 천대를 당하게 하심.
- **2:10–16 백성을 심판하심**: 자기 형제에게 거짓을 행하여 **언약을 욕되게 함** / **이방 신의 딸과 결혼** / 야곱의 장막 가운데서 끊어버릴 것 / **눈물·울음·탄식 = 이방 신을 섬기는 예배 방식**(강의 해석) / **경건한 자손(= 하나님의 자손)**(2:15).

### 2:17–3:15 성전에 임하시는 언약의 사자
- 틀(A…A): **2:17 “정의의 하나님이 어디 계시냐”** … **3:13–15 “하나님을 섬기는 것이 헛되니”** — 백성의 냉소로 감쌈.
- **3:1–6 언약의 사자가 임하실 것** — **예배의 회복을 위해** 임하심(레위 자손을 금은같이 연단, 3:3) / **심판하기 위해** 임하심(3:5). (3:1 “내가 내 사자를 보내리니 그가 내 앞에서 길을 준비할 것이요” → 세례 요한, 막 1:2 — 보충)
- **3:7–12 “내게로 돌아오라”** — 십일조와 봉헌물, 하늘 문을 열고 복을 쌓을 곳이 없도록.

### 3:16–4:6 율례와 법도를 기억하라
- **여호와를 경외하는 자**: **기념책**에 기록될 것 / **특별한 소유** — “내가 정한 날에 그들을 나의 특별한 소유로 삼을 것” / **공의로운 해가 떠올라 치료하는 광선을 비출 것**(4:2).
- 악인은 발바닥 밑의 재와 같을 것.
- **마지막 경고(4:4–6)**: 모세의 율법을 기억하라 / 엘리야를 보내리니 아버지의 마음을 자녀에게, 자녀들의 마음을 아버지에게 돌이키게 하리라 (→ 눅 1:17 세례 요한 — 보충). **구약의 마지막 말씀 → 신약(언약의 사자)으로 연결**.
