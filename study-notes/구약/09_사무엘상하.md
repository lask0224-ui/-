# 사무엘상·하

> 출처: [삼] `구약 자료/9.사무엘 상& 10.사무엘 하.pdf` — “The Bible School”, 46쪽 슬라이드 (원본 추출, 모든 쪽 텍스트 있음). 지도 2장(p30 사울과 블레셋 전투·믹마스 전투, p33 다윗의 도피 경로)은 이미지로 확인.
> 관련: 사사기–사무엘 병행 구조(삿 13–삼상 7)는 `07_사사기.md`, 제사장 직분의 변화(엘리 → 사독)는 `03_레위기.md`.

## 표제

- **“사람을 공의로 다스리는 자, 하나님을 경외함으로 다스리는 자”(삼하 23:3)**

## 역사서 이해 (도입)

- 역사서 = 여호수아~역대기 12권. **Key word = 하나님의 주권.** 역사의 이해는 **언약을 통해서**.
- 두 종류의 언약:
  - **일방적(맹세) 언약**: 아브라함(창 12; 15; 17; 22장), 이삭(26장), 야곱(28장). 창 15:5 “뭇별을 셀 수 있나 보라”.
  - **조건적(행위) 언약**: 시내산 언약(출 19–24) — 책임과 의무가 있음, **회막 = 언약 갱신**의 장소.
  - **다윗 언약(삼하 7장) = 일방적 언약 + 조건적 언약**.
  - (창세기 강의의 세 분류 — 평등/종주권/약속 — 와 용어가 다름 → `00_모세오경_개관.md`)

## BRI

- **이름**: 히브리 성경 “쉬프뤠 사무엘”(한 권) → 70인역이 모음을 넣으며 상·하로 나눔. 70인역에서 사무엘서 = **제1·2 왕국서**, 열왕기 = **제3·4 왕국서**.
- **저자: 사무엘 / 나단 / 갓**
  - 삼상 10:25 사무엘이 나라의 제도를 **책에 기록**하여 여호와 앞에 둠 / 삼상 25:1 사무엘의 죽음(이후는 다른 사람) / **대상 29:29 다윗의 행적은 선견자 사무엘, 선지자 나단, 선견자 갓의 글에 기록**.
  - 선견자 = 히 **라아**(보다, 조사하다; 삼상 9:9) / 선지자 = 히 **나비**(대언자). 선견자 = 선지자(삼상 9:9; 삼하 24:11; 왕하 17:13).
  - 갓: 첫 등장 삼상 22:5, 마지막 삼하 24:11. 나단: 첫 등장 삼하 7:2, 마지막 왕상 1:45.
  - 사무엘: 마지막 사사, 선지자, 왕정의 기반을 세운 사람, 사울과 다윗에게 기름부음.
- **기록 시기**: 삼하 24장 = 다윗 통치 말기(BC 970). 솔로몬의 이름은 나오지만 즉위는 없음. 분열을 암시하는 구절(유다와 이스라엘; 삼상 27:6 “시글락이 **오늘까지 유다 왕**에게 속하니라”) → BC 930 직후 설도 있으나, 반론: 삼하 3:1(사울의 집과 다윗의 집의 전쟁), 5:5 다윗 때에도 이미 이스라엘/유다로 나누어 설명 → **BC 970 다윗의 죽음 이전**.
- **수신자**: 다윗 통치 말기의 사람들 — 다윗의 왕권이 위기에 처했을 때(**압살롬의 반역**, 전염병으로 **7만 명** 죽음).
- **중요 연대**: 사무엘 출생 BC 1100 / 아벡 전투 1075(삼상 4장) / 미스바 전투 1055(삼상 7장) / 사울 즉위 1050, 죽음 1010 / 다윗 출생 1040 / 다윗 즉위 1010 — 헤브론 1010–1003, 예루살렘 1003–970.
- **쓰여진 이유**: 신정 정치에서 왕정 정치로의 전환 과정 / **하나님께 합당한 왕은 누구인가?** / 사울은 어떤 왕인가? / 다윗은 어떤 왕인가? / **다윗이 받던 오해를 풀어 주기 위해**.
- **구조**:
  - 인물별: 엘리와 사무엘(엘리의 죽음) → 사무엘과 사울 → 사울과 다윗(사울의 죽음). ✓ **죽음 = 하나님과의 단절**.
  - 시대별: 신정 정치와 왕정 정치(= 하나님을 버림).

## 사무엘상

- **1:1–2:11 한나와 사무엘의 출생**: 에브라임 산지 라마다임소빔의 엘가나 — **대상 6:22–28 레위의 아들 그핫 자손**(→ `03_레위기.md` 도표: 이스할 계열). 한나 = “은총”. 여호와께서 임신하지 못하게 하심(5).
  - **한나와 룻 비교**:

| 한나 | 룻 |
|---|---|
| 자식이 없음(2) | 남편이 없음 |
| 여호와께서 임신하지 못하게 하심(5, 6) | 여호와께서 징벌하셨고 전능자가 괴롭게 함(나오미) |
| 브닌나가 심히 격분하게 함(6) | 이삭을 주워 생계 |
| 여호와께 기도하고 통곡(10) | 여호와의 말씀에 순종 |
| 서원(11) | — |
| 여호와께서 생각하심(19) | 여호와께서 임신하게 하심 |
| 사무엘 = “하나님께서 들으셨다” | 다윗의 할아버지 오벳 → 다윗 = “사랑받는 자” 또는 “두목” |

  - 1:21–28 사무엘을 드림 ↔ 2:12–17 “죄가 여호와 앞에 심히 컸다”. 한나의 기도(2:1–11): 감사·기쁨, **하나님의 하나님 되심 & 주권**.
- **2:12–36 엘리의 아들과 사무엘** (교차): A 엘리 아들들의 죄악(12–17) / B 여호와의 축복(18–21) / **C 하나님의 결심(22–25)** / B′ 여호와와 사람들에게 은총을 받은 사무엘(26) / A′ 엘리 가문의 심판(27–36).
- **3:1–4:1a 엘리에서 사무엘로**: “여호와의 말씀이 **희귀**하여 이상이 보이지 않았더라”(1) / 엘리의 눈이 점점 어두워 감(2) / “**하나님의 등불은 아직 꺼지지 아니하였으며**” 사무엘은 궤 있는 전 안에(3) / 19–4:1a 말씀으로 자기를 나타내심.
- **4:1b–7:17 하나님 vs 다곤** (교차):
  - A 아벡 전투 — “**그것(궤)으로 우리를 구원하게 하자**”(4:1b–10)
  - B 엘리와 아들들의 죽음(4:11–18)
  - C **이가봇 — 하나님의 영광이 떠났다**(4:19–22)
  - **D 하나님 vs 다곤(5:1–12)**
  - C′ 여호와의 궤가 돌아옴(6:1–18)
  - B′ 벧세메스 사람들의 죽음(6:19–7:2)
  - A′ 미스바 전투 — “**여호와께 부르짖어 우리를 구원하게 하소서**”(7:3–17)
  - (관찰) A(궤를 부적처럼) ↔ A′(여호와께 부르짖음)의 대조.
- **8장 왕을 구하는 이스라엘**: “모든 나라와 같이 우리에게 왕을 세워 다스리게”(4–5) ↔ 삿 2:16–18 사사의 역할. 10–18 **왕의 제도**(아들·병거·말, 밭, 무기, 딸은 향료 만드는 자, “너희가 그의 종이 될 것”), 18 경고.
  - **신명기의 왕의 규례(신 17:14–19)**: 여호와께서 택하신 자 / 이스라엘 민족 중에서 / **병마를 많이 두지 말라**(힘에 의존하지 말라 = 시 20:7) / **아내를 많이 두지 말라**(백성의 삶을 존중) / **은금을 쌓지 말라**(재물에 마음을 빼앗기지 말라) / 레위 사람 앞에서 **율법서를 베껴 쓰고** / 평생 곁에 두고 읽어 **여호와를 경외**. (→ 열왕기 솔로몬 평가의 기준)
- **9:1–10:27 이스라엘의 왕 사울**: 기스의 아들, 준수한 소년, 어깨 위만큼 큼 / 선견자를 찾아감 / “내 백성 이스라엘의 지도자로 삼으라” / 기름부음(9:22–10:1) / **세 가지 징조**(라헬의 묘실에서 두 사람, 벧엘로 올라가는 세 사람, 하나님의 산에서 선지자 무리) / “**사울도 선지자들 중에 있느냐**”(10:11; 19:24) / 미스바에서 왕으로(17–27).
- **11장 사울의 승리**: 암몬 — “하나님의 영에 크게 감동되매”(6[자료 표기 7]) → 길갈에서 “나라를 새롭게 하자”, 크게 기뻐함.
- **12장 왕정 제도 승인식**: 사무엘의 청렴(1–5) / **역사적 서언**(6–12, 조약 형식) / 여호와를 경외하여 섬기라(13–25) — **왕을 구한 일 = 여호와의 목전에서 범한 죄악**, 그러나 “**여호와께서는 자기 백성을 버리지 아니하실 것**”.
- 13:1–14:52 사울과 블레셋(지도: 믹마스 전투, 사울의 군대·요나단의 군대·블레셋 주둔지·길갈).
- **15장 사울의 불순종**: 아말렉을 진멸하라 → 좋은 것을 남김(9) → **하나님의 후회(나함 = 유감으로 여기다)**(10–11). (창 6:6 토브→나함과 같은 단어 — `01_창세기.md`)
- **16장 기름부음 받는 다윗**: 여호와의 영에 크게 감동 ↔ 여호와께서 부리시는 악령이 사울에게(14–23).
- 19:18–27:12 **다윗의 도피** (번호 경로 지도: 라마(사무엘의 피신처) → 놉(아히멜렉이 떡과 칼) → 가드 → 아둘람·그일라 → 모압 미스바(부모 피신) → 헤렛 수풀 → 십 광야 → 마온 광야 → 엔게디(사울을 살림) → 갈멜(아비가일) → 다시 가드 → 시글락. 번호와 지명의 1:1 대응은 지도상 배치로 읽은 것이라 일부 불확실)
- **31장 사울의 죽음** ↔ **대상 10:13–14**: “여호와의 말씀을 지키지 아니하고 **신접한 자**에게 가르치기를 청하고 **여호와께 묻지 아니하였으므로**.”
- **사울과 다윗 비교**:

| | 사울 | 다윗 |
|---|---|---|
| 지파 | 베냐민(부잣집, 9:1) | 유다(16:1), 양 치는 자 |
| 기름부음 | 10:1 | 16:13 |
| 신분 | 왕(10:24) | 쫓겨난 천부장 |
| 전쟁 | 승리(14:47–48) | 승리(17장, 23장…) |
| 따르는 자 | 힘센 사람, 용감한 사람(14:52), 군대 | **환난 당한 자, 빚진 자, 마음이 원통한 자**(22:2) |
| 죄 없는 자에 대한 태도 | 제사장 아히멜렉과 자녀들을 죽임(22:16–19) | 나발을 죽이려다 **멈춤**(25:28–33) |
| 위급할 때 | **하나님을 버림**(28:7 신접한 여인) | **여호와를 찾음**(23:2; 30:6) |
| 경외 | **사람을 두려워함**(15:30; 18:12) | **여호와를 경외**(17장; 24:6; 26:9–11) |

## 사무엘하

- **1:1–4:12 사울의 집과 다윗의 전쟁** (교차):
  - A 1:1–17 사울의 죽음
  - B 1:17–27 다윗의 애가(사울·요나단)
  - C 2:1–11 유다 왕 다윗 / 이스라엘 왕 이스보셋
  - D 2:12–32 유다와 이스라엘의 전쟁
  - **F 3:1–11 “사울의 집은 점점 약하여 가고 다윗의 집은 점점 강하여 가니라”**
  - D′ 3:12–21 유다와 이스라엘의 언약
  - C′ 3:22–30 요압(유다)과 아브넬(이스라엘)
  - B′ 3:31–40 다윗의 애가(아브넬)
  - A′ 4:1–12 이스보셋의 죽음
- **5장 이스라엘 왕 다윗**: 헤브론에서 모든 장로가 세움 / 헤브론 7년 6개월, 예루살렘 33년 / 예루살렘 점령 = 다윗성 / “만군의 여호와께서 함께 계시니 점점 강성” / **5:12 빈칸 질문**: “다윗이 ______ 알았더라” — (본문: 여호와께서 자기를 이스라엘 왕으로 세우신 것과 그 나라를 높이신 것을)
- **6장 하나님의 궤**: 3만 명(대상 13:1–3 제사장과 레위인 포함) / 궤 = “그룹들 사이에 좌정하신 만군의 여호와의 이름으로 불리는 것” / **베레스웃사**(6–11) ↔ 삼상 6:20 “누가 능히 서리요” / 다윗 성에 들어옴(12–23).
- **7장 다윗 언약**:
  - 다윗의 계획(1–3): 하나님이 거하실 **처소**를 건축 ↔ 하나님의 계획(4–17): **다윗의 집**을 건축 (“집”의 이중 의미).
  - 12–16 “네 집과 네 나라가 내 앞에서 영원히 보전되고 네 왕위가 영원히 견고하리라.”
  - 18–29 다윗의 고백: “**주 여호와여**” = **아도나이 야훼**(18, 19, 20, 22, 28, 29) / “**종**의 집” = **에베드**(19–29 반복) / 19 “이것이 사람의 법이니이다” / 28–29 “말씀하셨사오니… 영원히 복을 받게 하옵소서”.
- **8장 다윗의 전쟁**: “다윗이 어디로 가든지 여호와께서 이기게 하셨더라”(6, 14) / 15 **정의와 공의**를 행함.
- **9장 요나단의 언약을 기억함**: “사울의 집에 아직 남은 사람이 없느냐… **하나님의 은총(헤세드)**을 베풀고자” / 므비보셋이 항상 왕의 상에서 먹음.
- **11–12장 다윗의 죄** (교차): A 11:1 전쟁 중(암몬) / B 11:2–5 밧세바와 간음 / C 11:6–27 우리아를 죽임 / **D 12:1–15a 하나님의 책망(나단)** / C′ 12:15b–23 아이가 죽음 / B′ 12:24–25 밧세바와 동침(솔로몬 출생) / 12:26–31 전쟁 승리.
- **13–18장 압살롬의 반역**: 암논이 다말을 욕보임 → (2년 후) 압살롬이 암논을 죽임 → (3년) 그술에서 돌아옴 → 2년간 왕을 보지 못함 → (4년 준비) 반역 → 18:9–15 압살롬의 죽음. **다윗의 태도**: 15:25–26(궤를 돌려보내며 “주의 뜻대로”), 16:10(시므이의 저주를 받아들임).
- **21–24장 부록 — “하나님을 경외함으로”** (교차): A 21:1–14 사울의 죄, 3년 기근 → **기도를 들으심** / B 21:15–22 다윗의 부하들 / **C 22:1–23:7 다윗의 노래** / B′ 23:8–39 다윗의 부하들 / A′ 24장 다윗의 죄, 7만 명이 죽음 → **기도를 들으심**.
- **22장 다윗의 노래** (교차): A 1 구원하신 날(현재) / B 2–4 나의 반석, 구원의 뿔 / C 5–20 환난 중에 구원 / **D 21–25 다윗의 공의 ↔ D′ 26–28 하나님의 공의** / C′ 29–46 원수를 멸하심(하나님과 동행) / B′ 47–49 나의 반석 / A′ 50–51 기름부음 받은 자에게 인자를 영원히(미래적 간구). (시 18편과 같은 노래 — 강의안에 명시 안 됨)
