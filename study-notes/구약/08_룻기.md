# 룻기

> 출처: [삿A] `구약 자료/7.사사기& 8.룻기.pdf` 45–55쪽 (“2023 TBS 구약2 룻기 HS.P”) · [삿B] 2025년판 4분할(이미지로 렌더링해 확인 — 2023년판과 동일, 각 교차구조의 중심을 빨간색으로 강조).

## 표제 · 중심 주제

- 표제: **“신실한 하나님의 사람들로 세워지는 다윗 왕조”**
- 중심 주제: **하나님이 경건한 이스라엘 사람 보아스와 이방 여인 룻을 통해 다윗을 예비하심.**
- 쓰인 이유:
  1. **다윗의 계보를 설명, 다윗 왕의 정통성을 변호**
  2. 원독자가 보아스와 룻처럼 **하나님을 선택하고 따르는 삶**을 살라는 교훈
  3. **의로운 자에게 보응하시는 하나님**을 가르쳐 신뢰하게 함

## BRI

- **저자: 사무엘**(추정): 이스라엘 전통을 잘 앎(4:12–13, 4장 ↔ 신 25:5–10 계대 결혼) / 베레스에서 다윗까지 계보(4:17–22)를 앎 / 오벳을 다윗과 연결 / **다윗의 아들 솔로몬은 언급하지 않음**. 외증: 탈무드 — 룻기와 사사기를 사무엘이 기록.
- **기록 시기**: “사사들이 치리하던 때에”(1:1), 족보가 다윗에서 끝남, 사무엘은 사울과 다윗에게 기름부은 선지자 → **사무엘이 다윗을 옹호하려는 의도** → 사울 통치 중·사무엘 사망 전, 다윗 즉위 전: **BC 1050–1010**.
- **수신자**: 사사기와 같음 — 사울이 불순종하기 시작한 때부터 사무엘 사망 전, 다윗 즉위 전의 이스라엘(사울·다윗 포함).
- (연결) 사사기 17–21장의 두 레위인 이야기가 모두 **베들레헴**과 얽혀 있고, 룻기는 **베들레헴**에서 다윗 왕조를 준비함 → `07_사사기.md` 병행 도표. (해석)

## 장별 구조 (모두 카이아즘/병행)

### 1장 — 모든 것을 잃은 나오미, 신실한 며느리 룻과 돌아오다 (카이아즘)
- A 나오미의 가족이 유다 베들레헴을 떠나 모압에 거주 1:1–2
- B 나오미 고통의 이유 — 모두 잃음(남편, 두 아들) 1:3–7
- **C <교환/진전> A 나오미: “돌아가라”(×3) / B 며느리의 반응 → “죽는 일 외에는 어머니를 떠나지 않을 것, 어머니의 하나님이 나의 하나님” 1:8–17** (중심)
- B′ 나오미 고통의 이유 — “전능자께서 나를 심히 괴롭게 하셨음” 1:19–21
- A′ 나오미와 모압 여인 룻이 모압에서 베들레헴으로 돌아옴 1:22

### 2장 — 은혜를 행한 룻, 하나님께서 온전한 상 주시길 원함 (카이아즘)
- A 모압 여인 룻 — 시어머니 부양(이삭줍기), **우연히** 엘리멜렉의 친족 보아스의 밭에서 2:1–3
- B 사환들 “여호와께서 당신에게 복 주시기를” / 보아스 “누구의 소녀냐?” 2:4–7
- C 보아스가 룻에게 베푼 은혜 2:8–10
- **D 은혜를 행한 룻 — “여호와께서 온전한 상 주시기를 원하노라” 2:11–12** (중심)
- C′ 보아스가 룻에게 베푼 은혜 2:13–17
- B′ 시어머니 “오늘 어디서 일했어?” / “너를 돌본 자가 여호와께 복 받기를” 2:18–20a
- A′ 룻 — 시어머니 부양, **기업 무를 자 보아스**, “살아 있는 자와 죽은 자에게 은혜를 베풂” 2:20b–23

### 3장 — 룻이 베푼 인애로 여호와께서 복 주시길 (카이아즘)
- A 시어머니가 친족 보아스를 통해 룻을 복되게 하려 함 3:1–2
- B 준비하고 타작마당에 내려가 그에게 보이지 말라 3:3
- C 룻이 명대로 보아스의 발치에 누움 3:4–8
- D “당신은 **기업 무를 자**” 3:9
- **E “네가 베푼 인애 — 여호와께서 네게 복 주시기를” 3:10–11** (중심)
- D′ 기업 무를 자의 책임을 이행하리라 3:12–13
- C′ 새벽까지 발치에 누움 3:14a
- B′ 타작마당에 들어온 것을 사람들이 알지 못하게 3:14b–15
- A′ 시어머니 — 룻이 복 받기를 기다림 3:16–18

### 4장 — 보아스가 모압 여인 룻을 통해 죽은 자의 기업을 회복함 (병행)

| | 전반 | 후반 |
|---|---|---|
| A 첫 번째 기업 무를 자 | 4:1 | 4:6 |
| B 증인들 | 4:2 | 4:7–8 (증명) |
| C 엘리멜렉의 소유지 | 나오미가 팔려 함 4:3 | 보아스가 나오미의 손에서 엘리멜렉·기룐·말론의 모든 것을 삼 4:9 |
| D 죽은 자의 기업 | 죽은 자의 아내 룻에게서 기업을 세워야 함 4:4–5 | 말론의 아내 룻을 사서 죽은 자의 기업을 세움 4:10–22 |

- (관찰) 세 장의 중심이 모두 **복을 비는 말**(2:12, 3:10 / 1장은 “어머니의 하나님이 나의 하나님”) — 헤세드(인애)와 보응의 주제. 민수기의 **고엘(기업 무르기) 제도**와 연결(민 27; 36 → `04_민수기.md`, 레 25장 → `03_레위기.md`).
