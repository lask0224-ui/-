## 중심 내용 · 쓰인 이유

- 중심 내용: **보이지 않으시는 하나님께서 자신의 백성들을 향하여 섭리와 은총을 베푸신다.**
- 쓰인 이유: ① 하나님이 **보이지 않지만 여전히 주권자**되심을 깨닫게 ② **페르시아에 남아 있는 유대인들**에게 하나님이 여전히 지키신다는 것을 ③ **부림절**을 기억하고 계속 지키도록.

## 구조 — “반전의 책”

- **7장 중심 교차(전환)**:
  - A 1–2장 에스더가 왕비가 됨
  - B 3장 하만이 높아짐 — 유대인 진멸 조서
  - C 4–5장 에스더의 결단과 하만의 분노
  - **D 6장 왕의 잠 못 드는 밤 — 모르드개가 존귀케 됨** (전환점)
  - C′ 7장 에스더의 구원 요청과 하만의 죽음
  - B′ 8장 모르드개가 높아짐 — 유대인 대적 진멸 조서
  - A′ 9–10장 유대인의 대적이 말살됨
- **반전 대조표** (3장 ↔ 8장): 하만이 총리(3:1) ↔ 모르드개가 총리(10:3) / 왕이 하만에게 인장 반지(3:12[10]) ↔ 모르드개에게(8:2) / 서기관 소집(3:12 ↔ 8:9) / 진멸 조서를 쓰고 인침(3:12 ↔ 8:10) / 유대인과 처자를 죽이라 ↔ 대적과 처자를(3:12 ↔ 8:11) / 초본 반포(3:14 ↔ 8:13) / 역졸이 급히 나감(3:15 ↔ 8:14) / **수산성이 어지러움(3:15) ↔ 기뻐함(8:15)** / 모르드개가 굵은 베와 재(4:1) ↔ 2인자의 조복(8:15) / 애통하고 금식(4:3) ↔ 기뻐하며 잔치(8:17).
- **잔치의 책**: “잔치”는 구약 43번 중 **19번이 에스더서**. 잔치로 짜인 교차: 왕이 귀족을 위해(1:2–4) / 수산 사람들을 위해(1:5–8) / 에스더 즉위 잔치(2:18) / 에스더의 첫 잔치(5:1–8) / **E 왕의 잠 못 이루는 밤(6장)** / 에스더의 두 번째 잔치(7:1–9) / 모르드개의 등극 축하(8:17) / 전국 유대인의 부림절 첫 잔치(9:17, 19) / 수산 유대인의 두 번째 잔치(9:18).
- **다트(דָּת) — 법령·포고·규정**: 구약 20번 중 **18번이 에스더서**. 페르시아 = “법의 나라”(고레스·다리오·아닥사스다의 조서), **법은 수정 불가**(단 6:8; 에 8:8). 1:8 어전 음주법이 있지만 마음대로 마시는 잔치.
- **정경 논란**: 하나님이 언급되지 않음 / 신구약에서 한 번도 인용되지 않음 / 토라와 같은 권위 인정 vs 토라에 없는 부림절 불인정 / 유대적 성향 / 우연한 사건들 / 잔인한 살육 장면.

## 본문

- **1장**: 127지방(인도~구스), **아하수에로 3년 그리스 원정 준비**, 180일 잔치 — 목적: 왕의 위대함 과시, 신하의 충성 유도. **와스디 폐위** 병행: A 왕이 내시 7명에게 명령 / B 왕후가 거절 / C 왕이 진노 // A′ 현자 7명에게 물음 / B′ 거절은 관리와 백성에게도 잘못 / C′ 폐위.
- **2장**: “그 후에”(4년 후 — **그리스 원정 패배 후**) 왕비 선발, 조건은 “아리따운 처녀”. 모르드개가 “딸같이 양육”(7, 15).
  - **은혜와 사랑을 받는 에스더**: 헤개가 **은혜(헤세드)**(2:9) / 모든 보는 자에게 **사랑(헨)**(2:15) / 왕이 더 사랑하여 **은총(헤세드)**(2:17[표기 2:15]) / 뜰에 선 에스더가 사랑스러워(헨) 금규(5:2) / “왕의 은혜를 입었으면”(5:8; 7:3; 8:5). **HINT?** — 창 39:21 “여호와께서 요셉과 함께하시고 인자를 더하사 간수장에게 **은혜**를 받게” / 단 1:9 “하나님이 다니엘로 환관장에게 은혜와 긍휼을 얻게” → **하나님의 이름 없이 하나님의 손길을 암시**.
- **2–3장 대비**: 왕의 생명을 구한 모르드개(2:19–23) → **보상을 받지 못함** / 하만의 지위가 높아짐(3:1) → **이유 없음**.
- **3장 “600년 세월이 흘러 다시 만난 악연”**: 모르드개 = 유대인, 베냐민, **기스의 증손**(2:5) vs 하만 = **아각 사람** 함므다다의 아들(3:1) = 아말렉의 후예(삼상 15장).
  - **아말렉 이야기의 흐름**: 신 25:18 “피곤할 때 뒤에 떨어진 약한 자들을 쳤고 하나님을 두려워하지 아니하였느니라” → 르비딤 전투(출 17:14, 16 “아말렉을 없이 하여 천하에서 기억도 못하게… 여호와가 대대로 싸우리라”) → 발람의 예언(민 24:20 “그의 종말은 멸망”) → **사울의 불순종**(삼상 15장, 아각 왕과 가축을 살려 줌 — 하나님의 후회) → **모르드개·에스더의 순종** → 에스더서에서 아말렉이 진멸됨 = **하나님의 말씀의 성취**.
  - **모르드개가 꿇어 절하지 않은 이유**(3:2, 5): “꿇어 절하다” = **카라 샤하** — 대하 7:3; 29:29; 시 22:29; 95:6에서 **오직 하나님께 경배할 때** 쓰는 표현, 사람에게 쓰이지 않음. 모르드개가 자신이 유대인임을 밝힘(3:4). “유다인 모르드개”(5:13; 6:10; 8:7; 9:29, 31; 10:3).
  - 유대인 진멸의 날 = **아달월(12월)**, **부르(제비)**로 결정(3:7). 하만의 고발(3:8–9): “한 민족”(유대인이라고 대놓고 말하지 않음), “**그 법률(다트)이 만민의 것과 달라 왕의 법률(다트)을 지키지 않음**”, 왕에게 무익, **1만 달란트(제국 1년 예산의 60%)**.
  - 조서 반포 **1월 13일 — 유월절 전날**(3:12), 멸절의 날 12월 13일. “왕과 하만은 앉아서 술을 마시고 수산성은 어지럽더라”(3:15).
- **4장 모르드개의 요청과 에스더의 결단** (교환 A 모르드개 / B 에스더): 애통(1–4) / 물음(4–5) / **개입 요구**(6–8) / **거절 — 부름 없이 나아가면 사형인 법(다트)**(9–11) / **결단 촉구**(12–14) / **결단**(15–16) / 모르드개가 따름(17) / 에스더가 나아감(5:1–4).
  - 12–14 결단 촉구: 유대인의 정체성을 잊지 마라 / 하나님은 반드시 구원하신다 / **“네가 왕후의 자리를 얻은 것이 이때를 위함이 아닌지 누가 알겠느냐”** = 수사 의문문 → “이때를 위함이다!”
  - **“죽어야 사는 3일”**: A 3일 금식(16a) / B “규례(다트)를 어기고 나아가리니 **죽으면 죽으리이다**”(16b–17) / A′ 3일 후에 나아감(5:1–4) — 이삭을 바치는 아브라함(여호와 이레), 예수 그리스도의 죽음과 부활(3일)과 연결.
  - **페르시아의 법(다트) vs 하나님의 법 — 유대인의 정체성**: 4:16의 다트와 3:8의 다트를 대비.
- **5장**: 금규(5:2 헨). “**그대의 소원이 무엇이냐… 나라의 절반이라도**” 3번(5:3, 6; 7:2) / “왕의 목전에서 은혜를 입었으면” 3번(5:8; 7:3; 8:5).
  - 5:9–14 교차: A 하만이 즐거이 나옴 / B 모르드개에게 분노 / C 자기 높아짐을 자랑 / **D 에스더가 왕과 하만만 잔치에 초대** / C′ 모르드개가 살아 있는 한 만족 없음 / B′ 모르드개를 매달 나무 / A′ 즐거이 잔치에 가려 함.
- **6장 왕의 잠 못 이루는 밤**:
  - 다니엘의 세 친구(단 3장, 풀무불)·다니엘(단 6장, 사자굴)·모르드개(에 5–6장, 장대)의 비교: 앞의 둘은 “하나님께서 천사를 보내 구해 주심”(단 3:25; 6:22), 모르드개는 **“우연?” — 왕의 잠 못 이루는 밤**.
  - “그날 밤에”(에스더의 두 번째 잔치 전날, 장대를 만든 그날), “왕이 잠이 오지 아니하므로” = **나다드**(도망하다, 떠나다) → **왕의 잠이 달아났다**. ↔ 시 127:2 “여호와께서 그의 사랑하시는 자에게는 잠을 주시는도다.”
  - 모르드개는 왕처럼 존귀케 된 후 **다시 대궐 문으로** / 하만은 수치를 안고 집으로 → 6:13 “모르드개가 과연 유다 사람의 후손이면… 분명히 그 앞에 엎드러지리이다.”
  - 사건 흐름도: 에스더 왕비 → 모르드개가 역모를 막음 → 하만의 멸절 계획 → 에스더의 결단·중보 → 첫 잔치 → 장대 → **하나님께서 일하심**.
- **7장 두 번째 잔치**: “왕후 에스더” ×4(1, 2, 3, 7) / 세 번째로 소원을 묻는 왕 / “은혜를 입었으며” = 겸손 / **자신과 민족을 동일시**.
  - **1–2장 ↔ 7–8장 병행**: A 왕이 분노 / B 와스디 폐위 ↔ **하만 처형** / C 노가 가라앉음 / D 에스더가 왕후 ↔ **모르드개가 왕 앞에**.
- **8장**: 아직 구원이 이루어지지 않음 — 에스더의 **눈물의 간청**(8:3), 세 번째 간청(8:5)은 앞의 두 번(5:8; 7:3)보다 조건이 넷으로 늘어남. 하만의 조서 ↔ 모르드개의 조서 대조표(같은 날 12월 13일, 하만 = 모든 유다인을 죽이라 / 모르드개 = **모여서 스스로 생명을 보호하라**, 치려는 자들을). 8:17 “본토 백성이 유다인을 두려워하여 **유다인 되는 자가 많더라**.”
- **9장**: 모든 민족이 두려워함 = **파하드**(공포) ↔ 신 11:25. **“그들의 재산에는 손을 대지 아니하였더라”**(9:10, 15, 16 — 3번; 3:13 하만의 조서 “재산을 탈취하라”와 대조, 사울이 전리품을 취한 삼상 15장과도 대조 — 해석). **부림절 제정**(20–32): 잔치, 예물, **가난한 자를 구제** — 슬픔·애통 → 평안·기쁨·길한 날.
- **9:29 에스더의 마지막 명령**: “**아비하일의 딸 왕후 에스더**와 유다인 모르드개가 전권으로 글을 써서” → **에스더의 정체성**(왕후이자 유대인).

## 신학적 연결 (강의 결론부)

- **옛 언약 ↔ 새 언약**: 시내산 언약 — 출 17장 아말렉과의 전투 승리, 출 19장 돌판·십계명·언약궤 / 새 언약 — 렘 31장 하나님의 말씀이 마음에, 사람 / 에스더 9장 대적과의 전투 승리.
- **하나님의 영광**: 모세의 성막(출 40:34) → 솔로몬 성전(불, 대하 7:1) → **성전 된 우리 몸(성령의 불, 행 2장)**.
- **마지막 잔치를 소망하며**: 에스더의 잔치 → 예수 그리스도를 통한 구원 → **어린양의 혼인 잔치** (하나님 나라 밖 외인과 대비).
