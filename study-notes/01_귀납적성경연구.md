# 귀납적 성경연구 (방법론)

- 출처: `학습해야할 파일/귀납적 성경연구.pdf` (3.5MB)
- 읽기 상태: 텍스트 읽힘. **본문 속 스크린샷(SBS 차트 사이트 화면, 수평구조 예시 이미지)은 추출되지 않음.** PDF 텍스트 추출 과정에서 문장 부호·괄호 위치가 뒤섞인 곳이 있어 문맥으로 복원함.
- 성격: 더 바이블 미니스트리(더바미, TBS) 간사에게 배운 내용을 작성자가 후배(“장목”)에게 설명하는 개인 정리문. 예시는 “사도행전, 더 바이블 미니스트리 김상민 간사님” 자료를 토대로 함.

## 핵심 원리

- **성경을 성경으로 연구하고, 성경을 성경으로 해석한다.** 그 기초는 “관찰”이다.
- 제주 예래학교, 더 바이블 미니스트리 간사들, 예수전도단(YWAM)에서 쓰는 방법으로 소개됨.
- 이미 아는 책이라도 **최소 5번**은 읽게 되는 방법.

## 단계

| 단계 | 내용 |
|---|---|
| 0) 기도 | 모든 단계 전에 언제나 기도로 시작 |
| 1) 통독 | 가능하면 한 자리에서 한 번에 쭉 읽는다. 첫 통독 때는 아무 표시도 하지 않고 전체 이야기를 숙지 |
| 2) 관찰 | 다시 읽으며 **컬러코딩** + 문학 양식, 역사적 배경 단서, 반복 단어, 주제, 저자/수신자 단서 확인 |
| 3) 수평구조 만들기 | 단락 요약 → 묶기(Seg → Sec → Div) → 책 제목 짓기 → 핵심 구절 찾기 |
| 4) 비유적 표현·언어와 구성의 법칙 찾기 | 수직차트를 위한 준비: 구절 속 비유법·강조법·변화법·수사 기법을 찾고 묶는다 |
| 5) 수직차트 완성 | (문서에 세부 설명 없음) |
| 6) 삶에 적용 | (문서에 세부 설명 없음) |

### 2) 컬러코딩 — 4가지

1. 삼위일체 하나님 (하나님 / 예수님 / 성령님)
2. 시간과 때
3. 장소
4. 사람 이름

- 애매한 시간·장소 표현은 굳이 칠하지 않아도 된다. 한번 칠하면 되돌리기 어려우니 **보편적이고 분명하게 표현된 것부터** 칠한다.

### 3) 수평구조 (SBS 차트)

- 도구: https://www.sbscharter.com (회원가입, 한글 성경 없음 → 작성자는 ESV 사용). 외국인이 만든 무료 공개 사이트.
- 목표: **핵심 구절 찾기**와 **책 제목을 스스로 지어 보기**.
- 단락 요약 규칙 (중요):
  - 한 단락을 **5단어 이하**로 요약.
  - **본문에 적힌 표현 그대로** 쓴다. 예: 행 1:1은 “데오빌로”가 아니라 “데오빌로여”.
  - **본문에 나오는 순서 그대로** 쓴다. 예: “예수께서 성령으로 명하시고 승천하신” (O) / “승천하신 예수께서 성령으로 명하시고” (X).
  - 문장이 되지 않아도 되고 문장 구조를 맞출 필요도 없다.
  - 취지: 성경을 내 입맛대로 고쳐 쓰는 것이 아니라, 요약만 보고도 내용을 알 수 있게 하는 작업.
- 묶기: 의미·내용·하고자 하는 이야기가 비슷한 단락끼리 묶는다. Seg → Sec → Div 순으로 상위 묶음. 제목은 간결하게 쓰되 정해진 틀은 없다.
- 핵심 구절: 보편적으로 정해진 구절이 있다고 한다. **먼저 스스로 정한 뒤** 보편적인 것과 비교하고, 다르면 다시 생각해 본다.
- 결과물: Create Charts → View Horizontal → PDF 또는 Word로 다운로드.

### 수평 vs 수직

- **수평구조** = 큰 책 한 권을 한 문장으로 만드는 작업 (거시).
- **수직구조** = 한 구절 안을 하나하나 뜯어보는 작업 (미시): 비유법, 강조법, 변화법, 수사 기법 등을 찾아 묶는다.

## 주석 작성에 주는 시사점 (해석/추정)

- 사용자가 배운 방식은 **본문 관찰 우선, 본문 표현 그대로, 구조(수평) → 세부(수직)** 흐름이다. 주석도 외부 해설보다 본문 내부의 반복·대조·구조 단서를 먼저 제시하는 결이 맞을 것으로 보인다.
- 다른 TBS 강의자료(예: 디도서)에서 쓰는 관찰 라벨 — (목록), (반복), (대조), (단어), (샌드위치), (교환), (병행), (진전), (전환), (환유), 카이아즘 — 이 4) 단계 “구성의 법칙”의 실제 적용 예로 보인다. → `00_공통_관찰라벨.md`에 따로 정리 예정.
