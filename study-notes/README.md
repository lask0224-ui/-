# 성경 학습 노트

사용자가 배운 성경공부 자료(Google Drive `학습해야할 파일`)를 학습해 정리한 노트다. 목적은 오른쪽 사이드 주석이 달린 **성경 PDF**를 만들 때, 사용자가 배운 해석의 결에 맞춰 주석을 쓰기 위한 기준 자료로 쓰는 것이다.

## 작성 원칙 (사용자 결정, 2026-09-28)

1. **출처 표기**: 항목마다 원자료 약칭([창A], [TBS4] 등)을 붙이고, 각 노트 머리에 약칭과 파일 경로를 적는다.
2. **자료 간 차이**: 두 견해를 모두 기록하고 **최신 강의를 기본값**으로 둔다. 명백한 오타는 교정 의견을 따로 표시한다 → `자료간_차이.md`.
3. **중복 파일**도 다시 읽는다. 단, **단면/4분할 쌍은 하나만**(단면 우선) 읽는다.
4. **학습 순서**: 귀납적 성경연구 → 구약 → 신약.
5. 확인된 사실 / 해석·추정 / 확인하지 못한 것을 구분한다. 노트 안의 “(해석)”, “추정”, “확인하지 못함” 표시가 그 구분이다.

## 읽기 방식

- Drive 읽기 도구(read_file_content)는 **긴 파일을 알리지 않고 잘라낸다**(예: 출애굽기 강의자료 111쪽 중 약 79쪽까지만 반환).
- 그래서 **원본을 내려받아(download_file_content) PyMuPDF로 직접 텍스트를 추출**해 읽는다. 쪽수·글자 수·그림만 있는 쪽을 함께 확인한다.
- 단, 다운로드 도구는 **10MB 초과 파일을 받지 못한다**. 이런 파일은 읽기 도구로만 읽을 수 있어 잘림 여부를 완전히 확인할 수 없다 → `00_파일목록_읽기상태.md`에 따로 표시한다.

## 파일 구성

- `00_파일목록_읽기상태.md` — 127개 학습 파일 목록, 파일별 읽기 상태, 재전송이 필요한 파일
- `01_귀납적성경연구.md` — 방법론
- `구약/` — `00_모세오경_개관.md`, 책별 노트(파일명 번호는 **구약 정경 순서**. 학습은 `구약 자료` 파일의 TBS 과정 번호 순서로 진행)
- `신약/` — 책별 노트(번호는 신약 정경 순서)
- `자료간_차이.md` — 자료 간 불일치와 오기 추정 목록
