## 비평적 방법 (BRI) [고후U p1]

### 1. 저자

- 1) (**바울**)과 (**디모데**)(1:1) [→ 답] — 공동 저작임을 서두에 밝힘.
- 2) ‘나’라고 밝히는 (**바울**)(10:1) [→ 답] — 1인칭 시점(1:15; 2:1 …). 사도행전의 바울과 일치함(11:22–27, 32–33 = 행 9:23–25 다메섹 탈출).
- 디모데를 공동 저자로 적은 이유는 얼마 전 디모데가 방문했기 때문으로 예상됨(고전 4:17; 16:10).
- 결론: 바울 [→ 답].

### 2. 수신자

- (**고린도**)에 있는 하나님의 교회와 (**온 아가야**)에 있는 모든 성도(1:1) [→ 답].

### 3. 기록 시기

- 1) 2차 전도여행 때 (**고린도**)에 방문한 이후 [→ 답].
- 2) 바울이 **마게도냐**에 있었을 때(7:5).
  - 2차 때는 고린도 방문 이후 마게도냐에 간 적이 (**없음**) [→ 답].
  - 3차 여행 중 에베소에서 고린도전서를 써서 보냄 → 그 뒤 **드로아를 거쳐 마게도냐**로 감(2:12–13).
  - 고린도후서는 전서보다 **약 1년 뒤**에 기록됨(8:10; 9:2 “일 년 전부터”).
  - ✅ **확정: 56년 가을경, 마게도냐** → `00_확정연대표.md`
- [고후24]: 드로아 → 마게도냐(2:12–13) / 아시아에서 당한 환난(1:8–9 = 행 19:23–41) / 아시아 → 드로아 → 마게도냐(9:2–4) / 연보는 아가야에서 1년 전부터 준비함(8:10; 9:2; cf. 고전 16:1–4) ⇒ **전서보다 1년 후, AD 54–57**(3차 여행 AD 53–57).

### 4. 기록 장소

- (**마게도냐**)(7:5) [→ 답].
- [고후24]: 2:12–13 드로아에서 디도를 만나지 못함 → 7:5 마게도냐에 이르러 **디도를 만남** → 9:2–4 “마게도냐인들이 나와 함께 가서” ⇒ **마게도냐에서 기록**.

## 본문 [고후24]

### 1장 — 위로하시는 하나님

- 1:1–2 인사.
- **1:3–14 위로하시는 하나님**:
  - “찬송하리로다” = 헬 **율로게토스**, 히 **바라크**(찬송받는).
  - 3–4절 하나님 목록: **우리 주 예수 그리스도의 하나님 / 자비의 아버지 / 모든 위로의 하나님 / 모든 환난 중에 우리를 위로하시는 하나님**.
  - **사도의 고난과 하나님의 위로(4–5)** 《교차》: A 우리의 환난 / B 우리를 위로 / A′ 그리스도의 고난이 우리에게 넘침 / B′ 그리스도로 말미암아 위로가 넘침.
  - **사도의 고난과 성도의 위로(6)** 《교차》: A 우리의 환난 / B 너희의 위로와 구원 / A′ 우리가 위로받는 것 / B′ 너희가 위로받게 하려는 것.
  - **바울의 고난(8–11) = 행 19:21–41(에베소 소동)**: 힘에 겹도록 심한 고난, 살 소망까지 끊어짐, 사형 선고를 받은 줄 앎.
  - **바울의 확신(10)**: 큰 사망에서 **건지셨고, 건지실 것이며, 건지시기를 바라노라**(과거·미래·소망).
  - 바울의 자랑(12–14).
- **1:15–24 방문 계획 변경**:
  - 원안: 아가야 → 마게도냐 → 아가야 → 유대. 변경: (아가야 →) 마게도냐 → 에베소. 변경 이유는 1:23–24(“너희를 아끼려 하여”).
  - 강의안의 변경안 표기 “아가야 → 마게도냐 → 에베소”는 원문 그대로 옮긴 것.
  - **《카이아즘》**: A 1:15–17 계획 변경 / **B 1:18–22 하나님의 신실하심**(예와 아멘) / A′ 1:23–24 변경 이유.
  - ([고후U]가 1:18–22를 삽입 단락으로 본 것과 맞물림.)

### 2–3장 — 그리스도의 향기, 새 언약의 일꾼

- **《교차》 2:1–3:18**: A 근심하게 한 자(2:1–11) / B 그리스도의 향기(2:12–16) / A′ 말씀을 혼잡하게 하는 자(2:17–3:1) / B′ 새 언약의 일꾼(3:2–18).
- **새 언약의 일꾼** (3장 대조표):

| 옛 언약 | 새 언약 |
|---|---|
| 율법의 조문 = 문자, 글 | 영 = 성령 |
| 죽이는 것 | 살리는 것 |
| 영광이 있음(없어질 영광) | 더욱 영광이 있음 |
| 정죄의 직분 | 의의 직분 |

### 4장 — 질그릇 속의 보배

- 1–6 바울의 직분.
- 7–18 **사망은 우리 안에, 생명은 너희 안에**:
  - 10 “항상” — A 예수의 죽음을 몸에 짊어짐은 / B 예수의 생명이 우리 몸에 나타나게.
  - 11 “항상” — A 예수를 위하여 죽음에 넘겨짐은 / B 예수의 생명이 우리 죽을 육체에 나타나게.
  - 12 “그런즉 **사망은 우리 안에서, 생명은 너희 안에서** 역사하느니라”.

### 5장 — 덧입음, 화목

- 5:1–8 “**벗고자 함이 아니요 덧입고자 함이니**” — 덧입다 = **에펜뒤오마이**(겉에 덧입다) → 영혼만의 구원(이원론)이 아니라 몸의 부활로 덧입음 (해석: 고린도 이원론 배경과 연결됨).
- 5:9–10 몸으로 있든지 떠나든지 **주를 기쁘시게** 하는 자.
- 5:11–13 “우리가 다시 너희에게 자천하는 것이 아니요”.
- 5:14–19 한 사람이 모든 사람을 대신하여 죽음 → 새로운 피조물, 화목의 직분.
- 5:20–21 “**너희는 하나님과 화목하라**”.

### 6:1–7:1 — 하나님의 일꾼, 구별된 삶

- 6:1–10 “하나님의 은혜를 헛되이 받지 말라” → **하나님의 일꾼의 역설**(6:8–10):

| ~같으나 | 실상은 |
|---|---|
| 속이는 자 | (참되고) |
| (무명한 자) | 유명한 자 |
| 죽은 자 | 살아 있는 자 |
| 징계받는 자 | 죽임을 당하지 아니하고 |
| 근심하는 자 | 항상 기뻐하고 |
| 가난한 자 | 많은 사람을 부요하게 |
| 아무것도 없는 자 | 모든 것을 가진 자 |

  - 슬라이드 첫 줄은 “속이는 자 | 유명한 자”로 두 짝(속이는 자↔참된 자 / 무명한 자↔유명한 자)을 하나로 줄여 놓음. 괄호 부분은 본문에서 보충함.
- 6:11–7:1 “고린도인들이여” — **대조 5쌍**: 의 vs 불법 / 빛 vs 어둠 / 그리스도 vs 벨리알 / 믿는 자 vs 믿지 않는 자 / 하나님의 성전 vs 우상.
  - [고후U]가 **6:14–7:1도 삽입 단락**으로 분류함.

### 7장 — 디도를 만남

- 7:2–4 “마음으로 우리를 영접하라”.
- 7:5–16 마게도냐에서 디도를 만남 → **하나님의 뜻대로 하는 근심 → 회개에 이르게 함 / 세상 근심 → 사망을 이룸**.

### 8–9장 — 연보

- 8:1–7 **마게도냐 교회의 본**(환난의 많은 시련과 극심한 가난 중에 풍성한 연보).
- 8:8–15 연보의 이유(그리스도의 은혜, 균등하게).
- 8:16–24 연보를 맡은 자들의 보증(디도와 형제들).
- 9:1–5 형제들을 보내는 이유(미리 준비하게).
- 9:6–15 연보의 동기와 목적(즐겨 내는 자, 감사의 넘침).

### 10–13장 — 거짓 사도들과 바울의 자랑

- **거짓 사도들의 주장** — 바울을 이렇게 비난함:
  - 대면하면 유순하고 떠나 있으면 담대함(10:1).
  - 육신에 따라 행하는 자(10:2).
  - 외모가 형편없음(10:7).
  - “편지들은 무게가 있고 힘이 있으나 **몸으로 대할 때는 약하고 말도 시원하지 않다**”(10:10).
  - “교활한 자가 되어 너희를 속임수로 취하였다”(12:16).
- 11:1–4 “나의 어리석음을 용납하라”.
- 11:5–15 “**지극히 크다는 사도들**”.
- 11:16–12:13 바울의 자랑(약한 것들 — 고난 목록, 셋째 하늘, 육체의 가시) → **“내가 약한 그때에 강함이라”(12:10)**.
- **12:14–13장 세 번째 방문**:
  - 12:14 “내가 구하는 것은 너희의 재물이 아니요 **오직 너희**니라”.
  - 12:19 너희의 **덕을 세우기** 위함.
  - 12:20–21 두려워함(다툼, 시기, 분냄 … 회개하지 아니함).
  - 13:1–2 “회개하라” — 세 번째 가는 것.

## 주석용 핵심 메모

- 편지 4통과 방문 3번의 순서표를 기준으로 삼기(현존: 2번째 = 고전, 4번째 = 고후).
- 본서의 역설: **약함 ↔ 강함, 질그릇 ↔ 보배, 사망 ↔ 생명, 근심 ↔ 기쁨**.
- 3부 구조(1–7 / 8–9 / 10–13)와 삽입 단락(1:18–22; 2:14–7:4; 6:14–7:1) [고후U].
- [고후U]의 빈칸 추정값 [→ 답]은 강의에서 확인해야 함.
