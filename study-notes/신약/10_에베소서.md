## 1. 저자 — 바울 [엡 p2–6]

- **① 인종**: 2:11–13 “너희는 그때에 육체로는 이방인” / 2:17 “먼 데 있는 너희” / 3:1 “너희 이방인을 위하여 갇힌 자 된 나 바울” / 2:1–2 허물과 죄로 죽었던 **‘너희’** ↔ 2:3–5 **‘우리도’** 본질상 진노의 자녀 → 저자는 유대인, 수신자는 이방인.
- **② 시간·장소**: 2:13 “이제는 전에 멀리 있던 너희가 가까워졌느니라” / 1:15 “너희 믿음과 모든 성도를 향한 사랑을 나도 듣고”(이방인에게 믿음이 전해짐) / 3:1; 6:20 “**쇠사슬에 매인 사신**” / 3:13 이방인을 위한 여러 환난 → **저자가 감옥에 있음**. 감옥의 특징: 6:19 갇힌 중에도 복음을 전할 수 있음.
- **③ 발신자와 수신자의 관계**: 수신 지역의 구체적 인물이 언급되지 않음 / 공동 발신인이 없음 / 1:15 소식을 들음 / **3:3 “먼저 간단히 기록함”** — 첫 편지가 아님 / 1:16 기도할 때 기억함 / 6:19 자신을 위한 기도를 요청함 / 6:21 **두기고**를 소개함(행 20:4; 골 4:7; 딤후 4:12; 딛 3:12) → 서로 소식을 들으며 편지가 오가는 관계.
- **④ 교사의 권위**: 1:17–19 하나님을 더 알게 되기를 기도함(교사의 태도) / 4:1~ 권하고 명령함 / 4:20 “너희는 그리스도를 그같이 배우지 아니하였느니라”(강의안 “1:20”은 **오기**) ↔ 행 20:17–38.
- **⑤ 사도**: 1:1 하나님의 뜻으로 사도가 됨 / 3:3–4, 8 계시로 비밀을 앎 / 3:6–7 이방인을 위한 복음의 일꾼(갈 2:8–10).
- **⑥ 동역자**: 6:21–22 두기고를 보낼 수 있는 권위.
- 결론: 1:1과 3:1에서 이름을 밝히고 1인칭을 씀 ⇒ **바울**.
  - 외증: 폴리갑, 오리겐, 이레니우스, 알렉산드리아의 클레멘트, 터툴리안.

## 3. 수신자 — 에베소를 중심으로 한 아시아의 성도 [엡 p10–12]

- ① 인종: 이방인(2:11–12; 3:1). ② 시간: “이제는”, “전에” 멀리 있던 너희(2:13).
- ③ 인물·장소: 1:1 “에베소에 있는”. 그런데 **바울의 개인 문안이나 동역자들의 안부가 없음**(에베소에서 3년 사역했는데도).
- ④ **회람 서신의 성격**: 3:3 “먼저 간단히 기록한 글” / 골 4:16 “라오디게아로부터 오는 편지”(강의안은 “히에라볼리에 보낸 편지”로 적음 → 골 4:16은 **라오디게아**라서 **오기 추정**) / 에베소와 아시아의 연결(행 19:10).
- ⑤ 원독자 분류(1:1):
  - “**성도들**”(하기오스: 거룩한, 신에게 바쳐진, 구별된, 두려운).
  - “그리스도 예수 안에 있는 **신실한 자들**”(피스토스: 믿을 만한, 믿는, 신실한 — 강의안 표기 “파티오스”).
  - 2:19 “성도들과 동일한 시민이요 하나님의 권속”.
- 결론: **에베소를 중심으로 한 아시아 지역의 믿음의 사람들, 유대인과 헬라인(이방인)으로 구성된 교회**(행 19:19–20).
- **바울과 원독자의 관계**: 바울의 환난과 갇힘을 걱정하는 사람들(3:13 “낙심하지 말라”) / 바울이 그들을 위해 기도함(1:16) / 행 20:26–28 / 바울의 사정을 궁금해함(6:21) / 바울의 소식이 위로가 됨(6:22) / 바울이 기도를 부탁함(6:19).

## 4. 역사적 배경 [엡 p13–37]

- 에베소 배경을 알려 주는 성경: **행 19장**(교회의 내력), **행 20장**(밀레도의 에베소 장로들), **딤전후**(에베소에서 사역하는 디모데), **계 2:1–7**(에베소 교회) → 에베소서·골로새서·딤전후·요한1–3서·계시록.
- **① 바울의 에베소 방문**:
  - 2차 여행 초기: 16:6 아시아에서 막으심.
  - **AD 53년경 2차 여행 말기 “1차 방문”**: 18:18–21 에베소의 요청을 거절하고 떠남 → 18:24–28 브리스길라와 아굴라가 남음, 알렉산드리아 출신 아볼로가 그들에게 배움.
- **② AD 54–57 3차 여행, 3년(“2차 방문”)**:
  - 19:1–7 세례, 성령 임재, 은사 / 사역 기간 = 3개월(19:8) + 2년(19:10) = “삼 년”(20:31).
  - 19:9 비방자 / 19:12 놀라운 이적 / 19:13 스게와의 일곱 아들 / 19:18 유대인과 헬라인이 믿음 / 19:19 마술책을 태움 / 19:24 아데미 여신과 상업 / 19:34 2시간이나 외침.
- **③ AD 57년경 밀레도의 에베소 장로들**(20:17–38): 회상(겸손과 눈물, 유대인의 간계) / **예상(28–30): 사나운 이리, 여러분 중에서 어그러진 말을 하는 자** → “유대인의 간계”, “거짓 선생”.
- **④ AD 60–62 에베소서에 드러나는 배경**: 2:11–22 유대인과 헬라인으로 이루어진 교회의 문제 / 5:3–5 이교적 삶(음행, 더러운 것, 탐욕, 누추함, 어리석은 말, 희롱, 우상숭배).
- **⑤ 디모데전후서의 에베소**:
  - 딤전 1:3–10 다른 교훈, 신화와 끝없는 족보 / 딤전 4:7 망령되고 허탄한 신화(율법주의).
  - 딤전 1:19–20 믿음에 파선한 자 — **후메내오와 알렉산더** / 딤후 2:16–19 악성 종양 같은 **후메내오와 빌레도** — “부활이 이미 지나갔다” → 거짓 선생과 이단.
  - 딤전 4:3 혼인을 금하고 음식물을 폐하라 → 금욕주의.
- **⑥ 요한계시록 2:1–7**: 악한 자를 용납하지 않음 / 자칭 사도를 시험함 / **니골라당**의 행위를 미워함 / 수고와 인내 / **처음 사랑을 버림**.
- **에베소 도시** (사진·지도):
  - 바울 당시 인구 **25만 명 이상**, 로마의 3대 도시 중 하나, **동서양 물류의 중심지**.
  - 주변 지도: 서머나 · 사데 · 빌라델비아 · 라오디게아 · 히에라볼리 · 골로새 · 프리에네 · 밀레도.
  - 도시 평면도: 고대 항구 – 항구 목욕탕·체육관 – 아르카디아 길 – **극장** – 아고라(시장) – 쿠레테스 거리 – 국영 시장 – 신격 카이사르와 여신 로마의 신전 – 스타디움.
  - **대형 원형극장: 폭 152m, 2만 5천 명 수용**(19:29 소동 장소).
  - 공중 화장실 사진(“퀴즈! 이것이 무엇일까요?”).
  - **교육의 중심지** — 학교, 도서관, 강의실. **“두란노 서원으로 추정되는 셀수스 도서관”**(사진 캡션). 보충: 셀수스 도서관은 2세기 초 건물로 알려져 있어 바울 시대의 두란노와 같다고 보기는 어려움 — 강의안의 ‘추정’ 표현을 그대로 둠.
  - “크다 에베소 사람의 아데미여”(19:29–40): 아데미 신전은 고대 7대 불가사의, 풍요와 다산의 여신. 원래 아나톨리아 여신 **키벨레**의 성지 → 그리스 아르테미스, 라틴 다이아나와 동일시됨. **“에베소는 아데미의 신전지기를 자처하는 도시”**: BC 560경 리디아 침공을 신앙심으로 극복, BC 356 방화로 전소, 100년 동안 복구, **성벽이 없는 도시**.
  - → `05_사도행전.md` [심화4]와 같은 자료.
- **에베소의 사상 — 문화·철학·종교적 배경** [엡 p30–37]:
  - 목록: 우주적 이원론 / 헬라 철학(금욕주의, 쾌락주의) / 신비주의 / 유대교의 율법주의·신비주의 / **마술 = ‘에베소의 글’**(*Ephesia grammata*) / 비밀종교(미스테리) / 자연숭배(범신론) — **이름을 부르는 것** / 자해 / 여신 숭배.
  - **에베소의 혼합주의** = 그리스·로마의 보편 철학(이원론) + 동양의 신비 사상(페르시아와 동방, 알렉산더 이후) + 항구 도시의 특성(전 세계 신비주의·범신론의 집합) = “**영적 디즈니랜드**”.
  - **우주적 이원론(플라톤)**:
    - 악한 세상과 선한 신 → 신론: 선한 신은 악한 세상을 창조하지 않았다(창조를 하등하게 봄), 이신론/범신론.
    - 인간론: 본질적 존재가 아니라 **그림자**. 육은 악하고 영은 선하다.
  - **“분리된 세상, 유출된 세상”** 도식: **하늘(영)**과 **땅** 사이에 여러 층의 **간격(GAP)** → **충만(PLEROMA)**. AD 3세기 **플로티노스의 ‘신플라톤주의’**에서 완성됨(강의안 표기 “플로토니우스”).
  - **“어둠의 주관자들”**(6:12) = 자연적인 영들 — **아이온**(범신론): 만물 안의 영적 힘, 물질세계의 질서를 유지·조정함, 사람의 운명을 지배함. 이들에게 잘 보여야 높은 영적 단계로 올라갈 수 있다고 믿음. **아이온의 계급은 30등급**.
  - **그들이 추구한 구원 = 영의 높은 차원으로 올라가는 것(상승)** — 죄의 문제를 해결하는 것이 아님. 상승의 세 가지 길:
    1. 죽어서 — 로마인의 죽음관: 자살은 미덕.
    2. 살아서 비밀한 지식을 앎 → **영지주의**로 발전.
    3. 신비한 경험, 비밀 의식.
  - 초월·구원·충만을 위한 방법들: 아데미 여사제, 신비주의, 비밀 종교, 영웅 숭배·황제 숭배, 마술과 마술책, 스토아·에피쿠로스·도덕 포기론자, 극심한 금욕주의와 자해.
  - (해석) 에베소서의 핵심어 **충만(1:23; 3:19; 4:13)**, **비밀(3:3–9)**, **모든 이름 위에(1:21)**, **하늘에 앉히심(2:6)**, **통치자들과 권세들(3:10; 6:12)**이 이 배경에 대한 답으로 쓰였다는 것이 강의 구성의 논리로 보임.

### 교회 설립 [엡 p38]

- 세 가지 가능성: ① 오순절 성령 강림 때 믿은 자들이 돌아가서(행 2:9 “아시아”) ② 브리스길라와 아굴라를 통해(행 18:18–19) ③ 바울의 3차 여행 에베소 사역 2년(행 19:10). “3가지 가능성 중에 당신의 선택은?”(강의안은 결론을 열어 둠).

### 교회 구성원

- 유대인과 이방인 / 사도, 선지자, 교사, 목사, 장로 / 종과 상전 / 남편과 아내 / 자녀와 아비.

| 그리스도를 배웠고 진리의 가르침을 받음(4:20–21) | 5:3 음행, 더러운 탐욕 / 5:4–5 누추함, 어리석은 말, 희롱, 우상숭배 / 5:6 속이는 자 |

## 6. 중심 주제와 기록 목적 [엡 p43]

- **중심 주제**: 하나님이 주시는 **그리스도인의 정체성과 합당한 삶** / **그리스도의 몸으로서 교회가 가진 정체성**.
- **기록 목적**: **믿는 것과 아는 것에 하나 되게 하기 위해**(4:13). 1:18–19의 세 가지 “알게 하시기를”과 맞물림:
  1. **부르심의 소망**을 알게 하려고 → 신비주의 종교들의 공격으로부터 변증.
  2. **성도 안에서 기업의 영광의 풍성함**을 알게 하려고 → 합당한 삶, 믿는 이방인과 유대인이 하나 되도록.
  3. **그리스도의 힘의 위력으로 역사하시는 능력의 지극히 크심**을 알게 하려고.

## 본문

### 1장 그리스도 안의 축복

- **반복 “~안에서”**(1장에서만 **16번**): 그리스도 안에서 9 / 그 안에서 3 / 사랑 안에서 1 / 그가 사랑하시는 자 안에서 1 / 1:18 성도 안에서 / 1:23 만물 안에서(교회). → 에베소 도시의 영적 혼란 속에서 “**나는 어디에 있는가?**”에 대한 답.
- **반복 “하나님의 뜻” ×3**: 1:1 하나님의 뜻으로 사도 된 바울 / 1:5 기쁘신 뜻대로 아들들이 되게 / 1:11 뜻의 결정대로 기업이 되었으니 → “원독자들에게 주는 의미는?”(운명·아이온에 휘둘리는 세계관과 대조, (해석)).
- **1:3–14 축복송 “베라카”** — 삼위일체 3연:
  - a 성부의 사역 — 아들이 되게(3–5) / b 은혜의 영광을 찬송하게(6)
  - a 성자의 사역 — 그의 피로 죄 사함(7–11) / b 그의 영광의 찬송이 되게(12)
  - a 성령의 사역 — 인치심, 보증, 속량(13–14a) / b 그의 영광을 찬송하게(14b)
  - 세부: 1:3–4 신령한 복 / 5–6 예정하사 아들들이 되게 / 7 죄 사함 / **8–10 그 뜻의 비밀 — 그리스도 안에서 통일** / 11–12 기업 / 13–14 인치심·보증·속량. ↔ 5:19 시와 찬미와 신령한 노래로 찬송.
- **1:15–19 바울의 기도 1** — “알게 하시고”: 부르심의 소망 / 기업의 풍성함 / 능력의 지극히 크심.
- **1:20–23 하나님의 충만 — 교회**:
  - 20 죽은 자 가운데서 살리시고 하늘 우편에 앉히심.
  - 21 모든 통치와 권세와 능력과 주권과 이 세상과 오는 세상에 일컫는 **모든 이름 위에** 뛰어나게 하심(3:15; 5:3, 20).
  - 22 만물을 발아래 복종시키시고, 그를 만물 위에 교회의 **머리**로 삼으심.
  - 23 교회는 **그의 몸**(1:22; 4:15; 5:23), “만물 안에서 만물을 충만하게 하시는 이의 **충만**”(4:6) → 플레로마 사상에 대한 답 (해석).

### 2장 그리스도 안의 소망 — 새로운 정체성: 성전, 처소, 함께 지어져 감

- **“그때에 너희는 / 전에는 우리도” 표**:

| 그때에 너희는(이방인) 2:1–2 | 전에는 우리도(유대인) 2:3 | 그때에 너희는(이방인) 2:11–12 |
|---|---|---|
| 이 세상 풍조를 따름 | 육체의 욕심을 따라 | 육체로 이방인, 할례받지 않은 자 |
| 공중의 권세 잡은 자를 따름 | 육체와 마음의 원하는 것을 함 | 그리스도 밖, 이스라엘 나라 밖 |
| 불순종의 아들들 | 본질상 진노의 자녀 | 약속의 언약에 외인, 세상의 소망이 없고 하나님도 없는 자 |

- **2:4–10 긍휼이 풍성하신 하나님이 하신 일**: 그리스도와 함께 살리심 / 은혜로 구원받음 / 함께 일으키사 / **함께 하늘에 앉히심** / 은혜의 풍성함을 오는 여러 세대에 나타내려 하심 / **믿음·선물 vs 행위·자랑** / 우리는 그가 만드신 바, 선한 일을 위해 지으심.
- **대조 — 구원의 목적**: “그 가운데서 **행하여**”(2:2, 옛 삶) ↔ “그 가운데서 **행하게** 하려고”(2:10, 새 삶).
- **2:13–18 예수님이 하신 일**: 13 먼 데 있던 너희가 **피로 가까워짐** / 14 화평, 둘로 하나를 만드심, **중간에 막힌 담**을 허무심 / 15 율법을 폐하고 둘로 **한 새사람**을 지어 화평 / 16 **십자가로 한 몸**, 원수 된 것을 소멸 / 17 먼 데와 가까운 데에 평안을 전함 / 18 한 성령 안에서 아버지께 나아감.
- **《전환점》 2:11–22 “이제는~ 너희가”**:

| 그때에 (11–12) | **전환점 (이제는) 13–18** | 이제부터 (19–22) |
|---|---|---|
| 육체로 이방인, 할례받지 않은 무리, 그리스도 밖 사람, 약속의 언약에 외인, 소망이 없는 자, 하나님도 없는 자 | **그리스도 예수 안에서 / 그리스도의 피로 / 십자가로** | 성도들과 동일한 시민, 하나님의 권속(가족), 사도들과 선지자들의 터 위에 세워진 자, 주 안에서 **성전**이 되어 감, 하나님이 거하실 **처소** |

- 흐름 [엡 p60]: 1:15–19 기도 1 → 1:20–22 충만(교회는 몸) → 2:1–13 이방인과 유대인의 이전/이후 → **2:14–18 예수님이 하신 일** → 2:19–22 이전/이후 → 3:1–13 비밀 → 3:14–20 기도 2.

### 3장 그리스도 안의 비밀 — 갇힌 자 됨

- 3:1 이방인을 위하여 갇힌 자 / 2 은혜의 경륜 / **3 계시로 비밀을 알게 하심 — 먼저 간단히 기록함(4 읽으면 알 수 있음)** / 5 성령으로 나타내심.
- **비밀의 내용(3:6) = 이방인이 복음으로 “함께” 상속자, “함께” 지체, “함께” 약속에 참여하는 자**(3중 “함께”).
- 7–9 비밀의 일꾼이 된 바울 / **10–12 교회로 말미암아 하늘의 통치자들과 권세들에게 하나님의 각종 지혜를 알게 하심** / 13 “나의 환난에 대하여 낙심하지 말라”.
- 3:14–20 바울의 기도 2 — 믿음으로 말미암아 알고 깨달아 → 하나님의 모든 **충만하신 것으로 충만하게**(3:19).
- **반복 “말미암아”**: 하나님의 뜻으로(1:1) / 예수 그리스도로(1:5) / 그의 피로(1:7) / **믿음으로(2:8; 3:12; 3:17)** / 그로(2:18) / 복음으로(3:6) / 교회로(3:10) / 성령으로(3:16).

### 4장 그리스도의 몸 — 교회 공동체

- **4:1 “그러므로”** = 1–3장 전체를 받는 요약 → 부르심에 합당하게 행하라(2–3): **겸손, 온유, 오래 참음, 사랑, 서로 용납** → 평안의 매는 줄로 **성령이 하나 되게 하신 것**을 힘써 지키라.
- **4:4–6 “하나”인 것 7(8)가지**: 몸 / 성령 / 소망 / (부르심) / 주 / 믿음 / 세례 / 하나님.
- **4:7–12 은사와 직분**: 각 사람에게 분량대로 주신 선물(7) / **사도, 선지자, 복음 전하는 자, 목사와 교사**(11) / 목적(12): **성도를 온전하게**(완전한 공급) → **봉사의 일**을 하게 → **그리스도의 몸을 세우려**.
- **온전한 사람 vs 어린아이(4:13–14)**:

| 온전한 사람 | 어린아이 |
|---|---|
| 하나님의 아들을 믿는 것과 아는 일에 하나 됨 | 사람의 속임수 |
| 그리스도의 장성한 분량 | 간사한 유혹 |
| 충만한 데까지 이름 | 온갖 교훈의 풍조에 요동 |

- 4:15–16 **사랑 안에서** 그에게까지 자랄지라 — 그는 머리.
- 4:17–19 이방인처럼 마음의 허망한 것으로 행하지 말라.
- **4:20–24 옛사람 vs 새사람**:

| 옛사람 (4:22) | 새사람 (4:23–24) |
|---|---|
| 유혹의 욕심을 따라 | 심령으로 새롭게 되어 |
| 썩어져 가는 구습 | 하나님을 따라 의와 진리와 거룩함으로 지으심을 받은 |
| **벗어 버리라** | **입으라** |

- **4:25–32 버릴 것 vs 행할 것**:
  - 거짓 → 참된 말 / 분 → 죄를 짓지 말고 해가 지도록 품지 말 것 / 도둑질 → 자기 손으로 수고함 / 더러운 말 → 덕을 세우는 선한 말, 은혜를 끼침.
  - 4:30 성령을 근심하게 하지 말라.
  - 모든 악독·노함·분냄·떠드는 것·비방·모든 악의를 버리고 → 친절, 불쌍히 여김, 용서 — “하나님이 그리스도 안에서 너희를 용서하심과 같이 하라”.

### 5장 — 사랑, 빛, 지혜, 예배

- **《교차》 5:1–11 사랑 vs 음행**: a 5:1–2 사랑받는 자녀같이 **하나님을 본받는 자**가 되고 사랑 가운데서 행하라 / b 5:3–7 음행, 더러운 것, 탐욕, 누추함, 어리석은 말, 희롱, 우상숭배 → 하나님 나라에서 기업을 얻지 못함 / a′ 5:8–11 **빛의 자녀들처럼 행하라**(전에는 어둠, 이제는 빛).
- **5:15–21 지혜와 예배**: 지혜롭게 행하기 — **성령 충만**(15–18) / 예배(19) — 시와 찬미와 신령한 노래(함께 찬양, 홀로 찬양) / 복종으로 행하기(20–21) — 범사에 감사, 그리스도를 경외함으로 서로 복종(서로를 높임, 존중).

### 5:22–6:9 관계 안에서 행하기

| | 약자 (A) | 강자 (B) |
|---|---|---|
| 부부 | 아내 — 복종하라 | 남편 — 사랑하라 |
| 부모 자녀 | 자녀 — 순종하라 | 부모 — 노엽게 하지 말라 |
| 주종 | 종 — 순종하라 | 상전 — 위협을 그치라 |

- **“슈퍼 갑” 6:9** — “그들과 너희의 상전이 하늘에 계시고 그는 사람을 외모로 취하지 아니하시느니라” → 강자도 하늘의 주인 아래 있음.

### 6:10–24 영적 싸움과 마지막 당부

- 6:10–11 마지막 당부: 주 안에서 그 힘의 능력으로 강건하여지고 **하나님의 전신갑주**를 입으라(마귀의 간계를 대적하기 위해).
- 6:12 씨름의 대상: 혈과 육이 아니라 통치자들, 권세들, **이 어둠의 세상 주관자들**, 하늘에 있는 악의 영들 → 에베소의 ‘아이온’ 배경.
- **전신갑주(사 59:17–21 배경)**: 진리의 허리띠 / 의의 호심경(흉배) / 평안의 복음이 준비한 신 / 믿음의 방패 / 구원의 투구 / 성령의 검 곧 하나님의 말씀.
- **무장해야 하는 이유(6:11–13)**: 마귀의 간계를 대적하려고 / 씨름이 악의 영들을 상대하는 것이라서 / 악한 날에 능히 대적하려고 / **모든 일을 행한 후에 서기 위하여**.
- 6:18 싸움을 위한 기도 / 6:19–20 바울을 위한 기도 — “**사슬에 매인 사신**”.
- 끝인사: 평안과 믿음을 겸한 사랑 / “**우리 주 예수 그리스도를 변함없이 사랑하는 모든 자**에게 은혜가 있을지어다”(6:24) — 계 2:4 “처음 사랑을 버렸다”는 에베소 교회와 대조됨 (해석).

## 주석용 핵심 메모

- 핵심어: **그리스도 안에서, 하나님의 뜻, 충만, 비밀(함께), 몸, 하나 됨, 말미암아, 행하라, 서라**.
- 배경 열쇠: 에베소의 혼합주의(아데미, 마술, 아이온, 플레로마, 상승 구원) ↔ 에베소서의 답(모든 이름 위, 하늘에 앉힘, 충만, 전신갑주).
- 연대: 로마 1차 투옥 **60–61** (옥중서신 60–62).
- 오기: “1:20 오직 너희는 그리스도를…” → 4:20 / 골 4:16 “히에라볼리” → 라오디게아.
