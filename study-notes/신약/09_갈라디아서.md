## 1. 비평적 방법 (BRI) [갈B]

### 저자 — 바울

- 가) “사도 된 바울”, “나 바울”(1:1; 5:2).
- 나) (**1인칭**) 대명사 [→ 답]:
  - ① 직접 쓴다는 표현 — “내가 너희에게 **쓰는 것은**”(1:20), “**내 손으로 너희에게 이렇게 큰 글자로 쓴 것**을 보라”(6:11).
  - ② “나”라는 표현이 22번, “내가”라는 표현은 모든 장에 나타남.
- 다) 1–2장 (**자서전적 이야기**)의 주인공 [→ 답].
- 결론: 바울.

### 기록 시기 — 남갈라디아설 + 공회 전후

- 가) (**갈라디아**) 교회 설립 이후 [→ 답]. 두 학설:
  - ① (**북**)갈라디아설 [→ 답]: 갈라디아 = 골(Gauls)족(켈트족)이 살던 소아시아 중앙고원 북쪽. 2차 여행(행 16:6 “브루기아와 갈라디아 땅”)과 3차 여행(18:23)에 방문했다고 봄.
  - ② (**남**)갈라디아설 [→ 답]: 로마 **행정구역**상의 갈라디아 속주. 1차 여행(행 13–14장)의 남갈라디아(비시디아 안디옥, 이고니온, 루스드라, 더베).
    - 근거: 바울이 남갈라디아에 익숙함(행 13–14; 16:1–5) / 사도행전에는 오직 남쪽에 교회가 세워졌다고 나옴 / 유대인의 영향력은 남쪽이 더 어울림 / 주요 도로가 북갈라디아를 지나지 않음 / 갈라디아서에 **바나바가 세 번** 언급됨(1차 여행의 동역자).
    - 유인물은 남갈라디아설의 근거만 나열함 → **강의 입장 = 남갈라디아설** (해석). [TBS4] 지도도 남갈라디아 네 도시를 사각형으로 묶음.
- 나) 갈 2:1–10, 바울의 (**예루살렘**) 방문 이후 [→ 답].
  - ▣ 바울의 예루살렘 방문 기록 [갈B]:

| 차수 | 본문 | 계기 | 연대 [갈B] |
|---|---|---|---|
| 1차 | 갈 1:18–24; 행 9:26–30 | 예수님을 만난 이후 | AD 35 |
| 2차 | 행 11:27–30; 12:25 | 안디옥에서 가르친 후(기근 부조) | AD 46 |
| 3차 | 행 15장 | 1차 전도여행 이후(공회) | AD 49 |
| 4차 | 행 18:22 | 2차 전도여행 이후 | **AD 53** |
| 5차 | 행 21:17 | 3차 전도여행 이후 | **AD 58** |

  - ⚠ 4차 AD 53 / 5차 AD 58은 [TBS4]·[바울일대기](52 / 57)와 1년 차이 → `../자료간_차이.md`.
  - 갈 2:1 “십사 년 후에 … 다시 예루살렘에 올라갔나니”가 2차(행 11장) 방문인지 3차(행 15장) 방문인지가 연대를 가름함. 유인물은 빈칸이라 강의의 결론은 **확인하지 못함**.
- **[심화2 p8] 결론(최신)**: 1차 여행 직후(46–48) + 예루살렘 공회(49) **이전** ⇒ **48–49년경**. 기록 장소 안디옥 [연대표].
  - 따라서 강의는 **갈 2:1–10 = 행 11장(2차) 방문**, 공회 전 기록으로 보는 입장으로 추정됨 (해석).

- 기록 장소: (**수리아 안디옥**) — 행 14:26–28 [→ 답: 1차 여행을 마치고 돌아온 안디옥].

## 2. 역사적 방법 [갈B]

### 역사적 배경

- 가) 사도행전에 기록된 (**1차 전도여행**) [→ 답].
- 나) (**유대인**)이 많을 가능성 [→ 답].
- 다) 교회 안에 (**다른 복음**)이 있음(1:6–9) [→ 답].
- 라) (**거짓 교사**)들이 있었던 시기 [→ 답] — 갈라디아서에 나오는 대적자 묘사:
  - 교인들을 **교란한** 자들(1:7) / **가만히 들어온** 자들(2:4) / 교인들을 **꾀던** 자들(3:1).
  - (**열심 내게**)하는 자들(4:17) [→ 답] / 막아 진리를 (**순종**)하지 못하게 하던 자들(5:7) [→ 답].
  - **요동하게** 하는 자들(5:10) / **어지럽게** 하는 자들(5:12).
  - (**육체**)의 모양을 내려 하는 자들(6:12) [→ 답] / 억지로 (**할례**)받게 하려는 자들(6:12) [→ 답].
- 마) 갈라디아 교인들이 (**율법주의**)에 빠지고 있었음 [→ 답]:
  - 어리석게 꾐에 넘어가려 함(3:1).
  - (**약하고 천한 초등학문**)에게 종노릇하려 함(4:9) [→ 답].
  - (**날**)과 (**달**)과 (**절기**)와 (**해**)를 지킴(4:10) [→ 답].
  - 율법 아래 있고자 함(4:21).
- 바) (**베드로/유대인**)과의 갈등이 있었음 [→ 답: 2:11–14 안디옥 사건].

### 교회 설립

- 가) 사도행전 (**13–14**)장의 증거 [→ 답] — 바울의 (**1**)차 전도여행 때 남갈라디아에 교회가 세워진 것으로 보임 [→ 답]: 비시디아 안디옥(행 13:43, 44, 48, 49), 이고니온(14:1), 루스드라(14:6–7), 더베(14:20–21a).
- 나) 갈라디아서 (**내적 증거**) [→ 답] — 바울 자신이 전에 복음을 전했다고 기록함(1:8, 9, 11; 4:11, 13).

### 교회 구성원

- (**유대인과 헬라인, 종과 자유인, 남자와 여자**)(3:28) [→ 답].

### 교회의 장점

- 가) (**성령**)을 받음(3:2, 5) [→ 답].
- 나) 하나님을 알고 하나님이 아신 바 된 자들(4:9).
- 다) 하나님의 천사같이 바울을 (**영접**)함(4:14–15) [→ 답].
- 라) (**눈이라도 빼어 줄 만큼 바울을 사랑함**)(4:15) [→ 답].
- 마) (**달음질을 잘함**)(5:7) [→ 답].

### 교회의 문제점

- 가) 그리스도의 복음을 속히 떠나 (**다른 복음**)을 따름(1:6).
- 나) (**거짓 교사들**)의 꾐에 빠지는 어리석음(3:1).
- 다) (**성령**)으로 시작했다가 (**육체**)로 마침(3:3).
- 라) 다시 (**초등학문**)에 종노릇함(4:9).
- 마) (**날과 달과 절기와 해**)를 지킴(4:10).
- 바) 바울이 수고한 것이 (**헛되게**) 하려 함(4:11).
- 사) (**이간**)당하여 거짓 가르침에 열심을 내려 함(4:17).
- 아) 그리스도의 (**형상**)을 이루지 못함(4:19).
- 자) (**바울에게 의혹**)이 있음(4:20).
- 차) (**율법 아래 있고자 함**)(4:21).
- 카) (**진리를 순종하지 못함**)(5:7b).
- 타) (**바울을 괴롭게 함**)(6:17).
- (위 괄호 안은 모두 [→ 답], 개역개정 본문 표현으로 추정함.)

- **중심 내용**: “의롭게 되는 것은 (**율법의 행위**)가 아닌 (**믿음**)이며, (**종**)의 멍에(율법)를 버리고 성령의 열매 맺는 (**자유**)의 삶을 살아야 한다.” [→ 답]
  - [심화2] 중심 사상: “**율법의 행위가 아닌 오직 믿음으로 의롭게 됨**”.
- **기록 목적**:
  - 가) (**바울의 사도권**)과 (**복음**)을 변증하기 위해서 [→ 답].
  - 나) 다른 복음을 전하는 자들을 (**경계/책망**)하기 위해서 [→ 답].
  - 다) 갈라디아 교인들이 복음으로 (**자유**)를 누리게 하기 위해서 [→ 답].
  - [심화2]: “율법의 행위로 돌아가려는 독자들에게 오직 예수 그리스도의 복음으로만 의롭게 됨을 깨닫게 하고, 율법이 아닌 **성령으로 자유한 삶**을 살도록 하기 위함.”
- **핵심 구절** [심화2 p10]: 5:1 “그리스도께서 우리를 자유롭게 하려고 자유를 주셨으니 … 다시는 종의 멍에를 메지 말라” / 5:6 “할례나 무할례나 효력이 없으되 **사랑으로써 역사하는 믿음**뿐이니라” / 5:13 “자유로 육체의 기회를 삼지 말고 오직 사랑으로 서로 종 노릇 하라” / 5:16 “성령을 따라 행하라 그리하면 육체의 욕심을 이루지 아니하리라”.

## 본문 도식 [갈본]

### 1장 — 바울의 사도권과 복음

- **〈진전〉 바울의 사도권(1:1)** — “A”를 점점 크게 쓴 점층 도식:
  - A 사람들에게서 난 것도 아니요
  - A 사람으로 말미암은 것도 아니요
  - **A 오직 그리스도와**
  - **A 그를 죽은 자 가운데서 살리신 하나님 아버지로 말미암아**
- **복음(1:6–12)**: ① 그리스도의 은혜 ② 우리가 너희에게 전한 것 ③ 우리가 전에 말하였던 것 ④ 너희가 받았던 것 → 이것과 다른 복음은 저주를 받음.
- **바울의 소명 = 선지자적 소명(1:15–16)**:

| 갈 1:15–16 | 렘 1:4–5 | 사 49:1 |
|---|---|---|
| 내 어머니의 태로부터 나를 택정하시고 | 내가 너를 모태에 짓기 전에 너를 알았고, 네가 배에서 나오기 전에 너를 성별하였고 | 여호와께서 태에서부터 나를 부르셨고, 내 어머니의 복중에서부터 내 이름을 기억하셨으며 |
| 이방에 전하기 위하여 그를 내 속에 나타내시기를 기뻐하셨을 때에 | 너를 **여러 나라의 선지자**로 세웠노라 | (사 49:6) 내가 또 너를 **이방의 빛**으로 삼아 나의 구원을 베풀어서 **땅끝까지** 이르게 하리라 |

  - + **행 13:47** “내가 너를 이방의 빛으로 삼아 너로 땅끝까지 구원하게 하리라”(바울이 비시디아 안디옥에서 사 49:6을 자기 사명으로 인용함).
  - ⇒ 바울의 사도직은 예레미야와 이사야의 종처럼 **태에서부터 이방을 위해 부르심을 받은 것**.

| C | 믿음이 온 후 초등교사 아래 있지 않음(3:25) | **아들을 보내심** — 아들의 명분을 얻음(4:4–5) |
| D | 믿음으로 아들이 됨 — 예수 안에서 하나(3:26–28) | 아들이 됨 — **아빠 아버지**라 부름(4:6) |
| E | 아브라함의 자손 — 유업을 이을 자(3:29) | 유업을 받을 자(4:7) |

- **종 vs 아들** 요약:

| 종 | 아들 |
|---|---|
| 율법 아래에 매임 | 그리스도로 옷 입음 |
| 믿음의 때까지 갇힘 | 차별 없이 하나 됨 |
| 율법이 초등교사가 됨 | 유업을 이을 자 |
| 종과 다름이 없음 | 아들의 명분을 얻음 |
| 후견인과 청지기 아래 | 아들의 영을 받음 |
| 초등학문 아래에서 종노릇 | 유업을 받음 |

### 4:21–5:1 — 하갈과 사라 비유

| 여종(하갈) | 자유자(사라) |
|---|---|
| 옛 언약 | 새 언약 |
| 육체 | 약속 |
| 시내산 | (위에 있는 예루살렘) |
| (종의 멍에) | 성령 |
| 이스마엘 | 이삭 |
| 종 | 자녀 |

- 슬라이드에는 “육체/시내산 ↔ 약속/성령”으로 네 칸이 나란히 있음. “위에 있는 예루살렘”은 4:26에서 보충함.
- **여종에게서 난 자 vs 자유 있는 여자에게서 난 자**:
  - 약속의 자녀를 박해함(29) ↔ 박해를 받음(29).
  - 쫓겨남, 유업을 얻지 못함(30) ↔ 유업을 얻음(30).
  - **종의 멍에(5:1) ↔ 자유(5:1)**.

### 5:2–6:15 — 《카이아즘》

- A 5:2–12 **할례**에 대하여
- B 5:13–15 **서로 종노릇 하라**
- C 5:16–18 **성령으로 행하라**
- **D 5:19–24 ?** — 슬라이드는 물음표로 비워 둠. 내용상 **육체의 일 vs 성령의 열매**(아래 표) (해석).
- C′ 5:25–26 **성령으로 행하라**
- B′ 6:1–10 **서로 섬기라**
- A′ 6:11–15 **할례**에 대하여
- **육체의 일 vs 성령의 열매(5:19–23)**:
  - 육체의 일: 음행, 더러운 것, 호색 / 우상숭배, 주술 / 원수 맺는 것, 분쟁, 시기, 분냄, 당 짓는 것, 분열함, 이단, 투기 / 술 취함, 방탕함.
  - 성령의 열매(9가지): 사랑, 희락, 화평 / 오래 참음, 자비, 양선 / 충성, 온유, 절제.
  - 육체의 일을 4묶음으로 나누고 열매를 3×3으로 나눈 것은 슬라이드 배치를 따른 것.
- **6:1–10 “서로 섬기라” — 대상별 할 일**:

| 대상 | 할 일 |
|---|---|
| 형제들 | 자신을 살피라 |
| 서로 | 짐을 지라 |
| 각각 | 자기의 일을 살피라, 자기의 짐을 지라 |
| 가르침을 받는 자 | 가르치는 자와 모든 좋은 것을 함께하라 |
| 스스로 | 속이지 말라 |
| 믿음의 가정들 | 기회 있는 대로 착한 일을 하라 |

  - (해석) 6:2 “서로 짐을 지라”와 6:5 “각각 자기의 짐을 지라”는 모순이 아니라 대상이 다른 두 명령으로 정리됨.

### 6:16–18 — 결말 《교차》

- A 6:16 **평강과 긍휼**이 있을지어다
- **B 6:17 예수의 흔적**(스티그마) — “이 후로는 누구든지 나를 괴롭게 하지 말라”
- A′ 6:18 **은혜**가 너희 심령에 있을지어다
- (해석) 할례(육체의 표)를 자랑하는 대적자들과 달리, 바울이 몸에 지닌 표는 **예수의 흔적**이라는 대조가 A′ 할례 단락(6:11–15) 바로 뒤에 놓임.

## 주석용 핵심 메모

- 연대와 수신: **남갈라디아설 + 공회(49) 직전 48–49년, 안디옥**(강의 최신 입장, 일부 추정).
- 구조의 열쇠어는 **자유**(바울의 자유 → 자유의 근거 → 자유 안에 사는 삶).
- 대조 쌍: 율법 ↔ 믿음, 종 ↔ 아들, 하갈 ↔ 사라, 육체 ↔ 성령, 할례 ↔ 예수의 흔적.
- 빈칸 추정값 [→ 답]은 강의에서 확인할 것.
