## 귀납적 연구 방법 요약 [눅P p1–5]

- 성경 연구 방법: 주관적 방법(묵상) / 연역적 방법(주제별 성경 연구) / **귀납적 방법(원독자적 본문 연구)**.

| 귀납적 방법 | 연역적 방법 |
|---|---|
| 본문에 열린 마음으로 다가감 | 이미 정해진 마음으로 다가감 |
| 발견하기 원함 | 증명하기 원함 |
| 관찰로 시작 | 결론을 가지고 시작 |
| 문맥·역사적 배경 안에서 포괄적으로 연구 | 정해진 주제 안에서 단편적으로 연구 |
| 잘못된 이해를 바로잡을 수 있음 | 잘못된 이해를 굳힐 수 있음 |

- 5단계: 기도 → 성경 읽기 → **관찰**(“본문이 말하고 있는 것은?”) → **해석**(“원독자에게 어떤 의미?”) → **적용**(“나에게 어떤 의미?”).
- 기초 질문: 저자 / 원독자 / 기록 시기 / 역사적 배경.

## BRI

### 저자 — 누가 [눅 p2–10; 눅P p7–15]

1. **동일한 수신자**: 눅 1:1–4 “데오빌로 각하에게 차례대로 써 보내는 것이” ↔ 행 1:1 “데오빌로여 내가 먼저 쓴 글에는”. 두 사람이 같은 사람인가, 이름만 같은가 → 누가복음과 사도행전을 비교해 봄:
   - **지리적 연결**: 눅 = 갈릴리 → 유대·사마리아 → **예루살렘** / 행 = **예루살렘** → 유대·사마리아 → 땅끝까지. 두 책이 예루살렘을 경첩으로 대칭을 이룸(도식).
   - **성령 강림**: 예수님의 성령 세례(눅 3:21–22, **기도하실 때**) ↔ 제자들의 성령 세례(행 2:1–4, **기도** 중). 구약 성령 예언의 성취도 짝을 이룸: 눅 4:18–19 ↔ 행 2:17–21.
   - **고발당함** (평행 표):

| 예수님 (누가복음) | 바울 (사도행전) |
|---|---|
| 공회(22:66) → **유죄**(22:71) | 공회(22:30) → **유죄**(23:2) |
| 빌라도(23:1) → 무죄(23:4) | 벨릭스(24:3) → 무죄(24:24–27) |
| 헤롯(23:8) → 무죄(23:15) | 베스도(25:6) → 무죄(25:18–29, 25) |
| 빌라도(23:13) → 무죄(23:14) | 헤롯(아그립바, 25:23) → 무죄(26:31) |

2. **저자는 목격자가 아님**: 눅 1:1–3 “목격자와 말씀의 일꾼 된 자들이 전하여 준 그대로” → 전해 들은 사람. 행 1:13(다락방), 1:19(“**그들의** 말로는 … 아겔다마”), 2:4(“**그들이** 다 성령의 충만함을 받고”) → 저자는 사도가 아니고 오순절 성령 강림을 직접 겪은 사람도 아님. 이방인일까?
3. **“우리” 단락**: 인칭 대명사가 “그들”이 아니라 “우리” — 행 16:10(마게도냐로 떠남), 20:6, 21:17, 27:1, 28:1, 28:16 → 저자는 바울의 동행자.
4. **바울의 동행자는 누구인가**: 옥중서신 인사말에서 찾음 — 에베소서: 두기고 / 빌립보서: 디모데 / 골로새서: 두기고·디모데·아리스다고·마가·유스도·에바브라·누가·데마 / 빌레몬서: 디모데·에바브라·마가·아리스다고·데마·누가.
5. **소거법**:
   - 골 4:10–11 아리스다고·마가·유스도는 **할례파(유대인)** → 이방인 저자가 아님.
   - 행 20:4–5 아리스다고·디모데·두기고는 “**그들**”로 지칭됨(“우리”와 구별됨) → 저자가 아님.
   - 에바브라는 2·3차 전도여행에 동행하지 않음.
   - 데마는 세상을 사랑해서 떠남(딤후 4:10–12).
   - 남는 사람 = **골 4:14 “사랑을 받는 의사 누가”**.
6. **의사다운 표현**:
   - 눅 6:6 “**오른**손 마른 사람” ↔ 막 3:1 “손 마른 사람”.
   - 눅 4:38 “**중한** 열병” ↔ 마 8:14; 막 1:30 “열병”.
   - 눅 14:2 고창병(수종병).
   - 행 3:7 “**발과 발목**이 곧 힘을 얻고”.
   - 눅 18:25의 바늘 = **의료용 바늘**(마 19:24와 비교).
7. 초대 교부 **터툴리안·이레니우스·유세비우스**가 누가를 저자로 봄 [눅 p10].

### 기록 시기

- **[눅] (기본값)**: 행 1:1 “먼저 쓴 글” → 사도행전보다 앞섬. 사도행전 마지막 사건의 기록 연대는 **AD 62–64**. 행 24:27 “이태가 지난 후” → 가이사랴 투옥 **AD 58–59(60)**. 누가는 이 기간에 이스라엘 곳곳을 다니며 자료를 모았을 것(눅 1:1–4) ⇒ **결론 AD 59–62**.
- [눅P] (옛 자료): “사도행전 기록 연대(AD 62 이후) 이전일 것”, 가이사랴 2년 투옥을 근거로 “**AD 58–59년, 혹은 60년**” → [눅]과 차이가 있음 → `../자료간_차이.md`.

### 원독자 (수신자)

- **데오빌로**(헬 “하나님을 사랑하는 자”; 데오스 = 하나님, 필로스 = 사랑하는 친구).
  - **개인설**: “**각하**”라는 호칭 — 눅 1:3의 데오빌로, 행 23:26의 벨릭스, 행 26:25의 베스도에게 같은 호칭이 쓰임 → 고위 관리급.
  - **공동체설**: 데오빌로는 1세기에 흔한 이름이었음 → “하나님을 사랑하는 사람들, 하나님의 친구들”?
  - **절충**: 개인이면서 공동체를 이끄는 리더?
- **이방인 수신자**의 증거:
  - 이방인에게 친숙한 단어를 씀(“랍비”가 아니라 “선생”).
  - 때를 말할 때 유대 달력이 아니라 **로마 황제**를 기준으로 함.
  - 족보가 **하나님까지** 올라감.
  - 유대 지역을 자세히 설명함(8:26; 19:29; 24:13).
  - 구약 인용에 **70인역**을 사용함.

### 역사적 배경 (원독자의 상황)

- [눅 p15]:
  - 플라톤의 이원론(보이는 것 = 악, 보이지 않는 것 = 선) → “예수님은 정말 신인가?”
  - 구원에 이르는 길은 무엇인가? (믿음 **or** 율법, 믿음 **and** 율법)
  - 기독교를 향한 유대인들의 거센 항의와 핍박.
  - 성령은 무엇인가? 하나님 나라란 무엇인가?
  - [눅P]는 여기에 “헬라 철학과 기독교 세계관의 차이”, “교회란 무엇인가?”를 더함.
- **황제 숭배** [눅 p16] — 아우구스투스 탄생 기념 비문(프리에네 비문으로 보임 — 강의안에는 이름이 없음, (해석)) 인용:
  > “가장 존엄하신 황제 … 만물이 (무질서로) 타락하여 소멸해 가고 있을 때 그는 한 번 더 만물을 회복시키시고 … 모든 도시가 만장일치로 신성하신 황제의 탄생일을 새로운 해의 시작으로 채택한다 … 우리의 모든 존재를 다스려 온 섭리(신)께서 … 아우구스투스를 보내 주심으로 … 그는 우리와 후손들의 **구세주**로 보냄받아서 전쟁을 끝내고 만물을 질서 있게 … 신(아우구스투스)의 탄생일은 온 세계를 위한 **기쁜 소식(Evangelion)**의 시작이었다.”
- **로마 제국의 언어를 복음이 전유함** [눅 p17]:

| 로마 제국의 용어 | 복음의 용어 |
|---|---|
| **바실레이아**(로마 제국을 지칭) | 하나님 나라 |
| **복음**(황제의 탄생·즉위·전쟁 승리) | 예수 그리스도 |
| **그리스도**(신적 권위를 위임받음) | 예수 그리스도 |
| **신의 아들**(왕과 황제의 대중적 칭호) | 하나님의 아들 예수 |
| **파루시아**(황제의 귀환) | 예수 그리스도의 재림 |
| **퀴리오스**(통치자의 명칭, 최고 통치자) | “주 예수” |

### 중심 사상과 기록 이유 [눅 p18; 눅P p21]

- 중심 사상: **잃어버린 자를 구원하러 오신 예수님(19:10)**.
- 기록 이유:
  1. 데오빌로가 들은 복음을 **확신**하게 하려고(1:1–4).
  2. 예수님이 유대인뿐 아니라 **모든 사람**을 구원하러 오신 하나님의 아들임을 보이려고.
  3. 하나님 나라를 이해시키려고.
  4. **사람의 아들로 이 땅에 오신 하나님의 아들**임을 알게 하려고.
  5. 제자란 무엇이며 그 삶이 어떠해야 하는지 알게 하려고.

## 누가복음의 특징

1. **소외당한 자들**
   - **가난한 자**(4:18) = **프토코스** — 절대 가난, 큰 불행 속에서 방황하는 자. 관련 구절: 1:51–53; 4:18; 6:20; 7:22; 14:13, 21; 16:19–31.
   - **복과 화** (평지 설교, 6:20–26):

| 복 | 화 |
|---|---|
| 6:20 가난한 자 | 6:24 부요한 자 |
| 6:21 지금 주린 자 | 6:25 지금 배부른 자 |
| 6:21 지금 우는 자 | 6:25 지금 웃는 자 |
| 6:22 인자로 말미암아 이름이 악하다 하여 버림받을 때 | 6:26 모든 사람이 너희를 칭찬하면 |
| 6:23 그들의 조상들이 **선지자들**에게 이와 같이 | 6:26 그들의 조상들이 **거짓 선지자들**에게 이와 같이 |

     → 6:27 “그러나 … 너희 원수를 사랑하며 너희를 미워하는 자를 선대하며” = **하나님 나라에 합당한 삶**.
   - **여인들**:
     - 엘리사벳과 마리아(1:5–66).
     - 선지자 안나(**아셀 지파**, 2:36–38).
     - 사렙다(사르밧) 과부(4:25–27, **첫 번째 설교**).
     - 나인성 과부의 죽은 아들(7:11–17).
     - 막달라 마리아·요안나·수산나와 다른 여자들(8:1–3).
     - 18년 동안 귀신 들린 여인(13:10–17).
   - **죄인들과 세리들**:
     - 5:8 베드로 “나는 죄인이로소이다”.
     - 5:29–30 레위(마태)의 잔치.
     - 7:36–50 죄인인 한 여자.
     - 15:1–2 세리와 죄인들을 영접하심.
     - 18:9–14 바리새인과 세리의 비유.
     - 19:1–10 세리장 삭개오.
     - 23:39–43 십자가 위의 죄인.
2. **성령 강조**
   - 1–4장에 성령이 집중적으로 언급됨: 세례 요한(모태로부터), 마리아, 엘리사벳, 사가랴, 시므온, 예수님.
   - **구속사 3단계 표** (→ 하나님 나라의 완성):

| | 세례 요한 | 예수님 | 제자들 |
|---|---|---|---|
| 성령 | 성령 충만(눅 1:15) | 성령 강림(눅 3:22) | 성령 충만(행 2:4) |
| 사명 | 예수의 오심을 예비(1:17, 76) | 만민에게 예비하신 구원(강의안 “1:30–31” — 2:30–31의 **오기 추정**) / 하나님 나라를 전하러 오심(4:43) | 땅끝까지 증인(행 1:8) / 다시 오심(행 1:11) |
| 시점 | 예수 그리스도의 **초림 전** | **십자가의 죽음과 부활**(24:46–47) | 예수 그리스도의 **재림 전** |

3. **기도**:
   - 3:21–22 기도하실 때 성령이 강림하심.
   - 5:16 한적한 곳에서 기도하심.
   - 6:12 제자를 택하실 때 기도하심.
   - 11:1–4 기도를 가르치심(13절 “성령을 주시지 않겠느냐”).
   - 18:1–8 항상 기도하고 낙심하지 말 것.
   - 22:43 십자가 전의 기도.
4. **복음의 보편성**:
   - 이방인 저자(누가), 이방인 독자(데오빌로).
   - 2:30–32 만민 앞에 예비하신 구원, 이방을 비추는 빛.
   - 3:6 “모든 육체가 하나님의 구원하심을 보리라”.
   - 3:23–38 하나님까지 이르는 족보.
   - 24:46–48 모든 족속에게 전파될 것, 제자들은 증인.
5. **재물**:
   - 3:10–14 세례 요한의 가르침.
   - 12:13–21 어리석은 부자.
   - 12:33–34 소유를 팔아 구제하라.
   - 14:33 모든 소유를 버리지 않으면 제자가 될 수 없음.
   - 16:1–13 불의한 청지기와 두 주인.
   - 16:19–31 부자와 거지 나사로.
   - 18:18–27 부자와 하나님 나라.
   - 19:1–10 삭개오.
   - **세례 요한의 가르침 ↔ 삭개오의 결단** 평행:

| 세례 요한의 가르침 (3:8–14) | 삭개오의 결단 (19:8–9) |
|---|---|
| 회개에 합당한 열매를 맺으라 / 이 돌들로도 아브라함의 자손이 되게 하시리라 | “**아브라함의 자손**임이로다” |
| 옷 두 벌 있는 자는 없는 자에게, 먹을 것이 있는 자도 그렇게 | 내 소유의 **절반**을 가난한 자에게 |
| 부과된 것 외에는 거두지 말라 / 강탈하지 말며 거짓으로 고발하지 말고 급료를 족한 줄로 알라 | 누구의 것을 속여 빼앗은 일이 있으면 **네 갑절**이나 갚겠나이다 |

6. **하나님 나라**:
   - 하나님의 나라 복음을 전해야 함(4:43).
   - 하나님 나라의 전파(8–10장).
   - 하나님 나라가 임하도록 기도하라(11:2).
   - 하나님 나라가 **이미** 임함(11:20).
   - 하나님 나라는 **너희 안에** 있음(17:20–21).
   - 하나님 나라가 **가까이** 온 줄 알라(21:29–31) — 평행 본문 마 24:32–33과 막 13:28–29는 “**인자가** 가까이”. 누가만 “하나님 나라”로 표현함.

- **영생이란?** 히브리어 “**오는 세대(세상)의 삶**”을 헬라어로 옮긴 것을 다시 현대어로 옮긴 말. 시간적으로 끝없이 긴 삶이라는 뜻만이 아니라, 하나님이 다스리시는 “오는 세대”, 곧 **구원의 시대의 삶** = **하나님의 나라** (김세윤, 『복음이란 무엇인가?』 인용).
