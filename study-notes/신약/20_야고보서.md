## BRI

### 저자 — 주의 형제 야고보

- **저자의 특징**:
  - 1:1 자신에 대한 설명 없이 이름만 밝힘 → **널리 알려진** 사람.
  - 3:1 “선생 된 **우리**가” / **명령을 54회** 사용 → 지도자 위치, 권위 있는 사람.
  - **유대인?** — 1:1 흩어져 있는 열두 지파에게 문안 / 2:2 **회당**의 풍경에 익숙함 / 2:21 “우리 조상 아브라함” / 1:9–10, 12; 4:11 율법에 우호적인 가르침 / 5:4 “**만군의 주**”(특별한 표현) / 5:7 **이른 비와 늦은 비**(신 11:14) / 1:18 **첫 열매**(레 23:10) / 1:11 **뜨거운 바람** / 5:10 선지자들을 본으로 삼으라 / 5:12 맹세하지 말라(레 19:12; 마 5:33–37).
  - **예수님의 말씀을 잘 아는 사람** — **마태복음 5–7장 산상수훈과 유사함**(가르침, 비유, 어투를 인용), 특히 **마태복음과 구조적 유사성이 매우 높음** → 저자는 제자일까?
- **신약의 야고보들**:
  - 세베대의 아들 야고보(요한의 형제, 마 10:2, 12제자).
  - 알패오의 아들 야고보(마 10:3, 12제자).
  - 다대오(유다)의 아버지 야고보(눅 6:16).
  - **예수님의 형제 야고보**(마 13:55).
- **예수님의 형제 야고보**:
  - 마 13:55; 막 6:3 — 예수님의 형제들: 야고보, 요셉, 시몬, “**유다**”(→ 유다서 저자), 누이들.
  - 막 3:21; 요 7:5 — 처음에는 **예수님을 믿지 않았음**.
  - 고전 15:7 — **부활하신 예수님을 만남**.
  - 행 1:14 — 오순절 다락방에 함께 있음.
  - 갈 1:19 “주의 형제 야고보” — 교회 지도자, **사도는 아님**.
- **영향력**:
  - 갈 2:9 예루살렘 교회의 “**기둥같이 여기는** 야고보, 게바, 요한”(첫 번째로 이름이 나옴).
  - 갈 2:11–12 게바의 외식 사건 — “야고보에게서 온 어떤 이들”.
  - 행 12:17 베드로가 옥에서 풀려난 뒤 “야고보에게 전하라”.
  - **행 15:12–21 AD 49 예루살렘 공회를 주관**하고 결론을 냄 — 아무도 반대하거나 그 권위에 도전하지 않음.
  - 행 21:17–26 3차 여행 뒤 바울의 보고를 받고 조언함.
- **결론**: 선생의 위치에 있고 권위를 가진 유대인, 사도는 아니지만 **모두가 인정하는 지도자** — “**낙타 무릎**, 기도의 사람 야고보”(무릎 전승, 보충: 유세비우스가 전하는 헤게십푸스 전승).

### 기록 연대 — AD 45–49 (공회 이전)

- 야고보서의 시험과 시련은 언제인가?
  - 4:5 “우리 안에 거하시는 성령” → **AD 31 오순절** 이후(강의안 연대).
  - 1:1 흩어진 12지파 → BC 722 북이스라엘 멸망 / BC 586 남유다 멸망 / **AD 32 스데반의 순교로 인한 큰 핍박과 흩어짐**(행 7–8장).
  - 1:2 믿음의 시련 → AD 32 예루살렘 교회의 흩어짐, 행 8:3 “잔멸”.
  - 2:7 “너희에게 대하여 일컫는 그 **아름다운 이름**을 비방” → AD 32–44 이후, 행 11:26 안디옥에서 **비로소 ‘그리스도인’**이라 불림.
  - 2:15–16 일용할 양식이 없는 형제자매 / 5:7 이른 비와 늦은 비를 기다림 → 행 11:28 **아가보가 예언한 기근**, 글라우디오 때 **45–47**.
- ⇒ **AD 45년 ~ AD 49년(예루살렘 공회 이전)**.
- 참고: 요세푸스에 따르면 야고보는 **AD 62년 무렵 예루살렘에서 순교**. 가능한 범위 AD 45–62(기근 ~ 죽음) → 좁히면 45–49(기근 ~ 공회). 비교: AD 57년경 바울의 로마서.
  - ⚠ 강의안의 오순절 “AD 31”과 스데반 “AD 32”는 [수평]·[연대표](오순절 29–30, 스데반 31)와 다름 → `../자료간_차이.md`.

### 수신자

- **유대인**: 1:1 흩어져 있는 12지파 / 2:2 **회당**에서 모임 / 2:8–12 율법을 앎 — 율법 vs **자유롭게 하는 온전한 율법**(1:25) / 2:19 하나님이 한 분이심을 믿음 / 2:21 우리 조상 아브라함 / 5:10 선지자들의 고난과 오래 참음을 앎 / 5:11 **욥의 인내와 결말**을 앎.
- **유대인 그리스도인**: 1:18 진리의 말씀으로 낳음을 받음 / 2:1 예수 그리스도에 대한 믿음 / 1:12; 2:5 하나님을 사랑하는 자, 약속을 받음 / 2:7 아름다운 이름으로 일컬음을 받음 / 2:12 자유의 율법 / 4:5 우리 속에 거하시는 성령 / 5:7–8 주의 강림을 기다림.
- **믿음 때문에 시험과 시련을 겪는 사람들**: 1:2 시험을 당함 / 1:3 시련이 인내를 만드는 줄 앎 / 2:6 **부자에게 억압받고 법정으로 끌려감** / 2:7 비방당함 / 4:2–3 구하여도 받지 못함 / 5:13 고난당하는 자, 즐거워하는 자, 병든 자 → “이 사람들은 왜 이런 고난을 당하고 있을까?”
- **시련 가운데 그들의 모습**:
  - 1:9–10 낮은 형제와 부한 자(행 2:43–45; 4:32–36의 공동체와 대조).
  - 1:19–20 **성내고 있음**.
  - 2:2, 9 형제를 **차별** / 2:6 가난한 자를 업신여김.
  - 3:1 선생이 되려 함 / 3:2–12 **말의 실수**.
  - 4:1 싸움과 다툼 / 1:6; 4:8 **두 마음**.
  - 4:11–12 형제를 비방하고 판단함 / 4:16 허탄한 자랑.
  - 5:1–5 부한 자들 — 말세에 재물을 쌓음, **임금 체불**.
- **결론**: **예루살렘 초대 교회의 구성원들 — 스데반의 순교로 흩어진 사람들, 기근으로 어려움에 처한 사람들**.
  - 행전 3–5장에 나타난 교회의 모습(통용, 나눔)은 어디로 갔나? → 가뭄으로 인한 어려움, 주의 강림을 기다림.
  - **위기의 그리스도인**: 믿음 때문에 고난 가운데 있음 → 현실과 믿음의 문제에 직면 → 올바른 믿음에서 벗어나 흔들림 → **경제적 어려움이 관계의 어려움으로 발전** → 화나고 성난 그리스도인(1:19) → 진리를 떠나 미혹된 길로 가는 사람들 … “**누구 탓?**”(→ 1:13 “하나님께 시험을 받는다 하지 말라”).

### 중심 내용과 기록 목적

- **중심 내용**: **온전한 믿음은 행함과 함께한다** / 행함으로 온전해지는 믿음 / **고난을 이기는 믿음은 행함이다**.
- **기록 목적**:
  1. 고난의 상황에서 **인내**를 배우도록.
  2. 공동체가 겪는 **빈부 격차**로 생긴 문제를 권면하려고.
  3. 말씀대로 행하지 않는 삶을 바로잡으려고.
  4. 서로 **비방**해서 생긴 문제를 해결하려고.
  5. **하나님에 대한 오해**를 바로잡으려고(1:13–17).

## 본문

### 1:1 인사

- “하나님과 주 예수 그리스도의 **종** 야고보” — 주의 형제이면서도 자신을 종으로 소개하는 까닭은?
- **디아스포라**(Diaspora, 분산, 흩어진): 강제로 또는 스스로 선택해서 이스라엘 땅을 떠난 유대인 → 수신인 “흩어져 있는 열두 지파”.

### 1:2–12 시험과 인내

- **“형제들아”(아델포스)** — 같은 태에서 태어난 사람(1:18 “진리의 말씀으로 우리를 낳으셨느니라”와 연결), **17번 반복**, 권면과 명령을 시작하기 전에 부름(히 10:24; 12:14–16 참조).
- **1:2–4 “여러 가지 시험을 당하거든”**:
  - 명령·결과: **시험(페이라스모스) → 온전히(파스, 모든) 기쁘게 여기라**(1:2).
  - 원인: **시련(도키미온)이 인내를 만들어 내는 줄 앎**(1:3).
  - **인내를 온전히 이루라**(1:4, 텔레이오스 = 완성, 완전, 성년 — ‘온전’ 2번).
  - 인내의 목록: 믿음의 시련이 만들어 냄(3) / 온전히 이루어야 함 — 완성하여 소유하라(4) / **온전하게**(성숙 — 시간이 필요) / **구비하게**(완성 — 시간이 필요) / **조금도 부족함이 없게**(4) → 히 10:36.
- **1:1–5 구조**: 1:2 시험을 당하거든 — 기쁘게 여기라 / 1:3 믿음의 시련이 인내를 만듦 — 너희가 앎 / 1:4a 인내를 온전히 이루라 / 1:4b 온전·구비·부족함 없게 / **1:5 지혜가 부족하거든 — 하나님께 구하라** (4절 “부족함이 없게” ↔ 5절 “부족하거든” 연쇄 — 해석).
- **1:5–8 지혜가 부족하거든**: 하나님 = **모든 사람에게 후히 주시고 꾸짖지 아니하시는** 분 / 명령 — 믿음으로 구하고 의심하지 말라.
  - **의심(디아크리노)** = 구별·판단하다, 흔들리다, 주저하다.
  - 의심하는 자(목록) = 마음이 나뉜 사람, 판단하는 사람 / 바람에 밀려 요동하는 바다 물결 / 주께 얻기를 생각하지 말라 / **두 마음을 품은 자** / 모든 일에 정함이 없는 자.
  - ⇒ “**환난의 이유 — 두 마음에서 시작된다.**”
- **1:9–11 대조**: 낮은 형제는 **높음**을 자랑하고 / 부한 자는 **낮음**을 자랑하라 — 풀의 꽃같이 지나감.
- **1:12 “시험을 참는 자는 복이 있나니”** — **팔복(마 5장)과 같은 형식**. 사역: “유혹에 저항하는 자는 복되다. 그가 인정을 받으면 하나님을 사랑하는 자에게 약속된 **생명의 면류관**을 받을 것이기 때문이다.” → 참을 수 있는 이유? (2:5 약속).

### 1:13–27 시험받을 때 — 오해하지 말고 말씀을 행하라

- 흐름 목록: 13 하나님께 시험받는다 하지 말라 / 14–16 시험은 욕심에 미혹된 것 / 17 좋은 은사와 선물을 주시는 하나님 / 18 진리의 말씀으로 낳으심 / 19 성내지 말라 / 21 심어진 말씀을 온유함으로 받으라 / 22 **말씀을 행하는 자가 되라** / 23–25 듣고 실천하는 자가 복을 받음.
- **1:13–18 오해하지 마**: 하나님은 시험하는 분이 아님 / **욕심이 잉태 → 죄를 낳고 → 죄가 장성 → 사망을 낳음**(14–15) / 속지 말라, 하나님은 **좋은 것**으로 주시는 분(16–17) / **첫 열매**가 되게 하시려고 자기 뜻으로 진리의 말씀으로 우리를 낳으심(18).
- **1:19–27 말씀을 듣고 행하라**: 19 명령 — **듣기는 속히, 말하기는 더디, 성내기도 더디** / 20 설명(사람의 성냄이 하나님의 의를 이루지 못함) / 21–22 명령 — 더러운 것을 내버리고 말씀을 온유함으로 받으라 / 23–25 설명 — 거울 비유, 롬 2:13(“율법을 행하는 자라야 의롭다 하심을 얻으리니”) / 26–27 스스로 생각하는 경건은 헛것 → 하나님 아버지 앞에서 **정결하고 더러움이 없는 경건 = 고아와 과부를 돌보고 세속에 물들지 않는 것**.

### 2:1–13 사람을 차별하지 말라

- 2:4부터 **수사의문문**(4, 5, 6, 7).
- 2:8–13 차별하면 **율법이 범법자로 정죄함**(롬 1:12; 4:15 참조) → “**자유의 율법대로 심판받을 자처럼 말하고 행하라**”(12) / 긍휼과 심판(13 “긍휼은 심판을 이기고 자랑하느니라”).

### 2:14–26 행하라 — 믿음과 행함

- 행함이 없는 믿음의 예(15–16: 헐벗고 굶주린 형제에게 “평안히 가라”만 말함) → 결론(17): **행함이 없는 믿음은 그 자체가 죽은 것**.
- 18–26 **행함으로 증명된 믿음** — **아브라함**(이삭을 드림), **라합**(정탐꾼을 숨김).
- **바울이 본 행함**: 갈 5:6 “**사랑으로써 역사하는 믿음**뿐이니라” / 갈 5:25 “성령으로 살면 성령으로 행하라” / 고전 16:14 “모든 일을 사랑으로 행하라” / 롬 14:15 / 겔 33:30–33(듣고 행하지 않는 백성).
  - ⇒ 강의 입장: 야고보와 바울은 충돌하지 않음 — **바울은 믿음의 근거를, 야고보는 믿음의 증거를** 말함 (해석: 강의안이 바울 구절을 병치한 의도를 요약).

### 3:1–18 혀와 위로부터 난 지혜

- **3:1–5** “선생이 많이 되지 말라, 우리가 **더 큰 심판**을 받을 줄 앎이라” / **말에 실수가 없는 자 = 온전한 사람**(재갈, 키 비유).
- **3:6–12 혀는 능히 길들일 사람이 없나니**: 혀는 불이요 불의의 세계 / 길들일 사람이 없음 / 쉬지 않는 악 / 죽이는 독이 가득함.
- **3:13–18 위로부터 난 지혜** — **성결, 화평, 관용, 양순, 긍휼, 선한 열매, 편견과 거짓이 없음** ↔ 갈 5:22–23 **성령의 열매**(사랑, 희락, 화평, 오래 참음, 자비, 양선, 충성, 온유, 절제; 강의안 “갈 4:22”는 **오기**) / 마 5:9 “화평하게 하는 자는 … 하나님의 아들이라”.

### 4:1–17 싸움과 비방과 허탄한 자랑

- **4:1–10 싸움과 다툼**: 정욕에서 나옴 / 욕심을 내어도 얻지 못함 / 살인하고 시기해도 취하지 못함 / **세상과 벗된 것 = 하나님과 원수 되는 것** / 7–10 하나님께 복종하라, 마귀를 대적하라, 하나님을 가까이하라, 두 마음을 품은 자들아 마음을 성결하게 하라, 주 앞에서 낮추라.
- **4:11–12 “너는 누구이기에 이웃을 판단하느냐?”** — 형제를 비방하고 판단하는 자는 **율법을 비방하고 판단하는 것**.
- 4:13–17 “너희가 허탄한 자랑을 하니” — “주의 뜻이면”.
- **요약적 진술**: 4:17 “**사람이 선을 행할 줄 알고도 행하지 아니하면 죄니라**” ↔ 2:9 “사람을 차별하여 대하면 죄를 짓는 것”.

### 5:1–20 부자에 대한 경고, 인내, 기도

- **5:1–6 “들으라 부한 자들아”** — 5:5 “너희가 … 마음을 **살찌게** 하였도다”(마 5:3 “심령이 가난한 자”와 대조).
- **5:7–11 “참으라, 주의 강림이 가까우니라”** — 이른 비와 늦은 비를 기다리는 농부 / **욥의 인내를 들었고 주께서 주신 결말을 보았거니와**.
- **고난에 대한 해설 슬라이드(“고난, 시련… 설명이 될까?”)**:
  - **유대인의 관점**: 고난은 고통받는 자의 **죄** 때문 / 인간의 죄에 대한 하나님의 진노.
  - **욥기**: 의인의 고난을 어떻게 설명할 것인가에서 출발 → “**진정한 지혜는 무엇인가?**”로 결말 / 고난은 인과응보라는 논리에 대한 **반론(지혜의 논쟁)** / 사람은 하나님의 지혜를 알 수 없음(욥 38:1 — 욥의 회개와 그 의미).
  - **욥기가 말하는 것**: 고난에 **끝**이 있음을 알고 소망을 가져야 함 / 고난 때 갖출 태도 / 고난은 **기계론적 인과응보의 결과가 아님**.
  - → 구약 `욥기` 노트와 연결.
- **5:12 “맹세하지 말지니”** — 마 5:33–37.
- **5:13–19 “너희 중에”** — 고난당하는 자(기도하라) / 즐거워하는 자(찬송하라) / 병든 자(장로들을 청하여 기름을 바르며 기도하라) / 죄를 지은 자(서로 죄를 고백하고 기도하라, 엘리야의 기도).
- 5:20 “너희가 알 것은” — 미혹된 자를 돌아서게 하는 자는 영혼을 구원하고 허다한 죄를 덮음.

## 주석용 핵심 메모

- 저자는 **주의 형제 야고보**(예루살렘 교회의 기둥, 공회 주재), 수신자는 **흩어진 유대인 그리스도인**(스데반 박해와 기근), 연대는 **45–49년**(신약에서 가장 이른 책 중 하나로 보는 입장).
- 열쇠어: 시험(페이라스모스)·시련(도키미온)·인내, 두 마음, 행함, 자유의 율법, 혀, 위로부터 난 지혜, 부자, 강림.
- 산상수훈과의 평행(1:12 팔복 형식, 5:12 맹세, 5:5 vs 마 5:3, 3:18 vs 마 5:9)을 주석에 표시할 것.
- 오기: “갈 4:22 성령의 열매” → 갈 5:22.
