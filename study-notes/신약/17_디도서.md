## BRI

### 저자: 바울
- “나 바울”(1:1). 1인칭으로 8번 자신을 표현(1:1, 3, 4, 5×2, 3:12×2, 15).
- 저자의 특징 9가지: ① 하나님의 종·예수 그리스도의 사도(1:1) ② 전도의 사명(1:3) ③ 디도와 돈독한 관계(1:4) ④ 디도의 권위자(1:5) ⑤ 목회 방향 제시(1:5–10, 2:1–10) ⑥ 유대주의자 경계(1:10–16) ⑦ 거짓 교사 경고(3:9–11) ⑧ 동역자를 돌아봄 — 디도·두기고·아볼로·아데마·세나(3:12–15) ⑨ 동역자를 보낼 수 있는 권위.

### 바울의 여정 (강의안 경로 텍스트)
- **1차**: 안디옥 → 실루기아 → 살라미(구브로) → 바보(구브로) → 버가 → 비시디아 안디옥 → 이고니온 → 루스드라 → 더베 → 루스드라 → 이고니온 → 비시디아 안디옥 → 버가 → 앗달리아 → 안디옥. 갈 2:1–3에 디도 언급. 예루살렘 공의회: 이방인에게 율법(할례) 강요 없이 오직 믿음으로 구원을 공식 채택.
- **2차**: 안디옥 → 다소 → 더베 → 루스드라 → 비시디아 안디옥 → 드로아 → 네압볼리 → 빌립보 → 데살로니가 → 베뢰아 → 아덴 → 고린도 → 겐그리아 → 에베소 → 로도 → 가이사랴 → 예루살렘 → 안디옥. 고린도 1년 6개월.
  - ⚠ 강의안 경로에 “로도”가 있으나 행 18:18–22에는 로도 경유 언급이 없음(로도는 3차 귀로 행 21:1). 확인 필요 → `../자료간_차이.md`.
- **3차**: 안디옥 → 다소 → 이고니온 → 에베소 → 드로아 → 빌립보 → 데살로니가 → 베뢰아 → 고린도 → 베뢰아 → 데살로니가 → 빌립보 → 드로아 → 앗소 → 미둘레네 → 밀레도 → 두로 → 가이사랴 → 예루살렘(체포). 고린도전서(에베소), 고린도후서(마게도냐, 디도 언급), 로마서(고린도, 서바나 계획).
- **로마행**: 가이사랴 → 시돈 → 무라 → 니도 → 살모네(그레데) → 라새아(그레데) → 미항(그레데) → 멜리데 → 수라구사 → 레기온 → 보디올 → 압비오 광장 → 삼관 → 로마. 옥중서신: 에베소·빌립보·골로새·빌레몬서.
- **4차 전도여행** (로마 석방 이후, 서신 근거로 재구성):
  - 롬 15:23–28 서바나 계획 / 몬 1:22 골로새 방문 계획 / 빌 2:24 빌립보 방문 계획 / 딤전 1:3 에베소에 디모데를 남기고 마게도냐로 / 딛 1:5 디도를 그레데에 남김 / 딛 3:12 니고볼리에서 만나자 / 딤후 4:13 드로아에 두고 온 겉옷 / 딤후 4:20 에라스도는 고린도, 드로비모는 밀레도.
  - 경로: 로마 석방 → 서바나 → 그레데 → 밀레도 → 골로새 → 에베소 → 드로아 → 마게도냐 → 빌립보 → 니고볼리 → 다시 로마 투옥, 디모데후서를 마지막으로 순교.

### 지도에서 확인한 내용 (2026-09-29 추가)
- 1·2·3차 전도여행, 로마행 지도는 강의안 경로 텍스트와 같은 경로를 그린 것.
- **4차 전도여행 지도(p16, p69)의 연대 표기**: 로마(62년경 석방) → **스페인(62–63년경)** → **그레데(63–64년경)** → **밀레도(64년경)** → **에베소·골로새(64–65년경)** → **마게도냐(65년경)** → **니고볼리(65–66년경)** → **로마(67/8년경, 재투옥·순교)**.
  - ⚠ 같은 강의안 안에서 차이: 본문 슬라이드는 디도서 기록을 **AD 62–64**, 2차 투옥을 **64–68**로 제시 / 지도는 그레데 63–64, 니고볼리 65–66, 로마 67/8 → 지도를 따르면 디도서 기록(니고볼리 가는 도중)은 **64–65년경**이 됨. `../자료간_차이.md`.
- 니고볼리 위치 지도(p69): 그리스 서북쪽 에베이로(에피루스) 해안, 아가야 서편 — 달마디아(딤후 4:10)와 가까운 쪽.
- p22 “어디에서 쓰였는가”: 3:12 — 니고볼리로 가는 도중(텍스트와 동일).

### 기록 연대: AD 62–64
- 행 27장의 그레데 방문(AD 59, 로마 이송 중)은 기록 시점이 될 수 없음 — 이송 중 편지 기록 불가, 1:5·7 “각 성에 장로·감독” → 그레데 각 성에 교회가 이미 성장해 있음.
- 로마 1차 투옥(AD 60–62) 중 서신에서 석방 기대(빌 2:24, 몬 1:22).
- 2차 투옥(AD 64–68) = 디모데후서(딤후 1:8, 16; 2:3, 9; 3:12; 4:5), 마지막 서신 암시(딤후 4:6–8).
- 결론: **1차 석방(AD 62) ~ 2차 투옥 사이, AD 62–64년, 니고볼리로 가는 도중**.

### 수신자
- “디도에게”(1:4). 2인칭 13회(1:5, 13; 2:1, 6, 7, 15; 3:1, 8, 11, 12×2, 15×3). “너희 무리에게”(3:15) → **디도에게 썼고 그레데 교회들에서도 읽혔을 것**.
- **디도**: 할례받지 않은 헬라인, 바울의 제자, 초기 동행자(갈 2:1–3). 바울 사역의 **문제 해결자**, 낙심한 바울의 위로(고후 2:12–13; 7:6–7, 13; 8:6, 16, 23; 12:18). 고후 8:23 “나의 동료요 동역자”. 달마디아(오늘날 유고슬라비아)로 감(딤후 4:10).
  - ※ 사도행전 자료[예습1-1]의 “디도 = 누가의 동생” 전승과 연결됨 → `05_사도행전.md`.
- 기록 장소: 3:12 → 니고볼리로 가는 도중.

### 역사적 배경: 그레데
- 행 2:11 오순절 현장에 그레데인.
- 그리스에서 가장 큰 섬, 지중해에서 다섯 번째. 제주도의 4.5배. 에게해와 지중해의 경계.
- 유럽 최고(最古) 문명인 **미노아 문명**의 중심(BC 2600–1400): 해상 문명, 미노스 왕권, 이집트·터키·그리스 문명의 교차점. 지중해 교역 독점. 이다산 = 제우스 탄생지 전설. 도자기·조각 기술.
- 온화한 기후. BC 67 로마 정복 전까지 도시국가로 분열. 로마령 100개 도시, 인구밀도 높고 독립적. 주요 지역: 미항·라새아·살모네. 로마에 자주 민란. 로마 황제들이 그레데 용병 고용.
- 평판 나쁨: 딛 1:12 “그레데인들은 항상 거짓말쟁이며 악한 짐승이며 배만 위하는 게으름뱅이” — 에피메니데스 인용으로 보통 알려짐(강의안에는 “그레데인 중의 어떤 선지자”로만 표기). ‘크레티조’, ‘크레티스모스’ = 거짓말하다. 레오니데스: “항상 도적질하고 노략질하며 불의하다.” 제우스·디오니소스 숭배.
- **구약의 그레데**: 그렛 사람/갑돌 사람/블레셋 사람. 갑돌 = 그레데 섬(렘 47:4, 암 9:7). → 그레데인에게 블레셋의 기질(거칠고, 능숙한 뱃사람, 약삭빠른 상인).

### 교회의 강점과 약점
- 강점: 지도자 디도, 각 성마다 믿는 자들(1:4–5).
- 약점: 지도자가 세워지지 않음(1:5–9), 할례파가 가정들을 무너뜨림(1:10–11), 그레데인의 부도덕(1:12), 거짓 가르침(1:14), 어리석은 변론·족보·분쟁·율법 다툼(3:9), 이단(3:10).

## 본문 관찰 (강의안의 라벨 그대로)

- **1:1–3 “나 바울이 사도 된 것은”**
  - (목록) 바울의 정체성: 하나님의 종 / 예수 그리스도의 사도 / 전도자.
  - 역본 비교: 개역개정, 표준새번역, **헬라어 직역성경**(“에슈아 마쉬아흐의 사도… 하나님의 종 파울”).
  - (목록) 사도 된 목적: 택하신 자들의 믿음 / 경건함에 속한 진리의 지식. 그 내용: 영생의 소망(영원 전 약속) / 자기 때에 말씀을 전도로 나타냄.
  - (단어) 거짓이 없으신(893, **압슈데스**): 조금도 속이지 않는, 신뢰할 만한. 경건(2150, **유세베이아**): 하나님을 창조주·구세주로 존경하는 일상적 행동 전체.
- **1:4** (목록) 디도: 같은 믿음을 따름 / 나의 참 아들.
  - (반복) **구주**: 우리 구주 하나님(1:3, 2:10, 3:4) ↔ 우리 구주 예수님(1:4, 2:13, 3:6) — 교차 배열.
- **1:5–9 그레데에 남겨 둔 이유**: 남은 일 정리 / 각 성에 장로를 세움.
  - (목록) 장로의 조건(1:6) 3가지, 감독의 조건(1:7–9) 13가지.
  - 병행 본문: 딤전 3:1–13, 행 20:28(밀레도 고별설교 “감독자로 삼고”) — 장로 = 감독.
  - (반복/대조) **책망**: 장로·감독은 책망할 것이 없어야 함(1:6, 7) ↔ 거스르는 자는 책망해야 함(1:9), 엄히 꾸짖으라(1:13).
  - 나그네 대접(8): 딤전 3:2, 이스라엘 유목민 문화, 복음 사역과 연관(마 10:10–13, 눅 9:3–4), 출 22:21; 23:9; 신 10:18–19.
  - (단어) 미쁜(4103, **피스토스**; 1:9, 3:8): 참된, 신실한.
- **1:10–16 저희의 입을 막을 것이라**
  - (목록) 거짓 교사의 특징 8가지(불순종·헛된 말·속임, 할례파, 더러운 이득, 거짓말쟁이·악한 짐승·게으름뱅이, 믿음 불온전, 허탄한 이야기, 마음과 양심이 더러움, 행위로 하나님 부인).
  - (**샌드위치**) A 거짓 가르침(1:10–12) / B 엄히 꾸짖으라(1:13) / A′ 거짓 가르침(1:14–16).
  - (대조) 하나님 “거짓이 없으심”(1:2) ↔ 그레데인 “거짓말쟁이”(1:12).
  - (대조) 장로·감독 ↔ 할례파: 불순종 없는 자녀(1:6) ↔ 불순종(1:10) / 더러운 이득 탐하지 않음(1:7) ↔ 더러운 이득(1:11) / 미쁜 말씀 지킴(1:9) ↔ 진리 배반(1:14).
- **2:1–10 바른 교훈에 합당한 것**
  - (단어) 바른(5198, **휘기아이노**): 건강하다.
  - (**교환**) A 교훈 대상 / B 이유: 늙은 남자·늙은 여자·젊은 여자 → 말씀이 비방받지 않게(2:5b) / 젊은 남자 → 대적이 부끄러워 악하다 할 것 없게(2:8b) / 종들 → 하나님의 교훈을 빛나게(2:10b).
  - 2:6–7 본이 되라 ↔ 고전 11:1, 딤전 4:12.
- **2:11–14 하나님의 은혜 / 영광의 나타남**
  - (**환유**) “하나님의 은혜” = 예수 그리스도(2:11).
  - (단어/반복) 나타나(G2014, **에피파이노**): 2:11 은혜가 나타남 / 3:4 자비와 사람 사랑하심이 나타남.
  - (목록) 은혜가 양육하는 것: 불경건과 정욕을 버림 / 신중·의로움·경건으로 삶.
  - 2:14 선한 일에 열심인 백성. **“이미”와 “아직” 사이**.
- **2:15** (**진전**) 말하고 → 권면하고 → 책망하여 → 업신여김을 받지 말라.
- **3:1–8 선한 일을 힘쓰게**
  - (목록) 가르칠 교훈 5가지(복종·선한 일 준비·온유·비방 금지·다툼 금지). 병행: 딤전 2:1–4.
  - (반복/대조) **선한 일**: 성도(2:7, 2:14, 3:1, 3:8, 3:14) ↔ 할례파 “모든 선한 일을 버리는 자”(1:16). 선한 = 칼로스/아가도스. 병행: 딤전 5:9–10.
  - (대조) 우리도 전에는(3:3) ↔ 되어야 할 모습(3:1–2).
  - (**전환**) A 구원 전(3:3) → B 하나님의 자비가 나타날 때 = 그리스도 사건(3:4) → C 구원 후(3:5–7): 중생의 씻음, 성령의 새롭게 하심, 의롭게 됨, 상속자.
  - (**병행**) 2:1–3:8: A 교회/가정(2:1–10) – B 그리스도가 하신 일: 선한 백성(2:11–14) – C 말하고 권면하라(2:15) // A 통치자·모든 사람(3:1–2) – B 그리스도가 하신 일: 상속자(3:3–7) – C 굳세게 말하라(3:8).
  - (대조) 선한 일(3:8: 힘써야 함, 아름답고 유익) ↔ 어리석은 변론·족보·분쟁·율법 다툼(3:9: 피해야 함, 헛되고 무익).
- **3:9–11** (명령) 바울이 디도에게: 2:15 말하고 권면하고 책망 / 3:8 굳세게 말하라 / 3:9 피하라 / 3:10 이단은 한두 번 훈계 후 멀리하라.
- **3:12–14** (목록) 요청: 아데마나 두기고를 보내면 니고볼리로 오라 / 율법교사 세나와 아볼로를 부족함 없이 보내라 / 열매 맺도록 좋은 일에 힘쓰라.
  - 이름 뜻: 아데마 = 아데미의 선물, 세나(제나스) = 제우스의 선물. 두기고: 행 20:4, 엡 6:21, 골 4:7–8, 딤후 4:9, 12, 21. 율법교사 = **노미코스**(법 전문가).
- **3:15** (반복) **믿음 ×5**: 1:1, 1:4, 1:13, 2:1(2:2), 3:15.
