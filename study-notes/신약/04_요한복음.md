### 역사적 배경

1. **예루살렘 멸망(AD 70)**:
   - AD 66 예루살렘에서 작은 정변이 일어남.
   - AD 67–68 **베스파시안 장군과 디도**가 성을 에워쌈.
   - AD 68 **네로가 죽고** 로마가 혼란에 빠짐 → 포위가 풀리고 전쟁이 잠시 소강상태가 됨 → **눅 21:20–21의 예언대로 기독교인들이 탈출**함.
   - AD 70 베스파시안이 황제로 추대됨 → 디도 장군이 예루살렘을 멸망시킴 → **기독교인은 한 명도 죽지 않음**.
   - AD 85 얌니야 회의 결과 기독교인 **“출교”**.
2. **출교의 3단계**:

| 단계 | 내용 |
|---|---|
| ① **니딘**(Niddin) | 30일 동안 약 2m 안에서 사람들과 대화할 수 없음 / 공적 예배 참석은 가능하나 성전 **정문으로는 들어갈 수 없음** / 면도 금지, 슬픔의 옷 착용 |
| ② **케렘**(Cherem) | 첫 단계보다 엄격함 / **10명 이상**이 요구해야 시행됨 / 다른 사람과의 교제 불허 / 성전·회당 출입 금지 |
| ③ **샴마다**(Shammatha) | 모든 유대인과 관계가 끊어짐 / 영원한 파멸에 처해짐 / 죽은 자를 위해 우는 것도 금지 / 죽은 자에게 돌을 던짐 |

3. **회당에서 선포된 저주문**(“18기도문” 제12조 *비르카트 하미님*으로 알려진 것 — 명칭은 보충이며 강의안에는 없음):
   > “배교자들에게는 희망이 없게 되며 완악한 지배자들은 우리 시대에서 멸절되어지리로다. **나사렛 사람들(그리스도인)과 미님(Minim, 이단들)**은 곧 멸망할지어다. 그들은 생명책에서 지워지고 의인들의 반열에도 들지 못할 것이다. 교만한 자들을 낮추시는 주의 축복이 있기를.”
4. **헬라 이원론과 영지주의**:
   - **이원론**: 타락한 영적 존재(**데미우르고스**)가 물질계를 창조함 / 육은 악하고 영은 선함 → **금욕주의**(모든 욕구를 금함) 또는 **쾌락주의**(모든 욕구를 추구).
   - **영지주의**(gnosis = 알다, 추구하다):
     - 지식을 믿음·순종·사랑보다 위에 둠.
     - “무엇을 해야 구원을 얻는가? 우주의 근원적 질서를 어떻게 회복할 것인가?”
     - 구원 = 영적 무지로부터의 해방. 영적 지식은 소수의 특별한 사람에게만 주어짐.
   - **가현설**:
     - 예수(인성)와 그리스도(신성)를 분리함 / 예수는 육체로 오지 않았음 / 육체는 구원의 대상이 아님.
     - 구원은 예수가 전해 준 영적 지식으로 받음.
     - 십자가에서 죽은 것은 육체의 예수이고, 그리스도는 그 전에 육체를 떠났음 — “신이 고난을 받는 것은 말이 안 됨”.
   - (해석) 1:14 “말씀이 **육신**이 되어”, 19:34–35 피와 물을 본 증언, 20:27 도마에게 몸을 보이심 → 가현설을 반박하는 본문으로 연결됨.

### 2:1–4:54 성전 되시는 예수

- **2:1–12 첫 번째 표적**:
  - 2:1 사흘째 되던 날.
  - 2:4 “**내 때**가 아직 이르지 아니하였나이다” — **때 = 십자가**(4:21; 7:30 …).
  - 2:6–10 물이 포도주로 변함 → 2:11 첫 표적, 제자들이 믿음.
- **2:13–25 성전 정화**:
  - 2:14–15의 성전 = 예루살렘 성전(건물, *히에론*).
  - 2:19–21의 성전 = **지성소**(*나오스*) = **예수님**.
    - 헬라어 단어 구분은 보충. 강의안은 “성전 = 지성소 = 예수님”이라고만 씀.
  - 2:23–25 표적을 보고 믿은 사람들에게 예수께서 자신을 의탁하지 않으심.
- **3:1–36 니고데모 — 누가 하나님의 백성인가?**
  - “거듭” = 헬 **아노센** = 위로부터, 처음부터, 다시, 새로이. 유대인은 혈통으로 이미 하나님의 백성이라 여겨 이 말을 자신에게 쓰지 않았고, **이방인에게 쓰는 단어**였음.
  - 3:4 니고데모의 오해: “두 번째 모태에 들어갔다가 날 수 있사옵나이까?”
  - 3:5 “**물과 성령**으로” — “과” = 헬 **카이** = “**즉**” → **물 즉 성령**(7:38–39 생수의 강 = 성령; 14:26).
  - 3:16–21 참된 거듭남: 3:16 / 3:17 세상이 구원을 받게 하려 하심 / 3:18 믿지 않는 자는 **벌써 심판을 받은 것**.
  - **영생**(3:15, 16, 36 … 17:3 — 요한복음에 *17번*): 히브리어 “오는 세대의 삶”을 옮긴 말. 시간적인 뜻이 아니라 하나님이 다스리시는 오는 세대, 곧 **구원의 시대의 삶** → `03_누가복음.md`의 같은 정의(김세윤).
  - 3:22–36 세례 요한의 증언: 세례 요한(**옛 언약**) → 예수님(**새 언약**) / 3:30 “그는 흥하여야 하겠고 나는 쇠하여야 하리라”.
  - 질문: **참 이스라엘 사람은? 참 성전은? 참 하나님의 백성은?** → 예수 그리스도.
- **4:1–42 사마리아 여인**:
  - **《교차》**: A 1–14 예수님의 갈증, 물 / B 15–30 사마리아 여인의 갈증, 예배 / A′ 31–38 예수님의 양식 / B′ 39–42 사마리아인들의 구원.
  - **니고데모 vs 사마리아 여인**:

| 밤 | 낮(정오) |

| 예루살렘 | 사마리아 |
| 도덕적으로 깨끗함 | 도덕적으로 흠이 있음(남편 다섯) |

### 5:1–7:52 하나님의 아들 (ἐγώ εἰμι)

- **5:1–18 38년 된 병자**:
  - **신 2:14** “38년 … 모든 군인들이 다 멸망”과 연결함. 병자와 광야 군인들이 멸망한 원인은 똑같이 **죄**.
  - 결말은 대조됨: 병자는 **구원**, 이스라엘 군인은 **죽음**.
  - 안식일 — 5:17 “내 아버지께서 이제까지 일하시니 나도 일한다”.
- **5:19–29 심판의 권세** (교차):
  - A 22–24 심판을 맡기심, 믿는 자는 영생
  - B 25 “아들의 음성을 들을 때가 오나니 **곧 이때라**”(살아나리라)
  - A′ 26–27 심판하는 권한을 주심
  - B′ 28 그의 음성을 들을 때가 오나니(선 = 생명, 악 = 심판)
- **5:30–47 다섯 가지 증거**:
  1. 33–35 요한의 증언(1장, 3장).
  2. 36 내가 하는 역사(**표적들**).
  3. 32, 37–38 아버지께서 친히 증언하심.
  4. 39 **성경**.
  5. 46 **모세**(“모세를 믿었더라면 나를 믿었으리라”).
- **6장**:
  - 1–15 오병이어.
  - 16–21 물 위를 걸으심 — 20 “**내니** 두려워 말라”: 내니(나다) = **ἐγώ εἰμι(에고 에이미)** = 출 3:14 “나는 스스로 있는 자”. 70인역에서 여호와를 ἐγώ εἰμι로 옮김.
  - 22–59 **나는 생명의 떡**(35):
    - 예수님의 살과 피(51, 53–56). 유월절 = 양고기와 무교병을 먹는 날 → “예수님을 먹어야 산다”.
    - 52 “어찌 능히 … 먹게 하겠느냐” ↔ 63 “**살리는 것은 영이니**”.
    - “**마지막 날에 다시 살리리라**”(39, 40, 44, 54).
- **7장 초막절**:
  - 수장절 = 장막절 = 초막절. 레 23:42–43 광야의 초막 생활을 기억함 / 한 해 농산물의 최종 수확을 완성함(신 14:22–29) / 민 29:12–38.
  - **8일째 대성회**: “**심하 토라**”(*Simchat Torah*) = 강의안의 번역은 “큰 구원의 날”.
    - 보충: *심하트 토라*는 보통 “토라의 기쁨”으로 번역됨 — 강의안 번역과 다르므로 확인이 필요함.
    - 토라 두루마리를 1년 주기로 낭독하는 일을 마감함.
    - 모든 사람이 **여인의 뜰**로 내려감 / **황금 등대 4개**에 불을 밝힘 → 8:12 “나는 세상의 빛”의 배경 (해석).
    - 신 14:22–29 초막절에 드리는 십일조 / 여인의 뜰에 **뿔나팔 모양 연보궤 13개**(→ 8:20 “헌금함 앞에서”의 배경, (해석)).
  - **7:37–39 생수의 강 = 성령**: 겔 47:1–5(발목 → 무릎 → 허리 → 건너지 못할 강) / 슥 14:8(생수가 예루살렘에서 솟아나 절반은 동해로, 절반은 서해로) / 합 2:14(물이 바다를 덮음같이).
- **《카이아즘》 5:1–7:52**:
  - A 5:1–47 38년 된 병자가 나음 → **참 안식**

  - **C 6:16–25 “내니(ἐγώ εἰμι) 두려워 말라”** (중심)
  - B′ 6:26–70 모든 사람을 살리는 예수님의 살과 피
  - A′ 7:1–52 초막절(**생수의 강**)

### 7:53–8:59 세상의 빛, 진리

- **7:53–8:11 간음한 여인** (재판 형식):
  - 고소인: 서기관·바리새인 / 피고소인: 간음한 여인 / 고소 내용: 간음하다 잡힘(율법에 근거).
  - 고소 목적: **예수를 시험하려고** / 판결: 죽음? 무죄?
- 8:12–20 “**나는 세상의 빛**” — 예수님의 증언과 판단은 참됨. 율법의 두 증인 = **예수님과 하나님**.
  - 강의안은 “7:12–20”으로 표기 → 8:12–20의 **오기 추정**. 이어지는 “7:21–30”, “7:24”도 8:21–30, 8:24의 오기로 보임.
- 8:21–30 믿지 않는 자들의 심판 — 8:24 “**내가 그인 줄 믿지 아니하면** 너희 죄 가운데서 죽으리라”(내가 그인 줄 = ἐγώ εἰμι, 보충). 16:9 **죄 = 예수님을 믿지 않는 것**.
- 8:31–59 “**진리가 너희를 자유롭게** 하리라”:
  - 진리 = 예수님 / 자유 = 율법과 전통으로부터의 자유(강의안 원문: “자유 = 율법과 전통”).
  - 33–59 논쟁: 아브라함(혈통과 전통) vs 예수님(진리) → 59 돌을 들어 치려 함.

### 9:1–11:57 맹인·선한 목자·나사로

- **9장**: 소경을 고침 = **그리스도(메시아)의 사역**(사 35:5; 42:7; 눅 7:22) / 9:5 = 8:12 “나는 세상의 빛” / 9:22 **출교** / 30–33 소경이었던 사람의 고백.
- **10:1–21 양의 문, 선한 목자**:
  - 7 “나는 양의 문” — 9 나로 말미암아 들어가면 구원 / 10 생명을 얻게 하고 더 풍성히 얻게.
  - 11 “나는 선한 목자” — 11, 14 양을 위해 목숨을 버림 / 14 나는 내 양을 알고 양도 나를 앎 / 16 **우리에 들지 아니한 다른 양들**(이방인, 해석) / 17 목숨을 버리는 것은 다시 얻기 위함.
- **10:22–39 수전절(하누카) = “빛의 명절”**: **안티오쿠스 에피파네스**가 BC 168년 예루살렘 성전을 더럽히고 유대인을 박해하자, 제사장 **마카비**를 중심으로 전쟁이 일어남 → **BC 164년** 성전을 수리하고 성별하여 봉헌한 절기. → `00_신구약중간사.md`
- **11장 나사로**:
  - 목적: 4 “하나님의 아들이 … 영광을 받게”.
  - 6 이틀을 더 유하심 / 8 “유대인들이 돌로 치려” 하는데도 가심 = 10:14 선한 목자.
  - 25 “**나는 부활이요 생명이니**” / 43 “나사로야 나오라!”
- **《교차》 9–11장**: A 9장 맹인을 보게 함(메시아의 표적) / **B 10장 양의 문, 선한 목자** / A′ 11장 죽은 자를 살리심(메시아의 표적).

### 13–17장 — 사랑이신 예수, 고별 강화

- **13장**:
  - 1 “**끝까지 사랑하심**” — 가룟 유다는?
  - 2–19 발을 씻기심 → 14–15 “너희도 서로 발을 씻겨”.
  - 21–30 영광을 얻으심 / 34–35 **새 계명** / 36–38 세 번 부인할 것.
- **14장**:
  - 1 하나님을 믿으니 또 나를 믿으라.
  - 2 “내 아버지 집에 **거할 곳**이 많도다” — 거할 곳 = 헬 **모네**(거주지). 14:23 “거처”와 함께 요한복음에서만 두 번 쓰임 → **거할 곳 = 영적 관계로 해석**(천국의 방 개념이 아님).
  - 20–21 “그날에는 … 내가 아버지 안에, 너희가 내 안에, 내가 너희 안에”.
  - **보혜사 성령**: 16 영원토록 함께 / 17 진리의 영, 세상은 알지 못하나 제자들은 앎, 너희와 함께 거하시고 너희 속에 계심 / 26 아버지께서 **내 이름으로** 보내실 성령, 모든 것을 가르치고 생각나게 하심.
- **15장**:
  - 1–8 참포도나무와 가지 — “내 안에 **거하라**” — 거하라 = 헬 **메노** = 머무르다, **반대에 맞서다**.
  - 9–17 사랑 안에 거하라 / 14–15 **친구**로 부르심 / 18–25 세상이 너희를 미워할 것.
- **《교차》 15:18–16:15**: A 15:18–25 세상이 미워할 것 / B 15:26–27 성령이 증언하실 것 / A′ 16:1–6 출교할 것 / B′ 16:7–15 성령이 알게 하실 것.
- **16장 — 《인클루지오》**:
  - A 16:1–4 실족하지 않게 하려 함 ↔ A′ 16:33 “세상에서는 너희가 환난을 당하나 담대하라 **내가 세상을 이기었노라**”.
  - 내용: 1–6 출교할 것 / 7–15 성령의 행하심 / 16–24 깨닫지 못하는 제자들 / 25–33 비로소 믿는 제자들.
- **17장 하나님 아들의 기도**:
  - 1–5 “영화롭게 하였사오니 영화롭게 하옵소서” — 영화롭게 = 찬양하다, **영광에 참여하다**. 12:28 “영광스럽게 하였고 또다시 영광스럽게 하리라”, 12:30–31 십자가 → **영화롭게 하는 것 = 십자가(18–20장)**.
  - 9–19 제자들을 위한 간구: 9 내게 주신 자들 / 11 보전하사 **하나 되게** / 13 내 기쁨이 충만하게 / 15 악에 빠지지 않게 보전 / 17, 19 **진리로 거룩하게**.
  - 20–26 믿게 될 모든 자를 위한 간구: 21 다 하나가 되어 우리 안에 있게 / 22 하나 되게 / 24 나의 영광을 보게 / 26 나를 사랑하신 사랑이 그들 안에. **하나 됨**이 반복됨(21, 22, 23).

### 18–21장 — 죽으심과 부활 (제7표적)

- **《교차》 18:1–27**: A 1–14 잡히심 / B 15–18 베드로의 부인 / A′ 19–24 심문당하심 / B′ 25–27 베드로의 부인.
- **18:28–19:16 빌라도의 심문**:
  - “네가 유대인의 왕이냐?”(33절; 강의안 “23절”은 **오기 추정**).
  - 36 “**내 나라는 이 세상에 속한 것이 아니니라**” / 38 아무 죄도 찾지 못함.
  - 19:12 빌라도가 놓으려 힘씀 / 19:15 대제사장들 “**가이사 외에는 우리에게 왕이 없나이다**” → 유대인들에게 넘김.
- **19:17–30 십자가**:
  - 명패 “나사렛 예수 유대인의 왕” — **히브리·로마·헬라 말**로 기록.
  - 26 “여자여 보소서 아들이니이다”.
  - 30 “**다 이루었다**” … 머리를 숙이니 영혼이 떠나가시니라.
- **19:31–42 장사**: 34 창으로 찌르니 **피와 물** / 35 “이를 본 자가 증언하였으니 그 증언이 참이라”(목격자 저자) / 40 유대인의 장례법대로.
- **20장 부활**:
  - 1–23 부활하신 예수님 — 22 “**성령을 받으라**” — 받으라 = 헬 **람바노** = 영접하다 = **1:12**(“영접하는 자”)와 같은 단어.
  - 24–29 도마의 의심 → 28 고백 “**OUR LORD, OUR GOD**”(나의 주님이시요 나의 하나님이시니이다, 도미티안 배경) → 29 “보지 못하고 믿는 자들은 복되도다”.
- **21장 초대**:
  - 1–14 제자들에게 나타나심.
  - 15–19 베드로를 부르심(초청) — “**네가 나를 사랑하느냐?**” ×3.
  - 20–23 요한의 이야기 / 24–25 “우리는 그의 증언이 참된 줄 아노라”.

## 주석용 핵심 메모

- 요한복음 읽기의 틀: **표적 7 + ἐγώ εἰμι 7**, 출교(9:22; 12:42; 16:2)는 AD 85 얌니야 배경, 가현설 반박(1:14; 19:34–35).
- **“때”** = 십자가(2:4 → 12:23 → 17:1).
- **처음 6일 ↔ 마지막 6일** 수미상관.
- 누가복음과 같은 “영생” 정의(오는 세대의 삶).
- 오기 추정 목록:
  - 8장을 “7:12–20 / 7:21–30 / 7:24”로 표기함.
  - 18:33을 “23절”로 표기함.
  - “와의 신하”(p42) → 왕의 신하.
