## BRI

### 저자 — 사도 베드로

- 직접 언급: “예수 그리스도의 사도 베드로는”(1:1).
- 본문에 나타난 특징:
  - 5:1 교회의 지도자로서 **장로들에게 권면할 수 있는 위치**(“함께 장로 된 자”).
  - 5:1 **그리스도의 고난을 목격**한 자.
  - 5:2 **양 무리를 치는** 사역을 언급함(요 21:15–17과 연결, (해석)).
  - **사도행전의 베드로 설교와 유사함**: 벧전 1:17 ↔ 행 10:34–44(하나님은 외모로 사람을 취하지 않으심) / 벧전 2:6–8 ↔ 행 4:11(버린 돌이 모퉁잇돌).
- 동역자: 5:13 **마가를 ‘내 아들’**로 부를 수 있는 사람.
- 외증: 폴리캅, 이레네우스, 클레멘트, 터툴리안.

### 수신자 — 소아시아에 흩어진 유대인과 이방인 그리스도인

- **유대인**: 1:1 “**본도, 갈라디아, 갑바도기아, 아시아와 비두니아**에 흩어진 나그네” — 흩어진 = **디아스포라**(분산, 흩어진 유대인) / 구약 인용이 많음(1:16, 24–25; 2:3, 6–10, 22; 3:10–12; 4:18; 5:5).
- 지도: 소아시아의 흩어진 나그네(Asia Minor, Crete, Corinth).
- **이방인**: 1:14 “전에 **알지 못할 때에** 따르던 너희 사욕” / 1:18 “**조상이 물려준 헛된 행실**” / 2:10 “**전에는 백성이 아니더니** 이제는 하나님의 백성”.
- ☞ **소아시아에 사는, 그리스도를 믿는 흩어진 유대인과 이방인**.

### 기록 연대 — AD 64 로마 대화재 직후

- 본문의 특징:
  - **고난 17번** 반복.
  - 시험(1:6; 4:12) / **불**(1:7; 4:12 “불시험”).
  - 독자들을 **악행한다고 비방하는** 자들(2:12) / 악하게 하고 욕하는 자들(3:9).
  - **선을 행하라 11번** 반복.
  - “너희 대적 마귀가 **우는 사자**같이 두루 다니며 삼킬 자를 찾나니”(5:8).
  - **로마를 ‘바벨론’으로** 표현함(5:13).
- ☞ **로마 대화재 직후, AD 64년**.

### 기록 장소 — 로마

- 5:13 “택하심을 함께 받은 **바벨론에 있는 교회**가 너희에게 문안하고” ☞ **로마**.

### 역사적 배경 — AD 64년 로마 대화재와 네로의 박해

- **화재**: AD 64년 7월 18–19일 밤에 시작해 **9일(18–26일)** 동안 계속됨.
  - 시오노 나나미 『로마인 이야기』: 불이 났을 때 네로는 무더위를 피해 로마에서 남쪽으로 50km 떨어진 해변 도시 **안치오**의 별장에 있었음.
  - 수에토니우스 『열두 명의 카이사르』: 네로가 ‘황금궁전’ 근처의 돌로 지은 곡식 창고 몇 개를 공성 기구로 부수고 안에 불을 질렀다.
  - 두 자료는 네로 방화설에 대해 서로 다른 인상을 줌 (해석).
- **로마 14개 행정구역 피해**: **3개 구역 전소**(3, 10, 11) / 7개 구역 반소(2, 4, 7, 8, 9, 12, 13) / 무사한 구역 1, 5, 6, 14 — **유대인이 거주한 곳은 14구**(무사함 → 의심을 받을 수 있는 상황, (해석)).
  - 원출처는 타키투스(“14구역 중 3구역 전소, 7구역 일부 남음”, 『연대기』 15권)로 알려져 있음 — 보충.
- **로마인들이 기독교인을 보는 시각**:
  - **유일신 사상의 포교** — 다신교인 그들에게는 쓸데없는 참견.
  - **성만찬에 대한 오해** — 살을 먹고 피를 마신다고 여겨 혐오함.
  - **근친상간자** — “형제여, 자매여, 당신을 사랑합니다” 같은 말을 한다는 이유로.
- **처형 방법**:
  - 야수의 모피를 뒤집어씌우고 들개 떼에게 물려 죽게 함.
  - 로마의 일반적인 처형법인 **십자가**.
  - 땅에 박은 말뚝에 묶어 산 채로 불을 붙여 **밤의 구경거리**로 삼음.
- → 4:12 “**불시험**”, 4:14 “그리스도의 이름으로 치욕을 당하면”, 4:16 “**그리스도인**으로 고난을 받으면”의 배경 (연결은 해석).

### 중심 내용과 기록 목적

- **중심 내용**: **하나님의 뜻대로 고난을 받는 자들은 선을 행하는 것을 멈추지 말고, 선하신 창조주를 온전히 의지하라**(4:19).
- **기록 목적**:
  1. 고난 중에도 **산 소망**을 가지고 거룩한 삶을 살도록.
  2. 고난 가운데 있는 성도를 위로하고 믿음이 흔들리지 않게 하려고.
  3. 고난 중에도 **본을 보이신 예수님**을 따라 선을 행하고 창조주 하나님을 의지하도록.

## 본문

### 1:1–25 산 소망 되신 말씀을 믿고 따르는 거룩한 삶

- 저자 1:1 예수 그리스도의 사도 베드로 / 수신자 1:1 흩어진 **나그네** — 흩어진(디아스포라) + **나그네(파레피데모스: 외국인, 거류인, 체류자)**.
- **〈목록〉 성도의 정체성(1:1–2)**: 흩어진 나그네 / **하나님 아버지의 미리 아심을 따라 택함받은 자들**(택하심 = **에클렉토스**: 고르고 고른, 정선한 — *choice, selected*) / **성령으로 거룩하게** 된 자 / **예수 그리스도께 순종**하는 자 / **예수 그리스도의 피로 씻긴** 자 (삼위 하나님 구도, (해석)).
- **〈병행〉 1:3–25 — A(하나님이 하신 일) – B(그러므로, 때) – C(너희가 행할 일)가 세 번 반복**:

| | A 하나님이 하신 일 | B 그러므로 — 때 | C 너희가 행할 일 |
|---|---|---|---|
| 병행 1 | **1:3–5** 예수 그리스도를 죽은 자 가운데서 부활하게 하심 / 우리를 거듭나게 하사 **산 소망** / 유업을 잇게 하심 | **1:6–7** 여러 가지 시험으로 잠깐 근심하나 크게 기뻐함 — **예수 그리스도께서 나타나실 때** 영광과 존귀 | **1:8–9** 보지 못하였으나 사랑함 → 믿음의 결국 = **영혼의 구원** |
| 병행 2 | **1:10–12** 이 구원은 선지자들이 연구하고 살핀 것 / 그리스도의 영이 고난과 영광을 미리 증언함 / 성령으로 복음 전하는 자들이 알림 / **천사들도 살펴보기를 원함** | **1:13** 마음의 허리를 동이고 근신하여 **예수 그리스도께서 나타나실 때** 가져다주실 은혜를 온전히 바라라 | **1:14–17** 부르신 거룩한 이처럼 **모든 행실에 거룩한 자**가 되라 / 나그네로 있을 때를 두려움으로 지내라 |
| 병행 3 | **1:18–21** 대속은 **흠 없고 점 없는 어린양 같은 그리스도의 보배로운 피**로 된 것 / 창세 전부터 미리 알려졌으나 이 말세에 나타나심 | (C 다음에 옴) **1:24–25** 모든 육체는 풀, 영광은 풀의 꽃 — **오직 주의 말씀은 세세토록 있도다** = 너희에게 전한 복음 | **1:22–23** 거짓 없이 형제를 사랑하고 **마음으로 뜨겁게 서로 사랑하라** / 썩지 아니할 씨, **살아 있고 항상 있는 말씀**으로 거듭남 |

  - 세 번째에서 B와 C의 순서가 바뀌고, “때”가 “나타나실 때”에서 “**세세토록**”으로 확장됨 → 1장 제목의 “세세토록 있는 말씀”이 결론이 됨 (해석).

### 2:1–12 보배로운 모퉁잇돌을 믿는 자 = 거룩한 제사장 — 《카이아즘》

- A **명령**: 악한 행위를 버리고 **신령한 젖**을 사모하라 / 이유: 구원에 이르도록 자라게(2:1–3)
- B 〈대조〉 **보배로운 산 돌** 예수를 대하는 태도: 사람에게는 **버림받음** / 하나님께는 **택하심**을 입음(2:4)
- C **신분 변화**(예수 그리스도로 말미암아, 2:5): 너희도 **산 돌**같이 → **신령한 집**으로 세워지고 / 신령한 제사를 드릴 → **거룩한 제사장**
- **D 2:6–8 “내가 택한 보배로운 모퉁잇돌을 믿는 자는 부끄러움을 당하지 아니하리라”** — 〈대조〉 믿는 너희 vs 믿지 않는 자(버린 돌 → 머릿돌, 부딪치는 돌)
- C′ **신분 변화**(보배로운 산 돌을 믿은 결과, 2:9): **택하신 족속, 왕 같은 제사장들, 거룩한 나라, 그의 소유가 된 백성**
- B′ 〈대조〉 믿은 후의 변화(2:10): **전에는 백성이 아니더니 이제는 하나님의 백성**
- A′ **명령**: 육체의 정욕을 제어하라 / 이유: 너희를 악행한다고 비방하는 자들이 **선한 일을 보고** 오시는 날에 하나님께 영광을 돌리게(2:11–12)

### 2:13–3:9 관계 안에서 선을 행하고 순종하라

- **〈명령〉 대상별 분량(절 수)**: ① 모든 제도·왕(2:13–17, 강의안 “7절” — 2:11–17을 센 것으로 보임) / ② **종들(2:18–25, 8절)** / ③ **아내(3:1–6, 6절)** / ④ 남편(3:7, 1절) / ⑤ 너희(3:8–9, 2절). 분량이 곧 **강조점(수위)**. 특히 **종과 아내** — 사회적 약자에게 가장 길게 말함 (해석).
- **① 모든 제도·왕(2:13–17)**: 인간의 모든 제도를 **주를 위하여** 순종하되 왕이나 총독에게 / 이유(15): **선행으로 어리석은 사람들의 무식한 말을 막으려고** / 16 자유가 있으나 그 자유로 악을 가리는 데 쓰지 말고 **하나님의 종**과 같이 / 17 뭇 사람을 공경하며 형제를 사랑하며 **하나님을 두려워하며 왕을 존대하라**.
- **② 종들(2:18–25)**:
  - 명령(18): 범사에 두려워함으로 주인에게 순종하되 **선하고 관용하는 자에게만이 아니라 까다로운 자에게도**.
  - 이유 ①(19–20 교차): A 부당하게 고난을 받아도 하나님을 생각하여 슬픔을 참으면 아름다움 / B 죄가 있어 매를 맞고 참으면 무슨 칭찬이 있으리요 / A′ **선을 행함으로 고난을 받고 참으면 하나님 앞에 아름다움**.
  - 이유 ②(21–25): **그리스도께서 본을 끼쳐 그 자취를 따라오게** — 죄를 범하지 않으시고, 욕을 받으시되 대신 욕하지 않으시고, 공의로 심판하시는 이에게 부탁하시며, 나무에 달려 우리 죄를 담당하심, 그가 채찍에 맞음으로 너희는 나음을 얻음(사 53장).
- **③ 아내들(3:1–6) 〈샌드위치〉**: A 남편에게 순종하라 — 말로 말미암지 않고 **행실로** 구원을 얻게(1–2) / B 외적 단장이 아니라 **썩지 아니할 온유하고 안정한 심령**으로 단장하라(3–4) / A′ 거룩한 부녀들같이 순종하라 — **사라가 아브라함에게 한 것같이**(5–6).
- **④ 남편들(3:7)**: 1절뿐 — 질문: **“고대 헬라 시대의 여성관은?”** → 아내를 더 연약한 그릇이요 **생명의 은혜를 함께 이어받을 자**로 알아 귀히 여기라는 말이 당시에는 파격적 (해석; `05_사도행전.md` [배경] 여성 항목 참조).
- **⑤ 너희(3:8–9)**: 마지막으로 — 마음을 같이하여 동정하며 형제를 사랑하며 불쌍히 여기며 겸손하며 / **악을 악으로, 욕을 욕으로 갚지 말고 도리어 복을 빌라** / 이유: **복을 이어받게** 하려 하심이라.

### 3:10–4:19 고난 중에 선을 행하고 창조주께 의탁하라

- **〈병행〉 3:10–22 — 악에서 떠나 선을 행함으로 고난을 받으면 복이 있다**:

| | 1차 | 2차 |
|---|---|---|
| A | 악에서 떠나 선을 행하라(3:10–11, 시 34편) | **선을 행함으로 고난받는 것이 하나님의 뜻이면, 악을 행함으로 고난받는 것보다 나음**(3:17) |
| B | **하나님은 어떤 분?**(3:12) — 의인을 향한 눈, 악인을 대하시는 얼굴 | **예수님은 어떤 분?**(3:18–19) — 의인으로서 불의한 자를 대신하여 단번에 죽으심, 영으로 살리심 |
| C | **의를 위하여 고난을 받으면 복이 있음**(3:13–15) — 그들의 두려움을 두려워하지 말고 소망에 관한 이유를 묻는 자에게 대답할 것을 준비하라 | 의를 위해 고난받는 자는 구원을 얻음(3:20 — 노아 때 여덟 명) |
| D | **선한 양심**을 가지라(3:16) | **하나님을 향한 선한 양심의 간구**(3:21–22 — 세례) |

- 4:1–6 그리스도께서 육체의 고난을 받으셨으니 너희도 같은 마음으로 갑옷을 삼으라(강의안에 별도 슬라이드 없음 — 보충).
- **〈병행〉 4:7–19 — 하나님의 뜻대로 고난받는 자들은 선을 행하고 영혼을 하나님께 의탁하라**:

### 5:1–14 믿음을 굳게 하라

- **장로들아(5:1–4)**: 함께 장로 된 자, 그리스도의 고난의 증인 / **하나님의 양 무리를 치되** 억지로 하지 말고 자원함으로, 더러운 이득을 위하지 말고 기꺼이, 주장하는 자세를 하지 말고 **양 무리의 본**이 되라 → 목자장이 나타나실 때 **시들지 아니하는 영광의 관**.
- **젊은 자들아(5:5–6)**: 장로들에게 순종하라 / 모두 서로 **겸손으로 허리를 동이라** — 하나님은 교만한 자를 대적하시고 겸손한 자에게 은혜를 주심(잠 3:34) / 하나님의 능하신 손 아래에서 겸손하라.
- **너희(5:7–11)**: 염려를 다 주께 맡기라 / 근신하라 깨어라 — **대적 마귀가 우는 사자같이** / 믿음을 굳건하게 하여 대적하라 / 세상에 있는 너희 형제들도 같은 고난을 당함 / 잠깐 고난을 당한 너희를 **온전하게 하시며 굳건하게 하시며 강하게 하시며 터를 견고하게** 하시리라.
- 5:12–14 **실루아노**로 말미암아 간단히 썼음(대서인 — `05_사도행전.md` [배경] 통신 항목) / 바벨론에 있는 교회와 **내 아들 마가**의 문안.
  - 5:7–14의 세부는 보충. 강의안에는 대상별 구분만 있음.

## 주석용 핵심 메모

- 핵심: **고난(17회) + 선을 행하라(11회) + 창조주께 의탁**. 배경은 **64년 로마 대화재와 네로 박해**, 수신자는 소아시아의 나그네 된 교회.
- 성도의 정체성: 나그네, 택함받은 자, 산 돌, 거룩한 제사장, 왕 같은 제사장, 하나님의 백성.
- 구조 기법: A-B-C 병행 3회(1장), 카이아즘(2:1–12), 분량으로 본 강조(2:13–3:9), 병행 3회(4:7–19) — 1장과 4장 모두 **마지막 반복에서 순서를 바꿔 결론을 강조**함.
- 베드로의 기억(목격자, 양 무리, 모퉁잇돌 설교)을 주석에 연결할 것.
