## 사랑의 사도 — 사도 요한 [사도요한]

- 이름 **요한** = “여호와를 사랑한다”(강의안 풀이. 보통은 ‘여호와는 은혜로우시다’로 풀이함 — 보충, 확인 필요).
- **1. 복음서에 나타난 요한**:
  - ① **세베대와 살로메의 아들**(마 4:21; 27:56; 막 15:40; 16:1).
  - ② 야고보의 형제, **갈릴리 어부**(마 4:21).
  - ③ **세례 요한의 제자였다가** 예수님을 따름(요 1:35–40) → `04_요한복음.md` 저자 항목의 “요한의 제자(?)”와 일치.
  - ④ 예수님 가까이에 있던 **3명의 제자** 중 하나(눅 8:51; 마 17:1; 막 14:33):
    - 변화산 사건을 목격함(막 9:2).
    - 야고보와 함께 **‘우레의 아들(보아너게)’**이라는 별명(막 3:17).
    - 자리를 부탁해서 다른 제자들을 화나게 함(마 20:20–28; 막 10:35–39) — “주님이 마시는 **잔**, 받는 **세례**를 받겠다”.
    - 최후의 만찬에서 예수님 품에 기대어 있었음(요 13:23).
    - 십자가 현장에 가까이 있었고 **예수님의 어머니 마리아를 부탁받음**(요 19:26).
    - 부활의 아침 **빈 무덤을 베드로보다 먼저** 봄(요 20:4).
    - 디베랴에서 예수님을 알아본 사람(요 21:7).
    - 그의 죽음에 대해 예수님께 예언을 받음(요 21:21–23).
- **2. 교회 시대의 요한**:
  - 베드로와 함께 앉은뱅이를 일으킴(행 3장) / 행 3–4장의 중요한 사건에 베드로와 함께함.
  - 베드로와 함께 **사마리아**에 파견됨(행 8:14).
  - 형제 **야고보를 순교자로 잃음**(행 12:2).
  - 바울의 표현으로 예루살렘 교회의 **‘기둥’** 중 하나(갈 2:9).
  - 예루살렘 공회에 참석(행 15장).
- **3. 교회의 전승**:
  - **AD 70년경** 예수님의 예루살렘 멸망 예언을 따라 멸망 전에 기독교인들을 데리고 예루살렘을 떠나 **에베소로 피신** → 유대인들은 요한과 기독교인을 **배신자**로 여김 → 회당 출교 문제로 이어짐(`04_요한복음.md` 출교·얌니야와 연결).
  - 에베소에서 **에베소 주교**가 되어 교회를 다스림. 이레니우스(요한의 직계 제자 **폴리갑**의 제자)의 증거에 따르면 요한은 **트라야누스 황제(98–117) 재위 기간까지** 에베소에 있었음 → **제자들 중 가장 오래 산 사람**.
- **4. 성품 — 복음서와 전승의 대조**:
  - 복음서: ‘우레의 아들’이라 불릴 만큼 **급한 성격**, 예수님을 통해 이루려는 **야망**.
  - 전승: **사랑의 사도**. 제롬이 전하는 일화 — 늙어 설교할 수 없게 되자 가끔 교인들 앞에 나가 “**어린 자녀들이여, 서로 사랑하시오**”라는 같은 말만 되풀이함 → 왜 같은 말만 하느냐고 묻자 “**이것이 주님의 명령이기 때문입니다! 이것만 잘 실천한다면 그것으로 충분합니다.**”
  - **예수님의 생존하는 마지막 제자, 가장 확실한 증인** — 1세기 후반 대부분의 증인이 떠난 시점에서 예수님에 대한 여러 증언의 진위를 확인할 권위.
  - **유세비우스**: AD 95년 도미티안의 핍박으로 **밧모섬 유배** → 에베소로 돌아와 **AD 100년경 사망**.
  - **터툴리안**: 베드로와 함께 로마로 보내져 **끓는 기름**에 던져졌으나 기적적으로 살아났고, 독배를 마실 때 컵이 뱀으로 변해 살았다는 전설 → 진위와 상관없이 **박해의 한가운데**를 지났음을 보여 줌 — “주님이 마시려는 잔”.
  - **진리의 수호자**: 이레니우스가 전하는 일화 — 노년의 요한이 공중목욕탕에서 영지주의자 **케린투스**를 만나자 “케린투스 때문에 목욕탕이 무너질 것이니 도망가라”고 함.
  - 말년에 제자들에게 안겨 다니며 “사랑하는 자들아 서로 사랑하라”고 전함.
- **최후의 사도, 마지막 증인**: 재림이 지연되고 첫 증인들이 순교와 자연사로 사라져 가던 때, 거짓 선지자들의 가르침과 성경 변개를 분별할 남은 사도의 권위는 절대적이었음 → **케논(기준), 곧 정경의 확정**을 재촉했을 것. 요한은 모든 힘을 다해 거짓 가르침에서 교회를 지키는 데 힘썼을 것이고, 요한1–3서의 **사랑**에 대한 언급이 그 모습을 보여 줌.

### 1. 저자 — 사도 요한

- **발신자의 이름이 나오지 않음**.
- ① **“우리”라는 특별한 대명사** — 1:1–4 “우리가 이것을 씀은”(**1인칭 복수 ‘우리’ 약 100번**) / 2:1, 7, 8, 12–14, 21, 26; 5:13 “내가 … 쓰는 것은”.
  - 우리는 누구인가? → 1:1 “우리가 **들은** 바요 **눈으로 본** 바요 **자세히 보고 손으로 만진** 바” / 1:2–3 영원한 생명을 보았고 증언하여 너희에게 전함(4:14) / 1:3 우리의 **사귐** / 1:5 그에게서 듣고 전하는 소식 → **목격자, 제자, 사도**(눅 1:2; 히 13:7).
- ② 수신자에 대한 특별한 호칭 — 2:1 “**나의 자녀들아**”(아비들아, 청년들아, 아이들아, 사랑하는 자들아) / 5:21 “자녀들아”.

### 2. 기록 연대 — AD 96–100 이전, 에베소

- ① 독자들이 이미 계명을 들었음 — 2:7–8 새 계명이 아니라 **옛 계명** / 2:24 “처음부터 들은 것” / 3:11 “처음부터 들은 소식” → **요한복음 이후**.
- ② 2:13 “너희가 **악한 자를 이기었음**” → **도미티안 박해(AD 85–95)가 끝난 이후**, 요한계시록 이후.
- ③ **적그리스도가 이미 활동을 시작함** — 2:18 “지금도 많은 적그리스도가 일어났나니” / 2:19 “그들이 **우리에게서 나갔으나**” → 이단과 갈등하고 분리를 겪음 / 예수가 그리스도이심을 부인하는 자(2:22) / 예수를 시인하지 않는 영(4:3).
- 종합:
  - 저자의 **노년기**에 쓴 것처럼 보임, 저자의 권위.
  - **박해에 대한 언급이 없음**(90–95년 도미티안 박해) — “악한 자를 이기었음 / 흉악한 자를 이기었음”(2:12–16) → **96년 이후**.
  - 적그리스도의 활동(4:1–6): **90년부터 예수님의 성육신을 왜곡하는 사상이 본격 활동** — **가현설 이단 ‘케린투스’**, **마르시온**의 개인 정경화 작업(육체로 오신 예수님을 부정하려는 목적). 마르시온의 연대는 보통 2세기 중엽이라 강의안의 시간 배치와 다름 — 보충.
  - 요한의 죽음 이전 — 전승상 트라야누스(98–117) 초기까지 생존, 100년경 사망.

### 5. 중심 사상과 기록 이유

- **중심 사상**: **예수 안에 있는 생명(아버지와 아들의 사귐)** / **하나님의 사랑이 예수로 나타남**.
- **기록 이유**: 거짓 교사의 영향력에 바르게 대응하도록 / 거짓 교사로 드러난 문제를 해결하는 방법 = **사랑**.

## 요한1서 본문

### 1:1–4 서론 — 증언과 서신의 목적: 사귐

- 1:1 **태초부터 있는**(엔: 있어 온) **생명의 말씀** — (아프 아르케스) 우리가 **들은** 바, **눈으로 본** 바, **자세히 보고 손으로 만진** 바 → **성육신**(2:23; 4:2 — 가현설 반박).
- 1:2 이 생명이 나타내신 바 된 **영원한(아이오니오스) 생명** — 우리가 보았고 증언하여 너희에게 전하노니 / 아버지와 **함께**(프로스) 계시다가 우리에게 나타나신 이.
- 1:3a 너희에게도 전함은 **우리와 사귐**이 있게 하려 함 / 1:3b 우리의 사귐은 **아버지와 아들 예수 그리스도와 더불어** 누림 / 1:4 이것을 씀은 **우리의 기쁨이 충만**하게.
- 1:5 “하나님은 **빛**이시라 그에게는 어둠이 조금도 없으시니라”.

### 1:5–2:17 사귐의 조건 — 빛 가운데 걸어가라

- **어둠 가운데 행하는 것 — 7개의 주장과 그 판정**:

| 주장 | 판정 | 대안 |
|---|---|---|
| 사귐이 있다 하며 어둠에 행함(1:6) | 거짓말, 진리를 행하지 않음 | 1:7 빛 가운데 행하면 사귐, 예수의 피가 깨끗하게 함 |
| 죄가 없다고 함(1:8) | 스스로 속임, 진리가 속에 없음 | 1:9 죄를 자백하면 사하심 |
| 범죄하지 않았다 함(1:10) | 하나님을 거짓말하는 이로 만듦, 말씀이 속에 없음 | 2:1–3 대언자 예수 |
| 그를 안다 하며 계명을 지키지 않음(2:4) | 거짓말하는 자, 진리가 속에 없음 | 2:5–8 |
| 빛 가운데 있다 하며 형제를 미워함(2:9–11) | 어둠에 있고 어둠에 행하며 눈이 멂 | 2:12–14 |
| 세상을 사랑함(2:15) | 아버지의 사랑이 그 속에 있지 않음 | 2:16–17 |
| 하나님을 사랑한다 하며 형제를 미워함(4:20) | 거짓말하는 자, 하나님을 사랑할 수 없음 | |

- **《카이아즘》 1:5–10 사귐의 결과 — 거짓 가르침에 대한 경계**:
  - A 1:6 만일 우리가 사귐이 있다 하고 **어둠에 행하면**(페리파테오: 걸으면) — 거짓말
  - B 1:7 **빛 가운데 행하면** 사귐이 있고 예수의 피가 모든 죄에서 깨끗하게 함
  - **C 1:8 만일 우리가 죄가 없다고 하면 스스로 속이고 진리가 우리 속에 없음**
  - B′ 1:9 **죄를 자백하면** 죄를 사하시며 모든 불의에서 깨끗하게 하심
  - A′ 1:10 범죄하지 않았다 하면 하나님을 거짓말하는 이로 만듦
- **《카이아즘》 1:1–2:14**:
  - A 1:1–4 태초부터 있는 생명의 말씀 — **우리의 사귐**
  - B 1:5–10 하나님은 빛, 빛에 행함 = 사귐 — 죄를 인정하고 죄인임을 앎
  - C 2:1–2 **대언자, 화목 제물** 예수 그리스도
  - C′ 2:3–8a 그를 아는 자는 **계명을 지킴**
  - B′ 2:8b–11 어둠이 지나가고 참빛이 벌써 비침 — 빛 가운데 행하는 자는 **형제를 사랑함**
  - A′ 2:12–14 태초부터 계신 이를 너희가 알았음 — **너희의 사귐**(죄 사함을 받음, 아버지를 앎, 악한 자·흉악한 자를 이김)
- **2:15–17 세상을 사랑하지 말라** — 아버지께로부터 온 것 vs 세상으로부터 온 것(육신의 정욕, 안목의 정욕, 이생의 자랑) / 하나님의 뜻을 행하는 자는 **영원히 거함**.

### 2:18–28 사귐의 본질 — 아들과 아버지 안에 거하라 《카이아즘》

- A 2:18–19 마지막 때, **많은 적그리스도** — 우리에게서 나감
- B 2:20–21 **기름 부음**, 모든 것을 앎
- **C 2:22–26 적그리스도의 정체**(예수가 그리스도이심을 부인) **와 권면(거하라)**
- B′ 2:27 기름 부음 안에, **주 안에 거하라**
- A′ 2:28 그의 안에 거하라 — **강림하실 때 부끄럽지 않도록**

### 2:29–4:21 사귐의 특성 — 의를 행하며 형제를 사랑함

- 2:29–3:3 **의를 행하라** — 우리는 하나님의 자녀, 세상이 우리를 알지 못함 / 그가 나타나시면 그와 같을 줄 앎 → 이 소망을 가진 자마다 **자기를 깨끗하게** 함.
- **《카이아즘》 2:29–3:10**:
  - A 2:29–3:1 **의를 행하는 자** — 그에게서 난 줄 앎, 하나님의 자녀
  - B 3:2–3 소망을 가진 자 — 자기를 깨끗하게 함
  - C 3:4–5 죄를 짓는 자마다 불법 — **죄는 불법** / 그가 죄를 없애려고 나타나심, 그에게는 죄가 없음
  - **D 3:6–7 그 안에 거하는 자마다 범죄하지 않음** / 범죄하는 자는 그를 보지도 알지도 못함
  - C′ 3:8 죄를 짓는 자는 **마귀에게 속함** — 하나님의 아들이 나타나신 것은 **마귀의 일을 멸하려** 하심
  - B′ 3:9 하나님께로부터 난 자마다 죄를 짓지 않음
  - A′ 3:10 **하나님의 자녀와 마귀의 자녀**가 드러남 — 의를 행하지 않는 자는 하나님께 속하지 않음
- **《카이아즘》 3:9–20**:
  - a 3:9 하나님께로 난 자는 죄를 짓지 않음
  - b 3:10 의를 행하지 않는 자, 형제를 사랑하지 않는 자는 하나님께 속하지 않음
  - c 3:11 서로 사랑하라 — **처음부터 들은 소식**
  - d 3:12–13 **가인과 아벨** — 세상이 미워해도 이상히 여기지 말라
  - **e 3:14 형제를 사랑하면 사망에서 생명으로 옮김 / 사랑하지 않는 자는 사망에 거함**
  - d′ 3:15 형제를 미워하는 자는 **살인하는 자**
  - c′ 3:16 그가 우리를 위해 **목숨을 버리셨으니** — 우리도 목숨을 버리는 것이 마땅함
  - b′ 3:17–18 형제의 궁핍을 돕지 않으면 사랑이 어찌 거하겠느냐 — **말과 혀로만 하지 말고 행함과 진실함으로**
  - a′ 3:19–20 진리에 속한 줄 앎, 마음에 책망할 것이 없으면
- **4:1–6 영 분별**: 4:1 영을 다 믿지 말고 하나님께 속했는지 **시험하라** / 4:2 하나님께 속한 영 = **예수 그리스도께서 육체로 오신 것을 시인** / 4:3 적그리스도의 영 = 시인하지 않음 / 4:4 너희는 하나님께 속했고 저희를 이겼음 — **너희 안에 계신 이가 세상에 있는 자보다 크심** / 4:5 저희는 세상에 속함 / 4:6 우리는 하나님께 속함 → **진리의 영과 미혹의 영**을 이로써 앎.
- **《카이아즘》 4:7–5:3 — 사랑**:
  - A 4:7–8 서로 사랑하자, **사랑은 하나님께 속한 것** — 하나님은 사랑이심
  - B 4:9 **독생자**를 통해 나타난 사랑
  - C 4:10–11 우리가 서로 사랑하는 것이 마땅함
  - D 4:12 우리의 사랑으로 **온전해지는** 사랑
  - E 4:13–14 아들을 앎(우리가 보았고 증언함)
  - **F 4:15 예수를 하나님의 아들로 시인하면 하나님이 그 안에 거하시고 그도 하나님 안에 거함**
  - E′ 4:16 사랑을 알고 믿었음
  - D′ 4:17–18 **온전한 사랑**은 두려움을 내쫓음
  - C′ 4:19–21 형제를 사랑하지 않으면 하나님을 사랑할 수 없음
  - B′ 5:1 예수께서 그리스도이심을 믿는 자마다
  - A′ 5:2–3 하나님을 사랑하는 것은 이것 — 그의 계명들을 지키는 것

### 5:1–21 사귐의 결과 — 세상을 이김, 아버지와 아들을 앎

- 5:1–4: 예수께서 그리스도이심을 믿는 자마다 하나님께로부터 난 자 → 사랑 / 하나님을 사랑하고 계명을 지킬 때 하나님의 자녀를 사랑하는 줄 앎 / **계명들은 무거운 것이 아님** / 하나님께로부터 난 자마다 **세상을 이김 — 이기는 승리는 우리의 믿음**.
- **5:5–8 물과 피로 임하신 이**: 예수께서 하나님의 아들이심을 믿는 자가 아니면 누가 세상을 이기리요 / **물로만이 아니요 물과 피로** 임하셨고 성령이 증언하심 → **가현설 이단 케린투스의 주장**(그리스도가 세례 때 예수에게 임했다가 십자가 전에 떠났다 — 보충)을 반박함.
- 5:9–12 **하나님의 증거** — 하나님이 증언하시는 아들 예수 그리스도 / 아들을 믿는 자 vs 하나님을 믿지 않는 자 / 5:11–12 “**아들이 있는 자에게는 생명이 있고** 아들이 없는 자에게는 생명이 없느니라”.
- **5:13 기록 목적**: “하나님의 아들의 이름을 믿는 너희에게 이것을 쓰는 것은 너희로 하여금 너희에게 **영생이 있음을 알게** 하려 함이라”(요 20:31과 짝 — 요한복음은 믿게 하려고, 요한1서는 알게 하려고 (해석)).
- 5:14–20 기도의 확신, 사망에 이르는 죄, 참된 하나님 / 5:21 “자녀들아 너희 자신을 지켜 **우상에게서 멀리하라**”.
- **적용**: “**안다고 생각하는 것이 아닌, 아는 것을 행하는 삶**” — 진짜 알아야 할 것 2가지(하나님은 빛이시다 / 하나님은 사랑이시다 — (해석), 강의안은 “2가지”라고만 적음).

# 요한3서 — “진리를 영접할 줄 아는 자가 되어라”
