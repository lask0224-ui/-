## BRI

### 1. 저자 — 바울 (+ 소스데네)

- 1:1 “바울과 형제 소스데네” — **저자 2명 언급**. 1:4 이후는 1인칭 “나/내가”. 3:5–6 “아볼로는 무엇이며 바울은 무엇이냐 … 나는 심었고 아볼로는 물을 주었으되”. 16:21 “나 바울은 친필로 문안하노니” [고26].
- **소스데네 = 회당장**(행 18:17) [고24] → 고린도에서 매 맞던 회당장이 바울의 동역자가 됨 (해석: 동일인으로 보는 것은 강의안의 입장).
- 결론: [고24] “바울 & 소스데네” / [고26] “저자: 바울”.

### 2. 언제, 어디서 — 3차 전도여행 중 에베소 (54–56년)

- 단서 [고26]:
  - 16:5 마게도냐를 지나 고린도로 / 16:8 **오순절까지 에베소에** 머물려 함.
  - 4:17; 16:10 디모데를 보냈으나 아직 도착하기 전 / 새 사역 계획 = 행 19:21–22, 롬 1:11의 정황과 같음.
  - 행 19:23 “그때쯤 … 적지 않은 소동” → 에베소에서 있었던 일.
- 바울은 언제 에베소에 갔나?
  - 2차 여행(**[고26] AD 50–53** / 행 16:6 아시아 불허) 끝에 잠깐 들름(18:19–21).
  - 18:24–19:1 “아볼로가 고린도에 있을 때 바울이 에베소에 도착”(고전 16:12).
  - 3차 여행(AD 53–57): 19:1–20 약 3년 에베소 사역 → 19:23 에베소 소동(**AD 57**).
  - ⇒ **54–56년 사이 에베소에서** 기록.
- [고24]: 기록 장소는 에베소(16:19 “아시아의 교회들이 문안하고”). 시기는 행 18:19 직후 / 19장 2년 3개월 / 디모데를 보냄(4:17 = 행 19:21–22) / 마게도냐를 지난 후(16:5) ⇒ **3차 전도여행 기간 중(AD 53–57)**.

### 3. 수신자

- 1:2 “고린도에 있는 하나님의 교회 곧 그리스도 예수 안에서 **거룩하여지고 성도라 부르심을 받은** 자들과 또 각처에서 … 예수 그리스도의 **이름을 부르는** 모든 자들” — **부르심을 받은 자 = 부르는 자** (말놀이, [고26] 강조). “우리의 주 곧 그들과 우리의 주(?)”.
  - [고24]: 거룩하여지고 = 헬 **하기아조**(거룩하게 하다, 성별하다) / 성도 = **하기오스** / 1:4–9 반복 단어 “주” = **퀴리오스**(주인), 고린도전서에서 **68번** 반복.
- **구성원의 다양성** [고26]:
  - 1:26 지혜로운 자·능한 자·문벌 좋은 자가 많지 않음.
  - 7:17–24 할례자와 무할례자, 자유인과 종.
  - 8:1–13 우상을 섬겼던 사람들.
  - 11:22–32 빈궁한 자와 부유한 자.
- **교회 구성원 명단** [고24 p16]:
  - 헬라인: 브드나도, 아가이고, 구아도, 디도 유스도.
  - 유대인: 아굴라, 브리스길라, 그리스보.
  - 부자: 가이오, 디도 유스도, 스데바나, 에라스도.
  - 종: 스데바나 집 사람들 (강의안의 분류. 스데바나를 부자와 종 양쪽에 연결함 — ‘글로에의 집 사람들’(1:11)과 혼동했을 가능성이 있어 확인이 필요함, (해석)).
- 고후 1:1 “아가야에 있는 모든 성도에게”도 함께 제시함 [고24].

### 4. 역사적 배경 — 고린도

- **역사** [고26 p2; 고24 p11]:
  - 지리적으로 아덴과 밀접 → 해상무역의 경쟁자. 스파르타를 이용해 아덴을 견제함 → 펠로폰네소스 전쟁(431–404, 아덴–델로스 동맹 vs 스파르타–펠로폰네소스 동맹) → 마게도냐 중심의 **고린도 동맹**.
  - **BC 146 로마 장군 뭄미우스**가 파괴 → **BC 46 카이사르**가 전략적 필요로 재건 → **BC 27 아우구스투스, 원로원 속주 아가야의 수도** → 경제·종교적으로 중요한 도시.
  - **AD 52–53 델피 비문: 아가야 총독 갈리오**(행 18:12) [고26]. ⚠ [TBS4]·[심화2]는 51–52 → `../자료간_차이.md`.
  - ✅ **확정: 갈리오 재임 AD 51–52** (비문은 52년 전반의 것 → 재임은 51년 여름–52년 여름) → `00_확정연대표.md`
- **특별한 항구 도시** — 두 항구와 **디올코스**:
  - [고24] 육상으로는 펠로폰네소스 반도(남)와 본토(북)를 연결. 해상으로는 **고린도만의 레케움(레기온)항(서쪽)**과 **사로닉만의 겐그레아(센크레)항(동쪽)**.
  - [고26]은 “서쪽 레기온(에게해), 동쪽 겐그레아(지중해)”로 적음. 바다 이름이 [고24]·지리와 맞지 않음(레기온은 고린도만 쪽, 겐그레아는 사로닉만=에게해 쪽) → **[고26] 오기 추정**. 지도 그림 자체는 레기온(고린도만, 서) – 겐그레아(동)로 바르게 그려짐.
  - 행 27:9–11(항해 위험기, 두 항구를 잇는 육로로 말라 곶을 피함 — 연결은 (해석)).
  - **디올코스**: 세계 최고의 물동량, 노동력이 필요함 → 값싼 노동력? → 다인종·다문화·다신론 = 항구 도시의 특징. 고린도 운하 사진(현대).
- **풍요와 번영의 상업 도시** [고26]: 특산품 **포도주 항아리** / **조선소**(배 수리 기술, **삼단노선 ‘트라이림’** 개발, 항해술 발달) / **길드** / 철학과 학문의 발달.
- **인구 집중과 종교**:
  - 신들이 사람들과 함께 옴 → 우상숭배, 혼합주의, 음란.
  - 신전 수: **적어도 12개 이상**(“고전 8:5 많은 신과 많은 주”) [고26] / **26개** [고24].
  - 대표 신: **여신 숭배와 축제** → 환락. [고24]: 아프로디테 신전(매춘), 아폴론 신전(동성애), 디오니소스(광란). [고26]: 아프로디테(우라니아/판데모스), 베스타, 아폴로(“고전 6:15–16”).
  - **이스미안 게임**(올림피아드 경기) → **겉사람의 자랑**. [고24]는 이스미안·네메아 경기(2년마다).
  - 요약: 지정학적 매력 → 부의 집결 → 환락·퇴폐.
- **‘고린도식 생활’ 관용어** [고26][고24]:
  - **코린티아조마이**(*Korinthiazomai*) = “고린도 사람처럼 행하다” = 매춘을 행하다, 부도덕을 훈련하다.
  - 코린티아 코레(소녀) = 매춘부 / 코린디악세스다이 = 고린도 난봉꾼 / 코린티아스테스 = 고린도 탕자.
  - “고린도인처럼 말한다” = 말을 정말 잘한다 / “고린도로 항해하지 말라” = 선원들의 격언 / “고린도인처럼 산다” = 음란한 삶.
  - 고대 문학의 고린도: **선원의 낙원, 주정뱅이의 천국, 정숙한 여인의 지옥, 허영의 시장**. 고대 연극에서 고린도인은 주정뱅이로 나옴. “모든 배가 고린도로 가는 것은 아니다.” “남자로 태어났다면 고린도는 가 봐야 한다.”
  - **16:13 “남자답게” = 헬 안드리조마이(용감하게 행하다) ↔ 코린디아조마이(부도덕을 훈련하다)** [고24] — 바울이 고린도의 ‘-아조마이’ 문화에 맞서 쓴 말놀이로 봄.
- **순회 철학자 = 소피스트** [고24]: 지혜를 가르치고 돈을 받음, 언어 연구실과 철학 학교, 진리와 정의는 상대적, **스승이나 학파를 따라 스스로 이름을 붙임** → 1:12 “나는 바울에게, 나는 아볼로에게…”의 배경.
- **사상 — 우주적 이원론** [고26 p4]:
  - 세상에 대한 질문(how, why): 선한 신? 불합리? 악한 세상? 운명? 인간은? 죄? 심판?
  - 헬라 철학: 영은 선하고 몸은 악함 → 금욕주의 / 쾌락주의, 지식의 추구, 우상숭배, 여신 숭배.
  - 고린도에서 초월·구원·충만을 얻는 방법 = **우상숭배**. 아프로디테 제의에서 신전 사제와의 성관계를 일반적인 **‘은밀한 경험’**으로 이해함.
  - → 6:12–20의 “몸” 논증과 15장 부활(몸)의 배경.

### 6. 기록 이유와 중심 주제

- [고26]:
  1. **들은 것과 쓴 것에 대한 대답과 지침**.
  2. **모든 일을 사랑으로 행하라**.
  3. 바울의 사도직에 대한 변호의 필요.
  4. 성숙한 그리스도인의 삶을 가르치고 권면하기 위해.

    - 세로로 보면 각 주제가 **A – B – A′ 샌드위치**이고, 가운데 줄(B)에 **십자가의 도 – 송사 – 부르심 – 권리 포기 – 머리에 쓰는 것 – 사랑**이 놓임. 마지막 열 **부활**은 따로 떨어져 전체를 마무리함.
    - 노란색으로 칠한 두 칸(우상제물 9:26–10:13 → 성만찬 10:14–33)을 **초록 화살표**로 이음. 10:14–22의 “성찬의 의의/그리스도와의 연합”이 우상제물 논의에서 **성만찬 주제로 넘어가는 경첩**이라는 표시로 보임 (해석).
    - 강의안의 가운데 줄 두 번째 칸 이름은 p9에서 “사도권, 권리포기”, p13에서 “사도권 자유, 종”(9:19 “모든 사람에게서 자유로우나 스스로 모든 사람에게 종이 된 것”).
    - 굵은 테두리는 “성만찬·은사/머리·사랑/성만찬·은사”(11–14장 공동 예배 블록)와 “부활”을 묶음.
  - (해석) 이 표에 따르면 **13장 사랑이 은사 논의의 가운데일 뿐 아니라 7–14장 전체 “B줄”의 마지막이자 정점**이고, 16:14 “모든 일을 사랑으로”가 그 결론이 됨.

## 본문

### 1:1–9 서론 — 부르심

- 사도로 부르심을 받은 바울과 소스데네(다메섹 도상) ↔ 성도로 부르심을 받은 고린도 교회(고린도).
- 1:4–7 **바울이 감사하는 이유**: “모든 일 곧 **모든 언변과 모든 지식**에 풍족”, “**은사**에 부족함이 없음” — 그러나 1:26(지혜로운 자가 많지 않음), 3:1(육신에 속한 자, 어린아이), 6:9–11과 대조됨 → 감사의 근거는 교인이 아니라 **1:8–9 끝까지 견고하게 하실 미쁘신 하나님**.
- 1:7–9: 주의 나타나심을 기다림 / 예수의 날에 책망할 것이 없도록 끝까지 견고하게 / 너희를 불러 아들과 교제하게 하시는 하나님은 미쁘심.
- **“권하노니” 인클루지오**: 1:10 “형제들아 권하노니” ↔ 16:15–18 “형제들아 권하노니”. 4:16 “내가 너희에게 권하노니 너희는 나를 본받는 자가 되라” = 11:1.
- 16:22 “누구든지 주를 사랑하지 아니하면 저주를 받을지어다 — **마라나타(우리 주여 오시옵소서)**”(강의안은 16:21 친필 문안과 함께 인용).

### 1:10–4:21 분쟁 — “내게 들리니”

- 1:10 명령 “권하노니”: 모두가 **같은 말**을 하고, **분쟁이 없이**, **같은 마음과 같은 뜻으로**, **온전히 합하라**.
- **책망(1:11–13a)**:
  - 나는 바울에게 / 나는 **아볼로**에게(**헬라인들**이 따랐을 것) / 나는 **게바**에게(**유대인들**이 따랐을 것) / 나는 그리스도에게.
  - “그리스도께서 어찌 나뉘었느냐? 바울이 너희를 위하여 십자가에 못 박혔으며, 바울의 이름으로 세례를 받았느냐?”
- **1:11–4:21 3단 구조** [고26 p7]: 1:11–17 동역자 — **분쟁** / **1:18–2:16 십자가의 도 — 하나님의 방법(어리석음, 약하심)** / 3:1–4:21 동역자 — **동역**.
  - 1:14–17 세례를 베풀지 않았음(→ 게바·베드로 파) / 1:18–31 십자가의 도, 표적과 지혜 / 2:1–5 지혜의 아름다운 말로 하지 않았음(→ 아볼로 파) — 각 파벌에 대한 응답이 순서대로 나옴 (해석: 강의안이 괄호로 게바, 아볼로를 붙인 것에 근거).
- **1:18–25 십자가의 도**:
  - 멸망하는 자에게는 미련함 ↔ 구원받는 우리에게는 하나님의 능력. 세상 지혜는 하나님을 알지 못함. 전도의 미련한 것으로 구원하심.
  - 1:22–23 유대인은 **표적**, 헬라인은 **지혜** → “**우리는**(바울·게바·아볼로) 십자가에 못 박힌 그리스도를 전하니” / 그리스도 = 하나님의 능력, 하나님의 지혜.
- **1:26–31 주 안에서 자랑하라**: 부르심을 보라(지혜·능력·문벌) → 아무 육체도 자랑하지 못하게 → 예수 = **지혜와 의로움과 거룩함과 구원함**.
- **2:1–5 바울의 선택**: 말과 지혜의 아름다움 ↔ 성령의 나타나심과 능력. **약하고(힘없음), 두려워하고(공포), 심히 떨었노라(두려움으로 전율)** → 믿음이 하나님의 능력에 있게 하려 함.
- **2:6–16**: 은밀한 가운데 있는 하나님의 지혜(7–9) ↔ 세상의 지혜. 성령이 하나님의 깊은 것까지 통달하심. **신령한 자(2:15) ↔ 육에 속한 사람(2:14)**. 2:16 “누가 주의 마음을 알아서 주를 가르치겠느냐 — 그러나 **우리가 그리스도의 마음**을 가졌느니라”.
- **3:1–9 하나님의 밭**:
  - 젖의 비유, “아직도 **육신에 속한 자**”.
  - 시기(바울 vs 아볼로)와 분쟁(다툼, 불화).
  - 사역자의 역할 — 심고 물을 주되 **자라게 하시는 이는 하나님**. “우리는 하나님의 동역자요 너희는 하나님의 밭이요 하나님의 집이라.”
- **3:10–23 하나님의 집(건축자 비유)**:
  - 10–11 터가 되신 예수 그리스도.
  - 12–15 공적(일, 행위)을 불로 시험함. “**누구든지**” 4번 반복.
  - **16–17 너희가 하나님의 성전 — 성령이 거하심, 더럽히지 말라**.
  - 18–20 자기를 속이지(자기기만) 말라, 세상 지혜를 따르지 말라.
  - **21–23 사람을 자랑하지 말라: 만물 → 너희 → 동역자들 → 그리스도 → 하나님의 것**.
  - “가르치는 자 = 성전을 세우는 자” [고26].
- **4:1–5 그리스도의 일꾼**: 하나님의 비밀을 맡은 자 / 구할 것은 **충성** / 판단은 하나님께서 하심 → “그때에 각 사람에게 하나님으로부터 칭찬이 있으리라”.
- **4:6–13 사도와 성도의 대조** [고24]:

| 그리스도 때문에 (사도들) | 그리스도 안에서 (성도들) |
|---|---|
| 어리석으나 | 지혜롭고 |
| 약하나 | 강하고 |
| 비천하나 | 존귀하나 |

  - 4:8 “너희가 이미 배부르며 … **왕 노릇** 하였도다”(반어, 보충).
- **4:14–21**: 일만 스승이 있어도 **아버지는 많지 않음**(“스승이 아닌 아비”) → “나를 본받는 자가 되라” / “하나님의 나라는 말에 있지 아니하고 **능력**에 있음이라”.

### 5:1–6:20 음행과 송사 — “심지어 음행이 있다 함을 들으니”

- **5:1–13 음행** — 아버지의 아내를 취함(근친상간? 종교적 매춘?):
  - 1–2 음행과 **출교하지 않음**을 책망 / 교회는 오히려 자랑함.
  - 3–5 판단: 이미 판단함, 사탄에게 내어 줌.
  - 6 누룩의 영향력(“알지 못하느냐?”) / 7 **유월절 양 그리스도** — 묵은 누룩을 내버리라(출 12:17) / 8 **순전함과 진실함의 떡**.
  - 9–11 이전 편지 확인(음행하는 자를 사귀지 말라 = 교회 안의 사람) / 교회 밖은 하나님이 심판하심.
  - 12–13 “이 악한 사람은 너희 중에서 내쫓으라”.
- **6:1–11 송사**:
  - 1–5 법정 소송 책망 — **불의한 자들**(로마 법정? 순회 철학자들?) 앞에서 형제가 형제를 고발함. 성도는 세상과 **천사**를 판단할 자.
  - 6–7 대안과 권면(차라리 불의를 당하라). 8–10 불의한 자에 대한 경고.
  - 11 “너희 중에 이와 같은 자들이 있더니 … **씻음과 거룩함과 의롭다 하심**을 받았느니라” — 성도의 과거(9–10)와 현재(11).
- **6:12–20 음행 2 — 음행하지 말아야 할 세 가지 이유**:
  1. **6:12–13 몸은 주를 위해 존재함**. “모든 것이 내게 가하나 … 내가 무엇에든지 **얽매이지** 아니하리라”(얽매이다 = 권리·권세를 가지고 행사하다 [고24]).
  2. **6:14–17 몸은 그리스도의 지체임** — 창녀와 합하는 자 vs 주와 합하는 자.
  3. **6:18–20 몸은 성령의 전임** — 너희는 너희 자신의 것이 아님.
  - 결론 6:20 “**그런즉 너희 몸으로 하나님께 영광을 돌리라**” ← **이원론적 사고관**(육은 악하고 영은 선하다)에 대한 반박.

### 7:1–40 결혼 — “너희가 쓴 것에 대하여는”

- 7:1–9 결혼 / 7:10–16 이혼 / **7:17–24 부르심 안에 행하라**(할례자와 무할례자, 종과 자유인 — “각 사람은 부르심을 받은 그 부르심 그대로 지내라”) / 7:25–38 미혼(처녀) / 7:39–40 과부.

### 8:1–11:1 우상의 제물

- 8:1–13 우상의 제물 1 / **9:1–27 사도의 권리** / 10:1–11:1 우상의 제물 2.
- **8:1–4 지식보다 사랑**:
  - 8:1 “**지식은 교만하게 하며 사랑은 덕을 세우나니**”.
  - 8:2 아는 줄로 생각하면 마땅히 알 것을 알지 못함(지식) ↔ 8:3 하나님을 사랑하면 하나님도 알아주심(사랑).
  - 8:4 우상은 아무것도 아니며 하나님은 한 분.
- **《카이아즘》 8:5–13** [고26]:
  - A 5–6 지식: 우상이 많으나 만물은 주로 말미암음 → 먹을 수 있다
  - B 7 지식이 모든 사람에게 있지 않음 → 양심이 약한 자가 더러워짐
  - **C 8 음식은 우리를 하나님 앞에 세우지 못함** (먹지 않아도 못 사는 것이 아니고, 먹어도 잘 사는 것이 아님)
  - C′ 9 너의 자유가 약한 자를 넘어지게 하지 않도록 주의하라 → 먹지 말라
  - B′ 10 지식 있는 네가 우상의 집에 앉아 먹는 것을 보면 약한 자의 양심이 담력을 얻어 먹게 됨
  - A′ 11–13 네 지식으로 약한 형제가 멸망함 — **그리스도께서 위하여 죽으신 형제** → 형제에게 죄를 지음 = 그리스도께 죄를 지음 → “**영원히 고기를 먹지 아니하여** 내 형제를 실족하지 않게 하리라”
- **9:1–27 바울의 사도적 권리와 절제의 모범**:
  - 1–2 사도권 변론 / 3–7 교회의 부양을 받을 권리 / 8–10 율법이 보장함(소의 입에 망을 씌우지 말라) / 11–12 권리를 제한한 이유.
  - 13–14 주께서도 명하심 / 15 쓰지 않음 / 16–18 쓰지 않는 이유 = 사명, 진정한 상급.
  - **19–27 복음을 위해 종이 됨**: 많은 사람을 얻으려 함(19–23) / 경기 비유(24) / 승리를 위한 절제(25) / 바울 자신의 절제를 모범으로 제시(26–27) — 이스트미아 경기가 배경.
- **10:1–13 이스라엘 조상들의 실패**:
  - 1–4 하나님의 능력과 은혜를 체험함(구름, 바다, 신령한 음식과 음료 — **성만찬?** [고26]) / 5 다수가 광야에서 멸망함.
  - 6–11 본보기: 7 **우상 숭배**하지 말라 / 8 **음행**하지 말라 / 9 **주를 시험**하지 말라 / 10 **원망**하지 말라 / 11 우리의 본보기.
  - 12–13 “**선 줄로 생각하는 자**는 넘어질까 조심하라” / 감당할 시험과 피할 길.
- **10:14–22 우상 숭배를 피하라**(“그런즉” — 요약적 진술이자 명령):
  - 15–18 성찬의 의의 = **그리스도와의 연합**.
  - 19–20 이방 제사 = **귀신과의 연합**.
  - 21–22 주의 잔과 귀신의 잔을 겸하여 마실 수 없음.
- **10:23–11:1 결론**:
  - 23–24 판단 기준: “모든 것이 가하나 … 자기의 유익을 구하지 말고 남의 유익을 구하라”.
  - 25–27 자유의 허용: 시장에서 파는 것은 양심을 위하여 묻지 말고 먹으라(“땅과 거기 충만한 것이 주의 것”), 불신자의 초대도 마찬가지.
  - 28–29a 자유의 제한: 누가 우상 제물이라고 알려 주면 먹지 말라 — (**누구의 양심?** → 알려 준 사람의 양심).
  - 29b–30 자유를 주장하는 자들에게.
  - **31–11:1 판단 기준: “무엇을 하든지 다 하나님의 영광을 위하여 하라”**, “내가 그리스도를 본받는 자가 된 것같이 너희는 나를 본받는 자가 되라”.

### 11:2–14:40 공동 예배

- **11:2–16 머리에 쓰는 것**:
  - 11:2 전해 준 **전통**을 지킴 — 칭찬.
  - 11:3 머리(= **근원, 명예, 위엄** [고24]): 남자의 머리는 그리스도, 여자의 머리는 남자, 그리스도의 머리는 하나님.
  - 4 남자가 머리에 쓰고 기도하면 머리를 욕되게 함 / 5 여자가 머리에 쓴 것을 벗고 기도하면 머리를 욕되게 함 / 6 가리지 않으려면 깎으라, 깎는 것이 부끄러우면 가리라 → “머리에 꼭 수건을 둘러라”.
  - 10 “권세 아래에 있는 표”.
  - 15 긴 머리는 여자에게 영광 — 배경: **신전 여사제의 머리 모양** [고26] → `00_복음서_향유부음사건.md`의 “머리를 푸는 행동” 설명과 연결됨 (해석).
- **11:17–34 성찬**:
  - **잘못된 성찬(17–22)**: 모임이 유익이 아니라 해로움 / 분쟁과 파당 / 주의 만찬을 먹을 수 없음 / **자기 만찬을 먼저 먹어** 어떤 사람은 시장하고 어떤 사람은 취함 / 교회를 업신여기고 빈궁한 자를 부끄럽게 함 → 칭찬하지 않음.
  - **주의 만찬(23–26)**: 주께 받은 것 / 떡 = 몸을 기념, 잔 = 피를 기념 / 26 **주의 죽으심을 그가 오실 때까지 전하는 것**.
  - **실제적 교훈(27–32)**: 합당하지 않게 먹으면 주의 몸과 피에 죄를 짓는 것 / 자기를 살피라 / **주의 몸을 분별하지 못하면** 자기 죄를 먹고 마심 / 스스로 살피면 판단받지 않음.
  - **지침(33–34)**: 먹으러 모일 때 **서로 기다리라** / 시장하면 집에서 먹고 오라 / 나머지는 가서 바로잡겠음.
- **12–14장 신령한 은사**: 12장 은사 — **13장 사랑** — 14장 은사.
  - 12:31 “더욱 큰 은사를 사모하라, 내가 또한 **가장 좋은 길**을 보이리라” → 13장 → 13:13 “믿음, 소망, 사랑 … 그중에 제일은(더 큰 것은) 사랑이라”.
  - **14장 공적 예배에서의 은사 사용**:
    - 14:1 사랑을 추구하며 신령한 것을 사모하되 **특히 예언**을 사모하라.
    - 방언에 비해 예언이 상대적으로 유익함(2–5) / 방언의 무익성(6–11) / 방언의 사용 원리(12–17) / 다시 예언의 상대적 유익성(18–19).
    - 14:20 “지혜에는 아이가 되지 말고 악에는 어린아이가 되라, 지혜에는 장성한 사람이 되라”.
    - 인용(21–22): **방언은 믿지 않는 자에게 표적, 예언은 믿는 자에게 유익**.
    - 공적 예배에서 방언은 제한하고 예언을 권장함(23–25).
    - 14:26 “모든 것을 **덕을 세우기** 위하여 하라”: 방언 규칙(27–28), 예언 규칙(29–33, “하나님은 무질서의 하나님이 아니시요 오직 화평의 하나님”), 여자의 발언 금지(34–35), 결론적 권면(36–38).
    - 14:39–40 “모든 것을 **품위 있게 하고 질서대로** 하라”.

### 15장 부활

- 인클루지오: **15:1–2 헛되지 않은 믿음과 구원 ↔ 15:58 헛되지 않은 수고** [고26].
- 1–11 내가 전한 복음: 그리스도의 **죽으심과 장사와 부활(3–4)**, 부활의 몸을 보이심(5–8).
- 12–19 “부활이 없다 하느냐?” → 그리스도도 살아나지 못했을 것이고, 전파도 믿음도 헛것 → “이 세상의 삶뿐이면 … 더욱 불쌍한 자”.
- 20–34 **잠자는 자들의 첫 열매** / 한 사람(아담)으로 사망, 한 사람(그리스도)으로 부활 → “깨어 의를 행하고 죄를 짓지 말라”.
- 35–58 “죽은 자들이 어떠한 몸으로 오느냐” → 썩을 것으로 심고 썩지 않을 것으로 다시 살아남(42–44) / 흙에 속한 형상 → 하늘에 속한 형상 / 58 “견실하며 흔들리지 말고 … 수고가 헛되지 않은 줄 앎이라”.

### 16장 연보와 결론

- 1–2 연보 독려(“갈라디아 교회들에게 명한 것 같이” — 매주 첫날 미리 준비) / 3–4 전달 계획 / 5–9 방문 계획 / 10–11 디모데 파송 / 12 아볼로.
- **결론 권면(13–14)**: “깨어 믿음에 굳게 서서 **남자답게(안드리조마이)** 강건하라” / “**너희 모든 일을 사랑으로 행하라**”.
- 15–18 고린도의 동역자(스데바나 집 — 아가야의 첫 열매)에게 “순종하라, 알아주라” / 19–20 아시아 교회들의 문안(“서로 문안하라”) / 21–24 친필 문안과 축도 — “누구든지 주를 사랑하지 아니하면 저주를 받을지어다, **마라나타**”.
