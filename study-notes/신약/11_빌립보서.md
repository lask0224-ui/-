## 1. 저자 — 바울 [빌B]

- **(1) 본문에 나타난 저자의 특징**:
  1. 유대인인가 이방인인가? → 3:5–6(팔 일 만에 할례, 이스라엘 족속, 베냐민 지파, 히브리인 중의 히브리인, 바리새인).
  2. **디모데와의 관계**: 동역자(1:1), 권위자(2:19), 디모데가 저자를 **아버지처럼 섬김**(2:22).
  3. **빌립보 교회와의 관계**:
     - 방문한 적이 있음(1:5; 4:15).
     - 교회가 **에바브로디도**를 통해 저자의 필요를 채움(4:16, 18) → 저자가 그를 다시 돌려보냄(2:25).
     - 교회를 특별히 생각함(4:1).
     - 교회에 명령할 수 있는 위치(3:17).
  4. **현재 상황**: 매여 있음(1:7, 13, 14, 17) / 편지를 쓸 자유가 있음(1:1) / 풀려날 것을 확신함(1:25; 2:24) / 사람을 만나고 보낼 자유가 있음(2:19–30) / 마음대로 밖에 나갈 수는 없음(2:23–24).
  5. **과거 행적**: 교회를 박해함(3:6) / 마게도냐(빌립보)를 방문함(4:15) / 마게도냐를 거쳐 데살로니가에 감(4:15–16).
- **(2) 직접 언급**: “바울과 디모데는 … 편지하노니”(1:1) / 1인칭 “나(내가)”(1:3, 7, 8, 9 …).
- **(3) 외적 증거**:
  - 로마의 클레멘트, 이그나티우스, 저스틴, 서머나의 폴리캅이 증언함.
  - 이레니우스, 알렉산드리아의 클레멘트, 터툴리안이 인용함(AD 200년대).
  - “현존하는 가장 오래된 빌립보서 사본(무라토리안 정경, 약 2세기 후반)”(강의안 표현. 무라토리 정경은 사본이 아니라 정경 목록 문서임 — 보충).

## 2. 수신자 [빌B]

- “빌립보에 사는 모든 성도와 **감독들과 집사들**”(1:1). 감독 = 장로(행 20:17, 28).
- 질문: **“수신자로 직분자를 언급한 이유는?”** — (해석) 4:2–3 유오디아와 순두게의 불화, “나와 멍에를 같이한 네게” 등 **하나 됨**의 문제를 지도자들이 함께 다뤄야 했기 때문으로 보임.

### 2-1. 빌립보 교회

- **역사**:
  - 2차 전도여행 때 처음 방문(행 16:12–40; 강의안 “행 12:12–40”은 **오기**).
  - 안식일에 **회당이 없어** 기도처를 찾아감(16:13).
  - 자색 옷감 장사 **루디아**를 만남(16:14) → 그와 그 집이 세례받음(16:14–15) → **루디아의 집에서 교회가 시작됨**.
- **특징**:
  - 많은 환난과 시련, 극심한 가난(고후 8:1–2).
  - 예루살렘 교회를 위해 많은 연보를 함(고후 8:1–2; 롬 15:25–26).
  - **바울의 필요를 채워 줌**(고후 11:9; 빌 2:25–30; 4:15–18).
- 바울이 빌립보에서 전한 메시지: **구원의 길**(행 16:17, 30–31 “주 예수를 믿으라 그리하면 너와 네 집이 구원을 받으리라”).
- 교회 설립: 바울의 2차 전도여행 때(행 16:11–40).

## 3. 기록 연대와 장소 [빌B]

- 바울의 상황: 나의 매임(1:7, 13, 14, 17) / **시위대 안**(1:13) / “내 일이 어떻게 될지를 보아서”(2:23).
- **본문에 드러나는 감옥의 특징**:
  1. 편지를 보낼 자유가 있었음(1:1).
  2. 밖의 소식을 자유롭게 들음(2:19).
  3. 사람을 만나고 함께 머물 수 있었음(2:19, 25; 4:18, 21, 22).
  4. 사람을 감옥 밖으로 보낼 수 있었음(2:19, 25).
  5. 풀려날 확신이 있었음(1:25; 2:24).
  6. **가이사의 집 사람들**도 성도로서 그와 관계함(4:22).
- **사도행전의 감옥 vs 빌립보서의 감옥**:

| 감옥 | 언제 | 얼마나 | 자유 |
|---|---|---|---|
| 빌립보(행 16:16–40) | 2차 여행 중(AD 50–52) | 하루 | X |
| 예루살렘(행 21:27–23:32) | 3차 여행 직후(AD 57) | 2–3일 | ? |
| 가이사랴(행 23:33–24:27) | 3차 여행 직후(AD 57–59) | 2년 | O |
| **로마(행 28:16–31)** | 로마로 압송된 후(**AD 60–62**) | 2년 | O |

  - 강의안은 결론 문장이 없지만, 시위대(1:13)와 가이사의 집(4:22)을 근거로 **로마 투옥(AD 60–62)**으로 보는 흐름임 (해석).
  - ⚠ 예루살렘·가이사랴 연대가 57 / 57–59로, [엡](58 / 58–60)과 다름 → `../자료간_차이.md`.
- p25 “빌립보서를 기록할 당시 바울의 상황” — 제목만 있고 내용은 비어 있음.

## 4. 역사적 배경 — 빌립보 [빌B]

- **마게도냐로 들어가는 첫 관문 도시**.
- 원래 지명은 **크레니데스**(‘작은 샘’ 또는 ‘작은 우물’). 금이 많이 나서 필립 2세가 그 금으로 마게도냐 함대를 만듦.
- 역사:
  - **BC 358** 필립 2세가 정복하고 크레니데스를 빌립보로 바꿈([심화2]는 BC 357).
  - BC 168 로마가 정복.
  - **BC 42 빌립보 전투**.
  - **BC 31 악티움 해전**.
  - BC 27 빌립보 거주자에게 자치권을 줌.
  - → 상세는 `05_사도행전.md` [심화2].
- **로마 시민권을 얻는 방법**: 부모로부터(행 22:28) / 돈을 주고 구입(22:28) / 로마 군인의 의무 복무를 마치고 전역할 때 / 로마 시민의 노예가 해방될 때.
- **시민권의 혜택**: 재산을 구입·소유·이전함 / 민사 소송권 / **인두세·토지세 감면** / 채찍질·십자가형 면제(행 22:25; 강의안 “22:5”는 오기) / 가이사에게 상소함(25:12).
- **빌립보 교회와 바울의 관계**:
  - 바울의 **후원 교회**(4:15–16; 고후 8:1–3).
  - 바울은 후원받는 일에 조심하고 또 조심함(고후 11:9).
  - 교회는 바울이 빌립보 감옥에서 겪은 기적을 앎(행 16장).
  - **바울의 사역이 투옥으로 멈춰 있는데도 후원함**.

## 본문 [빌본]

### 1:1–2 인사말

- **그리스도 예수의 종 — 둘로스**(노예). 보충: 사도직을 내세우지 않고 ‘종’으로만 소개한 것은 2:7 “종의 형체”와 맞물림 (해석).
- **디모데**를 공동 저자로 언급한 이유?(질문) → 2:19–22 디모데 파송 예고와 연결됨 (해석).
- **성도**: 성도의 두 가지 특징 / 성도와 지명을 함께 언급함(“그리스도 예수 안에서 빌립보에 사는 모든 성도” — 두 주소: **그리스도 안**과 **빌립보**, (해석)).
- 인사: **은혜와 평강**.

### 1:3–11 감사와 기도

- 기도의 세 가지 태도: **감사**(3) / **기쁨**(4) / **확신**(6 “착한 일을 시작하신 이가 … 이루실 줄을 확신”).
- 1:5 복음을 위한 일에 **참여 = 코이노니아**(교제, 동참 — 후원 포함).
- 1:8 예수 그리스도의 **심장 = 스플랑크논**(창자, 긍휼의 자리).
- **기도의 내용**:
  1. 사랑이 풍성하도록(1:9) — 기반은 **지식(에피그노시스)**과 **총명(아이스데시스, 분별력)**.
  2. 선한 것을 분별하도록(1:10; 롬 12:2).
  3. 진실하여 허물없이 그리스도의 날까지(1:10; 살전 5:23).
  4. **의의 열매**가 가득하도록(1:11).

### 1:12–26 변증 — 자신의 상황에 대한

- **“내가 당한 일”(1:12)의 세 가지 해석**:
  1. 지금 로마 감옥에 갇혀 있는 상황(7, 13절).
  2. 3차 여행 후 거짓 고소로 갇힌 때부터 지금까지.
  3. 1차 여행부터 지금까지의 모든 상황(고후 11장).
- **도리어 복음 전파에 진전이 됨(1:12–18)**:
  - 바른 동기 — 착한 뜻으로(15–16) / 바르지 않은 동기 — 투기와 분쟁으로(15, 17).
  - 평소에는 만날 수 없는 사람들에게 복음을 전함: **시위대**, 고위 공직자(벨릭스, 베스도, 아그립바).
  - **시위대(1:13) = 황제의 정예 부대**(친위대) → [배경]: 아우구스투스 때 로마에 1,500명.
- **“기뻐하고 또한 기뻐하리라”(1:18)** — 바울의 순전한 기쁨: 동기와 상관없이 **그리스도가 전파됨**.
- **“지금도 전과 같이”(1:20)** — 바울의 소원: 그리스도가 **존귀하게 되는 것 = 메갈뤼노**(크게 하다, 확대하다).
- **“죽는 것도 유익함이라”(1:21)** — 유익 = **케르도스**(이익; 3:7–8 “유익하던 것을 … 해로 여김”과 같은 단어군).
- **1:23 세상을 떠나 그리스도와 함께 있는 것** → 죽음 이후 그리스도인의 삶.
- **《병행》 1:21–24**:

| | 21절 | 22–24절 |
|---|---|---|
| A 사는 것 | 그리스도 | (A′ 22) 바울 — 열매 |
| B 죽는 것 | 유익 | (B′ 23) 떠나 그리스도와 함께 — 훨씬 더 좋음 |
| C 유익 | 바울에게 | (C′ 24) **너희를 위하여** 더 유익 |

  - 강의안 원문: “A 사는 것 – 그리스도(21) / B 죽는 것 – 바울(21) / C 유익(21) ∥ A′ 사는 것 – 바울(22) / B′ 죽는 것 – 바울(23) / C′ 유익(24)”. 위 표는 원문 배열을 본문에 맞게 풀어 쓴 것임 (해석).

### 1:27–2:18 권면 — 하나 됨

- **《교차》 1:27–2:18**:
  - A 한마음과 한뜻으로 서서 협력하라(1:27)
  - B 대적하는 자들을 두려워하지 말라(1:28a)
  - B′ 두려워하지 말아야 할 이유(1:28b–30)
  - A′ 한마음과 한뜻으로 서서 협력할 때 필요한 것(2:1–18)
- **1:27 “복음에 합당하게 생활하라”**: 복음 = **유앙겔리온** / 합당하게 = **악시오스**(무게가 같은) / **생활하라 = 폴리튜오마이**(**시민으로 살다** — 3:20 시민권과 연결, 로마 식민도시 빌립보의 자부심을 반영함 (해석)).
- **하나 됨의 의미(2:1–4)**: 마음을 같이함 / 같은 사랑 / 뜻을 합함 / 겸손으로 **나보다 남을 낫게 여김** / 다른 사람의 일을 돌봄.
- **어떻게 하나 될 수 있는가(2:5–8)**: **그리스도 예수의 마음을 품는 것**.
- **《진전》 2:6–8 — 낮아지심의 4단계**:
  - A 근본 하나님의 본체이시나 하나님과 동등됨을 취할 것으로 여기지 않음(6)
  - A 자기를 비워 **종의 형체**를 가지사 사람들과 같이 되심(7)
  - A 사람의 모양으로 나타나사 **자기를 낮추심**(8)
  - A **십자가에 죽으심**(8)
- **결과 — 높아지심(2:9–11)**: 낮아지심으로 높아지심 / **모든 이름 위에 뛰어난 이름** / 모든 무릎을 꿇게 / 모든 입으로 “예수 그리스도는 주”라 시인하게 / 하나님 아버지께 영광 / 하나님의 뜻을 이루심.
- **2:12 “너희 구원을 이루라”** — 어떻게? → 2:13 “**너희 안에서 행하시는 이는 하나님**이시니”.
- 2:16 **생명의 말씀**(행 5:20; 요일 1:1) — 말씀의 가장 중요한 특징.
- 2:17 “나를 **전제**로 드릴지라도” — 전제(부어 드리는 포도주 제사, 민 15:5 — 보충) → 순교를 예감함 (해석).

### 2:19–30 보냄

- **디모데**(2:19–24): 뜻을 같이하여 진실히 생각할 자, 아들이 아버지에게 하듯 섬김.
- **에바브로디도**(2:25–30): 형제, 함께 수고하고 함께 군사 된 자, 빌립보의 사자, 병들어 죽게 되었으나 긍휼을 입음 — 보충. 강의안은 이름만 제시함.

### 3:1–4:1 경고 — 율법주의자들을 향한

- **“끝으로”(3:1)**: 보통 결론에 쓰는 표현(고후 13:11)이지만 여기서는 **새 주제로 넘어가는 표지**.
- **할례파**: “믿음이 중요하지만 믿음만으로는 안 된다”고 주장함. 당시 마가도 할례파였음(골 4:10–11).
- **본문의 할례파 묘사**:
  1. **개들**(3:2).
  2. 행악하는 자들(3:2).
  3. **몸을 상하게 하는 일 = 카타토메(절단)** ↔ 할례 = **페리토메** — 말놀이.
  4. 그리스도의 십자가의 원수(3:18).
  5. 그들의 마침은 멸망(3:19).
  6. 그들의 신은 배(3:19; 딛 1:12; 롬 16:18; 고전 6:13).
  7. 땅의 일을 생각함(3:19).
- **“우리가 곧 할례파라”(3:3)**:
  1. **하나님의 성령으로 봉사함** — 봉사하다 = 헬 **라트류오**, 히 **아바드**(예배하다, 섬기다; 시 50:5 “제사로 나와 언약한 이들”).
  2. **그리스도 예수로 자랑함**(롬 3:21).
  3. **육체를 신뢰하지 않음**.
- **바울의 육체의 자랑 7가지(3:5–6)**:
  1. 팔 일 만에 할례.
  2. 이스라엘 족속.
  3. 베냐민 지파.
  4. 히브리인 중의 히브리인.
  5. 율법으로는 바리새인.
  6. 열심으로는 교회를 박해함.
  7. 율법의 의로는 흠이 없음.
- **그리스도 예수를 아는 지식이 가장 고상함(3:8–9)** — 유익하던 것을 해로, 배설물로 여김.
- **바울의 소원(3:14)**: **푯대를 향하여 / 부르심의 상 / 잡으려고 달려가노라**.
- **“눈물을 흘리며”(3:18)** → **십자가의 원수(3:18–19)**: 마지막은 멸망 / 섬기는 신은 자기 배 / 부끄러움을 영광으로 삼음 / 땅의 일을 생각함.
- **3:20 시민권 — 대조**:

| 로마 제국에 속한 자 | 하나님 나라에 속한 자 |
|---|---|
| 로마 시민권을 얻는 방법(출생·구입·전역·해방) | 하나님 나라 시민권을 얻는 방법 |
| 로마 시민권자의 특권(재산·소송·세금 감면·형벌 면제·상소) | 하나님 나라 시민권자의 특권 |

  - 오른쪽 칸은 강의에서 채우는 질문. (해석) 빌립보는 **로마 식민도시**(시민권 도시)라서 “우리의 시민권은 **하늘**에 있는지라”는 원독자에게 강하게 들렸을 것 → 1:27 폴리튜오마이와 수미상관.

### 4:2–20 권면과 감사

- **유오디아와 순두게(4:2)** — “복음에 나와 함께 힘쓰던 저 여인들”(4:3).
- **“나와 멍에를 같이한 네게”(4:3)** = 빌립보 교회 리더급의 어느 한 사람.
- **바울의 세 가지 권면(4:4–7)**:
  1. **기뻐하라**(4:4) — 빌립보서에서 기쁨이 **17번** 반복됨(1:4, 18, 25; 2:4(?), 17, 18 …). **“주 안에서”(엔)**의 세 가지 뜻: **공간**(주 안이라는 자리) / **도구·방법**(주로 말미암아) / **이유**(주 때문에).
  2. **너희 관용을 모든 사람에게 알게 하라**(4:5) — 관용 = **에피에이케스**(너그러움, 양보; 행 24:4; 딤전 3:3; 벧전 2:18).
  3. **아무것도 염려하지 말라**(4:6).
- **하나님의 평강(4:7)**: 마음과 생각을 지킴 / “너희에게 평강이 있을지어다”(요 20:19–20, 26) → **두려움을 해결하는 방법**.
- **절대 가치(4:8–9)**: 무엇에든지 참되며 / 경건하며 / 옳으며 / 정결하며 / 칭찬받을 만하며 / 무슨 덕이 있든지 / 무슨 기림이 있든지 → 이것들을 생각하라.
- **자족(4:11)** — 욕심을 다스리는 방법.
- **“내게 능력 주시는 자 안에서 내가 모든 것을 할 수 있느니라”(4:13)** — 능력의 근원.

### 4:21–23 끝인사

- “주 예수 그리스도의 은혜가 너희 심령에 있을지어다”(4:23).

## 주석용 핵심 메모

- 열쇠어: **기쁨(17회), 그리스도의 마음(2:5), 하나 됨, 시민권(1:27 폴리튜오마이 ↔ 3:20), 코이노니아(후원)**.
- 옥중서신이지만 기쁨의 편지 — 감옥의 특징표로 로마 투옥(60–62)을 확정함.
- 오기: 행 “12:12–40” → 16:12–40 / 행 “22:5” → 22:25 / “2:4 기쁨”은 빈도 목록에 들어갔으나 2:4에는 ‘기쁨’이 없음(2:2의 오기 추정).
