## I. ‘성취’ — 전체적 관점
1. **형식 인용구(성취 형식 인용구) 10회**: 1:22–23 / 2:15 / 2:17–18 / 2:23 / 4:14–16 / 8:17 / 12:17–21 / 13:35 / 21:4–5 / 27:8–10 (“…이루려 하심이라”).
2. 예수님과 율법(5:17 — 폐하러 온 것이 아니라 **성취**하러).
3. 구약 내용에 관한 잦은 언급.
4. **모형론**.

## II. 유대적인 동시에 반유대적 복음서
1. **유대적 요소**:
   - 언어·문화: 아람어가 번역 없이 사용(5:22 라가; 27:6 고르반) / 유대 관습이 설명 없이 언급(15:2; 23:5, 27) / 유대적 표현(**“하늘 나라”**, “하늘에 계신 우리/너희 아버지”).
   - **전도 범위가 이스라엘에 한정**(10:5–6; 15:24).
2. **반유대적/친이방적 요소**:
   - 21–22장 세 비유: 두 아들(21:28–32), 포도원 일꾼(농부)(21:33–46), 혼인 잔치(22:1–14).
   - 백부장의 믿음에 대한 논평(8:11–12 — 동서로부터 와서 아브라함과 함께 앉고, 나라의 본 자손들은 쫓겨남).
   - **선교 명령(28:18–20 — 모든 민족)**.
3. **모순의 해결(유대적 vs 반유대적)**: **출 19:5–6; 벧전 2:9** — 제사장 나라·거룩한 백성의 정체가 민족적 이스라엘에서 **예수를 따르는 새 백성**으로 (해석: 이스라엘의 사명을 성취하는 새 이스라엘).

## IV. 마태복음 개관

### 1. 1–2장 서론 — *quis et unde* (누구이며 어디서 왔는가)
- **(1) 계보(1:1–17): quis(누구)** — **그리스도, 다윗, 아브라함 inclusio**(1:1과 1:17) / “다윗의 자손 그리스도” / **14×3 구조** / 전환점: **다윗, 바벨론 포로** / **왕적 계보**(누가복음 계보와 비교 — 누가는 아담까지, 나단 계열).
- **(2) 성취 형식 인용구 (4+1)** — 1–2장에 다섯(1:22–23; 2:15; 2:17–18; 2:23 + 2:5–6 미가 인용) / ‘성취’ 주제의 중요성. (4+1: 형식 인용구 4 + 2:5–6 서기관의 인용 1로 보임 — 해석)
- **(3) 2장 지리 이동: unde(어디서)** — 유대 베들레헴 → (애굽) → 갈릴리 나사렛.
- **(4) 동방박사(2:1–12)** — **유대인들의 메시아가 유대인들에게는 배척당하고 이방인들에게 경배를 받음** → 반유대적·친이방적 복음서.

### 2. 3–4장 본론의 시작 — 첫째 이야기 단원
- **세례 요한(3:1–12)**: 왜 요한부터 시작? — **유대교의 종말론적 이원론**(현 시대/오는 시대) / **엘리야로서의 요한(말 4:5–6)** (→ `../구약/39_말라기.md` 마지막 말씀과 연결).
- **예수님의 세례(3:13–17)**: 왜 받으셨나? — **“모든 의를 이루기 위하여”** / **하나님의 아들 이스라엘의 세례(고전 10:2 — 홍해)와 예수님의 세례**.
- **시험(4:1–11)**: 이스라엘의 **광야 40년 시험 ↔ 예수님의 광야 40일 시험**.
  - **하나님의 아들 이스라엘–예수님 모형론**: ① 2:15 = 호 11:1 “애굽에서 내 아들을 불렀다” — **출애굽 모형** ② 3:13–17 — **홍해를 건넘/세례 모형** ③ 4:1–11 — **광야 시험 모형**.
  - 인용: 첫째 시험 **신 8:3** / 둘째 **신 6:16** / 셋째 **신 6:13** — 모두 이스라엘의 광야 시험을 반영하는 신명기 본문.
  - **셋째 시험의 위치적 중요성**: 세상에 대한 **‘왕권’** 제안 ↔ **28:18 “하늘과 땅의 모든 권세”** → 예수님의 사역을 **‘왕권’으로 감싸는 inclusio**.
- **갈릴리 사역 개시(4:12–25)**: 12–16 갈릴리의 중요성 — **사 9:1–2 성취** / **17 주제 선언 — 하늘 나라 = 하나님 나라, 회개** (**‘엥기켄’(가까이 왔다)의 시간적 함의** — 이미 도래/임박) / 18–22 네 제자를 부르심 — **하나님 나라와 제자도의 긴밀한 관계** / 23–25 주제 선언의 확장 — 4:23–9:35 inclusio.

### 3. 5–7장 산상설교 — 가르침으로 선포된 하나님 나라
- **구조**: A 서두(5:1–2) / B 서론(5:3–16) / **C 본론(5:17–7:12)** / B′ 결론(7:13–27) / A′ 결말(7:28–29).
- 청중: **제자들과 무리들**.
- **서론(5:3–16)**:
  - **3–10절 팔복 — ‘하늘 나라’ inclusio**(3절과 10절). 
    - 5:3 복되다 = **마카리오이**, 히 **아쉬레** — 심오한 내적 기쁨과 행복 / **영으로 가난한 자 = 아니(ani)** — 시 14:6; 25:16; 34:6; 40:17; 69:29; 86:1; **사 61:1–2**.
    - 5:6 **의에 주리고 목마른 자** — 시 42:1–2; 107:5–9; 사 55:1–2 / **‘의’ = 예수님의 메시아적 통치에 의해 선물로 주어진 것으로서, 하나님의 뜻에 순종하는 행동**(5:20; 6:33; 7:21).
    - 5:10 **의를 위하여 박해받은 자** — 하나님의 통치를 받는 제자는 삶의 원칙·목표가 세상과 철저히 달라 구별됨 / **제자란 박해받는 사실 자체를 기뻐하는 자**(벧전 3:14; 4:12–14).
  - **11–12절 세상의 부정적 반응(박해)** — 육체적·언어적 / 제자도는 이론이 아니라 ‘너희’의 일상적 현실.
  - **13–16절 세상의 긍정적 반응 — 소금과 빛**: 구별된 자(소금: 유일하게 짠맛 / 빛: 어둠과 확연히 구분) + **선한 영향**(맛과 빛) / 5:16 **착한 행실**, “하늘에 계신 너희 아버지”.
- **본론(5:17–7:12)**:
  1. **5:17–20 예수님과 구약**:
     - 17 “율법이나 선지자” = **구약 전체**, **7:12와 inclusio** / “폐하러 온 것이 아니라 **성취**하러” — **플레로사이**, 히 **말레(가득 채우다)**.
     - 18 “하늘과 땅이 없어지기 전에는, **모든 것이 이루어지기 전에는** 율법의 일점일획도…” — ‘모든 것’은? ‘이루어지다’는? → **‘성취’와 ‘완성’의 이미–아직 긴장**.
     - 19 “이 계명 중 지극히 작은 것 하나” — **성취된 율법의 전체적 유효성** / 율법과 계명이 속한 시대 구분.
     - 흐름: ① 17 구약을 성취하신 예수님 ② 18 구약 율법의 한계 ③ 19 성취된 율법의 전체적 유효성 ④ 20 성취된 율법을 지키는 제자들의 **더 뛰어넘는 의**.
     - **도식**: 구약 시대(예언의 시대) — **노모스 = 옛 율법, 성취를 내다봄**(17, 18절; 구약 백성이 지킨 율법) / 예수님의 지상 사역 = **성취** / 재림 = **완성** / 메시아 시대(성취의 시대) — **엔톨라이(19절) = 새 율법 = 성취된 율법 = 메시아적 율법**(제자들이 지킬 율법). 이미(기능·정신과 목표·십자가) ↔ 아직(권위·문자와 형식·제사제도).
     - 20 **서기관·바리새인의 의 vs 제자의 의**: 자기 의 ↔ 하나님의 의 / 자기 공로 ↔ 하나님의 은혜 / 자기 자랑 ↔ 하나님께 감사 — “뛰어넘지 않으면”: 양적? 질적? 둘 다?
  2. **5:21–48 여섯 가지 대조적 교훈**: 살인(21–26) / 간음(27–30) / 이혼(31–32) / 맹세(33–37) / 보복(38–42) / 사랑(43–48).
     - 도입 형식구: **“옛 사람에게 말한 바 … 너희가 들었으나(논제) / 나는 너희에게 이르노니(결론)”** → [하나님께서] 옛 사람들(=시내산 세대, 이스라엘)에게 말씀하신 것(=율법)을 너희가 [회당에서] 들었다 / 그러나 [궁극적으로] 나(=예수)는 너희(=제자들, 새 이스라엘)에게 (성취된 새 율법을) 말한다.
     - 5:22 세 부분: 형제에게 화내는 자 → 심판 / **‘라가’** → 공회 / **‘바보’** → 지옥 불 — 마음의 분노와 입술의 욕설이 성취 시대의 백성에게 심각한 문제.
     - **보복(38–42)** — 출 21:24–25; 레 24:20; 신 19:21: **구약 율법은 보복의 상한선** / 39절 ‘안티스테나이’ = 때로 **‘법적 소송을 걸다’** → 법적 분위기: 오른편 뺨 / 송사하여 속옷 / 억지로 오 리 / 구하는 자·꾸고자 하는 자.
  3. **6:1–18 세 가지 종교적 의**(앞은 윤리적 의, 여기는 종교적 의): 구제(2–4) / 기도(5–6) / 금식(16–18).
     - **주기도문 구조**: A 부름말 “하늘에 계신 우리 아버지”(9상) / B **아버지에 관한 세 탄원(2인칭)** — 이름(9하), 나라(10상), 뜻(10하) / C **제자의 필요에 관한 세 탄원(1인칭 ‘우리’)** — 일용할 양식(11), 죄 용서(12), 시험과 악에서 보호(13).
  4. **6:19–7:11 하나님, 재물, 이웃**: ① 6:19–24 재물 — “보화를 하늘에 쌓아 두라” ② 6:25–34 아버지께 대한 신뢰 — “염려하지 말라” ③ 7:1–6 사람에 대한 태도 — “비판하지 말라” ④ 7:7–11 아버지께 대한 신뢰 — “구하라, 찾으라, 두드리라”.
  5. **7:12 황금률 — 성취된 구약의 핵심** (“이것이 율법이요 선지자니라” — 5:17과 inclusio).
- **결론(7:13–27)**: 좁은 문과 넓은 문(13–14) / 좋은 열매와 나쁜 열매(15–20) / **아버지의 뜻대로 행하는 자(21–23)** — “주여 주여 하는 자마다 다 천국에 들어갈 것이 아니요 오직 하늘에 계신 내 아버지의 뜻대로 행하는 자라야” (5:20 ‘더 뛰어넘는 의’와 연결) / 세 부류: 예언하는 자, 귀신을 쫓아내는 자, 많은 권능을 행하는 자 / **“나는 너희를 도무지 알지 못하노라”** — **일방적 관계의 위험성** / “불법을 행하는 자들아” / “내게서 떠나가라” — 심판 선언 / **반석 위의 집과 모래 위의 집(24–27)** — “**나의 이 말**을 **듣고 행하는** 자” — 산상설교는 **듣고 행하라고 주어진 하나님 나라의 윤리**.

### 5. 10장 제자 파송 강화 — 두 번째 가르침 단원

### 7. 13장 하늘 나라 비유 — 세 번째 가르침 단원
- 앞 문맥과 긴밀: **첫 비유(씨 뿌리는 자)가 11–12장 부정적 반응의 이유를 설명** / **여덟 비유**의 체계적 배열 / 트리오 구조 / 모든 비유의 주제 = **‘하늘 나라’**.
- **Inclusio 구조**:
  - A 도입 비유: 씨 뿌리는 비유(1–9)
  - B 막간: a 비유의 **목적**(10–17) / b 씨 뿌리는 비유 **해설**(18–23)
  - C **세 가지 성장**에 관한 비유: 가라지(24–30), 겨자씨(31–32), 누룩(33)
  - B′ 막간: a′ 비유의 **목적**(34–35) / b′ 가라지 비유 **해설**(36–43)
  - C′ **세 가지 다른** 비유: 보화(44), 진주(45–46), 그물(47–50)
  - A′ 종결 비유: **집주인** 비유(51–53)
- **하늘 나라의 비밀(10–17, 34–35) — 비유의 목적**: 13:11 **‘비밀(뮈스테리온)’은 비유 가운데 나타나 있고, 그 의미를 깨닫는 것이 곧 하늘 나라의 비밀을 아는 것**(롬 16:25–26) / 14–15절 **사 6:9–10 직접 인용**(13절에서 암시) / 11:25–26 / **마음의 중요성** / 결국 **‘너희’(제자들)와 ‘저희’(외인)의 구분은 불가피**.
- **씨 뿌리는 자 비유(3–9, 18–23)**: 네 가지 밭의 4중 구조 — 열매 유무 대조 + **씨의 서로 다른 운명** 강조 / 팔레스타인 농업의 사실적 묘사가 아니라 **교훈을 위해 고안된 이야기** / 교훈: 복음이 때로 열광적 환영, 때로 즉각 거절 — **다양한 반응의 이유**를 설명 / 모두가 좋은 반응을 보이진 않지만 **좋은 반응을 보이는 자는 풍성한 결실**.

### 8. 14–17장 메시아의 지속적 사역과 십자가의 길 — 네 번째 이야기 단원
- **(1) 지속적 사역과 반응(14:1–16:20)**:
  1. 세례 요한의 죽음(14:1–12) — 예수님의 고난·죽음·장사를 내다봄(27:57–61).
  2. **오천 명을 먹이심(14:13–21)** — **네 복음서 모두에 기록된 유일한 기적** / **헤롯의 잔치와 대조되는 잔치** / 구약 배경: **왕하 4:42–44 엘리사(빵 20개로 100명)**, **출 16장 만나** / **메시아의 잔치** 상징 / **최후의 만찬과 평행**: 14:19 “떡을 **가지사** … **축사**하시고 **떼어** 제자들에게 **주시매**” = 26:26.
  3. 물 위를 걸으심(14:22–33) / 4. 병자들을 고치심(14:34–36).
  5. **장로들의 전통(15:1–20)** — **구약 음식법의 성취: 음식법의 폐지** / 전통의 위험성.
  6. **가나안 여인의 믿음(15:21–28)** — 음식법에 이어 **정결법 전체의 폐지를 내다봄**(두로·시돈 방문, 가나안 여인 치유) → **이방 지역·이방인의 장벽도 허무시는 상징** / 24절 “이스라엘 집의 잃어버린 양 외에는…”의 함의 / **유일하게 ‘큰 믿음’으로 칭찬받은 이방 여인**(8:5–13 백부장).
  7. 많은 사람을 고치심(15:29–31) / 8. **사천 명을 먹이심(15:32–39)** — 오천 명과의 평행과 차이:

| | 오천 명 14:13–21 | 사천 명 15:32–39 |
|---|---|---|
| 빵 | 5개 | 7개 |
| 생선 | 2마리 (익뛰아스) | 작은 생선 몇 마리 (익뛰디아) |
| 먹은 무리 | 5,000명 | 4,000명 |
| 남은 것 | **바구니(코피누스) 12개** | **광주리(스퓌리다스) 7개** |
| 기도 | **축복기도(율로게센)** | **감사기도(유카리스테사스)** |

  9. 표적을 구하는 자들(16:1–4) — 놀라운 기적에도 더 결정적 표적을 요구하는 바리새인·사두개인의 불신앙.
  10. 바리새인과 사두개인의 누룩(16:5–12) — 앞의 기적을 경험하고도 깨닫지 못하는 제자들, 먹는 빵에 집중.
  11. **베드로의 신앙 고백(16:13–20)**:
     - 사람들은 예수님을 **‘선지자적 범주’**로 이해 — 세례 요한, 엘리야, 예레미야 / 베드로 **“주는 그리스도시요”** — 베드로에게 ‘그리스도’는 어떤 의미? / **“살아 계신 하나님의 아들” — 마태만 기술**(14:33).
     - **16절 “당신은 그리스도” ↔ 18절 “너는 베드로”** 대구.
     - 17–20절 호의적 반응 — **마태만 기술** / 18 **페트로스와 페트라**의 관계 / **“내 교회(에클레시아)를 세우리니”** — 에클레시아 = 히 **카할**, 하나님의 **‘회중’, ‘공동체’** / 열두 제자와 이스라엘의 관계(19:28; 21:43) / ‘백성을 세우다’도 구약 개념(룻 4:11; 렘 1:10; 24:6; 31:4; 33:7; 시 28:5).
     - 19 **“매면 매여 있을 것이요 풀면 풀려 있을 것이다” — 미래완료형의 함의**(하늘에서 이미 결정된 것을 땅에서 선언) (18:18; 요 20:23).
- **(2) 고난·죽음·부활(16:21–17:27)** — 베드로가 고백한 ‘그리스도’의 진정한 모습: ① 거절·고난·죽음이 선교의 일부(21) ② 베드로의 간청 묵살(22–23) ③ **‘그리스도’ 칭호를 ‘인자’로 교체**(27) ④ **영광은 미래에 속함**(27).
  1. **첫 번째 수난 예고(16:21–23)** — 베드로가 붙들고 **항변**(꾸짖음) — 이유는? / **“사탄아 내 뒤로 물러가라”** — 왜 ‘사탄’이라고까지?
  2. **제자의 길(16:24–28)** — 제자도가 스승과 일치됨이라면 같은 운명을 나눔 / **“자기를 부인하고”** — 실질적 의미? / **“자기 십자가를 지고”**(10:38–39) / 28절(비교 막 9:1) “인자가 **그 왕권을 가지고** 오는 것” — 단 7:13–14 → **단일 사건보다 부활하여 하나님 우편에 앉으신 예수님의 현재적 최고 권위**를 인식하는 것.
  3. **변모(17:1–8)** — 공관복음 모두 빌립보 가이사랴 고백 및 수난 예고와 밀접히 연결.
  4. **엘리야로서의 세례 요한(17:9–13)** — 엘리야가 먼저 와야 한다는 신념(말 4:5) / 대답의 세 측면: ① 서기관들의 기대를 확증(11) ② 그러나 **엘리야의 도래는 이미 과거**(12) ③ **엘리야 도래의 목표는 예수님의 고난을 막는 것이 아니라 오히려 그 죽음을 전조**하는 것.
  5. 귀신 들린 소년(17:14–20) / 6. **두 번째 수난 예고(17:22–23)** — 빌립보 가이사랴에서 예루살렘 가는 여정의 중간 갈릴리 / “제자들이 매우 근심하더라” — 깨닫지 못함 / 7. 성전세(17:24–27).

### 9. 18장 제자 공동체에 관한 가르침
1. **진정으로 큰 자(1–5)**: “천국에서는 누가 크니이까?” — 제자들의 관심은 **지위와 특권**, 세상과 다르지 않음 / 대답은 **시청각적** / “돌이켜 어린아이들과 같이 되지 아니하면” — **어린아이의 성품보다 사회적 지위(낮음)에 관심** / 4절 **“자기를 낮추는 사람”** — 1절 질문에 대한 직접 답 / 5절 문자적 어린아이 → 6, 10, 14절 **‘작은 자’**로 전환 / **“내 이름으로”** 영접 = 나를 영접(25:40).
2. **넘어지게 하는 것(6–9)**: 다른 사람으로부터 오는 위험(6–7) / **자신 안에서 오는 위험**(8–9).
3. **길 잃은 양 비유(10–14)** — ‘작은 자’가 **모든 그리스도인**에게 적용 / 누가복음(잃은 양)과 비교: **마태 “길을 잃으면”(플라네테) vs 누가 “잃으면”** / “그들의 천사들”(단 10장; 12:1; 계 1:20; 시 34:7; 91:11; 히 1:14; 쿰란 문헌) / 14절 **하나님의 뜻**에 기초.
4. 목회적 관심 실천(15–20).
5. **용서(21–35)**: 몇 번? — **“일흔 번씩 일곱 번”: 490번? 77번?**(창 4:24 라멕) / **만 달란트 ≈ 약 20만 년 연봉**, **백 데나리온 = 만 달란트의 60만분의 1** / “너희가 각각 마음으로부터 형제를 용서하지 아니하면 … 이와 같이 하시리라”(6:14–15).

### 10. 19–20장 예루살렘을 향하여
- **하나님 나라의 혁명적 가치관**: 이혼과 재혼(19:1–12) / 어린아이들과 하늘 나라(19:13–15) / 부자(19:16–26; 13:44–46) / 제자도와 소유(19:27–30; 4:18–20) / **동등한 보상 비유(포도원 품꾼, 20:1–16)** — **19:30 ↔ 20:16 inclusio**(“먼저 된 자로서 나중 되고…”).
- **세 번째 수난 예고(20:17–19)**와 **야고보·요한의 요청, 섬김의 도리(20:20–28)** — 제자들의 더딘 깨달음(26:36–46).
- **여행의 마무리: 두 맹인을 고치심(20:29–34)** — **위치적 중요성: 진정한 제자도에 대한 깨달음(눈 뜸)** / **‘둘’의 중요성**(마가는 바디매오 한 명) — 8:28–34(두 귀신 들린 자 — “하나님의 아들”), 9:27–31(두 맹인 — “다윗의 자손”) (마태의 ‘둘’ = 법적 증인 두 명 — 해석).

### 11. 21–22장 유대교 지도자들과의 대결 (예루살렘 사역 개관)

| 본문 | 내용 |
|---|---|
| 21:1–22 | **세 가지 상징적 행동**: 입성 / 성전 척결 / 무화과나무 저주 |
| 21:23–27 | 예수님의 권위가 도전받음 |
| 21:28–22:14 | **세 가지 논증적 비유**: 두 아들 / 포도원 농부 / 혼인 잔치 |
| 22:15–40 | 적대자들의 **세 가지 질문**: 세금 / 부활 / 큰 계명 |
| 22:41–46 | 예수님의 질문: 다윗의 자손 |
| 23:1–36 | 유대교 지도자들에게 미칠 화 |
| 23:37–39 | 예루살렘에 미칠 심판 |
| 24:1–2 | 성전 파괴 예고 |
| 24:3–25:46 | 성전 파괴와 마지막 심판에 대한 강론 |

- **입성(21:1–11)**: 성취 인용 — 주로 **슥 9:9**, 도입부는 **사 62:11** — 구속자의 오심 약속 / 무리가 ‘다윗의 자손’으로 인식(9) / **“온 성이 소동하여 이는 누구냐”**(10–11) — “갈릴리 나사렛에서 나온 선지자 예수”.
- **성전 척결(12–17)**: 입성의 절정 / 당시 시장은 성전 제사에 필요했을 수도 — 먼 순례자에게 흠 없는 짐승 제공, **성전세용 두로 은전 환전** / 메시아적 암시: 겔 40:48; 슥 6:12–13; **말 3:1–4**; 슥 14:21 / 14절 **맹인과 저는 자들이 성전에서** 고침(삼하 5:8 — 다윗 때 배제되던 자들; 사 56:7) / 15–16 “어린 아기와 젖먹이들의 입에서 나오는 찬미”(시 8:2) — 어린아이의 영적 분별력(11:25).
- **무화과나무 저주(18–22)**: 미 7:1; 렘 8:13; 눅 13:6–9 — **열매 없는 나무 = 경건이 결여된 종교의 상징** → **성전 척결과 같은 시각**으로 해석.
- 권위 도전(21:23–27) — 성전에서 진행, 앞과 연속.
- **두 아들 비유(21:28–32)**: 지도자들의 실패는 도덕적 문제뿐 아니라 **예수님의 사역에 나타난 하나님의 구원 활동을 인식·환영하지 못한 것**.
- **포도원 농부 비유(21:33–43)**: “제때에 열매를 바칠 **다른 농부들**”(40–41) — 방심의 위험(롬 11:20–22) / **43절 “하나님의 나라를 너희는 빼앗기고 그 나라의 열매 맺는 백성이 받으리라” — 새 백성에 대한 마태의 가장 명백한 언급**, 반유대적·친이방적 성격 / **‘백성(에트네이)’ 단수** → 단순히 이방인이 아니라 **모든 나라들로부터 나온 하나님의 백성**.
- **혼인 잔치 비유(22:1–14)**: 6–7절 “그들의 동네” = 예루살렘 → **AD 70 예루살렘 파괴** / 9–10 예상치 않은 새 백성으로 대체 / 11–13 **예복** — 구원은 모두에게 열려 있으나 **원칙 없는 자유는 아님**(21:41, 43; 7:13–27; 계 19:8) / 14 **“청함을 받은 자는 많되 택함을 입은 자는 적으니라”**.

### 12. 23장 서기관과 바리새인에 대한 경고
- 비판의 이유(15:1–20과 같음): **사소한 율법 규율에 관심을 빼앗겨 율법의 더 중요한 근본 요구를 무시**.
- 1–12 무리와 제자들에게 경고: **“그들이 말하는 것은 행하고 지키되 그들의 행위는 본받지 말라”** — ‘말하는 것은 무엇이든지’는? ‘행위’는? / **‘짐’**(11:28–30과 대조).
- **13–36 일곱 가지 화**: 13 / 15 / 16–22 / 23–24 / 25–26 / 27–28 / 29–32 / 결론 33–36.

### 13. 24–25장 성전 파괴와 세상 끝 — 다섯 번째 가르침 단원
- **해석 원칙 (R. T. France)**: 1) 성전 파괴와 세상 끝이 함께 다루어짐 → **신학적 연관** 2) 그러나 **동시에 일어날 것임을 증명하지는 않음** 3) **24:4–35 = 질문 앞부분(성전 파괴) 답변 / 24:36–25:13(46) = 뒷부분(세상 끝) 답변** 4) 24장은 **구약 언어**에 빚짐 → 구약 배경으로 이해.
- **성전 파괴에 대한 교훈(24:4–35)**:
  - 4–14 **설익은 기대에 대한 경고** — 산통의 시기, 핍박과 미움 → 진정한 제자의 특징 **‘인내’**(13).
  - 15–28 **유대에서 위기의 도래** — 15–22 유대 땅의 위기 / 23–28 그 상황에서도 인자 재림에 대한 설익은 기대는 금물.
  - 29–35 **‘이 세대’ 안에 있을 성전 파괴** — 29절 “해가 어두워지며…”는 **사 13:10(바벨론 멸망), 34:4(에돔 멸망)**의 언어 → **성전의 운명**에 관한 것으로 보는 것이 자연스러움 / 30 “인자가 구름을 타고”(단 7:13–14) / 32–34 무화과나무 비유 / 34 “이 모든 일” — **이 세대가 지나가기 전에**.
  - (→ 강의 입장: 24:29–31을 AD 70 성전 파괴에 대한 **구약적 심판 언어**로 읽는 **France의 해석**을 소개 — `../구약/29_요엘.md` 2:10 ↔ 마 24:29 연결과 비교)
- **세상 끝에 대한 교훈(24:36–25:46)** — **파루시아**(3, 27, 37, 39절) / 강조: **그때를 모른다, 가장 예기치 않은 때** / **24:36 ↔ 25:13 inclusio** — 모르는 ‘날’과 ‘시각’.
  - “알지 못한다” 반복표: 24:36(날·시각) / 39 / 42(날, 깨어 있으라) / 43(알았더라면, 깨어 있어) / 44(생각하지 못한 시각) / 50(날·시각) / 25:13(날·시각, 깨어 있으라).
  - 노아의 때(24:36–39) / 두 사람(40–41) — 무슨 일을 하느냐가 아니라 **준비되었느냐** / 도둑(42–44) / **신실한 종과 악한 종(45–51)** — 준비란 가만히 기다림이 아니라 **활동적으로 임무 수행**.
  - **열 처녀(25:1–13)**: 신랑 = 예수님(9:15), 잔치 = 메시아 잔치(22:1–14; 8:11) / “다 졸며 잘새” — 준비성이란? / **준비성은 다른 사람의 준비에 의존할 수 없다** / **준비는 그날이 오기 전까지만 가능**(7:22).
  - **달란트(25:14–30)**: 기다림은 공허한 지연이 아니라 **맡겨진 것을 선히 사용할 기회** / “각각 그 재능대로” — 하나님은 백성을 각각의 개인으로 인지 / **셋째 종의 실수는 게으름보다 주인에 대한 그릇된 이해** — **그릇된 행동을 하지 않는 데만 마음을 쏟는 소극적 종교성의 위험**.
  - **마지막 심판(25:31–46)**: 마지막 가르침의 마지막, 21–25장 심판 주제의 절정(7:21–23) / “임금, 나라, 상속” — **단 7:14 성취의 궁극적 완성** / “예비된”(20:23) / **40절 “형제들” = 제자들**(12:48–50; 28:10), **“지극히 작은 자”**(10:42; 18:6, 10, 14) / “나를 떠나라” — **최종 선고는 예수님과의 교제 상실**(7:23).

### 14. 26–28장 예수님의 죽음과 부활
- 세 주제: ① **하나님의 뜻을 이루어 가시는 예수님** ② **대적하는 자들의 적극적 역할** ③ **하나님의 뜻을 따르는 데 실패하는 제자들**.
- **(1) 수난 준비(26:1–46)**: 도입(1–5) / **향유를 부음(6–13)** (→ `복음서에 언급되는 향유부음사건` 노트와 연결 예정) / 유다의 배반(14–16) / 유월절 만찬·배반 예고(17–25) / **주의 만찬 제정(26–30)** — 26절 14:19와 비교, ‘빵’·‘쪼개다’의 상징 / 28절 **“죄 사함을 얻게 하려고 많은 사람을 위하여 흘리는 나의 피 곧 언약의 피”** — 출 24:8; 마 20:28; 히 9:15–22.
  - **베드로 부인 예고(31–35)**: “다 나를 버리리라” / “모두가 버릴지라도 나는 결코…” — **대변인·대표자 역할을 벗어난 답변** / **“베드로의 문제: 자기 부정이 아니라 자기 확신!”**
  - **겟세마네(36–46)**: 베드로와 세베대의 두 아들(20:22; 26:35) / “고민하고 슬퍼하사” — **철저한 인성**(27:46; 히 5:7) / “내 마음이 매우 고민하여 죽게 되었으니” — 괴로움의 절정 / 39 **얼굴을 땅에 대고** “할 수만 있다면 이 잔을 … 그러나 나의 원대로 마시옵고 아버지의 원대로” — ‘할 수만 있다면’은 **아버지의 뜻과 다른 자기 뜻을 구하는 것이 아님** / 41 “시험에 들지 않게 깨어 기도하라” — **제자들은 준비 단계에서 이미 실패** / 42 “내가 마시지 않고는 이 잔이 지나갈 수 없거든 아버지의 원대로” — **첫 기도보다 진전**.
- **(2) 체포와 심문(26:47–27:26)**: 체포 / **공회 심문(57–68)** — 가야바, 서기관, 장로 / 왜 거짓 증거를 찾았나? / 58 **“멀찍이”** — 베드로의 모습을 예고 / 61 **“하나님의 성전을 헐고 사흘 동안에 지을 수 있다”** — 이 증언의 이유(12:6; 21:18–19; 23:38; 24:2; 요 2:19; 행 6:13–14; 슥 6:12; 겔 40–48) / 63 **침묵**(사 53:7) / “네가 하나님의 아들 그리스도인지” — 핵심 관건 / 64 **“네가 말하였느니라”** — 유보적 답변 / “인자가 권능자의 우편에 앉은 것과 하늘 구름을 타고 오는 것을” — 시 110:1; 단 7:13.
  - **베드로의 부인(69–75)** — 점증: **단순 부인(70) → 맹세하며 부인(72) → 저주하며 맹세하며 부인(74)** / 75 “밖에 나가서 심히 통곡하니라” — **마태복음에서 베드로 개인에 대한 마지막 언급**.
  - 빌라도에게 넘겨짐(27:1–2) / 유다의 죽음(3–10) / 빌라도 심문(11–14) / 사형 선고(15–26) — 19–20 **이방 여인(빌라도의 아내)과 유대교 지도자들의 대조** / 24–25 빌라도의 소극적 역할과 백성의 적극적 역할 — **“그 피를 우리와 우리 자손에게 돌릴지어다”**(21:33–46; 23:34–36, 38; 24:2) / 그럼에도 **최종 결정은 빌라도**.
- **(3) 십자가 죽음(27:27–56)**: 조롱 / 십자가 — **기독론적 호칭 연속**: 유대인의 왕(37), 성전 건축자(40), 하나님의 아들(40), 이스라엘의 왕(42), 하나님의 아들(43) / 40 “네가 만일 하나님의 아들이어든” — **4:3, 6 광야 시험의 반향**, 26:53 / 45 **제육시부터 제구시까지 어둠** — 암 8:9; 욜 2:2, 31; 습 1:15 / 46 **“엘리 엘리 라마 사박다니”** — 고통의 진정한 이유(20:28; 26:36–46) / 50 **“영혼이 떠나시니”** — 죽음의 의지적 요소 / 51 **성소 휘장이 위로부터 아래까지 찢어짐**(히 6:19; 9:3; 10:19–20) / 54 **이방인 백부장의 고백 “이는 진실로 하나님의 아들이었도다”** — 유대인들과 대조(14:33; 16:16) / 55–56 많은 여인들(27:61; 28:1–10).
- **(4) 장사와 부활(27:57–28:15) — 교차 구조**: A 요셉의 장사와 여인들(27:57–61) / B 경비병들이 무덤을 지킴(62–66) / A′ 살아나신 예수님과 여인들(28:1–10) / B′ 경비병들의 보고와 거짓 증언(28:11–15).
- **(5) 부활하신 주님의 왕권과 명령(28:16–20)**: 18 **“하늘과 땅의 모든 권세를 내게 주셨으니”**(4:8–9; 26:64; **단 7:14**; 빌 2:6–11) / 19–20 **“모든 민족을 제자로 삼아”**(비교 10:5–6; 8:11–12; 21:28–32, 41–43; 22:8–10) / **“아버지와 아들과 성령의 이름(단수)으로”** — ‘이름’이 단수인 함의 / **“내가 너희에게 분부한 모든 것을 가르쳐 지키게”**(7:24–27; 10:1, 8) / **“볼지어다 내가 세상 끝날까지 항상 너희와 함께 있으리라”** — **1:23 임마누엘; 18:20; 사 7:14 → 책 전체의 inclusio**.
