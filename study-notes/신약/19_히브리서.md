## BRI [히B]

### 1. 저자

- **저자의 특성**:
  1. **유대인** — “옛적에 선지자들을 통하여 우리 조상들에게 말씀하신 하나님”(1:1) / 구약 인용이 많음(1:5, 6, 7, 8–9 …) / 구약에 해박함(선지자, 천사, 모세, 대제사장, 언약 …).
  2. **예수님의 말씀을 직접 듣지 못함, 사도는 아님** — “들은 자들이 우리에게 확증한 바니”(2:3), “우리는 들은 것에”(2:1).
  3. **원독자의 상황을 잘 알고 친분이 있음** — “너희가 듣는 것이 둔하므로”(5:11–12) / “이미 성도를 섬긴 것과 이제도”(6:9–10) / “고난의 큰 싸움을 견디어 낸 것”(10:32–34) / “아직 피 흘리기까지는 대항하지 아니하고”(12:4) / 1인칭 복수 “우리”.
  4. **디모데와 친분**(13:23).
  5. **지도자급**의 사람.
- **가능성 있는 저자**(강의안은 결론을 내리지 않음):

| 후보 | 근거 |
|---|---|
| **아볼로** | 알렉산드리아 출신 유대인, 구약에 능통(행 18:24–28) / 초대교회의 전도자·교사(고전 1:12; 3:4–6; 4:6; 16:12) |
| **바나바** | ‘권위자’(“위로의 아들”, 행 4:36) ↔ “권면의 말”(히 13:22) / 구브로 출신 **레위인**(행 4:36) → 제사 제도에 해박함 |
| **브리스길라와 아굴라** | 헬레니즘에 익숙한 교양 있는 유대인 / 아볼로를 가르침(행 18:24–26) / 장막 만드는 일(행 18:3) / 여행이 많았음(행 18:2, 11; 롬 16:3; 히 10:34) |

  - 바울이 후보에 없음 — 2:3 “들은 자들이 우리에게 확증”과 맞지 않기 때문으로 보임 (해석).

### 2. 수신자

- **수신자의 특성**:
  1. **유대인** — “우리 조상”(1:1).
  2. **그리스도인** — “우리가 믿는 도리의 사도이시며 대제사장이신 예수”(3:1) / “시작할 때에 확신한 것을 끝까지”(3:14) / “우리도 복음 전함을 받은 자”(4:2) / “이미 믿는 우리들은”(4:3) / “하나님의 아들 예수시라 우리가 믿는 도리를”(4:14).
  3. 여전히 **헌신된** 그리스도인(6:9–10).
  4. **2세대**(2:3).
  5. 복음을 들은 지 **적지 않은 시간**이 흐름 — “때가 오래되었으므로 마땅히 선생이 되었을 터인데”(5:12) / “교훈의 터를 다시 닦지 말고”(6:1–2).
  6. **핍박을 받고 있음** — 10:32–36 / “아직 피 흘리기까지는”(12:4) / “너희도 함께 갇힌 것같이”(13:3).
  7. 고난 중 **지도자를 잃은** 것 같은 느낌(13:7 “하나님의 말씀을 너희에게 이르고 너희를 인도하던 자들을 생각하며”).
  8. 믿음이 **흔들림**(13:9 “여러 가지 다른 교훈에 끌리지 말라”).
  9. **모이는 일**에 어려움(10:25 “모이기를 폐하는 어떤 사람들의 습관과 같이 하지 말고”).
- (보충) 기록 장소가 비어 있음. 13:24 “이달리야에서 온 자들도 너희에게 문안하느니라”가 흔히 로마 관련 단서로 쓰임 — 강의안은 역사적 배경에서 **로마**(네로, 로마 유대교)를 다룸 → 수신지를 로마로 보는 흐름 (해석).

### 3. 기록 연대 — 64년 이후, 70년 이전 (추론)

- ① 이전에 박해가 있었음을 암시함(10:32–34). **박해 연표**:

| 연대 | 사건 |
|---|---|
| c.30 | 스데반 집사의 죽음 |
| 49 | 글라우디오 황제의 로마 추방 |
| **c.64** | **네로 박해** |
| **70** | **디도 장군의 예루살렘 멸망** |
| c.90 | 도미티안 박해 |

- ② 지금도 박해 가운데 있음(10:32–36; 12:4).
- ③ **“교회”라는 단어를 씀**(2:12 — 시 22:22에서는 ‘회중’) → 바울의 3차 전도여행 이후.
- ④ 저자와 원독자 모두 **복음을 직접 듣지 못한 2세대**.
- ⑤ **디모데** — 갇혔다가 풀려남(13:23). 강의안은 “**81년에 순교**”라고 적음 → 전승 연대로 보이며 출처는 확인하지 못함.
- ⑥ **성전이 멸망하기 이전** — “제사장마다 매일 서서 섬기며”(10:11), 현재형으로 제사장과 제사를 많이 언급함 / 예루살렘 성전은 **70년** 디도 장군에게 완전히 무너짐.
- ⇒ 강의안은 결론 연도를 쓰지 않음. 근거들을 종합하면 **64년(네로 박해) 이후 ~ 70년(성전 멸망) 이전**으로 보는 흐름 (해석).

### 4. 기록 장소

- 빈칸 슬라이드 → **확인하지 못함** (위 수신자 항목의 추정 참고).

### 5. 역사적 배경

1. **64년 로마 대화재와 네로의 그리스도인 박해**.
2. 당시 로마에서의 유대교와 기독교 — **아가야 총독 갈리오의 판결**(행 18:12–17: 기독교를 유대교 내부 문제로 봄 → 유대교처럼 보호받음) / **로마 대화재 이후 유대교인들의 입장**(기독교와 거리를 둠 → 그리스도인은 ‘합법 종교’의 보호막을 잃음, (해석)).
3. **그리스도인의 갈등**: 예수님은 누구신가? / **예수님의 침묵**(박해 중에도 개입하지 않으시는 것처럼 보임) → 차라리 보호받는 유대교로 돌아가려는 유혹 (해석).

### 6. 히브리서의 특징

- **(1) 형식**:
  - 전통적으로 **편지**(“히브리인들에게 보내는 편지”)로 분류되지만 당시 일반적인 편지 양식을 따르지 않음(서두 인사가 없음).
  - **권고로 시작하는 설교문** — 13:22 “**권면의 말**”(행 13:15 회당의 “권할 말”과 같은 표현).
  - **유대·헬레니즘 전통의 설교**.
  - ***Syncrisis*** — **비교(대조)를 통해 강조하는 연설문 형식**.
- **(2) 5개의 경고**:
  1. 예수님께서 주신 구원을 **등한히 여기지 말라**(2:1–4).
  2. **마음을 완고하게 하지 말라**(3:7–4:7 또는 3:7–19).
  3. 끝까지 믿음으로 약속의 기업을 붙잡으라 — **타락(배교)하지 말라**(5:11–6:12).
  4. **다시 죄를 짓지 말라**(10:19–39).
  5. **하나님을 거역하지 말라**(12:14–29).
- **(3) 예수님에 대한 풍부한 묘사**.
- **(4) 완전한 인간이 되어 고난을 받으신 예수님**: 죽음의 고난(2:9) / 시험을 받아 고난받으셔서 시험받는 자를 도우심(2:18; 4:15) / 받으신 고난으로 **순종을 배우심**(5:7–9) / **한 제물**(10:14) / **십자가를 참으심**(12:2–3) / **성문 밖에서 고난**(13:12).
- **(5) 대제사장 되신 예수님**.
- **(6) ~보다 뛰어나신 예수님**.
- **(7) 반복 강조**: 새 언약(8:8–12; 10:16–18) / **오늘**(3:7–11, 15; 4:3–7) / **멜기세덱의 반차**를 따른 제사장(5:6, 10; 6:20; 7:17) / 대제사장 되신 예수님(4:14, 15; 5:5, 6, 10; 6:20; 7:17; 10:21) / **“~보다 낫다” 13번 반복** / **고정·잡음**(3:1, 6, 14; 4:14).
- **(8) 요약적 결론 “그러므로”**: 2:1; 3:1, 7; 4:1, 11, 14, 16; 6:1; 7:25, 26; 8:1; 9:23; 10:19; 12:1 → “그러므로”를 기준으로 나누면 **가르침 → “그러므로”(실천적 권면 또는 경고)**가 반복되는 구조.
- **(9) 대조**: **영원한 것 vs 일시적인 것** / **그림자 vs 실체**.

## 본문 [히본]

### 1. 모든 선지자(계시)보다 뛰어나신 예수님 (1:1–3)

- 대조: **이제 하나님께서 말씀하시는 방법이 달라짐** — 구약의 모든 선지자와 그 계시 vs **아들** 예수님.
- 예수님에 대한 묘사(2–3절): ① **만유의 상속자** ② **창조자** ③ **하나님의 영광의 광채**(Radiance of God) ④ **하나님 본체의 형상** ⑤ **말씀으로 만물을 붙드심**(만물의 주권자·통치자) ⑥ **죄를 정결하게 하심**.

### 2. 천사보다 뛰어나신 예수님 (1:4–2:18)

- **(1) 하나님의 아들로서 (1:4–14)**:
  - 천사보다 더 아름다운 **이름**을 주심.
  - 천사의 존재: 창 18:1–8; 19:1–23 / **행 7:53; 갈 3:19 (천사가 전한 율법)** / 골 2:18–19(천사 숭배).
  - 천사가 전해 준 율법과 예수님의 대조 — 율법의 역할.
  - 묘사: 하나님의 아들(5–12) / **맏아들(프로토토콘)** / 천사들의 경배를 받으실 분(6) / 보좌가 영원함(8) / 공평한 규(8) / 의를 사랑하고 불법을 미워하심(9) / 즐거움의 기름 부음(9) / 태초에 땅의 기초를 두심(10) / 하늘을 지으심(10) / 영존하심(11).
  - **천사 vs 예수 그리스도**:

| | 천사 | 예수 그리스도 |
|---|---|---|
| 이름 | 하나님의 **메신저** | 하나님의 **아들** |
| 예배 | 예배하는 자 | 예배받는 자 |
| 역할 | **섬기는 영** | **다스리는 분**(통치자) |

  - **구약 인용 대조**(슬라이드에 원문 병치): 1:8–9 = **시 45:6–7**(왕의 혼인 시 — “왕”이 “주”로) / 1:10–12 = **시 102:25–27**(“주는 영존하시겠고 … 한결같으시고”) / 1:13 = **시 110:1**(“내 우편에 앉아 있으라”).
  - **구조 #1 (교차)**: A 예수님의 하나님 되심 — 아들(1:5–6) / B 천사 — 바람과 불꽃(1:7) / A′ 예수님의 하나님 되심 — 주, 왕, 창조자, 영원한 하나님(1:8–13) / B′ 천사 — 섬기는 영(1:14).
  - **구조 #2 (1:1–3 ↔ 1:4–14 평행)**:

| 주제 | 1:1–3 | 1:4–14 |
|---|---|---|
| 상속자 | 아들, 만유의 상속자(2a) | 하나님의 아들(5–9) |
| 창조자 | 모든 세계를 지으심(2b) | 주의 손으로 지으심(10) |
| 본질 | 영광의 광채, 본체의 형상(3) | 영존하심, 다함이 없음(11–12) |
| 승귀 | 지극히 크신 이의 우편(3) | 우편에 앉으심(13) |

- **(2) 경고 1 (2:1–4) — 예수님께서 주신 구원을 등한히 여기지 말라**:
  - 천사들을 통해 하신 말씀 = 율법(2절; 행 7:53; 갈 3:19).
  - 대조: 천사를 통해 주어진 율법을 어겨도 보응을 받았는데 → 영원한 왕이신 예수님께서 주신 **큰 구원**(3절)을 지키지 않는다면?
  - 핵심: 구원을 등한히 여기지 말고 온전히 지키라.
- **(3) 사람의 아들로서 천사보다 뛰어나신 예수님 (2:5–18)**:
  - “천사보다 **잠시 못하게** 하심”(7, 9) = 사람이 되셔서 죽음의 고난을 받으심 / “**영광과 존귀로 관**을 쓰심”(9) = 고난 후 부활하심.
  - **하나님의 아들이 혈과 육을 지닌 사람의 아들이 되신 이유** (6가지):
    1. 모든 사람을 위하여 **죽음을 맛보려고**(9).
    2. 죽음을 통해 **죽음의 세력을 잡은 자(마귀)를 멸하려고**(14).
    3. 죽기를 무서워하여 **한평생 종노릇하는 자들을 놓아 주려고**(15).
    4. **아브라함의 자손**들을 붙들어 주려고(16).
    5. 백성의 죄를 **속량**하려고(17).
    6. **시험받는 자들을 도우시려고**(18).
  - **구원의 창시자(10) = 헬 아르케고스**(히 2:10; 12:2; 행 3:15; 5:31) — 고난을 통해 온전하게 됨.
  - **한 근원(11)** = ‘한 가족’ → 형제라 부르심을 부끄러워하지 않으심.
  - **대제사장(17)** — 신약에서 예수님을 대제사장으로 설명하는 **첫 번째 구절**.

### 3. 모세보다 뛰어나신 예수님 (3:1–6)

- 권면: “**거룩한 형제들**아”(1) / “**깊이 생각하라**”(1 — ‘생각을 고정하라’) / 연속성(Continuity) / “소망의 확신과 자랑을 **끝까지 굳게 잡으라**”(6).
- 예수님에 대한 묘사(1절): **사도**(보냄을 받은 자; 마 10:40; 15:24; 막 9:37; 눅 9:48) + **대제사장**.
- **모세 vs 예수님 — 비교 후 대조**:

- 하나님의 집(6) = “우리가 … 끝까지 굳게 잡으면 우리는 그의 집이라”.

### 4. 경고 2 (3:7–4:7) — 마음을 완고하게 하지 말고 믿음을 버리지 말라

- 모세 당시 이스라엘의 예(3:7–11 = **시 95:7–11**) — 안식의 약속을 받고도 들어가지 못한 이유: 마음을 **완고하게** 함(8) / 하나님을 **시험**함(9) / 마음이 **미혹**됨(10) / **믿지 아니함**(19).

### 5. 여호수아의 안식보다 뛰어난 예수님의 안식 (4:8–13)

- 여호수아의 안식: 무엇으로부터의 안식인가? / 장소 = 약속의 땅 가나안 / **언약궤와 안식의 관계**.
- **예수님의 안식**:
  - 장소 = **언약궤(은혜의 보좌)** = 하나님 임재의 상징(출 25:22; 민 7:89; 대상 13:6; 17:16 — 강의안 한 곳에 “민 7:39”는 **오기**, 다른 곳에 7:89).
  - 성막 도해: 뜰 100규빗(50m) × 50규빗(25m), 번제단 → 물두멍 → 성소(금촛대·진설병·금향단) → 휘장 → 지성소(언약궤). 광야 진영 중앙의 성막 그림.
  - **잃어버린 언약궤** → **새 언약궤**: 옛 언약과 새 언약 / 스룹바벨 성전에는 언약궤가 없음(학 2:7, 9; 슥 8:3, 8, 23의 약속).
  - **옛 언약(궤) vs 새 언약(궤)**:

| 옛 언약 (출 19–24; 신 6:1) | 새 언약 (렘 31:31–34) |
|---|---|
| 언약이 **돌판**에 새겨짐 | 언약이 **마음**에 새겨짐 |
| **나무 궤**에 담김 | **사람의 삶**에 담김 |
| 이스라엘 진 중앙에 성소 | **성소 안에 우리**가 있음 |
| 하나님을 만나려면 성소로 나아감 | 어디서나 하나님을 만남 |
| **God with us** | **God in us** |
| 구름기둥이 앞에서 인도 | 성령님이 **안에서** 인도 |
| 제사·의식·율법으로 회복 | 예수님으로 회복 |
| 언약에 따른 저주와 축복 — 아무도 지킬 수 없음 | 긍휼히 여김, 죄를 기억하지 않음 — 모두 주를 앎 |
| 옛 언약의 (대)제사장 | 새 언약의 (대)제사장 |

  - **여호수아의 안식 vs 예수님의 안식**: 특정 장소로 나아가야 함 ↔ 그럴 필요 없음 / 외부에서 주어짐 ↔ 내부에서 주어짐 / 빼앗길 수 있음 ↔ 빼앗을 수 없음 / 일시적 ↔ 영원함.
  - 은혜의 보좌에 나아갈 이유(4:16): **긍휼하심**을 받고 **때를 따라 돕는 은혜**를 받으려고.

### 6. 모든 대제사장보다 뛰어나신 예수님 (4:14–7:28)

- 묘사: **큰 대제사장**(4:14) / 승천하신 이 / 하나님의 아들 / 믿음의 대상 / **연약함을 동정하시는 분**(4:15) / **시험을 받으셨으나 죄는 없으신 분**(4:15) / **멜기세덱의 반차**를 따르는 대제사장(5:6, 10; 6:20; 7:17) / 고난으로 순종을 배워 온전하게 되신 분(5:8–9) / **영원한 구원의 근원**(5:9; 구원의 창시자 2:10).
- **멜기세덱은 누구인가**(창 14:18; 시 110:4): 살렘 왕 = 의의 왕, 평강의 왕(7:1–2) / 지극히 높으신 하나님의 제사장(7:1) / 아브라함에게서 십일조를 받음(7:2) / 부모·족보·시작한 날·생명의 끝이 없음(7:3) / 하나님의 아들을 닮음, 항상 제사장(7:3) / 12지파에 속하지 않음(7:10).
- **아론 반차의 대제사장 vs 멜기세덱 반차의 예수님**:

| 아론 반차 | 멜기세덱 반차 (예수님) |
|---|---|
| 레위 지파 | 12지파에 속하지 않음 |
| 사람에게서 나옴 | 하나님에게서 나옴 |
| 연약함 | 온전함 |
| 이스라엘에게서 십일조 | 아브라함에게서 십일조 |
| 제한된 생명 | 영원한 생명 |
| 많은 제사장이 필요 | 한 분으로 충분 |
| 자기 죄를 위한 제사가 필요 | 필요 없음 |
| 이스라엘을 위한 제사 | 모든 사람을 위한 제사 |
| 날마다 드림 | **단번에** 드림 |

- 레위인·제사장·대제사장의 구분 / 예수님의 온전함 — 온전하게 되신 방법(강의 설명 항목).
- **경고 3 (5:11–6:12) — 타락(배교)하지 말고 끝까지 믿음으로 약속의 기업을 붙잡으라**:
  - 구조: A 권면(5:11–14) / **B 경고(6:1–8)** / A′ 권면(6:9–12).
  - 그리스도 도의 초보(6:1–2).
  - **난해 구절**(강의안 “5:4–8” — 내용상 **6:4–8**의 오기 추정: “한 번 빛을 받고 … 타락한 자들은 다시 새롭게 하여 회개하게 할 수 없나니”) → 이렇게 말하는 이유는 6:9–12(“너희에게는 이보다 더 좋은 것 … 확신하노라”).
  - 약속을 기업으로 받은 자의 예: **아브라함**(6:13–20).

### 7. 옛 언약·장막·제사보다 뛰어나신 예수님 (8:1–10:18)

- 대조 ① 옛 언약과 새 언약 → 위의 표.
- 대조 ② **옛 언약의 대제사장(아론) vs 새 언약의 대제사장(예수님)** — 지성소에 나아갈 때:

| 아론 | 예수님 |
|---|---|
| 몸을 씻어야 함 | 더러움과 악이 없음(7:26) |
| 거룩한 옷을 입어야 함(레 16:4) | 자체로 거룩하심(7:26) |
| 향으로 자신을 가림 | 가릴 필요가 없음 |
| 자기 죄를 위한 제사 필요 | 필요 없음 |
| 백성을 위해 **동물의 피** | 백성을 위해 **자신의 피** |
| 날마다(해마다) 드림 | **단번에** 드리심 |

- 대조 ③ **옛 언약의 장막 vs 새 언약의 장막**:

| 옛 장막 | 새 장막 |
|---|---|
| **모형·그림자·임시**(8:5) | **원형·실체·영원**(8:5) |
| 땅에 있음(8:4) | 하늘에 있음(8:5) |
| 사람이 세움(8:2) | 하나님이 세우심(8:2; 9:11) |
| 금촛대·진설병·금향단·언약궤 | 언약궤 |
| 성소와 지성소를 엄격히 구분, **지성소가 닫힘** | 구분이 없음, **지성소가 열림** |
| 대제사장이 죽음으로 계속 바뀜 | 한 대제사장이 영원히 섬김 |
| 한 제물이 한 사람의 죄만 감당 | 예수님이 모든 사람의 죄를 감당 |
| 계속 드려야 함, 동물의 피(많은 제물) | 단번에, 예수님의 피(예수님으로 충분) |
| 사람을 온전하게 할 수 없음 | 온전하게 할 수 있음 |

- **피·제사의 역할**: 부정한 자를 정결하게 함(9:13) / 첫 언약을 세움(9:18–20) / 일시적임(9:25) / **죄를 없이 하지 못함**(10:4, 11) / **죄를 생각나게 함**(10:3; 강의안 “9:3”은 **오기 추정**).

### 8. 경고 4 (10:19–39) — 다시 죄를 짓지 말라

- **권면(19–25)**: 예수님의 피를 힘입어 성소에 들어갈 수 있게 됨(19) — **새 장막의 휘장 되신 예수님**(20) / 참마음과 온전한 믿음으로 나아가자(22) / 소망을 굳게 잡으라(23) / 서로 돌아보아 사랑과 선행을 격려하라(24) / **모이기를 폐하지 말라**(25).
- **믿음을 버리는 것은**: 다시 속죄하는 제사가 없음(26) / 하나님의 아들을 짓밟는 것(29) / 언약의 피를 부정하게 여기는 것(29) / 은혜의 성령을 욕되게 하는 것(29).
- 대조: 모세의 법을 폐한 자가 받는 벌 ↔ 하나님의 아들에 대한 믿음을 버린 자가 받는 벌.
- **원독자가 이미 겪은 고난(32–34)**: 고난의 큰 싸움 / 비방과 환난으로 **구경거리**가 됨 / **소유를 빼앗김**.

### 9. 믿음의 삶 (11:1–13:25)

- **(1) 믿음의 전당(11장)**: 정의(1) — **바라는 것들의 실상, 보이지 않는 것들의 증거** / 역할(6) — **하나님을 기쁘시게 함** / 믿음의 사람들 — 아벨, 에녹, 노아, 아브라함, 사라, 이삭, 야곱, 요셉, 모세 … / 특징: **‘믿음’ 26번 반복**, 하나님의 약속이 전혀 보이지 않는 상황에서도 끝까지 믿음, “이 세상이 감당하지 못함”(38).
- **(2) 믿음의 경주(12:1–13)**:
  - **구름같이 둘러싼 허다한 증인들**(1) = 11장의 믿음의 선배들.
  - **믿음의 주(2) = 아르케고스**(저자, 창시자; 2:10 구원의 창시자).
  - **징계(5–11)**:

| 육신의 아버지의 징계 | 하나님 아버지의 징계 |
|---|---|
| 잠시 | 사랑하시기 때문에 |
| 자기 뜻대로 | 아들이기 때문에 |
| | 우리의 유익을 위해 |
| | 하나님의 거룩하심에 참여하게 하려고 |

  - 결론(12–13): 피곤한 손과 연약한 무릎을 일으켜 세우라 / 곧은 길을 만들라 / 저는 다리로 고침을 받게 하라.
- **(3) 경고 5 (12:14–29) — 하나님을 거역하지 말라**: 화평함과 거룩함을 따르라(14) / 은혜에 이르지 못하는 자가 없도록 서로 돌아보라(15) / **쓴 뿌리**를 제거하라(15) / 음행하지 말라(16) / 망령되이 행하지 말라(16 — 에서) / **대조: 시내산 vs 시온산**(18–24).
- **(4) 하나님이 기뻐하시는 제사(13:1–17)**:
  - 여러 권면: 형제 사랑을 계속하라(1) / 손님 대접을 잊지 말라(2) / 갇히고 학대받는 자를 생각하라(3) / 결혼을 귀히 여기라(4) / 돈을 사랑하지 말라(5) / 지도자들의 믿음을 본받으라(7) / 다른 교훈에 끌리지 말라(9) / **찬송의 제사**(15) / 선을 행하라(16) / 나눠 주기를 잊지 말라(16).
  - **새 장막에서의 새 제사** = **찬송의 제사(15) + 선을 행함(16) + 서로 나눠 줌(16)**.

## 주석용 핵심 메모
