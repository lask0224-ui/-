## 주제 · 제목

- 주제 문구: **“땅끝까지 이르러 내 증인이 되리라”** [TBS4]
- 강의 반복 구호: **“성령님과 함께하는 사도행전”** — 이 책의 주인공은 사도가 아니라 성령. 사도행전 = **‘성령의 행전’, ‘복음의 행전’** [예습1-1]
- 강의 목적: “사도행전의 **인상을 바꾸는 것**” [예습1-1]

## 읽는 법 (강사의 해석 원리) [예습1-1]

- 표면에 보이는 것 ≠ 저자가 의도한 것. 문학에는 **‘의도’와 ‘구조’**가 있다.
- **원독자의 자리**에서 읽기: ‘땅끝’은 오늘날의 지구본이 아니라 지중해 중심의 알려진 세계(헤로도토스 예화).
- **구성의 법칙**으로 읽기: 시간이 뒤로 돌아가는 서술(스데반 순교 → 흩어진 자들이 안디옥에서 최초 이방인 교회)도 구성상의 의도가 있다.
- 앞은 베드로, 뒤는 바울 — **가운데에 바나바**가 있다(바울을 받아 준 사람).
- ‘역사서’ = 사건 + **해석**. 사건은 하나여도 기억·해석은 다르다. 사도행전에서 캐야 할 것은 “저자가 무엇을 말하고 싶어 하는가”.
- 사도행전인데 사도는 **베드로와 바울만** 나온다. 두 사람이 같은 상황(이방인)을 다르게 통과하는 것 자체가 해석이다.

## BRI (Basic Required Information)

### 저자: 누가 [TBS4][예습1-1]

- 눅 1:1–3 “**나도**” → 직접 목격자가 아니라 전해 받은 자. ‘처음부터’(아르케) → 구약에도 밝았으리라 추정.
- 행 1:19 “**그들의 말로는** 아겔다마” → 히브리/아람어가 모국어가 아님 = **이방인**.
- 유대 풍습을 설명해 줌, 헬라어 표현(디오스구로, 트레이스 타베르네)을 번역 없이 씀, 로마 황제 기준 연대.
- 행 2:4 성령 강림을 경험한 사도가 아님.
- **“우리” 단락**: 행 16:10(드로아→빌립보), 20:6(5), 21:17, 27:1, 28:1, 28:16.
  - 16장 빌립보까지 동행 → 17:1 ‘그들이’ = 빌립보에 남음 → 20:5 다시 합류 → 예루살렘, 가이사랴, 로마까지 동행. [예습1-1]
- 동행자 좁히기: 옥중서신(골로새서·빌레몬서) 명단 → 골 4:10–11 아리스다고·마가·유스도는 할례파(유대인) 제외 → 행 20:4–5 아리스다고·디모데·두기고는 ‘그들’ → 에바브라는 2·3차 여행 비동행 → 데마는 딤후 4:10 떠남 → **골 4:14 “사랑받는 의사 누가”**.
- 의학적 흔적: 눅 6:6 ‘**오른손** 마른’(막 3:1 ‘손 마른’), 눅 4:38 ‘**중한** 열병’(마 8:14, 막 1:30 ‘열병’), 눅 14:2 고창병/수종병 구분, 행 3:7 ‘발과 **발목**’, 눅 18:25 바늘(의료용; 마 19:24와 비교), 혈루병 여인 “아무에게도 고침받지 못함”(막: 많은 의사에게 괴로움) — 동료 의사 체면(히포크라테스 윤리).
- 외적 증거: 저스틴, 무라토리 정경, 반마르키온 서문, 이레네우스, 유세비우스, 터툴리안 — **안디옥 출신 의사 누가**. [예습1-1]
- ⚑ 독특한 견해: 가톨릭 전승상 **디도가 누가의 동생**. 사도행전에 누가와 디도가 끝내 언급되지 않는 것 = 누가가 자기 가족을 감추는 겸손. [예습1-1]
- 누가의 글쓰기: 자기가 있던 때/없던 때를 엄격히 구분, 상상으로 채우지 않음. 목격자를 **인터뷰**한 사람 같다(향유 옥합 ‘발 뒤에서’, ‘돌 던질 만큼’, 행 27장 연안 항해술). [예습1-1]

### 수신자: 데오빌로

- 이름 뜻: 데오(하나님) + 필로스(사랑하는 친구) = ‘하나님을 사랑하는 자’. [TBS4]
- 두 견해 [TBS4]:
  - **개인**: “각하” 호칭 — 눅 1:3 데오빌로, 행 23:26 벨릭스, 행 26:25 베스도(같은 호칭).
  - **공동체**: 1세기에 흔한 이름 → ‘하나님을 사랑하는 사람들’.
- 이방인 수신자: 이방인에게 익숙한 단어(랍비 대신 선생), 로마 달력, 유대 지역 설명(눅 8:26, 19:29, 24:13).
- 호칭 변화: 누가복음 “데오빌로 **각하**” → 사도행전 “데오빌로**여**” = 누가가 데오빌로의 믿음을 한 단계 끌어올림. [예습1-1]

### 기록 연대

- [TBS4]: 행 28:30–31 두 해(AD 60–62) + AD 64 네로 박해 언급 없음 → **AD 62–64년 사이**.
- [예습1-1]: **63년경**. 근거: 사도행전 안에서 로마 당국은 한결같이 “무죄” — 64년 네로 박해, 66–70년 유대 반란의 분위기가 전혀 없음.
- → 두 자료는 모순되지 않음(63년은 62–64 범위 안).

### 역사적 배경 [TBS4][예습1-1]

- **로마**: 아우구스투스(BC 27–AD 14) 이후 약 200년 팍스 로마나, 도로 정비(높은 곳은 깎고 낮은 곳은 메우고 — 군대·교역·소식 전달), 강력한 중앙정부, 로마 시민권, 황제 속주/원로원 속주.
- **헬라 철학**: 플라톤 이원론(보이는 것=악, 보이지 않는 것=선), 행 17:18 에피쿠로스·스토아.
- **그레코-로망**: 역사가 짧은 로마가 헬라 문명을 깊이 수용. 구약과 마태복음 사이 400여 년 동안 세상이 네 번 이상 뒤집힘.
- **‘하나님을 경외하는 이방인’**의 등장 — 사도행전의 큰 이슈. [예습1-1]
- **회당**: BC 586 성전 멸망 후 바벨론 포로기에 기원. 성전에 대한 갈망, 예배·교육(율법)·순례자 숙소. 성인 남자 10명 이상이면 성립. 예배 순서: 쉐마 낭독(신 6:4–9; 11:13–21; 민 15:37–41) → 기도 → 율법과 선지서 낭독 → 설교 → 축도. 구성원: 유대인/이방인/유대교에 입교한 경건한 자(행 13:43). **회당 = 복음 전도의 전초기지** (갈 4:4 ‘때가 차매’). [TBS4]

## 누가복음 ↔ 사도행전 비교

- 같은 수신자, 이어지는 내용(탄생~승천 / 승천~땅끝). [예습1-1]
- **지리** [TBS4]: 눅 = 갈릴리 → 유대·사마리아 → **예루살렘** / 행 = 예루살렘 → 유대·사마리아 → **땅끝**.
- **성령 강림** [TBS4]: 예수님의 성령 세례(눅 3:21–22) ↔ 제자들의 성령 세례(행 2:1–4). 구약 예언 성취: 눅 4:18–19 ↔ 행 2:17–21. 둘 다 **기도할 때** 성령이 임함. [예습1-1]
- **고발당함 — 공회 유죄 후 세 번 무죄** [TBS4]:

| 예수님 (눅) | 바울 (행) |
|---|---|
| 공회(22:66) → 유죄(22:71) | 공회(22:30) → 유죄(23:2) |
| 빌라도(23:1) → 무죄(23:4) | 벨릭스(24:3) → 무죄(24:24–27) |
| 헤롯(23:8) → 무죄(23:15) | 베스도(25:6) → 무죄(25:18–29) |
| 빌라도(23:13) → 무죄(23:14) | 헤롯(아그립바)(25:23) → 무죄(26:31) |

- 평행 사건 [예습1-1]: 첫 설교 거절 / 치유(앉은뱅이) / 죽은 자 살림(나인성 과부 아들·야이로의 딸 ↔ 다비다·유두고) / 전도행(세 번 ↔ 1·2·3차 여행) / 결단하고 예루살렘으로 / 성전 사건 / 눅 24:44,47 “이루어져야” ↔ 행 28장 “이루어졌다”.
- 백부장 대조 [예습1-1]: 눅 7장 백부장은 “오지 마시고 말씀만” — 유대인을 배려해 알아서 피해 준 믿음. 행 10장은 하나님이 베드로를 고넬료 집에 **들이미심** → 돌파.
- 눅 6:46 이후 사람들이 ‘유대인/이방인’이 아니라 **‘듣고 행하는 자/행하지 않는 자’**로 나뉨. 사도행전 끝까지 “듣고 믿었더라/믿지 않았더라” 반복. [예습1-1]

## 구조 [TBS4]

1. **지리적**: 1:1–8:1a 예루살렘 / 8:1b–12:25 유대·사마리아 / 13:1–28장 땅끝까지
2. **인물별**: 1–12장 베드로 / 13–28장 바울
3. **요약적 진술을 통한 구조** (6단락):
   - 1:1–6:7 예루살렘 교회의 성장
   - 6:8–9:31 팔레스타인 곳곳의 확장 (7장 스데반의 죽음)
   - 9:32–12:24 안디옥 교회의 확장 (12장 야고보의 죽음)
   - 12:25–16:5 남갈라디아와 소아시아 중앙으로 확장 (13–14장 핍박)
   - 16:6–19:20 마게도냐·아가야로 확장 (16–18장 핍박)
   - 19:21–28:31 로마로 확장 (에베소·예루살렘·로마에서 핍박)
4. **성령 중심 방열 구조**: 여러 사건이 하나의 중심 주제에 연결 — 행 2장 성령 강림 → 교회 태동 → 복음 확장.
5. **수미상관(inclusion)**: A 1:1–3 예수 그리스도 & 하나님 나라 / B 1:4–28:29 성령 강림·교회 태동·확장 / A′ 28:30–31 하나님 나라 & 예수 그리스도. — [예습1-1]도 “책의 양 끝을 하나님 나라의 일이 떠받친다”고 설명.

## 본문 요점 [TBS4]

- **1:1–5** “먼저 쓴 글” = 누가복음. 신·세상·역사·잃어버린 자·재물에 대한 관점.
- **1:6–11** 승천, “오직 성령이 너희에게 임하시면”. **1:12–26** 맛디아 → 열두 사도의 완성.
- **2:1–4 성령 강림**: 오순절 / 불의 혀처럼 갈라지는 것 / 다른 언어(바대·메대·엘람·메소보다미아·유대·갑바도기아·본도·아시아·브루기아·밤빌리아·애굽·리비아·로마·그레데·아라비아).
- **오순절 = 칠칠절**: 3대 절기(유월절·칠칠절·초막절) 중 하나. 유월절 후 50일째, 안식일 기준 7주 다음 날. 출 19:1 출애굽 3개월 뒤 시내 광야 도착 → 출 19:16 셋째 날 하나님 임재 = **이스라엘(하나님 나라)** ↔ 행 2:1–4 성령 강림 = **교회 태동(하나님 나라)**.
- **창 11장 ↔ 행 2장 대조**:

## 수신자 데오빌로 보강 [행1 p19–23]

- 1:4 “배운 바가 있는 사람, 확실함이 필요한 사람”. 이름 = 데오스 + **필레오**(사랑하다, 친구가 되다). “확실해진 것 한 가지 — **그는 이방인이었다**.”
- 개인설: ‘각하’는 로마 관리에게 쓰던 존칭 → **예수를 영접한 로마 관료**.
- 공동체설: 흔한 이름을 써서 기독교 공동체에 보냄. 이때 “데오스”가 일반적인 신인지 하나님인지가 문제로 남음.
- 절충: 로마 관리로서 하나님을 섬기며 어떤 기독교 모임을 이끌던 사람 → 1차로 그에게 보내되 그를 통해 많은 사람이 읽도록 함.
- **누가복음 안의 데오빌로**:
  1. 기독교를 알고 있음.
  2. 확신이 필요함.
  3. 막 개종한 이방인이라 신앙에 어려움이 있음.
  4. “이방인인 우리가 유대인의 하나님의 구원에 초대되었는가” — 제자로서 확신이 필요함.
- **사도행전 안의 데오빌로 — 7가지 질문**:
  1. 이방인도 하나님 나라에 초대되었는가?
  2. 기독교는 이방인에게 어떻게 확산되었는가?
  3. 유대교와 기독교는 무엇이 다른가?

## 기록 당시 기독교의 상황 [행1 p67–72]

- **세력의 확대**:
  - 19:10 아시아의 유대인과 헬라인이 다 말씀을 들음.
  - 19:20 흥왕하여 세력을 얻음.
  - 24:5 “이 사람은 **염병**이라, 천하에 퍼진 유대인을 소요하게 하는”.
  - 24:22 벨릭스가 이 도를 자세히 앎.
  - 26:26 “이 일은 한쪽 구석에서 행한 것이 아니니이다”.
- **아직 로마법의 보호를 받던 시기**: 18:12–17 갈리오 / 23:10 천부장이 바울을 보호함 / 26:30–32 아그립바와 총독의 대화. 64년 이후에는 박해가 시작됨.
- **이방 초신자들의 질문과 서신의 대응**:
  - 갈라디아: 율법·할례·절기를 지키지 않아도 되는가?
  - 데살로니가: 재림과 그것을 기다리는 삶의 태도.
  - 고린도전서: 이원론적 세계관으로 복음을 이해하려 함 → “아니다, 몸으로 하나님께 영광을 돌려라”.
  - 고린도후서: 바울의 사도권.
- **원독자가 확신하지 못하게 만드는 것들**: 예수는 십자가에 못 박힌 범죄자 / 바울은 교회를 핍박하던 자, 예수의 제자가 아님 / 기독교는 무죄한가 / 교회가 말하는 하나님 나라는 로마에 대적하는가 / 교회는 어떻게 시작되어 우리에게 복음이 전해졌는가.
- **하나님의 백성이 되는 방법 — 갈라디아서의 쟁점**: ① 할례(갈 5:2–3; 행 15:1–2), ② 음식법 **카샤롯**(갈 2:11–16), ③ 유대 달력과 절기(갈 4:10).
- 구전 토라: “이방인들에게 율법을 가르쳐 주지 말아라” [행1 p64] → **“가까이하기엔 너무 먼” 하나님의 백성**. 눅 7장과 행 10장의 백부장, 13:43 입교한 경건한 사람들, 18:10 “이 성중에 내 백성이 많음이라”.

## 역사적 배경 보강 — 제국의 역사와 하나님 나라 [심화1][행1][배경]

- **“제국의 역사와 하나님 나라”** [심화1 p3–5]:
  - 창 10:10–11 “나라” = **맘라카**(왕국, 지배, 영토) ↔ 출 19:6 “**제사장 나라**”.
  - **언약의 역사(신 28–30)**: 불순종하면 땅에서 뽑혀 만민 중에 흩어짐(28:58, 63–68; cf. 창 11:9) → 돌이키면 흩어진 중에서 모으시고 **마음에 할례**(30:2–11).
  - 하나님 나라의 역사: 솔로몬 즉위 BC 971 → 성전 완공 966 → 솔로몬 사망 931 → 분열 → 북 722 / 남 586.
  - **예루살렘 멸망의 의미**: 하박국의 질문(합 1:1–4) → 하나님의 응답(1:5–11) → 다시 질문(2:1) → 2:4–12 → **2:13–14 “민족들이 헛된 일로 피곤하게 되는 것 … 여호와의 영광을 인정하는 것이 세상에 가득함”** → 사 62:6–11.
  - 멸망 이후의 변화 [행1 p27]: 제의 중심에서 **율법·말씀 중심**으로, 흩어진 유대인 공동체 **회당**의 시작과 제국의 흥망에 따른 확산, **하나님을 경외하는 지식**이 퍼지기 시작함.
- **제국들의 공통점**(“이들의 공통점은?”) [행1 p25]: 바벨론 – 페르시아 – 알렉산더와 헬라 – 톨레미 – 셀류키드 – 로마 → **경계를 허무는 정복과 통합**(p28, p37).
- **[배경] 산문 요지**:
  - **헤로도토스**(역사의 아버지, 『역사』): BC 5세기(강의안 표기 “BC 4세기”) 세계 인식의 대략을 알려 줌. 그의 여행은 **다리오(BC 521–486)**가 넓힌 제국 안이라서 가능했음(아람어, 같은 법체계, 환전, 안전).
    - [예습1-1]의 ‘땅끝’ 설명이 이 자료와 연결됨.
  - 페르시아의 한계 돌파 → 펠로폰네소스 전쟁(BC 431–404, 델로스 동맹 vs 펠로폰네소스 동맹) → 빌립 2세의 마게도냐 → **알렉산더(BC 336–323)**:
    - 알렉산드리아라는 이름의 도시를 70개 세움.
    - 헬라화: 간다라 미술, 동방 신비종교 유입.
    - **코이네 헬라어**(세속·일반) vs 아티카 헬라어(학자·철학자).
  - 후계자: 셀류키드(시리아·메소포타미아), 톨레미(이집트·팔레스타인), 리시마쿠스(드레이스·비두니아), 카산더(마게도냐).
    - **톨레미 = 알렉산드리아 도서관, 70인역**.
    - **셀류키드 = 행정도시 시리아 안디옥, 유대의 헬라화, 교육도시 다소**.
    - 헬라 문화의 중심이 그리스에서 이 두 왕조로 이동함.
  - 헬라 세계의 몰락:
    - BC 192 안티오쿠스 3세의 그리스 침공이 로마에 패함.
    - BC 188 로마가 주도권을 잡음.
    - BC 171 로마–마게도냐 전쟁 → 고린도 전멸.
    - BC 146 그리스 반도가 로마 보호령이 됨.
    - BC 88 본도 반란.
    - BC 65 폼페이우스의 정벌.
    - 빌립보·아덴·데살로니가·고린도는 파괴되었다가 아우구스투스 때 속주로 재건됨 → **사도행전에서 도시 지도자들이 로마를 두려워하는 이유**.
  - 로마:
    - 1차 삼두정치: 폼페이우스·크라수스·시이저. 크라수스 전사(강의안 “AD 55” → BC 53년의 **오기 추정**. 정확한 연도는 보충).
    - 시이저 종신 독재관 → BC 44 암살.
    - 2차 삼두정치(BC 43): 옥타비안·안토니우스·레피두스.
    - **빌립보 전투**(강의안 “AD 42” → **BC 42**의 오기)에서 부루투스와 카시우스가 자결.
    - BC 31 **악티움 해전**(아그립바) → BC 27 ‘아우구스투스’.
  - **악티움 해전 때 빌립보의 도움** → 퇴역 군인 정착, **콜로니 특권** → 시민권에 대한 자부심(빌 4:15, 강의안 인용).
  - **황제 연표**:
    - 아우구스투스 BC 27–AD 14.
    - 티베리우스 14–37(55세 즉위, 복음서의 ‘가이사 디베료’).
    - 칼리굴라 37–41(스스로 신이라 주장, 예루살렘 성전에 동상을 세우려다 암살됨).
    - 클라우디우스 41–54(49년 ‘클레스투스’ 소요로 유대인 추방 = 행 18:2, 아그리피나에게 독살됨).
    - 네로 54–68(62년 세네카 사망과 부르스 은퇴 후 변함, 64년 대화재와 그리스도인 처형, 전승상 베드로·바울 순교, 66년 유대 반란, 자살).
    - 68–69 갈바·오토·비텔리우스.
    - 베스파시안 69–79(성전세를 로마 제우스 신전에 바치게 함).
    - 티투스 79–81.
    - 도미티안 81–96.
- **제국의 통치 [배경 p7–10]**:
  - ① **원로원 속주**(아시아·마게도냐 등 안정된 곳): 총독(프로콘술, 행 13:7; 18:12; 19:38), 임기 1년, 레기온이 주둔하지 않음. 갈리오 = 델피 비문에 따르면 **AD 52–53** 아가야 총독(강의안 “행 18:11” → 18:12).
  - ② **제국 속주**(최근 편입, 국경 지대, 군 주둔): 황제가 임명함. 시리아는 원로원 계급이, **이집트와 유대는 기사 계급**이 맡음. 빌라도 때는 *praefectus*, 벨릭스·베스도 때는 총독.
    - 세금: 직접세(마 22:17), 인두세, 간접세(통행세·판매세). 벨릭스는 뇌물을 기대함(24:26).
  - ③ **가신국**: 헤롯 대왕, 헤롯 아그립바 1세. AD 6년부터 유대는 직할이 됨.
  - ④ **도시와 식민지**: 자치 도시(데살로니가·에베소의 ‘서기장’, 17:6–9; 19:35) / **콜로니 = 빌립보, 비시디아 안디옥**(퇴역 군인, 면세·자치, 더 로마화됨).
  - **군대**:
    - 레기온 28개(아우구스투스 사망 무렵). 1레기온 = 보병 5,000명과 기병 수백 명, 같은 수의 외인부대. 핵심 전력은 백부장 60명. 시리아에 4개, 이집트에 2개 주둔.
    - 유대에는 레기온이 없음 → **복음서와 행전의 백부장은 외인부대 백부장**.
    - 친위대(아우구스투스 때 로마에 1,500명, 인근에 3,000명) = 빌 1:13 **‘시위대’**.
    - 로마 도로 80,476km.
  - **경찰·법**:
    - 성전 수비대가 예수·사도를 체포함.
    - 치안관(총독)은 재량권이 커서 **심리를 거부**할 수 있음(18:12–17).
    - 지방 법원에는 처형권이 없음 → “그렇다면 스데반과 야고보의 죽음은?”
    - 신약의 재판에는 **공적인 검사가 없고 원고가 주도함**.
    - 형벌: 벌금 / 자유 박탈(노예·검투사·광산) / 채찍(*flagellum*) / 십자가형(주로 노예) / 화형 / 참수.
    - 유대: **사십에 하나 감한 매**(신 25:2–4; 고후 11:24). 성전 비문은 이방인이 들어오면 로마 시민이라도 즉시 돌로 칠 수 있다고 경고함.
- **이동성과 선교** [행1 p38–49; 배경 p11–13]:
  - 신약의 여행: 마리아는 1년 사이 세 번 여행함(눅 1:39–56; 2:1–5; 2:22–39). 빌립(사마리아–가사–가이사랴). 베드로(사마리아–룻다–욥바–가이사랴–안디옥(갈 2:11)–고린도(고전 1:12)).
  - **로마 도로 *viam munire***(‘도로’ + ‘건설’. *munire*에는 ‘방벽을 쌓다’라는 뜻이 있음 → 도로를 세우면 방벽이 됨):
    - 차도 약 4m + 양쪽 인도 3m = 폭 10m 이상, 깊이 1m 이상의 4층 구조, 아치형 노면과 배수로.
    - 길가에 나무를 심지 않음(뿌리 침식 방지, 시야 확보). 인도가 따로 있음(군대 이동 보장).
    - 직선을 선호함(아피아 가도 43km 직선). 37m를 깎아 낸 곳이 있고, AD 7년 플라미니아 가도에 37m 터널.
    - **밀리아리움**(1로마마일 ≈ 1.5km마다 설치하는 이정표).
    - 간선 약 80,000km + 지선 약 70,000km. 로마가 비용을 전액 부담함. 패자와 승자를 공동운명체로 만듦.
    - 대비 예화: 만리장성(차단) vs 가도(촉진), 조선의 신작로 억제 정책.
  - **에그나티아 가도**(빌립보 경유, BC 146 [심화2] / BC 145경 [배경] 착공): 비잔티움 ~ 디라키움 → 아드리아해를 건너 **아피아 가도**(BC 312 착공, 현존하는 가장 오래된 로마 도로, 행 28:15–16)로 로마까지 이어짐. **바울이 2차 전도여행에 이용함**.
  - 도로 위의 삶: 군대 순찰(강도 감소), 표준 화폐, 표준 헬라어·라틴어. 길에서 만나는 사람: 농민·수공업자·관리·순회 철학자·치유 순례자·신전 참배객과 경기 관람객·상인·노예.
    - **만시오네스**(숙박, 하룻길 40–56km) / **무타티오네스**(역참, 16km마다).
    - 가장 안전한 여행 방법은 **지인의 환대**(몬; 요이; 요삼).
  - **항해**:
    - 연안 항해술(나침반 이전, 낮에는 해·밤에는 별). 로마–알렉산드리아 **곡물 수송선**.
    - 계절풍: **5–10월** 순한 북풍 → 로마에서 알렉산드리아까지 10–20일, 돌아올 때는 역풍이라 2개월. 10–5월에도 군대와 긴급 화물은 운항함.
    - 행 27:5–7 로마행 선박과 계절 / **27:9 “금식하는 절기가 이미 지났으므로”(9–10월경) 항해가 위태함**.
    - 연안(닫힌 바다)용 화물선 vs 난바다(열린 바다)용 소형 화물선·군용선. BC 51 키케로는 아테네에서 에베소까지 군함으로 22일 걸림(매일 정박).
    - 배에 선실이나 음식 제공이 없음 → 갑판에서 취사하고 잠. 위험할 때는 승객도 작업에 동원됨.
  - **통신**: 표준화된 편지 형식, **대서인**(롬 16:22 더디오; 벧전 5:12 실루아노). 관리는 역참 마부를, 부자는 노예를, 그 밖의 사람은 친구나 방향이 맞는 사람을 이용함. → “**바울의 동역자로 편지를 전달했던 사람은?**”(질문)
- **로마의 사회** [행1 p50–54; 배경 p14–16]:
  - **시민권**:
    - 취득: 시민 부모에게서 출생(출생증명서), 시민권 도시의 주민(빌립보), 특별한 봉사, 노예 해방, 외인부대 25년 복무 후 제대, 돈으로 삼(22:28).
    - 특권: 투표권(로마에 있어야 행사), 채찍·십자가형 면제(16:22; 22:25), **황제에게 상소할 권리**(25:10–12).
  - 이주 사례: **아굴라**(본도 출신 → 로마 → 클라우디우스 칙령으로 추방 → 고린도 → 에베소 → 다시 로마, 롬 16:3).
  - **계급**: 원로원 / 기사(이집트·유대 총독을 배출함) / 평민 / 노예(인구의 약 1/4 → 빌레몬 자료 참조) / 자유민(클라우디우스·네로가 관료로 기용, **벨릭스는 황제 집의 자유민 출신**).
  - 여성: 여아 유기(BC 1세기 파피루스 편지 “딸이라면 버리고…”), 14세쯤 결혼. **에베소 아데미 신전에서는 여제사장의 역할이 컸음**. 폼페이의 유마키아.
  - **후견인과 가신**: 집을 모임 장소로 제공함(몬 1:2; 롬 16:3–5, 23), 전도자를 환대함(몬 1:22; 요삼 1:5–8). 뵈뵈 “보호자”(롬 16:2) = 후견인.
  - 언어: 공식어는 라틴어, 공통어는 헬라어 → 바울은 헬라어로 로마에 편지함.
  - 오락: **이스트미아 경기**(고린도에서 2년마다) — 바울은 벗고 하는 경기와 신에게 바치는 연극에는 가지 않았겠지만 편지에서는 그 이미지를 활용함(고전 9:24–27; 딤후 2:5). 로마 대중은 검투와 마차 경기, 공중목욕탕을 즐김.
- **로마의 종교와 철학** [행1 p55–58; 배경 p17–19]:
  - 전통 종교는 다신론이고, 제의의 기능은 신에게 잘 보이는 것. **윤리적 관습이 없음**. 삶에 영향을 주는 것은 종교가 아니라 **철학**. **타 종교에 배타적이지 않음** → 유일신 신앙은 거만하고 파괴적으로 보임.
  - 종류:
    1. 가정 종교(라레스, 페나테스).
    2. **치유 종교**(아스클레피우스: 고린도·아덴·버가모) → 초기 교회 치유 사역의 맥락.
    3. **비밀(밀의) 종교**(*mysteria*, 엡 3:3; “내가 … 자족하는 비밀을 알았다”).
    4. 운명·점성술·마술(에베소, 행 19:19) → “정사와 권세의 무장을 해제하심”이 해방의 복음이 됨.
    5. **황제 숭배**(BC 9년 비석: 아우구스투스의 생일 = 복음의 시작). AD 111년 플리니가 트라야누스에게 보낸 보고(황제상에 향과 포도주를 바치고 그리스도를 욕하게 함).
  - **철학**:
    - **견유학파**(*kunikos* = 개 같은. 디오게네스, “두려워 말라, 바라지 말라, 소유하지 말라”) — 순회 교사들이 바울 일행과 비교됨.
    - 스토아와 에피쿠로스는 아래 표 참조.
    - 도덕 포기론자.

| | **스토아** (행 17:18) | **에피쿠로스** (행 17:18) |
|---|---|---|
| 기원 | 제논, BC 304 아덴 ‘스토아 포이킬레’ | 에피쿠로스(BC 341–270) |
| 신 | **범신론**. 우주 속 규칙 = **로고스** | 신은 존재하지만 인간사에 무관심 → ‘무신론자’로 불림 |
| 창조·인간 | 인간 안에 선한 신성이 깃듦. 동시에 연약함과 악의 잠재력 | 창조를 부인함. 분자(원자)의 조합으로 우연히 생겨남 |
| 삶 | 절제로 자기 탐닉에 맞서 우주와 조화 추구, 이성 강조, 검소, 향락 배제. 자살 = 최고의 자유 | ‘쾌락주의’ — 쾌락은 육욕이 아니라 **내면의 평정**(고통 회피. 예: 술과 숙취) |
| 내세 | 사후 심판과 내세를 부정. 종말에 세상의 영혼에 흡수됨 | 죽으면 끝. 이후에는 아무것도 없음 |

- **로마인이 본 유대인과 그리스도인** [행1 p60–62; 배경 p20–22]:
  - 공통점은 배타적 유일신 신앙.
  - 유대교는 고대 종교로 인정받아 후원과 특권을 받음(헤롯과 아우구스투스의 우정 → 군 면제, 안식일 허용, 성전 제사 = 황제에 대한 충성의 증거).
  - 기독교는 처음에 **유대교의 한 분파**로 인식됨 → **64년 네로 박해 이후 분명히 구분됨**.
  - 1세기 유대인 인구는 300만–800만으로 추정되고, 팔레스타인 밖이 더 많음.
  - 이방인의 반응:
    - 존경 → 개종자(할례 등 의식법을 짐) / **하나님을 경외하는 자**(회당에 참석하되 할례는 받지 않음, 10:2; 13:16; 17:4).
    - 멸시 → 신상이 없는 신, 안식일·돼지고기 금지, 폐쇄적 공동체.
  - 디아스포라의 형성: 앗수르·바벨론의 강제 이주, 페르시아에서 돌아오지 않은 사람들, 알렉산더와 셀류키드를 따라간 사람들(2:9–10). 상업·금융·교육에 영향력이 컸고, 70년 티투스 이전에는 유대인 노예 비율이 낮았음.
  - **언어**:
    - 히브리어 → 아람어(바벨론·페르시아의 공용어. 예수님과 원청중의 대화 — 달리다굼(막 5:41, 강의안 “5:14”는 오기), 엘리 엘리 라마 사박다니, 아바) → 헬라어.
    - 셀류키드의 헬라화(예루살렘의 짐나지움). 강의안의 “안티오쿠스 에피파네스 3세”는 **4세**의 오기.
    - 반동으로 유대 학교가 세워짐: **베이트 하세페르**(책의 집, 5년, 3세부터, 12세 성인식에서 토라 낭독) → **베이트 하미드라쉬**(연구의 집). 예수님도 다니셨을 것.
    - ⇒ **히브리어는 사라지지 않았음**(행 22:2; 26:14 예수님이 바울에게 **히브리 말로**). 베드로 같은 제자들도 적어도 두 언어를 구사함 → “일자무식이라는 누명” [배경 p22].

## 제국의 완성 vs 하나님 나라 [심화1 p12–13]

| | 팍스 로마나의 완성자: **아구스도** | 하나님 나라의 완성자: **예수** |
|---|---|---|
| 등장 | 공화정의 오랜 내전을 끝내고 제정을 엶 — 제국의 외적 완성 | 구약의 율법과 예언, 하나님 나라의 완성 |
| 방식 | 강력한 군대, 법과 제도, 칭호(존엄한 자, 세상의 구원자)를 통한 **위로부터의 평화** | 십자가의 희생, 섬김과 사랑, 낮은 곳으로 임하심을 통한 **아래로부터의 평화** |
| 인프라 | 자신과 제국의 영광을 위해 육지와 바다의 ‘길’을 닦고 치안을 확립함 | 제자들이 로마가 닦은 그 ‘길’을 **복음의 통로**로 씀 |
| 결과 | 영원할 것 같던 로마와 아구스도의 평화는 사라짐 | 예수로 시작된 하나님 나라는 제국의 경계를 넘어 열방으로 확장됨 |

- 로마의 평화는 **양날의 검**: 군대·경찰의 치안과 법·제도 통합 vs 어떤 소요도 용납하지 않음. 헬라는 **문화**를, 로마는 **제도와 법**을 통합함. **안전하고 높은 이동성**이 1세기 로마의 특징.
- 지도 [심화1 p11]: 아그립바 장군(BC 63–12)이 모은 지리 정보를 바탕으로 한 ***Orbis Terrarum***(아우구스투스가 공공건물에 새김)을 20세기에 에르윈 라이스가 재구성한 지도 = “고대 로마인의 세계”.
  - [심화1 p6–9] 지도: 메소포타미아(아브라함의 고향), 페르시아 제국, 알렉산더 제국, 헬라 후계자들(→ 로마제국 화살표).

## 본문 보강 1–8장 [심화1 p16–26]

- **1:1–5 서론**: 행하시며 가르치시기를 **시작하심**부터 승천하신 날까지 / 1:4–5 하나님 나라의 일 — 예루살렘을 떠나지 말고 아버지의 약속을 기다리라, 성령으로 세례를 받으리라.
- **1:6–11**: 제자들의 질문 “이스라엘 나라를 회복하심이 이때니이까?” ↔ 1:8(강의안 “1:7”) 증인 ↔ 28:20 “이스라엘의 소망”.
- **1:12–26 사도**: 1:21–22 사도의 조건 / 1:23–25 요셉(바사바, 유스도) vs 맛디아 / 1:26 맛디아가 열한 사도의 수에 들어감.
- **2:1–12 오순절**:
  - 급하고 강한 바람 같은 소리, 불의 혀처럼 갈라지는 것 ↔ **시 104:4 “바람을 자기 사신으로 삼으시고 불꽃으로 자기 사역자를 삼으시며”**.

- 2:1 **오순절**(출 23:15; 34:22 — 칠칠절/맥추절).
- 2:2 급하고 강한 **바람 같은** 소리 / 2:3 **불의 혀처럼** 갈라지는 것들(시 104:4 “바람을 사신으로, 불꽃을 사역자로”) — “같이”라는 비유적 표현을 강조함.
- 2:5 경건한 유대인들 — 천하 각국에서 와서 예루살렘에 머묾, 자기 방언으로 듣게 됨. 수사 의문문 “다 갈릴리 사람이 아니냐? … 어찜이냐?”
- 2:11 “우리의 각 언어로 **하나님의 큰일**을 듣는도다” → 그 큰일은 무엇일까?(1:3과 연결 — 하나님 나라의 일).
- **두 종류의 사람**: “하나님의 큰일을 듣는도다” vs “새 술에 취하였다” → 2:37 “형제들아 우리가 어찌할꼬”.
- **새 언약의 성취, 성령 세례의 범위와 약속**:
  - 의미: 요엘을 통해 말씀하신 예언의 성취(16절) / “이 약속은”(39절).
  - 시기: **말세에**(2:17) = 예수 그리스도의 **초림과 재림 사이**의 시간.
  - 범위의 확장:
    - 모든 육체(17절), 누구든지 주의 이름을 부르는 자(21절)
    - **너희**(39절) — 개인
    - **너희 자녀** — 세대
    - **모든 먼 데 있는 사람** — 지역
    - **하나님이 얼마든지 부르시는 자** — 시간
  - 결과: “이 패역한 세대에서 구원을 받으라” → **3,000명**.
  - (강의안 “말세에 (1:17)”은 **2:17** 오기.)
- **《카이아즘》 베드로의 설교 2:17–40**:
  - A 2:17–21 내 영을 모든 육체에 — 누구든지 주의 이름을 부르는 자는 구원을 받으리라
  - B 2:22–24 이스라엘 사람들아 들으라 — 너희가 그리스도를 죽였으나 사망에 매여 있을 수 없으심
  - C 2:25–31 다윗의 예언 — 거룩한 자가 썩음을 당하지 않을 것
  - **D 2:32–33 하나님이 예수를 살리셨다 — 우리가 증인, 성령을 부어 주셨다**
  - C′ 2:34–35 다윗의 인용 — 거룩한 자가 있는 곳(내 우편에 앉았으라)
  - B′ 2:36–37 이스라엘 온 집은 확실히 알지니 — 너희가 십자가에 못 박은 예수를 주와 그리스도가 되게 하셨느니라
  - A′ 2:38–40 성령의 선물 — 모든 먼 데 사람, 얼마든지 부르시는 자들 — 구원을 받으라
- **《카이아즘》 2:41–47 하나님의 교회**:
  - a 2:41 이날에 신도의 수가 삼천이나 **더하더라**
  - b 2:42 가르침을 받음, 서로 교제, 떡을 뗌 — **기도**
  - c1 2:43 사도들의 기사와 표적
  - c2 2:44–45 믿는 사람들이 물건을 통용, 소유를 팔아 나눔
  - b′ 2:46 마음을 같이함, 모이기를 힘씀, 떡을 뗌 — **찬미**
  - a′ 2:47 구원받는 사람을 날마다 **더하게 하시니라**
  - → **c1이 3:1–4:22**(미문의 앉은뱅이)로, **c2가 4:32–5:11**(바나바 vs 아나니아와 삽비라)로 각각 확대됨 — 2장 요약이 이후 단락의 목차 역할을 함.

## 3–5장 — 예루살렘 교회

- **《카이아즘》 3:1–4:22 성전 미문의 앉은뱅이**:
  - A 3:1–8 두 사도가 앉은뱅이를 고침
  - B 3:9–10 모든 백성이 걷는 것과 찬송함을 보고 놀람
  - C 3:11–12 백성의 반응 — 크게 놀라며 솔로몬 행각에 모임
  - D 3:13–26 베드로의 가르침 — 행각에서 백성들에게, “예수로 말미암아 난 믿음”
  - **E 4:1–4 제자들이 잡힘 / 믿는 자가 오천이나 더함**
  - D′ 4:5–12 베드로의 변론 — 공회에서 제사장들에게, “나사렛 예수의 이름으로”
  - C′ 4:13–18 공회의 반응 — 유명한 표적을 우리도 부인할 수 없음
  - B′ 4:19–21 모든 사람이 된 일을 보고 하나님께 영광을 돌림
  - A′ 4:22 병 나은 사람은 40여 세
- **4:23–35 고난에 대한 교회의 반응**:
  - 교회의 이해: “하나님의 권능과 뜻대로 이루려고 예정하신 그것을 행하려고 이 성에 모였나이다”(4:28) — (강의안 참조 “스바냐 1:7–8”).
  - **4:29–30 담대함을 구하는 기도**: ① 위협을 굽어보옵소서 ② 종들로 담대히 말씀을 전하게 ③ 손을 내밀어 병을 낫게 ④ 표적과 기사가 예수의 이름으로 이루어지게.
  - 결과: 모인 곳이 **진동**, 다 **성령이 충만**하여 담대히 하나님의 말씀을 전함 — **또 한 번의 성령 충만**.
  - 성령 충만의 결과(4:32–35): 믿는 무리가 **한마음과 한뜻** / “**그중에 가난한 사람이 없으니**”.
- **4:36–37 바나바 vs 5:1–16 아나니아와 삽비라**:
  - 바나바: 구브로에서 난 레위인.
  - 아나니아와 삽비라:
    - 성령을 속였음(5:3) / 사람이 아닌 하나님께 거짓말(5:4) / “어찌 꾀하여 주의 영을 시험하느냐”(5:9) / 눅 12:10 성령을 모독하는 자.
    - 5:2 “감추매” = **노스피조**(nosphizo) → **수 7:21–22 아간의 범죄**와 같은 단어(LXX — 보충).
  - → **새롭게 출발하는 하나님의 군대(여호수아) = 새롭게 출발하는 하나님의 교회**. (해석) 가나안 정복 첫머리의 아간처럼, 교회 첫머리의 범죄에 엄중한 심판.
- **5:11–42 핍박 가운데 예수를 전하는 교회**:
  - 5:17–18 사도들을 가둔 이유 — “마음에 **시기**가 가득하여”.
  - 5:19–26 옥문이 열림 — “가서 이 생명의 말씀을 백성에게 다 말하라”. 5:26 분위기(백성이 돌로 칠까 두려워 강제로 못 함).
  - **옥문이 열린 사건 × 3**:

| 구절 | 인물 | 계기 |
|---|---|---|
| 5:18–20 | 사도들 | “가서 가르치라” |
| 12:5–11 | 베드로 | **교회의 기도**(12:5) |
| 16:23–26 | 바울 | **기도와 찬송**(16:25–26) |

  - **《카이아즘》 5:27–41**:
    - a 공회 앞에 세우니(27)
    - b 예수의 이름으로 말하는 것을 금하였으나 — 예루살렘에 가득(28)
    - c 제자들 — **사람보다 하나님께 순종**하는 것이 마땅(29)
    - **d 30–33 제자들의 고백 / 그들이 죽이려 함 → 7:57 스데반에게서 실제로 죽임**
    - c′ 가말리엘 — 사람으로부터냐 하나님으로부터냐(34–39)
    - b′ 채찍질하고 예수의 이름으로 말하지 말라 하고 놓음 — **기뻐함**(40–41)
    - a′ 공회 앞을 떠나니라(41) — “그 이름을 위하여 능욕 받는 일에 합당한 자로 여기심을 기뻐하면서”

## 6–8장 — 스데반과 흩어짐

- **6:1–7 스데반과 일곱 집사** — 믿음과 성령이 충만한 사람들, 사도들이 기도하고 안수 → 6:7 “하나님의 말씀이 점점 왕성하여 … **허다한 제사장의 무리도 이 도에 복종**하니라”.
- **큰 핍박이 일어난 때**:
  - ① 예루살렘이 크게 부흥했을 때(6:7) → 스데반의 순교.
  - ② 안디옥 교회가 크게 부흥했을 때(강의안 “1:20–24”, 문맥상 **11:20–24**) → 야고보의 순교(12:2).
  - (해석) 부흥 뒤에 핍박이 오는 패턴.
- **6:8–15 스데반의 체포**:
  - 은혜와 권능이 충만 / 큰 기사와 표적 / 지혜와 성령으로 말함.
  - 거짓 증언으로 체포당함 — 장소는 **회당**.
- **7장 스데반의 설교 — 사도행전에서 가장 긴 설교**(“강조”):
  - 아브라함의 언약부터 애굽까지(2–17): 아브라함 – 이삭 – 야곱 – 12족장 / **75명의 애굽 이주** / 번성.
  - 애굽의 핍박과 모세의 도망(18–29) / 모세의 구원 사역과 **백성이 모세를 거절함**(30–39).
  - 요약:
    - 유대인은 늘 하나님의 지도자를 거절해 왔다(39).
    - 하나님은 **손으로 지은 성전**에 거하시지 않는다(48).
    - 이스라엘은 언제나 불순종했다(51–52).
    - 율법을 지키지 않는다(53).
    - 모세에게 복종하지 않고 마음이 애굽을 향함(39).
  - **우상 숭배의 역사**:
    - 송아지를 만들어 제사하고 그 앞에서 기뻐함(41).
    - **하늘의 군대**(별, 별자리)를 섬김(42).
    - **몰록의 장막**(43) — 인신 제사, 자녀를 제물로.
    - **레판의 별**(43) — **토성**.
    - “너희가 절하고자 만든 형상”(43).
- **유대인들의 반응 — 대조**:
  - 7:54 “마음에 찔려 **이를 갈거늘**” ↔ **2:37 마음에 찔려 “어찌할꼬”**(회개) — 같은 ‘찔림’, 다른 반응.
  - 55절 하나님 우편에 **서신** 예수를 봄 → 큰 소리를 지르고 귀를 막고 달려들어 돌로 침.
- **7:58–8:1a 스데반의 순교와 사울** — 증인들이 옷을 **사울이라는 청년의 발 앞에** 둠(58) / 스데반의 죽음(59–60) / “사울이 그가 죽임 당함을 **마땅히 여기니라**”(8:1a) → 스데반 순교에 대한 사울의 책임.
- **8:1b–8 박해와 흩어짐**:
  - 예루살렘 교회에 큰 박해 → 사도 외에 다 유대와 사마리아로 흩어짐.
  - 스데반의 장사와 큰 슬픔(2) / 사울이 교회를 **잔멸**(3).
  - 흩어진 자들이 복음을 전함, **빌립의 사마리아 전도**(4–7) → “그 성에 큰 기쁨이 있더라”(8).
- **《카이아즘》 8:2–9:22**:
  - A 사울의 교회 박해(8:2–3)
  - B 빌립의 전도(8:4–13) — 마술사 시몬
  - **C 사마리아인 성령 세례(8:14–25) — 베드로**
  - B′ 빌립의 전도(8:26–40) — 간다게의 관리인 내시
  - A′ 사울의 회심(9:1–22)
- **《카이아즘》 6:8–12:24 (대구조)**:
  - A 스데반의 순교와 예루살렘 교회의 흩어짐(6:8–8:3)
  - B 빌립의 사마리아 전도(8:4–13) — “그 흩어진 사람들이”
  - C 사마리아인 성령 세례(8:14–25) — 사도들의 안수
  - D 빌립의 전도(8:26–40)
  - **E 사울의 회심과 박해(9:1–31)**
  - D′ 베드로의 이적과 전도(9:32–35)
  - C′ 이방인(고넬료) 성령 세례(10:1–48) — 말씀을 들을 때
  - B′ 이방인 전도와 안디옥 교회 부흥(11:1–30) — “흩어진 자들이”(11:19)
  - A′ 야고보의 순교와 교회의 흩어짐 → 부흥(12:1–24)
  - → (해석) 사울의 회심이 한가운데 있음. [심화1]의 구조와 함께 볼 것.

## 9–12장 — 사울의 회심, 고넬료, 안디옥

- **바울의 회심에 중요한 두 사람**:
  - **아나니아**: 그가 알았던 사울(9:13–14, 핍박자) vs 하나님이 소개하는 사울(9:15–16, 택한 그릇).
  - **바나바**: 바나바가 만난 사울, 바나바가 기억했던 내용은?(질문).
  - 요약 9:31 온 유대와 갈릴리와 사마리아 교회가 평안하여 든든히 서 가고, 주를 경외함과 성령의 위로로 진행하여 수가 더 많아지니라.
- **10:1–48 백부장 고넬료 — 하나님이 찾으시는 자**:
  - 이달리야 부대의 백부장(1).
  - 경건, 온 집안과 더불어 하나님을 경외(2) / 친척과 가까운 친구들(24) / 부하 가운데도 경건한 사람(7).
  - 백성을 많이 구제(2) / 하나님께 항상 기도(2) — **9시 기도 시간**(강의안 “아침 9시”라고 적었으나 10:3 “제9시”는 **오후 3시**. 오기로 보임).
  - 환상 중에 하나님의 사자가 방문(3) / 기도와 구제가 상달되어 기억하신 바 됨(4) / 베드로를 청하라는 명령에 순종(5, 7–8).
  - 말씀을 들을 때 성령이 내려오심, 방언하며 하나님을 높임(46) / 세례를 받음(48).
- **베드로의 환상 — 관점의 차이**:
  - 평가 대상: 각종 네 발 가진 짐승, 기는 것, 공중에 나는 것(10:12).
  - 베드로의 평가: “**속되고 깨끗지 아니한 것**”(10:14).
  - 하나님의 평가: “**하나님께서 깨끗하게 하신 것**”(10:15).
  - → 하나님과 하나님의 백성(유대인)의 관점 차이.
- **베드로의 한계와 변화**:
  - “너희도 알거니와”(28) — 고넬료에게 어떤 느낌이었을까?
  - 베드로는 욥바의 **‘무두장이’ 시몬의 집**에 머묾(9:43; 무두장이는 부정한 직업) / 고넬료가 보낸 이방인들과 함께 머묾(10:23) → 이방인과의 교제를 ‘위법’이라 말하면서(10:28) **이미 율법을 어기고 있는 베드로**.
  - 생각의 변화 — 깨달은 것: 하나님은 **외모로 사람을 보지 아니하심**(34), 각 나라 중 하나님을 경외하며 의를 행하는 사람은 다 받으심(35).
  - 고넬료: “이제 우리는 … 듣고자 하여 **하나님 앞에** 있나이다”.
  - 참조: 갈 2:17–18.
- **이방인에게 부어진 성령**:
  - 10:44 말할 때 성령이 말씀을 듣는 모든 사람에게 내려오심.
  - 10:45 할례받은 신자들이 놀람.
  - 10:46 방언하며 하나님을 높임 = **2:11 “우리의 각 언어로 하나님의 큰일을”과 같은 현상**.
  - 10:47–48 세례.
  - 11:15 “**처음 우리에게 하신 것과 같이**” → 이방인의 오순절(해석).
- **11:1–18 “이방인에게도 생명 얻는 회개를 주셨도다”**:
  - 11:3 할례자들의 비난 → 베드로의 설명(사건이 다시 한번 반복됨) → 교회가 인정.
  - 11:1을 **예루살렘 모임(회의)**, 곧 **‘공회 1’**로 봄(15장 = 공회 2).
  - 갈 2:11–13 바울이 베드로를 책망한 사건과 연결.
- **9:1–11:26 흐름 요약**[p42]:
  - 9:1–30 사울의 회심 → 다소로 감
  - 9:32–43 베드로의 룻다, 사론, 욥바 사역 → 요약 9:31
  - 10:1–8 고넬료의 환상 / 10:9–23 베드로의 환상(“성령이 말씀하셨다” 19절)
  - 10:24–29 베드로가 고넬료의 집으로 감(“불법”) / 10:30–48 고넬료 집에서의 일
  - 11:1–4 비난 / 11:5–12 환상 반복(“성령이 명하심” 12절) / 11:13–14 고넬료의 환상 / 11:15–18 교회가 인정
  - 요약 11:19–21 흩어진 자들이 안디옥에서 → 큰 무리가 더해짐
  - 11:25–26 바나바가 사울을 찾으러 다소로 감
- **11:23–26 바나바와 안디옥 교회 그리고 사울**:
  - 바나바가 사울을 찾아간 이유는?(질문) → 다소에서 데려와 **1년** 함께 사역.
  - 큰 무리가 모임.
  - 제자들이 **비로소 그리스도인**이라 일컬음을 받음(참조: 약 2:7 “너희에게 대하여 일컫는 바 그 아름다운 이름”).
- **11:27–28 아가보의 예언과 흉년**:
  - 글라우디오 황제 때 천하에 흉년 — **요세푸스의 기록: AD 41–54(글라우디오 재위)에 흉년**이 기록됨.
  - 아가보의 또 다른 예언 → 예루살렘에서 바울이 체포될 것(21:10–11).
- **11:29–30 안디옥 교회의 부조**:
  - 제자들 = 안디옥의 이방인 신자들 / 예루살렘 교회를 도울 만큼 성장함.
  - 각각 **그 힘대로** 부조를 작정(고전 16:2; 고후 9:7).
  - 바나바와 사울이 가지고 감 → 신뢰받고 있음.
- **12장**:
  - 12:1–4 헤롯이 야고보를 죽이고 베드로를 잡음(유대인을 기쁘게 하려고).
  - 12:5–19 교회의 기도와 베드로의 탈출.
  - 12:20–24 주의 사자가 헤롯을 쳐서 죽음 — “하나님의 말씀은 흥왕하여 더하더라”(12:24).
  - 바나바와 사울은 예루살렘으로 가서(11:30) **부조를 마치고 돌아옴(12:25)** → 12장이 부조 여행 사이에 끼워짐(**샌드위치**, 해석).
- **안디옥 교회 = 고넬료의 모습**[p48]:

| 안디옥 교회 | 백부장 고넬료 |
|---|---|

| 성령의 음성에 순종(13:2) | 경건, 온 집안이 하나님을 경외(10:1–2) |
| 바울과 바나바를 파송(13:3) | 기도와 구제가 상달, 기억하심(4) → 성령 충만(11:15) |

- **《카이아즘》 9:1–18:10 (사도행전 중반 대구조)**[p50]:
  - A 바울의 환상 — 예수 그리스도를 만남, **다메섹**(9:1–31)
  - B 베드로의 전도 여행 — 이방인(9:32–10:48)
  - C 예루살렘 회의 — 안디옥 교회(바나바를 보냄)(11:1–30)
  - D 예루살렘의 두 사도(야고보, 베드로) — 박해(12:1–25)
  - **E 안디옥 교회의 파송(13:1–3)**
  - D′ 수리아·길리기아의 두 사도(바울, 바나바) — 박해(13:4–14:28)
  - C′ 예루살렘 회의 — 이방인 교회(실라, 유다를 보냄)(15:1–35)
  - B′ 바울의 전도 여행 — 이방인(15:36–18:8)
  - A′ 바울의 환상 — 예수 그리스도를 만남, **고린도**(18:9–10)
  - → 중심이 **안디옥 교회의 파송**. [심화1·2]의 구조 도표와 비교할 것.

## 13–14장 — 1차 전도여행 (지도 p51–55)

- 경로: 수리아 안디옥 → 실루기아 → 구브로(살라미 – 바보) → 버가(밤빌리아) → 비시디아 안디옥 → 이고니온 → 루스드라 → 더베 → (돌아옴) → 앗달리아 → 안디옥.

| 도시 | 사역 | 반응·박해 |
|---|---|---|
| 비시디아 안디옥 | **회당에서** | “영생을 주시기로 작정된 자는 다 믿더라” / 유대인의 선동 → **“쫓아내게”** |
| 이고니온 | **회당에서** | 유대와 헬라의 허다한 무리가 믿음 / 순종하지 않는 유대인의 선동(악감) → 돌로 치려 하자 알고 **“도망”** |
| 루스드라 | 앉은뱅이의 발을 고침. **회당 언급 없음** | 안디옥과 이고니온에서 온 유대인이 무리를 충동 → 바울을 **“돌로 쳐서”** 죽은 줄 알고 시외로 끌어냄(갈 6:17 예수의 흔적; 딤후 3:11) |
| 더베 | | 바울이 돌아가는 길 … |

- (해석) 박해가 **쫓아냄 → 돌로 치려 함 → 돌로 침**으로 점점 강해짐. 유대인들이 **다른 도시에서 와서** 박해함.

## 15장 — 예루살렘 공회 (공회 2)

- **발단**:
  - 유대로부터 내려온 어떤 형제들 = “**우리 가운데서** 어떤 사람들이 **우리의 지시도 없이** 나가서”(15:24).
  - 주장: “모세의 법대로 할례를 받지 않으면 구원을 받지 못한다”(15:1).
  - 결과: “말로 너희를 괴롭게 하고 마음을 혼란하게 한다”(15:24; 갈 1:6–7 다른 복음).
- **결과**: 공회가 **바울이 전한 복음을 인정** — 베드로의 경험, 야고보의 확증.
- **결정**: 우상의 제물 / 피와 목매어 죽인 것 / 음행을 멀리함.
- **이방인에게 쓴 편지**:
  - “**성령과 우리는** …”.
  - 이방인들이 겪는 상황을 이해하고 위로함.
  - 바나바, 바울, 바사바라 하는 유다, 실라를 추천.
  - 원독자들이 읽고 그 위로한 말을 **기뻐함**.
- **시간 흐름 도식**[p47–49]:
  - 사울의 회심 → 다소 → 바나바가 데려옴 → 안디옥 1년
  - 고넬료 사건 → 교회가 인정(**공회 1**)
  - 흉년 → 부조 → 야고보 순교, 베드로 투옥, 헤롯의 죽음
  - 부조를 마치고 돌아옴 → 안디옥 금식 기도 → 1차 전도여행 → 두 사도가 돌아옴
  - 할례에 대한 변론 → 예루살렘 **공회 2**

## 15:36–18:22 — 2차 전도여행

- **바나바와 바울의 다툼**: 마가 요한을 두고 — 바나바는 “데리고 가자”, 바울은 “데리고 가는 것이 옳지 않다”. 훗날 딤후 4:11 “마가를 데리고 오라 **그가 나의 일에 유익하니라**”.
  - 바나바는 마가와 함께 구브로로 / 바울은 실라를 택하여 수리아, 길리기아로 다니며 교회를 견고하게 함.
- **갈라디아 교회들을 돌아봄**:
  - 더베, 루스드라에서 **디모데를 택함** — 할례를 행함(대조: 갈 2:3 디도에게는 할례를 강요하지 않음).
  - 예루살렘 공회의 규례를 전함 → 16:5 “여러 교회가 믿음이 더 굳건해지고 수가 날마다 늘어가니라”.
- **유럽으로 전파되는 복음**(지도 p62 “2차 전도여행의 출발 15:40–18:23a”):
  - 사도들의 계획은 아시아였으나 **성령이 아시아에서 말씀을 전하지 못하게**(16:6), 비두니아로 가려 하나 **예수의 영이 허락지 아니함**(16:7).
  - 부르기아와 갈라디아 땅을 거쳐 무시아 → 드로아.
  - **마게도냐 환상** “건너와서 우리를 도우라” → 16:10 “하나님이 … 우리를 부르신 줄로 **인정**함이러라”, 곧 떠나기를 힘씀.
  - 대조: 비두니아로 가고자 **애씀**(허락 안 됨) ↔ 마게도냐로 떠나기를 **힘씀**(부르심으로 인정).
- **빌립보(16:12–40)**:
  - 배경:
    - 마게도냐 지역의 **첫 성**(수도는 아님). 사면이 산이고 에게해 쪽 **네압볼리 항**을 가진 전략적 요충지.
    - **빌립 2세**가 점령하고 빌립보라 이름 지음(**BC 357**). 금광으로 군사 강국이 됨.
    - ✅ 확정: **BC 356** → `00_확정연대표.md`
    - **로마에 정복됨(BC 168)** — 이미 금광이 바닥나 쇠퇴.
    - **아우구스투스**의 빌립보 전투 승리(**BC 42**) → 로마 식민지 건설과 특혜(시민권, 세금 면제).
    - 헬라 시대의 유명한 의학 학교가 있었음(→ 누가 연결 가능성, 해석).
    - “로마 사람인 우리가 …” 로마 시민의 특권에 대한 자부심 → 빌립보서의 “**하늘의 시민권**”(빌 3:20).
  - **회당이 없음** → 안식일에 강가 기도처를 찾음.
  - **자주 장사 루디아**: 하나님을 섬기는 자, 들을 때 주께서 마음을 여심, 그와 그 집이 세례.
  - **귀신 들린 여종**: 점을 쳐 주인에게 큰 이익. “이 사람들은 지극히 높은 하나님의 종으로서 구원의 길을 너희에게 전하는 자”(귀신이 증거하는 정체 — 눅 4:34, 41) → 바울이 쫓아냄 → 주인들의 고소, 거짓 증언(행 19:25처럼 **돈** 문제).
  - 고소 내용: “**로마 사람인 우리가** 받지도 못하고 행하지도 못할 풍속을 전한다”(16:21; 강의안 “6:21” 오기).
  - 감옥 → **기도와 찬양 → 옥문이 열림** → 간수와 그 집이 구원.
  - 16:37 “로마 사람인 우리를 **죄도 정하지 아니하고** …” — 바울의 시민권.
- **데살로니가(17:1–9)**:
  - 빌립보에서 시작되는 로마 도로 **에그나티아 대로**(로마와 동방을 잇는 길) → 암비볼리 → 아볼로니아 → 데살로니가.
  - 배경:
    - **마게도냐의 수도**, 가장 부유하고 영향력 있는 도시, **인구 20만 명 이상**.
    - 로마의 **자유 도시**(자치권).
    - 제국의 중요한 무역항, 여러 민족과 종교가 섞임.
    - 유대인의 회당이 있음.
  - 관례대로 회당에서 **3안식일** 강론 → 경건한 헬라인의 큰 무리, 적지 않은 귀부인이 따름.
  - 유대인의 **시기** → 불량한 사람들을 데리고 떼를 지어 소송.
    - 고소 내용: “천하를 어지럽게 하던 이 사람들”, “**가이사의 명을 거역**”, “**다른 임금 곧 예수**라 하는 이가 있다”.
    - 야손 등에게 **보석금**을 받고 놓음 → 밤에 베뢰아로 보냄.
- **빌립보 vs 데살로니가 vs 고린도 vs 에베소 비교표**[p71, 80, 93]:

| | 빌립보 | 데살로니가 | 고린도 | 에베소 |
|---|---|---|---|---|
| 도시 | 마게도냐의 첫 성 | 마게도냐의 수도 | 아가야의 수도 | 아시아의 수도 |
| 사역 | 강가로 나감 | 회당 / 3안식일 | 18개월 | 회당 3달, 두란노 2년 |
| 발단 | 귀신 들린 여종을 고침 | 유대인의 시기 | 유대인이 일어남 | 데메드리오의 소동 |
| 법정 | 상관들 앞 | 읍장들 앞 | 총독 **갈리오** 앞 | 서기장이 무리를 진정 |
| 고소 | “로마 사람인 우리가 받지도 행하지도 못할 풍속” | “천하를 어지럽게”, “가이사의 명을 거역”, “다른 임금 예수” | “율법을 어기면서 하나님을 경외하라 권한다” | (서기장) 신전 물건 도적질도, 여신 비방도 안 함 |
| 결과 | 때리고 감옥 → **시민권** | 보석금 | **재판 거부** | 고발할 것은 재판 날에 총독들·민회에서 하라, “불법 집회” 보고 위험 → 무리를 흩음 |

  - (해석) 로마 당국이 점점 **복음 전파를 불법으로 보지 않는** 쪽으로 판결함 → 사도행전의 변증 목적([TBS4] 기록 목적)과 연결.
- **베뢰아(17:10–15)** — 회당에 들어감. 베뢰아 사람들은 데살로니가 사람보다 **더 너그러워서**(고상한, 관대한, 편견에서 자유로운):
  - **간절한 마음**으로 = 열린 마음.
  - “**이것이 그러한가**” 하여 = 진리를 찾고자 하는 마음.
  - 날마다 **성경을 상고**함.
  - → 믿는 사람이 많아짐, 헬라의 귀부인과 남자도 적지 않음.
- **아덴(17:16–34)**:
  - 배경: 아테네, 유대인의 회당이 있음. 헬라 문화의 정치·철학·교육 중심지였으나 **4세기 전에 몰락**, 바울 방문 때는 **인구 1만 명의 소도시**.
  - 17:21 이 도시 사람들이 시간을 보내는 법 — 새로운 것을 말하고 듣는 것.
  - 우상이 가득함을 보고 **마음이 격분**하여 회당(유대인, 경건한 사람들)과 장터(날마다 만나는 사람들)에서 변론.
  - 반응(17:18): “말쟁이가 무슨 말을 하고자 하느냐?” / “이방 신들을 전하는 사람인가 보다” — “이는 **예수와 부활**을 전하기 때문이러라”.
  - **아레오바고**로 청함 받음 — 그들이 원한 것은 **새로운 지혜**.
  - 평가: “**설교학적으로 완벽한 설교, 수사학적으로 최고의 구성**”.
  - 결과(17:32): 죽은 자의 부활을 듣고 **어떤 사람은 조롱**, 어떤 사람은 “다시 듣겠다” → **몇 사람만** 믿음.
- **고린도(18:1–17)**:

## 18:23–21:16 — 3차 전도여행

- **아볼로와 에베소의 제자들**:
  - 알렉산드리아 출신 **아볼로**가 에베소에 옴 — **요한의 세례만** 앎(18:24–25).
  - 브리스길라 부부가 하나님의 도를 더 정확히 풀어 줌(18:26).
  - 추천서를 가지고 아가야로 가서 유익을 줌 — 성경으로 예수는 그리스도라고 힘 있게 증언, 공중 앞에서 유대인을 이김(18:27–28) — “두려워하지 말며 침묵하지 말고 말하라”(18:9)와 연결.
  - 아볼로가 고린도에 있을 때 바울이 에베소에 옴 — 어떤 제자들은 **성령이 계심도 듣지 못하고 요한의 세례만** 앎(19:1–3) → 바울이 예수를 증거하고 안수하자 **성령이 임함**(19:6).
- **에베소의 배경**(지도 p84, 사진 p86–90):
  - **항구 도시 에베소 — 소아시아의 관문 → 교역의 중심지 → 경제적 번영**. 지도에서 유럽(고린도)과 아시아(에베소)가 에게해를 사이에 두고 마주 보는 두 축.
  - 해로와 육로가 교차하는 운송 중심지. 바울 당시 **인구 25만 명**, 로마 제국에서 **세 번째로 큰 도시**.
  - 극장, 목욕탕, 도서관, 광장, 포장도로 — 사진: 대극장, 아르가디안 길, “**퀴즈! 이것이 무엇일까요?**”(구멍 뚫린 돌 좌석 — 공중 화장실로 보임, 추정).
  - ⑥ **교육의 중심지** — 학교, 도서관, 강의실. 사진 제목 “**두란노 서원으로 추정되는 셀수스 도서관**”(보충: 셀수스 도서관은 2세기 초 건축이라 바울 시대 건물은 아님 — 강의안은 ‘추정’이라 표기함).
  - **아데미 신전**:
    - 에베소의 아데미 — 풍요와 다산의 여신.
    - 고대 세계의 신비(7대 불가사의 — 보충)로 에베소의 명성이 커짐.
    - 원래 **아나톨리아의 풍요의 여신 키벨레**의 성지 → 그리스의 아데미, 라틴의 **다이아나**와 동일시됨.
    - 사진: 사슴과 함께한 그리스식 아르테미스 상 vs 에베소식 **다유방(多乳房) 아데미 상**.
  - 에베소는 **아데미 신전 지기**를 자처하는 도시(19:35):
    - **BC 560년경 리디아의 침공** — 신앙심으로 극복.
    - **BC 356년 방화로 전소** → 약 100년 만에 원상 복구.
  - **사상적 배경**: 우주적 이원론, 헬라 철학, 금욕주의·쾌락주의, 신비주의, 유대교의 율법주의, **마술**, 밀의 종교(비밀), **혼합주의** → `10_에베소서.md`, `23_요한123서.md`(영지주의) 참조.
- **3차 전도여행의 에베소 사역 10가지**(p92):
  - ① 세례, 성령의 임재와 은사(19:5).
  - ② **3달** 동안 회당에서 하나님 나라 강론(19:8).
  - ③ 순종치 아니하고 도를 비방하는 무리(19:9).
  - ④ **두란노 서원에서 2년** 날마다 강론(19:9–10).
  - ⑤ 복음이 편만해짐, 바울의 이적(19:11).
  - ⑥ **마술의 성행** — 이름을 부르는 주술 행위(19:13–19, 스게와의 아들들).
  - ⑦ 마술책을 불태움 — **은 오만 = 5,000일 임금**(강의안 표기. 보충: 은 1드라크마 = 하루 품삯으로 보면 5만 일치 임금. ‘5,000일’은 계산 오기일 가능성 — 확인 필요).
  - ⑧ 아데미 숭배, 여신을 통한 상업 발달(19:24 은장색 데메드리오).
  - ⑨ **아데미 소동** — 2시간이나 외칠 정도로 과격(34절).
  - ⑩ 복음에 대한 저항이 심함(21–41, 35).
  - → “**고후 1:8–9** 바울의 기억 속의 에베소 소동”(힘에 겹도록 심한 고난, 사형 선고를 받은 줄).
- **마게도냐와 헬라 방문(20:1–6)**:
  - 아데미 사건 **이전부터** 계획이 있었음(19:21).
  - 마게도냐로 감 → 헬라에서 **3달**.
  - 원래 계획은 배를 타고 수리아로 → 유대인들이 해치려고 공모(20:3) → **달라진 계획**: 마게도냐로 돌아가기로 작정.
  - 지도 p95 귀로: 빌립보 → 드로아(유두고) → 앗소 → 미둘레네 → 기오 → 밀레도.
- **밀레도 고별 설교(20:17–38)** — 에베소 장로들을 불러서:
  - 에베소 사역 정리:
    - 18 아시아에 들어온 첫날부터 지금까지 여러분이 안다.
    - 19 모든 **겸손과 눈물**, 유대인의 간계로 인한 시험을 참고 주를 섬김.
    - 20 유익한 것은 무엇이든지 **공중 앞에서나 각 집에서나** 꺼림 없이 가르침.
    - 27(강의안 “28”) 하나님의 뜻을 다 꺼리지 않고 전함.
    - 31 **3년**이나 밤낮없이 각 사람을 **눈물로** 훈계.
    - 33–35 이익을 탐하지 않음.
  - 걱정 “**내가 떠난 후에**”: 29 사나운 **이리**가 들어와 양 떼를 아끼지 않음 / 30 여러분 중에서도 **어그러진 말**을 하는 사람들이 일어남 → 바울이 바라본 에베소의 문제(→ 딤전후, 요한서신, 계 2:1–7).
- **21:1–16 예루살렘 여행**:
  - 아가보의 예언(21:10–11).
  - 21:12 “우리가 권하니” → 21:13 “나는 주 예수의 이름을 위하여 결박당할 뿐 아니라 **예루살렘에서 죽을 것도 각오**하였노라” → 21:14 권함을 받지 않으므로 “주의 뜻대로 되기를 원하노라”.

## 21:17–28장 — 체포, 재판, 로마

- 예루살렘에서의 바울(21:17–26) → 성전에서 붙잡힌 바울(21:27–36).

| | 예수님(눅 22:66–23:13) | 바울(행 22:30–26:32) |

| 2 | 빌라도 — 무죄 | 벨릭스 — 무죄 |
| 3 | 헤롯 — 무죄 | 베스도 — 무죄 |
| 4 | 빌라도 — 무죄 | 아그립바 — 무죄 |
