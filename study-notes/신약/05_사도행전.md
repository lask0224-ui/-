# 사도행전

> 표기: [TBS4] = `사도행전/사도행전(TBS)_4분할.pdf` (19쪽, The Bible Ministry)
> [예습1-1] = `사도행전/사도행전_예습_1강-1.html` (TBS 심화학교 1강 ① 강의 녹취 정리본)
> [바울일대기] = `신약 강의자료(2)/15. 로마서/바울의 일대기.png` (TBS 이미지)
> 추가 사도행전 자료(심화반 1·3·4강, 수평, 연대표, 지도, 전도여행 정리 등)는 신약 학습 단계에서 이 파일에 보강.

## 주제 · 제목

- 주제 문구: **“땅끝까지 이르러 내 증인이 되리라”** [TBS4]
- 강의 반복 구호: **“성령님과 함께하는 사도행전”** — 이 책의 주인공은 사도가 아니라 성령. 사도행전 = **‘성령의 행전’, ‘복음의 행전’** [예습1-1]
- 강의 목적: “사도행전의 **인상을 바꾸는 것**” [예습1-1]

## 읽는 법 (강사의 해석 원리) [예습1-1]

- 표면에 보이는 것 ≠ 저자가 의도한 것. 문학에는 **‘의도’와 ‘구조’**가 있다.
- **원독자의 자리**에서 읽기: ‘땅끝’은 오늘날의 지구본이 아니라 지중해 중심의 알려진 세계(헤로도토스 예화).
- **구성의 법칙**으로 읽기: 시간이 뒤로 돌아가는 서술(스데반 순교 → 흩어진 자들이 안디옥에서 최초 이방인 교회)도 구성상의 의도가 있다.
- 앞은 베드로, 뒤는 바울 — **가운데에 바나바**가 있다(바울을 받아 준 사람).
- ‘역사서’ = 사건 + **해석**. 사건은 하나여도 기억·해석은 다르다. 사도행전에서 캐야 할 것은 “저자가 무엇을 말하고 싶어 하는가”.
- 사도행전인데 사도는 **베드로와 바울만** 나온다. 두 사람이 같은 상황(이방인)을 다르게 통과하는 것 자체가 해석이다.

## BRI (Basic Required Information)

### 저자: 누가 [TBS4][예습1-1]

- 눅 1:1–3 “**나도**” → 직접 목격자가 아니라 전해 받은 자. ‘처음부터’(아르케) → 구약에도 밝았으리라 추정.
- 행 1:19 “**그들의 말로는** 아겔다마” → 히브리/아람어가 모국어가 아님 = **이방인**.
- 유대 풍습을 설명해 줌, 헬라어 표현(디오스구로, 트레이스 타베르네)을 번역 없이 씀, 로마 황제 기준 연대.
- 행 2:4 성령 강림을 경험한 사도가 아님.
- **“우리” 단락**: 행 16:10(드로아→빌립보), 20:6(5), 21:17, 27:1, 28:1, 28:16.
  - 16장 빌립보까지 동행 → 17:1 ‘그들이’ = 빌립보에 남음 → 20:5 다시 합류 → 예루살렘, 가이사랴, 로마까지 동행. [예습1-1]
- 동행자 좁히기: 옥중서신(골로새서·빌레몬서) 명단 → 골 4:10–11 아리스다고·마가·유스도는 할례파(유대인) 제외 → 행 20:4–5 아리스다고·디모데·두기고는 ‘그들’ → 에바브라는 2·3차 여행 비동행 → 데마는 딤후 4:10 떠남 → **골 4:14 “사랑받는 의사 누가”**.
- 의학적 흔적: 눅 6:6 ‘**오른손** 마른’(막 3:1 ‘손 마른’), 눅 4:38 ‘**중한** 열병’(마 8:14, 막 1:30 ‘열병’), 눅 14:2 고창병/수종병 구분, 행 3:7 ‘발과 **발목**’, 눅 18:25 바늘(의료용; 마 19:24와 비교), 혈루병 여인 “아무에게도 고침받지 못함”(막: 많은 의사에게 괴로움) — 동료 의사 체면(히포크라테스 윤리).
- 외적 증거: 저스틴, 무라토리 정경, 반마르키온 서문, 이레네우스, 유세비우스, 터툴리안 — **안디옥 출신 의사 누가**. [예습1-1]
- ⚑ 독특한 견해: 가톨릭 전승상 **디도가 누가의 동생**. 사도행전에 누가와 디도가 끝내 언급되지 않는 것 = 누가가 자기 가족을 감추는 겸손. [예습1-1]
- 누가의 글쓰기: 자기가 있던 때/없던 때를 엄격히 구분, 상상으로 채우지 않음. 목격자를 **인터뷰**한 사람 같다(향유 옥합 ‘발 뒤에서’, ‘돌 던질 만큼’, 행 27장 연안 항해술). [예습1-1]

### 수신자: 데오빌로

- 이름 뜻: 데오(하나님) + 필로스(사랑하는 친구) = ‘하나님을 사랑하는 자’. [TBS4]
- 두 견해 [TBS4]:
  - **개인**: “각하” 호칭 — 눅 1:3 데오빌로, 행 23:26 벨릭스, 행 26:25 베스도(같은 호칭).
  - **공동체**: 1세기에 흔한 이름 → ‘하나님을 사랑하는 사람들’.
- 이방인 수신자: 이방인에게 익숙한 단어(랍비 대신 선생), 로마 달력, 유대 지역 설명(눅 8:26, 19:29, 24:13).
- 호칭 변화: 누가복음 “데오빌로 **각하**” → 사도행전 “데오빌로**여**” = 누가가 데오빌로의 믿음을 한 단계 끌어올림. [예습1-1]

### 기록 연대

- [TBS4]: 행 28:30–31 두 해(AD 60–62) + AD 64 네로 박해 언급 없음 → **AD 62–64년 사이**.
- [예습1-1]: **63년경**. 근거: 사도행전 안에서 로마 당국은 한결같이 “무죄” — 64년 네로 박해, 66–70년 유대 반란의 분위기가 전혀 없음.
- → 두 자료는 모순되지 않음(63년은 62–64 범위 안).

### 역사적 배경 [TBS4][예습1-1]

- **로마**: 아우구스투스(BC 27–AD 14) 이후 약 200년 팍스 로마나, 도로 정비(높은 곳은 깎고 낮은 곳은 메우고 — 군대·교역·소식 전달), 강력한 중앙정부, 로마 시민권, 황제 속주/원로원 속주.
- **헬라 철학**: 플라톤 이원론(보이는 것=악, 보이지 않는 것=선), 행 17:18 에피쿠로스·스토아.
- **그레코-로망**: 역사가 짧은 로마가 헬라 문명을 깊이 수용. 구약과 마태복음 사이 400여 년 동안 세상이 네 번 이상 뒤집힘.
- **‘하나님을 경외하는 이방인’**의 등장 — 사도행전의 큰 이슈. [예습1-1]
- **회당**: BC 586 성전 멸망 후 바벨론 포로기에 기원. 성전에 대한 갈망, 예배·교육(율법)·순례자 숙소. 성인 남자 10명 이상이면 성립. 예배 순서: 쉐마 낭독(신 6:4–9; 11:13–21; 민 15:37–41) → 기도 → 율법과 선지서 낭독 → 설교 → 축도. 구성원: 유대인/이방인/유대교에 입교한 경건한 자(행 13:43). **회당 = 복음 전도의 전초기지** (갈 4:4 ‘때가 차매’). [TBS4]

### 기록 목적 [TBS4]

1. 데오빌로에게 확신을 더하게 하기 위해
2. 교회와 하나님 나라의 확장
3. 복음의 확장을 알려 주기 위해
4. 성령의 역사
5. **교회는 로마에 대항하는 종교가 아님을 변증**

## 누가복음 ↔ 사도행전 비교

- 같은 수신자, 이어지는 내용(탄생~승천 / 승천~땅끝). [예습1-1]
- **지리** [TBS4]: 눅 = 갈릴리 → 유대·사마리아 → **예루살렘** / 행 = 예루살렘 → 유대·사마리아 → **땅끝**.
- **성령 강림** [TBS4]: 예수님의 성령 세례(눅 3:21–22) ↔ 제자들의 성령 세례(행 2:1–4). 구약 예언 성취: 눅 4:18–19 ↔ 행 2:17–21. 둘 다 **기도할 때** 성령이 임함. [예습1-1]
- **고발당함 — 공회 유죄 후 세 번 무죄** [TBS4]:

| 예수님 (눅) | 바울 (행) |
|---|---|
| 공회(22:66) → 유죄(22:71) | 공회(22:30) → 유죄(23:2) |
| 빌라도(23:1) → 무죄(23:4) | 벨릭스(24:3) → 무죄(24:24–27) |
| 헤롯(23:8) → 무죄(23:15) | 베스도(25:6) → 무죄(25:18–29) |
| 빌라도(23:13) → 무죄(23:14) | 헤롯(아그립바)(25:23) → 무죄(26:31) |

- 평행 사건 [예습1-1]: 첫 설교 거절 / 치유(앉은뱅이) / 죽은 자 살림(나인성 과부 아들·야이로의 딸 ↔ 다비다·유두고) / 전도행(세 번 ↔ 1·2·3차 여행) / 결단하고 예루살렘으로 / 성전 사건 / 눅 24:44,47 “이루어져야” ↔ 행 28장 “이루어졌다”.
- 백부장 대조 [예습1-1]: 눅 7장 백부장은 “오지 마시고 말씀만” — 유대인을 배려해 알아서 피해 준 믿음. 행 10장은 하나님이 베드로를 고넬료 집에 **들이미심** → 돌파.
- 눅 6:46 이후 사람들이 ‘유대인/이방인’이 아니라 **‘듣고 행하는 자/행하지 않는 자’**로 나뉨. 사도행전 끝까지 “듣고 믿었더라/믿지 않았더라” 반복. [예습1-1]

## 구조 [TBS4]

1. **지리적**: 1:1–8:1a 예루살렘 / 8:1b–12:25 유대·사마리아 / 13:1–28장 땅끝까지
2. **인물별**: 1–12장 베드로 / 13–28장 바울
3. **요약적 진술을 통한 구조** (6단락):
   - 1:1–6:7 예루살렘 교회의 성장
   - 6:8–9:31 팔레스타인 곳곳의 확장 (7장 스데반의 죽음)
   - 9:32–12:24 안디옥 교회의 확장 (12장 야고보의 죽음)
   - 12:25–16:5 남갈라디아와 소아시아 중앙으로 확장 (13–14장 핍박)
   - 16:6–19:20 마게도냐·아가야로 확장 (16–18장 핍박)
   - 19:21–28:31 로마로 확장 (에베소·예루살렘·로마에서 핍박)
4. **성령 중심 방열 구조**: 여러 사건이 하나의 중심 주제에 연결 — 행 2장 성령 강림 → 교회 태동 → 복음 확장.
5. **수미상관(inclusion)**: A 1:1–3 예수 그리스도 & 하나님 나라 / B 1:4–28:29 성령 강림·교회 태동·확장 / A′ 28:30–31 하나님 나라 & 예수 그리스도. — [예습1-1]도 “책의 양 끝을 하나님 나라의 일이 떠받친다”고 설명.

## 본문 요점 [TBS4]

- **1:1–5** “먼저 쓴 글” = 누가복음. 신·세상·역사·잃어버린 자·재물에 대한 관점.
- **1:6–11** 승천, “오직 성령이 너희에게 임하시면”. **1:12–26** 맛디아 → 열두 사도의 완성.
- **2:1–4 성령 강림**: 오순절 / 불의 혀처럼 갈라지는 것 / 다른 언어(바대·메대·엘람·메소보다미아·유대·갑바도기아·본도·아시아·브루기아·밤빌리아·애굽·리비아·로마·그레데·아라비아).
- **오순절 = 칠칠절**: 3대 절기(유월절·칠칠절·초막절) 중 하나. 유월절 후 50일째, 안식일 기준 7주 다음 날. 출 19:1 출애굽 3개월 뒤 시내 광야 도착 → 출 19:16 셋째 날 하나님 임재 = **이스라엘(하나님 나라)** ↔ 행 2:1–4 성령 강림 = **교회 태동(하나님 나라)**.
- **창 11장 ↔ 행 2장 대조**:

| 창 11장 (바벨) | 행 2장 (오순절) |
|---|---|
| 온 땅의 구음이 하나 | 온 땅의 언어가 혼잡함 |
| 한곳에 모임 | 한곳에 모임 |
| 하나님의 심판 | 성령 임함 |
| 언어를 혼잡케 하심(소통 단절) | 서로의 언어를 말함(소통) |
| 온 지면에 흩으심 | 땅끝까지 복음 전파 |
| 아브라함을 택하심(구원 계획) | 교회 공동체(구원 계획) |

- **교회 태동 = 하나님 나라**: 행 2:43–47 통용·모임·찬양. 눅 17:20–21 “너희 안에”(엔토스: within / among). 눅 19:12 바실레이아 = 통치하다. 엡 1:22–23 교회의 머리 = 그리스도.
- **예루살렘 교회 성장 진술**: 2:41 삼천 → 2:47 날마다 → 4:4 남자 오천 → 5:14 남녀 큰 무리 → 6:7 제사장 무리 복종.
- **스데반** (6–7장): 고발 = 신성모독(하나님과 성전; 6:11 모세와 하나님, 6:13 거룩한 곳과 율법), 고소인 = 자유민들(6:9). 설교(7:2–53): 아브라함(부르심·언약) → 요셉(시기) → 모세(출애굽·성전, 39–43 불순종) → 다윗·솔로몬 성전 → 51–53 “너희도 항상 성령을 거스르는도다”. 58절 증인들이 옷을 사울 발 앞에. 55절 예수께서 하나님 우편에 **서심**. 기도(59, 60).
- **8장**: 큰 박해(1) → 크게 울더라(2) → 큰 기쁨(8) = 박해에서 기쁨으로, 예루살렘에서 유대·사마리아로. 사마리아 성령(8:1b–25), 에디오피아 관리(26–40), 사울 회심(9:1–30), 애니아(9:31–35), 다비다(36–43), 고넬료(10:1–11:18).
- **수리아 안디옥 교회** (11:19–30): 스데반 일로 흩어진 자들이 세움, 헬라인에게도 전함, 예루살렘이 바나바 파송, 바나바·사울 양육, “그리스도인” 칭호, 예루살렘에 부조.
- **12장 교차 구조**: A 11:28–30 부조 / B 12:1–2 야고보의 죽음 / C 12:3–19 베드로 석방 / B′ 12:20–23 헤롯의 죽음 / A′ 12:24–25 부조.
- **1차 전도여행 파송** (13장): 선지자·교사, 금식하며 ‘섬길 때’ — 섬기다 = **레이투르게오**(70인역에서 제사장·레위인의 성전 직무).
- 도시별 분석 틀 [TBS4]: **회당 유무 / 설교·사역 / 회심자 / 핍박** 네 칸으로 정리.
  - 비시디아 안디옥(회당 O): 13:17–23 구약사 → 다윗 언약 = 예수 그리스도, 38–39 모세 율법으로 못 얻던 칭의. 회심 13:43, 48 / 핍박 13:45, 50.
  - 이고니온(O): 14:1 허다한 무리 믿음, 14:4 무리가 나뉨 / 핍박 14:2, 5.
  - 루스드라(회당 X): 14:8–10 치유, 14:15–17 창조주 설교, 제자들·디모데(16:2) / 14:19 돌에 맞음.
- **예루살렘 공의회** (15장): 원인 “할례 받지 않으면 구원 못 받는다”(1) / 베드로 “차별하지 않으셨다, 예수의 은혜로 구원”(9) / 야고보 “다윗의 무너진 장막” / 결정(20) 우상의 더러운 것·음행·목매어 죽인 것·피 / **유대교와 기독교의 분리**.
- **2차 전도여행**: 바울·바나바 결별(15:39), 디모데 할례(16:3), 아시아에서 막으심(16:6), 비두니아 불허(16:7), 마게도냐 환상(16:9) — “왜 마게도냐인가?”
  - 빌립보(회당 X, 로마 식민지): 루디아, 귀신 들린 여종, 투옥과 지진, 간수 가족, 시민권으로 석방.
  - 데살로니가(O): 세 안식일 강론, 일하며 사역(살전 2:9) = 장기 사역 계획, 경건한 헬라인·귀부인, 유대인 시기 → 밤에 베뢰아로, 베뢰아까지 추격(17:13).
  - **아덴 설교 대조표**: 하나님은 한 분(26) ↔ 스토아 범신론 / 창조주(24–25) ↔ 에피쿠로스 원자 우연 / 한 조상의 후손(25–26) ↔ 아덴인의 아티카 토착 자부심 / 섭리하심(26) ↔ 에피쿠로스 자연신론 / 사람 손으로 섬김 받지 않음(25, 29) ↔ 제사로 신이 행복해진다는 사고.
  - **고린도**: 관용어 코린디아조마이(부도덕을 훈련하다/간음하다), 코린디아 코레(고린도 창부), 코린디악세스다이(난봉꾼), 코린디아스테스(탕자). 이스미안 게임(2년마다, 아폴로 제사 → 시장에 제사 고기). AD 49 글라우디오 칙령(아굴라·브리스길라), 1년 6개월 체류, 실라·디모데 합류 → **데살로니가전후서 기록**. 갈리오 총독(AD 51–52) = 델피(갈리오) 비문 → “로마법으로 무죄”(18:14–16). 회당장 둘: 그리스보(8), 소스데네(17) → 회당 둘?
- **3차 전도여행**: 아볼로(18:24–28, 고전 1:12). 에베소 = ‘배가 육지에 정착’, 교통 중심, 아데미 신상, 주술(‘에베소 글’). 12제자 성령(19:2–7), 2년 3개월(19:10), 소동(19:23–41 = 고후 1:8–9 아시아 환난) → 로마법으로 무죄. **고린도전서 기록**(고전 16:8). 고린도 방문(20:1–3), 마게도냐에서 **고린도후서**(고후 7:5–7, 9:2–5), 고린도에서 **로마서**(행 20:3 = 롬 15:25–29). 예루살렘 연보(고후 9:5, 롬 15:26–27) = 이방 교회와 예루살렘 교회가 하나 됨.
- **예루살렘~로마**: 공회 유죄 → 벨릭스·베스도·헤롯 무죄, 가이사랴 2년(24:27). 로마: 유대인 만남(28:16–22), 하나님 나라 전파(23–28), 사 6:10 인용, “구원이 이방인에게”. 결론 28:31.
