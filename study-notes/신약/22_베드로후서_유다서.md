# 베드로후서

## BRI

### 저자 — 시몬 베드로

- **(1) 내증**:
  1. 예수님을 만난 경험이 있음 — “우리는 그의 크신 위엄을 친히 **본 자라**”(1:16).
  2. **변화산 사건을 경험함** — “거룩한 산에 있을 때 … **들은 것이라**”(1:17–18) → 베드로, 야고보, 요한.
  3. **자신의 죽음을 예견함**(1:14) ↔ 요 21:18–19.
  4. **바울과 친분**이 있고 그의 서신을 앎(3:15 “우리가 사랑하는 형제 바울”).
  5. **두 번째 편지**를 씀 — “이 둘째 편지를 쓰노니”(3:1).
  6. “예수 그리스도의 종이요 사도인 **시몬** 베드로”(1:1) ↔ 행 15:14(야고보가 “시므온”이라 부름) — Simon / **Symeon**(히브리식 이름).
- **(2) 외증과 위작설**:
  - 베드로의 이름을 빌린 **위작들**: 베드로 묵시록, 베드로 복음서, 베드로 행전, 베드로 설교.
  - **베드로후서 위작설**: 근거는 전서와 **용어·문체가 다름** → 반론: **벧전 5:12 “실루아노로 말미암아”** — 전서는 대서인(실루아노)이 썼기 때문에 문체가 다를 수 있음(“차이점 ? → 차이점 !”).
  - 교부들의 인정: 오리겐, 예루살렘의 시릴, 아타나시우스.

### 기록 시기와 장소 — AD 65–67년경 로마

- ① 바울의 서신을 언급함(3:15–16) → 바울 서신 AD 49–62 이후.
- ② 벧전 5:13 바벨론(로마)의 교회, 마가 → **베드로전서(AD 64) 이후**.
- ③ **임박한 죽음**(1:14) → 전승상 베드로는 **AD 66년경 로마에서 순교**.
- ⇒ **AD 65–67년경 로마**.
  - ⚠ 순교 연도 “66년경”은 [배경](네로 박해 64–68)과 모순되지 않음. 바울 순교 67/68 [바울일대기]와는 따로 봐야 함.

### 수신자

1. **첫 번째 편지를 받은 자들**(3:1) — 소아시아에 흩어져 사는 이방인과 유대인 그리스도인(벧전 1:1 본도, 갈라디아, 갑바도기아, 아시아, 비두니아).
2. “**동일하게 보배로운 믿음을 우리와 함께 받은** 자들”(1:1) → 이방인(행 15:11 “우리가 그들과 동일하게 주 예수의 은혜로 구원받는 줄을 믿노라”).
3. 택하심과 부르심과 약속을 알고 이미 **있는 진리에 서 있음**(1:10–12).
4. **사도들의 가르침**을 받음(3:2).
5. 바울의 편지를 받았고 **회람되는 서신**을 읽음(3:15–16).

### 역사적 배경 — 베드로전서와의 차이

| | 베드로전서 | 베드로후서 |
|---|---|---|
| 주제 | **고난** | **거짓 교사** |
| 배경 | 로마 화재, 로마 제국의 박해와 영향력 | 로마 제국의 탐욕과 방탕 → 거짓 교사의 성격 / **순교를 앞둔 베드로** |

- **거짓 교사의 특징** — 1세기 헬라 철학의 영향: 영적인 지식의 소유가 세상에 대한 태도를 결정함 → 금욕주의(스토아) / 쾌락주의(에피쿠로스) / 영적 지식의 추구와 자랑 / 분쟁과 음란.
- **베드로후서에 나타난 거짓 교사의 특징**:
  1. **자의적 성경 해석**(1:20; 3:3–4, 16).
  2. **영적 교만**(2:1, 9–11; 3:3–4).
  3. **탐욕**(2:3, 13–15, 20–22).
  4. **방종·음란**(2:2, 7, 10, 14, 18, 20–22).
  5. **종말을 부인함**(3:3–5).
  6. **스스로 멸망의 길을 선택함**(2:1–6, 12, 17–22; 3:3–7).
  - 거짓 선지자와 거짓 선생의 공통점: **하나님 말씀의 권위를 무시함**.
- **순교를 앞둔 베드로의 관심**(요 21:17 “내 양을 먹이라”):
  - 부르심과 택하심을 굳게 하라(1:10).
  - “내가 **항상 너희에게 생각나게** 하려 하노라”(1:12).
  - “생각나게 하여 … **기억하게** 하려”(3:1–2).
  - ⇒ **베드로의 유언적 성격**을 가진 편지.

### 중심 사상과 기록 이유

- **중심 사상**: **부르신 이를 앎으로 계속 자라 가라** / 세상에서 썩어질 것을 피하여 **하나님의 성품에 참여하라**.
- **기록 이유**: 거짓 선생에 대한 경고 / 예수님을 아는 지식에서 자라 감.

## 본문

### 1:1–2 인사 — “앎으로”

- **발신자 비교**: 벧후 1:1 “예수 그리스도의 **종**이요 사도인 **시몬** 베드로” ↔ 벧전 1:1 “예수 그리스도의 사도 베드로” → 질문: 전서와 달리 자신을 “**종**”이라 부르는 이유는?
- 수신자: “우리 하나님과 구주 예수 그리스도의 의를 힘입어 **동일하게 보배로운 믿음**을 우리와 함께 받은 자들”(행 15:11).
- **1장의 ‘우리’는 누구인가?** — 1:3 신기한 능력으로 우리에게 주심 / 1:4 보배롭고 지극히 큰 약속을 우리에게 / **1:16 우리는 친히 본 자** / **1:18 우리가 거룩한 산에 있을 때 들은 것** → ‘우리’ = **사도들(목격자)** ↔ 3:1–2 “너희의 사도들로 말미암아”.
- **《수미쌍관》**: 1:2 “하나님과 우리 주 예수를 **앎으로** 은혜와 평강이 더욱 많을지어다” ↔ 3:17–18 “너희가 이것을 **미리 알았은즉** 삼가라 … 우리 주 되신 구주 예수 그리스도의 **은혜와 그를 아는 지식**에서 **자라 가라**”.

### 1:3–11 하나님을 아는 사람들 — 신성한 성품

- **1:3 인과**: 결과 — 신기한 능력으로 **생명과 경건에 속한 모든 것**을 주심 / 원인 — **부르신 이를 앎으로**.
- **1:4**: 우리에게 약속을 주사(원인) → 이 약속으로 너희가(결과) **세상에서 썩어질 것을 피하여**(아포퓨고: 피하다, 도망치다) **신성한 성품에 참여하는 자**(코이노노스: 동반자, 참여자)가 되게 하려 하셨느니라.
- **1:5–7 “그러므로 더욱 힘써” — 8가지 사슬**: 믿음에 **덕** / 덕에 **지식** / 지식에 **절제** / 절제에 **인내** / 인내에 **경건** / 경건에 **형제 우애** / 형제 우애에 **사랑**을 더하라 — **더하라 = 에피코레게오**(공급하라, 합창단 비용을 넉넉히 대다).
- **1:8–9**: 이런 것이 **있어** 흡족한 자는 게으르지 않고 열매 없는 자가 되지 않음 / 이런 것이 **없는** 자는 **맹인**(마 15:14)이요 옛 죄가 **깨끗하게 된 것을 잊었느니라** → 1:12–15 “생각해야 할 것들”로 이어짐.
- **1:10–11 “그러므로 형제들아 더욱 힘써”**: **부르심과 택하심을 굳게 하라** / 이것을 행하면 실족하지 않음 / 이같이 하면 **영원한 나라에 들어감을 넉넉히 주시리라** — 주시리라 = **에피코레게오**(공급하시리라).
  - ⇒ **우리가 더함(공급함)(5) ↔ 하나님이 공급하심(11)** — 같은 동사의 수미상관.

### 1:12–21 베드로의 유언 — 기억하라

- **1:12–15 “생각나게 하려 하노라”** — 장막(몸)을 벗어날 때가 임박함 → 내가 떠난 후에라도 기억하게.
- **1:16–18 “주님의 다시 오심”**: 그리스도의 **능력과 강림**은 “교묘히 만든 이야기”가 아님 → **보았고**(16) **들었다**(17–18 변화산의 소리).
- **1:19–21 성경을 사사로이 풀지 말라**:
  - 19 **더 확실한 예언** = 성경(변화산 체험보다 더 확실함, (해석)).
  - 20 경의 모든 예언은 **사사로이**(사람의 뜻으로) 풀 것이 아님.
  - 21 예언은 사람의 뜻으로 낸 것이 아니라 **성령의 감동하심을 받아 하나님께 받아 말한 것**.

### 2:1–22 거짓 선생들의 행실과 확정된 심판 — 교만, 탐욕, 방탕

- 거짓 선생들 = **1:4–7의 신성한 성품에서 실패한 사람들** — 피하지 않고(1:4), 힘쓰지 않고(1:5), 굳게 하지 않은(1:10) 결과?
- 2:1 거짓 선지자는 (구약에) **일어났었나니** / 거짓 선생들은 **있으리라** → “지금 거짓 선생들은 교회 안에 있는가, 밖에 있는가?”
- 거짓 선생을 자세히 설명하는 이유 → 1장의 **지식, 분별, 절제**를 갖추게 하려고.
- **2:1–3**:
  - **이단(하이레시스 — 분당, 자의적 선택)**을 가만히 끌어들여 **자기들을 사신 주를 부인**함 → 임박한 멸망을 스스로 취함.
  - **호색(아셀게이아 — 방탕)** → 진리의 도가 비방을 받음.
  - **탐심**과 **지어낸 말**로 너희로 이득을 삼음 → 그들의 심판은 오래전부터 지체하지 않으며 멸망은 잠들지 않음.
- **2:4–16 확정된 멸망 — 구약의 3가지 판례**:
  1. **범죄한 천사들**을 “아끼지 아니하시고”(페이도마이)(2:4; 창 6:1–2; 유 6–7 “자기 지위를 지키지 않고 처소를 떠난 천사들”).
  2. **옛 세상**을 아끼지 않으시고 의를 전하는 **노아**를 보존하심(2:5).
  3. **소돔과 고모라** — 고통당하는 **의로운 롯**을 건지심(2:6–7).
  - 2:8 하나님의 심판의 원인 — **의인 때문에**(롯이 날마다 의로운 심령에 상함을 받음).
  - **2:9 심판의 선고**: 경건한 자는 **시험에서 건지실** 줄 아시고, 불의한 자는 **형벌 아래** 두어 심판 날까지 지키실 줄 아심.
  - 2:10–11 **교만** — 주관하는 이를 멸시함, 영광 있는 자를 비방함.
  - 2:12–14 **탐욕** — 탐욕에 연단된 마음, “저주의 자식”.
  - 2:15–16 **브올의 아들 발람의 길**(민 22–24장) — **하나님의 말씀을 듣고도 자기가 하고 싶은 대로 한 선지자**(불의의 삯을 사랑함, 나귀가 책망함).
- **2:17–22 거짓 선생들의 정체와 결말**:
  - 17–19 **자유를 말하지만** 자신은 멸망의 종 — 사람은 이긴 자의 종이 됨.
  - 20–22 **나중 형편이 처음보다 더 심함** — 20 “그리스도를 앎으로 세상의 더러움을 **피한 후에** 다시” ↔ **1:4 “세상에서 썩어질 것을 피하여”**(같은 동사 — 해석) / 개가 토한 것을 도로 먹고 돼지가 씻었다가 더러운 구덩이에 누움(잠 26:11) → 질문: “**정말 그 길을 안 것일까?**”

### 3:1–16 사도의 가르침 — 심판, 종말, 말씀

- **3:1–2 말씀과 명령을 기억하라 — 진짜를 알아라**: 거룩한 선지자들이 예언한 말씀 + 사도로 말미암아 명하신 것.
- **3:3–5 말씀을 조롱하는 자들**: 말세에 조롱하는 자들이 자기 정욕을 따라 “**주께서 강림하신다는 약속이 어디 있느냐**, 조상들이 잔 후로부터 만물이 처음 창조될 때와 같이 그냥 있다” — **강림의 말씀을 부정**하고 **심판의 말씀을 잊으려** 함.
- **종말이 늦어지는 이유 (교차)**:
  - A 3:3–5 말씀을 조롱하는 자들 — 강림 부정, 심판을 잊으려 함.
  - B 3:6–7 **그때에 확실한 멸망 — 물**(홍수) / **이제** 심판과 멸망의 날까지 보존 — **불사름**.
  - A′ 3:8–9 **잊지 말라** — 주께는 하루가 천 년 같고 천 년이 하루 같음 / **약속이 더딘 것이 아님** / “**너희에 대하여 오래 참으사** 아무도 멸망하지 않고 다 회개하기에 이르기를 원하심”.
- **3:10–14 반드시 임할 주의 날, 그날을 기다리는 자들**:

| 3:10–11 **주의 날** | 3:12–14 **하나님의 날** |
|---|---|
| 도둑같이 옴, 하늘이 큰 소리로 떠나가고 | 하늘이 불에 타서 풀어지고 |
| 물질이 뜨거운 불에 풀어지고 | 물질이 뜨거운 불에 녹아짐 |
| 땅과 그중에 있는 모든 일이 **드러남** | |
| → “너희가 어떠한 사람이 되어야 마땅하냐?” **거룩한 행실과 경건함** | → **약속대로 의가 있는 곳인 새 하늘과 새 땅**을 바라봄 → **점도 없고 흠도 없이** 평강 가운데서 주 앞에 나타나기를 힘쓰라 |

# 유다서

## BRI

### 저자 — 주의 형제 유다

- **내증**:
  1. “**야고보의 형제** 유다”(1:1) → 주의 형제 야고보(`20_야고보서.md`)의 형제 = **예수님의 형제 유다**(마 13:55; 막 6:3).
  2. 성도에게 구원과 믿음의 도에 대해 **권위로** 말할 수 있는 사람(1:3).
  3. 사도들을 “**그들**”로 표현함(17–18) → **사도는 아님**.
- **예수님의 형제 유다**: 요 7:3–8 처음에는 예수님을 믿지 않음 / 행 1:14 승천 이후 오순절에 함께 모여 기도함 / 고전 9:5 **기혼자**(“주의 형제들”이 아내를 데리고 다님).

### 기록 시기·장소

- 내적 증거: 1:3 **단번에 주신 믿음**을 위해 힘써 싸우라는 권함이 필요 / 1:17–18 사도들의 가르침을 받은 사람들 / 1:4 **가만히 들어온** 사람 몇 / **벧후 2:1 베드로의 예언**(“거짓 선생들이 있으리라”)이 **성취된** 상황.
- ⇒ **60년대 후반**(“67–80”으로 범위 제시). **예루살렘**에서 쓰였을 가능성.
  - 강의안 원문은 “60년대 후반에 쓰여졌을 것이다 (67–80)”이고, 두 표현의 범위가 다름 → 기본값은 60년대 후반.

### 수신자

- 1:1 **부르심을 입은 자** — 하나님 아버지 안에서 **사랑을 얻고** 예수 그리스도를 위하여 **지키심을 입은** 자들.
- 1:3 믿음을 위해 **힘써 싸워야 하는** 상황에 놓인 자들.
- 1:5 본래 모든 사실을 알고 있으나 **다시 생각나게** 할 필요가 있는 사람들.
- 1:12 **애찬**을 행하는 사람들(“너희 애찬의 암초”).
- 1:17–18 사도들의 가르침을 받은 사람들.
- **1:9 『모세의 승천』 / 1:14 『에녹서』 인용** → **유대적 배경**을 가진 독자일 가능성이 큼. 그러나 이런 외경은 초기 교회에 **널리 보편화된 책**이었음.

### 역사적 배경 — 가만히 들어온 자들

- 내적 증거:
  - 가만히 들어온 사람(4) / 경건하지 아니하여 **하나님의 은혜를 방탕한 것으로 바꿈**(4) / **홀로 하나이신 주재 곧 우리 주 예수 그리스도를 부인**(4).
  - **꿈꾸는** 이 사람들 — 육체를 더럽히고 **권위를 업신여기며 영광을 비방**(8).
  - 이성 없는 짐승같이 본능으로 아는 그것으로 멸망(10).
  - **가인의 길, 발람의 어그러진 길, 고라의 패역**을 따라 멸망(11).
  - **너희 애찬의 암초**(12).
  - **원망**하는 자, **불만**을 토하는 자, **정욕대로** 행하는 자, 입으로 **자랑**하며 이익을 위해 **아첨**함(16).
  - **분열**을 일으키는 자, **육에 속한 자**, **성령이 없는 자**(19).
- 종합: 그리스도의 주 되심을 부인(4) / 죄악의 방종(4, 8, 16) / 권위에 대항(8, 11, 18) / 정욕대로(16, 19) / 자기 유익에만 관심(11–12, 16) / 분쟁적(19) / 불만(16) / 자랑과 아첨(16).
- ⇒ “**하나님의 은혜를 방종과 음란으로 바꿔 버렸다.**”
