## 1. 저자 — 바울

- **본문에 나타난 저자의 특징**:
  1. 유대인(9:3; 11:1), **베냐민 지파**.
  2. 사도의 직분을 받음(1:5) — **이방인의 사도**(11:13), 이방인의 구원을 위해 수고함(15:18).
  3. **예루살렘에서부터 일루리곤까지** 복음을 편만하게 전함(15:19).
  4. 마게도냐 성도들의 헌금을 예루살렘으로 가지고 감(15:25–26).
  5. 로마에 갈 계획(1:10; 15:22–24).
  6. **서바나(스페인)**에 갈 계획(15:23, 28).
  - 지도: 예루살렘 → 일루리곤 → 로마 → 서바나.
- **바울**: 직접 언급(1:1) / 1인칭(1:8, 9, 11, 12, 15, 16 …) / **더디오가 대신 기록**(16:22).

## 2. 수신자 — 로마의 성도들 (유대인 + 이방인)

- 질문: 수신자는 복음을 처음 듣는 사람들인가, 이미 믿는 사람들인가? → 1:7 “로마에서 … **성도로 부르심을 받은** 모든 자” = 이미 믿는 사람들.
- **로마에 여러 교회(가정 교회 그룹)가 있었음**(16:3–15) — 7그룹:

| 그룹 | 사람들 | 절 |
|---|---|---|
| 1 | 브리스가, 아굴라, 에배네도, 마리아, 안드로니고, 유니아 | 3–7 |
| 2 | 암블리아, 우르바노, 스다구, 아벨레 | 8–10a |
| 3 | 아리스도불로의 권속, 헤로디온 | 10b–11a |
| 4 | 나깃수의 가족 중 주 안에 있는 자 | 11b |
| 5 | 드루배나, 드루보사, 버시, 루포, 루포의 어머니 | 12–13 |
| 6 | 아순그리도, 블레곤, 허메, 바드로바, 허마와 함께 있는 형제들 | 14 |
| 7 | 빌롤로고, 율리아, 네레오와 그 자매, 올름바와 함께 있는 모든 성도 | 15 |

- 구성: **유대인**(2:17; 3:1, 9 …) + **이방인**(11:13, 30 …).

## 3. 기록 연대 — 3차 전도여행 중 (55–56년경)

- 근거: ① 마게도냐·아가야 → 예루살렘(15:25–26) / ② 예루살렘부터 일루리곤까지 편만하게 전해짐(15:19) / ③ 로마로 가려는 중(1:13, 15; 15:22) / ④ 서바나로 가려는 중(15:28).
- ∴ **3차 전도여행 중, 55–56년경** [롬].
  - ⚠ 사도행전 자료들은 로마서 기록을 **57년**(고린도 3개월, 행 20:2–3)으로 봄([연대표], [바울일대기], [심화4]) → `../자료간_차이.md`.
  - ✅ **확정: 57년 초(56/57 겨울), 고린도** → `00_확정연대표.md`

## 4. 기록 장소 — 고린도

- 근거:
  1. 3차 여행 중 마게도냐·아가야에서 예루살렘으로 가는 길(15:25–26).
  2. **가이오**가 있는 곳(16:23; 고전 1:14 — 고린도에서 세례받은 가이오).
  3. **에라스도**가 있는 곳(16:23 “성의 재무관”; 딤후 4:20 “에라스도는 고린도에 머물렀고”).
     - **1922년 고린도 극장 근처에서 발견된 라틴어 비문**: “**조영관 에라스도가 자신의 비용으로 이 도로를 포장했다**.” 조영관(*aedilis*)은 공공건물·도로·시장을 감독하는 로마의 공무 감독관. 이 라틴어는 헬라어로 ‘도시 재정 담당관’을 뜻함 → 롬 16:23 “재무관”과 연결됨. 비문 사진: “…ERASTVS … STRAVIT”.
  4. 3차 여행 중 서신을 쓰기에 충분한 시간(행 20:2–3, 헬라에서 석 달).
- ∴ **고린도**.

## 5. 역사적 배경

1. **글라우디오 칙령(49년)** — 수에토니우스, 『열두 황제 열전』(*The Twelve Caesars*):
   - 원문: *“Iudaeos impulsore Chresto adsidue tumultuantes Roma expulit.”*
   - 해석 01: “그는 **크레스토의 선동으로 끊임없이 혼란을 야기하고 있는 유대인들**을 로마에서 추방하였다.” → 소란을 일으킨 유대인만 추방됨.
   - 해석 02: “**유대인들이** 크레스토의 선동으로 끊임없이 혼란을 야기했기 때문에 **그들을** 로마에서 추방하였다.” → 유대인 전체가 추방됨.
   - 크레스토(*Chrestus*) = 그리스도(*Christus*)를 가리킨다고 보는 해석이 일반적 → 로마 회당 안에서 예수가 메시아인지를 두고 소란이 있었다는 뜻이 됨 (보충: 강의안은 두 번역만 제시하고 이 해석은 쓰지 않음).
   - 행 18:2 아굴라와 브리스길라의 추방.
2. **유대인들의 로마 복귀**(54년 클라우디우스 사망 후로 보는 것이 일반적 — 보충). 그사이 이방인 중심이 된 교회에 유대인 신자가 돌아옴 → 7번 문제의 배경 (해석).
3. **로마 제국**: 다문화 도시, 평화 시대.
4. 헬라인 / 5. 야만인(1:14 “헬라인이나 야만인이나”).
6. 유대인 — ***Religio Licita***(로마 공인 종교).
7. 3차 전도여행.

## 6. 교회의 강점

1. 믿음이 온 세상에 전파됨(1:8).
2. 선함이 가득함(15:14).
3. 모든 지식이 가득 참(15:14).
4. 서로 권함(15:14).
5. 신실한 사역자가 많음(16:3–15).
6. 순종(16:19).

## 7. 교회의 문제점

1. 유대인 ➙ 이방인 (유대인이 이방인을 판단함).
2. 이방인 ➙ 유대인 (이방인이 유대인에게 자랑함, 11:18 등 — 보충).
3. 유대인의 **음식법** 문제.
4. **안식일·절기** 준수 문제.
5. **할례** 문제.
6. **정결과 부정** 문제.
7. **세금·국가 권력** (13장).

## 8. 교회는 언제 세워졌는가?

- 가능성 1: **오순절**(행 2:10 “로마로부터 온 나그네 곧 유대인과 유대교에 들어온 사람들”)이 돌아가 세움.
- 가능성 2: 2차 전도여행 중 만난 **브리스가와 아굴라**(행 18:2).
- 바울이, 베드로가, 다른 사도들이 시작한 것 같지는 않음.

## 9. 기록 목적

- 슬라이드에 제목만 있고 내용은 비어 있음(강의 중 채우는 빈칸으로 보임). → 강의안의 결론은 **확인하지 못했음**.
- (해석, 강의안 구조에서 추론) 7번 문제(유대인–이방인 갈등)와 표제 “한마음으로 하나님께 영광”(15:5–7), 방문·서바나 선교 계획(15:22–29)이 목적과 연결될 것으로 보임.

### “바울은 누구에게 무엇을 말하고 있는가?” — 이방인 → 유대인 → 모두 패턴

| 본문 | 누구에게 | 무엇을 |
|---|---|---|
| 1:18–32 | **이방인**에게(18, 19–20, 23) | 이방인의 죄(23–32) |
| 2:1–29 | **유대인**에게(1, 17, 20) | 유대인의 죄(1–23) |
| 3:1–20 | **모두**에게(9) | 모두 죄 아래 있음(9) |
| 3:21–31 | **모두**에게(22, 29, 30) | 사람이 의롭게 되는 방법 — **믿음**(28) |
| 4:1–25 | **유대인**에게(1) | **아브라함**이 의롭게 된 방법(3, 9) |
| 5:1–21 | **모두**에게(1) | **아담 혹은 그리스도** 안에 있음(12–19) |
| 6:1–23 | **이방인**에게(1, 17) | **죄에 대하여** 죽음(2, 11) |
| 7:1–25 | **유대인**에게(1) | **율법에 대하여** 죽음(4) |
| 8:1–39 | **모두**에게(1) | 모두 **생명의 성령의 법**으로 다시 삶(2) |
| 9:1–33 | 모두에게 | 긍휼의 그릇과 진노의 그릇(22–23) |
| 10:1–21 | 모두에게 | 모두 예수를 믿음으로 구원받음(9) |
| 11:1–36 | 모두에게 | **모두에게 긍휼을 베풀기 원하심**(32) |

- (해석) 1–8장은 **이방인 → 유대인 → 모두**의 3단 리듬이 세 번 반복됨(1:18–3:20 / 3:21–5:21 / 6–8장). 청중을 번갈아 겨냥하다가 “모두”로 묶는 방식이 7번 문제(유대인–이방인 갈등)에 대한 답이 됨.
