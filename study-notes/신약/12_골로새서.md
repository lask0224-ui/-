## BRI

### 저자 — 바울 (+ 디모데)

- “바울과 디모데”(1:1). 1인칭 대명사(나는, 내가, 나도, 나와, 내게 — 1:1, 23, 24, 25, 29; 2:1, 4, 5; 4:7, 8, 10, 18). “나 바울은 이 복음의 일꾼이”(1:23b), “나 바울은 **친필로** 문안하노니”(4:18).
- 외증: 이그나티오스, 이레나이우스, 테르툴리아누스, 알렉산드리아의 클레멘스 + **무라토리 단편**(2세기 후반의 신약 정경 목록 문서).

### 수신자

- “골로새에 있는 성도들 곧 그리스도 안에서 신실한 형제들”(1:2a).
- **회람 서신**: 라오디게아와 히에라볼리에 있는 자들(4:13) / “라오디게아인의 교회에서도 읽게 하고”(4:16).

- **기록 장소: 로마**.

### 역사적 배경 — 리쿠스 계곡의 세 도시

- **골로새**(Κολοσσαί 콜롯사이, 강의안 풀이 = ‘버림’ — 어원 풀이의 근거는 확인하지 못함):
  - **에베소에서 약 200km**(지도: “120 Miles (190 km) Colossae to Ephesus”). 현재 튀르키예 남서쪽.
  - 동서 교통의 중심이라 무역이 많았음. 여러 철학과 종교가 지역 전체에 있었음. 1세기 당시에는 **작은 농업 마을 도시**.
  - **고유한 진홍색으로 염색한 양털**로 유명함. 풍부한 수원과 비옥한 토양.
  - 수많은 이방 신과 열광적인 종교 활동.
  - **BC 6세기부터 브루기아에 유대인**이 있었다는 증거. **BC 3세기 말 안티오쿠스 3세가 메소포타미아 유대인 2,000여 명을 이주시킴**(요세푸스, 『유대 고대사』 12.147–53).
  - 지도 캡션: “**There's no record Paul ever came here**”(바울이 골로새에 온 기록은 없음 → 골 2:1 “내 육신의 얼굴을 보지 못한 자들”).
  - 주변 지도: 버가모, 두아디라, 사데, 서머나, 에베소, 밀레도, 빌라델비아, 라오디게아, 히에라볼리, 비시디아 안디옥, 앗달리아.
  - 성곽 도시 그림 지도(“COLOSSAE”, 상인·장인·대학 구역 등)도 있으나 역사적 근거는 확인하지 못함(삽화로 보임).
- **히에라볼리**(Ἱεράπολις, ‘**거룩한 성읍**’): 유명한 온천과 연회장, 극장, 목욕탕 / 무역이 번성함 / **천 염색 산업** / 약효가 뛰어난 온천 / 브루기아 여신 숭배의 중심지로 시작함 / **큰 유대인 공동체**(무덤 각인, 문학 유물).
- **라오디게아**(‘백성의 정의’): 부유한 상업 도시 / **면직·모직** / 온천물로 질병 치료 / **특효 안약 ‘콜로니온’** → 의료 도시로 유명함 / **물이 부족했음** → **계 3:15–16**(“차지도 아니하고 뜨겁지도 아니하고”의 배경, 연결은 (해석): 히에라볼리의 온천수와 골로새의 찬물 사이에서 미지근한 물).
- **골로새 이단**(Colossian Heresy) 5요소:
  1. **이원론**(Dualism).
  2. **금욕주의**(Asceticism) — 2:21–23.
  3. **혼합주의**(Syncretism).
  4. **유대주의**(Judaism) — 2:11–14, 16.
  5. **천사 숭배**(Angel Worship) — 2:18.

### 교회 설립과 구성원

- **3차 전도여행 중 세워짐** — 행 19:10(에베소 사역 때 “아시아에 사는 자는 … 다 주의 말씀을 듣더라”), 설립자는 **에바브라**(1:7; 4:12; 몬 23).
- 구성원: 유대인과 이방인 모두 — 유대인, 헬라인, 브루기아인, 할례파·무할례파, 스구디아인, 종, 자유인(3:11) / 아내, 남편, 자녀, 아비, 종, 상전(3:18–4:1) / **빌레몬**(몬 1), **압비아**(몬 2), **아킵보**(골 4:17; 몬 2), **오네시모**(골 4:9; 몬 10).

### 기록 목적과 중심 주제

- 목적:
  1. 수많은 이단과 거짓 교사 때문에 흔들리는 성도들에게 **예수님 한 분만으로 충분하다**고 말해 주려고.
  2. **만물의 으뜸이신 예수 그리스도**가 누구이시며 무엇을 하셨는지 알려 주어 이단 사상에 흔들리지 않게 하려고.
- 중심 주제: **교회의 머리 되시고 만물의 으뜸 되신 예수 그리스도**.

## 본문

### 1:1–6 문안과 감사

- “하나님의 뜻으로 말미암아(**델레마** — 고전·고후·엡·골 공통) 그리스도 예수의 **사도**(**아포스톨로스**, ‘보냄 받은 자’) 된 바울”.
- “골로새에 있는 성도들 **곧**(카이 = ‘그리고’) 그리스도 안에서 신실한 형제들” → 두 주소(골로새 / 그리스도 안).
- 감사의 이유(1:3–6): 믿음과 모든 성도에 대한 사랑(4) / **하늘에 쌓아 둔 소망**(5) / 복음, 진리의 말씀을 들음(5) / 복음이 온 천하에서 **열매를 맺어 자람**(6).
- 반복: 1:6 “열매를 맺어” ↔ 1:10 “모든 선한 일에 열매를 맺게”.

### 1:7–8 에바브라

- 바울·디모데와 **함께 종 된 자**(1:7) / 그리스도의 신실한 일꾼(1:7) / 성령 안에서 골로새 교회의 사랑을 알린 자(1:8) / 그리스도 예수의 종(4:12) / 항상 애써 기도함(4:12) / 라오디게아와 히에라볼리를 위해서도 많이 수고함(4:13) → “사랑하는 에바브라에게 너희가 **배웠나니**”.

### 1:9–12 바울의 간구 (목록 7)

1. 모든 신령한 지혜와 총명에 하나님의 뜻을 아는 것으로 **채우게** 하시고(9).
2. 주께 합당하게 행하여 범사에 기쁘시게 하고(10).
3. 모든 선한 일에 **열매를 맺게** 하시며(10).
4. 하나님을 아는 것에 **자라게** 하시고(10).
5. 그의 영광의 힘을 따라 모든 능력으로 **능하게** 하시며(11).
6. 기쁨으로 모든 견딤과 오래 참음에 **이르게** 하시고(11).
7. 빛 가운데서 성도의 기업의 부분을 얻기에 **합당하게**(worthy) 하신 아버지께 **감사하게** 하시기를(12).

- 반복 “**모든**”(9, 10, 11, 15 …).

### 1:13–23 만물의 으뜸이신 예수 그리스도

- 《대조》 1:13: **흑암의 권세** ↔ **그의 사랑의 아들의 나라** → 1:14 아들 안에서 속량 곧 죄 사함.
- **《샌드위치》**: A 하나님께서 하신 일(1:13–14) / **B 만물의 으뜸 되신 예수 그리스도(1:15–18)** / A′ 하나님께서 하신 일(1:19–20).
  - 하나님이 아들 안에서 **우리에게** 하신 일: 흑암의 권세에서 건져 아들의 나라로 옮기심(13).
  - 하나님이 아들 안에서 **하나님을 위해** 하신 일: 모든 충만으로 예수 안에 거하게 하심(19) / 십자가의 피로 화평을 이루심(20).
- **그리스도 찬가 목록(1:15–20)**:
  - 보이지 않는 하나님의 **형상**(15) / 모든 피조물보다 **먼저 나신 이**(15).
  - 만물이 그에게서 창조됨(16) — **하늘과 땅의 보이는 것과 보이지 않는 것, 왕권·주권·통치자·권세**가 다 그로 말미암고 그를 위하여 창조됨(천사 숭배에 대한 답, (해석)).
  - 만물보다 먼저 계심(17) / **만물이 그 안에 함께 섰음**(17).
  - **몸인 교회의 머리**(18) / 근본 / 죽은 자들 가운데서 먼저 나신 이 → **친히 만물의 으뜸이 되려 하심**(18).
  - **모든 충만**으로 예수 안에 거하게 하심(19; 2:9) / 십자가의 피로 화평(20) / 땅과 하늘에 있는 것들이 그로 말미암아 **화목**하게 되기를 기뻐하심(20).
- 1:21–22 **전에** — 악한 행실로 멀리 떠나 마음으로 원수 되었던 너희 → **이제는** — 그의 육체의 죽음으로 화목하게 하사 거룩하고 흠 없고 책망할 것 없는 자로 세우고자 하심.
- 1:23 **‘복음’ 3번 반복**(조건): “만일 … **복음의 소망**에서 흔들리지 아니하면” / 이 복음은 천하 만민에게 전파됨 / 나 바울은 이 복음의 일꾼.
- **소망의 발전(1:5 → 1:23 → 1:27)**: 하나님의 뜻 → **하늘에 쌓아 둔 소망 → 복음의 소망 → 영광의 소망**.

### 1:24–2:5 비밀이신 예수 그리스도

- 흐름(1:24–29): 그리스도를 위하여 수고하는 바울(24) / 하나님의 말씀을 이루려 함(25) / **비밀은 너희 안에 계신 그리스도시니 곧 영광의 소망**(26–27) / 각 사람을 그리스도 안에서 **완전한 자**로 세우려 함(28) / 그리스도를 위하여 수고하는 바울(29) — 인클루지오.
- 1:24 “그리스도의 남은 고난을 내 육체에 **채우노라**” — **안타나플레로오**(서로·상호 채우다), 신약에서 골로새서에만 1번 나옴.
- 1:29 “**힘을 다하여**(아고니조마이: 투쟁하다, 싸우다) **수고하노라**(코피아오: 육체적으로 힘든 노동)”.
- 비밀(목록): 만세와 만대로부터 감추어졌던 것 / **이제는** 성도들에게 나타났고 / 비밀의 영광이 **이방인 가운데** 얼마나 풍성한지(26–27).
- 1:28 목록: 각 사람을 **권하고**, 각 사람을 **가르침은**, 각 사람을 그리스도 안에서 **완전한 자로 세우려** 함.
- **《카이아즘》 2:1–5**:
  - A 육신으로는 떠나 있으나(1)
  - B 하나님의 비밀인 그리스도를 깨닫게 하려 함(2)
  - **C 그 안에는 지혜와 지식의 모든 보화가 감추어져 있느니라(3)**
  - B′ 아무도 교묘한 말로 속이지 못하게 하려 함(4)
  - A′ 육신으로는 떠나 있으나(5)
  - 바울의 현실(목록): 받는 괴로움(1:24), 남은 고난(1:24), 힘을 다한 수고(1:29). 인물(2:4): 교묘한 말로 속이는 자.

### 2:6–23 세상의 초등학문 vs 그리스도의 할례

- **2:6–7 인과**:
  - 원인: “그러므로 너희가 그리스도 예수를 주로 받았으니”.
  - 결과: 그 안에서 **행하되**(페리파테오: 주위를 걷다, 두루 다니다, 살다) / 그 안에 **뿌리를 박으며**(흐리조오: 안정되다; 엡 3:17; 딤전 6:10) 세움을 받아 / 교훈을 받은 대로 믿음에 굳게 서서 감사함을 넘치게 하라.
- **골로새의 문제들 표**:

| 문제 | 구절 |
|---|---|
| 철학, 헛된 속임수, 사람의 전통, **세상의 초등학문** | 2:8 |
| 먹고 마시는 것, 절기, 초하루, 안식일을 이유로 비판함 | 2:16 |
| **꾸며낸 겸손, 천사 숭배**를 이유로 정죄함 | 2:18 |
| **머리를 붙들지 아니함** | 2:19 |
| 규례에 순종함 | 2:20 |
| 사람의 명령과 가르침 | 2:22 |
| 자의적 숭배, 겸손, 몸을 괴롭게 함, 육체 따르는 것을 금함 | 2:23 |

- **2:8–15 세상의 초등학문 vs 그리스도를 따름**:
  - **신성의 모든 충만이 육체로 거하심**(9; 1:19) / 모든 통치자와 권세의 **머리**(10).
  - **육의 할례 vs 그리스도의 할례**(11).
  - **십자가에서 이루신 일**: 법조문으로 쓴 증서를 지워 없애고 **십자가에 못 박으심**(14) / 통치자들과 권세들을 **무력화하여**(아페크뒤오마이: 벗어 버리다) **드러내어 구경거리로**(파레시아: 개방하다, 밝히 드러내다) 삼으심(15).
- **2:16–19 명령**: **비판하지 못하게 하라**(16: 먹고 마시는 것·절기·초하루·안식일) / **정죄하지 못하게 하라**(18: 꾸며낸 겸손·천사 숭배·자의적 숭배·몸을 괴롭게 함).
  - 정죄하다 = **카타브라뷰오**(불리하게 판정하다 — 경기 심판 용어), 신약에서 골로새서에만 나옴.
  - 인물: 교묘한 말로 속이는 자(2:4) / 철학과 헛된 속임수로 사로잡으려는 자(2:8) / 본 것을 의지하여 육신의 생각으로 헛되이 과장하는 자(2:18) = 초등학문을 따르게 하는 사람들.
  - 2:19 “온몸이 **머리**로 말미암아 마디와 힘줄로 공급함을 받고 연합하여 **하나님이 자라게 하시므로** 자라느니라”(고전 3:5–7).
- **2:20–23 수사의문문**: “어찌하여 세상에 사는 것과 같이 규례에 순종하느냐?”(20) / “사람의 명령과 가르침을 따르느냐?”(22) → 초등학문에서 그리스도와 함께 죽었거든.

### 3:1–17 위의 것을 찾고 새사람을 입으라

- **위의 것 vs 땅의 것** (목록·대조):

| 위의 것 | 땅의 것 |
|---|---|
| 긍휼, 자비, 겸손, 온유, 오래 참음을 **옷 입음**(3:12) | 음란, 부정, 사욕, 악한 정욕, 탐심(=우상숭배)(3:5) |
| 지식에까지 새롭게 하심을 입은 자(3:10) | 분함, 노여움, 악의, 비방, 부끄러운 말(3:8) |
| **새사람**을 입음(3:10) | 서로 거짓말, **옛사람**과 그 행위(3:9) |

- **‘감추어졌다’ 3번 반복**: 비밀이 만세와 만대로부터 감추어졌다가 나타남(1:26) / 지혜와 지식의 모든 보화가 감추어져 있음(2:3) / **너희 생명이 그리스도와 함께 하나님 안에 감추어졌음**(3:3).
- 감춤 → 나타남: 1:26 이제는 나타났고 / 3:1 하나님 우편에 앉아 계신 그리스도 / **3:4 그리스도께서 나타나실 그때에 너희도 그와 함께 영광 중에 나타나리라**.
- 3:5–11 땅에 있는 지체를 죽이라 — 벗어 버리라(3:8–9) / 새사람을 입었으니(3:10) / 겸손·온유·오래 참음을 옷 입고(3:12). 3:11 “그리스도는 **만유**시요 **만유 안에** 계시니라”.
- 3:12–17 이 모든 것 위에 **사랑**을 더하라 — 서로 용납하고 용서하라(12–13) / **사랑 = 온전하게 매는 띠**(14).

### 3:18–4:1 가정 규범 — 에베소서와 비교

| | 에베소서 5:22–6:9 | 골로새서 3:18–4:1 |
|---|---|---|
| 아내 | 주께 하듯 복종(5:22–24) | 남편에게 복종 — 주 안에서 마땅함(3:18) |
| 남편 | 그리스도께서 교회를 사랑하심같이(5:25–33) | 아내를 사랑하며 **괴롭게 하지 말라**(3:19) |
| 자녀 | 주 안에서 순종, 약속 있는 첫 계명(6:1–3) | 모든 일에 순종 — 주 안에서 기쁘게 하는 것(3:20) |
| 아비 | 노엽게 하지 말고 주의 교훈과 훈계로(6:4) | 노엽게 하지 말라 — **낙심할까 함이라**(3:21) |
| 종 | 두려워하고 떨며 성실한 마음으로 … 주께로부터 그대로 받음(6:5–8) | 눈가림만 하지 말고 … 주께 하듯 … **기업의 상**을 주께 받음(3:22–25) |
| 상전 | 위협을 그치라, 하늘의 상전(6:9) | **의와 공평**을 베풀라, 하늘의 상전(4:1) |

- **가족 구조 도식**: 로마·헬라는 남자들 → 여자들 → 자녀들 → 종들의 위계 / 골로새서는 그 위에 **예수(머리)**가 계심 → 모든 관계가 주님 아래서 재정의됨.

### 4:2–6 기도

- 기도를 계속하고 감사함으로 **깨어 있으라**(4:2) / 매인 중에도 **전도할 문**을 열어 달라는 중보 요청(4:3).
- **반복 “기도”**: 1:3 / 1:9 / 4:2 / 4:3 / 4:12(에바브라가 애써 기도함).

### 4:7–18 동역자와 문안

- **편지 전달자: 두기고와 오네시모**(빌레몬서와 함께 전달).
  - 두기고(행 20:4; 엡 6:21; 골 4:7; 딤후 4:12; 딛 3:12): 사랑받는 형제, 신실한 일꾼, 주 안에서 함께 종 된 자, 바울이 특별히 보낸 자. 목적 — 바울과 디모데의 사정을 알게 하고 마음을 **위로**하려고.
  - 오네시모(골 4:9; 몬 10): 신실하고 사랑받는 형제, **골로새 교회에서 온 사람**, 두기고와 함께 로마의 사정을 알림.
- 문안하는 사람들:
  - 아리스다고(행 19:29; 20:4; 27:2; 몬 24).
  - **마가(바나바의 생질)**(행 12:12, 25; 15:37, 39; 딤후 4:11; 몬 24; 벧전 5:13).
  - 예수(유스도).
  - → “**할례파지만 하나님의 나라를 위하여 함께 역사하는 자들**”(4:11).
  - 에바브라 / 누가(4:14) / 데마(4:14; 딤후 4:10).
- 라오디게아와 히에라볼리의 형제들 / **눔바와 그 집에 있는 교회**(4:15) / **아킵보**(4:17 “주 안에서 받은 직분을 삼가 이루라”).
- 적용: **만물의 으뜸이신 예수 그리스도**(1:18).

## 주석용 핵심 메모

- 핵심 대조: 흑암의 권세 ↔ 아들의 나라, 세상의 초등학문 ↔ 그리스도, 육의 할례 ↔ 그리스도의 할례, 땅의 것 ↔ 위의 것, 옛사람 ↔ 새사람.
- 이단 5요소(이원론·금욕주의·혼합주의·유대주의·천사 숭배)와 1:15–20 찬가를 짝지어 주석하기.
- 에베소서와 쌍둥이 서신(두기고, 가정 규범, 충만, 비밀).
