## 1. 정의
- **구약과 신약의 중간 시기 = “침묵기”** [중B].
- 기간: **c. BC 400(말라기 선지자) 이후 세례 요한 때까지** [중A][중B].
- 정치: **페르시아 제국 → 헬라 제국 → 로마 제국** / 문화: **페르시아 → 헬레니즘** [중B].

### 고레스 칙령 — 고레스 원통(Cyrus Cylinder) [중B]
- 원통 사진 + 본문 인용(출처: 박정수, 『고대 유대교의 터, 무늬』, 새물결플러스, 59–61쪽):
  - 17절 “그(마르둑)는 전투와 싸움도 없이 그(고레스)를 자신의 도시 바벨론으로 진군하게 하여 … 자신을 경배하지 않은 나보니두스 왕을 그의 손에 넘겨주었다.”
  - 31–32절 “… 티그리스 강 건너편 도시들에 이르기까지 **나는 거기에 거했던 신(상)들을 원래의 처소로 돌아가게 하고** 그들의 영원한 처소를 세웠다. **나는 그 거주민들 전체를 통합하여 그들의 거처를 다시 세웠다.**”
  - 33–34절 나보니두스가 바벨론으로 가져온 수메르와 아카드의 신상들을 원래 처소로.
  - 35–38절 신들이 벨과 느보 앞에서 “고레스와 그의 아들 캄비세스”의 장수를 빌게 함.
- (의미: 피정복민의 신상과 백성을 **본향으로 돌려보내는 정책** → 스 1:1–4 귀환 칙령의 역사적 배경. 성경은 이를 여호와께서 고레스의 마음을 감동시키신 것으로 해석(스 1:1; 사 44:28; 45:1) — 연결은 보충)

## 4. 헬라 제국 — 알렉산더 (BC 336–323)
- 336 마게도냐 왕 / **333 23세에 이수스 전투에서 다리우스 3세를 이김** / **323 인도 인더스강에서 돌아오다가 33세에 죽음** [중A][중B].
- **알렉산더와 헬레니즘** [중B]: 영토 그리스~인도 서부 / **동서 융합** / 정복지에 그리스인 이주 / 정복민과의 집단 결혼 추진 / **알렉산드리아 도시를 통해 헬라 문화 보급** / **헬레니즘 = 그리스 문화 + 동방 문화의 융합** / 헬레니즘 철학 / 영향.
- **제국 분열(BC 323)**:
  1. 마게도냐(/헬라) — **카산더**
  2. 드레이스/비두니아 — **리시마쿠스**
  3. 시리아/메소포타미아 — **셀류키드 왕조**, 수도 **시리아 안디옥** (→ 단 11장 “북방 왕”)
  4. 팔레스타인/이집트 — **톨레미(프톨레마이오스) 왕조**, 수도 **알렉산드리아**, **유대인들에게 관대** (→ “남방 왕”) (`../구약/27_다니엘.md` 11장과 연결)

## 5. 셀류키드 지배와 마카비 혁명
- **BC 198** 안티오쿠스 3세가 **파니온**에서 톨레미 왕조를 무찌르고 팔레스타인 차지 [중A].
- **BC 190** 안티오쿠스 3세가 **마그네시아 전투**에서 로마에 패함 [중A].
- **BC 175** 안티오쿠스 4세(에피파네스) 즉위.
- **BC 174** 대제사장 **오니아스 3세**의 죽음, 동생 **여호수아**가 대제사장 → 이름을 헬라식 **야손(Jason)**으로 바꿈. 경건한 유대인들은 야손의 정책에 반대해 **‘하시딤(Hasidim)’** 조직 [중A]. (`../구약/27_다니엘.md` 70이레 표의 “오니아스 3세(BC 170 살해)”와 연결)
- **BC 171 메넬라우스**가 뇌물을 주고 대제사장이 됨 [중A].
- **BC 168/7** 안티오쿠스 4세가 예루살렘을 유린, 성전을 더럽히고 박해, **모든 종교적 자유 폐지** → **맛다디아스의 반란** → 다섯 아들 중 **유다(‘망치’라는 뜻의 ‘마카비’)**가 이어감 [중A].
  - [중B]: **BC 168 안티오쿠스 4세 이집트 공격 → 로마의 개입으로 완전 승리가 물거품** → **BC 167년 12월** 성전을 더럽히고 핍박 → 하스모니안 가문의 제사장 맛다디아스가 안티오쿠스의 사신을 죽이고 반란. (지도: 안티오쿠스 4세의 이집트 침공 — 1·2차 원정)

## 8. 유대교의 종파

### 바리새파
- 이름: ① **‘경건한 사람들’ 혹은 ‘자비한 사람들’**(하시딤) [중A].
- ② 헬레니즘의 생활방식이 유대교와 유대 사회에 잠식해 온 것을 개탄.
- ③ 처음에는 하스모니안 왕가와 협력 → 시몬이 죽고 **힐카누스 1세 때 하시딤과 하스모니안 가가 완전히 결별** → 이때부터 **바리새인 = ‘분리된 사람들’**(히 **Perushim** / 아람 **perishayya**) — 하스모니안 가와 결별했기 때문 → **야당 같은 역할**.
  - 체제 불만은 **알렉산더 얀네우스** 때 절정 → 반란을 잔인하게 진압, **약 800명을 십자가형**, 약 8,000명이 시골로 도주.
  - **살로메 알렉산드라**(약 9년) 때 반전 — 바리새인을 영향력 있는 자리에 대거 등용 → 핍박했던 사두개인들에게 되갚음 / **산헤드린에서 확고한 자리**.
  - 헤롯이 왕이 되자 산헤드린과 대제사장 모두 권한을 대부분 잃음. 그러나 **바리새인을 향한 백성의 신망은 줄지 않음**. **AD 6년 이후 60년 동안 대제사장은 부유한 사두개파 가문**에서 선출되어 산헤드린 장악 — 바리새파는 소수였지만 백성의 신망으로 영향력 행사.
- ④ **전통, 제사, 정결 문제, 음식 먹는 법, 안식일, 십일조** 강조(눅 18:12; 마 23:23).
- ⑤ 율법을 어떻게 해석·적용할지 체계를 세움 — 후에 율법과 동등하게 여김.
- ⑥ **기록된 율법 + 구전 율법 모두 인정**.
- ⑦ 표준적인 유대교인으로 인정 / ⑧ **예정론** 강조 / ⑨ **도시 상인들의 후손**.
- ⑩ 이방인뿐 아니라 **율법을 자신들처럼 철저히 지키지 못하는 유대인들도 업신여김** — 평범한 유대인은 율법을 연구할 여유가 없어 바리새인의 해석에 의존.
- ⑪ **천사와 마귀의 존재, 부활을 믿음** (→ 행 23:6–8 바울의 산헤드린 변론 — 보충).

### 사두개파
- ① 기원 불분명 / ② 힐카누스 1세 때 하시딤과 결별한 하스모니안 가의 **새 지지·조언 그룹** → 힐카누스 이후 정치적 힘 — **여당 같은 역할**.
- ③ 전통과 장로들의 유전을 인정하지 않고 **기록된 율법(모세오경)만 인정**.
- ④ **육체의 부활, 죽음 후 심판, 천사/악마 거부** — 이것들을 유대교 전통 교리가 아니라 **조로아스터교에서 유입된 것**으로 이해했기 때문 [중A].
- ⑤ **인간의 자유 의지(선택)** 강조 / ⑥ **귀족, 지주, 부유한 가문의 후손**.

### 에세네파
- 의식상 정결에 세심 / **옷·돈·음식 공동 소유** / 희생 제사·맹세·군복무를 삼감, 노예를 두지 않음 / **바리새인보다 더 심한 예정론자** / **독신주의**(성생활 비난) / **남자 성인만 회원** / **영혼 불멸**을 믿음.

### 열심당 (셀롯)
- ① **셀롯인 시몬**(눅 6:15; 행 1:13) = **가나안인 시몬**(마 10:4; 막 3:18) — 히 **칸나임**, 아람 **칸아나야** → ‘가나안인’은 아람어 칸아나야에 헬라어 어미가 붙은 것 (지명 가나안과 무관).
- ② **아론의 손자 비느하스의 후손**을 자처 — **바알브올 사건**(민 25; 시 106:28–31)의 열심. 미쉬나 ‘산헤드린’ 9:6: 이방 여인과 결혼하는 유대인은 열심당의 공격을 조심하라.
- ③ **AD 6 아켈라오 파면, 로마 속주화 → 시리아 총독 구레뇨가 공물 산정을 위해 호적 정리** → **갈릴리 사람 유다와 사둑**: 하나님의 백성이 이방인에게 공물을 바치는 것은 하나님께 대한 반역 → **열심당 발생**(행 5:37; 막 12:14 “가이사에게 세금을 바치는 것이 옳으니이까”).
- ④ 대체로 **바리새파의 신앙 노선**을 따름. 차이: **바리새파 — 하나님의 때를 기다리며 이방의 멍에를 지는 것이 하나님의 뜻 / 열심당 — 하스모니안 왕조처럼 이방 세력에 능동적으로 대처하는 것이 하나님의 뜻**.
