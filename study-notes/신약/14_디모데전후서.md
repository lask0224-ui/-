# 디모데전서

## 이해를 위한 배경

- 살필 것: ① 디모데와 바울의 관계 ② 디모데가 사역한 **에베소**에 관한 다른 신약의 언급(사도행전, 바울서신, 요한계시록) ③ 에베소 도시 → `10_에베소서.md`.

### 디모데와 바울의 관계

- **인적 사항**(행 16:1–3): **헬라파 유대인**. **루스드라**에 거주함(바울과 바나바를 제우스와 헤르메스로 여겨 제사하려던 곳). 아버지는 헬라인, 어머니는 유대인. 루스드라와 이고니온의 믿는 자들에게 칭찬받음.
- **바울과의 만남**: 1차 전도여행 때 바울이 당한 고난과 핍박을 목격함(딤후 3:10–11; 행 14:19 — 루스드라에서 돌에 맞음) → 2차 전도여행에 동행(행 16:3).
- **바울이 부른 호칭**:
  - 나의 동역자(롬 16:21).
  - 내 사랑하고 신실한 아들(고전 4:17).
  - 그리스도 예수의 종 바울과 디모데(빌 1:1).
  - 우리 형제, 하나님의 일꾼(살전 3:2).
  - 믿음 안에서 참아들(딤전 1:2) / 아들 디모데야(1:18) / **오직 너 하나님의 사람아**(6:11).
  - 사랑하는 아들(딤후 1:2) / 내 아들아(2:1).
- **공동 발신자**: 고후 1:1 / 빌 1:1 / 골 1:1 / 살전 1:1 / 살후 1:1.
- **바울이 맡긴 사역**:
  - 2차 여행 때 실라와 함께 베뢰아에 남음(행 17:14–15).
  - 데살로니가로 가서 상황을 살피고 보고함(살전 3:6).
  - 3차 여행 때 에베소에서 마게도냐와 고린도로 편지를 전달함(행 19:22; 고전 4:17; 16:10).
  - 1차 로마 투옥 때 빌립보로 보내짐(빌 2:19).
  - **4차 전도여행 중 에베소에 남겨짐**(딤전 1:3).
- **강점**: 전에 지도받은 예언(1:18) / 외조모와 어머니 같은 거짓 없는 믿음(딤후 1:5) / 안수로 받은 은사(딤후 1:6) / 복음을 위해 연단받고 수고함(빌 2:22).
- **연약함**:
  - 사역에 대한 **두려움**(고전 16:10; 딤후 1:7).
  - 망령되고 허탄한 신화에 관심을 둠(딤전 4:6–7).
  - **연소함** 때문에 업신여김을 받음(4:12).
  - 말·행실·사랑·믿음·정절에서 본이 되지 못함(4:12).
  - 읽는 것·권하는 것·가르치는 것에 전념하지 못함(4:13).
  - 안수받을 때 예언을 통해 받은 은사를 가볍게 여김(4:14).
  - 편견 없이 공평하게 처리하지 못함(5:21).
  - 경솔한 안수(5:22) / 다른 사람의 죄에 간섭함(5:22).
  - **건강이 좋지 않음**(5:23).
  - 망령되고 헛된 말과 거짓된 지식의 반론을 피하지 못함(6:20).
  - 강의안은 명령문을 ‘연약함’의 증거로 읽음. 명령이 곧 결함의 증거인지는 해석의 여지가 있음 (해석).

### 에베소 교회의 상황

- **거짓 교사들의 활동**:
  - 다른 교훈을 가르침(1:3).
  - **신화와 끝없는 족보**에 몰두함(1:4).
  - 헛된 말에 빠져 율법의 선생이 되려 하고, 자기가 하는 말도 깨닫지 못함(1:6–7).
  - 바른 교훈을 거스르고 죄를 범함(1:9–10).
  - 경건을 **이익의 방도**로 이용하려 함(6:3–5).
- **믿음을 버린 자들**: **후메내오와 알렉산더**(1:19–20).
- **믿음을 떠나게 하는 위협**: 후일에 미혹하는 영과 귀신의 가르침을 따름(4:1).
- **극단적 금욕주의자**: 혼인을 금하고 어떤 음식물은 먹지 말라 함(4:3).
- **여자들로 인한 문제**: 단정하지 않음(2:9) / 순종하지 않음(2:11) / 남자를 주관하고 가르치려 함(2:12).
- **직분자 문제**: 감독(3:1–7) / 집사(3:8–13) / 장로(5:17–19).
- **구제 문제**: 과부 구제(5:3–16).
- **돈 문제**: 돈을 사랑함(6:10) / 부자들의 교만과 인색함(6:17–19).

## 본문

### 1:1–2 인사

- 발신자: “우리 구주 하나님과 우리의 소망이신 그리스도 예수의 **명령을 따라** 그리스도 예수의 사도 된 바울”.
- 축복: 하나님 아버지와 그리스도 예수 우리 주께로부터 **은혜와 긍휼과 평강**(바울 서신에 흔한 ‘은혜와 평강’에 **긍휼**이 더해짐 — 딤후 1:2도 같음, 보충).

### A. 1:3–20 거짓 가르침과 싸우고 선한 싸움을 하라

- **1:3–11 다른 교훈을 가르치는 자들과 그에 대한 대처(현재)**:
  - 3 “내가 마게도냐로 갈 때에 너를 권하여 에베소에 머물라 한 것은” — 남겨 둔 이유. “다른 교훈을 가르치지 말며” = **헤테로디다스칼레오**(다른 교리를 가르치다).
  - 4 “신화와 **끝없는**(아페란토스 — 딤전에만 한 번) **족보**(게네알로기아 — 혈통이나 가계 기록)에 몰두하지 말게” → 하나님의 경륜을 이루기보다 변론을 냄.
  - **5 교훈의 목적 = 청결한 마음과 선한 양심과 거짓이 없는 믿음에서 나오는 사랑**.
  - 6–7 이에서 벗어난 자들: 헛된 말, 율법의 선생이 되려 함, 자기 말을 깨닫지 못함.
  - 8–10 **율법의 순기능**: 적법하게 쓰면 선함 / 옳은 사람을 위해서가 아니라 불법한 자를 위해 세운 것.
  - 11 바울에게 맡겨진 **복되신 하나님의 영광의 복음**.
- **1:12–17 죄인 된 바울을 구원하신 복음**:
  - 12 감사 — 나를 능하게 하시고 충성되이 여겨 직분을 맡기심.
  - 13–14 **과거에 베푸신 긍휼**: 전에는 **비방자, 박해자, 폭행자** → 믿지 않을 때 알지 못하고 행함 → 은혜가 믿음과 사랑과 함께 넘치도록 풍성함.
  - **15 “미쁘다 이 말이여” — 그리스도 예수께서 죄인을 구원하시려고 세상에 임하셨다, 죄인 중에 내가 괴수니라**.
  - 16 **현재의 긍휼**: 먼저 일체 오래 참으심을 보이사 믿어 영생 얻는 자들에게 **본**이 되게.
  - 17 찬양: 영원하신 왕, 썩지 않고 보이지 않고 홀로 하나이신 하나님께 존귀와 영광.
- **1:18–20 디모데가 받아야 할 교훈**: 18 “아들 디모데야 … 전에 너를 지도한 **예언**을 따라 **선한 싸움**을 싸우며 믿음과 착한 양심을 가지라” / 19–20 이 양심을 버리고 믿음에 **파선**한 자 — 후메내오와 알렉산더를 **사탄에게 내준** 것은 훈계를 받아 신성을 모독하지 못하게 하려 함.

### B. 2:1–3:13 교회를 세우기 위한 선한 싸움의 방법과 적용

- **방법(2:1–7)**:
  - 1 “**첫째로** 권하노니” — 모든 사람을 위하여 간구·기도·도고·감사.
  - 2 대상: 임금들과 높은 지위에 있는 모든 사람 → 경건과 단정함으로 고요하고 평안한 생활.
  - 3–6 이유: 하나님 앞에 선하고 받으실 만함 / **하나님은 모든 사람이 구원을 받으며 진리를 아는 데 이르기를 원하심** / **하나님은 한 분, 중보자도 한 분 — 사람이신 그리스도 예수** / 모든 사람을 위한 대속물.
  - 7 바울 = 전파하는 자, 사도, **이방인의 스승**(참고 엡 6:19–20).
- **적용(2:8–3:13)**:
  - **남자들**(2:8): 분노와 다툼 없이 거룩한 손을 들어 기도.
  - **여자들**(2:9–10): 단정한 옷, 소박함과 정절, 땋은 머리·금·진주·값진 옷이 아니라 **선행**으로 — “하나님을 경외한다 하는 자”(**데오세베이아**: 경건, 하나님 경외).
  - **여자들**(2:11–14): 일체 순종함으로 조용히 배우라 / 가르치는 것과 남자를 주관하는 것을 허락하지 않음 / 아담이 먼저 지음받음, 하와가 속음 → 배경은 **“종교 혼합주의 거짓 가르침”**(강의안 해석 — 에베소 아데미 여사제 문화와 연결됨, `10_에베소서.md`).
  - **여자들**(2:15): 정숙함으로 믿음과 사랑과 거룩함에 거하면 “**해산함으로 구원**”.
  - **감독**(3:1–7): 선한 일을 사모함 / 책망할 것이 없음 / 한 아내의 남편 / 절제·신중·단정 / 나그네 대접 / 가르치기를 잘함 / 술을 즐기지 않음 / 돈을 사랑하지 않음 / 자기 집을 잘 다스림 / 새로 입교한 자는 안 됨(교만 → 마귀의 정죄) / 외인에게서도 선한 증거.
  - **집사**(3:8–13): 정중, 일구이언하지 않음, 술에 인 박이지 않음, 더러운 이를 탐하지 않음, 깨끗한 양심에 **믿음의 비밀** / 먼저 시험하여 보고 / **여자들(여자 집사)**도 정숙·모함하지 않음·절제·충성 / 한 아내의 남편, 집을 잘 다스림 → 아름다운 지위와 믿음의 큰 담력.

### C. 3:14–16 하나님의 집을 세워 가는 경건의 비밀

- 14–15 바울의 계획: 속히 가기를 바라나 지체하면 “**하나님의 집**에서 어떻게 행하여야 할지” 알게 하려 함 → 하나님의 집 = **살아 계신 하나님의 교회, 진리의 기둥과 터**.
- **16 “크도다 경건의 비밀이여”** — 경건 = 예수 그리스도를 믿는 믿음, 그는 어떤 분이신가 (6행 찬송):

| 구절 | 강의안 해석 |
|---|---|
| 육신으로 나타난 바 되시고 | **성육신** |
| 영으로 의롭다 하심을 받으시고 | 세례받으심과 죽으심 |
| 천사들에게 보이시고 | **부활** |
| 만국에서 전파되시고 | 복음 전파 |
| 세상에서 믿은 바 되시고 | 교회의 설립과 성장 |
| 영광 가운데서 올려지셨느니라 | **승천** |

### A′. 4:1–16 거짓 가르침을 깨우치고 진리를 가르치라

- **4:1–5 다른 교훈을 따르려는 자들(미래)** — **딤전 4:1–3 ↔ 행 20:28–30** 병치(“후일에 … 믿음에서 떠나” ↔ “내가 떠난 후에 사나운 이리가 … 여러분 중에서도 어그러진 말을 하는 사람들이 일어날 줄”) → 밀레도 예언의 성취.
  - 양심이 화인 맞은 자들, 혼인을 금하고 음식물을 금함.
  - 대처(3b–5): 음식물은 하나님이 지으신 것이니 감사함으로 받으면 버릴 것이 없음, **말씀과 기도로 거룩하여짐**.
- **4:6–10 디모데가 소망하는 약속**: 이것으로 형제를 깨우치면 **그리스도의 좋은 일꾼** / 믿음의 말씀과 좋은 교훈으로 양육받음 / 망령되고 허탄한 신화를 버리고 **경건에 이르도록 네 자신을 연단하라** / **경건은 범사에 유익하니 금생과 내생에 약속이 있음** / 살아 계신 하나님께 소망 — 모든 사람, 특히 믿는 자들의 구주.
- **4:11–16 디모데가 가르쳐야 할 교훈**: 명하고 가르치라 / **연소함으로 업신여기지 못하게** 하고 말·행실·사랑·믿음·정절에 **본**이 되라 / 내가 이를 때까지 **읽는 것과 권하는 것과 가르치는 것**에 전념하라 / 장로의 회에서 안수받을 때 예언을 통해 받은 은사를 가볍게 여기지 말라 / 성숙함을 나타내라 / 16 자신과 가르침을 살펴 계속하라 → **네 자신과 네게 듣는 자를 구원**.

### B′. 5:1–6:2 교회를 세우기 위한 가르침의 방법과 적용 — 사람을 세우는 방법

- **5:1–2**: 늙은이는 **아버지에게** 하듯 / 젊은이는 **형제에게** 하듯 / 늙은 여자는 **어머니에게** 하듯 / 젊은 여자는 온전히 깨끗함으로 **자매에게** 하듯 → 교회 = 가족.
- **과부(5:3–16)**:
  - 원칙 — **참 과부를 존대하라**. 가족 공동체의 책임 강조: 자녀나 손자가 먼저 효를 행하라. 참 과부는 하나님께 소망을 두고 주야로 간구함 / 향락을 좋아하는 자는 살았으나 죽은 자.
  - 방법 — 자기 가족을 돌보지 않으면 믿음을 배반한 자, 불신자보다 악함.
  - **명부에 올릴 자**: 60세 이상, 한 남편의 아내였던 자, 선한 행실의 증거.
  - 젊은 과부는 올리지 말 것 / 믿는 여자는 과부 친척을 스스로 도와 **교회가 짐 지지 않게** → 참 과부를 도우려고.
- **장로(5:17–20)**: 잘 다스리는 장로는 **배나 존경**, 특히 말씀과 가르침에 수고하는 이 — “곡식을 밟아 떠는 소의 입에 망을 씌우지 말라”(신 25:4; 고전 9:9).
- **디모데를 향한 명령(5:21–23)**: 하나님과 그리스도 예수와 택하심을 받은 천사들 앞에서 엄히 명함 — **편견 없이** / 경솔히 안수하지 말라 / 남의 죄에 간섭하지 말라 / 자신을 정결하게 / “**물만 마시지 말고** 위장과 자주 나는 병을 위하여 **포도주를 조금씩** 쓰라” / 죄도 선행도 결국 드러남(24–25).
- **종(6:1–2)**: 상전을 범사에 공경하라 → 하나님의 이름과 교훈이 비방받지 않게 / 믿는 상전이면 형제라고 가볍게 여기지 말고 더 잘 섬기라.

### C′. 6:3–19 하나님의 집을 세워 가는 경건의 교훈

- **6:3–10 경건의 교훈** (교차):
  - ✗ 3–5 경건의 교훈을 따르지 않음 — 경건을 **이익의 방도**로 생각함 → 다툼.
  - ○ 6–8 따름 — **자족하는 마음이 있으면 경건은 큰 이익** / 아무것도 가지고 오지 않았고 가지고 가지도 못함 / 먹을 것과 입을 것이 있으면 족한 줄 알라.
  - ✗ 9–10 따르지 않음 — 부하려 하는 자들: 시험, 올무, 욕심, 파멸 / “**돈을 사랑함이 일만 악의 뿌리**” → 믿음에서 떠남.
- **6:11–14 디모데를 향한 격려와 명령**: “**오직 너 하나님의 사람아** 이것들을 피하고 의와 경건과 믿음과 사랑과 인내와 온유를 따르라” / **믿음의 선한 싸움을 싸우라, 영생을 취하라** / 본디오 빌라도 앞에서 선한 증언을 하신 그리스도 예수 앞에서 명함 / 나타나실 때까지 흠 없이 지키라.
- **6:15–16 권면의 근거 (송영)**: 복되시고 유일하신 주권자, **만왕의 왕, 만주의 주**, 오직 그에게만 죽지 않음이 있고 가까이 가지 못할 빛에 거하시는 이.
- **6:17–19 부한 자들에게**: 마음을 높이지 말고 정함 없는 재물에 소망을 두지 말고 **하나님께** 두라 / 선을 행하고 나누어 주기를 좋아하고 너그러운 자가 되라 → 장래에 좋은 터를 쌓아 **참된 생명**을 취함.

### 6:20–21 마지막 당부와 축도

- “디모데야 … 망령되고 헛된 말과 **거짓된 지식**(그노시스)의 반론을 피함으로 네게 **부탁한 것**(파라데케, 맡긴 것)을 지키라”. 헬라어는 보충, 영지주의 배경 → `10_에베소서.md`.

## 본문

### 1:1–2:13 그리스도 예수를 부끄러워 말고 고난을 받으라

- 1:1 바울을 향한 부르심 — 하나님의 뜻으로, **그리스도 예수 안에 있는 생명의 약속대로** 사도 된 바울.
- 1:2 축복 — 사랑하는 아들에게 은혜와 **긍휼**과 평강.
- **1:3–8 디모데를 향한 격려 (원인 → 결과)**:

| A 원인 | B 결과 |
|---|---|
| 3 밤낮 간구하며 쉬지 않고 너를 생각함 | 3 청결한 양심으로 조상 적부터 섬긴 하나님께 감사 |
| 4 네 **눈물**을 생각하여 너 보기를 원함 | 4 내 기쁨이 가득하게 하려 함 |
| 5 네 속의 **거짓 없는 믿음**을 생각함 | 5 이 믿음은 먼저 외조모 **로이스**와 어머니 **유니게** 속에 있더니 네 속에도 있는 줄 확신 |
| 6 안수로 네 속에 있는 은사를 **다시 불일 듯하게** | 7 하나님이 주신 것은 두려워하는 마음이 아니요 **능력과 사랑과 절제**하는 마음 |

  - ⇒ **결과(8)**: 주를 증언함과 갇힌 나를 **부끄러워하지 말고** 하나님의 능력을 따라 **복음과 함께 고난을 받으라**.
- **1:9–10 거룩하신 소명** — **영원 전**: 우리의 행위대로가 아니라 자기의 뜻과 그리스도 예수 안에서 주신 은혜대로 / **이제는**: 구주 예수의 나타나심으로 나타남, **사망을 폐하시고 복음으로 생명과 썩지 아니할 것을 드러내심**.
- 1:11 부르심받은 자 — 복음을 위해 **선포자, 사도, 교사**로 세우심.
- **1:12 확신 (결과 ← 원인)**: 고난을 받되 부끄러워하지 않음 ← “**내가 믿는 자를 내가 알고** 내가 의탁한 것을 그날까지 그가 능히 지키실 줄 확신함이라”.
- 1:13–14 권면: 내게 들은 **바른 말**을 본받아 지키라 / 성령으로 말미암아 네게 **부탁한 아름다운 것**을 지키라.
- **1:15–18 대조**:

| 오네시보로 — 그리스도 예수를 부끄러워하지 않음 | 부겔로와 허모게네 — 부끄러워함 |
|---|---|
| 나를 자주 격려함 / 사슬에 매인 것을 부끄러워하지 않음 / 로마에서 부지런히 찾아와 만남 / 에베소에서 많이 봉사 / “주께서 그로 그날에 긍휼을 입게 하옵소서” | **아시아에 있는 모든 사람이 나를 버림** — 그중에 부겔로와 허모게네 |

- **2:1–2 제자 재생산**: 은혜 가운데서 강하고 / 많은 증인 앞에서 내게 들은 바를 **충성된 사람들**에게 부탁하라 / 그들이 또 **다른 사람들**을 가르치리라 (바울 → 디모데 → 충성된 사람들 → 다른 사람들, 4세대).
- **2:3–6 “그리스도 예수의 좋은 병사로 나와 함께 고난을 받으라” — 세 비유**:

| 병사 | 경기하는 자 | 수고하는 농부 |
|---|---|---|
| 자기 생활에 얽매이지 않음, 모집한 자를 기쁘게 하려 함 | 법대로 경기하지 않으면 관을 얻지 못함 | 수고한 농부가 곡식을 먼저 받는 것이 마땅함 |
| 고난에 참여하는 **태도** | 고난에 참여하는 **과정** | 고난에 참여한 **결과** |

- 2:7–9 기억해야 할 것: 생각해 보라, 주께서 총명을 주시리라 / **다윗의 씨로 죽은 자 가운데서 다시 살아나신 예수 그리스도** / 죄인같이 매이는 데까지 고난을 받았으나 **하나님의 말씀은 매이지 아니하니라**.
- **2:10–13 고난받는 사역자로 살아야 할 이유**: 택함받은 자들이 구원을 영원한 영광과 함께 받게 하려고 / **주님의 미쁘심** — “미쁘다 이 말이여”:
  - 우리가 주와 함께 죽었으면 → 함께 살 것.
  - 참으면 → 함께 왕 노릇 할 것.
  - 주를 부인하면 → 주도 우리를 부인하실 것.
  - (그러나) 우리는 미쁨이 없을지라도 → **주는 항상 미쁘시니 자기를 부인하실 수 없으시리라**.

### 2:14–26 경건한 말씀의 사역자로 준비

- 구조: 2:14–19 준비하고 감당할 문제 / **2:20–21 귀히 쓰는 그릇이 되어라** / 2:22–26 준비하고 감당할 문제.
- **2:14–19**:
  - 준비: 말다툼하지 말라고 엄히 명하라 / **진리의 말씀을 옳게 분별하며 부끄러울 것이 없는 일꾼**으로 인정된 자로 자신을 하나님 앞에 드리기를 힘쓰라 / 망령되고 헛된 말을 버리라.
  - 감당: 거짓 교사를 대적함 — 악성 종양처럼 퍼짐, **후메내오와 빌레도 — “부활이 이미 지나갔다”** 하여 믿음을 무너뜨림 / 그러나 **하나님의 견고한 터**는 섰으니 “주께서 자기 백성을 아신다”, “주의 이름을 부르는 자마다 불의에서 떠날지어다”(민 16:5, 26 인용 — 고라 반역 사건).
- **2:20–21 그릇**: 종류 — 금, 은, 나무, 질그릇 / 용도 — 귀하게 쓰는 것과 천하게 쓰는 것 / **자기를 깨끗하게 하면 귀히 쓰는 그릇** → 거룩하고 주인의 쓰심에 합당하며 모든 선한 일에 준비됨.
- **2:22–26**: 준비 — **청년의 정욕을 피하고** 깨끗한 마음으로 주를 부르는 자들과 함께 의·믿음·사랑·화평을 따르라 / 어리석고 무식한 변론을 버리라. 감당 — 거역하는 자를 **온유함으로 훈계**: 주의 종은 다투지 않고 온유하게 가르치며 참음 → 하나님이 회개함을 주사 진리를 알게 하시고 마귀의 올무에서 벗어나게 하실까 함.

### 3:1–4:8 경건한 말씀의 사역자로 사역함 — 3단 반복 (문제 → 해결 → 결과)

| | 3:1–12 | 3:13–4:2 | 4:3–8 |
|---|---|---|---|
| **A 문제** | 말세 — 고통하는 때, 사람들의 경건하지 않음(1–8) | 악한 사람들과 속이는 자들이 더욱 악하여짐(13) | 바른 교훈을 받지 않음, 사욕을 따를 스승을 둠, 허탄한 이야기를 따름(3–4) |
| **B 해결** | 그들의 어리석음이 드러남, **바울의 삶의 모범**(9–11) | **배우고 확신한 일에 거함, 성경(말씀)**(14–17) | 모든 일에 신중, 고난을 받으며, 전도자의 일을 하며, 네 직무를 다하라(5) |
| **C 결과** | **경건하게 살고자 하는 자는 박해를 받는다**(12) | **말씀을 전파하라**(4:1–2) | 바울의 마지막이 가까움, **의의 면류관**(6–8) |

- **3:1–8 경건하지 않은 사람들 (사역 현장)**: 자기 사랑, 돈 사랑, 자랑, 교만, 비방, 부모 거역, 감사하지 않음, 거룩하지 않음, 무정, 원통함을 풀지 않음, 모함, 절제하지 못함, 사나움, 선을 좋아하지 않음, 배신, 조급, 자만, **쾌락을 하나님보다 더 사랑함** → “**경건의 모양은 있으나 경건의 능력은 부인하니** 이 같은 자들에게서 네가 돌아서라”.
  - 구체적인 예: 남의 집에 가만히 들어가 **어리석은 여자를 유인** — 죄를 중히 지고 욕심에 끌려 항상 배우나 진리의 지식에 이르지 못함 / **얀네와 얌브레가 모세를 대적한 것같이**(출 7:11 — 바로의 술객들; 이름은 유대 전승) → 진리를 대적함.
- **3:9–11**: 경건의 모양은 오래가지 못함(어리석음이 드러남) / **바울의 삶을 기억하라** — 교훈, 행실, 의향, 믿음, 오래 참음, 사랑, 인내, 박해와 고난, **안디옥·이고니온·루스드라**에서 당한 일(디모데가 직접 목격함) → 주께서 건지심.
- **3:14–17 성경**: 배우고 확신한 일에 거하라, **누구에게서 배운 것을 앎**(로이스, 유니게, 바울) / **어려서부터 성경을 앎** → 그리스도 예수 안에 있는 믿음으로 **구원에 이르는 지혜** / **모든 성경은 하나님의 감동으로 된 것**으로 교훈·책망·바르게 함·의로 교육하기에 유익 → 하나님의 사람을 온전하게 하며 모든 선한 일을 행할 능력을 갖추게 함.
- **4:1–2 명령**: 근거 — 하나님 앞과 산 자와 죽은 자를 심판하실 그리스도 예수 앞에서, 그의 나타나심과 그의 나라를 두고 엄히 명함 / **말씀을 전파하라, 때를 얻든지 못 얻든지 항상 힘쓰라**, 범사에 오래 참음과 가르침으로 경책하며 경계하며 권하라.
- **4:3–5**: “때가 이르리니” 바른 교훈을 받지 않음, **귀가 가려워서** 사욕을 따를 스승을 많이 둠, 허탄한 이야기를 따름 → 신중하라, 고난을 받으라, **전도자의 일**을 하라, 네 직무를 다하라.
- **4:6–8 사역자의 마지막**: “**전제와 같이 내가 벌써 부어지고** 나의 떠날 시각이 가까웠도다(빌 2:17과 연결) / **선한 싸움을 싸우고 달려갈 길을 마치고 믿음을 지켰으니** / 의의 면류관이 예비되었고 의로우신 재판장이 그날에 주실 것 — 내게만 아니라 **주의 나타나심을 사모하는 모든 자**에게도”.

### 4:9–22 개인적인 부탁과 마지막 당부

- 4:9 “**너는 어서 속히 내게로 오라**”.
- **데마**(4:10): “이 세상을 사랑하여 나를 버리고 데살로니가로 갔고” — 버리다(좋은 뜻으로는 ‘남겨 놓다’, 나쁜 뜻으로는 ‘저버리다’) / 1차 로마 투옥 때의 동역자(몬 24; 골 4:14) / **골로새서에서 데마만 칭찬의 말 없이 언급됨**(골 4:14 “데마도 너희에게 문안하느니라”) → 변심의 복선 (해석).
- 그레스게는 갈라디아로 / **디도는 달마디아로**(달마디아: 티베리우스 황제가 만든 아드리아해 동쪽 산악 지역의 로마 속주 → `17_디도서.md`).
- **누가만 나와 함께 있음**(4:11) / **마가를 데리고 오라 — 그가 나의 일에 유익**(4:11; 행 15:37–39의 갈등이 회복됨, (해석)) / 두기고는 에베소에 보냄(4:12).
- 4:13 겉옷과 책, 특히 가죽 종이(보충, 강의안에는 없음).
- **알렉산더**(4:14–15): **구리 세공업자**, 해를 많이 입힘, 주께서 갚으시리니 너도 주의하라 → 딤전 1:20의 알렉산더와 같은 인물일 가능성(보충, 확인 불가).
- **4:16–18 상황과 반응 (3쌍)**:

| A 상황 | B 반응 |
|---|---|
| 처음 변명할 때 함께한 자가 하나도 없고 다 나를 버림 | 그들에게 허물을 돌리지 않기를 원함 — **긍휼** |
| 주께서 곁에 서서 힘을 주심 — 선포된 말씀이 온전히 전파되어 모든 이방인이 듣게 | **사자의 입에서 건짐을 받음** — **담대함** |
| 주께서 모든 악한 일에서 건져 내시고 천국에 들어가도록 구원하시리니 | 그에게 영광이 세세무궁토록 — **영광을 돌림** |

- 4:19–21 문안: **브리스가와 아굴라와 오네시보로의 집** / 에라스도는 고린도에 머묾 / **드로비모는 병들어 밀레도에 머묾** / 으불로, 부데, 리노, 글라우디아와 모든 형제 / “**너는 겨울 전에 어서 오라**”(4:21).
- 끝인사(4:22): “주께서 네 심령에 함께 계시기를, 은혜가 너희와 함께 있을지어다”.
