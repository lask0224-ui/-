# 성경 학습 자료 (읽기 동반서)

사용자가 준 강의 자료로 공부한 내용을 **성경을 읽으면서 옆에 두고 보는 자료**로 다시 정리한 것이다.
원자료 노트는 `../study-notes/`에 그대로 두고, 이 폴더는 **성경 읽는 순서(책 → 장)**로 재배열하고 여러 자료를 통합한다.
주석 문안 작성과 주석 PDF 제작은 이 자료가 끝난 뒤의 단계다.

## 작성 원칙 (사용자 결정, 2026-09-29)

1. **형식**: Markdown으로 먼저 만든다.
2. **내용의 근거**: 사용자가 준 강의 자료만 쓴다. 항목마다 작은 출처 표시([삿A] 등)를 붙인다. 약칭은 책별 파일 맨 끝 ‘출처’에 적는다.
3. **정리자 해석**: 강의 자료에 직접 없고 정리자(Claude)가 자료를 연결하거나 해석한 것은 **〔정리자 해석〕**으로 표시해서 넣는다(사용자 결정).
4. **연대**: 신약은 `../study-notes/신약/00_확정연대표.md`의 확정값을 쓴다. 구약에서 자료끼리 연대·견해가 다른 항목은 **두 견해를 모두** 적는다.
5. **오기**: 강의 자료의 오기(오타)는 고친 값을 바로 쓰지 않는다. 원문 그대로 두고 **〔확인 대기 ①〕** 표시를 한 뒤, 사용자에게 먼저 알린다. 사용자가 승인하면 고친 값을 넣고, 파일 끝 ‘교정 기록’에 원문과 함께 남긴다. 강의안을 우선하므로, 강의안이 그렇게 적은 이유가 보이면 **원문 유지**하고 이유를 적는다(사용자 지시 2026-09-30). 확인 대기에 올리기 전에 **PDF를 만든 사람이 왜 이렇게 적었는지 세 번 생각**하고, 그래도 고쳐야 한다고 판단되는 것만 올린다(사용자 지시 2026-10-03).
6. **빈칸**: 강의 자료에 제목만 있고 내용이 빈 항목은 **빈칸으로 둔다**(〔강의안 빈칸〕 표시). 일반적인 해석은 사용자에게 따로 알리고, 사용자가 넣기로 하면 **〔일반 해석〕** 표시로 넣는다.
7. **이전 ‘견해 차이’ 정리**: 자료에 정확하게 없는 차이는 지운다. 스가랴 환상은 두 자료 모두 ‘여덟 가지 환상’이고, 말라기는 정리 방식만 다르다(원본으로 재확인).

## 책별 파일의 틀

1. **한눈에 보기** — 표제, 중심 주제, 한 줄 흐름, 각 장의 중심 구절
2. **BRI** — 저자, 기록 시기, 수신자(독자), 역사적 배경, 기록 목적
3. **성경 속 위치** — 정경 위치, 앞뒤 책과의 연결
4. **전체 구조** — 개요표
5. **장별 읽기 가이드** — 장(단락)마다 구조(카이아즘 등)와 중심, 읽을 때 볼 점, 연결 구절
6. **주제와 연결** — 신학 주제, 인물, 다른 책과의 연결
7. **알아 둘 차이** — 자료 간 다른 견해(두 견해 모두)
8. **확인 대기 → 교정 기록** — 사용자 확인 전에는 오기 확인 요청·빈칸, 승인 후에는 원문·결정·근거를 남긴 교정 기록
9. **출처**
