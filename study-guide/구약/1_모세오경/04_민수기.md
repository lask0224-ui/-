## 2. BRI

### 민수기의 원독자 — 1세대와 2세대 비교 [민]

| | 출애굽 1세대 | 출애굽 2세대 |
|---|---|---|
| 민족으로 성장된 장소 | 애굽 | 광야 |
| 백성을 향한 하나님의 돌보심 | 바로의 박해 → **번성하고 강해짐** | 발락의 박해 → **발람이 축복함** |
| 지도자 | 모세 | 여호수아 |
| 전쟁의 경험 | 애굽 군대, 아말렉 | 아랏, 시혼, 옥, 미디안 |
| 군대로 편성 | 1차 인구 계수 | 2차 인구 계수 |
| 제사장 | 아론 | 엘르아살 |
| 하나님을 향한 태도 | 원망, 불평, 음행 | 원망, 불평, 음행 |
| 언약과 율법 | 시내산 언약 | 모압 언약 |
| 약속의 땅에 대한 선택 | **포기** | **?** |
| 결과 | 광야에서 죽음 (기업을 얻지 못함) | **?** |

- 〔정리자 해석〕 2세대의 태도 칸이 1세대와 **똑같이** 적혀 있고, 선택과 결과는 **“?”로 비워** 두었다 → 원독자(2세대)에게 “너희는 어떻게 할 것인가”를 묻는 구성.

### 중심 내용 [민]
- 이스라엘 백성들의 불순종에도 하나님의 백성들을 약속하신 가나안 땅으로 인도하시기 위해 **백성들을 훈련시키시고 이끄시는 하나님의 신실하심**

### 기록 목적 — 이 책이 쓰인 주된 이유 [민]
1. 하나님께서 출애굽 1세대와 2세대를 가나안으로 인도하시기 위해 **어떻게 준비시켰는지** 알려 주시기 위함
2. **1세대의 실패를 통해 2세대에게 교훈**하기 위함
3. 1세대의 실패에도 불구하고 하나님은 **2세대를 일으켜** 가나안 땅으로 인도하실 것을 알려 주기 위함
4. **가나안 땅에서 하나님과 함께하는 삶**을 알려 주시기 위함

### 19장 · 붉은 암송아지를 태운 재로 만든 부정을 씻는 물 [민]

**재의 제작**
- **온전하여 흠이 없고 멍에 메지 아니한 붉은 암송아지** → 엘르아살에게 → **진영 밖**으로 끌어내어 잡음
- 엘르아살이 손가락에 피를 찍어 회막 앞을 향해 **일곱 번** 뿌림 → 암소를 불사름 + **백향목, 우슬초, 홍색 실**
- 제사장과 불사른 자는 옷을 빨고 몸을 씻은 후 진영에 들어감, 저녁까지 부정
- 정결한 자가 재를 거두어 **진영 밖 정한 곳**에 둠 → 회중을 위해, 부정을 씻는 물을 위해 간직 → 그것은 **‘속죄제’**

**사용 방법**

| 부정 | 방법 | 정결하게 하지 않으면 |
|---|---|---|

- 서론 1–2: 모세와 아론의 인도로 대오를 갖추어 애굽을 떠남 / **모세가 여호와의 명령대로 그 노정을 기록**
- **A 3–4 애굽 가운데 큰 권능으로 영광을 나타내심**: 첫째 달 15일 라암셋을 떠남, 애굽 모든 사람의 목전에서 / “**여호와께서 그들의 신들에게도 벌을 주셨더라**”
  - **B 5–37 라암셋 → 호르산 (40년 여정)**: 애굽 → 라암셋 → 숙곳 → 에담 → 바알스본 → 비하히롯 → 믹돌 → 홍해 → 마라 → 엘림 → 홍해 가 → 신 광야 → 돕가 → 알루스 → 르비딤 → 시내 광야 → 기브롯핫다아와 → 하세롯 → 릿마 → 림몬베레스 → 립나 → 릿사 → 그헬라다 → 세벨 산 → 하라다 → 막헬롯 → 다핫 → 데라 → 밋가 → 하스모나 → 모세롯 → 브네야아간 → 홀하깃갓 → 욧바다 → 아브로나 → 에시온게벨 → 신 광야 가데스 → 호르산
    - **C 38–40** — **출애굽 1세대의 활약이 끝나고 2세대의 활약이 시작됨**: 애굽에서 나온 지 **40년째 5월 초하루** 제사장 아론이 호르산에서 죽음 / 가나안 남방의 아랏 왕이 이스라엘이 온다는 소식을 들음
  - **B′ 41–49 호르산 → 모압 평지 (6개월 여정)**: 호르산 → 살모나 → 부논 → 오봇 → 이예아바림 → 디본갓 → 알몬디블라다임 → 아바림 산 → 모압 평지
- **A′ 50–56 가나안에서 나타내야 할 하나님의 영광**: 요단을 건너 가나안에 들어가거든 **원주민을 몰아내고 우상을 다 깨뜨리며 산당을 다 헐고** 거주하라 / 제비 뽑고 수에 따라 기업을 / 몰아내지 아니하면 남겨 둔 자들이 **눈에 가시, 옆구리에 찌르는 것**

**34장 · 가나안 땅의 경계 — 약속으로 주어질 땅** [민]

| 방향 | 경계 |
|---|---|
| **남** | 에돔 곁 신 광야 → 동쪽 염해 끝에서 시작 → 아그랍빔 언덕 남쪽 → 신 → 가데스바네아 남쪽 → 하살아달 → 아스몬 → 애굽 시내 → 바다 |
| **서** | **대해**가 경계 |
| **북** | 대해 → 호르산 → 하맛 어귀 → 스닷 → 시브론 → 하살에난 |
| **동** | 하살에난 → 스밤 → 리블라 → 아인 동쪽 → 긴네렛 동쪽 해변 → 요단 → 염해 |

- **34:13–15 요단 서편·동편 기업 분배**: 요단 서쪽 — 제비 뽑아 받을 땅, **아홉 지파 반** / 요단 동쪽 — **르우벤, 갓, 므낫세 반** (여리고 맞은편 요단 건너 해 돋는 쪽)
- **34:16–29 땅을 나눌 지휘관**: 제사장 **엘르아살**, 눈의 아들 **여호수아**, 각 지파에서 한 지휘관 — ‘**르우벤, 갓은 제외**’

**35장 · 레위인의 성읍과 도피성** [민]
- **35:1–8 레위인이 거주할 성읍 48개**:
  - 성읍은 거처, **초장**은 가축과 짐승을 둘 곳 / 들의 크기를 정하심
  - **도피성 6곳 + 그 외 42곳**
  - 원칙: **많이 받은 자에게서는 많이, 적게 받은 자에게서는 적게** — 각기 받은 기업을 따라
- **35:9–15 도피성**:
  - 필요: 요단을 건너 가나안에 들어가거든 도피성으로 정하라
  - 이유: **부지중에 살인한 자**가 피하게 / 복수할 자에게서 피해 **회중 앞에서 판결을 받기까지 죽지 않게**
  - 설치: 여섯 성읍 — **요단 이쪽 셋, 가나안 땅 셋** / 이스라엘 자손, 타국인, 거류하는 자 모두의 도피성
- **35:16–28 고의 살인과 악의 없는 살인**:

| 고의 살인 | 악의 없는 살인 |
|---|---|
| 철·돌·나무 연장으로 죽임 → 반드시 죽임 | 악의 없이 우연히 밀침, 엿봄 없이 무엇을 던짐, 보지도 못하고 돌을 던져 죽임 |
| 미워하여 밀쳐 죽이거나, 기회를 엿보아 던져 죽이거나, 악의로 손으로 쳐 죽이면 | 회중이 판결 → 피를 보복하는 자의 손에서 건져 **도피성으로 돌려보냄** |
| **피를 보복하는 자**가 만나면 죽일 것 | **대제사장이 죽기까지** 거기 거주 / 도피성을 벗어나 보복자가 죽이면 피 흘린 죄가 없음 / 대제사장이 죽은 후 자기 땅으로 돌아감 |

- **35:29–34 살인에 대한 판결 규례**:
  - **한 증인의 증거만 따르지 말 것** (2명 이상)
  - 고의 살인자는 **생명의 속전을 받지 말고** 죽일 것
  - 도피성에 피한 자는 대제사장이 죽기 전에는 속전을 받고 돌아올 수 없음
  - **하나님이 거하시는 땅을 더럽히지 말 것**: “**피는 땅을 더럽히나니** 피 흘림을 받은 땅은 그 피를 흘리게 한 자의 피가 아니면 속함을 받을 수 없느니라 … **나 여호와는 이스라엘 자손 중에 있음이니라**”

## 6. 주제와 연결

### 1세대와 2세대 — 같은 실패, 다른 결말?
- 강의안의 비교표는 2세대의 태도도 “원망, 불평, 음행”으로 적는다 [민] — 2세대도 므리바에서 원망하고(20장), 싯딤에서 음행한다(25장, **“2세대들의 실패”**).
- 그래도 2세대는 **훈련**받는다 [민 21장 제목]: 전쟁의 훈련(호르마, 시혼, 옥) / 회개의 훈련(놋뱀) / 이동의 훈련(21:10–20) / 순종의 훈련(에돔 20:14–21)

### 여호와의 임재와 진영
- 진은 **회막을 중심으로** 사방에 [민]
- 부정한 자를 진 밖으로 — “**내가 그 진영 가운데 거함**”(5:3) [민]
- 7:89 두 그룹 사이의 목소리 / 8:1–4 등잔불 = **성막의 완성, 하나님의 임재** [민]
- 9:15–23 구름 — “**여호와의 명령을 따라**” ×7 [민]
- 35:34 “나 여호와는 이스라엘 자손 중에 있음이니라” [민]

### 중보하는 모세
- 11장 백성을 위한 간구 / 12장 미리암을 위한 간구 / **14:13–19 모세의 기도**(교차 구조의 중심 D) / **16:22 “모든 육체의 생명의 하나님이여”**(교차 구조의 중심 D) / 21:7 놋뱀 [민]

### 기업과 언약
- 기업 분배 원칙: 크기(명수대로) / 위치(제비) / **언약의 성취와 유지**(조상 지파의 이름) [민]
- 슬로브핫 딸들: “가나안 땅을 기업으로 상속받는 것은 하나님 언약의 성취이며, 하나님의 언약을 기억하고 지키는 것” [민]
- cf. 고엘 제도 룻 4:3–6 [민] → 룻기 학습 자료

### 다른 책과의 연결
- 출 25:22 ↔ 민 7:89 / 출 27:21; 40:25 ↔ 민 8:1–4 / 레 8장 ↔ 민 6:13–21 / 레 6:1–7 ↔ 민 5:5–10 / 레 21:11 ↔ 민 6:7 [민]
- 민 13:33 “메뚜기” ↔ 창세기 강의의 원독자 정체성, 6:4 네피림 [창B]
- 신 2:13–15 세렛 골짜기 — 1세대 죽음의 성취 [민]
- 민 25:11 비느하스 ↔ 삼상 2:30 [레위]

## 7. 알아 둘 차이

- 레위인 계수(3장): 강의안은 “1차 인구 계수: 22,000 (22,300)”으로 두 수를 함께 적는다 — 〔정리자 해석〕 민 3:39의 총계는 22,000이고, 종족별 합(7,500 + 8,600 + 6,200)은 22,300이다. 강의안은 두 숫자를 모두 보여 준다.
- 갓 지파 지휘관의 아버지: 1:14 “드우엘” / 2:14 “르우엘” — 성경 본문 자체에 두 표기가 있다. 강의안도 두 곳에서 각각 그대로 적었다.
