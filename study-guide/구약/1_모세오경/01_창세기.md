## 5. 장별 읽기 가이드

### 1장 — 창조: 운행하심 → 말씀하심 → 좋았더라

**1:1 태초에 하나님이 천지를 창조하시니라** [창B]
- **태초에(베레쉬트)** = “근원에”, “시작에”. 창조에 대한 설명이지만 “**어떻게** 세상이 창조되었는가”를 말하는 과학적 설명이 아니다.
  - [창A]: 요 17:5 “아버지여 **창세 전에** 내가 아버지와 함께 가졌던 영화로써 지금도 아버지와 함께 나를 영화롭게 하옵소서”
- **창조하다(바라, bara)** 〔확인 대기 ①〕: 하나님 + 바라 = **만든 이가 강조됨**. 하나님이 만드신 것 = “하늘과 땅”.

**1:2 땅이 혼돈하고 공허하며 흑암이 깊음 위에 있고 하나님의 영은 수면 위에 운행하시니라** [창B]
- **운행하다(라하프, rachaph)**: 선회하다, 배회하다, **품다**.

**1:3 하나님이 이르시되 … 그대로 되니라** — 운행하심의 결과 [창B]
- **말씀하시는 하나님, 말씀이신 예수님**(요 1:1–3)
- 혼돈·공허·흑암의 자리에 **말씀이 자리함**.

**6일의 구조** [창B]

| 틀 (혼돈을 해결) | 채움 (공허를 해결) |
|---|---|
| 1일 빛 / 어둠 | 4일 해·달·별 — 낮과 밤, 계절 |
| 2일 물 / 궁창 / 물 | 5일 새, 물고기 |
| 3일 땅 / 바다, 풀·씨 맺는 채소·열매 맺는 나무 | 6일 생물 — 가축, 기는 것, 짐승 / **사람** |

- 어둠과 물은 특별히 **비강조**, **3일째와 6일째가 강조**된다.
- 〔정리자 해석〕 강의 도표는 왼쪽(1–3일)을 ‘혼돈’, 오른쪽(4–6일)을 ‘공허’와 짝지어 보여 준다. ‘틀/채움’이라는 이름은 정리를 위해 붙인 것이다.

**1:26–31 인간의 창조 — 창조의 절정** [창B]
- “우리의 **형상**(image, ‘새기다’)을 따라 우리의 **모양**(likeness, ‘~과 비슷하다’)대로”
- **인간의 네 가지 의미**:
  1. **존귀한 인간** — 하나님의 형상 = **왕 같은 존재**
  2. **평등한 인간** — 남자와 여자를 창조하셨다
  3. **통치하는 인간** — 하나님께 **위탁받은 통치**
  4. **하나님과 교제하는 인간** — 하나님과의 특별한 관계
- 역본 비교 (1:27 새한글성경): “하나님이 사람을 자기 모습으로 창조하셨다. 하나님의 모습으로 사람을 창조하셨다. 남성과 여성으로 그들을 창조하셨다.” [창B]

**1:28 하나님이 그들에게 복을 주시며** [창B]
- **복(바라크, barak)**: 무릎을 꿇다, 축복하다, 복을 주다, 찬양하다
- 명령 다섯: **생육하라 · 번성하라 · 땅에 충만하라 · 땅을 정복하라 · 다스리라**
- 비교: **1:29–31**(먹을거리 — 채소와 열매) ↔ **9:3–4**(육식 허용, 피째 먹지 말 것)

**운행하심의 결과 — “좋았더라”(토브, TOV)** [창B]
- 태초에 창조하시니라 → **운행하심 → 말씀하심 → 좋았더라** (“보시기에 좋았더라”, “심히 좋았더라”)

### 2장 — 안식일과 에덴

**2:1–3 창조의 완성 — 안식일** [창B]
- **안식일 = 하나님과 사람이 함께하는 자리**
- 구조:
  - 1:1–31 창조 — **이름을 지어 주시는 하나님**
  - 2:1–3 **안식일**
  - 2:4–25 창조 — **이름을 지어 주는 아담**
- 2:4 “… 하늘과 땅의 내력이니 여호와 하나님이 땅과 하늘을 …” (톨레돗 ①의 표제)

**2:15 에덴에서의 인간 — 경작하며 지키게** [창B]
- **아바드**:
  - + 땅·물건 = 다스리다, 지배하다
  - + 신적 단어 = **예배하다**
  - + 사람 = 섬기다
- **샤마르**: 지키다, 보존하다, 준수하다 → **창조를 지속시키다**
- **일, 노동의 시작**

**2:16–17 명령과 3:3 하와의 기억** [창B]
- 동산 가운데: 선악을 알게 하는 나무 / 생명나무

| 아담에게 주신 명령 (2:17) | 하와의 기억 (3:3) |
|---|---|
| 선악을 알게 하는 나무의 열매는 **먹지 말라** | **먹지도 말고 만지지도 말라** |
| 먹는 날에는 **반드시 죽으리라** | **죽을까 하노라** |

- 〔정리자 해석〕 하와의 기억에서 금지는 더해지고(“만지지도”), 경고는 약해졌다(“반드시” → “~할까”). 말씀의 변형.

### 3장 — 타락의 결과와 구속 (3:8–21)

- 3:7 무화과 잎으로 가린 치마
- 3:8 **하나님이 찾아오심** — 아담을 찾아오심
- 아담의 변명(3:12) / 하와의 변명(3:13)
- 3:14–20 하나님의 심판
- **3:21 하나님이 가죽옷을 지어 입히시니라** (원복음, 가죽옷 — ‘4사건’의 타락) [창B]
- **3:20–24 추방당하는 아담**:
  - 하나님이 아담을 추방하신 이유는? → **3:22** [창B]
  - **3:23 “그의 근원이 된 땅을 갈게”** — 인간의 본질 / 하나님의 명령(‘경작하라’)은 계속된다 / **땅에서 버려지는 사건이 4장으로 이어진다** [창B]

### 4장 — 가인과 아벨

- 아벨 — 양 치는 자 / 가인 — 농사하는 자 [창B]
- **가인의 제물을 거절하신 하나님 — 왜?** 참고 구절: 레 5:11; 히 9:22; 삼상 15:22; 사 11:11–17 〔확인 대기 ②〕 [창B] 〔강의 질문 — 답은 강의안에 없음〕
- **4:7** “네가 선을 행하면 … 선을 행하지 아니하면 **죄가 문에 엎드려 있느니라** 죄가 너를 원하나 **너는 죄를 다스릴지니라**” [창B]
- 4:8 가인의 살인 — “그의 아우 아벨에게 말하고 … 우리가 들로 나가자”
- **4:9 “내가 내 아우를 지키는 자니이까”** ↔ 2:15 “지키게” [창B]

**단어로 본 실패 — “창조–운행하심–이르시되–좋았더라 … 그러나”** [창B]

| 부르심 | 실패 | 의미 |
|---|---|---|
| 1:26 “**다스리게** 하자” | 4:7 “죄를 **다스릴지니라**” | 죄가 원하는 것을 들어줌 → **살인** |
| 2:15 “**지키게**” | 4:9 “내가 **지키는 자**니이까” | **부르심의 자리를 잃어버림** |

**3장과 4장의 대응** [창B]

| | 3장 | 4장 |
|---|---|---|
| 하나님의 명령 | 선악과를 먹지 말라 | 죄를 다스리라 |
| 불순종 | 하와의 불순종, 아담의 불순종 | 가인의 불순종 |

### 4:16–5장 — 두 계보

**가인의 족보와 아담(셋)의 족보** [창B p58, 창A p62]

| 가인의 계보 (4:16–24) | 셋의 계보 (4:25–5:32) |
|---|---|
| 가인 | 아담 → **셋**(아벨을 대신해 주신 **다른 씨**, 4:25) |
| 에녹 | 에노스 — **여호와의 이름을 부름**(4:26) |
| 이랏 | 게난 |
| 므후야엘 | 마할랄렐 |
| 므드사엘 | 야렛 |
| — | **에녹 — 하나님과 동행** |
| — | 므두셀라 |
| **라멕** (아내: 야다, 실라 〔확인 대기 ③〕) | **라멕** |
| 야발 · 유발 · 두발가인 · 나아마 | **노아** — 여로와께 〔확인 대기 ③〕 은혜를 입음(6:8) → 셈 · 함 · 야벳 |

- [창A]는 양쪽에 **같은 이름(에녹, 라멕)**이 있음을 나란히 보여 준다: 가인 ↔ 아벨(셋) / 에녹 ↔ 에녹(하나님과 동행) / 라멕 ↔ 라멕 / 아들들 ↔ 노아(하나님과 동행).
- **5장의 반복 문형**: “낳고, 지내며, 낳았으며, 살고, **죽었더라**” [창A]
- **5:3 아담이 자기의 형상과 같은 아들을 낳아 — 셋** [창A] 〔정리자 해석〕 1:26 “하나님의 형상”과 대비된다.

### 6장 — 하나님의 아들들과 노아

**6:1–4 하나님의 아들들, 사람의 딸들, 네피림 — “대조? 전환!”** [창B]
- **사람의 딸들 = 가인의 자손**
- **하나님의 아들들 = 셋의 자손** — “여호와의 이름을 불렀더라”(4:26)
- 연결: **신 7:1–4** 가나안 사람과의 통혼 금지 / **민 13:33** “거기서 네피림의 후손인 아낙 자손 거인을 …”
- 〔정리자 해석〕 원독자(출애굽 세대)에게는 가나안 통혼 금지와 가나안의 거인(아낙 자손)에 대한 두려움이 이 본문과 겹쳐 읽혔을 것이다.

**토브(좋았더라) → 나함(한탄하다, 후회하다)** [창B]
- “보시기에 좋았더라” — 창세기 1장의 이미지
- 6:5 “**보시고**” / 6:12 “**보신즉**” → 한탄, 근심
- **세상을 보는 관점 = 말씀. 말씀대로 이뤄진 상태**가 “좋음”이다 → **성경이 제공하는 선과 악!**

**6:1–22 노아의 의로움** [창B]
- 〈대조〉 6:1–7 **모든 사람** 악함 ↔ 6:9–22 **한 사람** 의로움
- 〈전환〉 6:1–7 모든 사람 악함 → **6:8 은혜** → 6:9–22 한 사람 의로움
- 노아: **의인, 당대에 완전한 자, 하나님과 동행**

**은혜의 반복 (3장–8장 정리 도표)** [창B p62]
- 1:31 “보시기에 심히 좋았더라” → 3장 불순종 → 4장 불순종 → 6장 하나님의 아들들·네피림 → 6:5 한탄 → 홍수 → **8:1 기억하심**
- 그 사이사이 “**은혜? 은혜? 은혜**”: 가죽옷(3:21) / 셋과 “여호와의 이름을 불렀더라”(4:26) / 노아가 은혜를 입음(6:8)
- 〔정리자 해석〕 도표에 적힌 “은혜? 은혜? 은혜”의 세 자리를 위의 세 구절로 채운 것은 정리자의 해석이다.

### 7–9장 — 홍수와 노아 언약

**9:1–7 새로운 시작** [창B]
- 땅의 짐승, 공중의 새, 땅에 기는 모든 것, 바다의 모든 생물이 **너희를 두려워하며 무서워할 것** — 너희 손에 붙였음(9:2)
- **육식을 허용하심 — 그러나 피째 먹지 말 것**
- 1:4–5 〔확인 대기 ④〕 **생명을 존중** / 1:6 〔확인 대기 ④〕 **하나님의 형상을 존중** — “다른 사람의 피를 흘리면 …”

**9:8–17 새로운 언약 (노아 언약)** [창B]
- 9:11 다시 홍수로 멸하지 아니할 것
- 9:13 **무지개** — “**내 무지개**를 구름 속에 두었나니” / 나와 세상 사이의 **언약의 증거** / “내가 구름으로 땅을 덮을 때에 …”
- **기억하리니**(9:15) / **기억하리라**(9:16) ↔ **8:1**(하나님이 노아를 기억하사) ↔ **출 2:24**(하나님이 그 언약을 기억하사)

### 10–11장 — 바벨탑

**배열** [창B]
- 10:21–30 셈의 족보 → 10:31–32 백성이 나뉘게 됨 → **11:1–9 바벨탑 사건** → 11:10–26 셈의 족보 → 11:27–32 데라의 족보

**11:1–9 온 땅의 언어가 하나 — 바벨탑** [창B]
- 동방으로 옮기다가 **시날 평지**(메소포타미아 지역)를 만나 거주
- **벽돌로 돌을 대신**, **역청으로 진흙을 대신** — 문명의 발전
- 슬로건: “**성읍과 탑을 건설하자 / 탑 꼭대기를 하늘에 닿게 하여 / 이름을 내고 / 흩어짐을 면하자**”
- 사진: **지구라트** — 달의 여신을 섬김
- 구조:
  - 11:1 온 땅의 언어가 하나
  - 11:2–4 **사람들의 계획** — 흩어짐을 면하자
  - 11:5 하나님이 성읍과 탑을 보려고 **내려오심**
  - 11:6–8 **하나님의 계획** — 흩으셨음
  - 11:9 온 땅의 언어를 혼잡하게 하셨음
- 강의 질문: “창세기 11장의 파급, 영향, 결과는?”

**구속사적 관점에서 본 바벨탑 사건** [창B]
- 창 11장 **언어가 나뉨**
- → 창 12장 아브라함과의 언약 — **땅의 모든 민족이 “복”**
- → 이스라엘의 시작 ~ 실패의 역사
- → **행 2장 오순절 성령 강림** — 천하 만국에서 모인 사람들이 **우리의 방언으로 들음** = **새로운 이스라엘의 시작**
- → **계 7:9–17** “이 일 후에 내가 보니” (각 나라와 족속과 백성과 방언)

### 12장 — 아브라함의 소명

- **구약 = 언약, 약속** → 이스라엘의 역사 = **언약사** / 이스라엘을 통한 계획 = **구속사** → **신약 = 구속사의 정점** [창B]
- **12:1 “가라”** — 본토, 친척, 아비의 집을 떠나 **보여 줄 땅으로** [창B]
- **12:2–8 아브라함에게 하신 약속** [창B]:
  - 큰 민족을 이루게 하겠다
  - 이름을 창대하게 하겠다
  - 복이 되어 — **땅의 모든 민족이 너로 말미암아 복을 얻을 것**
  - 12:7 가나안 땅이 그의 후손의 기업이 될 것

### 12–25장 — 아브라함

| 약속 | 구절 | 설명 |

**이 약속들은 언제, 누구를 통해 성취되는가? — 원독자의 자리** [창B]
- 출애굽을 이룬 백성들은 **민족을 이뤄 주신 하나님의 성취**를 보았다.
- 시내산에서 백성들은 **조상의 하나님이 아닌 그들의 하나님**을 인정했다 — **하나님의 백성이 되었다**.
- **이제 남은 것은?** 〔정리자 해석〕 → **땅**(가나안). 강의안은 질문으로 끝난다.

**12:4–13:18 약속의 땅으로 들어간 아브라함 — 아브라함의 이동** [창B]
- 12:1–3 언약
- 12:4–5 아브라함과 함께 떠난 사람들(롯)
- 12:6–8 **세겜 땅 모래 〔확인 대기 ⑩〕 상수리나무** — “이 땅을 네 자손에게 주리라”는 약속, **제단을 쌓음** → **벧엘과 아이 사이** — 장막을 치고 제단을 쌓고 **여호와의 이름을 부름**(↔ 4:26)
- 12:9 남방(네게브)으로 옮겨 감
- 12:10–20 애굽에서의 위기
- 13:1–2 네겝브 〔확인 대기 ⑩〕로 올라감
- 13:3–4 **벧엘** — 전에 여호와의 이름을 불렀던 곳
- 13:5–13 아브라함과 롯이 갈라섬 (소돔, 고모라)
- 13:14–18 언약 — **헤브론**에 이르러 제단을 쌓음
- 강의 질문: **“세겜, 벧엘, 헤브론 … 원독자에게 주는 의미는?”**
  - 〔정리자 해석〕 가나안에 들어갈 출애굽 세대에게, 조상이 이미 제단을 쌓고 여호와의 이름을 부른 곳들이 곧 그들이 들어갈 땅임을 보여 준다.

**12:10–20 아브라함의 위기** [창B]
- 가뭄 때문에 애굽으로 감 → 애굽에서 겪은 수모 → **애굽의 재앙** → 바로가 아브라함을 내보냄: 양·소·노비·낙타를 얻음, 아내와 소유를 보내 줌
- 강의 질문: **“원독자?”**
  - 〔정리자 해석〕 애굽으로 내려감 → 재앙 → 재물을 얻고 나옴의 흐름이 원독자의 출애굽 경험과 겹친다.

**14장 — 사로잡혀 간 롯, 아브라함의 승리** [창B]
- 14:1–16 가나안 도시 국가 간의 전쟁:
  - **북방**: 시날 왕, 엘라살 왕, 엘람 왕, 고임 왕 — 대장 엘람의 그달라오메 〔확인 대기 ⑧〕
  - **염해**: 소돔 왕, 고모라 왕, 아드마 왕, 소보임 〔확인 대기 ⑧〕 왕, 소알 왕
  - **아브라함과 380명 〔확인 대기 ⑧〕의 가신들**이 단까지 쫓아가 빼앗긴 것을 되찾아 옴 — 롯의 구출
- 14:20–23 아브라함의 승리:
  - 가나안 지역 왕들의 환영
  - 소돔 왕의 제안(14:21) → 아브라함의 답(14:22)
  - **하나님의 승리를 인정하는 아브라함** — **십일조**, 소돔 왕의 제안을 **거절!**
  - → **이름이 창대하게 됨** (〔정리자 해석〕 12:2 약속의 성취)

**15장 — 아브라함 언약! (언약 예식)** [창B]
- 15:1–3 아브라함의 상속자 — **엘리에셀?**
- 15:4–7 하나님의 언약 — **네 몸에서 날 자**가 상속자
- 15:8–11 언약의 예식 준비 (쪼갠 짐승)
- 15:12 해 질 때에 — 흑암과 두려움이 임함
- **15:13–16** — **원독자들이 겪은 시간에 대한 확증과 의미**
  - 15:16 “**아모리 족속의 죄악이 아직 가득 차지 아니함이니라**”
- 15:17a 해가 져서 어두울 때에 — 연기 나는 화로와 횃불
- **15:17b 언약을 맺으시는 하나님 — 쪼갠 짐승 사이를 지나심**
- 15:18–21 하나님의 언약 — 땅을 주실 것
- 16:1– 아브라함의 상속자 — **이스마엘?**
- 〔정리자 해석〕 하나님만 쪼갠 짐승 사이를 지나가신 것은 개관의 ‘③ 약속 언약’(언약을 주도하는 쪽에만 책임)의 모습이다.

**16장 — 이스마엘의 출생** [창B]
- 아브라함 **85세**, 사래의 제안 — 하갈을 첩으로
- 당시 문화 안에서는 정상(**누지 문서**) — **그러나 하나님의 뜻 안에서는? 관습을 따라갈 것인가?**
- **16:6–14 “나를 살피시는 살아 계신 이”** — 하갈의 고백(16:13), **브엘라해로이**
  - 강의 질문: 도망하던 여종 하갈이 다시 아브라함의 집으로 돌아간 이유는?
  - **이스마엘 = “하나님이 들으셨다”**
  - 16:12 “그가 사람 중에 **들나귀** 같이 되리니 …”

**17장 — 열국의 아비가, 어미가 될지라** [창B]
- **16:16–17:1 이스마엘이 태어난 후 13년이 지남**
- **17:1 “너는 내 앞에서 행하여 완전하라”** = **13년의 시간을 설명하는 명령**
  - 하갈을 통해 약속을 이루려 하는 아브라함 — **BUT 하나님은 완전하라고 요구하신다**
  - “행하다” = **할라크** — 창 3:8(동산에 “거니시는” 하나님)과 같은 단어
- 17:3 아브람이 엎드렸더니
- 17:4–6 **아브람 → 아브라함** — 민족의 아버지가 될 것, 왕들이 …
- **17:7–14 할례를 명하심** (너희 중 남자는 다)
  - **아브라함과 하나님의 언약을 자손과의 언약으로 연결** — “네 후손의 하나님이 될 것”
  - 17:14 할례를 받지 않으면 — “**내 언약을 배반**하였음이니라”
- 17:15–16 **사래 → 사라** — 민족의 어머니가 되게, 왕이 날 것
- 17:17–18 아브라함이 엎드려 웃으며 — “**이스마엘이나 하나님 앞에서 살기를 원하나이다**”
- 17:23–29 할례를 행함

**18장 — 하나님이 나누신 마음, 소돔을 향한 기도** [창B]
- 18:16–19 하나님이 나누신 마음:
  - 18:17 하나님의 계획을 아브라함에게 나눠 주심
  - **18:18 ↔ 출 19:6** (제사장 나라)
  - **〈하나님이 아브라함을 택하신 이유?〉 18:19 “여호와의 도를 지켜 의와 공도를 행하게 하려고 그를 택하였나니”**
- 18:20–33 소돔과 고모라를 향한 기도:
  - **50 → 45 → 40 → 30 → 20 → 10 (진전)**
  - **소돔성의 죄가 강조됨** — 의인 10명이 없다!
  - **하나님의 인내** — 끝까지 기다려 주시는 하나님
  - 의인 롯(벧후 2:6–8)
  - 강의 질문: “원독자?”

**19장 — 죄악이 극에 달한 성읍** [창B]
- 18:20–21 하나님이 알고 싶으셨던 것 — 소돔과 고모라의 죄악
- 19:1–11 **증명되는 소돔성의 죄악**
  - 19:8 딸을 대신 내보내려는 롯 — “**의롭다는 사람의 수준**”
  - 겔 16:49–50 소돔의 죄악
- 19:12–28 소돔, 고모라의 멸망
  - **19:12 “네게 속한 자가 있느냐?”** — 사위나 자녀나 네게 속한 자들은 다 성 밖으로 ↔ **수 6:25 라합의 경우**
- 19:30–38 롯의 실수 — 롯의 두 딸의 공모
  - 19:32 “우리가 우리 아버지에게 (　　)을 마시게 하고 (　　)하여 우리 아버지로 말미암아 (　　)을 이어가자” 〔강의안 빈칸〕
  - 19:37–38 큰딸 → **모압** — 모압 자손의 조상 / 작은딸 → **벤암미** — 암몬 자손의 조상

**20–21장 — 이삭의 출생** [창B]
- 20:1–18 아브라함의 위기:
  - 그랄 왕 **아비멜렉** / **아브라함의 실수**(반복)
  - 하나님: “**그는 선지자라**” / 아비멜렉의 집 태를 닫으심
  - 아비멜렉의 추궁 → 아브라함의 대답 → **아브라함의 기도** → 아비멜렉의 집 태가 열림
  - 결과: 제물을 얻음
- 21:1–8 **이삭의 출생** — 아브라함 100세
- 21:9–21 이스마엘이 쫓겨남
- 21:22–34 아비멜렉과 군대 장관 비골의 방문과 언약:
  - **아비멜렉이 아브라함을 인정함** — ‘언약의 관계’(평등 언약, 창 21:22)
  - **브엘세바 = 맹세의 우물**

**22장 — 독자 이삭을 번제로 드리라** [창B]
- **아브라함을 시험하시려고**
- **모리아산 = 예루살렘**
- 22:5 “**우리가** 너희에게 돌아오리라”
- 22:8 “**번제할 어린 양은 하나님이 자기를 위하여 준비하시리라**” — **아브라함이 경험한 하나님!**
- 22:16–19 “네 아들 네 독자라도 아끼지 아니하였은즉”

**23–25장 — 이삭의 결혼, 아브라함의 죽음** [창B]
- **23장 사라의 죽음** (127세):
  - **막벨라 굴**을 매장지로 구입 — 헷 족속, 곧 기럇아르바 / **은 400세겔**
  - 23:19 “**마므레는 곧 헤브론**이더라”
  - [창A] 막벨라 굴 ↔ **여호수아 14장**(헤브론)
- **24:1–67 이삭의 신붓감의 조건** (24:3–6):
  - **가나안 여자는 안 된다**
  - 내 고향 내 족속에게서
  - **아들을 고향으로 돌아가게 하지 말라**
  - 강의 질문: **원독자에게 주는 의미는?** 함께 볼 곳:
    - 26:34–35 에서의 결혼 — 리브가의 마음
    - 27:46 에서의 아내들 — 리브가의 마음 (“재미 없음”)
    - 28:6–9 야곱의 아내 / 이스마엘의 아내
- **25:1–11 자기 열조에게로 돌아감** — 25:9 **이삭과 이스마엘**이 막벨라 굴에 장사함

### 25–36장 — 이삭과 야곱

**25:19–34 야곱과 에서의 출생, 장자권** [창B]
- **25:23 하나님의 말씀 — “큰 자가 어린 자를 섬기리라”**
- 리브가의 입장 / 이삭의 입장
- 25:27–34 장자의 명분을 판 에서 — **장자의 명분이 에서에서 야곱으로**
- 이어지는 흐름 [창B p110]: 26:34–35 헷 여인과 결혼한 에서(리브가의 근심) → 27:1–45 장자의 축복을 받은 야곱(?) → 27:46 에서의 아내들(리브가의 재미 없음). 그리고 “26:1–33 ?” — 이 사이에 26장이 놓인 이유를 묻는다.

**26장 — 이삭의 언약: “이삭 파워^^”** [창B]

| 그랄에서 — 나타나심 | 브엘세바에서 — 나타나심 |
|---|---|
| 2–5 **조건적 축복** — 그랄을 떠나지 말라 → 축복 | 23–24 **무조건적인 축복** |
| 6 이삭이 명령을 지킴 | 25 이삭의 **예배** — 이름을 부름 |
| 7–11 사라 〔확인 대기 ⑨〕가 보호받음 | 26–31 이삭, 아비멜렉과 **조약** — 보호 |
| 12–16 이삭의 번성 — 농작물과 짐승 | 32–33 이삭의 번성 — **우물**이 터짐: 그랄 골짜기 → 에섹, 싯나, 르호봇 → **브엘세바** |

- [창A]의 26장 구조:
  - 26:1–2 흉년, 아비멜렉에게 / “애굽으로 내려가지 말라”
  - 26:3–5 아브라함의 언약을 계승 — “이 땅에 거류하면”
  - 26:6–11 리브가를 누이라 속임 — 안전을 보장받음
  - 26:12–22 이삭이 하나님의 축복을 받음 (우물을 파는 이삭)
  - 26:23–25 이삭에게 언약 — 제단을 쌓고 여호와의 이름을 부름
  - 26:26–33 아비멜렉이 계약을 요청함
  - 26:34–35 “에서” — 이삭과 리브가의 근심
- 〔정리자 해석〕 아브라함의 이야기(애굽으로 내려간 위기, 아내를 누이라 함, 아비멜렉과 언약, 브엘세바 우물)가 이삭에게서 되풀이된다.

**27–28장 — 야곱의 속임수와 축복** [창B]
- 27장: 이삭의 마음 / 리브가의 마음 — “**하나님의 말씀(25:23)을 기억하고 있는 리브가**” / 이삭의 상태는?
- 28장 이삭이 한 야곱의 축복:
  - **속임을 통한 축복**(27:28–29)
  - **도망갈 때의 축복**(28:3–4) — “아내를 …”

**야곱의 언약 — 벧엘 이야기** [창B]
- **28장 벧엘의 하나님** — 28:20–22 야곱의 서원
- 29–31장 야곱과 라반의 딸들 (31:7–13 [창B] / 31:11–13 [창A])
- 32–33장 에서를 만나러 가는 준비 — **하나님과의 씨름** — 에서를 만남 → 세겜에 머무름
- 34장 디나의 치욕
- **35장 “벧엘로 올라가자”** — 야곱의 언약
- 〔정리자 해석〕 28장 벧엘과 35장 벧엘이 야곱 이야기를 감싼다.

### 37–50장 — 요셉

**요셉 이야기** [창B]
- 37:1–11 요셉의 꿈
- 37:12–24 형제들의 계획과 루우벤 〔확인 대기 ⑩〕의 계획
- 37:25–28 **유다의 계획**
- 37:30–36
- **38장 유다와 다말 / 39장 요셉과 보디발의 아내** (두 장을 나란히 둠)

**애굽에서의 요셉** [창B]

- 40–41장 꿈을 해석하는 요셉
- **사브낫바네아**(41:45)
- 애굽에서의 형제들(42–46장)

**마무리** [창B]

- **49장 야곱의 유언 ↔ 신 33장 모세의 축복**

## 6. 주제와 연결

### 단어로 읽는 창세기 [창B]
- **다스리다**: 1:26 ↔ 4:7
- **지키다**: 2:15 ↔ 4:9
- **토브(좋았더라) ↔ 나함(한탄)**: 1장 ↔ 6:5–6
- **기억하다**: 8:1; 9:15–16; 출 2:24
- **할라크(행하다, 거닐다)**: 3:8 ↔ 17:1
- **여호와의 이름을 부르다**: 4:26; 12:8; 13:4; 26:25

### 은혜와 찾아오시는 하나님 [창B]
- 찾아오심: 아담을 찾으심(3:8) / 아벨을 찾으심(4장)
- 은혜: 가죽옷(3:21) / 셋, 다른 씨(4:25) / 노아가 은혜를 입음(6:8) / 기억하심(8:1)

### 원독자(출애굽 세대)에게 주는 연결 [창B]
- 네피림(6:4) ↔ 민 13:33
- 하나님의 아들들과 사람의 딸들(6:2) ↔ 신 7:1–4 통혼 금지
- 이삭의 신부 조건(24:3–6) ↔ 에서의 헷 여인 결혼(26:34–35; 27:46)
- 15:13–16 400년 → 원독자가 겪은 시간
- 세겜·벧엘·헤브론 → 들어갈 땅
- 19:12 롯의 가족 ↔ 수 6:25 라합

### 언약 [창A][창B]
- 창세기의 언약 종류: 평등 언약(21:22; 26:26; 31:43) / 약속 언약(12:1–3; 15장)
- 노아 언약(9:8–17) / 아브라함 언약(12; 15; 17; 22장) / 이삭의 언약(26장) / 야곱의 언약(28; 35장)

### 다른 성경과의 연결
- 창 11장 ↔ 행 2장 ↔ 계 7:9–17 [창B]
- 18:18 ↔ 출 19:6 [창B]
- 막벨라 굴 ↔ 수 14장 [창A]
- 49장 ↔ 신 33장 [창B]
- 〔다른 강의 자료〕 사도행전 강의에도 창 11장(바벨탑)과 행 2장(오순절)의 대조가 있다 → 사도행전 학습 자료
