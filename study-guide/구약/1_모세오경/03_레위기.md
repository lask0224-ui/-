## 2. BRI

### 저자 — “여호와께서 모세에게 말씀하셨다” [레A]
- ① **모세 개인에게** 하나님이 말씀하심 **×33번** (1:1; 4:1; 5:14; 6:1, 8, 19, 24; 7:22, 28; 8:1 …)
- ② **모세와 아론에게** 말씀하심 **×5번** (10:3; 11:1; 13:1; 14:33; 15:1)
  - 〔정리자 해석〕 10:3은 여호와께서 직접 두 사람에게 하신 말씀이 아니라 **모세가 여호와의 말씀을 아론에게 전한** 구절이다(“이는 여호와의 말씀이라”). 강의안은 이것도 ‘모세와 아론이 함께 받은 말씀’으로 센 것으로 보인다. 여호와께서 아론에게만 직접 하신 말씀은 10:8.
- ③ **시내산에서 모세에게** 명령하심 **×2번** (7:38; 27:34)

### 기록 시기 [레A]
- 레위기 안에서 장소는 **시내산**이다 — “시내산에서 모세에게”(7:38; 25:1; 26:46; 27:34)
- 이스라엘 백성이 시내산에 있었던 때는 언제인가?

|---|---|---|

- 레위기는 성막을 완성한 BC 1445년 1월 1일 이후에 **회막에서 모세를 부르시고 말씀하셨다**(1:1).
- 백성은 BC 1445년 2월 20일 시내산에서 광야로 출발했다(민 10:11, 13).
- **좁게는**: 성막이 완공된 후 시내산에서 광야로 행진하기까지 — **BC 1445.1.1 ~ 1445.2.20** (시내산에서 **1달 20일, 약 50여 일**의 일정을 기록한 책)
- **넓게는**: 성막이 완공된 후 모세가 죽기 전(신 34:5–8, 가나안 입성 직전 모압 땅, **BC 1406**) — **BC 1445 ~ 1406**

- **원독자**: 출애굽 2세대 이스라엘 백성

## 3. 핵심 개념 — 거룩 · 정결 · 부정

### 세 단어 [레A]

| 단어 | 원어 (스트롱 번호) | 뜻 |
|---|---|---|
| **거룩** | 코데쉬 (6944) | 분리됨, 거룩함, 신성함 |
| **정결** | 타호르 (2889) | 순수한(pure), 깨끗한(clean) |
| **부정** | 타메 (2931) | 더러운, 부정한 |

- [레A] 도식의 설명: “**제사와 규례를 통해**” / “**죄와 부정한 것 접촉**”

### 거룩–정결–부정 도식 [레B p2 — 이미지로 확인]

```
      거 룩 (Holy)

      정 결 (Clean)
   (죄) ↓        ↑ (제사)
      부 정 (Unclean)
```

- **정결 → (죄) → 부정** / **부정 → (제사) → 정결**. 거룩은 맨 위에 있고, 도식에서는 거룩으로 가는 화살표가 따로 없다.

### 거룩–정결–부정에 따른 구분 [레B] (11–16장 도입)

| 구분 | 거룩 | 정결 | 부정 쪽 |
|---|---|---|---|
| **장소** | 지성소 | 성소 | 뜰 |
| **사람** | 대제사장 | 제사장, 레위인 | 일반 백성 |
| **시간** | 안식일, 대속죄일 | 절기 | 월삭(초하루) |

## Ⅰ. 제사의 규례 (1–7장)

### 두 관점 — 백성의 관점과 제사장의 관점 [레B][레A]

| 백성의 관점 (1:1–6:7) — “이스라엘 자손에게”(1:2; 4:2) | 제사장의 관점 (6:8–7:38) — “아론과 그의 자손에게”(6:9, 20, 25) |
|---|---|
| 1. 번제 (1장) | 1. 번제 (6:8–13) |
| 2. 소제 (2장) | 2. 소제 (6:14–18) + 위임식 소제 (6:19–23) |
| 3. **화목제** (3장) | 3. 속죄제 (6:24–30) |
| 4. 속죄제 (4:1–5:13) | 4. 속건제 (7:1–10) |
| 5. 속건제 (5:14–6:7) | 5. **화목제** (7:11–36) |
| | 6. 요약 (7:37–38) |

- 〔정리자 해석〕 화목제의 자리가 다르다 — 백성의 관점에서는 세 번째, 제사장의 관점에서는 맨 마지막.
- [레A]의 대조표에서 속죄제 처리를 “6:23–30”으로 적었으나 6:23은 소제에 속하므로 **6:24–30**으로 고쳤다(교정 기록 ②).

### 제사 방식 [레A]

| 방식 | 뜻 | 설명 |
|---|---|---|
| **화제** | 제물을 불로 태워 드리는 제사 | |
| **요제** | 흔들어 드림 | 제사장이 제물의 **가슴이나 곡식단**을 여호와 앞에서 흔들어 바친 후 **제사장의 소득**으로 돌림 |
| **거제** | 들어서 드림 | 제사장이 여호와 앞에서 제물을 **높이 들어** 바친 후 제사장의 소득이 됨 (든 뒷다리, 든 넓적다리) |
| **전제** | 포도주를 붓는 것 | 포도주나 독주를 다른 제물과 함께 부어 드림 |

### 2장 · 소제 (히 **민하**, 4503 — 선물, 공물, 제물)

**소제의 의미(목적)** [레B]
- ① **선물**(조공)
- ② **감사**(신 26:9–10)
- ③ **실용적 목적**(2:3, 10, 16 — 제사장의 몫)

**드리는 방법** [레B][레A]

| 종류 | 본문 | 재료 |
|---|---|---|
| 익히지 않은 곡식의 소제 | 2:1–3 | 고운 가루 + 유향 |
| 익힌 곡식의 소제 | 2:4–10 | 화덕에 구운 것: 고운 가루 + 기름 / 철판에 부친 것: 고운 가루 + 기름 + 조각 / 냄비에 삶은 것: 고운 가루 + 기름 |
| 첫 이삭의 소제 | 2:11–12 (2:14–16 [레A]) | 볶아 찧은 것: 첫 이삭(보리, 밀) + 기름 + 유향 |

- [레A] 소제에 관한 제사 규정(2:11–16): 누룩과 꿀(2:11–12) / 소금을 치는 것(2:13) / 첫 이삭의 소제(2:14–16)

**함께 드리는 것과 드리지 못하는 것** [레B]

| 반드시 들어가야 할 것 | 들어가도 되는 것 | 반드시 들어가지 말 것 |
|---|---|---|
| **소금** | 기름과 유향 | **누룩과 꿀** |

**소제를 드리는 7가지 경우** [레B]
1. 상번제 (민 28:3–8)
2. 절기 때 (레 23:12–13; 민 28:9–10)
3. 온 회중이 부지중에 범죄했을 때 (민 15:24, 속죄제와 함께)
4. 나실인 서원 기간이 끝났을 때 (민 6:14–17, 번제·속죄제·화목제와 함께)
5. 감사제를 드릴 때 (레 7:11–14)
6. 제사장 임직식 때 (레 8:26–28)
7. 의심이 있을 경우 (민 5:15)

**신약에서의 소제** [레B]: 눅 17:11–14(레 14:19–20), 행 21:22–26(민 6:14) / 소제를 드리는 시간 (왕상 18:36; 왕하 3:20)

**제사장 관점의 소제 (6:14–23)** [레A]
- 소제의 규례(6:14–18): 기념물로 드리고 **남은 부분은 제사장의 몫** / 남은 부분은 제사장이 **회막 뜰, 거룩한 곳에서** 먹어야 함(6:16)
- **제사장의 위임식 소제(6:19–23)**: 온전히 불사르도록 규정(6:22–23)

### 3장 · 화목제 (히 **쉘라밈** / 셸렘, 8002 — 화목제, 감사제)

## 6. 제사장 직분의 변화 [레위] (1쪽 도표 — 이미지로 확인)

```
레위 ─┬─ 게르손
      ├─ 고핫(그핫) ─┬─ 아므람 ─┬─ 모세
      │              │          ├─ 미리암
      │              │          └─ 아론 ─┬─ 나답  ┐ 레 10:1–7 죽음
      │              │                   ├─ 아비후 ┘
      │              │                   ├─ 엘르아살 → 비느하스 → 사독   (대상 6:4–8)
      │              │                   └─ 이다말 → 엘리 → 아히멜렉      (대상 24:3)
      │              ├─ 이스할 ─────────────────────→ 사무엘              (대상 6:34–38)
      │              ├─ 헤브론
      │              └─ 웃시엘 (웃시엘의 아들 엘리사반 = 고핫 사람의 지휘관, 민 3:30)
      └─ 므라리
```

- **민 25:11** 비느하스 — **영원한 제사장의 언약** ↔ **삼상 2:30** (엘리 가문에 대한 선언)
- **레위인의 직무 기간: 30–50세** (민 4:3, 23, 30, 35, 47)
- 직무:
  - 아론의 아들들 = 제사장 직분
  - 게르손 = 휘장들 (민 3:25–26)
  - 므라리 = 널판·기둥·받침 (민 3:36–37)
  - 고핫 = 성소 기물 (민 3:31–32)
- 관리: 엘르아살 (민 4:16) / 이다말 (민 4:28, 33)
- 〔정리자 해석〕 도표는 제사장 직분이 이다말 계열(엘리 → 아히멜렉)에서 엘르아살 계열(비느하스 → 사독)로 옮겨 가는 흐름을 보여 준다(민 25:11 ↔ 삼상 2:30). **사무엘**은 아론 계열이 아니라 **이스할 계열의 레위인**으로 그려져 있다. 사무엘상·열왕기(사독의 등장, 아비아달 파면 왕상 2:27)에서 다시 확인할 것.

- 제사장의 임무: 거룩한 것과 속된 것, 부정한 것과 정한 것을 **분별**하고 **가르침**(10:10–11) [레A][레B]

### 출애굽기와의 연결
- 출 40:17 성막 완성 → 레 1:1 “그가 부르시고” [레A]
- 출 29장 위임식 명령 → 레 8장 실행 [출B][레B]
- 출 32장 금송아지 ↔ 레 9장 아론의 첫 제사가 수송아지 [레B]
- 출애굽기의 언약 조약 형식 ↔ 레 18장 “언약 문서 양식” [레B]
