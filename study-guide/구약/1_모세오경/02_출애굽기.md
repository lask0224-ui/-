## 2. BRI

### 저자 [출A]
- **오경 안의 증거**: ① 출 17:14; 34:27 “기록하라” ② 출 24:4; 민 33:2 “모세가 … 기록하고” ③ 신 31:9, 24 “모세가 이 율법을 써서”
- **다른 성경의 증거**: ① 수 1:7–8 ② 왕상 2:3; 단 9:11; 대하 25:4 “모세의 율법에 기록된 대로” ③ 스 6:18; 느 13:1 “모세의 책”
- **신약의 증거**: 요 7:19 — 예수님도 모세가 저자임을 말씀하신다.
- **모세 저작의 증거**: ① 모세의 교육 정도(행 7:22; 출 2장) ② 이스라엘 역사에 대한 지식(출 2:8–10) ③ 당시의 종교·법·문화·언어 ④ 오경의 용어 — 날씨·기후·나무·동물·지리 등 / 하나님의 이름 / 예루살렘에 대한 언급 (〔정리자 해석〕 [창B]는 같은 항목을 “예루살렘에 대한 언급이 **없음**”으로 적음 — [출A]는 항목 제목만 적고 강의에서 설명한 것으로 보임)
- 오경 전체의 저자 논의(문서설 비판)는 `00_모세오경_개관.md` 6절.

### 연대 [출A][출B]
- **내적 증거**: 출애굽 이후 40년의 광야 생활(16:35) / 모세가 명령대로 기록(17:14) / 모세의 죽음(신 34:5)
- **출애굽 연대의 두 견해**(왕상 6:1): ① **이른 연대 1400년대** ② 늦은 연대 1200년대 [출A]
  - **이른 연대를 지지하는 고고학 증거** [출A]: ① **아마르나 문서**(BC 1400년경의 문서들) ② **메르넵타 비석**(BC 1200년경) — 사진 속 비문: “Israel is wasted, its seed is not” (1205 BC)
  - **이른 연대를 반대하는 주장** [출A]: ① 하비루가 히브리인이라는 증거의 불충분 ② 비돔과 라암셋 국고성의 건축(1:11)
- **시간적 배경** [출B]:
  - 출애굽 **BC 1446** = **애굽 18왕조(BC 1570–1320)** 시기
  - 야곱 130세(창 47:9)에 애굽 거주 시작 **BC 1876** (창 46:29)
  - 왕상 6:1 출애굽 후 480년 = **BC 966**
  - 애굽 거주 기간 **430년**(12:40–41)

### 구약의 절대 연도 측정 [출B]
1. 니느웨 터에서 **앗수르 연대기가 적힌 토판**(앗수르 왕 목록)이 발견되었다.
2. **Eponym List (신앗수르)**: 기록을 모아 보면 체계적이며, 수백 년간의 연대가 상당 부분 연결되어 있다. 다만 앗수르 자체의 연도 명칭을 써서 서기력으로 바꿀 단서가 필요했다.
3. 토판의 연대기 중 **일식이 일어난 사건과 정확한 날짜**의 기록이 발견되었다.
4. 이 기간의 앗수르 기록 가운데 **성경 연대기와 일치하는 사건**이 발견되면, 그 성경 사건에 서기력을 쓸 수 있다.
5. **가장 확실한 접점: 산헤립** — 앗수르 기록에 따르면 BC 701년 산헤립이 힛타이트 땅(아람)으로 세 번째 진출한 뒤 남유다를 침략해 라기스까지 무너뜨리고 예루살렘을 포위했다. 앗수르 기록: “**유대인 히스기야를 그의 왕도인 예루살렘에 새장과 같이 가두었다**.” 이 사건은 **히스기야 14년**(왕하 18:13–16) = **BC 701년**.

**7:8–13 바로 앞에서 이적을 행함** [출B]

## Division 2 — 언약을 맺으시는 하나님 (19–24장)

### Section 5 · 19:1–24:18 시내산 언약

**19장 — 언약을 위한 준비** [출A]

**언약의 종류** [출B][출A]
- **평등 언약**: 결혼, 평화 조약 — 당사자가 평등, 쌍방 책임 → 아브라함과 아비멜렉(창 21:22), 이삭과 아비멜렉(26:26), 야곱과 라반(31:43)
- **약속 언약 (은혜 언약)**: 일방적인 약속, 언약을 주도하는 사람에게만 책임 → 아브라함에게 주신 약속(창 12:1–3), **횃불 언약(창 15:1–21)**, 새 언약(렘 31:31–34)
- **종주권 조약**: 조약의 일반 형태 / 왕과 신하, 종주국과 봉신국, 지주와 소작농 사이의 불평등 언약 / **강자는 약자를 보호해 주는 대가로 약자는 강자에게 절대 복종** / 불순종하면 저주, 순종하면 축복 → 시내산 언약(출애굽기), 모압 언약(신명기)
- **종주권 조약의 발견** [출B]: **히타이트 조약** BC 1500–1200년경 — 히타이트의 투드할리야 4세 / **함무라비 법전** BC 1750년경

**성막의 배치** [출A][출B 도면]

   - 29:43 “내가 거기서 이스라엘 자손을 만나리니 내 영광으로 말미암아 회막이 거룩하게 될지라”
   - 30:6 “그 속죄소는 **내가 너와 만날 곳**이며”

| 목적 | 지극히 거룩한 것으로 구별, 접촉하는 것은 거룩 / 제사장 직분 | 지극히 거룩함 |
| 금지 | 사람 몸에 붓지 말라, 같은 방법으로 만들지 말라 → 백성 중에서 끊어짐 | 너희를 위해 만들지 말라, 냄새를 맡으려고 만드는 자는 끊어짐 |

- **브살렐과 오홀리압 (31:1–11 하나님이 지명 ↔ 35:30–36:1 모세가 부름)**:
  - **브살렐**: 유다 지파, 훌의 손자, 우리의 아들 / **하나님의 영을 충만하게** — 지혜·총명·지식·재주로 금·은·놋 세공, 보석을 깎아 물림, 나무를 새김
  - **오홀리압**: 단 지파, 아히사막의 아들 / 조각·세공, 청·자·홍색 실과 베 실로 수놓는 일, 짜는 일
  - “지혜로운 마음이 있는 모든 자에게 내가 지혜를 주어 … 다 만들게 할지니”
- **안식일 (31:12–17 ↔ 35:1–3)**:
  - 31장: “너희는 **나의 안식일**을 지키라” / 이유 — **나와 너희 사이의 대대의 표징**, “**너희를 거룩하게 하는 여호와**인 줄 알게 함” / 어기면 죽일지며, 일하는 자는 끊어짐 / **영원한 언약**, **영원한 표징** — 엿새 동안 천지를 창조하고 일곱째 날에 쉬었음이니라
  - 35장: 엿새 동안 일하고 일곱째 날은 거룩한 날 / **처소에서 불도 피우지 말라**
  - 〔정리자 해석〕 강의안의 배열을 따라가면, 성막 명령 단락은 **안식일로 끝나고(31장)** 성막 제작 단락은 **안식일로 시작한다(35장)**. 그 사이에 금송아지 사건(32–34장)이 있다.

### Section 7 · 32:1–34:35 금송아지 반역과 언약 갱신

**32:1–35 금송아지 반역 — 언약의 깨어짐** 《교차》 [출B]
- **A 1–14**:
  - 백성이 금송아지를 만들어 달라 요구, 아론이 만듦
  - 하나님의 진노 — 이스라엘이 **간음**을 행함
  - **모세의 중보기도 — 진멸되지 않도록**
- **B 15–20** ← 중심:
  - **모세가 두 증거판을 던져 깨뜨림 — 언약의 깨어짐**
    - 판 양면에 글자가 있음, **판은 하나님이 만드신 것, 글자는 하나님이 쓰신 것**
    - 여호수아: “진중에서 **싸우는 소리**가 나나이다” ↔ 모세: “승전가도 패하여 부르짖는 소리도 아니요 **노래하는 소리**로다”
    - 송아지와 춤추는 것을 보고 크게 노하여 판들을 산 아래로 던져 깨뜨림
  - **모세가 금송아지를 부숨** — 불살라 가루로 만들어 물에 뿌려 마시게 함
- **A′ 21–35**:
  - 아론의 변명
  - 모세의 분노 — 이스라엘이 **방자하게** 행함
  - **모세의 중보기도 — 용서받을 수 있도록**
- [출A] 32–34장 《교차》: **A** 언약 파괴 — 금송아지 사건(32장) / **B** 모세의 중재(33장) / **A′** 언약 재체결(34:1–28) / **B′** 모세의 얼굴(34:29–35)

**33:1–34:35 언약 갱신 — 같은 조약 형식으로 다시** [출B]

| 형식 | 언약 갱신 |
|---|---|
| 전문 — 언약의 화자 소개 | 33:1a |
| 역사적 서문 — 역사적 관계, 종주의 우호적 행동, 중재자 모세의 역할, 당사자들의 대면 | 33:1b–34:9 |
| 조항 — 종주의 의무(보호), 봉신의 의무(충성) | 34:10–26 |
| 낭독·기록·보관 | 34:27–28 |
| 증인 — 아론과 회중의 모든 어른, 온 이스라엘 | 34:29–33 |
| **축복 — 언약 관계의 회복, 하나님의 임재를 전달** | 34:34–35 |

- 〔정리자 해석〕 19–24장의 시내산 언약과 같은 틀로 언약이 **다시** 맺어진다. 축복의 자리에 모세의 빛나는 얼굴(하나님의 임재를 전달)이 놓인다.

### Section 8 · 35:1–40:38 성막의 제작과 완성

**반복 — “여호와께서 모세에게 명령하신 대로” (×18)** [출A]

**39:32–43 성막과 기구, 제사장의 옷 완성** [출B]
- 32 이스라엘 자손이 회막의 모든 역사를 마치되 **명령하신 대로 다 행하고**
- 33–41 만든 성막과 기구, 제사장의 옷의 목록
- 42 명령하신 대로 모든 역사를 마치매
- **43 모세가 그 마친 모든 것을 본즉 명령하신 대로 되었으므로 모세가 그들에게 축복하였더라**

**40:1–33 성막을 세울 것을 명령하고 실행** [출B]

| 40:1–16 명령 | 40:17–33 실행 |
|---|---|
| 시간: **첫째 달 초하루**에 성막 곧 회막을 세우고 | 시간: **둘째 해 첫째 달 그달 초하루**에 성막을 세우니라 |
| 증거궤를 들여놓고 휘장으로 가리고 | 받침 → 널판·띠·기둥 → 막을 펴고 덮개를 덮음 |
| 상을 들여놓고 물품을 진설 | 증거판을 궤 속에, 채를 꿰고, 속죄소를 궤 위에 → 궤를 성막에 들이고 휘장으로 가림 |
| 등잔대를 들여놓아 불을 켜고 | 성막 **북쪽**, 휘장 밖에 상 → 떡을 진설 |
| 금 향단을 증거궤 앞에 | 성막 **남쪽**에 등잔대, 상과 마주 → 불을 켬 |
| 성막 문에 휘장 | 금 향단을 휘장 앞에 → 향을 사름 |
| 번제단을 성막 문 앞에 | 성막 문에 휘장 |
| 물두멍을 회막과 제단 사이에 | 번제단을 성막 문 앞에 → 번제와 소제 |
| 뜰 주위에 포장, 뜰 문에 휘장 | 물두멍 → 모세·아론·아들들이 수족을 씻음 |
| 관유를 발라 거룩하게 | 성막과 제단 주위에 포장, 뜰 문에 휘장 |
| 아론과 아들들을 씻기고 옷을 입히고 기름을 부어 제사장 직분을 | (각 단계마다) “**여호와께서 모세에게 명령하신 대로 되니라**” |

**40:34–38 하나님의 임재로 가득한 성막** [출B]
- **성막 가운데 가득한 하나님의 영광**: 모세가 역사를 마치니 → **구름이 회막에 덮이고 여호와의 영광이 성막에 충만** → 모세가 회막에 들어갈 수 없었음
- **하나님의 영광이 백성을 인도하심**: 구름이 떠오르면 행진, 떠오르지 않으면 머묾 / **낮에는 여호와의 구름, 밤에는 불** — 온 족속이 모든 행진하는 길에서 눈으로 보았더라
- [출A] 35–40장 요약: ① 반복 “명령하신 대로”(×18) ② **여호와의 영광이 성막에 충만**(40:34–38)
