# 시편 (Psalms) — 150편

> **구분**: 구약 · 시가서 (히브리 성경에서는 **성문서 — 지혜서**) · **강의**: 시편 유인물 [시], 2025 더바미 시편 [시25], 시편 1~3권 연구 [시1-3]
> **이름**: 시편(詩篇) = 시로 된 책, 시의 묶음 / **테힐림**(תהילים) = **찬양, 찬양집** [시25]

> **자료의 관계** 〔정리자 해석〕: [시25]와 [시1-3]은 2025년의 같은 강의 세트로 보인다(파일 날짜와 내용) — [시25]는 시편 전체, [시1-3]은 제1–3권의 상세. [시]는 히브리 시의 특징과 분류를 다룬 이전 유인물이다. 두 자료가 다르게 적은 곳은 ‘8. 알아 둘 차이’에 둘 다 적었다.

## 1. 한눈에 보기

### 시편의 특징 [시25]
1. **시로 된 노래책** — 시편: 시로 된 책 / 테힐림: 찬양, 찬양집
2. **인간 감정의 총체적 표현** — 논리적 연관성 / **정서적 연관성(솔직한 감정)**
3. **예배에 사용됨** — 성전 예배와 묵상에 널리 사용됨, 탁월성이 입증되어 왔고 입증되고 있다
4. **역사와 믿음**이 담겨 있음
5. **하나님에 대한 바른 정보**를 제공

### 주신 말씀 vs 드려진 말씀 [시25]
- 시편은 사람이 하나님께 **드린** 말이다. 그런데 어떻게 하나님이 **주신** 말씀이 되는가?
- → **확증된 진리, 말씀을 살아내는 과정에 대한 기록**

### 1) 시편의 저자 — 누구의 시인가?

**표제어** [시25]
- 150편 중 **116편**이 표제를 가진다 — 시의 **저자**가 누구인지 / 어떤 **상황**을 배경으로 삼는지 / 시의 **음악적 성격**은 어떤지
- 116개의 표제 중 **73개**가 주목하는 것 — **다윗의 시편** “미즈모르 레다비드”(מזמור לדוד)
- 표제에 이름을 올린 사람들: 모세, 솔로몬, 아삽, 고라 자손, 헤만, 에단
- “다윗의 시편” = “**다윗의 삶, 그의 길**”

**시편 저자의 이정표 — 다윗** [시25]
- **대상 6:31–32** “언약궤가 평안을 얻었을 때에 다윗이 여호와의 성전에서 **찬송하는 직분**을 맡긴 자들은 … 솔로몬이 예루살렘에서 여호와의 성전을 세울 때까지 그들이 회막 앞에서 찬송하는 일을 행하되 그 계열대로 직무를 행하였더라” — 에단 · 헤만 · 아삽
- **암 9:11** “그날에 내가 **다윗의 무너진 장막**을 일으키고 그것들의 틈을 막으며 그 허물어진 것을 일으켜서 옛적과 같이 세우고”

### 5) 문학적 방법 — 히브리 시의 특징
- **1753년** 이전에는 히브리 시를 알지 못했다 — 그래서 성경은 오직 산문으로만 여겨졌다. 1753년에 히브리 시를 처음 발견한 이후 **RSV 성경이 처음으로 히브리 시를 시답게 번역**하였다 [시].
- 1753년 히브리 문학의 “시” 발견: **운율이 아닌 대구(평행)법** [시25]
- 분량: [시] 66권 가운데 **5권(레위기, 룻기, 에스더, 학개, 말라기)을 제외한 61권**에 시가 포함 / [시25] **신구약 성경의 2/3 이상**을 차지
- **은유**(metapher 〔확인 대기 ⑩〕) = mata(초월) + phrein(운반하다) 〔확인 대기 ⑩〕 → “**사실을 뛰어넘어 느낌으로**” — 시 23: 하나님이라는 “사실”을 목자라는 “느낌”으로 [시25]
- 형식을 지님: **답관체, 아크로스틱** [시25]

### 3) 주제·양식(문학 장르)에 따른 7분류 [시][시25]
- 150편은 크게 두 부분 — **찬양/감사**와 **탄식/탄원** → 세부 7분류: **찬양시, 감사시, 탄원시(신뢰시), 제왕시, 시온시, 예배 의식시, 지혜시**
- **시를 이해하기 위한 접근** [시25]
  - **내용** = 시를 **느끼는** 것 = 시의 **생김새**
  - **형식** = 시를 **생각하는** 것 = 시의 **쓰임새** — **균형이 필요함**
  - 시의 형식(유형)은 **시어를 담는 그릇**의 역활 〔확인 대기 ⑩〕

#### ① 찬양시 (테힐라) [시][시25]
- 하나님의 **창조와 구원, 주권과 은혜**를 찬양하고 선포
- 시편: 8, 19(:1–6), 29, 33, 47, 65, 66, 78, 93, 95–100, 103–106, 111, 113–114, 117, 134–136, 145–150
- **짜임새** [시25]

| | 부분 | 내용 |

| 1 | **찬양하라는 요청 — 부름** | 대상, 방법, 태도 |

| 3 | **찬양하라는 요청 — 결론** | 서두의 반복, 소원, 확신의 표현 |

  - 부름의 형태: 공동체를 소집하는 **명령형 복수**가 대다수 (회중적) / **할렐루야로 시작**(111–113, 117, 135, 146–150) / **부름 없이 바로 내용**(8, 19, 65, 67, 114, 145)

- 34편 “아비멜렉(아기스??)” — 강의자 자신의 물음(표제의 아비멜렉과 사무엘서의 아기스).
- [시1-3] p1 “시편 **14**~24편의 구성” — 표는 15편부터. 14편을 앞 묶음의 끝이자 이 묶음의 문턱으로 함께 적었을 수 있어 그대로.
- [시1-3] p1 “… 후손이 그를 섬길 것 … (22:**17**~31)” — 인용 내용은 22:30–31이지만, 17절부터 탄식이 찬양으로 넘어가는 전체 흐름을 범위로 잡았을 수 있어 그대로.
- [시1-3] p5 “36:**6–10**”과 [시25] “36:**5–9**” — 찬양 단락의 범위를 다르게 본 두 견해로 ‘알아 둘 차이’에.
- [시25] p55 제5권 표 C′와 A′가 모두 “145” — 145편이 알파벳시이자 찬양시라 두 자리에 모두 적은 것으로 읽힘.
- [시] p6 찬양의 이유 “하나님의 성품 **(1, 23)**” — 무엇을 가리키는지 근거를 찾지 못했다(1편은 찬양시가 아님). 고칠 값을 제안할 근거도 없어 그대로 둠.

- “요낫 엘렘 르호김”의 “테레빈”([시] 테레빔, [시25] 테레핀) — 음역 차이.
