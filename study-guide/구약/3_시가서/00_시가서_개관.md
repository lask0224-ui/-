# 시가서 개관 — 욥기 ~ 아가 (5권)

> 시가서 5권을 읽기 전에 보는 안내. 시가서 전체를 다룬 강의 자료는 따로 없어서, 각 책 강의(욥기·시편·잠언·전도서·아가)와 다른 강의의 성경 구분표에서 시가서 전체에 해당하는 내용을 모았다. 책별 자세한 내용은 아래 ‘7. 책별 파일’을 따라간다.

---

## 1. 시가서란 무엇인가

### 이름과 범위
- **시가서** = 욥기, 시편, 잠언, 전도서, 아가 — 헬라어 성경과 대다수 번역 성경의 구분이다 [소개관]
- 히브리 성경에는 ‘시가서’라는 묶음이 없다. 다섯 권은 셋째 부분 **성문서(케투빔)** 안에 나뉘어 있다 → 2. 성경 안의 자리
- 〔정리자 해석〕 ‘시가서’는 **형식**(시로 쓰였다)에 따른 이름이고, 히브리 성경의 ‘지혜서’·‘오축’은 **성격과 쓰임**(지혜 / 절기에 읽음)에 따른 이름이다. 같은 책을 다른 기준으로 묶은 것이다.

### 시는 시가서에만 있지 않다
- 1753년에 히브리 문학의 “시”가 발견되기 전에는 성경을 산문으로만 여겼다. 히브리 시의 핵심은 **운율이 아니라 대구(평행)법**이다 [시][시25]
- 66권 가운데 **레위기, 룻기, 에스더, 학개, 말라기 5권을 뺀 61권**에 시가 들어 있다 [시] / 시는 **신구약 성경의 2/3 이상**을 차지한다 [시25]
- 〔정리자 해석〕 그러니 시가서는 ‘시가 있는 책’이 아니라 ‘**시가 중심인 책**’이다. 욥기도 앞뒤(1–2장, 42:7–17)는 산문이다 [욥].

## 2. 성경 안의 자리 — 두 가지 분류

| 책 | 히브리 성경(타낙) — 케투빔 안의 자리 | 절기 [아][단] | 기독교 구약 |
|---|---|---|---|
| 욥기 | **지혜서** | — | 시가서 |
| 시편 | **지혜서** — 케투빔의 첫 책 | — | 시가서 |
| 잠언 | **지혜서** | — | 시가서 |
| 전도서 | **오축(메길롯)** | **초막절(장막절)** | 시가서 |
| 아가 | **오축(메길롯)** | **유월절** | 시가서 |

### 강의마다 다른 이름과 순서 (모두 적음)

| 자료 | 케투빔의 첫 묶음 | 나머지 묶음 |
|---|---|---|
| [시25] | **지혜서**: 시편, 잠언, 욥기 | 오축 / 인물(다니엘, 에스라, 느헤미야) / 역사 정리(역대기) |
| [잠] [아] | **지혜서**: 시편 / 욥기 / 잠언 | 오축 / 인물 / 역사정리 |
| [단] | **지혜서**: 욥기, 시편, 잠언 | 오축(절기와 함께) / 그 외 책 |
| [대] | **시가서**: 시편, 잠언, 욥기 | 5축 / 적용(다니엘, 에스라, 느헤미야, 역대기) |

- 세 권의 **이름**(지혜서 / 시가서)과 **순서**가 자료마다 다르다. 어느 자료든 욥기·시편·잠언을 한 묶음, 전도서·아가를 오축에 둔다는 점은 같다.
- [잠][아]는 타낙의 세 부분에 기능을 짝지었다 — **토라 = 원리 / 선지서 = 교육 / 성문서 = 적용** [잠][아]. [아]는 다른 그림에서 **모세오경 = 법 / 선지서 = 예언 / 지혜문학 = 적용**으로도 나타냈다 [아].
- **눅 24:44** “모세의 율법과 선지자의 글과 **시편**” — 유대인 성경의 세 부분을 가리키는 근거로 여러 강의가 인용한다 [시25][아][대]
  - 〔정리자 해석〕 여기서 ‘시편’은 성문서 전체를 대표한다 — 성문서의 첫 책이 시편이기 때문이다.
- 오축과 절기: 아가 — 유월절 / 룻기 — 오순절 / 애가 — 성전 파괴(아브월 9일) / 전도서 — 초막절(장막절) / 에스더 — 부림절 [아][단]. [아]는 이것이 “**주후 15세기 이후 드러난 ‘유대교’의 전통**”이라는 주의점을 덧붙인다.
- 시가서를 예언서 앞에 둔다(사용자 결정) → `../../README.md`

## 3. 시가서를 읽는 법 — 히브리 시와 지혜 문학

### 히브리 시 — 대구법 [시][시25]

| 대구법 | 정의 | 예 |
|---|---|---|
| **동의적** | 같은 내용을 **다른 말로** 되풀이 | 시 27:1 “여호와는 나의 빛이요 나의 구원이시니” |
| **대조적(반의)** | 둘째 행이 **반대로** 말함 | 시 1:6; 잠 10:1; 15:1 |
| **종합적** | 둘째 행이 **보충·확장·결과·이유**로 이어 감 | 시 1:2; 37:4 |
| **상징적** | 상징·이미지를 먼저 주고 뜻으로 풂 | 시 42:1; 103:13 |
| **점층적(상승)** | 반복하며 **절정**에 이름 | 시 29:1–2; 24:7–10 |
| **교차** | 순서를 **대칭**으로 배열 | 사 6:10 |

- 그 밖의 시적 표현: **후렴**(시 136편 26절에 26번), **수미쌍관**(시 8; 103; 104; 118) [시][시25], **은유** — “사실을 뛰어넘어 느낌으로”(시 23) [시25], **답관체(아크로스틱)** [시25]
- 자세한 것 → `19_시편.md` ‘문학적 방법’

### 다섯 권에 나타나는 문학 형식

| 책 | 형식 | 강의안 |
|---|---|---|
| 욥기 | **산문(1–2장) – 시(3:1–42:6) – 산문(42:7–17)** / 지혜서 | [욥] |
| 시편 | **150편의 시** — 다섯 권, 7분류(찬양·감사·탄원(신뢰)·제왕·시온·예배 의식·지혜시) | [시][시25] |
| 잠언 | **마샬**(비교) — 훈계·가르침(1–9장) / 짧은 격언(10–31장) / **답관체**(31:10–31) / **숫자 격언**(6:16–19; 30:15–31) / 축복 | [잠] |
| 전도서 | 시작하는 말(1:1–3)과 끝내는 말(12:8–14)이 **“헛되고 헛되도다”**로 감쌈 / “더 나은 것” 비교(4장; 7장) | [전] |
| 아가 | **사랑의 노래** — 여자·남자·코러스의 노래 / **와스프**(몸을 시적 이미지로 묘사, 4:1–7) | [아] |

- 〔정리자 해석〕 답관체(각 절의 첫 글자가 히브리어 알파벳 순서)는 시편(25, 34편 등)과 잠언(31:10–31) 모두에 나온다 → 잠언·시편 학습 자료

### 고대 근동의 지혜 문학과 사랑 노래
- **왕상 4:29–31** “솔로몬의 지혜가 동쪽 모든 사람의 지혜와 이집트의 모든 지혜보다 뛰어난지라” [잠]
- 메소포타미아(수메르 잠언, 아카드어 잠언), 이집트(**아멘엠오페의 교훈** — 잠 22:17–23:11과 비슷) [잠]
- 욥기와 유사한 문학 작품이 족장 시대의 **이집트와 메소포타미아**에서 쓰였다 [욥]
- 이집트, 메소포타미아, 우가릿 문헌에서 발견한 **사랑의 노래와 아가서의 닮음** [아]
- 〔정리자 해석〕 시가서는 주변 세계와 같은 문학 형식을 쓰면서도, 그 지혜와 사랑을 **여호와 경외** 안에 둔다 → 5. 줄기

## 6. 책을 가로지르는 줄기 〔정리자 해석〕

> 아래 줄기는 정리자가 다섯 권의 강의 내용을 이어 본 것이다. 각 항목의 근거는 강의안에 있는 구절이다.

### 경외 = 지혜의 근본
- 욥 28:28 “**주를 경외함이 지혜요** 악을 떠남이 명철이니라” [욥]
- 잠 1:7 “여호와를 경외하는 것이 **지식의 근본**” / 9:10 “**지혜의 근본**” [잠]
- 전 5:7 “오직 너는 하나님을 경외할지니라” / 12:13 “하나님을 경외하고 그의 명령들을 지킬지어다 이것이 **모든 사람의 본분**이니라” [전]
- 시 111:10 “여호와를 경외함이 지혜의 근본이라” 〔정리자 보충 — 본문〕
- → 욥기는 **고난** 속에서, 잠언은 **일상** 속에서, 전도서는 **해 아래 삶의 한계** 앞에서, 시편은 **예배**와 기도 속에서 같은 고백에 이른다.

### 응보와 그 너머
- 잠언은 경외하는 자의 **보상**(장수, 피난처, 재물과 영광과 생명 — 잠 10:27; 14:26; 22:4)을 가르친다 [잠]
- 욥기는 “모든 고통은 죄로 말미암았다”는 사상을 논박하고, **응보적 정의만이 유일한 원리가 아님**을 보여 준다 [욥]
- 전도서는 “멸망하는 의인, 장수하는 악인”(7:15)을 보고도 하나님의 **심판**(12:14)을 기억하게 한다 [전]
- 시편 1편은 “의인들의 길은 여호와께서 인정하시나 악인들의 길은 망하리로다”(1:6)로 시작한다 [시25]. 73편은 지혜시로 분류되는데 [시], 악인의 형통을 보고 “내 발이 거의 넘어질 뻔하였고”(73:2–3) 하다가 성소에 들어가서야 그들의 종말을 깨닫는다(73:17) 〔정리자 보충 — 본문〕
- → 잠언의 원칙을 욥기·전도서가 **버리지 않고 넓힌다** — 원칙은 참이지만, 삶 속에서 그대로 보이지 않을 때에도 하나님을 신뢰하라는 것이다.

### 솔직한 탄식에서 찬양으로
- 시편: 인간 감정의 총체적 표현 — **솔직한 감정** / 시편 전체가 **탄식에서 찬양으로** [시25]
- 욥기: 욥의 탄식 — “**왜 하나님은 생명을 주셔서 쓰디쓴 인생을 살아가게 하는가?**”(3:20–26) → 마지막에 “이제는 눈으로 주를 뵈옵나이다”(42:5–6) [욥]
- → 두 책 모두 하나님 앞에서 감정을 숨기지 않는 기도를 보여 준다.

### 솔로몬 — 지혜와 마음
- 왕상 4:29–34 솔로몬의 지혜, **잠언 3000, 노래 1005** — 잠언·전도서·아가 강의가 모두 이 구절을 든다 [잠][전][아]
- 잠언(1:1)과 아가(1:1)는 솔로몬의 이름을 밝히고, 전도서는 “다윗의 아들 예루살렘 왕 전도자”(1:1)라고 한다 [전]
- 아가 강의의 손글씨 메모: 하나님의 마음에 든 기도 — **지혜**(왕상 3:9) / 왕의 마음이 — **마음**(왕상 11장) [아]
- → 지혜를 구한 왕이 마음을 잃은 왕이 되었다. 시가서의 솔로몬은 **지혜만으로는 충분하지 않고, 마음이 하나님을 경외해야 한다**는 것을 보여 주는 인물이다.

### 사랑과 언약
- 아가: **언약의 틀 안에서 보호받는 신실한 사랑** / 사랑의 언약(8:5–7) [아]
- 잠 5:15–19(네 우물의 물을 마시라, 젊어서 얻은 아내를 즐거워하라)과 아가의 공통점 [아]
- 시편의 후렴 “그 인자하심이 영원함이로다”(136편; 118편) [시][시25]
- → 사람 사이의 신실한 사랑이 하나님과 그 백성의 언약적 사랑을 비춘다.

### 헛됨과 하나님의 선물
- 전도서: 해 아래의 수고는 **헤벨**(증기, 숨)이지만, 먹고 마시며 수고 중에 낙을 누리는 것은 **하나님의 선물**(3:13; 5:19) [전]
- 시편 90편(모세): 인생의 짧음 앞에서 “우리에게 우리 날 계수함을 가르치사 지혜로운 마음을 얻게 하소서”(90:12) 〔정리자 보충 — 본문〕
- → 인생이 짧고 다 알 수 없다는 고백이 절망이 아니라 **지혜와 감사**로 이어진다.
