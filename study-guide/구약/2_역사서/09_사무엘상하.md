## 2. BRI

### 역사서 이해 (도입) [삼]
- **역사서 = 여호수아~역대기, 12권**
- **Key word = 하나님의 주권**
- **역사의 이해는 언약을 통해서**
  - **일방적(맹세) 언약**: 아브라함(창 12; 15; 17; 22장), 이삭(창 26장), 야곱(창 28장) — 창 15:5 “하늘을 우러러 뭇별을 셀 수 있나 보라 … 네 자손이 이와 같으리라”
  - **조건적(행위) 언약**: 출 19–24장 **시내산 언약** — 책임과 의무가 존재, **회막 = 언약 갱신**
  - **다윗 언약(삼하 7장) = 일방적 언약 + 조건적 언약**
- 〔정리자 해석〕 창세기 강의는 언약을 평등 · 종주권 · 약속으로 나눈다([창B]). 사무엘 강의의 ‘일방적 / 조건적’과 용어가 다르다 → `../1_모세오경/00_모세오경_개관.md`
- 여호수아 강의의 “역사서는 이야기다 …” 네 문장도 같은 도입이다 → `06_여호수아.md`

### 책의 이름 [삼]
- 히브리 성경: “**쉬프뤠 사무엘**” — 한 권
- **70인역** 번역에서 모음을 넣으며 상·하로 구분
- 70인역: 사무엘서 = **제1, 제2 왕국서** / 열왕기서 = **제3, 제4 왕국서**

### 저자 — 사무엘 / 나단 / 갓 [삼]
- 삼상 10:25 사무엘이 나라의 제도를 백성에게 말하고 **책에 기록하여** 여호와 앞에 둠
- 삼상 25:1 **사무엘의 죽음** (이후 부분은 사무엘이 쓸 수 없음)
- **대상 29:29** 다윗 왕의 행적은 **선견자 사무엘, 선지자 나단, 선견자 갓**의 글에 기록됨
- 셋 모두 선지자
  - **선견자** = 히브리어 **라아** (삼상 9:9) — 보다, 조사하다, 바라보다
  - **선지자** = 히브리어 **나비** — 대언자
  - 선견자 = 선지자 (삼상 9:9; 삼하 24:11; 왕하 17:13)
- **갓**: 첫 등장 삼상 22:5 / 마지막 등장 삼하 24:11
- **나단**: 첫 등장 삼하 7:2 / 마지막 등장 왕상 1:45
- **사무엘**: 이스라엘의 **마지막 사사** / 이스라엘의 **선지자** / **왕정 정치의 기반을 세운 사람** / 초대 왕 사울과 2대 왕 다윗에게 기름을 부음
- **결론: 사무엘 / 갓 / 나단이 기록함**

### 기록 시기 [삼]
- 근거
  - 삼하 24장 = 다윗의 **통치 말기**(BC 970)
  - **솔로몬의 이름은 언급되지만 왕으로 즉위하지 않았다**
  - 이스라엘의 **분열을 암시하는 구절들**(유다와 이스라엘) — 삼상 27:6 “시글락이 **오늘까지 유다 왕에게** 속하니라”
- 두 견해: **BC 970년 이전**(다윗의 통치 말기) / **BC 930년 직후**(솔로몬 이후 분열 직후)
- 반론(분열 암시 구절에 대해): 삼하 3:1 사울의 집과 다윗의 집 사이의 전쟁 / 삼하 5:5 다윗이 왕이 되었을 때에도 이스라엘과 유다로 나누어 설명
- → 결론: **BC 970년 다윗의 죽음 이전**에 기록했을 것

### 쓰여진 이유 [삼]
1. 신정 정치에서 왕정 정치로의 **변환 과정**
2. **하나님께 합당한 왕은 누구인가?**
3. 사울은 어떤 왕인가?
4. 다윗은 어떤 왕인가?
5. **다윗이 받던 오해를 풀어 주기 위함**
- 〔정리자 해석〕 수신자가 “압살롬의 반역과 전염병으로 다윗의 왕권이 위기에 처한 때”의 사람들이라는 설명과 5번이 맞물린다 — 사울의 집안을 해하지 않았고(삼상 24; 26장; 삼하 1; 3–4; 9장) 하나님이 세우신 왕이라는 변호.

## 5. 장별 읽기 가이드

### 사무엘상

#### 1:1–2:11 — 한나와 사무엘의 출생 [삼]
- 1:1 **에브라임 산지 라마다임소빔**에 사는 **엘가나**
  - 대상 6:22–28 — 엘가나는 **레위의 아들 그핫 자손**
- **한나 = 은총** / 자식이 없었다(2절) / **여호와께서 임신하지 못하게 하심**(5절)

**한나와 룻** [삼]

| 한나 | 룻 |
|---|---|
| 자식이 없음 (2절) | 남편이 없음 |
| 여호와께서 임신하지 못하게 하심 (5, 6절) | 여호와께서 징벌하셨고 전능자가 괴롭게 함 (나오미의 고백) |
| 브닌나가 심히 격분하게 하여 괴롭게 함 (6절) | 이삭을 주워 생계를 유지함 |
| 여호와께 기도하고 통곡함 (10절) | 여호와의 말씀에 순종함 |
| 여호와께 서원함 (11절) | |
| 여호와께서 그를 생각하심 (19절) | 여호와께서 임신하게 하심 |
| 사무엘을 낳음 (20절) | 다윗의 할아버지 오벳을 낳음 |
| **사무엘 = 하나님께서 들으셨다** | **다윗 = 사랑받는 자, 또는 두목** |

- 1:21–28 사무엘을 여호와께 드림 ↔ 2:12–17 “**죄가 여호와 앞에 심히 컸다**” (엘리의 아들들)
- **한나의 기도** (2:1–11): 감사와 기쁨 / **하나님의 하나님 되심 & 하나님의 주권**
- 〔정리자 해석〕 한나의 기도 끝(2:10) “자기 왕에게 힘을 주시며 자기의 **기름 부음 받은 자**의 뿔을 높이시리로다”는 아직 왕이 없는 때에 왕을 내다본다. 사무엘서 전체의 주제(하나님께 합당한 왕)가 첫 노래에 들어 있다.

#### 2:12–36 — 엘리의 아들과 사무엘 《카이아즘》 [삼]

| | 본문 | 내용 |
|---|---|---|
| A | 12–17 | 엘리 아들들의 죄악 |
| B | 18–21 | 여호와의 축복 (사무엘, 한나) |
| **C** | **22–25** | **하나님의 결심** |
| B′ | 26 | 여호와와 사람들에게 은총을 받은 사무엘 |
| A′ | 27–36 | 엘리 가문의 심판 |

- 〔정리자 해석〕 A′의 심판 선언(2:30 “나를 존중히 여기는 자를 내가 존중히 여기고”)은 제사장 직분이 엘리(이다말 계열)에서 사독(엘르아살–비느하스 계열)으로 옮겨 가는 흐름과 이어진다 — 레위 지파 직분 도표 [레위]: 민 25:11 비느하스의 영원한 제사장 언약 ↔ 삼상 2:30 → `../1_모세오경/03_레위기.md`. 성취는 왕상 2:27(아비아달 파면).

#### 3:1–4:1a — 엘리에서 사무엘로 [삼]
- 1절 사무엘이 엘리 앞에서 여호와를 섬길 때에 — **여호와의 말씀이 희귀하여 이상이 보이지 않았더라**
- 2절 **엘리의 눈이 점점 어두워** 가서
- 3절 **하나님의 등불은 아직 꺼지지 아니하였으며** — 사무엘은 하나님의 궤 있는 전 안에 누웠더니
- 19–4:1a 여호와의 **말씀으로** 사무엘에게 자기를 나타내시니라
- 〔정리자 해석〕 “말씀이 희귀함”(3:1) → “말씀으로 자기를 나타내심”(3:21) → “사무엘의 말이 온 이스라엘에 전파”(4:1). 어두워 가는 엘리의 눈과 꺼지지 않은 등불이 대조된다.

#### 4:1b–7:17 — 하나님 vs 다곤 《카이아즘》 [삼]

#### 1:1–4:12 — 사울의 집과 다윗의 전쟁 《카이아즘》 [삼]

| | 본문 | 내용 |
|---|---|---|
| A | 1:1–17 | 사울의 죽음 |
| B | 1:17–27 | 다윗의 애가 (사울 / 요나단) |
| C | 2:1–11 | 유다 왕 다윗과 이스라엘의 왕 이스보셋 |
| D | 2:12–32 | 유다와 이스라엘의 전쟁 |
| **F** | **3:1–11** | **사울의 집은 약하여 가고 다윗의 집은 강하여 가고** |
| D′ | 3:12–21 | 유다와 이스라엘의 언약 |
| C′ | 3:22–30 | 요압(유다)과 아브넬(이스라엘) |
| B′ | 3:31–40 | 다윗의 애가 (아브넬) |
| A′ | 4:1–12 | 사울의 아들 이스보셋의 죽음 |

- 강의안 표기: A와 B가 **17절을 함께** 가진다 — 1:17 “다윗이 이 슬픈 노래로 사울과 그의 아들 요나단을 조상하고”는 죽음 보고를 맺고 애가를 여는 **이음 구절**이다. 중심 표지는 E 없이 **F**로 적혀 있다(뜻에는 영향 없음).
- 〔정리자 해석〕 A·B와 A′·B′가 짝을 이룬다: 사울과 이스보셋의 죽음 모두 다윗의 손이 아니며, 다윗은 사울·요나단과 아브넬을 위해 애가를 부른다 — 쓰여진 이유 ⑤ “다윗이 받던 오해를 풀어 줌”과 이어진다.

#### 5장 — 이스라엘 왕, 다윗 [삼]
- 1–3 이스라엘 모든 장로가 **헤브론**에서 다윗을 왕으로 세움
- 4–5 헤브론에서 **7년 6개월**, 예루살렘에서 **33년**
- 6–10 **예루살렘을 점령함 — 다윗성**
- 10 **만군의 여호와께서 함께 계시니** 다윗이 점점 강성하여 가니라
- 12 “다윗이 ________ 알았더라” 〔강의안 빈칸〕
  - 〔일반 해석〕 본문: 다윗이 “**여호와께서 자기를 세우사 이스라엘 왕으로 삼으신 것과 그의 백성 이스라엘을 위하여 그 나라를 높이신 것**을” 알았더라. 왕권은 자기 힘으로 얻은 것이 아니라 **하나님이 세우신 것**이고, 나라를 높이신 것은 **백성을 위한 것**임을 알았다는 뜻이다. 열왕기 강의는 이 구절을 솔로몬과 대비한다 [왕학1].

#### 6장 — 하나님의 궤를 모셔 옴 [삼]
- 1 이스라엘에서 뽑은 무리 **3만 명**을 다시 모으고 — 대상 13:1–3: **제사장과 레위인이 포함된** 사람들
- 2 “궤” = **그룹들 사이에 좌정하신 만군의 여호와의 이름으로 불리는 것**
- 6–11 **베레스웃사** — 삼상 6:20 “이 거룩하신 하나님 여호와 앞에 **누가 능히 서리요**”
- 12–23 여호와의 궤가 다윗 성에 들어옴
- 〔정리자 해석〕 삼상 6:20의 벧세메스 사람들과 삼하 6장의 웃사는 모두 궤를 가볍게 다룬 결과다. 역대기는 두 번째 운반 때 레위인이 궤를 멨다고 강조한다(대상 15:2, 13–15) → 역대기 학습 자료.

#### 7장 — 다윗 언약 [삼]
- 1–3 **다윗의 계획**: 하나님이 거하실 **처소**를 건축
- 4–17 **하나님의 계획**: **다윗의 집**을 건축
- **12–16 다윗 언약**: “네 집과 네 나라가 내 앞에서 **영원히 보전되고** 네 왕위가 **영원히 견고하리라**”
- **18–29 다윗의 고백(감사)**
  - “주 여호와여” = **아도나이 야훼** (18, 19, 20, 22, 28, 29)
  - “종의 집에” = **에베드** (19, 20, 21, 25, 26, 27, 28, 29)
  - 19 “주 여호와여 이것이 사람의 법이니이다”
  - 28–29 “말씀하셨사오니 … 영원히 복을 받게 하옵소서”
- 역사서 도입: 다윗 언약 = **일방적 언약 + 조건적 언약** [삼]
- 〔정리자 해석〕 ‘집’의 두 뜻 — 다윗은 하나님께 **집(성전)**을 지어 드리려 했고, 하나님은 다윗에게 **집(왕조)**을 지어 주신다. 조건적 요소는 14절(“그가 만일 죄를 범하면 … 징계하려니와”), 일방적 요소는 15절(“내 은총을 그에게서 빼앗지 아니하리라”)에서 보인다.

#### 8장 — 다윗의 전쟁 [삼]
- 6, 14절 “다윗이 **어디로 가든지 여호와께서 이기게 하셨더라**”
- 15절 온 이스라엘을 다스려 모든 백성에게 **정의와 공의**를 행할새
- 열왕기 강의의 영토 확장 목록: 블레셋(5:17–25; 8:1), 모압(8:2), 소바(8:3), 다메섹 아람(8:5), 하맛의 조공(8:9), 암몬·에돔·아말렉(8:12–13), 두로와 화친(5:11) [왕B]

#### 9장 — 요나단의 언약을 기억함 [삼]
- 3절 “사울의 집에 **아직도 남은 사람이 없느냐**? 내가 그에게 **하나님의 은총(헤세드)**을 베풀고자 하노라”
- 13절 **므비보셋이 항상 왕의 상에서 먹으므로**
- 〔정리자 해석〕 삼상 20:14–17 요나단과의 언약을 지킨 것이다. 룻기의 핵심어 ‘인애(헤세드)’와 같은 말 → `08_룻기.md`

#### 11–12장 — 다윗의 죄 《카이아즘》 [삼]

| | 본문 | 내용 |
|---|---|---|
| A | 11:1 | 전쟁 중인 다윗 (암몬과의 전쟁) |
| B | 11:2–5 | 밧세바를 간음한 다윗 |
| C | 11:6–27 | 다윗이 우리아를 죽임 |
| **D** | **12:1–15a** | **하나님의 책망** (나단) |
| C′ | 12:15b–23 | 다윗의 아이가 죽음 |
| B′ | 12:24–25 | 밧세바와 동침 (솔로몬 출생) |
| (A′) | 12:26–31 | 전쟁 승리 |

- 강의안은 마지막 줄에 A′ 표지를 붙이지 않았다 — 자리로 보아 A(전쟁 중)와 짝.
- 시편 51편 표제: 다윗이 밧세바와 동침한 후 선지자 나단이 그에게 왔을 때 [시] → 시편 학습 자료
- 〔정리자 해석〕 솔로몬의 다른 이름 **여디디야**(“여호와께 사랑받는 자”, 12:25) — 열왕기 강의가 솔로몬 출신을 설명할 때 쓴다 [왕B].

#### 13–18장 — 압살롬의 반역 [삼]
- 13:1–22 **암논**이 다말을 욕보임
- 13:23–39 압살롬이 암논을 죽임 (**2년 후**)
- 14:1–24 압살롬이 그술에서 돌아옴 (**3년이 지남**)
- 14:25–33 압살롬이 **2년 동안** 왕을 보지 못함
- 15:1–18:33 압살롬이 반역을 일으킴 (**4년 동안 준비**)
- 18:9–15 압살롬의 죽음
- **다윗의 태도**: 15:25–26, 16:10 〔강의안 빈칸 — 구절만 있음〕
  - 〔일반 해석〕 **15:25–26**: 하나님의 궤를 성으로 도로 메어 가게 하며 “내가 여호와 앞에서 은혜를 얻으면 도로 나를 인도하사 … 그러나 그가 이와 같이 말씀하시되 내가 너를 기뻐하지 아니한다 하시면 종이 여기 있사오니 선히 여기시는 대로 내게 행하시옵소서”. **16:10**: 자기를 저주하는 시므이를 치려는 아비새를 막으며 “여호와께서 그에게 다윗을 저주하라 하심이니”. → 도망하는 위기에도 **궤를 수단으로 쓰지 않고**(아벡 전투, 삼상 4장과 대조) **하나님의 주권에 자신을 맡긴** 태도. 사울과 다윗 비교표의 “위급한 상황의 태도 — 여호와를 찾음”과 같은 줄이다.
- 〔정리자 해석〕 12:10–11 나단의 선언(“칼이 네 집에서 영원토록 떠나지 아니하리라 … 네 집에 재앙을 일으키고”)이 13–18장에서 이루어진다. 11–12장 바로 뒤에 이 단락이 놓인 이유다.

#### 21–24장 — 하나님을 경외함으로 《카이아즘》 [삼]
- 강의안 제목 범위는 “삼하 22:1~51”이고, 표의 내용은 21–24장 전체다. 〔정리자 해석〕 강의안은 이 단락을 **중심(C) 다윗의 노래(22장)를 보여 주는 슬라이드**로 잡고, 그 노래가 21–24장 안에서 놓인 자리를 표로 보여 준 것으로 읽힌다.

| | 본문 | 내용 |
|---|---|---|
| A | 21:1–14 | 사울의 죄, 삼 년 기근 → **기도를 들으심** |
| B | 21:15–22 | 다윗의 부하들 |
| **C** | **22:1–23:7** | **다윗의 노래** |
| B′ | 23:8–39 | 다윗의 부하들 |
| A′ | 24장 | 다윗의 죄, 칠만 명이 죽음 → **기도를 들으심** |

- 〔정리자 해석〕 C에 “다윗의 마지막 말”(23:1–7)이 들어 있고, 책의 표제 “사람을 공의로 다스리는 자, 하나님을 경외함으로 다스리는 자”(23:3)가 바로 여기서 나왔다. 단락 제목 “하나님을 경외함으로”가 표제를 가리킨다.

#### 22장 — 다윗의 노래 《카이아즘》 [삼]

| | 본문 | 내용 |
|---|---|---|
| A | 1 | 다윗을 구원하신 날 (**현재적** 상황) |
| B | 2–4 | 여호와는 나의 반석, 구원의 뿔 |
| C | 5–20 | 환난 중에 구원을 베푸신 여호와 |
| **D** | **21–25** | **다윗의 공의** |
| **D′** | **26–28** | **하나님의 공의** |
| C′ | 29–46 | 원수들을 멸하시는 여호와 (하나님과 동행) |
| B′ | 47–49 | 나의 반석, 구원의 반석 |
| A′ | 50–51 | 기름 부음 받은 자에게 인자를 영원하도록 (**미래적** 간구) |

- 〔정리자 해석〕 시편 18편과 거의 같은 노래다(시 18편 표제: “여호와께서 다윗을 모든 원수들의 손에서와 사울의 손에서 건져 주신 날에”). 강의안에는 적혀 있지 않다.
- 〔정리자 해석〕 A′ 51절 “**그의 기름 부음 받은 자**에게 인자를 베푸심이여 영원토록 다윗과 그 후손에게로다”는 한나의 기도 끝(삼상 2:10)과 짝을 이룬다 — 사무엘서가 ‘기름 부음 받은 자’로 시작하고 끝난다.

## 6. 주제와 연결

### 하나님께 합당한 왕
- 쓰여진 이유 ②–④ [삼] / 사울과 다윗 비교표 [삼] / 신명기 왕의 규례 [삼]
- 표제 삼하 23:3 “**공의로** 다스리는 자, **하나님을 경외함으로** 다스리는 자” — 8:15 “정의와 공의를 행할새”, 22:21–28 “다윗의 공의 / 하나님의 공의”.

### 언약
- 일방적 언약 + 조건적 언약 = **다윗 언약** [삼]
- 요나단과의 언약을 기억함(9장, 헤세드) [삼]
- 12장 왕정 승인식의 역사적 서언 — 조약 형식 [삼]

### 사사기와 사무엘상의 병행 [병행]
- 삼손 ↔ 사무엘(출생, 나실인, 사역) / 미가의 레위인 ↔ 엘리의 아들들 / 베냐민 이야기(삿 19–21) ↔ 사울의 등장(삼상 8–11) → 표 전체는 `07_사사기.md`
- 사무엘의 관점: 왕정을 세웠지만 **왕정을 지지한 사람은 아니다** / 사사 시대에도 **왕은 하나님이셨다**(삼상 12:12) [병행]

- 사무엘은 아론 계열이 아닌 레위인(이스할 계열, 대상 6:34–38) [레위]

| 번호 | 강의안 원문 | 반영 | 판단 근거 |
|---|---|---|---|
| ① | p12 “삼하4:5절 다윗이 왕이 되었을 때에도 이스라엘과 유다로 나누어 설명” | 삼하 5:5 | 4:5(레갑과 바아나)에는 이스라엘/유다 구분이 없고, 강의안 문장은 5:5의 요약. 번역본 장절 차이도 없음 |

**세 번 검토한 뒤 강의안 그대로 두기로 한 것 (이번에 철회)**
- **삼하 1:1–4:12 표 A “1:1~17” / B “1:17~27”** — 17절이 겹치지만, 1:17은 죽음 보고를 맺고 애가를 여는 **이음 구절**이라 두 칸에 함께 둔 것으로 읽힌다. 본문에 설명을 붙임.
- **같은 표 중심 표지 “F”** — E를 건너뛰었지만, 짝 없는 중심을 표시한 것이라 뜻에 영향이 없다. 강의안이 앞선 판에서 E 항목을 빼면서 남은 흔적일 수도 있다. 고칠 이익이 없어 그대로 둠.
- **21–24장 단락 제목 “삼하 22:1~51”** — 표 내용은 21–24장이지만, 강의안이 이 슬라이드를 **중심인 22장 다윗의 노래**를 보여 주려는 것으로 잡았다고 읽을 수 있다. 본문에 설명을 붙임.

**처음부터 강의안 그대로 둔 것**
- 11–12장 표 마지막 줄(12:26–31)에 A′ 표지가 없음 — 표지 누락. 본문에 “(A′)”로 괄호 보충만 함.
- “압살롬이 반역을 일으킴(**4년 동안** 준비)” — 삼하 15:7은 히브리어 본문이 “40년”이고, 일부 고대 역본과 여러 현대 번역이 “4년”으로 읽는다. 강의안은 “4년” 읽기를 따른 것으로 보임.
- 나단의 “마지막 등장 왕상 1:45”, 갓의 “마지막 등장 삼하 24:11” — 사건 속 등장을 말한 것으로 읽힘.
- p8 “선견자 = … 보다, 조사하다, 바라보”, p27 “그의 기업의 지도자로 삼” — 슬라이드에서 끝이 잘린 것.
