## 2. BRI

### 저자 — 모르드개 [에]

**저자의 특징**
1. **유대인**
2. **페르시아에 대해 잘 알고** 있음
3. 페르시아의 **고위 관직자**
4. **사건과 밀접한 연관**이 있는 자

**1. 유대인?**
- 히브리어 이름으로 기록: **아하수에로**(1:1) — 그리스: 크세르크세스, 페르시아: 크샤이아르샨
- 유대인들의 **애도 관습** (4:1)
- 길이 단위 **규빗** 사용 (5:14; 7:9)
- **유대 달력** 사용 (아래 표)
- 하만을 **유대인의 대적**이라 부름 (3:10; 8:1; 9:10, 24)
- 반유대인들을 **대적**이라 부름 (8:13; 9:5, 16, 22)
- **유대인의 문자와 언어**로 조서 기록 (8:9)

**2. 페르시아의 관습, 행정들을 잘 알고 있다**
- 페르시아 **127지방** (1:1; 8:9; 9:30)
- 페르시아와 메대의 **7지방관** 이름 언급 (1:14)
- 왕의 **내시 7명** 이름 언급 (1:10)
- 왕을 시해하려던 자들의 이름과 지위를 알고 있음 (2:21)
- **왕비 간택 과정**을 자세히 묘사 (2:1–18)

**3. 사건과 밀접한 연관성이 있음**
- 아하수에로의 잔치와 와스디 폐위 과정 (1:1–22)
- 페르시아의 **궁중 일기, 역대 일기** (2:23; 6:1)
- 에스더의 즉위 날짜 (2:16)
- 하만이 제비를 뽑던 날 (3:7)
- 부림절이 지켜지는 날 (9장)
- 모르드개와 에스더의 대화 (4:7–17)

**모르드개는 누구인가?**
- 유대인 (2:5) / **베냐민 자손** (2:5)
- **여고냐와 함께** 잡혀 왔음 (2:6)
- 에스더의 **사촌이자 양아버지** (2:7, 15)
- 매일 후궁 뜰 앞으로 왕래 (2:11)
- 페르시아의 공직자 (2:19, 21; 5:9, 13)
- 페르시아의 **총리**가 됨 (10:3)
- 모르드개가 **부림에 대한 조서**를 기록 (9:20, 29)
- → **저자: 모르드개**

### 원독자 [에]

**페르시아에 남아 있는 유대인들**
- 유대인 = **예후디** — **44번** 사용
- 유대인의 달력 사용
- 하만과 반유대인들을 “유대인의 대적”이라 부름
- 본토로 돌아간 유대인들과 **서신 교환**, **왕래** 가능
- 연표: 538 1차 귀환 → 516 스룹바벨 성전 완공 → 458 2차 귀환 → 444 3차 귀환

| 본토로 돌아간 유대인들 | 페르시아에 남아 있는 유대인들 |
|---|---|
| 하나님의 역사를 이루기 위해 귀환 | **하나님의 역사보다 자신의 안락한 삶을 선택 → 죄책감** |
| 성전 재건의 어려움 | 하나님의 역사와 **상관없다**고 생각 |
| 하나님의 영광이 임하지 않음 | **이방 문화**를 받아들임 |
| 생계, 생활의 어려움 / 영적, 도덕적 타락 | **환경과 타협하는 삶** |

**원독자의 질문** [에]
- 하나님은 살아 계신가?
- 하나님은 여전히 **페르시아에 남아 있는 우리와 함께**하시는 분이신가?
- 하나님의 주권은 오늘도 역사하는가?
- 하나님은 정말 **열방의 통치자**인가?
- 하나님은 자신의 백성을 향한 **언약을 기억**하고 계시는 분이신가?
- 하나님이 **이방 신에 비해 연약한 신**은 아닌가?

## 4. 전체 구조 [에]

### 반전의 책 — 6장을 중심으로 한 교차 구조

| | 장 | 내용 |
|---|---|---|
| A | 1–2장 | **에스더가 왕비**가 됨 |
| B | 3장 | **하만이 높아짐** — 유대인 진멸 조서 |
| C | 4–5장 | 에스더의 결단과 하만의 분노 |
| **D** | **6장** | **왕의 잠 못 드는 밤 — 모르드개가 존귀케 됨** (전환점) |
| C′ | 7장 | 에스더의 구원 요청과 하만의 죽음 |
| B′ | 8장 | **모르드개가 높아짐** — 유대인 대적 진멸 조서 |
| A′ | 9–10장 | **유대인의 대적이 말살**됨 |

### 반전 — 3·4장 ↔ 8장

| 3–4장 | 8장 · 10장 |
|---|---|
| 하만이 총리가 됨 (3:1) | 모르드개가 총리가 됨 (10:3) |
| 왕이 하만에게 인장 반지를 줌 (3:10) | 왕이 모르드개에게 인장 반지를 줌 (8:2) |
| 하만이 왕의 서기관을 소집 (3:12) | 모르드개가 왕의 서기관을 소집 (8:9) |
| 유대인 진멸 조서를 쓰고 인침 (3:12) | 대적을 진멸하는 조서를 쓰고 인침 (8:10) |
| 유대인들과 그들의 처자까지 죽이도록 함 (3:12) | 유대인의 대적들과 그들의 처자까지 죽이도록 함 (8:11) |
| 조서 초본을 각 지방에 반포 (3:14) | 조서 초본을 각 지방에 반포 (8:13) |
| 역졸이 급히 나감 (3:15) | 역졸이 빨리 나감 (8:14) |
| **수산성이 어지러움** (3:15) | **수산성이 기뻐함** (8:15) |

| 애통하고 금식함 (4:3) | 기뻐하며 잔치를 베풂 (8:17) |

### 잔치의 책 — “잔치”는 구약 43번 중 **19번**이 에스더서 [에]

| | 본문 | 잔치 |
|---|---|---|
| A | 1:2–4 | 왕이 귀족들을 위해 베푼 잔치 |
| B | 1:5–8 | 왕이 도성 수산 사람들을 위해 베푼 잔치 |
| C | 2:18 | 에스더의 왕후 즉위식을 위한 잔치 |
| D | 5:1–8 | 에스더의 첫 번째 잔치 |
| **E** | **6:1–14** | **왕의 잠 못 이루는 밤 — 모르드개가 존귀케 됨** |
| D′ | 7:1–9 | 에스더의 두 번째 잔치 |
| C′ | 8:17 | 모르드개의 등극을 축하하는 잔치 |
| B′ | 9:17, 19 | 전국 유대인들의 부림절 첫 번째 잔치 |
| A′ | 9:18 | 수산 유대인들의 부림절 두 번째 잔치 |

- 〔정리자 해석〕 첫 잔치들(A–C)은 **왕의 영광**을, 마지막 잔치들(C′–A′)은 **구원받은 백성의 기쁨**을 위한 것이다. 한가운데에는 잔치가 아니라 **잠 못 이루는 밤**이 있다.

### 정경으로서의 논란? [에]
- 하나님이 언급되지 않음
- 신약과 구약에서 한 번도 인용되지 않음
- 에스더서를 토라와 같은 권위로 인정 **vs** 토라에 기록되지 않은 부림절을 인정하지 않음
- 유대적 성향이 짙음
- 우연한 사건들
- 잔인한 살육의 장면들
- 강의안은 논란을 나열하고 판단을 적지 않았다 〔강의안 빈칸 — 질문〕.
  - 〔일반 해석〕 유대교와 교회는 결국 에스더서를 **정경으로 받았다**. 하나님의 이름이 없는 것은 오히려 “**보이지 않는 하나님의 섭리**”(중심 내용)를 보여 주는 장치로 읽힌다(은혜·잠 못 이루는 밤 등). 부림절은 토라에 없는 절기지만 **언약 백성의 구원을 기억하는 날**로 받아들여졌다(요 5:1의 “유대인의 명절”을 부림절로 보는 견해도 있다). 살육 장면은 “**스스로 생명을 보호하라**”는 방어 조서(8:11) 안의 일이고, 재산에 손대지 않았다는 말이 세 번 강조된다(9:10, 15, 16).

### 6장 — 왕의 잠 못 이루는 밤 (전환점) [에]

**우연?** [에]

|---|---|---|---|

**왕의 잠 못 이루는 밤** [에]
- “**그날 밤에**” — 에스더의 두 번째 잔치 전날, 하만이 모르드개를 매달 장대를 만든 그날
- “왕이 잠이 오지 아니하므로” = **나다드**(נָדַד): 도망하다, 피하다, 떠나다 → **왕의 잠이 달아났다**
- 시 127:2 “여호와께서 그의 사랑하시는 자에게는 **잠을 주시는도다**”
- 〔정리자 해석〕 하나님은 사랑하시는 자에게 잠을 **주시고**(시 127:2), 이 밤에는 왕에게서 잠을 **달아나게** 하신다. 천사도 기적도 없지만, 다니엘의 두 장면과 같은 자리에 이 밤이 놓여 있다.

**왕의 생명을 구한 모르드개 ↔ 하만의 굴욕** [에]
- 모르드개: 왕처럼 존귀케 됨 → **다시 대궐 문으로**
- 하만: 모르드개를 높임 → **수치심을 안고 서둘러 집으로**
- 6:13 “모르드개가 과연 **유다 사람의 후손**이면 당신이 그 앞에서 굴욕을 당하기 시작하였으니 능히 그를 이기지 못하고 **분명히 그 앞에 엎드러지리이다**”

**사건의 흐름** [에]: 에스더가 왕비가 됨 → 모르드개가 역모를 막음 → 하만이 유대인 멸절을 꾀함 → 에스더의 결단 & 중보 기도 → 에스더의 첫 번째 잔치 → 하만이 모르드개를 매달 장대를 만듦 → **하나님께서 일하심**

- 〔정리자 해석〕 강의안의 흐름도는 앞의 여섯 사건이 모두 사람의 일이고 마지막 칸만 “하나님께서 일하심”이다. 그러나 앞의 일들이 하나씩 맞물려 있어야(2장의 역모 기록이 6장에서 읽혀야) 마지막 칸이 이루어진다 — 중심 내용 “보이지 않으시는 하나님의 섭리”.

### 8장 — 새로운 조서 [에]

**아직 유대인의 구원이 이루어지지 않음 (8:1–8)**
- 모르드개가 하만의 자리를 차지함 (8:1–2)
- 에스더의 **눈물의 간청** (8:3)
- 왕후 에스더와 유다인 모르드개에게 유대인 구원 조서를 쓰게 허락

**에스더의 세 번의 간청** [에]

| 1·2번째 간청 (5:8; 7:3) | 3번째 간청 (8:5) |
|---|---|
| 왕의 목전에서 은혜를 입었으면 | 왕이 만일 즐거워하시며 |
| 왕이 좋게 여기시면 | 왕의 목전에 은혜를 입었고 |
| | 왕이 이 일을 좋게 여기시며 |
| | 나를 좋게 보실진대 |

- 〔정리자 해석〕 조건이 둘에서 넷으로 늘어난다 — 변경할 수 없는 법(8:8) 앞에서 더 간절해진 간청.

**새로운 조서의 반포 (8:9–17)** [에]

| | 하만의 조서 (3:13–14) | 모르드개의 조서 (8:10–13) |
|---|---|---|
| 전달 | 역졸에게 맡겨 왕의 각 지방에 보냄 | 역졸들에게 부쳐 전함 (**준마**를 타고) |
| 날 | 12월 13일 하루 동안 | 12월 13일 하루 동안 |
| 내용 | **모든 유다인**: 젊은이, 늙은이, 어린이, 여인들을 모두 죽이고 도륙하고 진멸하고 그 재산을 탈취하라 | **전국의 유대인에게**: 모여서 **스스로 생명을 보호하라** / 각 도의 백성 중에서 세력을 가지고 **그들을 치려 하는 자들**과 그들의 처자를 죽이고 도륙하고 진멸하고 그 재산을 탈취하라 |
| 반포 | 이 명령을 각 지방에 전하기 위하여 조서의 초본을 모든 민족에게 선포하여 그날을 위하여 준비하게 하라 | 이 조서 초본을 각 도에 전하고 각 민족에게 반포하고 유다인들에게 준비하였다가 그날에 대적에게 원수를 갚게 한지라 |

- 조서가 도성 수산에도 반포됨 (8:14)
- 모르드개가 **제국의 2인자의 예복**을 입고 나아옴 / **수산성은 즐거이 부르며 기뻐함** / 유다인에게는 **영광, 즐거움, 기쁨, 존귀함**
- 8:17 “각 지방, 각 읍에서 유다인들이 즐기고 기뻐하여 잔치를 베풀고 그날을 명절로 삼으니 본토 백성이 유다인을 두려워하여 **유다인 되는 자가 많더라**”

### 9장 — 유대인의 승리와 부림절 [에]
- **유대인의 승리 (9:1–5)** — 모든 민족이 유대인을 두려워함 (8:17; 9:2, 3)
  - 두려움 = **파하드**(פַּחַד): 공포, 두려움, 두려움의 대상
  - 신 11:25 “너희의 하나님 여호와께서 너희에게 말씀하신 대로 너희가 밟는 모든 땅 사람들에게 너희를 **두려워하고 무서워하게** 하시리니 너희를 능히 당할 사람이 없으리라”
- “**그들의 재산에는 손을 대지 아니하였더라**” (9:10, 15, 16)
  - 〔정리자 해석〕 세 번 반복된다. 조서는 재산 탈취를 허락했지만(8:11) 유대인들은 손대지 않았다 — 하만의 조서(3:13 “재산을 탈취하라”)와 다르고, 아말렉의 좋은 가축을 취한 사울(삼상 15:9)과도 다르다.
- **부림절 제정 (9:20–32)**
  - 잔치를 베풀고 즐기라
  - 서로 **예물**을 주며 **가난한 자를 구제**하라
  - 대적의 위협 · 슬픔 · 애통 → **평안함 · 기쁨 · 길한 날**

### 9:29 — 에스더의 정체성 [에]
- **에스더의 마지막 명령**: “**아비하일의 딸 왕후 에스더**와 **유다인 모르드개**가 전권(능력, 권력, 세력)으로 글을 쓰고 부림에 대한 이 둘째 편지를 굳게 지키게 하되” (9:29)
- 〔정리자 해석〕 책의 처음에 에스더는 민족과 종족을 밝히지 않았다(2:10, 20). 마지막에는 “**아비하일의 딸**”(유대인의 딸)이자 “**왕후**”로 이름을 걸고 명령한다 — 원독자에게 페르시아 안에서도 유대인의 정체성을 드러내며 살라는 말.

### 10장 — 모르드개 [에]
- 모르드개가 **총리**가 됨 (10:3) — 반전표의 마지막 칸
- 〔정리자 해석〕 10:3 “그의 백성의 이익을 도모하며 그의 모든 종족에게 안위하는 말을 하였더라” — 하만(3:1)과 정반대의 2인자.
