# 역사서 개관 — 여호수아 ~ 에스더 (12권)

> 역사서 12권을 읽기 전에 보는 안내. 각 책 강의의 도입부와 BRI에서 역사서 전체에 해당하는 내용을 모았다. 책별 자세한 내용은 아래 ‘6. 책별 파일’의 링크를 따라간다.

---

## 1. 역사서란 무엇인가

### 네 문장 [수A]
1. 역사서는 **이야기**다.
2. 역사서는 **목적을 가진** 이야기들이다.
3. 역사서는 **민족의 정체성**을 확립하게 한다.
4. **하나님이 이야기의 주인공**이며, 그분이 영광을 받으신다.

### 열왕기 강의의 일곱 문장 (빈칸 유인물) [왕학1]
1–4는 위의 네 문장과 같고, 세 문장이 더 있다.
5. 역사서는 ( **신학적(하나님 중심적)** )적 관점의 역사이다. 〔일반 해석〕
6. 역사서는 ( )로 구성되어 있다. 〔강의안 빈칸 — 근거 없음〕
7. 역사서는 하나님이 자신을 ( **계시** )하시고 ( **(언약을) 성취** )하시는 것이다. 〔일반 해석〕
- 5·7의 괄호는 열왕기 학습 자료에서 승인받아 넣은 일반 해석이다 → `11_열왕기상하.md`

### 역사서를 읽는 원리 [수A]
1. 하나님께서 **말씀과 행위**를 통해 역사를 주관하신다.
2. 하나님의 말씀이 **언약 안에서 어떻게 성취**되고 있는지 서술된다.
3. **역사 그 자체가** 하나님의 백성을 향한 **하나님의 선포**다.

### Key word와 언약 [삼]
- 역사서 = 여호수아~역대기, 12권 〔확인 대기 ①〕
- **Key word = 하나님의 주권**
- **역사의 이해는 언약을 통해서**
  - **일방적(맹세) 언약** — 아브라함(창 12; 15; 17; 22장), 이삭(26장), 야곱(28장)
  - **조건적(행위) 언약** — 시내산 언약(출 19–24장), 책임과 의무, 회막 = 언약 갱신
  - **다윗 언약**(삼하 7장) = 일방적 언약 + 조건적 언약

### ‘역사’라는 말 [대]
- 시간 속에 실제로 일어난 일 = **사건** / 사건에 대한 기억 = **역사** — 기억은 주관적 → **역사의 인식 차이**
- 성경의 역사 = **원독자와 저자의 입장이 만나는 곳** → **목적을 지닌 역사 진술**
- **다름 vs 틀림** — 같은 사건을 다르게 쓴 책(사무엘·열왕기 ↔ 역대기)은 틀린 것이 아니라 목적이 다르다
- 이스라엘의 역사 = **언약이 성취되어 가는 과정**: 하나님께서 약속을 이루기 위해 무엇을 하셨는가? 백성은 약속을 받고 어떻게 반응했는가?

### 역사적 방법 (책마다 묻는 질문) [수A]
- 사건의 대략적인 때 / 하나님이 쓰신 사람들 / 그때의 적과 하나님이 그들을 어떻게 쓰셨는가 / 그 땅의 역사와 문화

## 3. 두 관점 — 선지자와 제사장 [대]

| | 사무엘서 · 열왕기 | 역대기 |
|---|---|---|
| 관점 | **선지자적 관점** | **제사장 관점** |
| 역사의 성격 | 정치적인 역사 | 종교적인 역사 |
| 중심 | 전쟁 중심 | **성전 중심** |
| 범위 | 북이스라엘 · 남유다 | **남유다에 주목** |
| 초점 | **인간의 실패**(불순종) | **하나님의 성공**(신실하심) |

- 열왕기 강의: 저자는 **신명기에 근거한 역사관**, **선지자적 특성**을 가진 사람 [왕A]
- 역대기 강의: 저자는 **족보, 제사장, 성전, 제사장과 율법**에 관심 [대]
- 〔정리자 해석〕 같은 왕을 두 책이 다르게 그린다 — 아비얌/아비야(열왕기 8절 / 역대기 22절), 여호사밧(51절 / 102절), 므낫세(회개 기사는 역대기에만) [대]. 끝맺음도 다르다: 열왕기는 **여호야긴의 석방**(포로 안의 다윗 자손), 역대기는 **고레스의 “올라갈지어다”**(성전 재건).

## 6. 책을 가로지르는 줄기 〔정리자 해석〕

강의안들이 서로 이어 놓은 고리를 따라가면 역사서 전체가 한 이야기로 읽힌다. 각 고리의 근거는 괄호 안의 강의 자료다.

### 왕 — “왕이 없으므로”에서 “여호와가 왕이시다”까지
- 사사기: “왕이 없으므로 자기 소견대로” — 진정한 왕(다윗)이 필요하다 [삿A] / 그러나 “왕은 하나님이셨다”(삼상 12:12) [병행]
- 룻기: 다윗 왕조를 예비하심 [룻]
- 사무엘: 하나님께 합당한 왕은 누구인가 — 사울과 다윗 비교, 신명기의 왕의 규례(신 17장) [삼]
- 열왕기: 같은 규례로 솔로몬을 평가, 남북 왕들의 실패 [왕B][왕학2]
- 역대기: 다윗 언약은 끊어지지 않았다 — 회복될 다윗 왕가 = **메시야** [대]
- 에스라·느헤미야·에스더: 왕이 없는 귀환 공동체, 페르시아 왕 아래의 백성 — 그래도 **하나님의 선한 손**, **보이지 않는 주권**

### 성전과 하나님의 영광
- 실로 성막(수 18:1) → 실로가 무너짐, 이가봇(삼상 4장) [병행] → 언약궤가 다윗 성으로(삼하 6장) → 솔로몬 성전, 구름과 불(왕상 8장; 대하 5–7장) [왕B][대] → 성전 멸망(왕하 25장) → 스룹바벨 성전, 영광이 없음(스 6장) → **사람이 언약궤**(새 언약, 렘 31:33) [스느] → 성전 된 우리 몸(행 2장) [에]

### 언약 — 말씀대로 이루어짐
- 여호수아: “네 손에 넘겨 주었으니” — 약속의 성취 [수B] / 세겜 언약(종주권 조약 형식) [수A]
- 열왕기: “한 번 하신 말씀은 반드시 이루시는 하나님” [왕A]
- 느헤미야: 레 26장·신명기에 근거한 기도(느 1:8–9), 9–10장 언약 갱신과 13장의 언약 어김 [스느]
- 에스더: 출 17장 아말렉에 대한 말씀이 에스더서에서 성취됨 [에]

### 레위인과 율법
- 사사기–사무엘: “이스라엘에서 레위인의 역할이 무엇인지 상고해 보라” — 레위인의 실패 1·2·3 [병행]
- 사무엘·열왕기: 엘리 → 사독, 제사장 직분의 변화 [레위]
- 역대기: 레위인 정비(대상 23–26장), 여호사밧의 율법 교육 [대]
- 에스라·느헤미야: 레위인의 역할 9가지, 율법을 연구·준행·가르친 에스라(스 7:10), 율법 낭독(느 8장) [스느]

### 하나님을 찾음 / 마음
- 역사 이해의 열쇠 대하 15:2 “너희가 그를 찾으면 그가 너희와 만나게 되려니와” [대]
- 열왕기 “마음의 문제”(분열의 영적 원인) [왕학2], 다윗 = “A man after God’s own heart” [왕B]
- 역대기의 왕별 평가: 르호보암 “구하는 마음을 굳게 하지 아니함”, 아마샤 “온전한 마음으로 행하지 않음”, 웃시야 “마음의 교만” [대]

### 이방인과 언약 백성
- 라합(수 2장), 룻(모압 여인), 기브온 → 느디님 [수B][룻][스느]
- 에스라의 통혼 개혁 — 좋은 예(요셉·모세·라합·룻) / 나쁜 예(솔로몬·아합·여호람) [스느]
- 에스더 8:17 “유다인 되는 자가 많더라” [에]
